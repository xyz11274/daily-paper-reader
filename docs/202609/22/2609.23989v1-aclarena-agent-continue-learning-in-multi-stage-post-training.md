## 摘要
构建用于工业部署的通用智能体需要集成多种能力，而每种能力通常在不同的训练阶段获得。然而，目前尚无成熟的智能体持续学习（ACL）方案，且对现有集成范式之间的权衡了解甚少。为填补这一空白，我们提出了 ACLArena，一个用于全面研究、分析和评估 ACL 的框架。我们首先构建一个顺序训练流水线，并从模型层面和 token 层面这两个互补视角进行深入分析，解释遗忘与泛化的机制。在这些分析的指导下，我们系统比较了多教师同策略蒸馏、自蒸馏微调和模型合并，以评估它们在保留新获得能力的同时恢复先前学习能力的效果。通过大量实验，我们深入理解了能力如何跨阶段迁移。最后，我们提出了一种新的 ACL 配方，将高质量轨迹上的离线回放与由多个 LoRA 专家组成的路由网络相结合，每个专家均通过 RL 专门化，从而显著提升智能体跨多个领域学习的能力。在四个推理与智能体任务上，在域内和域外设置下进行的综合实验，证明了我们分析的价值以及方法的有效性。

## Abstract
Building general-purpose agents for industrial deployment requires integrating multiple capabilities, each typically acquired at a distinct stage of training. Yet there is currently no well-established recipe for Agent Continual Learning (ACL), with little understanding of the trade-offs among existing integration paradigms. To address this gap, we introduce ACLArena, a framework for comprehensively studying, analyzing, and evaluating ACL. We first build a sequential training pipeline and conduct an in-depth analysis that explains the mechanisms of forgetting and generalization from two complementary perspectives, the model level and the token level. Guided by these analyses, we systematically compare multi-teacher on-policy distillation, self-distilled fine-tuning, and model merging to assess their ability to recover previously learned capabilities while preserving newly acquired ones. Through extensive experiments, we develop a detailed understanding of how capabilities transfer across stages. Finally, we propose a new ACL recipe that combines offline replay over high-quality trajectories with a routed network of multiple LoRA experts each specialized via RL, substantially improving the agent's ability to learn across multiple domains. Comprehensive experiments on four reasoning and agentic tasks, evaluated under both in-domain and out-of-domain settings, demonstrate the value of our analysis and the effectiveness of our approach.

## 1. 核心问题与整体含义

- **研究背景**：工业级通用智能体依赖多阶段后训练，能力（CoT 推理、工具调用、指令遵循等）通常在不同阶段、不同环境与训练管线中依次获得。因此，训练一个智能体本质上是一个**持续学习（Continual Learning）问题**：既要习得新能力，又要保留旧能力。
- **核心痛点**：
  - 现有技术报告训练细节披露有限，缺乏受控条件下的范式对比；
  - 经典持续学习方法在智能体训练中不实用——回放需保留昂贵的环境与奖励管线，任务特定模块增加部署复杂度，联合重训随能力累积愈发昂贵；
  - ACL 领域缺少真实的测试床（testbed）与实用训练策略的受控比较。
- **整体含义**：论文构建了 **ACLArena** 框架，围绕三个递进式研究问题展开——**RQ1 现象**（顺序后训练如何重塑能力、何时遗忘/泛化）、**RQ2 机制**（遗忘与迁移的根本驱动因素）、**RQ3 方法**（能否复用先前模型缓解遗忘、促进迁移）。目标是为 ACL 提供可分析、可评测的基准，并给出可落地的训练配方。

## 2. 方法论

### 2.1 诊断基线：顺序训练（Sequential Training）

- 形式化：从预训练基座 π₀ 出发，按课程顺序 π₀ →D₁ π₁ →D₂ … →D_K π_K，每阶段在特定提示分布 D_k 与奖励 r_k（智能体阶段还与环境 E_k 交互）下优化。
- 采用固定课程 **Math → Search → E-commerce → Instruction Following**：数学与 IF 阶段直接 RL（GSPO 无 critic 算法），智能体阶段先拒绝采样 SFT 冷启动再 RL。
- 诊断视角：
  - **模型级**：对单位归一化 checkpoint 做 PCA，观察参数位移方向；计算任务向量 Δθ_k = θ_k − θ₀ 的余弦相似度矩阵。
  - **token 级**：固定 Seq-Math 解码出的 token 序列，后续所有 checkpoint 前向打分，按预测熵 H=0.5 nats 分箱，统计 top-1 预测一致性。

### 2.2 三种能力整合范式

- **MMOPD（多教师混合 on-policy 蒸馏）**：
  - 基础 OPD 用反向 KL：L_reverse = E[D_KL(π_student ‖ π_teacher)]，在学生自采样轨迹上做 token 级监督；
  - 问题：反向 KL 是 mode-seeking，在智能体轨迹的高熵决策点（如选择搜索查询/工具调用）会熵坍缩、训练崩溃；
  - **混合 OPD（MOPD）**：在高熵 token 上注入经 top-q 截断、重归一化的正向 KL 项，即 L_MOPD,t = L_reverse,t + γ·1[H_tea>α]·Σ_{v∈S_q} π̃ log(π̃/π_student)，γ=0.5、熵阈值 0.3、top-q=16；
  - **多教师扩展**：学生从 π_K 初始化，在平衡混合提示流 D_mix 上训练，每个 prompt 带域标签，仅由**该域对应的教师**打分（路由而非集成），环境产生的 token（工具观测、模拟用户轮次）从损失中掩码。

- **SDFT（自蒸馏微调）**：
  - 为每个任务从基座独立训练一个 oracle 专家 π*_k；
  - 对 oracle rollout 按最终奖励正确性、工具调用格式、交互协议合规过滤，并去重保多样性，得到轨迹集 T_k；
  - 用标准 SFT 损失（负对数似然）在混合数据上训练 π_K，需调数据混合比 P 与课程顺序。

- **MM（模型合并）**：
  - 训练-free：θ_merge = θ₀ + Σ λ_k(θ_k − θ₀)，λ_k 为任务向量权重；
  - 探索均匀平均、网格搜索加权、能力均衡加权三类方案。

### 2.3 提出的方法：MLE（Mixture of Low-Rank Experts）

- **动机**（三条设计原则）：① SDFT 能把异构轨迹快速整合为共享能力中心；② 不同任务优化方向仅部分对齐，单一共享参数天然易受跨阶段干扰；③ RL 更新幅度远小于 SFT，剩余的环境特化可用轻量残差表示。
- **架构**：以 SDFT checkpoint 为共享主干并冻结；为每个阶段实例化独立的 LoRA 专家，在其对应环境中用 RL 优化，即 θ_k = θ_shared + Δθ_k。
- **关键性质**：残差参数隔离——学习新阶段只新增 LoRA 专家，不修改主干与旧专家，从根本上防止后续阶段覆盖已获能力；推理时依据 agent 执行上下文中可观测的交互环境路由到对应专家，**无需 benchmark 身份或真实任务标签**。

## 6. 主要结论与发现

- **Finding 1｜任务诱导仅部分对齐的参数更新**：四个单任务 oracle 在 PCA 中方向各异；任务向量中 Math 与后续域近乎正交（cos≈0.08），E-commerce 与 IF 近乎共线（cos=0.98，因累积嵌套所致），剥离共享前缀后各域 RL 增量近似正交（|cos|≤0.004）。顺序训练只能部分调和这些错位更新，导致转移与遗忘不均衡。
- **Finding 2｜共享模型整合必然产生权衡**：MMOPD 恢复数学（10.21→21.25）与搜索（33.5→45.2），但 MMLU/IF-Bench 略降；SDFT 搜索恢复更强（NQ 48.3、多跳 38.0），却大幅损伤电商（τ3-Telecom 45.9→21.7）与 IF-Eval（84.8→53.6）；MM 的 MMLU 最高（80.3）但电商/IF 较弱。没有单一共享 checkpoint 能全面占优。
- **Finding 3｜SFT 建立行为，RL 精炼能力**：SFT 产生大而方向一致的参数更新（相对幅度为 RL 的 3–7 倍），负责教会任务接口与合法格式，但会覆写旧能力；RL/MMOPD 做更小、更 policy-local 的更新，负责能力精炼与巩固。直接对搜索任务做 RL（无 SFT 冷启动）会导致格式违规与截断率飙升。
- **主结果**：MLE 在域内基准上接近独立训练的任务专家，并在 GPQA、单跳/多跳搜索、mock 域上取得所有对比方法中的最佳成绩，说明其优势不止于保留能力，还支持域外泛化。
- **训练稳定性**：vanilla 反向 KL OPD 在智能体搜索任务上崩溃（截断率升至 100%、有效率为 0），混合 OPD 训练稳定且能锐化关键决策 token。

## 7. 优点

- **问题定位清晰且有价值**：把工业级智能体多阶段后训练显式建模为持续学习问题，填补了"缺少真实测试床与受控比较"的空白。
- **诊断深入且双视角互补**：模型级（PCA、任务向量余弦）与 token 级（按熵分箱的预测一致性）结合，指出遗忘集中在少数高熵决策点，而低熵多数 token 几乎不变——这一发现对理解与设计干预手段都有指导意义。
- **范式比较公平**：统一基座、统一工具格式、统一评估配置，并对每种范式做最佳配置调优，避免"稻草人"式对比。
- **方法有明确的分析驱动**：MLE 的共享主干 + 参数隔离 LoRA 专家设计直接对应三条实证发现，且推理时无需任务标签、每阶段仅增加少量参数，工程可落地性较强。
- **域内 + 域外双重评测**，并给出跨初始化更新余弦（0.77 vs 无关任务 0.05）等定量证据支撑"SFT 是数据驱动的强变换"这一论断。

## 8. 不足与局限

- **覆盖面受限**：仅使用 Qwen3-8B-Base 与固定的四阶段课程，遗忘模式与方法权衡能否推广到其他模型家族、其他训练顺序、更长训练序列尚不清楚。
- **路由假设较强**：MLE 依赖可观测的环境上下文选择专家；当上下文模糊、交互过程中发生变化，或单个 episode 需要组合多种特化时，其有效性未被验证。
- **算力信息不完整**：仅说明使用两个 H200 节点，缺少总 GPU 时长、各范式算力/显存开销的定量对比（如 MMOPD 的常数次教师前向在 K 增大时的实际成本）。
- **MLE 自身消融不足**：未报告 LoRA rank、专家数量、路由粒度等关键超参的敏感性分析。
- **统计与偏差风险**：主结果基于三次运行，部分域外指标方差较大（如 τ3-Mock 62.5±6.6）；SDFT 数据配比与课程顺序虽做了部分消融，但"最佳配置"的搜索空间未必穷尽。
- **应用限制**：MLE 每阶段需新增专家参数，长期部署下参数与路由管理成本会随阶段数增长；模型合并的权重扫描表明线性加权只能转移权衡而非消除干扰，说明该类方法天花板有限。
