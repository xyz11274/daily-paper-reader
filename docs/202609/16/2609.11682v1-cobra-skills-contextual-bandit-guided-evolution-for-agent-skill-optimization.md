## 摘要
大语言模型（LLM）智能体可以从既往任务经验中提炼出的可复用技能中受益，但现有的技能优化方法往往依赖代价高昂的基于执行的评估以及大量任务数据。我们提出 COBRA-Skills，一个高效框架，将技能优化建模为在动态演化的候选空间上的预算约束序贯优化。COBRA-Skills 将上下文老虎机引导的优先级排序与基于证据的技能演化相结合，有选择地将评估分配给有前景或信息量大的候选技能，同时依据执行反馈持续精炼技能种群。在六个异构智能体基准和三个目标模型上，COBRA-Skills 在对比方法中始终取得最强的平均性能，同时相较于 SkillOpt 将优化成本降低 55–58%，且每个基准仅使用 50 个唯一的优化样例。进一步分析表明，COBRA-Skills 对智能体运行框架的变化保持稳健，并且在目标模型自身用于技能生成与精炼时也能有效发挥作用。

## Abstract
Large language model (LLM) agents can benefit from reusable skills distilled from prior task experience, yet existing skill optimization methods often rely on costly execution-based evaluation and substantial task data. We introduce \textbf{COBRA-Skills}, an efficient framework that formulates skill optimization as budgeted sequential optimization over a dynamically evolving candidate space. COBRA-Skills couples contextual-bandit-guided prioritization with evidence-grounded skill evolution, selectively allocating evaluations to promising or informative candidates while continually refining the skill population from execution feedback. Across six heterogeneous agent benchmarks and three target models, COBRA-Skills consistently achieves the strongest average performance among compared methods, while reducing optimization cost by 55--58\% relative to SkillOpt and using only 50 unique optimization examples per benchmark. Further analyses show that COBRA-Skills remains robust to changes in the agent harness and performs effectively when the target model itself is used for skill generation and refinement.

## 1. 核心问题与研究动机

- **背景**：LLM 智能体在处理具有重复目标、流程、工具和失败模式的任务时，可从"技能"（skill）——即任务特定的准则、推理策略或工具使用流程——中获益，技能可注入上下文以辅助新任务求解。
- **问题**：高质量技能难以获取。
  - 人工编写需大量领域专业知识；
  - 直接用 LLM 参数知识生成易产生"看似合理但无根据"的指导；
  - 因此现有方法将技能构建建立在真实执行轨迹与反馈上，并采用迭代式演化精炼。
- **两大效率瓶颈**：
  1. **候选效用评估昂贵**：需通过"生成–评估–精炼"循环，把候选技能实际执行后才能观察其效用，预算易被低质技能浪费；
  2. **技能精炼本身昂贵**：需反复调用 LLM 分析轨迹、诊断失败、聚合修改，token 开销大。
- **核心挑战**：在有限算力与任务经验下，如何**有选择地分配候选评估**并**高效复用执行证据**，而非穷举评估与反复重写候选。
- **整体含义**：论文把技能优化形式化为**动态演化候选空间上的预算约束序贯优化**问题，用上下文老虎机（contextual bandit）在"评估分配"与"种群演化"之间形成闭环，兼顾性能与成本。

## 2. 方法论

### 2.1 问题形式化
- 设 $D_{opt}\subset D$ 为小型优化集，$T_0$ 为无技能初始轨迹；候选技能基于历史 $H_{t-1}$ 与执行证据迭代生成/精炼。
- 目标：在有限优化轮次 $T$ 内，从探索过的技能集合 $S_T$ 中找出泛化性最好的技能
  $$s^\star=\arg\max_{s\in S_T}\mathbb{E}_{(x,y)\sim D}[\text{Metric}(A(x;s),y)]$$
- 反馈 $F_t$ 可包含轨迹、性能分数、文本反馈等，并入历史 $H_t$ 与轨迹档案 $\{T_i\}$。

### 2.2 核心思想
- 将每个候选技能视为一个**上下文臂**，用其语义嵌入表示；目标智能体性能作为奖励。
- 技能集合随演化不断变化，恰好契合"臂特征描述 + 臂集合动态变化"的上下文老虎机设定。
- **闭环设计**：老虎机引导评估与种群保留；证据驱动的演化算子不断刷新候选空间。

### 2.3 关键技术细节（对应 Alg. 1）

- **神经奖励预测**：
  - 固定嵌入模型 $\phi$ 得到技能语义表示 $z_s=\phi(s)$；
  - 用轻量两层 MLP $f_\theta$（ReLU 隐层、标量输出）在历史 $H_{t-1}$ 上拟合，损失为 MSE + $\ell_2$ 正则：
    $$L(\theta)=\frac{1}{|H_t|}\sum_{(s_i,z_i,r_i)\in H_t}(f_\theta(z_i)-r_i)^2+\beta\|\theta\|_2^2$$

- **LinearUCB 探索奖励**：
  $$b_t(z_s)=\nu\sqrt{z_s^\top A_{t-1}^{-1}z_s},\quad A_{t-1}=\lambda I+\sum_{i=1}^{t-1}z_{s_i}z_{s_i}^\top$$
  - 语义空间中探索较少的区域获得更大不确定性奖励。

- **优先级分数**：
  $$U_t(s)=f_{\theta_{t-1}}(z_s)+b_t(z_s)$$
  - 每轮选择 $U_t$ 最高的技能，在 $D_{opt}$ 上由目标智能体评估；
  - 同一分数也用于种群更新时**剪枝**（淘汰预测效用与探索价值都低的技能）。

- **证据驱动的技能演化**（按对数调度周期性触发，条件为 $t-t_{last}\ge d$ 且 $\log(t/t_{last})\ge\eta$）：
  - **Regeneration（再生）**：仅从原始无技能轨迹 $T_0$ 独立生成新候选，不依赖父技能，保持多样性、避免早熟收敛；
  - **Rollout Mutation（轨迹变异）**：对当前轮被评估的技能 $s_t$，用本轮成功/失败轨迹作为具体证据做**保守的局部修改**；
  - **Crossover（交叉）**：当历史足够时，把已评估技能分为高/低性能组，采样一个强技能作骨干、另一个强技能作正向证据、弱技能作负向证据，进行性能导向的重组（不直接拼接父技能）。
  - 每次更新剪掉 $m$ 个最低优先级技能，用新演化技能填补；新技能无继承奖励，需重新进入老虎机评估循环。

- **最终输出**：$H_T$ 中平均奖励最高的技能。

## 6. 主要结论与发现

- **性能最强**：三个目标模型上平均性能均最高，相对无技能基线分别提升 **+13.1 / +26.9 / +22.5** 个百分点。
- **成本显著更低**：总成本较 SkillOpt 降低 **55%–58%**，每提升 1 分的成本降低 **60%–69%**；教学模型 token 减少 67%–80%。
- **样本高效**：每基准仅用 **50 个唯一优化样例**。
- **harness 泛化**：在 Claude Code（68.2）与 Codex（72.4）下同样最优。
- **自教学可行**：用目标模型自身替代 GPT-5.5 时，性能仅从 73.5 微降至 72.5，成本减半，仍明显优于 SkillOpt。
- **跨模型可迁移**：36 个跨模型迁移中 **34 个**优于对应无技能基线，说明技能捕获的是任务级可复用策略。
- **消融结论**：去掉 Bandit 或 Evolution 各降约 2.2/2.4 分，Best-of-30 低 2.5 分——增益并非来自"候选更多"，而是来自自适应评估分配 + 候选空间演化。
- **探索系数**：$\nu$ 在 0.1 时最优，过大或过小均下降，印证探索–利用平衡的重要性。

## 7. 优点

- **问题形式化新颖**：把技能优化建模为"动态演化候选空间上的预算约束序贯优化"，并用上下文老虎机自然刻画"候选效用不确定 + 候选集合动态变化"。
- **算法闭环设计巧妙**：同一优先级分数同时用于**评估分配**与**种群剪枝**，最大化复用；演化算子与执行证据严格对应（再生/变异/交叉各有明确证据来源），避免凭空生成。
- **样本与成本双高效**：仅用 50 例优化样本，教学 token 大幅减少，成本/收益比显著优于基线。
- **评估较全面**：覆盖 6 类异构任务、3 档能力模型、多 harness、自教学、跨模型迁移、组件消融与超参敏感性，且固定测试集、固定超参跨模型/基准使用。
- **实用性好**：自教学设置让框架在无强外部教师时仍有效，降低部署门槛；技能可跨模型迁移。
