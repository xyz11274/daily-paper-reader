## 摘要
大型语言模型智能体日益依赖复合程序进行检索、工具使用、推理与验证，然而其失败往往源于局部过程性决策。现有的强化学习与提示优化方法通常依赖标量奖励或反复修改整个提示，难以在保持智能体冻结的同时捕捉并复用过程性改进。为解决这一问题，我们提出自然语言策略梯度（NLPG），一种外部策略记忆方法，用于在不改变固定智能体模型参数或程序结构的情况下改进其表现。NLPG 诊断执行轨迹，将下游反馈沿模块图反向传播，并将反复出现的失败转化为路径局部的自然语言修正，这些修正被聚合为有界的策略更新以用于后续执行。在涵盖记忆、推理、指令遵循与证据验证的六个基准上，NLPG 平均比每个基准所列最强基线高出 8.71 个百分点。这些结果表明，经过评估的过程性经验可以转化为局部且可解释的策略更新，从而实现冻结智能体的持续改进。

## Abstract
Large language model agents increasingly rely on compound programs for retrieval, tool use, reasoning, and verification, yet their failures often arise from local procedural decisions. Existing reinforcement-learning and prompt-optimization approaches typically rely on scalar rewards or repeatedly modify entire prompts, making it difficult to capture and reuse procedural improvements while preserving a frozen agent. To address this problem, We propose Natural-Language Policy Gradients (NLPG), an external policy-memory method for improving a fixed agent without changing its model parameters or program structure. NLPG diagnoses execution traces, propagates downstream feedback backward through the module graph, and converts recurring failures into route-local natural-language corrections that are aggregated into bounded policy updates for subsequent executions. Across six benchmarks covering memory, reasoning, instruction following, and evidence verification, NLPG also outperforms the strongest listed baseline for each benchmark by 8.71 percentage points on average. These results provide evidence that evaluated procedural experience can be transformed into local and interpretable policy updates, enabling continual improvement of frozen agents.

## 1. 核心问题与整体含义

- **研究背景**：大语言模型（LLM）智能体越来越多地以“复合程序”形式工作——一个固定程序协调多次模型调用、检索操作、工具使用与中间表示，再产出最终答案（如 ReAct、Toolformer、AutoGen、DSPy 等范式）。
- **核心痛点**：这种分解提升了能力，却带来**信用分配（credit assignment）问题**。一个失败的最终答案，可能源于早期的查询构造、遗漏的实体、错误的内存写入，或最终的合成步骤。因此：
  - 基于参数的强化学习（RL）优化标量目标，需要大量 rollout，且可解释性有限；
  - 非参数的提示优化器（如 PromptBreeder、MIPROv2、TextGrad、GEPA）反复修改**整段提示**，反馈粗糙，可能改动与错误无关的部分；
  - 长期记忆系统主要存储/检索交互内容，缺乏从“被评估的失败”到“责任模块策略”的显式信用分配。
- **整体含义**：论文提出 **NLPG（Natural-Language Policy Gradients，自然语言策略梯度）**，一种**参数无关（parameter-free）的外部策略记忆方法**。它保持基准程序、模型参数、检索后端**完全冻结**，仅通过注入有界的过程性指令来改进智能体，实现**局部化、可解释、可复用的持续自我演化**。
- **一句话定位**：把“经过评估的过程性经验”转化为“路由局部的自然语言策略更新”，让冻结的智能体也能持续变强。

## 2. 方法论

### 2.1 核心思想
- 将策略执行与策略改进**分离**：执行时每个模块使用其路由对应的策略；评估后，把观察到的失败沿**已记录的模块依赖图反向传播**，归因到责任模块或任务族策略，而非整个智能体或全局提示。
- 用“自然语言梯度”类比数值梯度：`∂text` 表示语言层面的反馈变换，`∇LLM` 表示将输出与下游反馈转化为文本修正的 critic 操作。

### 2.2 关键概念与符号
- **程序模块 b**：执行过程中的可调用单元（检索、工具、验证、解析等），第 j 次调用产生显式输出 `o_{i,j}`。
- **策略记忆 M_t**：按任务类别或程序模块索引，`M_t = {M^a_t}`，存储简短自然语言指令（过程性经验，而非任务特定参考答案）。
- **执行轨迹 τ_i**：`τ_i = (x_i, {o_{i,j}}, y_i)`，只含可观察输出，不含隐藏推理。
- **失败**：可识别的偏差，用失败签名 s 表示，可关联一组策略记忆索引。
- **自演化目标**：`M_{t+1} = Update(M_t, {(τ_i, z_i)})`，其中 M_t 在评估轮内固定，M_{t+1} 仅在后续轮加载。

### 2.3 算法流程（三阶段）

**（1）路由策略记忆与选择**
- 对模块路由任务，`a_{i,j}` 为第 j 步调用的模块；对任务族路由任务，为任务族。
- 候选池：`C_{t,i,j} = Dedup(M^{a_{i,j}}_t ∪ M^gen_t)`，去重后按历史优先级 `w_t(m)` 排序，取 Top-K：`P_{t,i,j} = TopK_{w_t}(C_{t,i,j}, K)`。
- 策略注入：`c_{i,j}(M_t) = c^base_{i,j} ∥ Format(P_{t,i,j})`，即把有界策略附录拼接到原始上下文后。

**（2）自然语言策略梯度（反向传播）**
- 失败诊断：`D_B(τ_i, z_i) = (α_i, S_i, e_i)`，α_i 为失败权重（正确=0，失败=1），S_i 为偏差类型集合，e_i 为执行标识符（用于统计跨执行支持度）。
- 受 TextGrad 启发，沿模块依赖图**逆拓扑序**传播任务级语言反馈 L_i。
- 输出级梯度：`∂text L_i / ∂y_{i,j} = ∇LLM(o_{i,j}, F^down_{i,j})`。
- 路由级梯度：`g^text_{i,j} = ∂text L_i / ∂r_{i,j} = ∇LLM(M^{a_{i,j}}_t, c_{i,j}, o_{i,j}, F^down_{i,j})`。
- 传播在无进一步反馈分配时沿分支终止，修正严格遵循观察到的依赖关系。

**（3）跨执行聚合与策略更新**
- 按路由 a、失败类型 s、归一化修正文本 u 分组。
- 保留评分：`w_{a,s,u} = |E_{a,s,u}| / max(N_a, |E_a|, 1) × α_i × κ_{i,j}`，三项分别代表**跨执行支持度、失败权重、critic 置信度**。
- 经安全过滤（去除空、重复、过具体、过长、标签泄漏、不安全指令）后与当前记忆合并为候选 `cM_{t+1}`。
- **仅在配对留出验证满足增益与回归约束时**才提升该候选，否则保留 M_t。被提升的策略在下一轮提供 Top-K 策略。

## 6. 主要结论与发现

- **总体性能**：六个基准上平均超越各基准最强基线 **8.71 个百分点**；单基准提升区间为 2.23–23.11 点。
- **LoCoMo**：86.72 总体（+5.17），多跳 +4.14、时序 +10.70、开放域 +9.72、单跳 +2.85——**过程组合性越强，收益越大**。
- **迁移套件**：Qwen3-8B 平均 59.00（GEPA 51.09，+7.91）；GPT-4.1 Mini 平均 63.33（GEPA+Merge 59.43，+3.90）。
- **HaluMem**：Memory Accuracy 96.20、QA Accuracy 85.37（Memory Integrity 70.25 略低于 ProMem 的 73.80）。
- **LongMemEval**：71.80，高于 ProMem（69.57）与 LightMem（68.64）。
- **消融结论**：移除文本梯度降幅最大（5.3%），移除策略更新或失败签名降 4.0 点，移除路由信用再降 3.3 点——**文本反馈与模块级信用分配是收益关键**。
- **受控干预**：specificity 策略在检索覆盖不变（recall=1.0）下，把过泛答案“musician”修正为“guitarist”，证明局部策略可修复答案特异性。
- **核心论断**：收益来自外部策略记忆与更新机制，而非额外模型调用、更大推理预算或特定答案格式。

## 7. 优点

- **方法层面**：
  - **参数无关、结构冻结**：不改模型权重、程序结构、检索索引，部署成本低、可解释性强。

  - **自然语言梯度形式化**：用 `∂text`、`∇LLM` 类比数值梯度，概念清晰，且修正可读、可复用。

- **实验层面**：
  - 数据划分严谨（高层分组键、构造/选择/测试三分离），有效防止信息泄漏。

  - 消融与反馈质量分析细致，区分了“诊断质量”与“端到端修复成功率”两个互补维度。
  - 主动报告负面/中性结果（如 Memory Integrity 未夺冠、修复率温和、单例回归），学术诚实度较高。
