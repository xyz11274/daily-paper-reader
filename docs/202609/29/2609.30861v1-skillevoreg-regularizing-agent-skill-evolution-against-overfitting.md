## 摘要
语言模型智能体越来越多地通过将执行经验转化为可复用的外部技能来提升自身能力。然而，反复的技能更新本身构成了一种学习过程：局部有用的编辑可能累积成冗余或任务特定的指令，而新的更新可能破坏先前有效的行​​为。我们将这一问题视为技能演化过拟合，并提出了 SkillEvoReg，一个受神经网络训练中抗过拟合技术启发的通用技能演化正则化框架。SkillEvoReg 结合了训练时技能丢弃（扰动更新生成）与复杂度感知局部正则化（控制不必要的结构增长），以及因果反例验证（CCV），后者对候选特定的回归提供有针对性的行为验证。我们在异构技能演化系统中实例化该框架，同时保留每个系统原生的技能演化器和任务评估器。在 SkillOpt、SkillEvolBench 和 ContinualSkillBench 上，SkillEvoReg 在保持有竞争力的下游能力的同时，持续控制技能状态增长，改善了若干迁移和后期演化结果，并识别出仅靠结构指标无法揭示的更新级回归。这些结果表明，显式正则化是对日益强大的技能更新器的有益补充。

## Abstract
Language-model agents increasingly improve by converting execution experience into reusable external skills. Yet repeated skill updates form a learning process of their own: locally useful edits can accumulate into redundant or task-specific instructions, while new updates can disrupt behavior that previously worked. We study this problem as skill-evolution overfitting and introduce SkillEvoReg, a general regularization framework for skill evolution inspired by anti-overfitting techniques in neural-network training. SkillEvoReg combines training-time skill dropout, which perturbs update generation, and complexity-aware local regularization, which controls unnecessary structural growth, with causal counterexample validation (CCV), which provides targeted behavioral validation of candidate-specific regressions. We instantiate the framework across heterogeneous skill-evolution systems while retaining each system's native skill evolver and task evaluator. Across SkillOpt, SkillEvolBench, and ContinualSkillBench, SkillEvoReg consistently controls skill-state growth while preserving competitive downstream capability, improves several transfer and later-stage evolution outcomes, and identifies update-level regressions that structural metrics alone cannot reveal. These results suggest that explicit regularization is a useful complement to increasingly capable skill updaters.

## 1. 核心问题与整体含义

- **研究背景**：语言模型智能体（LLM Agents）正从一次性技能生成转向**反复的技能演化**——将执行经验持续转化为可复用的外部技能（指令、流程、代码、结构化资源）。这一范式使智能体无需修改模型参数即可持续自我改进。
- **核心问题**：反复的技能更新本身构成一个独立的学习过程，会产生**技能演化过拟合（skill-evolution overfitting）**。具体表现为三种可独立出现的失效模式：
  - **结构性累积**：不断添加规则、示例或狭窄例外，却无相应的可迁移收益。
  - **语义特化**：将仅对近期轨迹有用的属性提升为广泛适用的指令。
  - **更新诱发的行为回归**：新编辑破坏了先前技能已支持的行为。
- **关键洞察**：这三种失效模式**不一定同时出现**——结构可能大幅膨胀但性能尚未下降；一个简洁的编辑也可能引入狭窄回归而不显著增加技能体积。因此，**仅靠性能退化或技能复杂度都不足以刻画技能演化过拟合**。
- **动机实验**：作者在 SpreadsheetBench 上对 SkillOpt 做了 8 轮纵向追踪。迁移性能在第 4 轮达到峰值（46.67%），此后 IID 准确率升至 61.67% 而迁移性能降至 37.50%，IID–迁移差距从 7.50 扩大到 24.17 个百分点；同时技能词法长度膨胀至初始值的 23.6 倍。这清晰展示了"峰值后迁移退化"模式。
- **整体含义**：论文主张将**正则化**作为技能演化的第一类组件，而非仅依赖越来越强的技能更新器。

## 2. 方法论

### 2.1 核心思想

借鉴神经网络训练中的抗过拟合机制（dropout、容量正则化、数据增强/对抗训练），将其**功能角色**（而非具体实现）迁移到离散的、语言生成式的技能演化过程中。框架保留各系统原生的技能演化器与评估器，仅在**候选更新边界**插入三个互补的正则化器。

### 2.2 关键技术细节

**（1）训练时技能丢弃（Training-Time Skill Dropout）**

- 将当前技能状态表示为局部有意义的**技能原子**集合 A(S_t) = {a₁, ..., aₘ}（如单条指令、列表项、过程块）。
- 采样掩码子集 M_t，构造临时丢弃视图 S^drop_t = Mask(S_t, M_t)。
- 在扰动视图下生成训练轨迹与原生更新，仅提取该上下文下学到的**变化量** Δ^drop_t = Diff(S^drop_t, S̃^drop_{t+1})。
- 通过 Reconcile 操作将该变化迁移回完整技能：S^drop_{t+1} = Reconcile(S_t, Δ^drop_t)。
- **关键不变量**：掩码只影响更新生成，被掩码原子在后续正则化前恢复，**绝不视为候选删除**；冻结评估始终使用完整技能。
- 与神经 dropout 的类比在于**扰动作用的时机**：神经 dropout 扰动参数更新所依赖的表示，技能丢弃扰动技能更新所依赖的外部上下文。

**（2）复杂度感知局部正则化（Complexity-Aware Local Regularization）**

- 定义阶段局部变化 Δ^comp_t = Diff(S_t, S^drop_{t+1})，计算复杂度信号 c_t = f_comp(φ(S_t), φ(S^drop_{t+1}), φ(Δ^comp_t))，其中 φ 汇总词法规模、原子组织、结构碎片化、可执行代码结构等可观测属性。
- 当触发结构重审时，**限制编辑范围**：D_t = 候选引入/修改的原子，Ω_t = D_t ∪ Related(S_t, D_t)。这一局部性约束防止结构庞大的候选触发对整个技能的无限制重写。
- 对每个候选原子 a ∈ D_t，局部编辑器选择操作 o_a ∈ {NOOP, MERGE, REWRITE, DELETE}（受 Mem0 的记忆调和机制启发）。
- **NOOP 明确允许保留新增结构**（当它携带独特有用行为时），因此**复杂度降低是正则化手段而非目标本身**。
- 复杂度度量 C(S) 的实例化公式：对每个原子 aᵢ，C(S) = Σ(τᵢ/100 + 0.2 + Lᵢ/20 + 2Bᵢ/5 + 2Dᵢ/3)，其中 τᵢ、Lᵢ、Bᵢ、Dᵢ 分别为词法单元数、非空代码行数、控制流数、外部依赖数。

**（3）因果反例验证（Causal Counterexample Validation, CCV）**

- 核心四路比较：要求**原始源任务上** incumbent 与 candidate 均合格（clean pair），然后在**同一攻击案例**上独立评估两者，仅当 incumbent 成功而 candidate 退化时才确认为回归。
- 三步流程：
  1. **源选择**：从训练历史 H_t 中选择 incumbent 已支持、candidate 仍合格的源 e_t。
  2. **攻击构造**：基于阶段局部变化 Δ^ccv_t = Diff(S_t, S^comp_{t+1}) 生成针对性扰动 a_t（针对候选引入/强化/收窄的假设、依赖或决策边界），得到攻击案例 x^ccv_t。
  3. **配对评估与判定**：r_old = Evaluate(S_t, x^ccv_t)，r_new = Evaluate(S^comp_{t+1}, x^ccv_t)，由 RegressionCriterion 判定 g_t。
- 确认回归时，执行**至多一次范围受限的修复**，修复区域由候选变化和攻击结果定位。
- **"因果"的限定**：四路比较控制了普通源任务失败和过难攻击，但作者明确声明这是**操作性因果**，而非随机 rollout 或多编辑候选下的形式化因果识别。

**（4）跨异构更新语义的适配**

- 三个正则化器角色不变，主要适配发生在原生更新边界：
  - **SkillOpt**：单文档的排序编辑，复杂度参与正则化验证门控。
  - **SkillEvolBench**：多技能库的局部补丁，增长预算触发有界局部正则化。
  - **ContinualSkillBench**：显式 CREATE/MODIFY 操作，CREATE 用绝对预算+库级比较，MODIFY 用相对增长。

## 6. 主要结论与发现

- **技能状态增长受控**：在三个基准上，SkillEvoReg 一致产生更紧凑的持久技能状态。SkillOpt 上复杂度降至基线的 0.32–0.49 倍；SkillEvolBench 上第二遍 token 增长减少 34.0%、复杂度增长减少 32.7%；ContinualSkillBench 五个领域的技能数、token 数、复杂度全面下降。
- **下游能力保持竞争力**：交付检查点上匹配或优于基线（SpreadsheetBench 58.50 vs 54.75；SearchQA 81.14 vs 80.46；LiveMath 35.02 vs 34.79）。
- **迁移与后期演化改善**：SkillEvolBench 部署成功率 33.33% vs 2-pass 的 29.44%，组合任务提升最显著（26.67% vs 13.33%）。
- **分布敏感权衡**：LiveMath 上 SkillEvoReg 最终检查点下降 4.84 个百分点，其中 85.7% 集中于 92 道"更强结果可证"的 meta-option 题目——说明正则化可能抑制在当前评估分布下仍有用的重复特化。
- **组件互补**：复杂度正则化限制状态增长，dropout 提升准确率但允许更大状态，二者结合得到最小技能与最强分数。
- **CCV 检测结构指标无法揭示的回归**：代表性案例中，incumbent 在包边界攻击下得 1.0，candidate 得 0.8（7/7 结果检查通过但 2 项过程检查失败），CCV 定位并修复了候选新增的原子。
- **部署侧副产品**：在执行路径相对可控的任务上（SpreadsheetBench、LiveMath、SearchQA），冻结评估 token 使用量分别降低 29.5%、38.6%、56.1%；但在外部工具主导轨迹的场景（ContinualSkillBench 部分领域）收益被掩盖。
