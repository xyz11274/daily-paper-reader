## 摘要
光学镜头设计是一项复杂的非凸优化挑战，高度依赖人类经验与直觉。现有的基于优化的自动镜头设计方法，若没有细致的人工调参，难以在庞大的参数空间中进行搜索。本文提出了 LensDesigner，一种模拟专家验光师问题解决流程的自主智能体框架。为克服初始冷启动问题，我们构建了 LensLib100K，一个广泛的光学镜头库，并采用光学感知检索来提供物理上有效的结构种子。在交互式物理仿真环境中，智能体执行宏观编排，同时接收即时光学反馈。此外，我们引入了一种由课程智能体引导的持续自演化机制。通过迭代解决难度逐渐增加的设计任务，智能体自主提取、积累并复用设计启发式方法，有效随时间演化其光学镜头设计专长。在评估层面，我们引入了 LensArena，一个包含 120 个多样化光学设计任务（涵盖极端配置）的标准化评估基准。在该基准上的大量实验表明，LensDesigner 显著优于公开可用的基线算法，实现了更高的成功率和优化效率。我们希望这项工作能为智能光学这一新兴领域提供启示。代码将公开可用。

## Abstract
Optical lens design is a complex, non-convex optimization challenge that relies heavily on human experience and intuition. Existing optimized-based automatic lens design methods struggle to navigate this vast parameter space without meticulous manual tuning. In this paper, we present LensDesigner, an autonomous agent framework that mirrors the problem-solving workflow of expert opticians. To overcome the initial cold start problem, we construct LensLib100K, an extensive optical lens library, and employ Optics-Aware Retrieval to supply physically valid structural seeds. Within an interactive physical simulation environment, the agent executes macroscopic orchestration while receiving immediate optical feedback. Furthermore, we introduce a continuous self-evolving mechanism guided by a curriculum agent. By iteratively solving design tasks with progressively increasing difficulty, the agent autonomously extracts, accumulates, and reuses design heuristics, effectively evolving its optical lens design expertise over time. At the evaluation level, we introduce LensArena, a standardized evaluation benchmark comprising $120$ diverse optical design tasks, covering extreme configurations. Extensive experiments on this benchmark demonstrate that LensDesigner significantly outperforms publicly available baseline algorithms, achieving superior success rates and optimization efficiency. We hope this work sheds light on the emerging field of intelligent optics. The code will be publicly available.

## 2. 方法论

### 2.1 核心思想
模拟人类验光师"不从头设计、而是基于已知构型起步"的启发式，通过**知识检索 + 交互式推理 + 自演化**的闭环自主系统完成镜头设计。

### 2.2 关键技术细节

- **LensLib100K 镜头库构建**：
  - 基于增强版 QGSO 算法，投入约 2000 GPU 小时生成 18 万个镜头设计。
  - 两项增强：①强制使用真实玻璃目录（可制造性）；②集成 ray aiming 机制保证大视场下光线追迹保真度。
  - 覆盖 FoV 8°–118°、#F 1.6–6.0。

- **Optics-Aware Retrieval（光学感知检索）**：
  - 采用"仿真器在环"离线近轴光线追迹，为每个镜头预计算物理指标（EFFL、TOTR、RMS、孔径半径），检索基于确定性物理性能而非语义相似度。
  - 核心是**非对称光学先验距离**：FoV 偏差权重高达 10.0（角拓扑难以扩展）；#F 采用非对称惩罚——候选孔径小于目标时重罚（1.0），大于目标时轻罚（0.5，缩小孔径光学安全）。
  - 两阶段检索：距离公式筛出 top-20，再由轻量 LLM 依据结构启发式选出 top-5。
  - **主动路由**：若为分布外查询（FoV 偏差>10° 或 #F 偏差>0.5），自动附加标准操作流程提示。

- **光学工具套件（Optical Tool Suite）**：
  - `align_effl`：确定性几何缩放匹配目标焦距，保持相对像差轮廓，设 300% 缩放上限。
  - `modify_lens`：单面参数调整，含五重物理护栏（光阑识别、孔径缩放限制、动态 F 数同步、材料白名单、循环预防）。
  - `split_lens`：将单正透镜分裂为双胶合，严格守恒光焦度 ϕ_orig = (n_d−1)/R_orig，分配比 r∈[0.2,0.8]。
  - `local_optimize`：有限差分梯度下降，目标函数显式惩罚 EFFL 偏差：RMS̃(R) = RMS(R) + β·RMS₀·max(0, |EFFL−EFFL₀|/|EFFL₀| − τ)，其中 β=0.5、τ=0.03。
  - `zemax_optimize`：DLS 光线追迹作为最终真值验证，玻璃中心厚度不可变以防"沙漏形"不可制造透镜。

- **宏观编排（Macro Orchestration）**：
  - 系统提示中嵌入确定性标准操作流程（SOP），强制"检索→宏观对齐→微观优化→最终验证"顺序。
  - 两级评估：先用近轴近似快速过滤极端偏差，再进入昂贵的 Zemax 追迹。
  - 滑动窗口断路器：最近 10 步内相同动作重复 3 次即强制策略切换。

- **光学感知自演化机制**：
  - 双智能体架构：课程智能体生成难度递增的设计任务，设计智能体尝试求解。
  - 因果轨迹记录：显式关联几何动作与 RMS/EFFL 物理指标变化。
  - 六重启发式过滤：优先保留 OOD 成功轨迹，并显式蒸馏失败经验（如材料替换边界条件）。
  - 知识接地蒸馏提示：拒绝教科书式常识，仅提取非直觉操作序列或极端参数组合。
  - 新颖性评估：Bigram-Jaccard 相似度>0.80 则拒绝，但极端数值参数仍视为新技能；技能序列化为持久 JSON 库注入后续提示。

- **LensArena 基准**：120 个设计任务，FoV 5°–180°、#F 0.7–8.0，70% 为相对 LensLib100K 的分布外查询，分易/中/难三级，每任务有目标 RMS 阈值判定成功。
