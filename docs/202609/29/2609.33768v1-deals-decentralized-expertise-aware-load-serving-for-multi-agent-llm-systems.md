## 摘要
多智能体系统（MAS）近来已成为一种有效方法，用于协调基于大语言模型（LLM）的智能体，通过结构化交互解决复杂任务。在实践中，MAS通常处理一连串异构且复杂的任务，要求智能体分解每个任务，然后自组织和自演化，以适应不断到来的任务，同时共享执行资源。然而，大多数早期MAS方法依赖集中式控制器或固定协调模式，这可能限制可扩展性或适应性。相比之下，现有的去中心化和动态MAS通常需要训练专用路由器或调用LLM进行智能体选择，导致大量计算成本和协调开销。为应对这些挑战，并实现高效的任务级自组织和自演化，以支持任务级和工作负载级协作，我们提出去中心化专长感知负载服务（DEALS），这是一个去中心化且低复杂度的框架，使智能体能够自组织并动态路由并发任务进行处理。具体而言，每个智能体维护传入任务的本地队列，其路由器根据积压量和成功率的差异，决定是在本地处理任务还是将其转发给邻居。同时，执行器在智能体内部和智能体之间并发处理独立任务，部分解决的任务可由其他智能体继续处理。实验表明，DEALS不仅在同构和异构智能体池中沿多个维度（例如答案准确率和任务吞吐量）提升性能，还以自组织方式平衡智能体专长和工作负载，从而实现有效的去中心化协调。

## Abstract
Multi-agent systems (MAS) have recently emerged as an effective approach for coordinating large language model (LLM)-based agents to solve complex tasks through structured interactions. In practice, MASs often handle a stream of heterogeneous and complex tasks, requiring agents to decompose each task and then self-organize and self-evolve to adapt to incoming tasks while sharing execution resources. However, most early approaches to MASs rely on centralized controllers or fixed coordination patterns, which can limit scalability or adaptability. In contrast, existing decentralized and dynamic MASs often require training dedicated routers or invoking LLMs for agent selection, resulting in substantial computational costs and coordination overhead. To address these challenges and enable efficient task-level self-organization and self-evolution for task- and workload-level collaboration, we propose Decentralized Expertise-Aware Load Serving (DEALS), a decentralized and low-complexity framework that enables agents to self-organize and dynamically route concurrent tasks for processing. Specifically, each agent maintains local queues of incoming tasks, and its router decides whether to process a task locally or forward it to a neighbor based on differences in backlog and success rate. Meanwhile, executors process independent tasks concurrently within and across agents, and partially solved tasks can be resumed by other agents. Experiments show that DEALS not only improves performance along multiple dimensions (e.g., answer accuracy and task throughput) in both homogeneous and heterogeneous agent pools, but also balances agent expertise and workload in a self-organized manner, enabling effective decentralized coordination.

- **研究背景**：基于大语言模型（LLM）的多智能体系统（MAS）已成为解决复杂任务的有效范式，通过任务分解、角色分工与协作产出答案。早期方法依赖集中式控制器或手工设计的静态角色与固定交互模式，后续工作虽在通信图结构、工作流优化、团队组成等方面有所改进，但仍是静态优化，缺乏自组织与自演化能力。
- **核心痛点**：
  - 集中式协调随系统规模增长会成为**可扩展性瓶颈与单点故障**。
  - 现有去中心化/动态 MAS 通常需要**训练专用路由器**或**调用 LLM 进行智能体选择**，带来大量训练成本、推理资源消耗与额外协调延迟。
  - 实际场景中 MAS 需同时服务**连续到达的异构任务流**，若不加以管理会导致智能体间**负载不均衡**，降低吞吐、增加延迟。
- **研究问题（Q）**：能否设计一个自组织、自演化的 MAS，以**低复杂度去中心化路由**协作解决多个并发任务，同时保持高准确率与低延迟？
- **整体含义**：论文提出 DEALS（Decentralized Expertise-Aware Load Serving），将"可用执行容量"与"任务解决能力"联合考虑，通过本地积压与成功率差异实现去中心化路由，无需额外 LLM 调用或单独训练路由模型，为多智能体 LLM 系统提供高效、可扩展的协调框架。

## 2. 方法论

### 2.1 核心思想
- 借鉴经典**背压路由（backpressure routing）**，但不仅用积压差异，还融合**任务类型特定的成功率差异**，在拥塞与能力之间做权衡。
- 每个智能体仅使用**本地状态 + 直接邻居广告信息**做路由决策，无中心控制器。
- 支持**智能体间与智能体内部并发执行**，部分完成的任务可被其他智能体续作。

### 2.2 系统模型
- 拓扑为固定有向图 \(G=(A,E)\)，任务随机到达某智能体，每个任务有类型 \(d \in D\)。
- 每个智能体 \(a_i\) 包含三部分：
  - **FIFO 队列** \(\{Q_i^d\}_{d\in D}\)：存储本地到达与邻居转发的任务；
  - **路由器**：决定本地执行还是转发邻居；
  - **执行器**：最多并发处理 \(C_i\) 个任务并返回答案。

### 2.3 三阶段任务处理流程
- **Stage (i)**：类型 \(d\) 任务按随机到达过程进入入口智能体，加入对应类型队列。
- **Stage (ii)**：智能体在有服务容量时出队并标记为"in flight"，路由器决定转发或本地执行；被转发任务在接收方重复此阶段。
- **Stage (iii)**：本地任务占用一个执行槽，从私有记忆中检索相似成功轨迹作为示范，用 ReAct 策略执行，返回最终答案或产生续作重新入队。

### 2.4 关键公式与路由机制
- **积压（Backlog）**：\(B_i^d(t) = Q_i^d(t) + I_i^d(t)\)，其中 \(I_i^d(t)\) 为已出队但仍在路由/执行的任务数。积压仅在任务被转发或完成时下降。
- **任务特定质量（成功率）**：采用 Beta 平滑估计
  \[
  q_i^d = \frac{N_{i,d}^+ + \alpha_q}{N_{i,d}^+ + N_{i,d}^- + \alpha_q + \beta_q}
  \]
  其中 \(N^+\)、\(N^-\) 为成功/失败次数，Beta 先验在样本少时稳定估计。
- **路由分数**：从 \(a_i\) 转发类型 \(d\) 任务到邻居 \(a_j\) 的分数为
  \[
  R_{i\to j}(d) = B_i^d - B_j^d + V(q_j^d - q_i^d)
  \]
  - \(V=0\) 时退化为仅看积压；
  - \(V\neq 0\) 时，能力更强的邻居即使积压更大也可能接收任务，直到积压差抵消质量优势。
- **决策规则**：对所有合格直接邻居（排除上一跳、满足跳数限制 \(H\)）计算分数，选最高者；仅当最高分**严格大于边际 \(m\)** 时转发，否则本地执行或拆分。
- **执行器设计**：
  - **记忆引导推理**：每个智能体维护成功轨迹私有记忆 \(M_i\)，检索最多 \(k\) 条相关轨迹作为示范；
  - **并发执行**：支持 `execute`（产出最终答案）与 `split`（解决子问题并将未完成工作返回本地队列）两种动作，独立任务在 \(C_i\) 个槽位中异步并行。
- **整体运行**：每个智能体并发运行 DISPATCH、PROCESS TASK、FINISH 三个过程；warm-up 阶段验证答案并更新成功率与记忆，test 阶段冻结记忆与成功率，仅积压继续变化。

## 3. 实验设计

### 3.1 数据集 / 场景
- **MATH**：700 训练 + 140 测试，覆盖 7 种数学类型。
- **BBH**：627 训练 + 100 测试，来自 20 个子任务。
- **MMLU-Pro**：从生物、计算机科学、历史、法律、数学 5 个学科各采样 40 训练 + 20 测试，共 200 训练 + 100 测试。
- 使用 Dirichlet 分布建模不均匀任务到达（\(\alpha=0.7\)）。

### 3.2 模型与智能体池配置
- 骨干模型：Qwen2.5-7B-Instruct、Mistral-7B-Instruct-v0.3、Llama-3.1-8B-Instruct。
- 配置：
  - 同构三智能体（3×Qwen）；
  - 异构三智能体（Qwen/Mistral/Llama 各一）；
  - 扩展至五、七智能体：同构 H5、H7（全 Qwen），异构 M5（3 Qwen + 1 Mistral + 1 Llama）、M7（M5 + 2 Llama）。

### 3.3 对比基线
- **Single Agent**：单智能体 ReAct。
- **AgentNet**：去中心化多智能体框架，用 LLM 执行/拆分/转发任务。
- **GPTSwarm**：将智能体建模为可优化计算图，学习边并多数投票。
- **AgentPrune**：剪枝通信图中冗余消息以降低 token 成本。

### 3.4 评价指标
- 答案准确率（Accuracy）；
- 测试吞吐量（每分钟完成任务数）；
- 质量权重 \(V\) 对任务分配与准确率的影响；
- 更大智能体池下的准确率。

## 6. 主要结论与发现

- **准确率**：DEALS 在四种配置下均取得最高平均准确率，12 项个体评估中 9 项第一；异构设置下平均 66.52% vs. 最强基线 AgentNet 的 57.76%。
- **吞吐量**：DEALS 吞吐量为 AgentNet 的 **4.7× 至 22.7×**，源于并发执行与去中心化负载分配。
- **自组织任务分配**：\(V=0\) 时最终答案在三智能体间近似均匀分布；\(V=80\) 时向更强的 Qwen 倾斜（MATH 上约 99%，MMLU-Pro 上约 64%），且该分配由本地路由自发形成，非预设策略。
- **专长-负载平衡**：异构池中 \(V=0\) 准确率最低，增大 \(V\) 在所有数据集上提升准确率（MATH 从 44.29% 到 73.57%）；同构池因能力相近，准确率对 \(V\) 不敏感。
- **更大池规模**：M5 从 \(V=0\) 的 47.86% 提升到 \(V=80\) 的 72.86%，M7 从 40.00% 提升到 67.86%，均超过最强单智能体的 66.43%；同构池变化很小。
- **总体结论**：将质量信息纳入路由对异构池尤为关键；DEALS 以低复杂度去中心化方式实现任务级自组织与自演化，兼顾准确率与吞吐量。

## 7. 优点

- **方法亮点**：
  - 将背压路由与任务特定成功率差异结合，同时兼顾**负载与专长**，思路简洁且理论上有经典队列稳定性支撑。
  - **完全去中心化**：仅用本地状态与直接邻居信息，无需中心控制器、无需训练路由器、无需额外 LLM 调用，显著降低协调开销。
  - 支持**智能体间与智能体内并发**，并允许部分完成任务被其他智能体续作，提升吞吐。
  - 通过单一权重 \(V\) 提供**可调节的专长-负载权衡**，用户可按场景调整。
- **实验亮点**：
  - 覆盖同构/异构、3/5/7 智能体、3 个数据集，验证了方法的通用性与可扩展性。
  - 通过 \(V\) 的敏感性分析与最终任务分配统计，直观展示了自组织行为。
  - 提供案例研究，清晰展示 split + forward + 续作的实际工作流。
  - 公开了较完整的实现参数（容量、跳数限制、拆分限制、Beta 先验、检索阈值等），可复现性较好。

## 8. 不足与局限

- **实验覆盖**：
  - 仅评估**完全图拓扑**，未涉及链、环、稀疏图等其他通信结构（作者在附录 B 中自述）。

  - 基准限于 MATH、BBH、MMLU-Pro，未覆盖更复杂或长程 agentic 任务。
  - 模型家族限于 Qwen、Mistral、Llama 三种 7B/8B 级别，未涉及更大或更多样化的 LLM。
- **偏差风险**：
  - 部分基线在个别数据集上表现异常低，可能受提示工程或适配差异影响，横向比较的公平性存疑。
  - 未报告多次运行的方差、置信区间或统计显著性检验。
  - warm-up/test 划分与成功率冻结机制可能对结果有影响，但未做敏感性分析。
- **应用限制**：
  - 成功率估计依赖 warm-up 阶段的验证反馈，在无标注或反馈延迟的场景中适用性受限。
  - 路由依赖邻居广告积压与成功率，通信开销虽低但仍需邻居状态同步。
  - 跳数限制 \(H\) 与拆分限制 \(K\) 为固定超参数，可能对任务分布变化不够自适应。
  - 未讨论安全性、隐私（邻居状态暴露）与故障容错等实际部署问题。
