## 摘要
多智能体强化学习（MARL）通常从零开始训练去中心化策略，要求智能体同时获得个体任务能力与协调能力。然而，许多多智能体问题都存在一个兼容的单智能体对应问题，其中底层任务可以孤立地学习。我们提出用于现有单智能体策略的多智能体观测变换（MATES），这是一种输入侧适应框架，适用于多智能体观测在保留单智能体任务信息的同时还暴露出可单独识别的邻居信息的任务。基于多智能体经验，MATES 学习一个小型适配器，将该观测映射为冻结的单智能体策略所期望的格式，从而在不更新单智能体策略本身的情况下诱导出适合共享环境的动作。MATES 不改变预训练策略的内部架构，并保留底层 MARL 算法的目标与更新过程。我们在终身路径规划、导航和协作发现任务上，使用同策略和异策略算法评估 MATES，涵盖离散与连续的观测和动作空间。在所有评估设置中，MATES 仅优化全策略训练参数量的 3.5-7.3%，却始终优于从零开始的 MARL 训练。它接近完全微调的性能，总体上与基于演示的基线方法相比具有竞争力，并且在训练期间未遇到的团队规模下仍保持较强的任务性能。这些结果证明，在这种观测结构下，无需修改编码个体能力的策略即可学习到有效的多智能体行为。

## Abstract
Multi-agent reinforcement learning (MARL) commonly trains decentralized policies from scratch, requiring agents to acquire individual task competence and coordination simultaneously. Yet many multi-agent problems admit a compatible single-agent counterpart in which the underlying task can be learned in isolation. We introduce Multi-Agent Observation Transformation for Existing Single-Agent Policies (MATES), an input-side adaptation framework for tasks whose multi-agent observations preserve the solo-task information while exposing separately identifiable neighbor information. From multi-agent experience, MATES learns a small adapter that maps this observation into the format expected by a frozen single-agent policy, inducing actions suited to the shared environment without updating the single-agent policy itself. MATES leaves the pretrained policy's internal architecture unchanged and retains the objectives and update procedures of the underlying MARL algorithm. We evaluate MATES using both on- and off-policy algorithms on lifelong pathfinding, navigation, and cooperative discovery, spanning discrete and continuous observation and action spaces. Across all evaluated settings, MATES optimizes only 3.5-7.3% as many parameters as full-policy training while consistently outperforming MARL training from scratch. It approaches the performance of full fine-tuning, remains competitive overall with demonstration-based baselines, and retains strong task performance at team sizes not encountered during training. These results provide evidence that, under this observation structure, effective multi-agent behavior can be learned without modifying the policy that encodes individual competence.

## 1. 核心问题与整体含义

- **研究动机**：多智能体强化学习（MARL）通常从零开始训练去中心化策略，要求智能体**同时**习得个体任务能力与多智能体协调能力，这带来了非平稳性等核心挑战。
- **关键观察**：许多多智能体问题存在一个**兼容的单智能体对应版本**，其底层任务可以孤立地学习。例如，单智能体导航只需沿路径到达目标，而多智能体导航还需避碰与协调。
- **核心研究问题（RQ1）**：能否在**不修改**已编码个体能力的策略的前提下，学习到有效的多智能体行为？
- **整体含义**：论文提出 MATES 框架，试图将已训练好的单智能体策略"冻结"后直接复用到多智能体场景，仅通过轻量的**输入侧观测变换**来适配多智能体交互，从而避免从零重学个体能力。

## 2. 方法论

### 核心思想
- 利用观测的**可分解结构**：多智能体观测 $\bar{o}_i = (o_i, N_i)$，其中 $o_i$ 是单智能体任务信息，$N_i$ 是邻居智能体信息。
- 冻结单智能体策略 $\pi_{solo,\theta}$，仅训练一个小型**观测适配器** $C_\phi$，将 $\bar{o}_i$ 映射为单智能体策略可接受的格式 $\tilde{o}_i$。

### 关键技术细节
- **两阶段流程**：
  1. 在单智能体对应任务中正常训练 $\pi_{solo,\theta}$；
  2. 冻结 $\theta$，在多智能体任务中仅优化适配器参数 $\phi$。
- **组合策略**：$\pi_{MATES,\phi}(a_i|\bar{o}_i) = \pi_{solo,\theta}(a_i | C_\phi(\bar{o}_i))$。
- **梯度机制**：虽然 $\pi_{solo}$ 冻结，但它仍在可微计算图中，梯度可穿过它回传以更新 $C_\phi$，但不更新 $\theta$。
- **Critic 处理**：同样冻结单智能体 critic，并在其前放置独立适配器；可选训练 critic 的 value head（MATES）或不训练（MATES-NH）。
- **实现变体**：适配器可共享（同质智能体）或独立；实验中采用共享适配器，使参数量与团队规模无关。
- **兼容性**：不改变底层 MARL 算法的目标与更新流程，仅增加轻量组件并限制优化范围。

### 算法流程（文字描述）
1. 用 RL 在单智能体任务上训练 $\pi_{solo,\theta}$；
2. 冻结 $\theta$，初始化观测适配器 $C_\phi$；
3. 定义组合策略 $\pi_{MATES,\phi}$；
4. 在多智能体环境中用 MARL 算法训练，仅更新 $\phi$（及可选的 value head）；
5. 返回训练好的 $\pi_{MATES,\phi^\star}$。

## 6. 主要结论与发现

- **RQ1（性能与参数效率）**：MATES 仅优化全网络 **3.5%–7.3%** 的参数（MATES-NH 为 1.0%–5.7%），却始终优于从零 MARL 训练，接近全微调性能。
- **RQ2（跨团队规模泛化）**：在训练团队规模之外（包括更大规模）仍保持强性能，且相对 solo 策略的优势随团队规模增大而扩大。
- **RQ3（性能来源）**：性能来自**预训练单智能体能力**与**观测适配**的结合；adapter-only 或随机冻结骨干均无法达到 MATES 水平。
- **RQ4（value head 适配）**：value head 训练**并非普遍必要**，仅在 POGEMA 等部分设置中略有收益，ISAC 下作用相反。
- **总体结论**：在观测结构满足 $\bar{o}_i = (o_i, N_i)$ 的条件下，无需修改编码个体能力的策略即可学得有效多智能体行为。

## 7. 优点

- **参数高效**：仅训练极小比例参数，显著降低多智能体训练成本。
- **架构无关**：不改变预训练策略内部结构，兼容多种策略架构与 MARL 算法。
- **无需演示数据**：与 PegMARL、R2BC 不同，MATES 不需要专家演示缓冲区或模仿学习更新。
- **强泛化性**：适配器训练于固定团队规模，却能泛化到未见过的更大团队规模。
- **实验覆盖广**：涵盖离散/连续空间、on/off-policy 算法、多任务与多团队规模。
- **消融清晰**：明确分离了 solo 能力与适配器的贡献，验证了方法有效性来源。

## 8. 不足与局限

- **观测结构假设强**：要求多智能体观测可显式分解为 $(o_i, N_i)$，且 $o_i$ 语义在部署后保持不变；论文未评估更广泛的兼容单智能体场景。
- **算力细节缺失**：未报告 GPU 型号、数量、训练时长，影响可复现性评估。
- **任务覆盖有限**：仅 3 个任务，且 POGEMA 仅用 IPPO，ISAC 无实现；未涉及异构智能体、竞争或混合动机场景。
- **基线适配偏差**：PegMARL 与 R2BC 为适配同质设置做了修改，可能未完全反映其原始性能。
- **value head 结论不统一**：RQ4 的答案因任务与算法而异，缺乏一致性解释。

- **应用限制**：方法依赖单智能体对应任务的存在与可训练性；若单智能体任务本身难以学习，MATES 的优势将受限。
