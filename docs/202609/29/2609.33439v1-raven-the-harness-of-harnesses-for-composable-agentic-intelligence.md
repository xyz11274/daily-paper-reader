## 摘要
随着大语言模型的发展，AI 智能体正从孤立的、特定领域的任务迈向长时程、跨领域的工作流。这一转变暴露出两个挑战：日益增加的驾驭复杂度使人工设计难以规模化，而对特定领域的更紧耦合限制了单一驾驭的通用性。因此，核心问题从如何为某一领域设计更强的驾驭，转变为如何自主构建专用驾驭、通过经验改进它们，并跨领域编排它们。我们提出 Raven，即“驾驭之驾驭”，一个开源多智能体生态系统，能够为特定模型和领域自动构建并演化模块化驾驭，将每个可执行的模型—驾驭对视为可组合的智能单元。为支持“全领域协作网络”，其宿主智能体分解目标、将子任务匹配到专用智能体、协调执行依赖并整合结果，同时宿主档案库与 EverOS 跨任务保存经验，而 Skill Forge 将这些经验转化为可复用的流程。我们的理论确立了在共享资源预算下，这种组合能够将可靠任务覆盖范围扩展到超过可用个体智能体的充分条件。在复杂且长时程的任务上，Raven 显著优于最先进的智能体系统，推动了可组合智能体智能的前沿。

## Abstract
As large language models advance, AI agents are moving beyond isolated, domain-specific tasks toward long-horizon, cross-domain workflows. This transition exposes two challenges: increasing harness complexity makes manual design difficult to scale, while tighter coupling to specific domains limits the generality of a single harness. The central question thus shifts from how to engineer a stronger harness for one domain to how to autonomously construct specialized harnesses, improve them through experience, and orchestrate them across domains. We introduce Raven, \emph{The Harness of Harnesses}, an open-source multi-agent ecosystem that automatically constructs and evolves modular harnesses for specific models and domains, treating each executable model--harness pair as a composable unit of intelligence. To support an \emph{All-Domain Collaboration Network}, its Host Agent decomposes goals, matches subtasks to specialized agents, coordinates execution dependencies, and integrates results, while a host archive and EverOS preserve experience across tasks and Skill Forge makes that experience available as reusable procedures. Our theory establishes sufficient conditions for such composition to expand reliable task coverage beyond that of the available individual agents under a shared resource budget. On complex and long-horizon tasks, Raven significantly outperforms the state-of-the-art agent systems, pushing the frontier of composable agentic intelligence.

## 2. 方法论：核心思想与关键技术细节

### 2.1 核心思想
- 将 `Agent(M_i, h_i)`（模型 + harness）作为**可调用执行单元**，由 **Host Agent** 统一规划、分配、协调。

### 2.2 理论框架（第 2 章）
- **任务相对能力**：`p_S(t;B) = P(V_t(ω, Y_S)=1, C_S ≤ B)`，即在预算 B 内正确完成任务的概率；可靠任务集 `C_S(B,δ) = {t : p_S(t;B) ≥ 1−δ}`。
- **兼容计划（Definition 1）**：良类型计划需满足 Hoare 式蕴含链 `I_{j−1} ⇒ A_j`、`I_{j−1} ∧ D_j ⇒ I_j`、`I_K ⇒ V_t=1`。

- **可靠性定理（Theorem 1）**：`q_t(ζ,π) ≥ [1 − Σ_j ε_j]_+`，**无需独立性假设**。
- **宿主级可靠性（Proposition 1）**：`p_{S_H}(t;B) ≥ (1−η_H)(1−ε̄)`。
- **超越个体能力（Corollary 1）**：当 `(1−η_H)(1−ε̄) ≥ 1−δ > max_a p_a(t;B)` 时，`t ∈ C_new(B,δ)`，即组合可覆盖个体无法可靠解决的任务。
- **任务族覆盖（Corollary 2/3）**：给出类型化任务文法（原始、顺序、fork–join）的编译构造与资源/误差递推，证明 `T_{n0,r0} ⊆ C_{S_H}(B,δ)`。

### 2.3 多智能体协作（第 3 章）
- **异构智能体注册表**：支持四种后端（进程内循环、CLI、ACP、OpenAI 兼容 API），记录 stateful / file-capable / progress-reporting 能力标签。
- **分阶段编排引导**：每轮仅携带引导摘要，需要多智能体时才加载完整引导，降低上下文成本。
- **图构建与准入**：五组检查（格式、图结构、能力、状态、环境），首个错误即拒绝并返回引导指针。
- **依赖就绪调度**：`Ready_jrt` 集合排除已提交与未裁决节点；共享并发信号量（默认 8）。
- **完成裁决**：独立 LLM 调用判断节点是否"accomplished"，负判定进入异常状态供宿主决策（continue / abandon / replan）。
- **澄清请求**：宿主优先从对话与记忆中自动填充答案，仅将无法回答的问题转给用户。
- **共享组记忆**：两阶段评估（close verdict + feedback verdict），按 owner 分区存储，默认关闭且未评估。

### 2.4 Harness 自演化（第 4 章，基于 HarnessBank）
- **四策略接口**：Memory、Planning、Capability、Action，围绕冻结模型 M。
- **诊断驱动演化**：从失败轨迹生成可测试干预假设（补丁 + 语义描述 + 激活规范）。
- **语义基因库**：`B_r: W_edit × Y_fail → H(X_edit) ∪ {⊥}`，每个（编辑类别, 病理标签）单元保留一个精英。
- **门控筛选**：有效性门 `g_valid`、激活门 `g_act`、配对增益门 `g_sig`（`t_pair ≥ λ_screen = 1.96`）。
- **竞争性档案更新**：仅完整训练评估可更新基因库；测试集不参与搜索。

### 2.5 记忆系统（第 5 章，EverOS）
- **情景轨迹形成**：语义边界检测 → 源片段 → MemCell（episode + 原子事实 + 前瞻 + 元数据）。
- **语义巩固**：在线聚类为 MemScene（相似度 + 时间窗 7 天），驱动用户画像更新。
- **重构式检索（HYBRID）**：BM25 + 稠密检索 → RRF 排序扩展 → 逻辑校准打分 → 事实可与父 episode 竞争。
- **用户上下文组装**：宿主 Markdown 档案 + EverOS 召回，`MemContext(q) = Archive(q) ++ Fence(Recall(q))`。
- **智能体经验**：case 提取（意图、方法、洞见、质量分）→ 技能生成，支持跨会话复用。

### 2.6 Skill Forge（第 6 章，基于 SkillCorpus）
- **策展目录**：96,401 个活跃技能，六阶段策展（解析、过滤、去重、质量评估、发布准入、嵌入索引）。
- **质量公式**：`qual_cur(s) = clip[0.85·qual_content + 0.15·p_src + bonus]`，硬标志（prompt_injection 等）直接拒绝。
- **任务感知检索**：三源（local / memory / hub）并发查询 → 名称分组 RRF 融合 → 代表选择 → 正文获取与策略检查 → LLM 门选择（正常上限 2，失败回退 5）。
- **经验驱动技能演化**：case 质量 ≥ 0.2 才触发；增量意图聚类 → 选择现有技能与支持案例 → 生成 add/update/none 操作 → 验证与血缘更新。

## 6. 主要结论与发现

- **组合可扩展可靠覆盖**：理论证明在共享预算下，具备互补局部能力、兼容交接与有界误差的组合系统，可解决个体智能体无法可靠解决的任务。
- **编排优势一致**：Raven 在 MAOB 全部 4 项指标、2 个 backbone 上领先，Exact Match 提升约 10.4–10.5 pp。
- **Harness 演化有效**：冻结 backbone 下，7 个 benchmark 的 held-out Pass@1 全部提升，证明执行策略适配可跨域迁移。
- **专用 harness 显著增益**：研究、编码、设计、运维四个领域均超越强基线，且部分场景成本更低。
- **技能复用有效**：策展技能库在 12 个 cell–benchmark 比较中全部提升；Raven 比 OpenClaw 更能将检索到的流程转化为成功执行（execute–verify–fix 循环）。
- **策展与检索缺一不可**：消融显示，去掉微调检索器（22.6% → 13.8%）或改用原始爬取（→14.9%）均显著下降。

## 7. 优点
