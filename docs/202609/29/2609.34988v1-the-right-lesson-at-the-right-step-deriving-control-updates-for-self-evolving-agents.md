## 摘要
自进化智能体通过复用过去经验来改善未来行为，通常以全局提示、记忆或反思的形式实现。然而，这些机制很少控制经验在何处生效。在长工具使用工作流中，同一教训可能纠正一个决策却干扰另一个决策，使得经验复用成为局部控制问题，而不仅仅是记忆问题。我们提出EvoCUE（通过证据的控制更新实现进化），一个从已完成的智能体执行中学习可复用控制程序更新的框架。EvoCUE将智能体表示为显式状态机控制器，其节点执行模型或工具调用，边定义控制下一步传递的位置。这使得工作流可在精确位置编辑，因此每个学习到的更新可以指定添加什么、在何处作用以及何时应用。从已完成的轨迹中，EvoCUE利用残余目标和观察到的执行轨迹来提出局部化的指令或技能编辑。每个候选更新在它将作用的位置进行评估，即从同一检查点恢复父控制器和编辑后的控制器，并比较它们的最终结果。被接受的编辑与适用性规则一起编译，在留出任务上确认，并由后续执行继承。我们在长工具使用环境中评估EvoCUE，其中学习到的约定必须到达正确的执行步骤。从一个没有基准特定引导指令的最小AppWorld控制器开始，EvoCUE学习到缺失的任务完成约定，并大幅提高了在Test-Normal和Test-Challenge上的成功率。在PAST-Bench办公工作流上，EvoCUE将组织要求从先前情节迁移到后续任务，提高了任务执行质量。这些结果表明，自进化智能体应将经验置于控制流内部，而不仅仅将其存储为文本。

## Abstract
Self-evolving agents improve future behavior by reusing past experience, typically as global prompts, memories, or reflections. Yet these mechanisms rarely control where experience takes effect. In long tool-use workflows, the same lesson may correct one decision but distract another, making experience reuse a problem of localized control rather than memory alone. We introduce EvoCUE (Evolution through Control Updates from Evidence), a framework for learning reusable control-program updates from completed agent executions. EvoCUE represents the agent as an explicit state-machine controller, whose nodes perform model or tool calls and whose edges define where control passes next. This makes the workflow editable at precise locations, so each learned update can specify what to add, where it acts, and when it applies. From completed trajectories, EvoCUE uses residual goals and observed execution traces to propose localized instruction or skill edits. Each candidate is evaluated at the point where it would act by resuming the parent and edited controllers from the same checkpoint and comparing their final outcomes. Accepted edits are compiled with applicability rules, confirmed on held-out tasks, and inherited by later executions. We evaluate EvoCUE on long tool-use environments where learned conventions must reach the right execution step. From a minimal AppWorld controller without benchmark-specific onboarding instructions, EvoCUE learns the missing task-completion convention and substantially improves success on Test-Normal and Test-Challenge. On PAST-Bench office workflows, EvoCUE transfers organizational requirements from prior episodes to later tasks, improving task-execution quality. These results show that self-evolving agents should place experience inside the control flow, rather than only store it as text.

## 1. 核心问题与整体含义

- **研究动机**：自进化智能体通常通过全局提示、记忆或反思来复用过去经验，但这些机制**很少控制经验在何处生效**。

- **关键例证**：AppWorld 中一条任务完成约定，放在第一步仅解决 5/16 任务，放在后续步骤则解决 14/16。
- **整体含义**：自进化智能体应将经验**嵌入控制流内部**，而非仅作为文本存储，才能让正确经验在正确步骤生效。

## 2. 方法论

### 核心思想
- 将智能体表示为**显式状态机控制器** C = (G, π, Ω)：节点执行模型/工具调用，边定义控制流向，边可携带指令。
- 每个学习到的更新需明确三要素：**添加什么内容、在何处作用、何时应用**。

### 关键技术细节
- **残余目标（Residual Goals）**：从已完成轨迹中估计指令要求中尚未被公开历史满足的部分，用于定位失败步骤。
- **局部化编辑**：候选编辑 δ 指定内容、位置（边）、作用域（当前调用/技能调用/下一步动作）和预期效果；支持指令编辑与结构编辑（插入 1–6 步可执行技能）。
- **配对试验（Paired Trials）**：从编辑作用前的检查点恢复父程序 C 与编辑程序 C⊕δ，共享前缀后各自运行至结束，比较最终得分差：
  - d_tj(δ; C) = Y_tj(C⊕δ) − Y_tj(C)
- **适用性规则拟合**：枚举至多两个等式测试的规则 q，选择最大化覆盖比例×平均效应−复杂度惩罚的规则：
  - q̂_δ ∈ argmax_q [ p̂_Sδ(q)·d_δ,q − λ|q| ]
  - 通过条件：至少覆盖 2 个任务、平均效应>0、加权增益>0。
- **编译、确认与继承**：通过的编辑编译为候选程序 C′，在独立确认任务上从任务起点比较 C′ 与 C，满足接受标准后由后续任务继承。
- **试验记忆**：记录所有接受与拒绝的试验，供后续提案参考，避免重复失败方向。

### 算法流程（一轮学习）
1. 选择提案与试验任务，划分独立确认集；
2. 索引公开轨迹、残余目标与历史试验；
3. 提案局部化编辑；
4. 对每个候选采样检查点，运行配对试验；
5. 拟合适用性规则，通过者进入候选集；
6. 编译候选程序，在确认集上比较，决定是否继承。

## 6. 主要结论与发现

- **AppWorld**：从最小控制器出发，EvoCUE 学到任务完成约定，Test-Normal 成功率从 13.7% 提升至 79.2%，Test-Challenge 从 6.7% 提升至 70.0%；场景成功率分别从 5.4%→57.1%、2.2%→44.6%。
- **位置至关重要**：同一指令在首步仅解决 5/16 任务，在重复入口解决 14/16；关键是**完成决策时指令是否可用**。
- **PAST-Bench**：任务执行分数从 0.608 提升至 0.772，增益为最大基线增益的 2.6 倍；未见家族从 0.35 提升至 0.73。
- **基线表现**：四个基线在相同协议下最多提升 4.8 个百分点（Test-Normal），Test-Challenge 无增益。
- **额外领域**：初始程序已高分或任务较短，EvoCUE 未接受任何更新，基线变化也很小。
- **核心发现**：经验驱动的适应应学习**复用何种经验**以及**经验应进入控制流的何处**。

## 7. 优点

- **问题定位精准**：将经验复用重新定义为局部控制问题，切中长工作流中经验错位的核心痛点。
- **方法设计优雅**：状态机表示使编辑位置显式化；配对试验从匹配检查点比较，排除前缀变异干扰，因果推断更干净。
- **适用性规则拟合**：借鉴因果异质性估计思想，用少量试验拟合何时应用编辑，提升泛化性。
- **试验记忆机制**：接受与拒绝的试验均保留，支持后续提案修正方向，避免重复失败。
- **实验严谨**：冻结评估与学习严格分离；位置消融直接验证核心主张；重新发现实验增强结论稳健性。
- **资源效率**：仅用 32 训练任务、15.9M tokens 即大幅超越使用 90 任务、更多 tokens 的基线。
