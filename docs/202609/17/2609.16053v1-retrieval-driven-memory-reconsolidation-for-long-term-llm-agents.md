## 摘要
长期记忆对于在长程交互中运行的基于LLM的智能体至关重要。现有记忆系统主要在新信息到来时更新记忆，将检索视为记忆访问的终点，而非记忆演化的驱动力。因此，检索反馈很少被用于持续地重组记忆以供未来访问。此外，大多数现有方法依赖预定义记忆结构以及固定检索流程，限制了智能体自主组织和演化自身记忆的能力。受认知神经科学中记忆再巩固的启发，我们提出 REALM，一种再巩固-演化智能体长期记忆框架。它通过自主地将记忆组织为异构认知图、通过自适应组合的图搜索原子检索证据，并基于检索反馈持续再巩固记忆，将长期记忆建模为一个持续生命周期。REALM 在 LoCoMo 上取得 75.97% 的平均准确率，在 LongMemEval 上取得 65.11% 的平均准确率，分别比最强基线高出 7.17 和 1.31 个百分点。消融实验证实，记忆再巩固能够持续提升性能；进一步分析表明，它会逐步将相关记忆单元重组为更连贯的局部结构，以便在推理过程中进行集体证据召回与利用。这些结果表明，检索驱动的记忆再巩固为LLM智能体持续演化长期记忆提供了一种有效机制。

## Abstract
Long-term memory is essential for LLM-based agents operating over extended interactions. Existing memory systems primarily update memory when new information arrives, treating retrieval as the endpoint of memory access rather than a driver of memory evolution. Consequently, retrieval feedback is rarely exploited to reorganize memory for future access continuously. Moreover, most existing approaches rely on predefined memory structures together with fixed retrieval pipelines, limiting the agent's ability to organize and evolve its own memory autonomously. Inspired by memory reconsolidation in cognitive neuroscience, we propose \textbf{REALM}, a \textbf{r}econsolidation-\textbf{e}volution \textbf{a}gentic \textbf{l}ong-term \textbf{m}emory framework. It models long-term memory as a continual lifecycle by autonomously organizing memories into a heterogeneous cognitive graph, retrieving evidence via adaptively composed graph-search atoms, and continually reconsolidating memories based on retrieval feedback. REALM achieves an average accuracy of 75.97\% on LoCoMo and 65.11\% on LongMemEval, outperforming the strongest baselines by 7.17 and 1.31 points respectively. Ablation studies confirm that memory reconsolidation consistently boosts performance, with further analyses revealing that it progressively reorganizes related memory units into more coherent local structures for collective evidence recall and utilization during reasoning. These results suggest that retrieval-driven memory reconsolidation provides an effective mechanism for continually evolving long-term memory in LLM agents.

## 1. 核心问题与研究动机

- **背景**：LLM 智能体在个人助理、长程任务协作、持续决策等场景中需要跨大量历史交互积累知识，长期记忆成为其基础能力。
- **现有范式的缺陷**：
  - 主流长期记忆系统遵循"前向演化"范式——记忆的新增、删除、合并**仅由新到达的信息触发**，检索被视为记忆访问的**被动终点**，检索反馈很少被用于持续重组记忆。
  - 大多数方法依赖**预定义记忆结构 + 固定检索流程**，智能体无法自主组织和演化自身记忆。
- **理论启发**：认知神经科学中的**记忆再巩固（memory reconsolidation）**指出，被回忆的记忆并非静态数据，再激活会使其进入易变状态，连接可被增强、削弱或新建，从而在保持稳定性的同时随使用不断适应。
- **核心主张**：长期记忆应是一个**动态闭环生命周期**，具备在每次检索后重新对齐其组织结构的反馈驱动自主性；难点在于同时兼顾高度灵活的记忆结构与在演化拓扑上的自适应检索机制。

## 2. 方法论：REALM 框架

- **总体思路**：将长期记忆建模为"组织—检索—再巩固"的闭环生命周期，形式化为
  `G_{t+1} = Reconsolidating(G_t \ G_q ∪ G'_q, f)`，即检索激活的子图 `G_q` 在任务反馈 `f` 下被重组为 `G'_q` 后回写全局图。

### (1) 自主组织：统一认知图
- **图表示**：`G = (V, E)`，节点类型空间 `V ⊂ {entity, event, episode, fact}`，边类型空间 `E ⊂ {logical, causal, hierarchical(taxonomic), associative}`，均为**无 schema 约束**的局部配置。
- **节点定义**：`v = (κ_v, c_v, des_v, k_v, t_v)`，分别对应类型、原始内容、语义描述、类型特定关键词/名称、时间跨度约束。
- **边定义**：`e_ij = (v_i, v_j, κ_ij, des_ij, w_ij)`，其中 `w_ij ∈ [0,1]` 为置信权重；将原始记忆内容与拓扑解耦，为后续检索与拓扑演化提供结构变量。
- **记忆构建**：新观测 `o_t` 到来时，结合对话摘要 `s_t` 与近期上下文 `c_t` 抽取 m 个候选记忆单元；对每个候选检索邻居 `N(x) = N_sim(x) ∪ N_recent(x)`；由智能体决策 **add / merge / skip**；若 add 或 merge 则进一步推断与邻居间的有向关系边。
- **特点**：将插入、合并、遗忘**统一为单一集成阶段**，视"遗忘"为冗余（由合并与选择性保留隐式实现）。

### (2) 自适应检索：策略原子组合
- 将图检索形式化为**种子定位 → 证据扩展 → 证据聚合**三阶段动态流水线，策略为原子策略的组合：`π = π_seed ⊕ π_expand ⊕ π_filter`。
- **种子定位**：每个检索计划 `p_i = (Q_i, K_i, T_i, τ_i)` 显式定义查询串、关键词、目标节点类型与时间约束；匹配模式含 `query_match`（纯嵌入相似）、`keywords_match`（纯词法倒排）、`hybrid_match`（嵌入 0.6 + 关键词 0.4 加权）。类型过滤在无候选时按两步松弛，时间窗仅在 hybrid 模式下强制生效，保证种子集非空。
- **自适应证据扩展**：每轮先由"充分性控制器"判断当前证据是否足以作答（`is_enough`），不足则选出前沿节点集 `F_t`；对每个前沿节点 `v`，LLM 预测个性化扩展动作 `a_v = (mode, predicate, decay, inhibit)`，分别控制遍历模式（`subgraph_beam` 广域聚合 / `path_search` 链式路径）、边类型谓词过滤、时间衰减与冲突抑制。
- **访问评分**：新发现节点 `v_i` 经边 `e_ij` 到达时，
  `s_aces(v) = β·s_sim(q, des_ij) + (1-β)·w_ij − Δ_decay(t_v)`，即语义相似度、拓扑关系置信度与时间惩罚的加权组合。
- **证据聚合**：终止后全局重排 `Score(v) = α·s_aces(v) + (1-α)·s_sim(v, q)`，取 Top-K 构成证据集 `V_q`，并诱导出激活子图 `G_q = (V_q, E_q)` 作为再巩固的输入。

### (3) 记忆再巩固：拓扑演化
- **检索诱发的结构反馈**：不修改记忆内容，而是利用 `V_q` 中的**拓扑共利用模式**，先推断潜在主题结构 `T_q = InferTopicStructure(q, V_q)`。
- **局部拓扑再巩固**：智能体生成修改决策集 `D = {d_1, …, d_n}`，每条 `d = (v_i, v_j, a, r, c)`，其中 `a ∈ {add, strengthen, weaken}` 为原子边操作，`c ∈ [0,1]` 为决策置信度。同上下文下被反复共同激活的记忆之间可新建关系；持续支持成功检索的关系被增强；反复引入无关证据的弱/误导关系被抑制。
- **置信度引导的有界权重更新**：令 `w_b = max(w_min, min(1, w_ij))`，则
  `w_ij ← Clip(w_ij + η·c, w_min, 1)`，其中 `η = 0.8`（add）、`1 − w_b`（strengthen）、`−(w_b − w_min)`（weaken）。该设计在权重边界附近平滑调节更新幅度，避免单次或重复检索导致拓扑失稳。
- **闭环演化**：`G_t —Retrieve→ (G_q, f) —Reconsolidate→ G_{t+1}`，记忆图从初始的语义组织逐步转变为**使用感知（usage-aware）的认知结构**。

- 文中明确说明：框架**不需要专用硬件**，可在标准计算环境执行；所有实验依赖**基于 API 的 LLM 推理与轻量图操作**，属于免训练（training-free）的智能体式方案。
- 因此本文的可复现性主要取决于 API 调用成本与 LLM 版本稳定性，而非算力规模。

## 5. 实验数量与充分性

- **主要性能实验**：2 个 benchmark × 6 个基线，覆盖 4 类（LoCoMo）/ 6 类（LongMemEval）问题类型，REALM 在两榜均居首。
- **消融实验**：移除再巩固模块的对照，按类别报告增益（LoCoMo 平均 +2.01，LongMemEval 平均 +2.13）。
- **鲁棒性实验**：LoCoMo 上多种随机打乱问题顺序，性能波动很小。
- **机制分析实验**：
  - 图组成 vs 证据检索的节点/关系类型分布偏差（节点差异 <1.5 个百分点；检索时 causal +13.39、logical +6.57 个百分点，associative 显著减少）；
  - 支持证据首次检索的扩展深度分布（LoCoMo 84.87% 直接从种子节点获得；LongMemEval 40.52% 直接获得，相当比例需达到最大扩展深度）；
  - 检索策略选择对比（path_search only 39.84% / subgraph_beam only 43.09% / 自适应 43.36%）；
  - 拓扑演化带来的证据发现 vs 证据利用增益对比（发现增益仅 +3.70% / +5.41%，而检索到证据后正确作答增益达 +20.83% / +19.23%）。
- **充分性与公平性评估**：
  - **优点**：实验层次较完整，从总体性能、消融、鲁棒性到机制剖析形成闭环；统一 backbone 与 judge prompt 增强了可比性。
  - **保留意见**：部分基线结果直接复用（MIRIX、Mem0 取自 MemOS 论文，MAGMA、Nemori 取自 MAGMA 论文），仅 A-Mem 为自行复现，跨论文结果可能受实现差异影响；LongMemEval 使用合成补充问题构造"历史使用"，与真实长程交互存在偏差；自适应策略的增益幅度很小，统计显著性未报告。

## 6. 主要结论与发现

- **性能**：REALM 在 LoCoMo 上平均 75.97%（较最强基线高 **7.17** 分，四类问题全部第一），在 LongMemEval 上平均 65.11%（高 **1.31** 分）；在 LoCoMo 的多跳与时序推理上分别提升 8+ 与 5+ 分，在 LongMemEval 的时序推理与知识更新上表现最佳。
- **再巩固有效且稳定**：移除再巩固在两榜均导致一致下降（多跳 +4.97、开放域 +5.21、单会话偏好 +6.66、知识更新 +4.17）；打乱问题顺序后性能基本不变，说明增益来自拓扑改进而非对特定查询序列的过拟合。
- **价值在"利用"而非"发现"**：再巩固主要不是扩大可召回的记忆空间，而是持续重组认知图，使已检索到的证据对下游推理更相关、更有信息量。
