## 摘要
终身对话智能体依赖记忆系统来维持与用户深度、上下文感知的交互。然而，现有的显式文本记忆流水线存在严重的信息瓶颈，往往会丢失细微的行为模式和情感变化。此外，它们通常在部署后是静态的，无法在没有人工反馈的情况下自主适应用户的个人习惯和偏好。然而，认知科学表明，人类完全在潜在空间中维持心智模型，并通过预测编码不断对其进行优化。受此启发，我们提出 ThinkFlow，一种面向终身对话智能体的新型端到端潜在记忆框架。ThinkFlow 通过将对话流动态压缩为概率潜在记忆技能，绕过文本瓶颈，自主地将复杂用户状态整合为解耦的连续向量，且不受语义干扰。为突破这一瓶颈，我们引入一种测试时演化范式。通过将教师引导的潜在对齐与自监督的下一用户话语预测任务相耦合，以引导初始状态并进行持续优化，该框架成功克服了冷启动挑战，并实现了无需标签的终身个性化。在长期对话基准上的大量实验表明，ThinkFlow 显著优于现有主流记忆系统，能够在延长的多会话交互中提供高度个性化和上下文准确的回复。

## Abstract
Lifelong conversational agents rely on memory systems to maintain deep, context-aware interactions with users. However, existing explicit textual memory pipelines suffer from a severe information bottleneck, often losing subtle behavioral patterns and emotional shifts. Furthermore, being typically static post-deployment, they cannot autonomously adapt to personal habits and preferences without manual feedback. Cognitive science, however, suggests that humans maintain mental models purely in a latent space and continuously refine them through predictive coding. Inspired by this, we propose \textbf{ThinkFlow}, a novel end-to-end latent memory framework for lifelong conversational agents. ThinkFlow bypasses the text bottleneck by dynamically compressing conversational flows into probabilistic latent memory skills, autonomously consolidating complex user states into disentangled, continuous vectors without semantic interference. To break this barrier, we introduce a test-time evolution paradigm. By coupling teacher-guided latent alignment to bootstrap the initial state with a self-supervised next-user-utterance prediction task for continuous refinement, the framework successfully overcomes cold-start challenges and achieves label-free lifelong personalization. Extensive experiments on long-term conversation benchmarks demonstrate that ThinkFlow significantly outperforms prevailing memory systems, providing highly personalized and contextually accurate responses over extended multi-session interactions.

- **现有范式缺陷**：当前主流依赖**显式文本记忆**，通过复杂流水线管理记忆的构建、管理与检索。但其根本问题是**严重的信息瓶颈**——将丰富连续的人类交互强制物化为刚性离散的纯文本，剥离了隐式偏好、情感变化、未言明的行为模式等细微信息。
- **部署瓶颈**：文本记忆库在部署后通常静态不变，无法在无人工反馈下自主适应用户个性，阻碍了真正共情、类人的终身陪伴。
- **认知科学启发**：依据**隐式心智理论**，人类并非记忆离散文本摘要，而是在潜在抽象空间中无意识追踪他人心理状态；依据**预测编码**，大脑持续生成自上而下的预测，并依据预测误差优化内部模型。
- **核心主张**：放弃显式文本瓶颈，纯在潜在空间中通过自监督预测反馈维护持续演化的记忆，即可实现长期对话中的真正零样本个性化。

## 二、论文提出的方法论

### 2.1 核心思想

- 提出 **ThinkFlow**，一个端到端潜在记忆框架，将连续对话流动态压缩为**概率潜在记忆技能（PLMS）**，把复杂用户状态解耦为连续向量，避免语义干扰。
- 整体架构由三个互联组件构成：**PLMS**（提取解耦记忆技能）、**GLC**（门控巩固与过滤噪声）、**CAHA**（动态桥接历史潜在技能与当前语义上下文）。
- 训练采用**自监督测试时演化**两阶段范式，克服冷启动并实现无标签终身个性化。

### 2.2 关键技术细节

**（1）概率潜在记忆技能（PLMS）**

- 输入当前轮次的思维流隐状态 \(E_t \in \mathbb{R}^{L \times D}\)，通过交叉注意力将可学习技能 \(S \in \mathbb{R}^{K \times D}\) 压缩为 \(K\) 个密集记忆技能。
- 引入**分布保持缩放因子**防止方差塌缩为确定性点质量：
  \[
  C_t = \left( \text{Softmax}\left( \frac{S E_t^T}{\sqrt{D}} \right) E_t \right) \times \frac{1}{\sqrt{c}}, \quad c = L/K
  \]
- 通过两个并行线性层输出均值 \(\mu_t\) 与对数方差 \(\log\sigma_t^2\)，采用**重参数化技巧**采样：\(\hat{S}_{new} = \mu_t + \sigma_t \odot \epsilon,\ \epsilon \sim \mathcal{N}(0, I)\)。
- 使用 **KL 散度损失** \(L_{KL}\) 将近似后验正则化至标准高斯先验。

**（2）门控潜在巩固器（GLC）**

- 引入**信息增益门** \(g_t \in (0,1)^{K \times D}\)，由 MLP 基于新旧记忆技能拼接表示学习：
  \[
  g_t = \sigma\left( W_2 \text{ReLU}(W_1[\hat{S}_{new} \| S_{old}]) \right)
  \]
- 采用 **GRU 核心**条件式更新，兼顾时序保持与优雅遗忘：
  \[
  S_t = g_t \odot \text{GRU}(\hat{S}_{new}, S_{old}) + (1 - g_t) \odot S_{t-1}
  \]
- 噪声（如冗余问候）门值低（约 0.12），有效信息（如“酒店/巴黎/$200”）门值高（约 0.91）。

**（3）上下文感知超对齐器（CAHA）**

- 采用**超网络**根据当前用户查询 \(x_t\) 生成低秩变换矩阵 \(W_{adapt} \in \mathbb{R}^{D \times D}\)：
  \[
  W_{adapt} = W_{down}(x_t) \times W_{up}(x_t)
  \]
- 残差投影得到对齐记忆技能：\(S_{aligned} = S_t + S_t \times W_{adapt}\)，并将其作为**软提示**前置到语言模型以条件化生成。

**（4）自监督测试时演化**

- **Phase 1：教师引导潜在对齐**（解决冷启动）
  - 文本教师模型读取完整明文历史 \(H_{<t}\) 输出目标分布 \(P_T(y|H_{<t}, x_t)\)；学生仅读当前查询 \(x_t\) 与潜在技能 \(S_t\)，输出 \(P_S(y|S_t, x_t)\)。
  - 损失：\(L_{Phase1} = D_{KL}(P_T \| P_S) + \alpha L_{KL}\)。
- **Phase 2：下一用户话语预测**（持续终身学习）
  - 教师离线后，利用用户隐式反馈作为免费监督信号：用 \(S_{t+1}\) 与上一响应 \(a_t\) 预测用户下一话语 \(x_{t+1}\)。
  - 若记忆失败则交叉熵损失 \(L_{CE}\) 高，直接迫使 GLC 门关闭，防止记忆库被污染。
  - 引入**最小熵置信先验** \(L_{Conf}\) 防止语义模糊塌缩。
  - 损失：\(L_{Phase2} = L_{CE}(x_{t+1}|S_{t+1}, a_t) + \beta L_{Conf} + \alpha L_{KL}\)。

## 六、主要结论与发现

- ThinkFlow 在三个长期对话数据集上**全面超越**显式记忆基线与现有潜在记忆方法，Mauve 指标提升尤为显著，表明响应更连贯、更类人且不丢失细微对话细节。
- 在 PersonaMem 上，ThinkFlow-8B **媲美甚至超越**闭源模型与 405B 开源模型，在“Revisit Reasons”“Track Evolution”等动态复杂任务上优势明显。
- 消融验证了 **PLMS、GLC、CAHA 及两阶段训练**均不可或缺，其中移除 PLMS 性能下降最严重。
- t-SNE 显示潜在记忆空间自然解耦：静态事实形成密集局部簇，动态演化形成宽广连续流形。
- 增加潜在技能数 \(K\)（1→10）持续提升准确率，在 1M 超长上下文场景中提升尤为显著。
- 效率上，ThinkFlow 仅消耗 2,857 tokens、12.1s，远低于 MemTree（21,339 tokens + 33,868 隐藏 tokens、57.8s）与 A-Mem（27,450 tokens + 43,793 隐藏 tokens、94.9s）。
- 案例研究表明，显式检索易被表面事实困住而忽略情感崩溃，ThinkFlow 能平滑跟踪潜在情感转变并生成共情响应。

## 七、优点

- **范式创新**：首次系统性地提出端到端纯潜在记忆框架，绕过显式文本瓶颈，避免信息丢失。
- **技能化解耦**：将记忆分解为 \(K\) 个概率技能向量，自主解耦事实、情感、偏好等不同维度，防止语义干扰。
- **概率建模**：通过均值-方差输出与重参数化，显式建模认知不确定性，避免确定性点质量塌缩。
- **门控巩固机制**：信息增益门与 GRU 结合，有效过滤噪声并优雅遗忘过时信息。
- **超网络对齐**：CAHA 以极低参数开销动态桥接历史潜在技能与当前查询的分布差距。
- **自监督终身演化**：利用“下一用户话语预测”作为免费监督信号，实现无标签、部署后的持续个性化，克服冷启动。
- **效率优势显著**：token 与时间消耗远低于显式记忆方法，适合实时陪伴场景。
- **实验扎实**：多数据集、多骨干、多基线、消融、可视化、案例研究齐备，结论有说服力。
