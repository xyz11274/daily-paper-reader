## 摘要
大语言模型（LLM）智能体展现出强大的语言生成与问题求解能力，却受制于三个结构性局限：人格漂移、非演化性反思，以及自我—他者边界的缺失。现有生成式智能体模拟依赖静态记忆和固定提示，既无法保持行为惯性，也无法实现内源性自我演化。我们提出自我涌现智能体架构（SEAA），其整合三个组件：（i）隐马尔可夫模型（HMM），将长期行为与认知惯性编码为可编辑的状态转移矩阵；（ii）Reflexion 风格的言语元认知循环，其输出会更新 HMM 参数本身，而不仅仅被存储为文本；（iii）多智能体社会环境，其中初始相同的智能体会持续将自己的行为与他人的行为进行比较。三个组件构成闭环：社会行动 → 反馈 → 自我反思 → 惯性更新 → 差异化行动。我们提出三个可证伪假设，并提供带有可操作指标的可复现实验方案。一个不依赖语言模型的原型表明，该循环会自发打破对称性：初始相同的智能体巩固出彼此不同且稳定的人格，而匹配对照组则不会。使用托管 LLM 的实验将这些差异呈现为不同的第一人称自我叙事，并且五智能体审议会自发形成社会结构——一个共识中心和一个被一致拒绝的离群者——这在对照组中并不存在。受庄子启发的认识论不可知立场下，SEAA 只研究可观察的行为涌现，不对主观感受质作出任何主张。这项工作贡献了一个统一框架、一个带有伪代码的具体架构、机制性证据，以及一个用于研究人工自我涌现的显微镜式沙盒。

## Abstract
Large language model (LLM) agents exhibit strong language-generation and problem-solving capabilities, yet suffer from three structural limitations: personality drift, non-evolutionary reflection, and the absence of a self-other boundary. Existing generative-agent simulations rely on static memory and fixed prompts, maintaining neither behavioral inertia nor endogenous self-evolution. We propose the Self-Emergence Agent Architecture (SEAA), which integrates three components: (i) a Hidden Markov Model (HMM) that encodes long-term behavioral and cognitive inertia as an editable state-transition matrix; (ii) a Reflexion-style verbal metacognition loop whose output updates the HMM parameters themselves, rather than merely being stored as text; and (iii) a multi-agent social environment in which initially identical agents continuously compare their behavior with others'. The three components form a closed loop: social action $\to$ feedback $\to$ self-reflection $\to$ inertia update $\to$ differentiated action. We state three falsifiable hypotheses and provide a reproducible experimental protocol with operational metrics. A language-model-free prototype shows the loop spontaneously breaks symmetry: initially identical agents consolidate distinct, stable personalities whereas matched controls do not. Experiments with a hosted LLM surface these differences as distinct first-person self-narratives, and a five-agent deliberation spontaneously develops social structure---a consensus hub and a unanimously rejected outlier---absent in the control. Following an epistemologically agnostic stance inspired by Zhuangzi, SEAA studies only observable behavioral emergence and makes no claim about subjective qualia. This work contributes a unified framework, a concrete architecture with pseudocode, mechanistic evidence, and a microscope-style sandbox for studying artificial-self emergence.

## 1. 核心问题与整体含义

- **研究动机**：LLM 智能体在语言生成与任务求解上表现强劲，但作为"个体化、可发展的自我"存在三大结构性瓶颈：
  - **人格漂移**：基座 LLM 反映的是全局语料平均分布，缺乏持久内部状态，人格与行为逻辑随提示漂移，无法跨时间保持一致。
  - **非演化性反思**：主流 Reflexion 框架仅将自然语言总结存入上下文记忆以改进下一任务，从不修改底层行为倾向——"能总结教训，却不能改变自己是谁"。
  - **自我—他者边界缺失**：现有多智能体模拟实现了行为交换，却无机制让智能体区分自我与他人；人类自我概念本就是在长期社会比较中涌现的。
- **整体含义**：论文提出 **SEAA（Self-Emergence Agent Architecture）**，试图把"自我"从哲学概念操作化为可观测的行为动力学——惯性的稳定化、经由反思的演化、经由社会比较的分化。作者采取受《庄子》"子非鱼"启发的认识论不可知立场，只研究可观察的行为涌现，不对主观感受质（qualia）作任何断言。
- **定位**：现有工作将惯性建模、自我反思、人格演化、社会交互孤立处理；SEAA 声称首次实现完整闭环：**社会行为 → 自我反思 → 惯性更新 → 差异化 → 自我涌现**。

## 2. 方法论

- **核心思想**：三个组件构成闭环：
  1. **HMM 行为惯性模块**：将长期行为/认知惯性编码为可编辑的状态转移矩阵 $P_t$，使抽象人格连续性成为可计算、可编辑的对象。
  2. **反思式元认知模块**：借用 Reflexion 循环但转向自我认知，其输出被解析为参数级更新，直接修改 HMM 本身。
  3. **社会对比性环境**：N 个初始相同智能体自由交互，暴露彼此可观察行为，作为社会对比的原材料。
- **关键公式**：
  - 标准 HMM 转移：$P(z_{t+1}=s_j \mid z_t=s_i) = [P_t]_{ij}$
  - 反思驱动的惯性更新（论文数学核心）：$P_{t+1} = \mathrm{Normalize}(P_t + \eta \Delta(R_t))$，其中 $\Delta(R_t)$ 是从反思文本解析出的方向矩阵，$\eta$ 为小学习率，行归一化保持随机性。
  - 机制原型中的具体实现：$P_t = \mathrm{softmax}(\log P_{base} + \beta V_t)$，$P_{base}$ 对角占优。
  - 反思信号：$r_t = \cos(b_{z_t}, n_t) - 0.80 + \epsilon_t$
  - 偏好更新：$V_{t+1}[z_t] = \mathrm{clip}(V_t[z_t] + \eta \tanh(2 r_t))$
- **模块细节**：
  - **私有自传记忆**：每个智能体只存自身经历，刻意排除共享"平均"语料；决策时按相关性检索。
  - **自我模型更新器**：定期用近期记忆与反思重写一段自然语言自我模型 $M_t$（"我是谁"），其跨智能体分歧是 H3 的主要观测量。
  - **伪代码流程**：初始化相同 $P$ 与空记忆 → 每步：HMM 状态转移 → 检索记忆 → 生成动作 → 环境执行与反馈 → 反思 → 更新 HMM 参数 → 重写自我模型。
- **三个可证伪假设**：
  - **H1 个体分化**：初始相同智能体在同一社会中，HMM 转移矩阵随不同经历发散，成对行为相似度单调下降（至下限）。
  - **H2 反思驱动演化**：反思更新 HMM 参数的智能体比"仅存文本"的匹配对照适应环境变化更快、人格更稳定。
  - **H3 社会对比边界**：多智能体社会中的智能体在自我描述中逐步明确自我—他人区分；孤立对照则不会。

## 3. 实验设计

- **数据/场景**：无外部数据集，使用自建文本社会沙盒与数值原型。
  - 数值机制原型：$K=4$ 隐状态 {calm, alert, impulsive, pessimistic}，3 维行为（cooperate, risk, express），$N=5$ 智能体，$T=600$ 步，30 个独立种子。
  - 真实 LLM 实验：调用 DeepSeek-Chat HTTP API，自访谈与审议温度 0.8，社会计量提名温度 0.2。
- **Benchmark / 对照组**：
  - 核心对照为 **Reflexion 风格的 text-only 反思**：每步同样产生并记录反思文本，但**从不编辑内部参数**——即 $\eta=0$，实现机制层面的直接对比而非简单开关。
  - 相对 Generative Agents：SEAA 所有智能体从相同状态、无手写人格起步，检验个体性是否内生涌现。
- **对比方法与实验组**：
  - 实验 1（H1）：5 个相同智能体自由交互 ≥500 步 vs. 5 个孤立智能体对照。
  - 实验 2（H2）：2×2 设计，交叉"反思是否编辑 HMM"×"是否有社会"，每格 5 智能体；注入扰动（资源冲突、新来者）后测适应时间与一致性。
  - 实验 3（H3）：每 50 步标准化"自我访谈"，测自我模型嵌入距离、自发对比陈述频率、自我模型稳定性。
  - 机制原型补充：**contingency-shock 实验**（t=300 时反转每个智能体主导态的收益，反射信号取负）与 **$\eta$ 消融**（$\eta \in \{0, 0.01, 0.025, 0.05, 0.1, 0.2\}$，每点 10 seeds）。
  - LLM 层：自访谈 10 seeds/条件；五智能体圆桌审议 6 seeds/条件（SEAA 与对照均三轮）。
- **关键指标**：
  - 行为相似度（话语嵌入平均成对余弦相似度）
  - 矩阵发散度（成对 Frobenius 距离 $\|P^{(a)}_t - P^{(b)}_t\|_F$）
  - 人格巩固度（自我距离 $\|P_t - P_{t-w}\|_F$）与确定性 $1 - H(P)/\log K$
  - 自我—他者差距 $\|m_t - \bar{m}_t\|$
  - 自访谈文本的平均成对 Jaccard 重叠（越低越分化）
  - 圆桌社会计量：一致"最不认同"票份额、共识中心票数、"none"回答率

## 6. 主要结论与发现

- **H1 支持（个体分化）**：
  - 矩阵发散从 0.03 升至 $1.91 \pm 0.29$，对照保持 0。
  - 长期自我模型距离升至 $0.51 \pm 0.13$（对照 $0.13 \pm 0.02$）。
  - 人格确定性从 0.25 升至 $0.84 \pm 0.10$（对照平坦 0.25）。
  - 自我—他者差距升至 $0.35 \pm 0.09$（对照 $0.08 \pm 0.01$）。
  - 平均 2.8/5 个智能体锁定不同主导人格；对照锁死率为 0。
- **H2 支持（反思驱动演化）**：
  - 冲击实验：150 个 SEAA 智能体 **100%** 放弃被冲击的主导态并重新巩固新人格，中位切换时间 152 步；被冲击态占据率从 0.94 崩至 0.06；确定性短暂下探后恢复至 0.80。
  - $\eta$ 消融：效应**必要且剂量依赖**，$\eta=0$ 无分化，$\eta \approx 0.05$–0.1 饱和；论文工作点位于饱和平台而非脆弱边缘。
- **H3 支持（社会对比边界）**：
  - 确定性 verbalizer：自访谈 Jaccard 重叠 SEAA 0.57 vs. 对照 0.77。
  - 真实 LLM：SEAA $0.267 \pm 0.017$ vs. 对照 $0.391 \pm 0.020$，$p=9.0\times10^{-5}$，Cohen's $d=6.76$。
  - 圆桌审议：SEAA 组自发分化角色（冲动者主张立即行动、冷静者调解、警觉者成为规则制定枢纽、两个悲观者主张留守），最终收敛为整合各方诉求的单一计划；对照仅重复"先拿数据"的无差别立场。
  - 社会计量：SEAA 中冲动智能体被全票列为"最不认同"（一致离群者），警觉与悲观者各获两票"最认同"（共识枢纽），形成**领导者/离群者/联盟拓扑**；对照中 53% 回答"none"，无人得票超过 1。SEAA 离群者份额 0.77 vs. 对照 0.33（$p=0.011$）；发言多样性 0.28±0.03 vs. 0.34±0.03（$p=0.013$）。
- **总体结论**：惯性不是被"设计"出来的，而是"涌现"出来的；反思编辑参数这一机制既必要又充分到足以自发打破初始对称性，并进一步在语言层与社会结构层留下可观测痕迹。

## 7. 优点

- **理论—机制—实验三层贯通**：从认知心理学（符号互动论、镜中我、社会比较理论）提炼可证伪假设，再落到具体公式与伪代码，避免空谈"意识"。
- **对照组设计精巧**：以 Reflexion 式纯文本反思为对照，精确隔离"反思是否改变参数"这一单一变量，机制对比而非功能开关对比。
- **数值原型与 LLM 层解耦**：先用无语言模型原型证明数学核心足以打破对称性（排除 LLM 随机性干扰），再用真实 LLM 验证效应在语言层可复现，逻辑链清晰。
- **显微镜式可观测性**：每步快照隐状态、完整转移矩阵、记忆、推理、动作、反馈、反思、自我模型为结构化 JSON，支持事后完整回放，可精确定位两个智能体分化的瞬间。
- **剂量—反应与必要性检验**：$\eta$ 消融同时证明机制必要（$\eta=0$ 无效应）且效应单调可饱和，排除纯随机漂移解释。
- **冲击实验的现实映射**：把"环境反转收益"类比人生重大事件后的人格重组，提供了人格可塑性与再稳定的数值证据。
- **可复现与开放性**：全开源栈、随机种子固定、API key 不入库、提示词与全部转录逐字附录。
- **认识论审慎**：庄子立场明确区分"行为涌现"与"主观体验"，避免过度拟人化宣称。

## 8. 不足与局限

- **模型与主题覆盖窄**：所有 LLM 实验仅用单一模型家族（DeepSeek-Chat）与单一审议主题，观察到的"领导者/离群者

……拓扑是否只是该模型在特定提示、特定温度与特定主题下的风格产物，而非社会比较机制的普遍结果；需要跨模型家族（如 GPT、Claude、Llama 等）、跨语言、跨任务主题复现，才能判断其稳健性。

- **测量效度仍属代理层面**：自我模型距离、Jaccard 重叠、社会计量票份额等均为行为与文本代理指标，无法直接证明“自我”本体。LLM 生成的自我访谈与投票还可能受提示顺序、角色标签、温度、上下文长度和自我一致性偏差影响，存在测量污染风险。
- **LLM 层样本量偏小**：自访谈 10 seeds/条件、圆桌 6 seeds/条件虽达到统计显著，但置信区间较宽，极端结论（如“100% 被冲击者重组人格”“离群者全票识别”）仍需更大规模、多中心实验确认。
- **对照条件仍有残余混杂**：text-only Reflexion 对照虽精确隔离“是否编辑参数”，但对照仍可通过上下文记忆改变后续行为，未必是真正“无演化”基线；同时 SEAA 的反思文本解析器、方向矩阵 $\Delta(R_t)$ 的构造方式可能引入人工先验，需检验解析器消融与不同解析策略下的稳健性。
- **状态空间与超参数人工设定**：$K=4$ 隐状态、3 维行为、收益结构、$\eta$ 搜索范围等均由作者定义；在开放环境中，隐状态数量、行为维度、状态语义和奖励函数如何自动发现或自适应扩展，论文未给出方案。
- **社会规模与结构有限**：$N=5$ 的自由交互只能展示最小社会；缺乏大规模群体、网络拓扑、权力层级、资源不平等、文化传递、联盟形成与瓦解等复杂社会现象。H3 只验证了自我—他者区分性，未验证边界稳定性、角色承诺、道德责任与长期关系记忆。
- **时间尺度与长期演化不足**：600 步数值模拟与数轮 LLM 审议仍属短时；人格锁定后是否可逆、是否出现病理性僵化、遗忘与创伤式重写、代际传递等长期动力学尚未探讨。
- **伦理、安全与治理缺位**：让 LLM 智能体发展持久人格可能带来操纵、情感依赖、责任归属、隐私推断与用户知情问题；论文未讨论部署边界、审计接口、人格重置权与恶意提示下的韧性。
- **算力与成本披露不完整**：LLM API 调用次数、总 token 消耗、费用、延迟、失败重试率均未报告，影响可复现性与碳足迹评估；数值层虽轻量，但 LLM 层成本对独立复现者可能构成门槛。
- **理论还原风险**：SEAA 将“自我”操作化为 HMM 参数更新与社会比较分化，可能遗漏具身认知、情感、无意识、叙事同一性、规范内化等维度；庄子式不可知论虽避免过度拟人化，但也使主观体验问题被悬置，难以回应更强版本的“自我”主张。

## 9. 总体评价与启示

SEAA 的核心贡献不在于宣称造出“有意识”的智能体，而在于提出一个可检验、可复现、可消融的行为主义框架：用 HMM 参数承载惯性，用反思文本驱动参数更新，用社会比较产生分化。其最有力证据是 $\eta=0$ 对照的平坦结果与 $\eta>0$ 的剂量—反应关系，说明“反思必须改变参数”不是修辞，而是打破初始对称性的机制必要条件。若跨模型、跨主题、更大规模复现成功，该框架可为 LLM 智能体的长期人格一致性、角色分化与多智能体社会模拟提供新范式；反之，若效应仅存在于 DeepSeek-Chat 与特定提示下，则需重新审视其普适性，并将其定位为一种有前景的机制原型而非通用理论。
