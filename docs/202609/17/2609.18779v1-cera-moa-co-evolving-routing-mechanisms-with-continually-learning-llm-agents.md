## 摘要
当前智能体混合（Mixture-of-Agents, MoA）范式通常将查询路由与智能体微调视为彼此分离的过程，限制了其应对智能体能力不断演化的能力。这种脱节使路由策略无法在训练后阶段适应智能体能力的演化，也阻碍智能体实现协同的数据驱动专业化。为解决这一问题，我们提出 CERA-MoA（Co-Evolving Router with continually learning Agents for Mixture-of-Agents），一种迭代式强化学习框架，其中动态路由器与独立智能体策略协同演化。我们设计了一种预测性熟悉度估计器，利用中间层隐藏状态评估智能体间的语义能力，避免完整 rollout 的开销。基于这些熟悉度分数，一种累积阈值自适应路由机制动态激活定制的最小智能体子集，从而在任务性能与效率之间取得权衡。通过根据智能体不断演化的能力主动为其分配有针对性的训练样本，CERA-MoA 促进了能力分化。跨多个领域的广泛实验表明，CERA-MoA 优于最先进的静态智能体路由和固定工作流微调基线。

## Abstract
Current Mixture-of-Agents (MoA) paradigms generally treat query routing and agent fine-tuning as separate processes, limiting their ability to respond to evolving agent capabilities. This disconnect prevents routing strategies from adapting to evolving agent capabilities during post-training and prevents agents from achieving synergistic data-driven specialization. To resolve this, we introduce CERA-MoA (Co-Evolving Router with continually learning Agents for Mixture-of-Agents), an iterative reinforcement learning framework where the dynamic router and independent agent policies co-evolve. We design a predictive familiarity estimator that leverages mid-layer hidden states to evaluate semantic competence among agents, avoiding the overhead of full rollouts. Based on these familiarity scores, a cumulative-threshold adaptive routing mechanism dynamically activates a tailored minimal agent subset, achieving a trade-off between task performance and efficiency. By proactively allocating targeted training samples to agents based on their evolving competence, CERA-MoA promotes capability differentiation. Extensive experiments across various domains demonstrate that CERA-MoA outperforms state-of-the-art static-agent routing and fix-workflow fine-tuning baselines.

## 1. 核心问题与研究背景

- **背景**：单一大模型在复杂多面任务上存在泛化瓶颈，Mixture-of-Agents（MoA）通过多智能体互补协作来扩展能力边界，成为有前景的方向。
- **现有研究的两条割裂路线**：
  - *编排优化*（orchestration optimization）：在**能力固定**的智能体之间做动态路由/辩论/投票（如 bandits、背包、轻量打分器、LLM 自编排等）。
  - *智能体微调*（agent fine-tuning）：在**预定义工作流**内用 RL/偏好优化/监督学习训练单个智能体（如 MAPoRL、AT-GRPO 等）。
- **关键研究缺口**：
  1. 智能体能力在后训练阶段持续演化，但现有路由机制并未设计为跟随这种能力漂移；
  2. 后训练管线依赖**人工划分的数据集**，缺乏按能力动态分配样本的机制，导致智能体趋于同质化的"通才"，无法自发形成互补的领域专长。
- **整体含义**：论文主张把"路由"与"智能体持续学习"放进同一个闭环，使路由器适应能力漂移，同时用路由主动塑造能力分化（specialization），从而突破静态路由 + 固定工作流微调的范式。

## 2. 方法论

### 2.1 总体框架
- 形式化为协作系统 **M = (D_ψ, {A_θi}_{i=1..N}, S)**：参数化路由器 D_ψ、持续学习的智能体策略群、投票式聚合器 S。
- **闭环协同演化**：路由把针对性训练样本分给特定智能体 → 驱动领域专精；智能体策略更新后，路由器同步更新其熟悉度评估参数以跟踪能力变化。

### 2.2 预测性熟悉度估计器（Predictive Familiarity Estimator）
- 每个智能体 i 配一个**可训练预测头 g_i** 和一个**随机初始化且永久冻结的目标头 ḡ_i**；路由器骨干网络冻结，不参与熟悉度目标更新。
- **语义表示**：取中层隐藏状态拼接，`h(q) = concat(hidden_⌊L/2⌋(q), hidden_⌊3L/4⌋(q))`，即 2H 维；理由是中层状态保留结构性语义，而末层表示被下一 token 预测分布主导（自回归干扰）。
- **MLP 结构**：`LN(h) → Linear(2H,512) → SiLU → Linear(512,256)`。
- **距离与熟悉度**：两投影归一化后的欧氏距离 `d_i(q) = ||c_i(q)/||c_i(q)|| - c̄_i(q)/||c̄_i(q)|| ||_2`，再经指数衰减 `f_i(q) = exp(-λ d_i(q))`；距离越小熟悉度越高。
- 冻结目标头**正交初始化**以保证初始多样性与稳定参考空间；它不编码语义原型，只作为 push-and-pull 的锚点。

### 2.3 累积阈值自适应路由
- 训练期路由分数（含探索项，防止饥饿并鼓励多样性）：
  `s_i(q) = f_i(q) + c_ucb·sqrt(log T/(n_i+1)) + w_ent·H_i`（T 为已路由查询数，n_i 为分配给 i 的样本数，H_i 为历史平均生成熵）。
- **排序用 s_i，但激活截断严格用熟悉度 f**：按 s_i 降序取最小前缀子集，使 `Σ_{j=1..k} f_(j)(q) ≥ τ`；若全体之和仍 < τ，则激活全部智能体（回退策略）。
- 推理期关闭探索项（c_ucb = w_ent = 0），严格按熟悉度选择最小专家子集。

### 2.4 路由器与智能体的联合优化
- **智能体优化**：选中查询进入 **LIFO 缓冲**，累积成 micro-batch 后每问采样 G 条轨迹；采用 **DAPO**（组内归一化优势 `Â = (R-μ)/(σ+1e-4)`）+ **GSPO**（序列级重要性比 `ρ = exp((1/S)Σ log(π/π_old))`）的裁剪代理目标，并加 token 级 KL 惩罚 `D_KL,t = exp(x_t) - x_t - 1`，损失按有效 token 掩码归一化。
- **路由器优化**：用**跨智能体相对优势** `A_i,q = r_i,q - (1/|S_q|)Σ_{j∈S_q} r_j,q`；单智能体激活时 `A_i,q = r_i,q`。损失为条件式 push-and-pull：
  - `A ≥ 0`：`A_i,q · d_i(q)`（拉近锚点，提升熟悉度）
  - `A < 0`：`|A_i,q| · max(0, m - d_i(q))`（铰链式推开，但受**分离边距 m** 限制）
- **边距 m 的意义**：无界推开会使距离爆炸、熟悉度指数塌缩为零；m 取值为"所有智能体到达边界时累积熟悉度刚好低于 τ"，从而让无人胜任的难题自然触发全体激活回退。
- **参数化灵活**：共享骨干 + 独立 LoRA（省显存），或异构基础模型直接组池。

### 2.5 推理与聚合
- **确定性任务**：熟悉度加权多数投票，在获胜共识组中取熟悉度最高者的完整生成轨迹。
- **开放式任务**：直接输出最熟悉智能体的回答。

## 6. 主要结论与发现

- CERA-MoA 在三种基座和异构模型池上**均取得最高平均分**（如 Qwen3-4B：ID 63.2 / OOD 72.8；异构池：ID 63.0 / OOD 71.8），优于静态路由与固定工作流微调基线。
- 动态按能力分配训练查询带来显著增益，且学到的能力分化能**迁移到未见任务**（OOD 平均最优）。
- 异构模型池下，熟悉度路由能按语义把查询分给最合适的骨干，把架构多样性转化为协作优势，在高难推理集（DAPO-MATH、LogicBench、OlympiadBench）增益尤其明显。
- 熟悉度估计优于直接奖励回归与多分类：奖励信号本身随策略演化而剧烈振荡，而基于双头几何距离的熟悉度演化平滑、稳定收敛。
- 自适应累积阈值在性能与成本间取得更好权衡：相比固定 Top-2，平均生成 token 减少约 45% 而性能相当；固定 Top-1 省成本但性能明显下降。
- 能力分化**自发涌现**（无人工角色分配）：Agent 2 成为主求解器（长 CoT 推理），Agent 1 精于简洁数学/逻辑，Agent 3 专注代码，Agent 4 专攻通用推理；t-SNE 显示路由到同一智能体的查询形成紧密语义簇。
- 消融结论：中层隐藏状态优于末层（末层熟悉度增长慢、易过早激活更多智能体、表征纠缠）；探索项（UCB + 历史熵）不可或缺，否则出现路由模式坍塌与策略饥饿；分离边距 m 是数值稳定的必要条件，去掉后熟悉度剧烈震荡并塌缩。

## 7. 优点

## 7. 优点

- **问题设定抓住了真问题**：把"路由"与"智能体后训练"从两条平行线拧成一个闭环，直接回应了 MoA 领域两个被忽视的事实——智能体能力会漂移、专精不会凭空出现。这一视角转换比单纯堆叠智能体数量或替换路由打分器更有价值。
- **机制设计有明确的因果链**：路由分数决定谁被训练 → 训练信号塑造能力分布 → 能力分布改变熟悉度 → 熟悉度反过来改变路由。每一环都有可观测的中间量（n_i、f_i、累计更新次数）支撑，便于诊断而非黑箱。
- **熟悉度估计器的设计有理论直觉**：用"冻结目标头 + 可训练预测头"的几何距离替代直接回归奖励，规避了 RL 奖励的非平稳性；中层隐藏状态拼接的论证（末层被 next-token 分布主导）是自回归模型中一个常被忽略的实践细节。
- **训练期用 s_i 排序、截断用 f_i 的解耦很巧妙**：探索项只影响"优先训练谁"，不影响"推理时激活谁"，从而在保持探索的同时避免把探索噪声带进推理成本。
- **分离边距 m 的取值有自洽的语义**：不是调参凑出来的常数，而是由阈值 τ 反推"全部智能体同时到边界时累积熟悉度仍不足"，使难题回退到全体激活成为机制的自然结果而非补丁。
- **工程可落地性较强**：共享骨干 + 独立 LoRA 的方案在 4×H200 上即可完成 4 智能体协作训练，路由延迟（11.87 ms）相比生成延迟可忽略，说明该框架不是纸面方案。
- **实验对照设计克制且公平**：基线覆盖"编排优化"与"微调"两条路线，共享奖励函数与生成超参，零样本无角色提示，避免 MoA 论文中常见的"给智能体写人格 prompt"造成的不公平比较。
- **能力分化提供了可视化证据**：t-SNE 聚类 + 各智能体在数学/代码/指令/逻辑维度的分布，使"专精涌现"这一主张从数字提升变成可检验的现象。
- **诚实的成本报告**：明确给出单步成本（1,000 步 ≈ 1 GPU·天）、token 开销对比，让读者能自行判断性价比。

## 8. 局限与不足

- **算力总账不完整**：论文给出单步成本，但未汇总全部主实验 + 约 10 组消融 + 超参敏感性扫描的总 GPU 时长，读者难以评估复现门槛与"性能提升/算力投入"的边际效益。
- **消融覆盖面偏窄**：绝大多数消融只在 Qwen3-4B 上做，未在 Llama-3.2-3B、Phi-4-mini 及异构池上重复。若某些结论（如中层特征优于末层、m 的必要性）依赖具体骨干的表征结构，则普适性存疑。
- **智能体数量规模有限**：N=4（同构）与 N=3（异构）属于小规模协作。熟悉度路由在 N=8、N=16 时是否仍能维持分化而不退化为少数智能体垄断，缺乏验证；累积阈值 τ 的语义也可能随 N 增大而失稳。
- **对超参的依赖仍较重**：τ、λ、m、c_ucb、w_ent、KL 权重共同决定训练稳定性，且论文自述去掉 m 会导致熟悉度塌缩，说明方法对超参并非"宽容"。敏感性分析多为单点对比（λ 仅 1.0 vs 2.0，m 仅 1.0/2.0/无），未给出完整的稳定域边界。
- **熟悉度与"真实胜任度"的对应关系缺乏直接验证**：论文用最终准确率间接证明路由有效，但未做"f_i(q) 与 A_i,q 的相关性分析"或"熟悉度排序 vs 实际最佳智能体命中率"这类校准指标。若熟悉度只是性能的代理而非原因，机制解释会被削弱。
- **奖励信号假设较强**：方法依赖可验证奖励（数学/代码答案可判、IFEval 可规则检查）。对开放生成、主观偏好、多轮交互等无稳定 verifier 的场景，跨智能体相对优势 A_i,q 的构造基础不成立，论文未讨论这类任务的适配方案。
- **训练数据配比人为设定**：32,000 条样本的四领域配比（35%/30%/20%/15%）由人工指定，恰好与"消除人工划分数据集"的动机存在张力——虽然分配是动态的，但领域池的边界与规模仍由人定义。
- **OOD 提升的归因不够排他**：OOD 增益可能部分来自多智能体集成本身的方差降低效应，而非专精化。缺少"同算力下单一大模型继续训练"或"随机路由 + 相同训练量"这类控制组，难以彻底剥离集成红利。
- **推理阶段的选择偏保守**：确定性任务取"获胜共识组中熟悉度最高者的完整轨迹"，可能丢弃其他智能体的有效推理片段；开放式任务直接输出单一智能体回答，未利用多智能体聚合潜力，与其协作框架的初衷略有落差。
- **未见失败案例的定性分析**：论文报告了平均值与个别高难基准的提升，但未展示路由错误、专精冲突（两个智能体争夺同一领域）、或回退到全体激活频率过高的具体案例，读者难以判断机制的失效边界。
- **可复现细节仍有缺口**：冻结目标头的正交初始化具体实现、LIFO 缓冲的容量与淘汰策略、micro-batch 的聚合粒度等关键实现细节，需依赖代码仓库而非论文正文。

## 9. 对后续研究的启示

- **把"能力漂移"作为一等公民**：任何在多智能体系统上做路由的工作，都应显式建模智能体参数随时间变化，而非假定固定能力画像。
- **训练分配即能力塑形**：路由不只是推理期的效率工具，也可以是训练期的课程设计器。这一思路可迁移到多专家 MoE 训练、多模态专家分工、甚至多轮对话中的角色分化。
- **用几何量替代奖励回归**：在非平稳 RL 环境中，用"表征距离 + 指数衰减"这类结构性信号替代直接拟合回报，可能是更稳健的胜任度估计范式。
- **分离边距思想可推广**：任何用"推开负样本"的对比式目标都可能面临距离爆炸，设定由下游阈值反推的边距，是一个可复用的稳定性技巧。
- **值得补齐的实验**：(1) N 从 3 到 16 的扩展曲线；(2) 熟悉度的校准分析（命中率/ECE）；(3) 无 verifier 任务下的替代优势构造；(4) 与"同等算力单模型训练"的严格对照；(5) 跨任务迁移时的路由器重用与再适应成本。
- **潜在改进方向**：分层路由（先选领域再选智能体）、路由器与智能体的交替而非同步更新（减少非平稳耦合）、以及允许智能体在训练中"分裂/合并"的动态拓扑，都可能是该框架的自然延伸。
