## 摘要
自主智能体越来越多地被用于完成真实场景下复杂的多工具工作流。然而，现有基准通常按应用或能力拆分任务，并且在比实际实践中遇到的更干净、更稳定的环境中评估智能体。我们提出DuMateBench，这是一个从大规模生产级智能体平台收集的、经过匿名化和隐私筛选的用户会话中重构得到的真实会话基准。每个任务都保留了相关的求解前交互历史、持久化配置和工作空间状态，并经过人工验证。最终得到的基准包含200个任务，覆盖8大类场景和17个细粒度能力类别，大多数任务需要多种能力协同。我们在隔离的Docker容器中执行这些任务，并注入三种形式的真实世界环境复杂度：资源不足型、不稳定型和噪声型，采用结合确定性评估与LLM-as-Judge的混合评估协议评估性能。将五种代表性自主智能体框架搭配四种前沿大语言模型开展的实验表明，严格任务完成率仍存在显著差距。补充的鲁棒性、效率和诊断分析进一步显示，环境扰动下的性能由大语言模型能力和配套智能体框架共同决定。代码和数据已公开于https://dumatebench.com/。

## Abstract
Autonomous agents are increasingly adopted to complete complex, multi-tool workflows in real-world settings. However, existing benchmarks typically separate tasks by application or capability and evaluate agents in environments that are cleaner and more stable than those encountered in practice. We introduce DuMateBench, a real-session benchmark reconstructed from anonymized and privacy-screened user sessions collected from a large-scale production agent platform. Each task preserves the relevant pre-solution interaction history, persistent configurations, and workspace state, and is then validated through human verification. The resulting benchmark comprises 200 tasks spanning 8 broad scenarios and 17 fine-grained capability categories, with most tasks requiring multiple capability coordination. We execute these tasks in isolated Docker containers injected with three forms of real-world environmental complexity: Insufficient, Unstable, and Noisy, and assess performance using a hybrid deterministic and LLM-as-Judge evaluation protocol. Experiments across five representative autonomous-agent frameworks paired with four state-of-the-art LLMs reveal substantial gaps in strict task completion. Complementary robustness, efficiency, and diagnostic analyses further show that performance under environmental perturbations is jointly shaped by the capabilities of the LLM and the surrounding agent framework. The code and data are publicly available at https://dumatebench.com/.

## 1. 核心问题与研究背景
随着大语言模型的发展，自主智能体越来越多地被应用于完成真实场景下复杂的多工具协同工作流，但现有基准存在两个核心缺陷：
- 现有基准通常按应用或能力拆分任务，很少覆盖需要跨能力协同的组合工作流，无法反映真实用户需求通常需要多能力整合的特点
- 现有基准大多在理想、干净、稳定的环境中评估智能体，没有模拟真实场景中常见的依赖缺失、网络不稳定、工作空间干扰噪声等实际挑战，评估结果无法准确反映智能体的真实表现
现有基准很少同时解决上述两个问题，因此需要一个更贴近真实场景的评估基准。

## 2. 提出的方法论
### 核心思想
DuMateBench是一个从大规模生产级智能体平台的真实用户会话中重构得到的基准，同时支持对跨能力组合工作流的评估，并且内置了可控的真实环境扰动，能够更准确地衡量自主智能体在真实复杂工作流中的实际能力。

### 关键技术细节
- **任务构建流程**：
  1. 从DuMate生产平台的匿名化、隐私筛选后的用户会话中，还原原始交互历史，切分得到目标用户请求，保留任务发起前的上下文和工作空间状态，排除任务发起后的结果避免泄露
  2. 经过人工验证筛选，只保留满足请求保真、工作空间完整、无解决方案泄露、无隐私安全风险的任务
  3. 最终得到200个任务，覆盖8大类场景、17个细粒度能力类别，平均每个任务需要2.28种能力协同，知识领域覆盖商业、科技工程、人文社科等多个方向，符合真实场景的需求分布。

- **环境设计**：
  所有任务都运行在隔离的Docker容器中，注入三类可控的真实环境复杂度：
  1. **资源不足型环境**：容器仅预装通用基础工具，任务所需的特定依赖、工具包不预安装，同时对CPU、内存、存储、运行时长做了限制，考验智能体的环境诊断、依赖配置能力
  2. **不稳定型环境**：注入可控的网络层和工具层故障，包括启动阶段的DNS故障、执行阶段间歇性网络延迟丢包、工具临时不可用等，考验智能体的故障识别和恢复能力
  3. **噪声型环境**：保留原始会话中自带的无关干扰文件，还可添加不同强度的合成干扰文件（如重复、过时、冲突文件），考验智能体筛选有效信息的能力。

- **混合评估协议**：
  结合确定性规则和LLM-as-Judge两种评估方式，兼顾客观性和生成质量评估：
  1. 确定性检查：为每个任务生成可客观验证的原子检查项，计算所有检查项的部分通过率，仅当所有检查项通过才认为任务完成
  2. LLM-as-Judge评分：针对输出产物（文档、代码、报告等），提前生成任务专属的评分规则，从需求完整性、内容正确性、输出质量等维度对产物打分
  3. 最终得分计算：最终得分给予确定性检查30%权重，LLM评分70%权重，同时分别报告各分项得分。

- **测试基准**：DuMateBench自带的200个任务
- **对比方法**：选取5个代表性自主智能体框架（Claude Code v2.1.212、Hermes v0.19.0、DuMate v1.0.59、OpenCode v1.18.4、OpenClaw v2026.7.1-2），每个框架分别搭配4个当前SOTA大语言模型（GPT-5.5、Opus-4.8、GLM-5.2、DeepSeek-V4-Pro），一共20种测试配置

## 6. 主要结论与发现
- 现有自主智能体在严格任务完成上仍然存在显著差距，真实复杂环境下的性能同时由基础大语言模型的能力和agent框架设计共同决定
- 不同agent框架对基础大模型变化的敏感度差异很大，DuMate框架的敏感度最低，整体鲁棒性最好
- 工作空间噪声强度提升会普遍导致性能下降，不同agent的抗噪声能力差异明显，DuMate的性能降幅最小
- 自主智能体存在明显的质量-效率trade-off：性能越高的配置，通常运行耗时越长、token消耗越大
- 常见失败模式可分为四类：超时/预算耗尽、工具使用/实现错误、需求理解与上下文 grounding失败、环境依赖故障，不同agent的失败分布存在差异，对应不同的优化方向。

## 7. 方法与实验亮点
- 任务来源于真实生产环境的用户会话，保留了原始交互上下文和工作空间状态，比人工构造的任务更贴近真实需求
- 首次在同一个基准中同时整合了跨能力组合工作流和三类可控真实环境扰动，更符合真实工作场景的实际挑战
- 环境设计可复现，所有任务都运行在隔离Docker容器中，环境扰动可控可重复
- 混合评估协议结合了确定性规则和LLM-as-Judge，兼顾了客观要求验证和开放生成产物的质量评估，比单一评估方式更准确
- 实验覆盖多个维度，能够诊断出智能体的具体薄弱点，对后续算法优化有明确的指导价值。

## 8. 不足与局限
- 任务来源于单个生产平台的用户会话，可能存在平台使用偏差，不一定能覆盖全场景的用户、职业和工作流类型
- 论文仅提供评估基准，没有提出新的agent优化算法，聚焦评估而非算法改进
- 仅测试了少数主流代表性agent框架，覆盖的agent种类有限
- 环境扰动是预定义可控的，和完全开放的真实生产环境仍然存在一定差距。
