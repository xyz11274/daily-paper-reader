## 摘要
大规模三维多智能体路径规划在密集交通下变得日益困难。带回溯的优先级继承（PIBT）具有良好的可扩展性，但在密集交互和大规模拥塞下，其单步目标导向的排序可能变得不足。我们提出 GuardPIBT，它对 PIBT 执行器进行增强而非替换：神经预测仅对 PIBT 原生候选提出残差重排序，而最终动作仍由 PIBT 决定。首先，局部图注意力对邻近交互进行建模，而全局源-目标传输特征为候选重排序提供群体级协调上下文。其次，反事实组门控过滤掉其闭环效应可能降低协调性的重排序。第三，对于超大规模群体，群体自适应分组保持决策粒度，异步缓存推理分摊神经计算开销，选择性修复解决长尾智能体。PIBT 全程保留有效性检查、优先级继承和回溯。多达 100,000 个智能体的实验表明，在二维和三维环境中均能可靠完成，包括所有三次 100,000 智能体仓库运行，且经审计的图违规为零。项目网站见 {\color{magenta}\texttt{https://guardpibt.github.io/GuardPIBT/}}。

## Abstract
Large-scale 3D multi-agent path finding becomes increasingly difficult under dense traffic. Priority Inheritance with Backtracking (PIBT) scales well, but its one-step goal-directed ordering may become insufficient under dense interactions and large-scale congestion. We present GuardPIBT, which augments rather than replaces the PIBT executor: neural predictions only propose residual reorderings of PIBT's native candidates, while final actions remain determined by PIBT. First, local graph attention models nearby interactions, while global source--goal transport features provide population-level coordination context for candidate reordering. Second, a counterfactual group gate filters reorderings whose closed-loop effects may degrade coordination. Third, for ultra-large populations, population-adaptive grouping preserves decision granularity, asynchronous cached inference amortizes neural computation, and selective repair resolves long-tail agents. PIBT retains validity checking, priority inheritance, and backtracking throughout. Experiments with up to 100,000 agents demonstrate reliable completion across 2D and 3D environments, including all three 100,000-agent warehouse runs with zero audited graph violations. The project website is available at {\color{magenta}\texttt{https://guardpibt.github.io/GuardPIBT/}}.

- **核心问题**：经典最优/有界次优MAPF求解器（如CBS、ECBS）可扩展性差；PIBT及其衍生方法（LaCAM、LaGAT等）虽可扩展至10^4智能体，但在极密集场景下存在两大局限：
  - PIBT主要依赖局部交互和目标导向代价，难以捕捉大量智能体汇聚到共享区域所导致的长程拥塞。
  - 直接应用学习偏好具有挑战性，因为最终执行由PIBT的优先级继承和回溯过程决定，一个被偏好的候选未必能改善最终的联合运动。
- **整体含义**：论文提出GuardPIBT，一种**执行器对齐的神经增强框架**，在不替换PIBT原始执行机制的前提下提升其可扩展性。核心思路是学习对PIBT候选排序的**残差修改**，让原始PIBT执行器维持可行性和冲突消解能力。

## 2. 方法论

### 2.1 核心思想

- GuardPIBT保留PIBT作为离散执行器，仅学习对其候选排序的残差调整。神经预测只提出对PIBT原生候选的重排序建议，最终动作仍由PIBT决定。
- 整体流程：3D PIBT骨干计算默认候选键和优先级 → 全局-局部网络融合邻近交互与群体级传输上下文，对27个原生候选打分 → 执行条件组门控决定是否激活残差重排序 → PIBT最终解析声明、继承、位移和回溯，产生下一个有效联合配置。

### 2.2 关键技术细节

**（1）轻量级3D PIBT骨干**
- 使用松弛但障碍感知的下界，避免为每个目标计算完整3D距离场（O(NWHD)内存开销）。
- 水平列仅当所有体素被占据时才视为阻塞；共享同一目标列的智能体复用8连通BFS场。
- 候选键由等待感知欧氏转移代价（轴向1、面对角√2、空间对角√3）与启发式下界之和构成。
- 智能体排序使用累积延迟和非目标等待：δ = [q + h(x) - h(s)]₊，p = δ + λ_w·w + ε。

**（2）全局-局部候选评分**
- **局部交互分支**：13维智能体特征（归一化位置、目标位移、无穷范数、时间、近期运动、是否到达目标、度数等），半径图连接最多k_n个邻近智能体，两层消息感知注意力将边嵌入加到键和值上。
- **全局源-目标传输分支**：每个源-目标对定义直线路径，工作空间划分为固定B×B×B网格，每个活跃传输/目标单元存储中心、当前/目标密度、密度失衡、平均剩余位移、平均近期速度等。密集自注意力耦合活跃token，速度头通过L_FM监督。智能体通过学习的距离、相对方向和目标对齐偏置查询所有token，产生z_flow。
- **门控残差融合**：γ = σ(W_g[z_loc; z_flow])，z = LN(z_loc + γ⊙z_flow)。
- **PIBT感知候选评分**：对每个位移构造7维特征（位移分量、目标占用、竞争默认需求、一步反向边风险、是否默认候选），共享网络产生27动作logit，加上候选特定分数和传输速度对齐项。

**（3）执行器对齐的反事实组门控**
- 高分候选未必改善最终联合执行，因为PIBT可能拒绝它或通过长位移链传播其影响。
- **反事实监督**：冻结评分器从on-policy帧生成top-k提议，活跃提议智能体划分为空间组。对每个非空组，基线和干预rollout从相同配置和相同逐步优先级噪声开始，基线保持默认PIBT排序，干预在前K步激活组提议重排序。两者执行真实PIBT内核H步，计算代价J(τ) = C_exec + H_rem - λ_s·N_solved + λ_w·W + λ_m·L_motion + λ_c·C_column。
- 反事实优势A_g = J(τ_base) - J(τ_int)，门控标签y_g = 1[A_g > 0]。
- **动作条件组门控**：结合融合智能体表示z_i与候选特征ψ_ia，ℓ_cf = ℓ_base + w_cf^T·tanh(W_cf·z_i + φ_c(ψ_ia))。训练时组内聚合logit，用加权BCE和方差正则优化。在线时组内平均概率超过阈值τ_cf才保留重排序。

**（4）两阶段训练**
- **阶段1**：on-policy PIBT rollout提供状态、默认代价向量、执行有效目标候选和未来运动统计，训练编码器和候选评分器，损失L1 = λ_rank·L_rank + λ_def·L_default + λ_FM·L_FM + λ_aux·L_aux。
- **阶段2**：冻结传输编码器、局部GAT和候选评分器，生成组标签，仅优化反事实头。部署阈值在留出组上通过校准和实际配对优势选择。

**（5）大规模部署扩展**

- **可扩展性**：在10,000智能体规模下，GuardPIBT在Forest场景实现2.24×加速（172.41s vs LaGAT 386.40s）且C_SOC略低；在Maze场景相对LaCAM实现1.54×加速和29.5%的C_SOC降低。

## 7. 优点

- **执行器对齐设计**：不替换PIBT，仅学习残差重排序，保留了PIBT的有效性检查、优先级继承和回溯机制，设置所有bonus为零可精确恢复PIBT基线，安全性有保障。
- **反事实组门控**：通过配对PIBT rollout获得执行器对齐的监督信号，直接反映闭环执行效果（包括声明、继承、位移、回溯），而非仅依赖动作偏好，能过滤有害干预。
- **全局-局部融合**：局部图注意力捕捉邻近交互，全局源-目标传输token提供群体级协调上下文，且token在线生成于固定3D网格，可跨地图和规模迁移，无需地图特定引导图。
- **超大规模部署机制**：群体自适应分组保持决策粒度，异步缓存推理将神经计算分摊到多个PIBT步，选择性SIPP修复仅对长尾智能体付出时间扩展搜索代价，设计务实。
- **实验规模突出**：验证到1,000,000智能体，100,000智能体跨6种场景全部完成，三次仓库运行零审计图违规，展示了极强的工程可扩展性。
- **两阶段训练**：分离提议学习和提议准入，避免标签非平稳性，减少学习偏好与实际PIBT执行之间的分布漂移。
