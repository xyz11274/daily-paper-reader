## 摘要
递归自改进（RSI）在长视界任务中仍难以实现，不断增长的历史会掩盖任务状态并造成技能调用错位。本文提出Recuris，一种面向长视界智能体框架的递归经验-工作记忆架构，其中工作记忆追踪任务进展，并从经验记忆中引导技能选择，将技能使用锚定在当前需求而非完整历史上。这种耦合还将执行过程转化为结构化证据，可将故障定位到特定记忆组件。在不同任务中，固定元智能体将该证据转化为技能记忆的局部化、验证门控更新，重塑执行过程并产生新的证据，形成有界的递归记忆演化循环。在四个长视界基准和十个模型上的实验表明，Recuris在37组已完成的模型-基准对中，有35组提升了任务成功率，将前沿模型推至SOTA级任务性能：在tau-bench上，它为GPT-5.6 Sol提升了17.8个百分点，为Claude Opus 5提升了15.6个百分点，使Opus 5达到87.9%的成功率；在SkillFlow上，为Qwen3.6-27B/35B分别提升了16.6/13.5个百分点。随着交互视界增长，性能优势进一步扩大，在最长任务中达到+32.2个百分点，常见长视界故障最高降低了80%。这些结果表明，递归演化记忆是RSI可扩展的基础，使智能体能够将积累的经验持续转化为愈发有效的长视界行为。代码地址：https://github.com/Gen-Verse/Recuris

## Abstract
Recursive self-improvement (RSI) remains hard in long-horizon tasks, where growing histories obscure the task state and misalign skill invocation. We introduce Recuris, a recursive Experiential-Working Memory architecture for long-horizon agent harnesses, in which Working Memory tracks task progress and guides skill selection from Experiential Memory, grounding skill use in current needs rather than the full history. This coupling also turns execution into structured evidence that localizes failures to specific memory components. Across tasks, a fixed Meta-Agent turns that evidence into localized, validation-gated updates to Skill Memory that reshape execution and yield new evidence, forming a bounded recursive memory-evolution loop. Across four long-horizon benchmarks and ten models, Recuris improves task success in 35 of the 37 completed model-benchmark pairs, carrying frontier models to SOTA-level task success: on tau-bench it adds +17.8 points to GPT-5.6 Sol and +15.6 to Claude Opus 5, taking Opus 5 to 87.9%, and +16.6/+13.5 points on Qwen3.6-27B/35B on SkillFlow. The advantage widens as the interaction horizon grows, to +32.2 points on the longest tasks, and common long-horizon failures fall by up to 80%. These results position recursively evolving memory as a scalable foundation for RSI, enabling agents to continuously transform accumulated experience into increasingly effective long-horizon behavior. - 传统方法失败后只能拿到最终成败信号，无法定位故障出在哪个记忆模块，只能做粗粒度的全局修改，改进效率低效果差，长任务下容易出现错误级联，成功率快速衰减。

## 2. 提出的方法论
### 核心思想
提出Recuris架构，将经验记忆（EM，存储可复用技能）和工作记忆（WM，跟踪验证当前任务状态）耦合，生成结构化执行轨迹，实现组件级的有界验证门控递归记忆演化，不需要修改基础大模型权重，仅在外部记忆控制层完成自改进。
### 关键技术细节
1. **技能记忆架构**：演化过程中记忆控制层由四个可修改组件构成：
   - 经验记忆E：存储可复用的领域技能
   - 工作记忆规范W：定义状态 schema 和状态更新规则
   - 调用策略ρ：决定触发检索的时机和要调用的技能
   - 检查器集合C：验证状态变更是否符合环境反馈
2. **任务内验证式EM-WM耦合**：
   - 工作记忆维护结构化当前状态：每个目标记录内容、完成状态、支撑证据、阻塞信息，仅提交环境反馈验证通过的状态变更，不相信模型自身的完成断言，保证状态一直准确。
   - 状态锚定技能调用：在预定义的执行事件（如工具调用前、轮次边界）触发检索，根据当前状态选择匹配的技能，避免全历史检索的噪声干扰。
   - 执行过程生成结构化轨迹，记录每一步的状态、调用的技能、动作、观测、验证结果，为后续故障定位提供支撑。
3. **跨任务有界递归演化**：
   - 故障定位：固定元智能体基于结构化轨迹，将每个失败归因到具体的记忆组件（如E对应技能缺失，W对应状态定义错误，ρ对应调用时机错误，C对应验证规则错误）。
   - 局部补丁：仅对出问题的组件做针对性修改，未出问题的组件保持不变，避免全局改写带来的能力退化。
   - 验证门控：补丁只有同时满足「修复源故障」和「不降低已有锚定任务的性能」两个条件，才会被合并到正式记忆中。
   - 递归循环：更新后的记忆会改变未来任务的执行，产生新的结构化轨迹，支持下一轮改进，整个过程基础大模型、元智能体、验证规则都保持固定，递归仅发生在记忆控制层，属于有界安全的自改进。
4. 额外支持**单任务测试时自适应模式**，针对无共享结构的孤立任务，在单个任务的多次尝试中完成局部记忆演化。

## 3. 实验设计
### 测试基准与数据集
一共使用4个标准长视界基准：

- 主实验对每个模型，对比「基准原生智能体」和「原生智能体+Recuris」的性能，所有基础模型参数全程冻结，不更新权重。

## 6. 主要结论与发现
- Recuris在35/37的模型-基准对上实现了任务成功率提升，对前沿模型也有显著收益：在`τ²-Retail`上为GPT-5.6 Sol提升17.8个百分点，为Claude Opus 5提升15.6个百分点，最终达到87.9%的成功率；在SkillFlow上为Qwen3.6-27B/35B分别提升16.6/13.5个百分点。
- 性能优势随任务交互长度增加而扩大：在最长的任务中成功率提升达到32.2个百分点，常见长视界任务失败（幻觉完成、漏写操作、错误级联等）发生率降低20%~86%。
- 结构化轨迹大幅提升故障定位准确率：注入已知故障的测试中，结构化轨迹的故障定位准确率达到64.8%，而仅用最终任务结果只有13.0%。
- 演化得到的技能记忆可以稳定跨任务、跨模型迁移：在一个中端模型上演化得到的记忆，直接迁移到从未参与演化的其他规模模型，依然可以获得显著提升。
- 状态锚定的技能调用远优于将全量技能放入上下文让模型自行选择：全量技能放入上下文不仅会增加计算成本，还会导致成功率下降18个百分点。

## 7. 优点
- 架构设计创新：将递归自改进限制在外部记忆控制层，不需要修改基础大模型权重，演化成本低，可移植性好，复用方便。
- 机制设计合理：EM-WM耦合解决了长历史噪音问题，结构化轨迹支持精准组件级故障定位，局部修改+验证门控保证了演化稳定性，不会破坏已有能力。
- 实验设计严谨：控制变量到位，统计检验规范，覆盖了从小模型到前沿模型的不同规模，不同类型的长视界任务，验证充分结论可信。
- 通用性强：同时支持跨任务共享结构下的批量演化，和孤立单任务的测试时自适应，适配不同应用场景。

## 8. 不足与局限
- 单任务测试时自适应的提升在当前实验样本下没有达到统计显著性，仅观察到方向上的提升，还需要更大规模的验证。
- 对于基线已经很高的任务，方法的收益空间有限，部分高基线任务没有观察到显著提升。
- 长期多轮递归演化的稳定性还没有在超大规模跨领域任务集上得到充分验证，长期演化的安全性还有待进一步研究。
- 验证门的判断受开发集样本量限制，部分有潜力的补丁会因为开发集统计力不足被拒绝，可能损失部分潜在收益。
