## 摘要
训练工具使用的智能体从自身经验中改进仍然具有挑战性，因为监督微调依赖于固定的教师蒸馏轨迹，而稀疏奖励强化学习为长程交互提供的监督较弱。我们提出了DeepSearch-Evolve，一个基于DeepSearch-World构建的Web智能体自我蒸馏框架，DeepSearch-World是一个确定且可验证的环境，具有可复现的搜索和页面阅读工具。DeepSearch-World包含42万个由实体级随机游走构建的多跳问答任务，并支持对自我进化有用的关键智能体认知行为，包括进度验证、基于反思和失败恢复。DeepSearch-Evolve迭代地进行轨迹生成、过滤、数据混合和微调，以训练更强的智能体。在没有从更强模型蒸馏的情况下，DeepSearch-World-9B在开源智能体中取得了具有竞争力的性能，在BrowseComp上达到31.2%，在GAIA上达到61.5%，在HotpotQA上达到93.4%，表明可验证环境能够为长程Web智能体实现可扩展的自我进化。我们将发布环境、42万个训练池、验证集、模型和代码，以促进未来关于自我改进深度搜索智能体的研究。

## Abstract
Training tool-use agents to improve from their own experience remains challenging, as supervised fine-tuning relies on fixed teacher-distilled trajectories, while sparse-reward reinforcement learning provides weak supervision for long-horizon interactions. We present DeepSearch-Evolve, a self-distillation framework for web agents built on DeepSearch-World, a deterministic and verifiable environment with reproducible search and page-reading tools. DeepSearch-World contains 420K multi-hop QA tasks constructed from entity-level random walks and supports key agentic cognitive behaviors useful for self-evolving, including progress verification, grounded reflection, and failure recovery. DeepSearch-Evolve iteratively performs trajectory generation, filtering, data mixing, and fine-tuning to train stronger agents. Without distillation from more capable models, DeepSearch-World-9B achieves competitive performance compared with open-source agents, reaching 31.2% on BrowseComp, 61.5% on GAIA, and 93.4% on HotpotQA, showing that verifiable environments enable scalable self-evolution for long-horizon web agents. We will release the environment, 420K training pool, validation set, model, and code to facilitate future research on self-improving deep search agents.

- **整体含义**：本文旨在通过构建一个**确定性、可验证的离线环境**，以及**自蒸馏框架**，使智能体能够从自身生成的、经过环境验证的轨迹中学习，实现无需更强模型蒸馏的自我进化，从而提升长程搜索与推理能力。

## 2. 方法论：核心思想与关键技术细节
- **核心思想**：利用可验证环境提供过程级监督信号，通过迭代生成、过滤、格式转换和SFT训练，让智能体从自身成功经验中蒸馏出规划、记忆、纠错等高级能力。
- **关键技术细节**：
  - **DeepSearch-World环境**：
    - 基于Wikipedia知识图谱（约1000万实体）构建确定性离线工具：`web_search_wiki`（BM25检索，返回标题+摘要+确定性URL）和`visit_wiki`（SQLite偏移索引读取全文）。
    - 42万条多跳QA任务，由实体级随机游走生成，支持**进度验证**（实体级完成集）、**基于反思**（环境注入反馈）和**失败恢复**。
  - **脚手架教师智能体**：
    - 三阶段生成：**Plan**（初始化进度状态，含completed_list、todo_list、experience、information）、**Act**（迭代调用工具，更新状态）、**End**（生成基于已验证信息的答案）。
    - 关键：环境在每次工具调用后返回反思信号（如“Found target keyword”），用于指导重试和规划。
  - **自蒸馏训练循环（DeepSearch-Evolve）**：
    - 每轮R，当前模型πθR作为教师在DeepSearch-World中生成轨迹。
    - 经过**拒绝采样**（答案正确）和**质量过滤**（Qwen3.5-9B评判冗余性、对齐性、逻辑性）后，将脚手架格式转换为**ReAct格式**（将进度状态和反思重写为<think>推理，公式：<think>t = Pt ⊕ Rt ⊕ At）。
    - 使用**重要性采样数据混合**（轮次衰减因子γ=0.5）和**SFT训练**更新学生模型πθR+1。
    - 目标函数：最小化验证轨迹上的交叉熵（等同于硬标签策略蒸馏）。
  - **异步训练设计**：生成与训练解耦，生成永不阻塞训练，通过批量处理提高吞吐量。

## 6. 主要结论与发现
1. **可验证环境使自蒸馏成为可能**：DeepSearch-World通过实体级进度验证和反思信号，提供了稳定、可复现的监督，使得智能体可以从自身经验中学习规划、记忆和纠错能力。

3. **数据规模与多样性是关键**：420K数据池比100K产生更高平台性能、更低格式错误率及更稳定的工具使用，说明自蒸馏依赖多样化经验而非重复暴露。
