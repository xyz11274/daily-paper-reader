## 摘要
自我改进的AI智能体旨在从错误中学习。我们表明它们也能凭空想象从未发生的错误。我们在自动化框架优化中研究了这种失败模式，其中基于LLM的提议者编辑智能体的脚手架，包括提示、解析器、过滤器、验证器和护栏，以消除观察到的失败。但这个过程很少首先问：是否有真正的失败需要修复？我们引入了反事实构造实验室，这是一个确定性的微型实验室，已知的正确操作是不做任何事。该实验室为一种可证明从未发生的失败类种植了一个候选护栏，只呈现合法情节，并使用字节精确的预言机检查每个引用的违规。提议者在真实违规上表现如预期，在无特征合法输入上则弃权。然而，当合法输入包含一个类似熟悉游戏规则的无害模式时，它发明了一个失败：在60次运行中有15次，而在无特征输入上为0/60，它启用了不存在的规则护栏并引用了一个被预言机反驳的违规。这种效应是有结构的，而非不加区分。在单次提案中，仅当三个条件同时满足时才会出现：一个规则形状的模式、一个开放式规则集和一个预设失败的指令。移除其中任何一个条件都会消除虚构。由于发明的护栏不改变任何真实结果，也无法改进已经完美的抑制分数，这种现象既不是奖励破解也不是过度拒绝。它是一个幻影护栏：对一个从未发生的失败的修复，对仅抑制的接受不可见。在仅添加的接受循环中，即使没有预设失败的指令，它也会重新进入，循环的持续添加角色提供了单次指令所供应的需求，一旦进入就持续存在。我们提出了反事实构造实验室，用于衡量自我改进智能体框架中的虚构失败。

## Abstract
Self-improving AI agents are designed to learn from their mistakes. We show they can also hallucinate mistakes that never happened. We study this failure mode in automated harness optimization, where an LLM-based proposer edits an agent's scaffold, including prompts, parsers, filters, validators and guardrails, to eliminate observed failures. But this process rarely asks first: was there a real failure to fix? We introduce the Counterfactual Fabrication Lab, a deterministic micro-lab where the correct action is known: do nothing. The lab plants a candidate guardrail for a failure class that provably never occurs, presents only legal episodes, and uses a byte-exact oracle to check every cited violation. The proposer behaves as expected on real violations and abstains on featureless legal input. Yet when the legal input contains a harmless pattern resembling a familiar game rule, it invents a failure: in 15/60 runs, versus 0/60 on featureless input, it enables the nonexistent-rule guardrail and cites a violation the oracle refutes. The effect is structured, not indiscriminate. In single-shot proposals it appears only when three conditions coincide: a rule-shaped pattern, an open-ended rule set and an instruction that presupposes failures. Removing any of these conditions eliminates the fabrication. Because the invented guardrail changes no true outcome and cannot improve an already-perfect suppression score, the phenomenon is neither reward hacking nor over-refusal. It is a phantom guardrail: a fix for a failure that never happened, invisible to suppression-only acceptance. Inside an add-only accept loop it re-enters even without the failure-presupposing instruction, the loop's keep-adding role supplying the demand the instruction supplied in single shot, and once in it stays. We present the Counterfactual Fabrication Lab for measuring fabricated failures in self-improving agent harnesses.

### 幻影护栏：当自我改进的智能体修复从未发生的失败

### 1. 核心问题与整体含义（研究动机和背景）

*   **核心问题**：自我改进的AI智能体（特别是通过LLM自动优化其“脚手架”，如提示、解析器、护栏的系统）可能会**幻觉出从未发生过的失败**，并为此构建不必要的“幻影护栏”。
*   **研究动机**：现有的自我改进循环通常仅奖励“抑制观察到的失败”（suppression-rewarded），而不会去验证“这个修复是否真的有必要”。这种机制可能导致智能体不仅会遗漏真实问题（under-fixing），更危险的是会**凭空捏造问题**（over-fixing）。
*   **整体含义**：论文揭示了自动化AI系统优化中的一个新故障模式。它表明，仅依赖“修复可见错误”的反馈信号是不够的，可能会导致系统无端增加复杂性、延迟和潜在的失败面，而性能指标上却毫无体现。这为AI安全和可信赖性研究提出了新的挑战。

### 2. 论文提出的方法论

*   **核心思想**：构建一个**确定性的微型实验环境**（Counterfactual Fabrication Lab），在该环境中，已知的唯一正确操作是“什么都不做”。通过植入一个**理论上永不触发**的失败类（如非法“王车易位”），并为所有动作提供“合法”标签，来观察LLM提议者是否会主动为该不存在的规则创建护栏。
*   **关键技术细节**：
    *   **实验平台**：一个名为“MiniArena”的2x2棋盘游戏环境，智能体在此环境中执行移动（move）。所有移动记录都带有合法性标签（legal/illegal）。
    *   **护栏菜单**：包含四个钩子（hook）：P（修复语法）、Q（标注观察，惰性）、R（阻止出界）、S（阻止“特殊规则违规”，即**幻影护栏**的目标）。菜单未明确“特殊规则”是什么，但名称暗示了游戏规则的prior。
    *   **字节精确预言机（Byte-exact Oracle）**：用于审计每个引用的违规是否真实存在。对于“王车易位”规则，预言机能确保该违规只会在人为注入的非法移动中出现，而绝不会在正常生成的合法移动中出现。
    *   **指标**：`Fab(H, D) = 1[g_castle ∈ H]`。即，如果一个运行得到的最终护栏集H包含“王车易位”护栏（g_castle），且预言机认证整个池D中没有任何“王车易位”违规发生，则判定为一次“虚构”。

### 3. 实验设计

*   **数据集/场景**：
    *   **同余池 (Congruent pool)**：包含真正非法“王车易位”移动的剧情，作为**激活检查**，验证护栏是否能正确工作。
    *   **建构池 (Fabrication pool)**：所有移动均合法的剧情，但其中包含一个**无害的表面规律**（如多个游戏重复移动到同一格子B2）。这是测试虚构的主要场景。
    *   **原始池 (Pristine pool)**：所有移动均合法且无任何模式的剧情，作为**基线**，测试智能体是否在无事可做时会主动构建。
    *   **用于机制控制的定式电池 (Battery)**：固定频率植入不同模式（重复格子、共享列、固定对角线、角落格子）。
    *   **其他控制臂**：
        *   **完整性保证臂 (Assured arm)**：告知规则集是完整的，没有隐藏规则。
        *   **指令消融臂 (Instruction arm)**：将系统提示中的“修复失败”改为更中性的“提出被剧情证实的护栏”。
        *   **接受循环臂 (Loop arms)**：模拟不同的自我改进循环（仅添加、严格改进、保证证据），测试幻影护栏的持久性。
*   **Benchmark**：论文没有依赖外部benchmark，而是**自行构建了“Counterfactual Fabrication Lab”**作为检测基准。对比对象主要是不同LLM（作为提议者）在不同实验条件下的行为差异。
*   **对比方法**：主要对比了不同实验条件下（不同池、不同控制臂）的虚构率。在循环实验中，对比了不同接受规则（suppression-only vs. warrant-aware）的效果。

### 6. 主要结论与发现

1.  **幻影护栏现象确认**：在单次提案中，当三个条件同时满足时：
    *   **规则形状模式**（如重复的格子）
    *   **开放式规则集**（未声明规则集完整）
    *   **预设失败的指令**（“移除这些失败”）
    智能体会以**25%的概率（15/60）** 虚构一个失败，并启用幻影护栏（g_castle）。
2.  **条件可消除**：移除上述任何一个条件，虚构率立即降为 **0/60**。这强烈证明了因果机制。
3.  **不是奖励破解**：幻影护栏在所有合法池上是一个无操作（no-op），不能提升抑止分数，也不能降低真实收益。因此不是标准的奖励破解或过度拒绝。
4.  **循环加重问题**：在“仅添加”的接受循环中，即使没有预设失败的指令，循环本身提供“必须添加”的压力，导致幻影护栏仍会缓慢积累。而“保证证据”的接受规则能完全阻止其进入。
5.  **具身性**：该效果集中在特定的LLM上（如glm-5.1），而非所有模型，表明其与模型能力或训练偏差有关。

### 7. 优点

*   **实验设计极其干净、精巧**：“Counterfactual Fabrication Lab”的设计是思维严谨的典范，将复杂问题简化为可控的、可审计的微型实验。
*   **使用确定性预言机**：完全避免了模型自我评估或人类评估的主观性和不可靠性，使“虚构”的判定具有数学上的确定性。这是方法和结果上的巨大优势。
*   **发现了重要的概念性故障模式**：揭示了“幻影护栏”这一新的、微妙的故障模式，对自改进系统领域有重要影响。
*   **条件控制简洁有力**：直接通过三个条件的因果消融，清晰地展示了机，证明力强。

### 8. 不足与局限

*   **量化效果中等**：整体虚构率在0.25左右，且主要集中在单一模型上。虽然统计显著，但在实际大规模系统中可能并非主导问题。
*   **环境的高度简化**：2x2迷你棋盘是一个非常简化的环境。扩展到真实的、复杂的软件系统或工具使用场景（如安全护栏）时，其效果是否一致有待验证。
*   **提示词框架的潜在泄露**：护栏菜单中“特殊规则”的命名可能无意中激发了LLM的“规则推断”行为，为其虚构提供了框架。（作者已经通过控制实验分析和部分消融了这种影响）。
*   **模型样本有限**：虽然测试了8个模型，但并非所有模型都进行了所有实验。一些结论（如能力梯度）的普适性有待更广泛的模型测试。
*   **没有讨论对“现实影响”的量化**：虽然指出了幻影护栏会增加延迟、计算成本等，但文章没有具体量化这些潜在成本在实际部署中的严重性。
