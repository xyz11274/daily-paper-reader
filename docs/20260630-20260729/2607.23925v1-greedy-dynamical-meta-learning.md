## 摘要
梯度下降法能很好地扩展到大规模模型，但在长时间跨度下变得不稳定。无梯度优化器可以扩展到任意时间跨度，但受限于高维度。由于学习发生在长时间尺度的大模型中，这些方法都不太可能产生能够加速学习过程的特征。相反，我们提出了一种元学习算法，其中智能体学习修改自身的权重和偏差。我们的算法包括一个内循环，其中智能体对自己执行一些高维优化，以及一个外循环，其中我们对内循环执行一些低维优化。由于外循环处理的参数非常少，可以使用标准的零阶方法。

## Abstract
Gradient descent scales well to large models, but becomes unstable over long time horizons. Gradient-free optimizers can scale to arbitrary timespans, but are hobbled by high dimensions. Since learning occurs in large models over long timescales, neither of these approaches is likely to produce traits which can accelerate the learning process. Instead, we propose a meta-learning algorithm in which the agent learns to modify its own weights and biases. Our algorithm consists of an inner loop, wherein the agent performs some high-dimensional optimization upon itself, and an outer loop, wherein we perform some low-dimensional optimization upon the inner loop. Since the outer loop handles very few parameters, standard zeroth-order methods may be used.

- **核心问题**：现有的优化方法在大模型和长时间学习场景下存在根本性缺陷——梯度下降法在长时间跨度下因混沌动力学（蝴蝶效应）导致梯度爆炸/消失，无法稳定优化；而无梯度优化器（如进化策略）虽然可应对任意时间跨度，但在高维参数空间中面临“维度诅咒”（随机采样效率随维度平方下降）。

## 2. 方法论：核心思想、关键技术细节、算法流程

### 核心思想
- 将智能体视为**随机动力系统**，其状态 \(x\)（包含权重和激活值）随时间按固定运动定律演化。
- 学习过程通过**贪婪选择**实现：在每个“世代”（内循环）中，从父代状态生成多个突变体，沿长时间模拟多条轨迹，根据评估累积奖励选择最佳突变体作为下一代的父代。
- 关键在于**分离两个时间尺度**：
  - **突变时间尺度 \(\mu\)**：突变后系统达到“智能”峰值的时间；
  - **评估时间尺度 \(\nu\)**：奖励函数变得可区分的时间（通常晚于 \(\mu\)）。
- 外循环使用**零阶方法**（随机方向随机逼近，RDSA）自适应调整 \(\mu\) 和 \(\tau\)（\(\tau\) 控制评估总长度），仅需优化两个标量参数，避免了高维优化困难。

### 关键技术细节
1. **内循环算法（Algorithm 1）**：
   - 固定突变数 \(m=8\)（Rechenberg 规则）。
   - 从父代 \(x_{\text{parent}}\) 生成 \(m\) 个突变体（通过随机扰动）。
   - 对每个突变体，模拟 \(\tau\) 条轨迹（每条轨迹从时间 \(\mu\) 开始评估至 \(\tau j\)），累计奖励 \(z_i\)。
   - 选择奖励最高的突变体作为新父代。

2. **外循环自适应调参（Algorithm 2）**：
   - 定义速度指标 \(Q(\mu,\tau) = \frac{\mathbb{E}[f(C_{\mu\tau}(x))-f(x)]}{\tau}\)，其中 \(C_{\mu\tau}\) 是内循环。
   - 定义 \(S(\mu,\tau) = \frac{\mathbb{E}[f(C_{\mu\tau}(x))-f(x)]}{\mu}\)。
   - 通过梯度条件 \(dQ=0\) 导出更新方程：
     \[
     \Delta \log \mu = \eta\left(\frac{1}{\sigma^2}(S^+-S^-)\xi^\mu + (S^++S^-)\right),\quad
     \Delta \log \tau = \eta\left(\frac{1}{\sigma^2}(S^+-S^-)\xi^\tau - (S^++S^-)\right)
     \]
     其中 \(\xi^{\mu,\tau}\sim\mathcal{N}(0,\sigma^2)\)，\(\sigma^2\approx0.1\)，\(S^\pm\) 由并行运行两个不同参数的循环获得。
   - 仅需调整一个超参数 \(\eta\)（学习率），其余参数有默认合理取值。

### 算法流程（文字说明）
1. 初始化状态 \(x\)、参数 \(\mu,\tau\)。
2. 重复以下步骤：
   - 从当前 \(x\) 出发，生成两个扰动版本 \((\mu^+,\tau^+)\) 和 \((\mu^-,\tau^-)\)。
   - 分别运行 \(T=\tau/\mu\) 轮内循环，得到新状态 \(x^+,x^-\)。
   - 对 \(x, x^+, x^-\) 各采样 \(N\) 个奖励，计算 \(z, z^+, z^-\)。
   - 更新 \(\mu\) 和 \(\tau\) 的 log 值，随机选择 \(x^+\) 或 \(x^-\) 作为下一轮状态。
