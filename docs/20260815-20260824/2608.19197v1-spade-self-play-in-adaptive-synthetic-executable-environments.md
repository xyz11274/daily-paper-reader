## 摘要
持续自我改进需要一个不断扩充的、由自我生成的多样化自适应目标池。对于语言智能体而言，现有训练环境池（人工整理、静态合成或固定验证器）在学习者规模扩展时，目标分布始终保持固定。我们提出SPADE（Self-Play in Adaptive Synthetic Executable Environments，自适应合成可执行环境中的自我对弈），这是一个自我对弈强化学习框架，其中单个大语言模型（LLM）同时扮演两个角色：环境设计者，它以可执行代码编写具备OpenAI Gym风格reset()/step()接口的完整长范围训练环境；推理智能体，负责学习在这些环境中执行动作。每个环境都是有状态的多轮环境（包含状态转移、奖励函数和验证代码），因此单个接口即可同时覆盖推理问题与多步智能体工具使用任务。推理智能体的遗憾值通过其获得特权提示与未获得特权提示的奖励差距估计；在优化该遗憾值信号的过程中，环境设计者学习生成处于智能体能力边界、同时保持可行性的环境。通过大量实验，我们发现了多个对成功至关重要的组件：将环境设计者锚定到从大规模预训练语料采样得到的文档，以及为其配备累积环境记忆。扩展至300亿参数模型后，SPADE在8个留存的数学、科学、代码和推理基准上平均比最强的固定环境基线提升5.3个点；在工具使用场景中，SPADE在BFCL-v4多轮测试上提升5.7个点，在ACEBench-Agent上提升13.9个点；在游戏场景中，与最强基线的性能差距随模型规模扩大而增长。通过将环境设计本身变为可学习组件，SPADE朝着开放式自我改进迈出了切实一步。

## Abstract
Continuous self-improvement requires an ever-expanding pool of self-generated, diverse, adaptive goals. For language agents, existing training environment pools (hand-curated, statically synthesized, or frozen-verifier) keep the goal distribution fixed as the learner scales. We introduce SPADE (Self-Play in Adaptive Synthetic Executable Environments), a self-play RL framework in which a single LLM plays two roles: an Environment Designer that writes complete, long-horizon training environments as executable code with an OpenAI Gym-style reset()/step() interface, and a Reasoning Agent that learns to act in them. Each is a stateful, multi-turn environment (state transitions, reward functions, and verification code), so one interface spans reasoning problems and multi-step agentic tool use. The Reasoning Agent's regret is estimated using the gap between its reward with and without privileged hints; in optimizing this regret signal the Environment Designer learns to target environments at the edge of the agent's capabilities while keeping them feasible. Through extensive experimentation, we find several components critical to success: grounding the Environment Designer on documents sampled from a large pretraining corpus, and giving it an accumulated environment memory. Scaling to 30B-parameter models, SPADE improves over the strongest fixed-environment baseline by +5.3 on average across eight held-out math, science, code, and reasoning benchmarks, and lifts the tool-use setting by +5.7 on BFCL-v4 multi-turn and +13.9 on ACEBench-Agent; on the games setting, the margin over the strongest baseline grows with model scale. By making environment design itself a learnable component, SPADE takes a concrete step toward open-ended self-improvement.

## 核心思想
让单个大语言模型同时承担**环境设计者**和**推理智能体**两个角色，共享模型参数共同进化，环境设计者持续生成适配推理智能体当前能力边界的可执行训练环境，支撑推理智能体持续提升，实现开放式自我改进。

## 关键技术细节
1. **双角色共权架构 + 代码化环境表示**
  单个LLM通过角色提示切换两个功能：
  - 环境设计者（ED）：输出符合OpenAI Gym标准`reset()/step()`接口的完整Python可执行环境，每个环境自带状态转移逻辑、奖励函数、验证代码，统一支持单轮推理任务和多轮交互/工具使用任务；同时为每个环境生成一个不暴露答案的特权提示（包含核心解法思路、关键观察）。
  - 推理智能体（RA）：在生成的环境中交互学习，获得任务完成奖励。
2. **提示-based 遗憾奖励（难度适配核心）**
  环境设计者的奖励定义为推理智能体带提示和不带提示的平均奖励差：`r_D = 带提示平均奖励 - 不带提示平均奖励`。该奖励的逻辑是：高遗憾代表环境刚好在推理智能体的学习边界——带提示能解决、不带提示无法解决，是最适合训练的难度；如果智能体已经掌握（带不带都能赢）或完全无法解决（带提示也赢不了），遗憾都会很低，设计者就不会倾向生成这类无效任务。
3. **多样性与稳定性保障**
  - 语料接地：每次生成环境都从大规模预训练语料采样一个文档作为生成种子，避免无接地自对弈的模式坍缩，维持环境多样性。
  - 环境记忆：缓存历史生成环境和对应的遗憾得分，帮助设计者避开已经被掌握的简单任务和完全不可解的任务，持续聚焦能力边界。
  - 训练稳定技巧：采用分角色优势归一化、延迟环境设计者更新、截断重要采样修正离线梯度、不对称PPO裁剪范围，保证双角色共权训练的稳定性。

## 算法流程
每次迭代：①环境设计者生成一批环境，过滤语法错误、无法执行的无效环境；②推理智能体分别对每个环境做带提示和不带提示的多轮交互采样；③计算环境设计者的遗憾奖励和推理智能体的任务完成奖励；④共同更新LLM参数，循环迭代。

1. SPADE的自适应自对弈增益显著：30B参数规模下，在8个推理基准上平均比最强固定环境基线提升5.3个百分点，性能增益随模型规模扩大而增长（相对于初始base模型，4B提升+5.2，8B提升+5.7，30B提升+8.1）。

3. 语料接地和环境记忆是稳定有效的核心：去掉语料接地会导致环境多样性快速坍缩，去掉环境记忆会大幅降低难度匹配准确性，两者都会导致性能大幅下降。
4. 提示遗憾奖励比传统EMA学习潜力信号更精准，能更好定位推理智能体的能力边界，最终性能更高。
5. 训练过程中环境设计者会自动跟随推理智能体的能力提升，逐步生成更复杂、难度更高的环境，实现共同进化，避免了固定环境池的性能饱和问题。
6. 课程多样性越高，最终泛化性能越好，多技能课程的增益远高于限制为少数技能的课程。

# 7. 优点
1. 思路创新：将环境设计本身变为可学习的强化学习组件，实现环境与智能体的共同进化，从根源上解决了固定环境池无法支撑持续自我改进的问题。
2. 通用性强：用可执行代码表示环境，统一了单轮推理和多轮工具使用任务，同一个框架可以适配完全不同的任务领域。
3. 解决了自对弈的经典缺陷：通过语料接地解决了无约束自对弈的模式坍缩问题，通过提示遗憾信号精准实现难度适配，避免生成过难或过易的无效任务。
4. 实验验证充分，可复现性好：跨规模、跨领域验证了方法有效性，代码和实验配置全部公开。

# 8. 不足与局限
1. 生成环境的复杂度受限于基础模型的能力：环境的最大复杂度受限于基础模型的上下文长度和表达能力，无法生成比模型本身表达能力更复杂的环境。
2. 学习规则是人工固定的：整个训练过程依赖人工设计的GRPO优化算法，SPADE没有实现学习规则本身的自我改进。
3. 未验证长期开放式进化：当前实验仅评测固定训练轮次后的固定任务基准性能，没有验证真正长期的开放式持续自我改进的效果。
4. 计算开销高于固定环境训练：每次迭代需要生成新环境并让推理智能体做两次采样（带提示、不带提示），训练成本更高。
