## 摘要
尽管参数高效微调（Parameter-Efficient Fine-Tuning, PEFT）通过减少可训练参数量大幅降低了大语言模型（Large Language Models, LLM）适配的硬件成本，近期研究仍试图通过参数共享进一步改进PEFT。然而这些现有方法要么采用跨层均匀参数共享，该方式会延缓收敛，要么依赖动态掩码策略，该方式会增加计算开销。由Transformer架构固有层次结构启发得到的共享模式，其在PEFT中的潜力尚未得到探索。为填补这一空白，我们提出SAPE（Sandwich Adapters for Parameter Efficiency，面向参数效率的三明治适配器），这是一个基于三明治式硬权重共享拓扑的PEFT框架。SAPE通过平衡的共享组适配器路由Transformer中间层，同时严格隔离输入嵌入和最终投影的边界变换以避免梯度干扰。该设计在显著降低内存消耗的同时，消除了动态参数共享方法带来的计算开销。在仅编码器和因果解码器架构上的大量评估表明，SAPE在低参数区间取得了当前最优性能。在自然语言理解任务中，SAPE仅使用基线proPETL 10%的参数预算，就在RoBERTa-large上性能超越了proPETL。在严格约0.6M参数约束下，使用LLaMA-3.2（3B）开展自然语言生成与世界知识推理实验，SAPE性能优于AdaLoRA，在GSM8K上取得了+4.85%的绝对提升，在CommonsenseQA上取得了+3.11%的绝对提升。此外，通过全面的拓扑消融实验，我们明确了一个固有的容量权衡：硬参数共享虽然对语义泛化有较强的正则化作用，但会轻微平滑刚性多步算术推理所需的尖锐分层变换。

## Abstract
While Parameter-Efficient Fine-Tuning (PEFT) has substantially reduced the hardware cost of adapting Large Language Models (LLMs) by decreasing the number of trainable parameters, recent studies have sought to further improve PEFT through parameter sharing. However, these approaches either employ uniform parameter sharing across layers, which can delay convergence, or rely on dynamic masking strategies, which add computational overhead. The potential of sharing patterns inspired by the inherent hierarchical structure of Transformer architectures remains unexplored in PEFT. To address this gap, we introduce SAPE (Sandwich Adapters for Parameter Efficiency), a PEFT framework based on a sandwich-style hard weight-sharing topology. SAPE routes intermediate Transformer layers through balanced shared group adapters while strictly isolating the input embedding and final projection boundary transformations to prevent gradient interference. This design significantly reduces memory consumption while eliminating the computational overhead associated with dynamic parameter-sharing methods. Extensive evaluations across encoder-only and causal decoder architectures demonstrate that SAPE achieves state-of-the-art performance in low-parameter regimes. On natural language understanding, SAPE outperforms proPETL on RoBERTa-large while utilizing only 10% of the baseline's parameter budget. On natural language generation and world knowledge reasoning with LLaMA-3.2 (3B) under a strict ~0.6M parameter constraint, SAPE outperforms AdaLoRA, yielding absolute improvements of +4.85% on GSM8K and +3.11% on CommonsenseQA. Furthermore, through comprehensive topological ablations, we formalize an inherent capacity trade-off: while hard parameter sharing strongly regularizes semantic generalization, it slightly smooths the sharp layer-wise transformations required for rigid multi-step arithmetic reasoning.

# 2. 提出的方法论
## 核心思想
基于三明治式硬权重共享拓扑设计适配器，隔离Transformer输入输出边界层的独立适配，中间层分组共享适配器参数，在大幅压缩可训练参数量的同时避免梯度干扰，完全消除动态参数共享方法的额外计算开销。

## 关键技术细节
1. **拓扑划分**：将Transformer所有层划分为两类：
   - 边界层：最底层输入嵌入层（$L_0$）和最顶层输出投影层（$L_{N-1}$），为两个边界层分别分配独立、不共享的适配器，保留输入低级特征和输出任务特征的变换自由度，避免梯度干扰
   - 中间层：除边界层外的所有中间层，划分为$G$个均衡分组，保证任意两个分组的层数差不超过1，支持配置额外层数集中在前端（`DenseEarly=True`）或后端（`DenseEarly=False`），同一分组内所有层共享同一个适配器的全部参数
2. **适配器结构与位置**：采用常规瓶颈适配器结构，在每个Transformer层的FFN输出后插入适配器，做残差变换：先将隐藏态降维到瓶颈维度，经ReLU激活和dropout，再升维回原维度
3. **优化与正则化设计**：共享适配器的梯度为分组内所有层的梯度累加，迫使共享参数学习跨深度通用特征，天然起到结构正则化作用；核心设计创新是**独立dropout掩码**：每个层调用共享适配器时，都生成独立的随机dropout掩码，而非全分组共用同一个掩码，避免层间耦合导致的过拟合
4. **参数复杂度**：总可训练参数量为 $(2+G) \times (2md + m + d)$，其中$d$是Transformer隐藏维度，$m$是适配器瓶颈维度，相比每层一个独立适配器大幅压缩了参数量

# 6. 主要结论与发现
1. 低参数约束下SAPE实现了SOTA性能：自然语言理解任务中，SAPE仅使用proPETL 10%的参数预算，就在RoBERTa-large上超越proPETL；在约0.6M严格参数约束下，SAPE在LLaMA-3.2 3B上相比AdaLoRA，GSM8K绝对提升4.85%，CommonsenseQA绝对提升3.11%
2. 三明治拓扑设计的必要性得到验证：同时隔离输入输出边界层才能避免表征退化，全均匀共享会导致严重性能下降，仅隔离单个边界的效果也远低于三明治设计
3. 性能不随分组粒度单调提升：DeBERTa-v3-base上$G=2$为最优配置，仅用全不共享适配器1/3的参数量，就能达到全不共享方案99.4%的性能
4. 方法鲁棒性好：密度分配（额外层放前端还是后端）对性能影响极小，拓扑设计鲁棒；独立dropout掩码相比共享掩码能带来明显性能提升
5. 明确了固有容量权衡：硬参数共享对语义泛化有很强的正则化效果，能提升语义类任务性能，但会略微平滑刚性多步算术推理所需的层特异尖锐变换，因此在GSM8K这类任务上性能略低于全不共享的PEFT基线

# 7. 优点
1. 结构设计贴合Transformer层级特性：三明治隔离边界的设计既大幅降低了可训练参数量，又解决了均匀共享带来的梯度干扰、性能退化问题
2. 无额外计算开销：采用静态硬共享拓扑，不需要动态掩码、动态重要性排序等操作，训练收敛速度远快于AdaLoRA等动态PEFT方法
3. 参数效率更优：同等参数预算下，SAPE通过跨层共享保留了更大的适配器瓶颈容量，相比“缩小瓶颈降参”的传统方案性能提升明显
4. 实验系统严谨：多维度消融覆盖所有核心设计选择，明确了方法的适用场景与性能 trade-off，结论可复现性好

# 8. 不足与局限
1. 存在固有结构 trade-off：在多步算术推理这类需要层特异变换的刚性任务上，性能略低于全不共享的PEFT方案
2. 目前仅在适配器PEFT范式下验证，尚未扩展到LoRA等其他主流PEFT范式，通用性有待进一步验证
3. 仅在3B及以下规模的模型上验证，尚未在更大规模（如7B+）的大语言模型上测试效果，大模型上的泛化性待验证
4. 未量化测试推理阶段的延迟等效率指标，仅说明训练无额外开销，推理效率优势没有得到量化验证
