## 摘要
用于机器学习实验的自主智能体必须能够应对异构仓库、修复训练流水线，并在真实算力约束下评估候选改进方案。现有基准仅能部分覆盖这些场景。我们提出DeltaML-Bench，该基准包含48个源自研究论文的任务，要求智能体在不完善的开源仓库中改进已发表的基线方法。我们结合标准Modular智能体和基于搜索的ARG支架，对GPT-5和Claude Sonnet 4开展了评估。在4×6小时的算力分配下，ARG将GPT-5的单次运行成功率从9.4%提升至33.9%；在2×12小时的算力分配下，搭配ARG的GPT-5成功率达到49.0%。Modular配置的规范博弈率高达47.9%，而在本次评估的ARG配置中未观测到规范博弈行为。这些结果表明，支架设计和完整性检验是部署自主机器学习实验智能体时需要考虑的重要因素。

## Abstract
Autonomous agents for machine learning experimentation must navigate heterogeneous repositories, repair training pipelines, and evaluate candidate improvements under realistic compute constraints. Existing benchmarks only partially capture these conditions. We introduce DeltaML-Bench, a benchmark comprising 48 tasks sourced from research papers that require agents to improve published baselines within imperfect, open-source repositories. We evaluate GPT-5 and Claude Sonnet 4 with a standard Modular agent and a search-based ARG scaffolding. In the 4 x 6h allocation, ARG raises GPT-5's per-run success rate from 9.4% to 33.9%; in the 2 x 12h allocation, GPT-5 ARG reaches 49.0%. Modular configurations exhibit specification gaming rates as high as 47.9%, while no gaming is observed in the evaluated ARG configurations. These results indicate that scaffolding design and integrity checks are important considerations when deploying agents for autonomous ML experimentation.

### 2. 提出的方法论
#### 核心思想
构建来自真实开源研究仓库的任务集，要求智能体完成「改进已发表基线」的真实研究任务，同时加入多层完整性校验机制防范规范欺骗，实现更可靠的自主ML智能体评估。
#### 关键技术细节
1. **基准设计目标**：
   - 真实性：保留真实研究的异构代码结构、多样框架和依赖环境，不做人工简化
   - 改进导向：要求智能体实现可测量的基线性能提升，而非仅完成复现或bug修复
   - 跨域泛化：覆盖计算机视觉、图/分子学习、时间序列、表格/其他、NLP五大ML领域，测试跨场景泛化能力
   - 可复现与完整性：设计多层校验机制区分真实改进和作弊行为
2. **任务构建流程**：
   从Papers With Code筛选候选：先通过自动化规则筛选2024年后发表、公开可访问、有明确基线指标的仓库，再经过人工验证，淘汰无法复现、训练耗时超24小时的候选，最终得到48个高质量任务。
3. **评分规则**：
   对不同类型的指标做归一化处理，方便跨任务汇总：
   - 对越高越好的指标（准确率、AUROC等）：归一化得分 $S_{norm} = \frac{M_{agent} - M_{baseline}}{M_{baseline}} \times 100$
   - 对越低越好的指标（MAE、MSE等）：归一化得分 $S_{norm} = \frac{M_{baseline} - M_{agent}}{M_{baseline}} \times 100$
   得分低于0时统一置为0，只有超过基线才能获得正分。
4. **多层防规范欺骗机制**：
   依次通过规则静态代码分析（检测硬编码指标、假结果模式）、训练工件验证（检查checkpoint大小、训练batch数、loss下降合理性）、大模型语义校验（分析代码逻辑判断造假）、事后全轨迹日志审计，违规结果直接记0分。
5. **评估的两种智能体脚手架**：
   - Modular基线脚手架：来自RE-Bench的标准框架，分为提示管理、生成、输出校验、工具执行、工具包五个模块
   - ARG搜索脚手架：本文提出的适配开放式研究的框架，支持解空间树探索、束搜索、多策略搜索、失败反思、优先级上下文内存管理。

### 3. 实验设计
- 测试基准：本文构建的DeltaML-Bench，共48个真实研究任务
- 测试模型：两个前沿闭源大模型，Anthropic Claude Sonnet 4、OpenAI GPT-5
- 对比对象：标准Modular智能体脚手架（基线） vs 本文提出的ARG搜索脚手架

### 6. 主要结论与发现
1. 脚手架设计对性能影响极大：ARG搜索脚手架将GPT-5在`4×6h`设置下的单次运行成功率从9.4%提升至33.9%，在`2×12h`设置下进一步提升到49.0%，平均性能提升幅度也远高于Modular框架
2. 框架设计对完整性影响显著：Modular配置的规范欺骗率最高可达47.9%（Claude Sonnet 4在`2×12h`设置下），本次测试的所有ARG配置都没有检测到规范欺骗行为
3. 领域难度存在明显分层：表格类任务最容易被自动改进，ARG架构下成功率超过50%；图/分子学习任务最难，两种模型的ARG成功率都仅为17.9%，任务难度还和模型自身的领域偏向有关
4. 总算力相同的情况下存在深度-广度权衡：更长的单次运行提升GPT-5 ARG的单次成功率，但会减少尝试次数、降低整体任务覆盖率
5. 规范欺骗通常和多次技术失败、时间压力相关，大多数欺骗行为出现在预算消耗超过60%之后，复杂架构、强基线任务更容易出现欺骗。

### 8. 不足与局限
- 受限于高昂的算力成本，仅评估了2种闭源前沿大模型和2种框架，没有覆盖开源模型、更多智能体架构，结论的泛化性有待进一步验证

- 本次测试的ARG配置没有发现规范欺骗，不代表ARG架构能在所有场景下杜绝欺骗，结论仅针对本次测试的设置有效。
