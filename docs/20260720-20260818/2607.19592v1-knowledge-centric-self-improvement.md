## 摘要
自改进人工智能系统通常将智能体作为改进对象，通过优化提示词、工作流、工具集甚至智能体自身代码实现改进。这种以智能体为中心的视角会导致改进维护成本高昂，且难以迁移，因为性能增益与特定智能体设计、任务分布或适配运行过程绑定。本文研究一种互补范式：以知识为中心的自改进，该范式中智能体保持通用可替换，而持久化核心是经整理的知识库，可供智能体在未来任务中调用。我们通过简单协议将该思路可操作化，开展了对照案例研究。智能体尝试任务后，会通过任务级论坛和跨任务论坛向共享知识库贡献基于证据的洞见，随后进行知识蒸馏。由于自改进蕴含在知识而非智能体中，因此改进更具可检查性、可迁移性和可移植性。在抽象推理、编码和终端基准测试中，相比于以智能体为中心的基线方法，该协议提升了求解率，同时降低了金钱成本。所得蒸馏知识还可迁移到留出任务和不同大语言模型（LLM）家族之间，表明该改进并非仅针对特定LLM或特定运行的行为。这些结果支持了自改进智能体系统的新观点：进展可主要由经整理的持久化知识驱动。代码可在https://github.com/recursive-knowledge/KSI获取

## Abstract
Self-improving AI systems typically treat the agent as the object that improves, by optimizing prompts, workflows, harnesses, or even the agent's own code. This agent-centric view can make improvements expensive to maintain and difficult to transfer, because gains become tied to a particular agent design, task distribution, or adaptation run. We study a complementary paradigm: knowledge-centric self-improvement, in which agents remain generic and disposable while the persistent object is a curated knowledge base that agents can leverage for future tasks. We conduct controlled case studies to operationalize this idea via a simple protocol. Agents attempt one task, then contribute evidence-grounded insights to a shared knowledge base via task-level and cross-task forums, followed by knowledge distillation. Because self-improvement is contained in the knowledge rather than the agent, improvement can be more inspectable, transferable, and portable. Across abstract reasoning, coding, and terminal benchmarks, this protocol improves solve rates while reducing dollar cost relative to agent-centric baselines. The resulting distilled knowledge also transfers to held-out tasks and across LLM families, indicating that the improvement is not merely an LLM- or run-specific behavior. These results support a new view of self-improving agentic systems: progress can be driven primarily by the curated persistent knowledge.
