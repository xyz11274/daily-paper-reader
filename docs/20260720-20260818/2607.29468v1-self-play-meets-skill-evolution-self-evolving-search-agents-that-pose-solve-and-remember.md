## 摘要
自对弈智能体无需目标基准提供问题即可生成训练任务，但其训练课程缺乏持久状态：失败会影响梯度，却无法显式塑造未来的训练过程。外部技能记忆可以保留过程性经验，但通常从固定任务分布中学习得到。我们引入\textbf{SESA}（自演化技能增强智能体，Self-Evolving Skill-Augmented Agent），该方法将过程性记忆作为工具增强型搜索自对弈的演化状态。由挑战者生成问题，单独参数化的求解器独立完成技能检索。信息丰富的失败被蒸馏为可复用技能并写回记忆。更新后的记忆会改变求解器的行为与成功率，进而改变挑战者的奖励和未来问题的分布；由此产生的前沿会生成新的失败，进而重写记忆。这种双向循环使得任务生成与技能记忆共同演化。由于检索到的技能会塑造同策略训练轨迹，其收益既可以存入模型参数，也可以保留在外部存储库中，支持无记忆部署，也可选择在推理阶段进行检索。在七个开放域多跳问答基准测试中，SESA在多个骨干模型上的平均准确率相较SSP提升了1.2--3.2个百分点，在统一评估协议下比技能增强基线SkillRL高出0.9个百分点。在Qwen3模型上，SESA-Off相较SSP仍保留了1.8--2.2个百分点的准确率提升，最终技能库还可额外带来0.5--1.0个百分点的提升。这些结果表明，演化技能记忆不仅是推理阶段的插件：它还能改变策略学习与未来训练分布，同时保留作为可选外部记忆的价值。我们的代码可在https://github.com/Zenghuang-Fu/SESA-Self-Evolving-Search-Agents获取。

## Abstract
Self-play agents can generate training problems without questions from target benchmarks, but their curricula lack persistent state: failures affect gradients yet do not explicitly shape future practice. External skill memories preserve procedural experience but are typically learned from fixed task distributions. We introduce \textbf{SESA} (Self-Evolving Skill-Augmented Agent), which makes procedural memory an evolving state of tool-augmented search self-play. A challenger poses problems, while a separately parameterized solver alone retrieves skills. Informative failures are distilled into reusable skills and written back to memory. The updated memory changes solver behavior and success, which changes the challenger's reward and the distribution of future problems; the resulting frontier produces new failures that rewrite memory. This bidirectional loop makes task generation and skill memory co-evolve. Because retrieved skills shape on-policy training trajectories, their benefits can enter the model parameters as well as remain in the external bank, enabling memory-free deployment and optional inference-time retrieval. Across seven open-domain and multi-hop question-answering benchmarks, SESA improves average accuracy over SSP by 1.2--3.2 points across multiple backbones and surpasses the skill-augmented SkillRL baseline by 0.9 points under a unified evaluation protocol. On Qwen3 models, SESA-Off retains 1.8--2.2 points of improvement over SSP, while the final skill bank adds a further 0.5--1.0 points. These results show that evolving skill memory is not merely an inference-time plug-in: it changes policy learning and the future training distribution while retaining value as optional external memory. Our code is available at https://github.com/Zenghuang-Fu/SESA-Self-Evolving-Search-Agents.

## 1. 核心问题与研究背景
- 背景：当前大语言模型智能体越来越多地采用无人工标注的自对弈训练，可自适应生成训练任务、调整难度，但现有自对弈方法存在本质缺陷：训练中的失败经验仅用于更新梯度，没有被显式保留为可复用知识，无法持久塑造后续训练过程，相当于“会找训练题但学过就忘”。
- 互补方向：技能增强强化学习可以将过程性经验存储为外部可检索的技能记忆，但现有技能记忆方法大多基于固定任务分布或人工设计课程学习，无法适配自对弈动态变化的训练过程，相当于“会记经验但不会主动选合适的训练内容”。
- 核心问题：填补两个方向的缺陷，实现自生成任务分布与技能记忆的双向共同演化。

## 2. 提出的方法论
### 核心思想
提出**SESA（自演化技能增强智能体）**，构建“挑战者生成问题→求解器检索技能求解→有效失败蒸馏为可复用技能写回记忆→更新记忆改变求解器能力→挑战者生成更难的前沿问题”的双向循环，让任务生成和技能记忆持续共进化。

### 关键技术细节
1. **基础架构设计**：采用分离参数的不对称设计：挑战者负责生成搜索问题，仅求解器可访问技能库，避免技能泄露给挑战者，保证自对弈的有效性；技能库存储结构化技能，每个技能包含描述、触发条件、避坑提示、搜索查询模板、使用统计信息。
2. **四阶段训练循环**：
   - **记忆初始化**：用15个手写基础技能+142个自举预挖掘的去重技能构建初始技能库，提供初始检索基准。
   - **不对称自对弈训练**：基于GRPO（分组相对策略优化）做无评论员的策略梯度优化，求解器奖励为回答正确与否，技能直接参与训练轨迹，收益可内化到模型参数；挑战者看不到技能，仅通过求解器的反馈更新。
   - **前沿塑造**：为挑战者设计钟形奖励函数，惩罚全对（太简单）和全错（无法解决）的问题，仅鼓励生成刚好处于求解器当前能力边界的问题，保证收集的失败都是可学习的，避免噪声污染技能库。
   - **失败蒸馏与技能库维护**：仅保留前沿的有效失败，定期将失败抽象为新技能，通过相似度去重后加入技能库；自动淘汰无帮助的技能，控制技能库总大小不超过800条，实现自维护。
3. **双模式部署**：支持两种部署方式：SESA-Off（关闭技能库，仅依靠训练内化的参数能力，实现无记忆部署）、SESA-On（推理阶段也启用技能检索获得额外增益）。

## 3. 实验设计
### 数据集与评测基准
- 训练：采用SSP公开的5万带跳数约束的目标答案种子，不使用评测基准的训练问题，符合零数据自对弈设定。
- 评测：总共3125个留出样本，覆盖7个开放域/多跳问答基准：
  - 开放域事实检索：Natural Questions (NQ)、TriviaQA、PopQA
  - 多跳推理问答：HotpotQA、2WikiMulti-HopQA、MuSiQue、Bamboogle
### 对比方法
- 不同骨干模型的原生预训练/微调 checkpoint（Base）

- 覆盖多个模型家族：Qwen3系列（4B、4B-Instruct、8B）、Qwen2.5系列（7B-Base、7B-Instruct）、LLaMA-3.1-8B、搜索专用Search-R1-7B
