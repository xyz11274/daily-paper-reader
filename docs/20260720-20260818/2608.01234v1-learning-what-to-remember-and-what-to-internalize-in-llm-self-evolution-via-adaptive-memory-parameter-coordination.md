## 摘要
大语言模型智能体越来越多地运行于动态环境中，这类环境的工具接口、API以及用户需求会在部署后发生变化。现有自演化方法主要遵循两种范式：基于外挂框架的方法将反馈外置为可编辑的记忆或技能以实现快速适配，基于参数的方法将经验内化到模型参数中以实现更深层次的能力提升。然而，单独使用任意一种机制都会产生灵活性与性能之间的权衡。本文探究智能体如何协调两种学习通道以实现鲁棒的自演化。我们提出了COVE，这是一个统一的智能体自演化框架，通过任务感知路由、阶段感知调度和知识优化，结合了基于外挂框架与基于参数的两类学习方式。通过该设计，COVE不将自演化视为无差别的经验积累，而是将其看作一个将任务、知识类型匹配到对应学习机制的协同过程。在多类任务上的实验表明，COVE优于单通道演化策略，在变化环境下能够实现更鲁棒、更高效的提升。

## Abstract
Large language model agents increasingly operate in dynamic environments where tool interfaces, APIs, and user requirements change after deployment. Existing self-evolution methods mainly follow two paradigms: harness-based approaches, which externalize feedback into editable memories or skills for rapid adaptation, and parameter-based approaches, which internalize experience into model parameters for deeper capability improvement. However, using either mechanism alone creates a trade-off between flexibility and performance. This paper asks how an agent can coordinate both channels to achieve robust self-evolution. We present COVE, a unified agent self-evolution framework that combines harness-based and parameter-based learning through task-aware routing, stage-aware scheduling, and knowledge optimization. Through this design, COVE treats self-evolution not as indiscriminate accumulation of experience, but as a coordinated process that matches tasks and knowledge types to appropriate learning mechanisms. Experiments across multiple task categories show that COVE outperforms single-channel evolution strategies, demonstrating more robust and efficient improvement under changing environments.

# 论文详细总结

## 1. 核心问题与研究背景
- 背景：大语言模型智能体部署后需要运行在动态环境中，工具接口、API、用户需求会持续发生变化，要求智能体能够自主完成能力自演化，不需要人工反复重训或配置。
- 现有方案缺陷：当前自演化方法分为两类单范式，单独使用都存在难以调和的权衡：
  1. 基于外挂框架（harness-based）的方法：将经验存储在外部可编辑记忆中，适配快、灵活，但基础模型本身能力不足时，无法正确解读记忆中的反馈，性能上限低。
  2. 基于参数的方法：将经验直接内化到模型参数中，能够学习深层稳定能力，但训练成本高、适配慢，还容易把易变的表面知识（如API名称）内化，导致环境变化后性能暴跌。
- 核心问题：如何协调外部记忆和参数更新两个学习通道，实现动态环境下鲁棒高效的LLM自演化。

## 2. 提出的方法论
### 核心思想
不将自演化视为无差别的经验积累，而是针对不同任务特性、学习阶段、知识类型，自适应匹配最合适的学习存储机制，兼顾灵活性和性能，同时控制计算开销。提出统一框架**COVE (Channel Orchestrated Volatility-aware Evolution)**。

### 关键技术细节
COVE包含三个核心模块：
1. **任务感知路由**
   - 接收任务描述和执行反馈，调用LLM Judge对每个任务做通道分类，输出可解释的决策：
     - `harness_only`：失败来自易变的上下文知识，仅更新外部记忆，不做参数更新；
     - `parametric_candidate`：任务需要内化深层能力，适合参数学习；
     - `hybrid`：同时需要两种能力，激活双协同流程。
2. **阶段感知调度**
   - 不固定通道切换顺序，基于三个可测量信号动态触发参数更新，满足任意一个条件即激活：
     1. 性能 plateau：最近N个任务的性能提升低于阈值，说明harness演化已经到顶；
     2. 数据充足：积累了足够多的高质量任务轨迹，可以做参数训练；
     3. 冷启动失败：新任务家族前K个任务成功率远低于阈值，harness无法自举，需要先做参数更新获得基础能力。
   - 同时支持「先harness探索再参数内化」和「先参数打基础再harness演化」两种路径，适配不同场景。
3. **KnowledgePO双模态知识优化**
   实现两个通道的正向循环，避免各自的缺陷：
   - 外部记忆辅助参数训练：所有新增记忆条目都会被标记知识挥发性（易变/稳定/策略），反复修改的条目自动升级为易变；训练时对易变知识添加特殊标记，设计**反背诵惩罚**：训练中随机重命名易变知识中的表面名称，模型如果用了过期的 memorized 名称就会得到奖励惩罚，避免模型死记硬背易变知识，只让稳定的深层模式内化到参数。
   - 参数更新精简外部记忆：参数训练完成后，对稳定记忆做AB测试，如果移除某条记忆后性能下降低于阈值，说明该知识已经成功内化，将其从在线检索集合中释放，减少上下文开销和检索噪声；易变知识永远保留在外部，保持可编辑性。

### 优化目标
在最大化累计任务收益的同时，约束推理token成本和参数训练的计算开销，实现高效自演化。

## 6. 主要结论与发现
1. 协同双通道自演化的效果显著优于单通道方案，COVE在多类任务上性能均超过纯harness和纯参数基线，同时比无差别全参数更新减少了**86%的训练token开销**，效率提升明显。
2. 任务感知路由能够精准筛选需要参数更新的任务，仅消耗全双通方案16%的训练成本，就能保留大部分全双通的性能，效率远高于随机路由和全量双通方案。
3. 挥发性感知的反背诵机制有效提升了动态环境鲁棒性：API重命名后，传统参数自演化的API正确率从96.5%暴跌至54%，COVE仍能保持92.5%的正确率，解决了参数学习对环境变化的脆性问题。
4. 稳定知识内化后的记忆释放机制能够有效压缩外部记忆的大小，减少上下文开销，同时不会损失任务性能。

## 7. 方法与实验亮点
1. 问题定位精准：首次系统从任务特性、学习阶段、知识挥发性三个维度分析了两类自演化范式的互补缺陷，抓住了当前LLM在线自演化的核心痛点。
2. 设计贴合实际需求：反背诵惩罚解决了易变知识内化导致的脆性问题，记忆释放解决了外部记忆无限膨胀带来的上下文开销问题，两个设计都直击实际部署的痛点。
3. 实验设计严谨：覆盖多类任务，每个模块都做了针对性消融，验证逻辑清晰，结论可信。
4. 通用性强：框架是模块化设计，可以适配不同base LLM，也可以集成到各类现有自演化流程中，落地性好。

## 8. 不足与局限
1. 未测试长期大规模自演化的稳定性：没有验证在数万条以上任务累积、长期在线演化场景下，是否会出现记忆管理混乱、性能漂移等问题。
2. 路由决策存在额外开销：任务路由依赖大模型Judge做决策，会增加推理阶段的额外计算开销。
3. 模型规模泛化性未验证：所有实验都基于8B参数的中等规模模型，没有验证在更大规模（如70B）或更小端侧模型上的效果泛化性。
4. 缺乏真实在线部署验证：所有实验都基于离线标准数据集，没有在真实世界的长期动态在线部署场景中验证效果。
