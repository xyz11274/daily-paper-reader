## 摘要
训练基于大语言模型的搜索智能体需要高质量搜索数据：即要求真正多跳检索的任务，以及能够有效使用搜索工具的轨迹。现有训练流程通常依赖人工编写任务、专家示范或是能力更强的教师模型。我们提出SearchMaster，这是一个自博弈框架，可在本地搜索环境中基于单个大语言模型自行生成、求解并验证搜索任务，完成对该模型的训练。核心挑战在于，自生成任务和展开轨迹会产生误导性信号：伪多跳问题、忽略搜索深度的基于成功率的难度估计，以及存在过度打开文档却几乎没有针对性证据获取的轨迹。SearchMaster通过三种控制机制解决这些失效问题：证据链生成器（ECG）将任务生成锚定在显式跨文档证据链上，减少伪多跳问题；搜索深度奖励（SDR）基于成功轨迹的搜索深度而非仅成功率对任务难度评分，使保留的任务保持搜索密集性；过度打开惩罚（OOP）对工具使用进行规范，通过惩罚过度打开文档的行为，避免产生长而浅的浏览。随后使用GRPO对经过验证的提议者与求解器轨迹进行联合优化。在六个深度搜索基准测试上，SearchMaster将Qwen3.5-9B主干模型的平均准确率从38.19%提升至51.52%，在BrowseComp-Plus上取得了30.1个百分点的提升。这些结果表明，接地规范化自博弈无需人工标注问答对或专家示范即可为搜索智能体训练提供有效数据。代码已开放于https://github.com/WentaoTan/SearchMaster。

## Abstract
Training LLM-based search agents requires high-quality search data: tasks that demand genuine multi-hop retrieval and trajectories that use search tools effectively. Existing pipelines often depend on human-written tasks, expert demonstrations, or stronger teacher models. We present SearchMaster, a self-play framework that trains a single LLM from search tasks it generates, solves, and verifies in a local search environment. The key challenge is that self-generated tasks and rollouts can yield misleading signals: pseudo multi-hop questions, success-rate difficulty estimates that ignore search depth, and rollouts with excessive opening but little targeted evidence acquisition. SearchMaster addresses these failure modes with three controls. An Evidence-Chain Generator (ECG) grounds task generation in explicit cross-document evidence chains to reduce pseudo multi-hop questions. A Search-Depth Reward (SDR) scores task difficulty by the search depth of successful rollouts rather than success rate alone, keeping retained tasks search-intensive. An Over-Opening Penalty (OOP) regulates tool use by discouraging excessive document opening, avoiding long but shallow browsing. Verified Proposer and Solver rollouts are then jointly optimized with GRPO. Across six deep-search benchmarks, SearchMaster improves a Qwen3.5-9B backbone from 38.19% to 51.52% average accuracy, with a 30.1-point gain on BrowseComp-Plus. These results show that grounded and regulated self-play can provide effective search-agent training data without human-labeled QA pairs or expert demonstrations. The code is available at https://github.com/WentaoTan/SearchMaster.

# SearchMaster论文总结
## 1. 核心问题与研究背景
- 背景：基于大语言模型（LLM）的搜索代理依赖高质量训练数据，即要求真正多跳检索的任务、以及有效使用搜索工具的交互轨迹；现有训练方案大多依赖人工标注任务、专家演示或能力更强的教师模型，数据获取成本很高。
- 核心问题：自博弈方案虽然可以减少对外部标注数据的依赖，但自生成的任务和交互轨迹容易产生误导性训练信号，具体存在三类典型失效：
  1. 生成伪多跳问题：表面需要跨文档检索，实际单文档即可回答
  2. 任务难度估计偏差：传统用成功率衡量难度，忽略搜索深度，容易保留大量浅查找任务，无法维持训练信号的难度
  3. 工具使用漂移：模型逐渐过度依赖打开文档动作，产生大量长而浅的浏览轨迹，多数打开动作是冗余重复的，没有获取新证据
- 研究目标：构建规范化的自博弈框架，解决上述问题，实现无需人工标注的搜索代理自主训练。

## 2. 提出的方法论
### 核心思想
让同一个LLM共享参数，同时承担**任务提议者（Proposer）**和**任务求解者（Solver）**两个角色，在本地搜索环境中完成自生成、自求解、自验证的闭环训练，通过三个针对性机制解决上述三类失效，最终用GRPO算法完成联合优化。

### 关键技术细节
1. **整体自博弈流程**
   - 用共享的可训练策略同时做Proposer和Solver，用初始模型冻结充当固定Verifier；每一轮从本地文档集合采样种子文档，Proposer生成多个候选任务，经过质量过滤后，由Solver对合格任务生成多个解答轨迹，Verifier判断解答正确性，计算奖励后用GRPO更新共享策略，迭代推进。
2. **证据链生成器（ECG）**
   - 要求Proposer从种子文档出发，逐步沿着实体/事实链接跨文档构建显式证据链，最终基于完整证据链生成问题，强制要求问题必须结合整条链的信息、无法从单文档得到答案；生成后再加四层质量过滤：工具使用过滤、格式过滤、有效性过滤、参数知识过滤，从源头大幅减少伪多跳任务。
3. **搜索深度奖励（SDR）**
   - 替代传统基于成功率的难度估计，用所有正确解答轨迹中的最小搜索深度（即最少搜索次数就能答对的深度）衡量任务难度，最小深度越大奖励越高，达到目标深度后奖励饱和；鼓励Proposer生成真正需要多步搜索的任务，避免随着Solver能力提升，训练任务退化为浅查找任务。
4. **过度打开惩罚（OOP）**
   - 针对模型过度打开文档的行为漂移，惩罚打开动作数与搜索动作数的比值（而非惩罚总打开数），既抑制冗余重复的打开行为，又不会影响正常的多文档探索，平衡工具使用效率。
5. **优化策略**
   用GRPO对Proposer和Solver的合格轨迹做联合优化，每个种子仅保留最高奖励任务的Solver轨迹用于更新，避免Solver样本占比过高，平衡两类任务的梯度贡献。
