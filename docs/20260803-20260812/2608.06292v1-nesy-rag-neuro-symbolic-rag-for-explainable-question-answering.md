## 摘要
检索增强生成（RAG）通过将大语言模型（LLM）锚定在文本语料等外部知识上，提升问答性能。但其推理过程在很大程度上仍然不透明：中间推理步骤难以验证，也无法可靠归因到特定证据。此外，缺失的用户特定上下文很少得到系统性检测，往往会导致输出不完整或错误。我们提出NeSy-RAG，这是一种模块化神经符号RAG框架，可从检索得到的文本块合成可归因的Prolog模块。对于每个文本块，系统会生成编码布尔断言的具有语义意义的谓词，这些谓词可依赖于用户事实。利用联合自然语言-代码嵌入，谓词被检索并组合为Prolog查询。为解决用户上下文不完整的问题，我们引入了一种符号知识缺口检测机制，可识别出真值会影响查询结果的缺失用户事实，并自动触发后续交互。执行最终得到的Prolog查询可得到确定性答案，以及将每个推理步骤关联到其原始来源的透明执行轨迹。在ShARC基准测试中，无需领域特定训练，NeSy-RAG达到了61.1%的准确率，优于取得42.8%准确率的同模型RAG基线。

## Abstract
Retrieval-augmented generation (RAG) improves question answering by grounding large language models (LLMs) in external knowledge such as text corpora. However, its reasoning process remains largely opaque: intermediate reasoning steps are difficult to verify and cannot be reliably attributed to specific evidence. Moreover, missing user-specific context is rarely detected systematically, often leading to incomplete or incorrect output.   We propose NeSy-RAG, a modular neuro-symbolic RAG framework that synthesizes attributable Prolog modules from retrieved text chunks. For each chunk, the system generates semantically meaningful predicates that encode Boolean claims, which may depend on user facts. Using joint natural language-code embeddings, predicates are retrieved and composed into Prolog queries. To address incomplete user context, we introduce a symbolic knowledge-gap detection mechanism that identifies missing user facts whose truth values affect the query outcome and automatically triggers follow-up interactions.   Executing the resulting Prolog queries yields deterministic answers together with transparent execution traces that link each reasoning step to its originating source. On the ShARC benchmark, without domain-specific training, NeSy-RAG achieves 61.1% accuracy, outperforming a same-model RAG baseline that achieves 42.8% accuracy.

## 1. 核心问题与研究背景
- 背景：检索增强生成（RAG）是当前大语言模型领域问答任务的主流方案，通过引入外部知识锚定大模型输出，有效减少幻觉，提升问答准确性。
- 核心问题：
  1. 标准RAG推理过程不透明，中间推理步骤难以验证，也无法可靠归因到原始源证据，在医疗、法律等高风险领域难以满足可信任部署的要求。
  2. 现有神经符号结合的问答方法大多依赖人工定制规则、单体统一知识库，大多不支持推理步骤的来源归因，也无法系统性检测推理过程中缺失的用户特定上下文，容易生成不完整或错误的输出。
- 研究目标：构建兼具可解释性、可溯源性，能自动检测缺失用户信息的模块化神经符号RAG框架。

## 2. 提出的方法论
### 核心思想
将大语言模型的文本理解能力与Prolog符号推理的确定性、可解释性结合，从检索到的文本块生成模块化可归因的符号推理规则，实现透明可溯源的问答，同时通过符号机制自动识别缺失的用户信息，触发澄清交互。NeSy-RAG可作为插件扩展现有RAG系统，无需改动原有检索流程。

### 关键技术细节
1. **可归因模块化Prolog合成**：对每个检索到的文本块，单独调用大语言模型合成独立的Prolog模块，每个模块内的事实和规则都唯一对应原始文本块，推理过程的执行轨迹可以直接追踪到每个规则/事实的来源，实现细粒度可验证与可解释性，模块化设计也避免了维护大规模单体知识库的问题，支持扩展。
2. **0元谓词抽象**：为每个Prolog模块生成0元（无参数）布尔谓词，将模块的推理功能暴露为独立的语义单元，把查询构造转化为谓词选择与组合问题，避免了查询生成阶段需要加载整个知识库的开销，提升可扩展性。
3. **分层检索式查询构造**：采用两级检索：第一级是传统的文本块检索，第二级对检索到的模块内的0元谓词，用联合自然语言-代码嵌入计算与用户问题的相似度，取top相关的谓词交给大语言模型组合成最终Prolog查询，缩小搜索空间，减少大模型生成幻觉。
4. **符号知识缺口检测**：将Prolog事实分为两类：①通用事实：所有值都来自领域文本，无需用户输入；②动态事实：值需要用户提供（比如用户年龄是否达标）。Prolog执行推理时，如果遇到未赋值的动态事实，自动触发澄清提问；如果缺失信息的真值会影响最终查询结果，系统会输出`more`要求用户补充信息，系统性解决了缺失用户上下文的问题。
5. 推理完成后，将Prolog的确定性结果结合可溯源执行轨迹，转化为自然语言答案输出给用户。

## 3. 实验设计
- 数据集/场景：采用ShARC基准测试数据集，该数据集是基于英国政府官网法律文本构建的对话式可解释问答数据集，测试集包含8276个样本，要求系统主动识别缺失用户信息并发起澄清，最终输出`yes/no/irrelevant/more`四类结果。实验中为每个目标样本添加随机干扰snippet，模拟真实检索的噪声场景，用大语言模型模拟用户回答澄清问题，分离推理能力和用户交互的影响。
- 对比方法：
  1. LLM RAG基线：和NeSy-RAG设置完全对齐，仅替换符号推理为纯大语言推理，使用相同基础大模型。
  2. LLM Upper基线：给大模型提供完整的用户上下文，无需发起澄清，作为领域无关非训练方法的性能上界。
  3. 当前SOTA训练方法BiAE：作为任务训练方法的性能参照。

## 6. 主要结论与发现
1. 在ShARC基准上，NeSy-RAG（gpt-oss:20b，k=10）无需领域特定训练即可达到61.1%的准确率，显著优于同模型纯RAG基线的42.8%。
2. NeSy-RAG的推理效率更高，平均单样本处理时间仅7.4s，低于纯RAG基线的11.4s，受益于模块复用和小上下文窗口的分层检索设计。
3. 符号知识缺口检测机制效果显著，NeSy-RAG正确分类了61%的需要补充信息的`more`类样本，远高于纯RAG基线的19%，证明该机制能有效解决大模型无法主动识别缺失信息的问题。
4. NeSy-RAG的主要错误模式是动态谓词过生成，导致部分可回答样本被误判为需要补充信息，这种保守偏好比纯大模型的假确定性更适合高风险领域。

## 7. 方法与实验的亮点
1. 解决了标准RAG的核心痛点：实现了推理步骤到源文本的细粒度归因，推理过程透明可验证，适合高风险领域部署。
2. 创新性提出符号化的知识缺口检测机制，比纯LLM生成澄清问题更可靠，性能提升显著。
3. 模块化插件式设计，可兼容现有RAG系统，Prolog模块可复用，分层检索提升了可扩展性，支持大规模领域语料。
4. 无需领域特定训练，属于领域无关方法，部署成本低。

## 8. 不足与局限
1. 当前方法仅支持布尔类型问答，对非布尔问题、复杂数据类型的用户信息支持不足。
2. 存在动态谓词过生成的问题，会引发不必要的澄清提问，降低问答效率和准确率。
3. 实验仅在ShARC单数据集测试，未验证多跳推理、多文本块场景，也未在医疗等其他领域验证泛化性，未开展核心模块的消融实验。
4. 性能依赖初始检索的质量，初始检索错误会导致整个系统出错，大语言模型合成Prolog时仍存在2.2%左右的语法错误概率。
