## 摘要
参数高效微调（PEFT）可实现大语言模型的高效适配，但现有基于混合专家（MoE）的PEFT方法通常通过存储多个完整LoRA专家来提升容量，导致适配器存储量随专家数量线性增长，且将适配限制在固定专家池中。我们探究基于MoE的PEFT能否无需为每个专家显式存储单独的LoRA模块，即可生成实例特定的适配结果。为填补这一研究空白，我们提出MoEGen，这是一个将基于MoE的PEFT从专家选择转向专家条件参数生成的适配框架。MoEGen并未将每个专家存储为完整的LoRA适配器，而是将每个专家表示为一个小型可学习向量，称之为专家码。它将每个输入在这些向量上进行路由，并用它们的加权组合调节一个轻量级超网络，生成输入特定的低秩更新。这一设计将专家容量与适配器存储解耦，同时支持实例条件适配。在八个常识推理基准上的实验表明，在三个骨干模型上，MoEGen始终优于性能较强的静态PEFT基线和基于MoE的PEFT基线。MoEGen在医疗与法律领域的联合适配任务中也表现优异。

## Abstract
Parameter-efficient fine-tuning (PEFT) enables efficient adaptation of large language models, but existing MoE-based PEFT methods typically improve capacity by storing multiple full LoRA experts, causing adapter storage to grow linearly with the number of experts and restricting adaptation to a fixed expert pool. We ask whether MoE-based PEFT can produce instance-specific adaptations without explicitly storing a separate LoRA module for each expert. To address this gap, we propose MoEGen, an adaptation framework that shifts MoE-based PEFT from expert selection to expert-conditioned parameter generation. Instead of storing each expert as a full LoRA adapter, MoEGen represents each expert as a small learnable vector, termed an expert code. It routes each input over these vectors and uses their weighted combination to condition a lightweight hypernetwork that generates input-specific low-rank updates. This design decouples expert capacity from adapter storage while enabling instance-conditioned adaptation. Experiments on eight commonsense reasoning benchmarks show consistent improvements over strong static and MoE-based PEFT baselines across three backbones. MoEGen also performs strongly in joint medical and legal-domain adaptation.

# MoEGen论文详细总结
## 1. 核心问题与研究背景
- 背景：预训练大语言模型下游适配时，全参数微调的存储和计算成本极高，参数高效微调（PEFT）是当前主流方案，LoRA及其变种是PEFT中应用最广泛的方法之一；近年基于混合专家（MoE）的PEFT方法通过引入多专家扩展模型适配能力，但存在固有缺陷。
- 核心问题：现有基于MoE的PEFT方法需要为每个专家存储完整的LoRA适配器，导致适配器存储开销随专家数量线性增长，无法低成本扩展专家池，且仅能在固定专家池做选择组合，无法实现实例级的自适应适配。本研究的目标是：无需为每个专家显式存储单独的完整LoRA模块，即可生成实例特定的适配参数。

## 2. 提出的方法论
### 核心思想
将MoE基PEFT的范式从「专家选择」转变为「专家条件参数生成」，通过轻量专家表示+共享超网络生成实例专属LoRA参数，解耦专家容量和适配器存储开销，支持实例级自适应适配。
### 关键技术细节
整体框架由四部分组成： frozen预训练LLM、frozen提示编码器、稀疏MoE路由器、共享LoRA超网络，原LLM参数全程保持冻结不更新：
1. **轻量专家表示：专家码**：不存储每个专家的完整LoRA参数，将每个专家表示为一个低维可学习向量（称为专家码），所有LLM适配组件共享同一专家码池，新增专家仅增加少量参数。
2. **组件级语义路由**：用 frozen句子编码器对输入prompt生成语义上下文嵌入，结合每个适配组件的专属可学习嵌入生成组件特定的路由特征；随后计算所有专家码的路由得分，做Top-K稀疏选择，对选中专家做Softmax归一化得到权重，加权混合得到联合专家码。
3. **专家条件LoRA生成**：采用不对称设计：仅动态生成LoRA的A矩阵，B矩阵设为静态可训练参数，降低生成成本；共享超网络对每个适配组件的每个输入维度提供一个专属可学习坐标嵌入，超网络拼接坐标嵌入和选中的专家码，逐行生成LoRA A矩阵，超网络共享给所有组件、专家、输入维度；最终用混合后的专家码生成实例专属A矩阵，结合静态B矩阵得到低秩权重更新，施加到冻结的原LLM权重上。
4. **训练目标**：使用标准因果语言建模损失，额外添加负载均衡正则项防止路由塌陷，鼓励专家均衡使用，全程仅优化适配器相关参数。

## 6. 主要结论与发现
1. 常识推理任务：MoEGen在三种骨干上均取得最优性能，相比最强静态PEFT基线平均提升0.8~2.4个百分点，相比现有MoE基PEFT基线平均提升0.6~1.9个百分点，仅更新0.44%~0.52%的模型参数，性能甚至超过全参数微调；
2. 跨领域多任务联合适配：MoEGen在三种骨干上的平均性能比最强基线提升4.6~6.2个百分点，对长生成任务（如BillSum）提升尤为明显，解决了静态LoRA和现有MoE PEFT无法适配多异质任务需求的问题；
3. 模块验证：8个专家码+Top-2路由是最优配置，额外增加专家数量不会带来性能提升；额外引入的 frozen句子编码器能提供更干净的语义路由信号，仅带来不到3%的推理延迟开销；
4. 路由行为验证：MoEGen的路由器能够自动学习到任务相关的语义聚类，不同任务的路由表征自然分群，相似任务的表征聚集，符合设计预期。

## 7. 方法与实验的亮点
- 范式创新：将MoE PEFT从「存储多完整专家→选择组合」的旧范式，转变为「轻量专家码→条件生成实例专属LoRA」的新范式，从根本上解耦了专家容量和存储开销，扩展专家池的边际成本极低；
- 实例适配能力：能够为每个输入生成专属的LoRA更新，相比静态LoRA的固定更新，能更好适配不同输入的语义特征，尤其适合异质多任务场景；
- 参数效率高：在性能提升的同时，可训练参数比例不到总参数的1%，符合PEFT的设计目标；
- 实验设计完整，覆盖多种场景，结果可信度高。

## 8. 不足与局限
- 需要额外实现标准静态PEFT之外的路由和超网络生成模块，工程实现复杂度更高；
- 目前仅在监督微调场景下验证，尚未拓展到偏好微调、持续学习等其他常见适配场景；
- 短输出任务的推理 overhead相对更高，固定路由成本无法被摊销，相比LoRA有一定程度的延迟提升；
- 未验证更大专家池在更多异质任务场景下的扩展性。
