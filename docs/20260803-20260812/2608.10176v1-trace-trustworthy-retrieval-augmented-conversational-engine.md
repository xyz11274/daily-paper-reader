## 摘要
公共服务聊天机器人需要基于底层公共服务目录给出推荐，同时需确保推荐满足用户明确提出的约束条件。实际应用中，公共服务目录存在噪声且不一致，通用大语言模型（LLM）或基于人工智能的聊天机器人常常生成不可靠的推荐，还会引用网络上未经验证的来源。本文针对构建在含噪声的异构服务目录之上的公共服务对话系统，研究了检索质量对感知约束推荐任务的影响。我们提出了TRACE（可信检索增强对话引擎，Trustworthy Retrieval-Augmented Conversational Engine），这是一个基于检索的感知约束框架，借助双重数据表示模式，将用户输入查询解析为结构约束与语义约束，以供下游检索使用。我们利用一个经过整理的全州食品储藏室目录和一个合成查询基准，评估了多种引入知识图谱（KGs）与不引入知识图谱的知识表示变体。我们在多个开源大语言模型和一个专有模型上开展实验，结果表明，增强检索能力可大幅提升用户约束满足度，同时减少幻觉推荐。在我们的实验中，随着检索质量提升，不同大语言模型之间的性能差异缩小，使得结果对模型大小的敏感度降低。这些发现表明，检索质量是构建鲁棒公共服务对话系统的关键。

## Abstract
Public service chatbots are expected to deliver recommendations from an underlying public service directory, while also making sure that the recommendations respect explicit user constraints. In practice, public service directories are noisy and inconsistent, and general-purpose large language model (LLM) or AI-based chatbots frequently generate unreliable recommendations, citing unverified sources from the web. We investigate the impact of retrieval quality on constraint-aware recommendation in public service conversational systems built over noisy and heterogeneous service directories. We propose TRACE (Trustworthy Retrieval-Augmented Conversational Engine), a retrieval-based, constraint-aware framework that parses input user queries into structural and semantic constraints for downstream retrieval, with the help of a dual data representation schema. Using a curated statewide pantry directory and a synthetic query benchmark, we evaluate multiple knowledge-representation variants with and without knowledge graphs (KGs). We experiment with several open-source LLMs and a proprietary model, showing that strengthening retrieval substantially improves user constraint satisfaction while reducing hallucinated recommendations. Performance differences across LLMs narrowed in our experiments as retrieval quality improved, making results less sensitive to model size. These findings suggest that the quality of retrieval is key for robust public service conversational systems.

  3. 这类错误在公共服务/社区帮扶场景成本极高，会直接降低用户信任和工具效用。

## 2. 论文提出的方法论
### 核心思想
公共服务推荐场景中，生成质量主要由检索质量决定：只要检索能提前得到满足用户约束的候选服务，LLM仅需要基于检索证据整合输出，不需要凭空生成推荐，就能大幅降低幻觉。
### 框架流程（TRACE：可信检索增强对话引擎）
1. **约束解析**：将用户查询拆分为两类约束：
   - 结构约束：需要严格匹配的属性（如城市、县、邮编），采用严格的AND逻辑筛选；若用户查询未提供结构约束，系统主动发起澄清提问获取；
   - 语义约束：自然语言表述的要求（如“需要带ID”），需要基于候选服务的非结构化文本做语义验证。
2. **双知识表示**：对公共服务目录做双重表示：
   - 知识图谱（结构视图）：将服务提供者关联到位置、营业时间等结构化实体，支持结构约束的快速筛选，本文设计了多种KG变体做消融验证；
   - 向量嵌入（语义视图）：对非结构化文本（如资格要求）做嵌入，支持语义约束匹配。
3. **两阶段检索与约束校验**：
   - 阶段1（结构筛选）：基于结构约束查询知识图谱，获取top-k候选服务集合；
   - 阶段2（语义过滤）：在获取的候选集合中，基于语义约束做匹配筛选；若当前top-k没有满足约束的候选，就拉取下一批top-k重复校验，直到得到符合要求的候选后再交给LLM生成最终回复。

## 3. 实验设计
### 数据集与场景
- 真实服务目录：采用美国堪萨斯州经过整理的全州食品救济站目录，包含约800个服务站点，既有结构化字段（名称、地址、位置、电话、营业时间）也有非结构化字段（资格要求）；该目录被设定为唯一权威来源，不在目录中的推荐记为幻觉；框架可扩展到诊所、收容所等其他公共服务场景。
### 基准测试集
构建了1000条带真值标注的合成查询基准，分为5类：仅位置查询、资格查询、营业时间查询、特定名称查询、多约束组合查询，所有查询的真值都基于权威目录生成。
### 对比消融设计
- 知识表示消融：对比4种KG设置：①KG-0：无KG基线（纯文本索引）；②KG-1：仅位置建模的KG；③KG-2：仅营业时间建模的KG；④KG-3：同时包含位置+营业时间建模的KG。
- 模型对比：测试了15个不同参数规模的开源指令微调LLM（覆盖Qwen、Llama、Gemma、Phi、DeepSeek R1 Distill等主流模型，分为小模型≤3B、中模型4-8B、大模型>8B三组），外加1个专有模型GPT-5.5作为强基线。
### 评估指标
包含四类：检索质量（Precision@k、Recall@k、F1@k）、约束满足度（所有显式约束都被满足的查询占比）、幻觉率（回复包含目录外推荐的查询占比）、语义相似度（生成回复和真值回复的余弦相似度）。

## 6. 主要结论与发现
1. 结合位置和营业时间的结构化知识图谱，相比纯文本无KG基线能大幅提升检索质量：最优设置KG-3的P@3达到0.87，R@3达到0.91，远高于无KG基线的0.38和0.40。
2. 检索质量提升会显著改善端到端可靠性：平均所有模型，约束满足度从无KG的64.15%提升到KG-3的88.48%，幻觉率从10.54%下降到2.12%，生成回复和真值的语义相似度从0.67提升到0.77。
3. 检索质量提升会大幅缩小不同LLM之间的性能差距：检索质量越好，不同参数规模、不同家族模型的性能方差越小，小模型也能获得接近大模型的性能，系统整体性能对模型大小的敏感度显著降低。
4. 核心结论：检索质量是公共服务对话系统鲁棒性的核心瓶颈，提升检索质量比提升LLM能力对系统可靠性的贡献更大。

## 8. 不足与局限
