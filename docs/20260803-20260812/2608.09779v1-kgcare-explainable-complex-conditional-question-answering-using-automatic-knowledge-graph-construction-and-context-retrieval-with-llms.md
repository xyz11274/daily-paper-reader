## 摘要
利用大语言模型（LLMs）和检索增强生成（RAG）回答复杂条件问题目前仍是一项挑战，尤其是在通用大语言模型与RAG通常表现不佳的特定领域场景中。我们提出假设：为RAG增广从文档和知识图谱（KGs）中提取的非结构化与结构化知识，可提升此类任务的推理能力与回答准确率。为验证该假设，我们提出KGCaRe，这是一种将神经检索与大语言模型生成知识图谱上的符号推理相结合的混合方法。KGCaRe采用多提示抽取策略从文档中构建知识图谱，并将其存储在图数据库中；同时将文档嵌入到向量存储中以支持神经检索。KGCaRe执行由大语言模型引导的创新迭代图遍历，提取相关三元组、剪枝无关信息，若初始遍历未提供足以生成答案的满意上下文，则利用额外线索实体再次遍历图。随后，从知识图谱中以路径形式提取的相关三元组，与语义检索得到的文本片段一同输入定制的KGCaRe提示，生成复杂条件问题的答案与解释。我们在两个复杂条件问答数据集上评估了KGCaRe。实验结果表明，在Mistral、Mixtral、GPT-3.5、GPT-4o等多款大语言模型上，KGCaRe始终优于现有基准方法，包括原生大语言模型、代码提示、文本提示、Think-on-Graph、原生RAG以及HybridContextQA。我们公开发布了实现所提KGCaRe方法的软件管线。

## Abstract
Answering complex conditional questions using Large Language Models (LLMs) and Retrieval-Augmented Generation (RAG) remains a challenge, particularly in domain-specific contexts where general-purpose LLMs and RAG tend to underperform. We hypothesize that augmenting RAG with unstructured and structured knowledge, extracted from both documents and knowledge graphs (KGs), can improve reasoning and answer accuracy for such tasks.   To test this, we propose KGCaRe, a hybrid approach that combines neural retrieval with symbolic reasoning over LLM-generated KGs. KGCaRe constructs a KG from documents using a multi-prompt extraction strategy and stores it in a graph database. Simultaneously, the documents are embedded into a vector store to enable neural retrieval. KGCaRe performs innovative iterative graph traversal guided by the LLM to extract relevant triples, prune irrelevant information, and uses additional clue entities to traverse the graph again if the initial traversal does not provide satisfactory context to generate the answer. The relevant triples extracted from the KG in path form, along with semantically retrieved text passages, are then fed into custom KGCaRe prompts to generate answers to the complex conditional questions with explanations.   We evaluate KGCaRe on two complex conditional QA datasets. Our results on these datasets show that KGCaRe consistently outperforms existing baselines, including Vanilla LLM, Code Prompt, Text Prompt, Think-on-Graph, Vanilla RAG, and HybridContextQA, across multiple LLMs such as Mistral, Mixtral, GPT-3.5, and GPT-4o. We publicly release the software pipeline that we developed to implement the proposed KGCaRe approach.

# 论文详细总结
## 1. 核心问题与研究背景
- 当前通用大语言模型（LLM）和标准检索增强生成（RAG）在回答领域特定的复杂条件问题时性能不佳：通用LLM缺乏领域专业知识，缺少足够上下文时容易产生幻觉，而条件问题对隐含约束高度敏感，要求多跳推理才能整合分散在文档不同位置的信息。
- 现有方法存在明显缺陷：纯提示方法没有引入结构化知识，无法有效梳理条件逻辑；纯知识图谱（KG）方法依赖KG的稠密连接，在从文档自动构建的稀疏KG上效果很差；纯RAG方法依赖相似度搜索，难以捕捉逻辑依赖与条件约束；现有混合方法仅对KG做简单关键词搜索，没有充分利用KG的结构信息做推理。
- 核心研究假设：为RAG增广从文档提取的非结构化知识和从KG提取的结构化知识，能够提升复杂条件问答的推理能力和答案准确率。

## 2. 提出的方法论
### 核心思想
KGCaRe是一种混合推理框架，结合LLM生成KG上的符号推理和原始文档的神经语义检索，同时发挥结构化知识的逻辑准确性和非结构化文本的语义覆盖优势，生成准确且可解释的复杂条件问题答案。

### 关键技术流程
1. **多提示三元抽取与KG构建（四阶段流程）**：
   - 阶段1：深度分析输入文本，抽取初始实体与关系三元组，侧重捕捉时间、因果、程序、条件等逻辑结构
   - 阶段2：专门扩展条件、例外、替代场景，补充if-then分支逻辑对应的三元组，解决条件信息遗漏问题
   - 阶段3：精炼整合已有三元组，基于传递逻辑推理补全隐含三元组，提升整个KG的逻辑一致性
   - 阶段4：标准化三元组格式，导入Neo4j图数据库存储
2. **并行语义向量索引**：同步将原始文档嵌入为向量存储在FAISS向量库，支持基于问题的语义相似性检索，补充KG未覆盖的上下文信息
3. **LLM引导的迭代KG遍历**：
   - 从输入问题提取主题实体作为遍历起点，初始化存储三元组、线索实体、遍历路径的记忆模块
   - 按设定最大深度迭代遍历：第一层深度采用部分匹配扩大搜索范围，深层采用精确匹配聚焦推理；同时并行搜索线索实体关联的三元组
   - 每轮遍历后用LLM剪枝无关三元组，再由LLM判断当前累积知识是否足够回答问题：足够则终止遍历，不足则提取新的线索实体进入下一轮遍历；达到最大深度或无新实体可扩展则终止
4. **融合上下文生成带解释的答案**：将KG遍历得到的三元组路径，与向量检索得到的相关文本片段整合，输入定制prompt生成答案，要求模型明确说明答案成立的条件，同时保留完整的KG遍历轨迹作为可追溯解释。

## 3. 实验设计
- **数据集**：两个公开复杂问答基准：
  1. `ConditionalQA`：源自英国公共政策文档，专门针对条件问答，官方测试集未公开，本文使用开发集的271个有效样本，包含Yes/No、抽取式Span、条件回答三类问题
  2. `HotpotQA`：源自维基百科，要求多跳推理，本文从官方开发集分层随机抽样500个样本，包含Yes/No、抽取式Span两类问题
- **评价指标**：采用标准精确匹配（exact match）计算F1分数，报告所有问题的平均F1，以及不同类型问题的分类F1
- **对比基线**：共6类现有方法：Vanilla LLM（原生大模型）、Code Prompt（代码提示）、Text Prompt（文本提示）、Think-on-Graph（纯KG推理方法）、Vanilla RAG（标准检索增强生成）、HybridContextQA（现有混合方法）
- **测试模型**：覆盖4款不同类型的LLM：开源的Mistral-7B、Mixtral-8x7B，闭源的GPT-3.5、GPT-4o
- 额外设置了针对单确定答案Yes/No问题子集的分组验证实验。

## 6. 主要结论与发现
1. 在两个数据集的所有测试LLM上，KGCaRe的平均F1分数始终高于所有对比基线，在条件类和Yes/No类需要多跳推理的问题上提升幅度最为明显。
2. 融合符号KG推理和神经语义检索的混合策略，性能显著优于纯KG、纯提示、纯RAG方法，哪怕是能力最强的GPT-4o，也能通过KGCaRe获得进一步的性能提升。

## 7. 方法与实验亮点
- 设计了四阶段多提示KG自动构建流程，能够有效捕捉文档中的条件逻辑和隐含依赖，比单次抽取的KG质量更高。
- 提出LLM引导的迭代线索扩展遍历机制，能够解决稀疏KG的推理问题，比静态KG检索更灵活。
- 充分结合了结构化知识和非结构化知识的互补优势：KG提供准确的符号推理，向量检索补充KG未覆盖的语义上下文。
- 实验覆盖全面，结论鲁棒，并且完整公开了整个软件管线、构建好的KG和提示模板，可复现性强。
