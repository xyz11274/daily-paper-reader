## 摘要
智能体框架（agent harness）已成为现代大语言模型智能体的运行基础设施，负责协调上下文、工具、验证与执行控制，将潜在模型能力转化为可靠的长时程行为。然而，可靠的长时程行为要求框架控制能够适应任务需求、执行环境及动态演化的执行状态，而当前主流框架主要依赖手工设计或全局固定的策略；这种不匹配会造成不必要的计算开销，并在不利情况下降低任务成功率。为解决这一局限，我们将智能体系统中实现自适应编排的任务形式化为一个因果学习问题，并提出面向长时程智能体的反事实框架干预学习（CHILL-Harness）。CHILL-Harness在编排层进行干预，以实现优势引导的工作流自适应调整，从而在保持任务性能的同时提升推理与执行效率。具体而言，我们开发了因果干预效应学习（作为CHILL-Harness的效应估计组件），基于置信度加权的执行证据估计与干预相关的工作流优势，并识别有利的工作流调整。我们进一步引入优势实现型因果编排（作为其实现组件），来自适应分配反事实推理，并仅执行具有充分预期优势支持的工作流调整。最后，我们将成功保持目标与优势边际授权约束纳入CHILL-Harness，以促进可靠的自适应。在涵盖信息检索、软件工程和终端交互的异构长时程任务上的大量实验表明，CHILL-Harness在显著降低令牌消耗和执行时间的同时，持续保持或提升任务成功率。

## Abstract
Agent harnesses have become the operational infrastructure of modern large language model agents, coordinating context, tools, verification, and execution control to translate latent model capability into reliable long-horizon behavior. However, reliable long-horizon behavior requires harness control to adapt to task demands, execution environments, and evolving execution states, whereas current harnesses predominantly rely on hand-crafted or globally fixed policies; this mismatch manifests as unnecessary computational overhead and, in adverse cases, reduced task success. To address this limitation, we formulate the task of enabling adaptive orchestration in harness systems as a causal learning problem and propose Counterfactual Harness Intervention Learning for Long-Horizon Agents (CHILL-Harness). CHILL-Harness intervenes at the orchestration layer to enable advantage-guided workflow adaptation, thereby improving reasoning and execution efficiency while preserving task performance. Specifically, we develop causal intervention effect learning as the effect-estimation component of CHILL-Harness to estimate intervention-relative workflow advantage from confidence-weighted execution evidence and identify advantageous workflow adaptations. We further introduce advantage-realizing causal orchestration as its realization component to adaptively allocate counterfactual reasoning and realize only workflow adjustments supported by sufficient expected advantage. Finally, we incorporate a success-preserving objective and advantage-margin authorization constraints into CHILL-Harness to promote reliable adaptation. Extensive experiments on heterogeneous long-horizon tasks spanning information seeking, software engineering, and terminal interaction show that CHILL-Harness consistently preserves or improves task success while substantially reducing token consumption and execution time.

## 1. 核心问题与整体含义

- **研究动机**：大语言模型智能体在长时程任务中需要持续管理上下文、调用外部工具、进行中间验证、失败恢复和执行控制，这些功能由“智能体框架（harness）”统一协调。然而，现有的大多数框架要么依赖手工编写的规则，要么采用全局固定策略，无法根据任务需求、执行环境和动态变化的执行状态进行调整。
- **核心矛盾**：可靠的长时程行为需要框架控制能够“随环境自适应”，而当前框架的固定策略会导致冗余推理、延迟纠错、不必要的流程中断，进而增加计算开销甚至降低任务成功率。
- **关键问题（Causal Harness Orchestration Problem）**：如何让框架利用因果干预来判断“某个具体的工作流调整在当前上下文中是否真正有助于改善执行”，并将这种判断转化为既高效又保持任务成功率的编排决策。
- **核心思想**：将自适应编排建模为因果学习问题——当前工作流作为事实参考（factual reference），可执行的替代方案作为相同上下文下的反事实干预（counterfactual interventions）。通过估计干预效应，只授权有足够优势的工作流变更，从而在保持成功率的同时提升效率。

## 2. 方法论：核心思想与技术细节

### 总体框架
CHILL-Harness 由两个耦合组件构成：
- **CIEL（Causal Intervention Effect Learning，因果干预效应学习）**：负责估计干预效应，回答“哪种工作流调整是有益的”；
- **ARCO（Advantage-Realizing Causal Orchestration，优势实现型因果编排）**：负责执行授权，回答“估计到的优势是否足以支持替换当前工作流”。

### CIEL 的技术细节
- **统一因果干预归纳**：将常见框架行为抽象为统一干预空间：
  - `Keep`：保持当前工作流；
  - `Deliberate`：追加推理；
  - `Revise(r)`：r ∈ {Inspect, Verify, Visual}，表示获取证据、验证结果或视觉检查；
  - `Stabilize(q)`：q ∈ {Dedup, NoOpRecovery}，表示去重或恢复无效执行；
  - `AnswerSynthesis`：转向答案构造（非终止）。
- 每个干预通过实现映射 G_t(ι) 对应到具体的可执行工作流集合，且遵循“工作流中介假设”——干预只通过实际执行的工作流影响结果。
- **工作流效应估计**：定义反事实效应 Γ_t(ω) = E[U_t | do(W_t=ω), χ_t] − E[U_t | do(W_t=ω₀), χ_t]，其中 ω₀ 是当前事实工作流，效应为零。CIEL 学习估计器 bΓ_φ 来逼近真实效应，并用保守平局规则在无正效应估计时选择 Keep。
- **干预偏好归纳与摊销预测**：离线根据估计效应选出最优干预族 ι*，再用一个在线预测器 p_θu 摊销该偏好，从而避免在线重复估计。
- **因子化干预决策学习**：
  - **CDE（反事实深思效应）**：预测深思路线 z_t ∈ {Skip, Light, Full}，控制额外推理计算量；
  - **CRE（反事实修订效应）**：预测是否应该用候选工作流替换当前工作流（Keep/Change）；
  - **CAE（完成归因效应）**：预测当前证据是否支持任务完成（0/1），且必须与显式验证器共同决定终止。
- **损失函数**：总目标 L_CIEL = L_eff + L_int + L_CDE + L_CRE + L_CAE。其中 L_eff 使用离线成对回放数据（checkpointed paired executions）监督效应估计；L_int 监督干预偏好；后三项用轨迹级弱监督训练。
- **理论保证**：推导出干预选择遗憾上界 V_int(ι†) − V_int(ι̂) ≤ 2ε_t + ρ_t，其中 ε_t 是效应估计误差，ρ_t 是摊销差距；进一步结合 Hoeffding 不等式给出成对回放误差的有限样本界。

### ARCO 的技术细节
- **路线先于生成（route-before-generation）**：先用 CDE 预测深思路线，再决定是否生成候选工作流。Skip 直接保留事实工作流；Light 只做受限诊断；Full 才进行完整候选生成和评估。
- **可行性与过滤**：考虑规划预算、全路线冷却、工具可用性等约束，得到可行路线集合；候选生成后经过安全评分、模式验证、任务兼容性和预算检查，形成可接受集合 Ω_t = Ω_t ∩ A_t。
- **因果-操作联合估值**：对每个候选工作流计算 bU_ARCO = bU_op + η_Γ bΓ_φ，其中 bU_op 综合了进度、成本、风险、信息增益、鲁棒性和安全度。
- **优势边际授权**：选择最高估值候选 ω⁺，若 CRE 支持替换且估计优势 Δ_cf 超过干预相关阈值 δ，则执行该候选；否则保留原工作流。
- **证据型完成判定**：终止必须同时满足 CAE 预测 b_b=1 和显式任务验证器 e_comp=1，防止凭“无能为力”或预算耗尽而误终止。

### 成功保持目标与约束
- 全局优化目标：最小化轨迹资源成本，同时满足 PassRate(CHILL) ≥ PassRate(ref) − ε_pass。
- 轨迹级损失：L_traj = J_eff + λ_fail(1−Y) + λ_break·I[参考成功但当前失败]，明确惩罚“破坏成功”的适应行为。

- 同时每个 CHILL-Harness 运行都配有使用相同模型、工具、环境和资源限制的参考运行，用于控制变量比较。

### 模型配置
- GAIA 使用 deepseek-v4-flash；
- SWE-bench Verified 和 Terminal-Bench 2.0 使用 deepseek-v4-pro；
- 所有模型调用温度 1.0，最多 150 轮交互；
- CIEL 在不相交的轨迹上离线训练，评估时冻结。

### 评估指标
- 成功率（Success=% 解决任务比例）；
- Token 消耗总量、每解决任务 Token 数（Tokens/Solved）；

### 主要实验结果
- **RQ1 有效性**：CHILL-Harness 在 GAIA 上成功率 71.3%（最高），SWE-bench Verified 上 65.6%（最高），Terminal-Bench 2.0 上 56.1%（超过 Terminus-KIRA 和 Meta-Harness，略低于 LemonHarness 的 57.4%）。
- **RQ2 效率**：相对于最低 token 基线，token 消耗分别减少 28.4%（GAIA）、13.1%（SWE-bench）、23.1%（Terminal-Bench）；相对于最快基线，运行时间减少 46.6%、25.9%、2.6%。
- **RQ3 泛化**：在 GAIA 和 SWE-bench 上同时提升成功率和 token 效率；在 Terminal-Bench 上取得最高 token 效率，与 LemonHarness 构成效率-有效性前沿。

### 消融实验
- 设置 **Always-Full** 变体：强制 z_t = Full（保留其他组件），对比 CDE 和 route-before-generation 的贡献。
- 结果：GAIA 成功率从 71.3% 降至 27.7%，token 升至 114.33M；SWE-bench 成功率降至 53.3%，token 升至 160.40M；Terminal-Bench 成功率基本持平但 token 升至 259.77M，且产生大量额外规划开销。消融表明选择性反事实深思是必要的。

## 6. 主要结论与发现

- CHILL-Harness 能够通过因果干预效应学习识别“保持或提升任务成功率”的工作流调整，并通过优势实现型编排显著降低 token 消耗和运行时间。
- 反事实深思路线的自适应选择（Skip/Light/Full）是效率提升的关键：强制全量深思会导致过度干预、成功率下降或规划开销增加。
- 成功保持目标与双重完成验证可以有效避免“为省 token 而牺牲成功率”或“过早终止”。
- 该方法在信息检索、软件工程和终端交互三类异构环境下均表现出有效性，说明其具备跨场景泛化潜力。

## 7. 优点

- **新颖的问题形式化**：将 harness 自适应编排首次系统性地建模为因果学习问题（事实 vs. 反事实工作流），理论框架清晰，与 potential-outcome 框架自然衔接。
- **模块化设计**：效应估计（CIEL）与实现编排（ARCO）分离，分别处理“做什么”和“是否做”，便于独立改进与替换。
- **安全性考量**：设计了成功保持目标、优势边际授权、显式任务验证器、安全过滤、禁止重复/无效工作流等多层保护，使效率优化不会无约束地损害任务成功。
- **理论支持**：给出了干预选择遗憾的上界和成对回放的有限样本浓度界，为方法提供了理论依据。
- **实验场景丰富**：覆盖三个不同性质的长时程任务基准，展示了方法的泛化性。
- **透明日志记录**：设计了完整的推断记录结构（包括干预预测、路线选择、候选评估、拒绝原因等），有助于可审计性和后续分析。

## 8. 不足与局限

- **缺乏消融深度**：只对 CDE 做了 Always-Full 消融，未对 CRE、CAE、授权阈值 δ、效应权重 η_Γ、置信权重 w 等关键超参数进行敏感性分析。
- **统计验证不足**：没有多种子运行的标准差、置信区间或显著性检验，无法判断结果差异是否稳定。
- **资源信息缺失**：未披露训练 CIEL 效应估计器所需的 GPU 数量、训练时长和具体硬件配置，影响复现性。
- **外部对比公平性存疑**：不同基线的模型和工具配置不完全一致，所谓“token/时间增益”在不同模型下可能不完全可比，依赖匹配参考运行来补偿但匹配细节未充分展开。
- **理论假设较强**：依赖工作流中介假设、状态充分回放假设等，真实环境中可能不完全成立；且仅在 GAIA/SWE-bench/Terminal-Bench 上验证，未覆盖多模态、分布式或多智能体等更复杂场景。
- **应用限制**：需要离线成对回放数据来训练效应估计器，这本身成本较高；在无法构造可靠检查点的环境中，CIEL 的训练会受限。
- **优化范围有限**：ARCO 只保证在“路线暴露且可接受的候选集”内最优，不是全局工作流空间最优；实际收益受候选生成质量约束。
