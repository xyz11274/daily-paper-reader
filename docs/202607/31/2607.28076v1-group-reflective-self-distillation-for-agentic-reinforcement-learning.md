## 摘要
基于可验证奖励的强化学习（RLVR）能有效训练大型语言模型智能体。然而，终端奖励仅提供粗粒度的轨迹级监督，使得成功行为、重复错误与偶然选择纠缠于同一结果信号中。现有的智能体自蒸馏方法用自然语言技能来丰富稀疏监督，但这些技能若从外部检索或由更强模型从单条轨迹中提取，可能不符合当前经验、超出策略能力或仅适用于特定路径。我们提出群体反思自蒸馏（GRSD），该方法从策略自身的已验证 rollout 中推导出与能力对齐且具有结果区分度的指导。对于每个提示，策略在同策略群体中对每条已验证轨迹进行反思，并通过停止梯度的快照对比成功与失败 rollout 的反思结果，以构建群体层面的特权指导。在此指导条件下，自我教师通过调节基于结果的优势来细化轮次级信用分配，同时保持验证器确定的学习方向。在多个智能体环境和模型规模上的实验表明，GRSD 一贯优于竞争性基线，并在未见任务上具有更强的泛化能力。

## Abstract
Reinforcement learning with verifiable rewards (RLVR) is effective for training large language model agents. However, terminal rewards provide only coarse trajectory-level supervision, leaving successful behaviors, recurring mistakes, and incidental choices entangled in the same outcome signal. Existing agentic self-distillation methods enrich sparse supervision with natural-language skills, but skills retrieved externally or extracted from a single trajectory by stronger models may mismatch current experience, exceed the policy's capability, or remain path-specific. We propose Group-Reflective Self-Distillation (GRSD), which derives capability-aligned and outcome-discriminative guidance from the policy's own verified rollouts. For each prompt, the policy reflects on each verified trajectory in an on-policy group, and a stop-gradient snapshot contrasts the resulting reflections from successful and failed rollouts to construct group-level privileged guidance. Conditioned on this guidance, a self-teacher refines turn-level credit assignment by modulating outcome-based advantages while preserving the verifier-determined learning direction. Experiments across multiple agentic environments and model scales demonstrate that GRSD consistently outperforms competitive baselines and generalizes more effectively to unseen tasks.

## 1. 论文的核心问题与整体含义

**研究动机与背景**
- 大型语言模型（LLM）智能体通过多轮交互调用工具、感知环境反馈来解决复杂任务，但单一的终端奖励只能提供**粗粒度、稀疏的轨迹级监督**，无法帮助策略区分轨迹中哪些决策导致了成功、哪些行为造成了失败、哪些选择只是偶然因素。因此，**不充分的信用分配**成为智能体策略优化的关键瓶颈。
- 现有的智能体自蒸馏方法（如 Skill-SD、SDAR）试图用自然语言技能来丰富稀疏监督，但存在两个显著问题：
  - **外部检索技能**可能与当前 prompt、交互轨迹或环境状态不匹配，属于“经验错位”；
  - **由更强外部模型从单条轨迹中提取的后见技能**可能超出当前策略的能力边界，且单轨迹提取容易引入路径特异的噪声，无法区分成败模式。
- 因此，论文提出一个核心命题：**如何让策略从自身的已验证经验中，自动、在线地提炼出“能力对齐”且“结果判别”的指导信号**，并在不改变验证器判定方向的前提下，将轨迹级优势细化到轮次级信用。

**核心思路（GRSD 的总体含义）**
- GRSD 建立了一个**“经验驱动的自进化闭环”**：
  1. 策略对自己的同策略已验证轨迹进行**策略原生反思**（policy-native reflection）；
  2. 用**停止梯度快照**对比成功与失败轨迹的反思结果，合成**群体级 DO/AVOID 指导**；
  3. 以此指导作为“特权上下文”，驱动**自我教师**完成轮次级信用分配；
  4. 通过联合任务目标与反思目标，让策略既能更好地执行任务，也能持续提升从经验中提炼可复用技能的能力。
- 该方案**不依赖外部技能库、不依赖更强外部模型进行内容生成**，且推理阶段无任何额外开销。

## 2. 论文提出的方法论

**核心思想**
- 在 GRPO 框架下，对于每个 prompt 采样 G 条同策略轨迹，分别获得验证器奖励；GRSD 引入两个关键阶段（Stage A 与 Stage B），将反射技能转化为群体级特权指导，然后用该指导对轨迹级优势做**轮次级、有界、保符号的自蒸馏调制**。

**Stage A：策略原生自我反思（Policy-Native Self-Reflection）**
- 每条已验证并标有成败标签的轨迹，由策略自身（而非更强大的外部模型）按反思指令 `pref` 生成反思 `si`，内容需识别关键转折轮次、解释成败原因、总结应强化/应避免的具体行为。
- 外部固定裁判 `J`（DeepSeek-V4-Flash）仅对每条反思打分 `rref ∈ {0,1,2,3}`（从因果正确性、结果一致性、轨迹忠实性、可操作性四个维度评价），但**不生成或改写反思内容**。
- 反思奖励经过与公式（1）相同的组内归一化，得到反思优势 `Aref_i`，供反射目标单独优化。

**Stage B：群体级指导构建（Group-Level Guidance Construction）**
- 将同 prompt 下的反思按结果标签分为成功集合 `S+` 与失败集合 `S-`。
- 用**停止梯度快照** `π̄θ` 对比两组反思，依照指令 `pguide` 生成紧凑的 DO/AVOID 群体特权指导 `zx`：
  - 从成功轨迹提炼“应保留/应重复的正确决策与步骤”；
  - 从失败轨迹提炼“应避免的重复错误与无效行为”。
- 与 Stage A 不同，Stage B 的指导合成**完全断开梯度**：zx 只作为后续信用分配的固定特权上下文，不参与本轮的策略更新。
- 仅当同一 prompt 的群体中**同时存在成功与失败轨迹**（即 `mx=1`）时激活指导调制；单侧群体则退化为标准 GRPO。

**轮次级自蒸馏（Turn-Level Self-Distillation）**
- 对每个采样轮次构建两类上下文：
  - 纯学生上下文 `c_stu = C(x, H_t)`
  - 指导增强的教师上下文 `c_tea = C(x, z_x, H_t)`
- 用同一停止梯度策略 `π̄θ` 计算两组上下文下该轮动作 token 的均值对数似然差 `Δi,t`，并将“指导引起的似然改变”与验证器决定的优势方向对齐：`qi,t = sign(Ai)·Δi,t`。
- 将该对齐偏差映射为有界调制分数 `bq_i,t`（公式10：归一化 + 截断），最终轮次级优势为：
  - `Âi,t = Ai (1 + λ·bq_i,t·mx)`，且约束 `λ·bG ≤ 1`，**确保调制不逆转验证器设定的更新方向**。

**整体优化目标（公式12-14）**
- `L(θ) = L_task(θ) + α·L_ref(θ)`
  - `L_task`：用轮次级调制优势 `Âi,t` 替代 GRPO 的轨迹级 `Ai`，保持 PPO clip 结构；
  - `L_ref`：仅针对 Stage A 生成的反思 token，用反思优势 `Aref_i` 执行 GRPO 式更新；
  - 任务 token 与反思 token 互不重叠，二者在同一个反向传播中联合优化。

- 证明群体级对比估计器在理想表示模型下可降低轨迹特异性方差（Proposition 1）。

## 6. 论文的主要结论与发现

1. **GRSD 在聚合性能上全面领先**：
   - 在 ALFWorld 上，三个骨干下 GRSD 平均优于 GRPO 5.5%；SearchQA 上优于 GRPO 2.7%；WebShop 得分/成功率分别高出 4.8% / 7.2%。
   - 与各自骨干下 Skill-SD 与 SDAR 中较强者相比，ALFWorld 平均提升 4.2%，WebShop 成功率提升 5.5%。
2. **训练动态优势**：GRSD 在训练后期仍持续改进，而基线较早陷入平台期；同时，GRSD 的教师-学生差距小于 Skill-SD 与 SDAR，表明其生成的指导与策略当前能力更为兼容，优化过程更平滑。
3. **消融验证了各组件的互补性**：
   - 去掉群体反思指导后，ALFWorld 和 WebShop 成功率均明显下降（各约 7% 左右）；
   - 跳过群体聚合或去除失败反思都带来一致的性能损失，说明 Stage B 与失败信息的必要性；
   - 轮次级调制优于 token 级（噪声大）与轨迹级（过于粗糙）。
4. **策略原生反思优于外部模型生成**：在 ALFWorld 上，政策自身生成的指导相比外部模型版本取得更高的最终成功率与更小的教师-学生差距，验证了“能力对齐”是有效蒸馏的关键。
5. **泛化能力增强**：在 ALFWorld Unseen 拆分上，GRSD 比 GRPO 高 8.2%、比 SDAR 高 6.0%，Pick2 与 Cool 任务增益最明显，说明其提炼的决策原则更具可迁移性。
6. **超参数中等取值最佳**：`α=0.01`、`λ=0.5` 能平衡主任务与辅助反思学习、避免调制过度或不足。

## 7. 优点

- **方法设计优雅且具有通用性**：策略自身完成反思与指导合成，无需外部技能库、无需更强外部模型生成内容，是一种**完全自我依赖的经验驱动自进化机制**；推理阶段完全无额外开销。
- **信用分配细致且安全性高**：轮次级调制在保留验证器确定符号的前提下细化学习信号，从理论上保证了调制方向不会逆转，控制风险较好。
- **实验与消融设计较完整**：3 环境 × 3 骨干 × 多种基线的配对比较、多维度消融、超参数敏感性、训练动态、泛化测试与理论分析相互印证，方法有效性的证据链条较充分。
- **训练成本控制较好**：尽管在线生成指导，但 Stage B 将轨迹级反思压缩为紧凑指导，反而使教师前向传播更快（12.0s vs SDAR 25.1s），总训练时间仅比 GRPO 高 17%，较 SDAR

（接上：较 SDAR 的 8% 而言，GRSD 以 17% 的额外训练开销换来了显著更高的性能收益，性价比较为合理。）

## 8. 不足与潜在局限

- **外部裁判依赖**：虽然反思内容由策略自身生成，但打分仍需调用固定外部模型（DeepSeek-V4-Flash）。这引入了一个未消融的第三方变量：裁判的评分质量、尺度、对轨迹忠实性的敏感度都会直接影响反思优势与后续指导合成，而论文未报告替代裁判（如 GPT-4o、本地评判模型、规则评分）下的结果，也未分析裁判评分噪声对训练稳定性的影响。
- **理论假设较强**：附录中的 Proposition 1 依赖于“理想表示模型”的假设，该假设在实际 Transformer 特征空间中难以严格成立；Proposition 2 与 3 的保符号结论也基于调制因子的确定性计算，而实际优化中采样与截断可能带来轻微偏差。论文未提供理论假设不满足时的退化边界分析。
- **统计显著性缺失**：所有实验均未报告多次独立运行的均值与方差，也未进行显著性检验。考虑到 RL 训练对随机种子敏感，关键结论（如 GRSD 平均优于 SDAR 4.2%）的稳健性存疑，尤其当某些基线在特定子集上波动较大时。
- **通用性未跨家族验证**：骨干模型全部为 Qwen 系列（1.7B/3B/7B），未在 Llama、Mistral、DeepSeek 等主流架构上评估。策略原生反思的有效性可能依赖模型本身的指令跟随与内省能力，不同模型家族（尤其是小型模型）的“自反思能力”差异较大，结论外推需谨慎。
- **搜索域外数据集的表现异常未深挖**：在 MuSiQue、Bamboogle 上，部分基线（如 SDAR、Qwen2.5-3B）出现明显低于主趋势的结果，GRSD 也并非在所有域外集上都保持领先。论文仅报平均值，未细化分析这些复杂多跳子集对指导蒸馏策略的挑战。
- **未与其他信用分配家族对比**：缺少与基于价值函数的 critic（如 actor-critic、GAE）、基于蒙特卡洛的轮次归因、以及过程奖励模型（PRM）的对比。GRSD 的轮次级自蒸馏优势是相对于 GRPO、OPSD、RLSD 等同类方法而言的，其绝对竞争地位尚不清晰。
- **环境步数/任务的多样性有限**：ALFWorld、SearchQA、WebShop 虽覆盖三个场景，但都属于“有限状态 + 显式成功信号”的沙盒式任务，尚未在开放式编程（如 SWE-bench）、游戏控制、多智能体协作等更复杂环境中验证。
- **对成功轨迹占比的敏感性**：GRSD 的指导聚合需要同 prompt 下同时存在成功与失败轨迹（`mx=1`）才激活。当任务极难或极易（群体全失败或全成功）时，方法退化为标准 GRPO，其增益可能在这些极端难度分布下削弱，论文未报告这类场景的消融。

## 9. 总结与个人评价

GRSD 是一篇方法动机清晰、设计自洽、实验较扎实的智能体策略优化论文。其核心贡献在于：**让策略从自身的成败轨迹中提炼“能力对齐”的经验指导，并以保符号的轮次级调制方式安全地细化信用分配**，从而在不引入外部知识、不增加推理成本的前提下缓解智能体 RL 的稀疏奖励问题。这一思路兼具实用性（训练开销仅增 17%）与理论纪律性（保证更新方向不被逆转），在三个长视界任务上相对 GRPO 与最强技能蒸馏方法均取得了稳定提升，并通过对消融与训练动态的分析，说明了每个组件存在的必要性与“原生反思优于外部生成”的关键发现。

从审稿角度看，论文的弱点主要集中在外生变量（单一裁判模型、单一模型家族、无多次运行方差）以及理论假设与实验场景的覆盖面。若能在后续工作中补充跨家族模型验证、裁判敏感性分析、统计显著性检验，并在更复杂的环境中展示其可扩展性，该方法的适用性与说服力将大幅提升。总体而言，GRSD 代表了一种“经验自蒸馏 + 安全信用细化”的新范式，在 LLM 智能体高效探索与学习方向上具有较强的启发意义。
