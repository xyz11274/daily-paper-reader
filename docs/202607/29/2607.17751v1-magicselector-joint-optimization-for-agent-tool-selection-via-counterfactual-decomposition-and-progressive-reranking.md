## 摘要
我们提出了MagicSelector，一个集成反事实任务分解、渐进重排序和动态Top-K的联合优化框架，旨在解决智能体中工具检索的基本挑战。MagicSelector是一个专门的框架，能够将模糊的用户指令翻译为可执行的原子子任务，并指导高精度工具检索，有效缓解域外（OOD）场景中的冗余噪声和严重的上下文分心。我们通过三个关键贡献赋予MagicSelector这些能力：（1）一种偏好引导的反事实任务分解机制，利用反事实奖励量化分解对检索排序的边际因果增益，有效施加细粒度的结构监督以保持逻辑连贯性；（2）一种由自蒸馏难负例挖掘驱动的渐进工具重排序方法，同时优化逐点和列表相关性，增强高度相似工具间的细粒度区分；（3）一种双语义边界感知的动态Top-K策略，自适应监控重排序分数悬崖和工具间语义偏移，动态截断候选列表，在过滤长尾噪声的同时最大化相关工具召回。在MTDTool上（我们为移动多轮交互构建的第一个任务分解基准，带有过程级注释），MagicSelector展示了有前景的性能。大量实验表明，MagicSelector在工具检索准确性、OOD泛化能力和整体令牌效率上显著优于现有最先进方法，从而证明了我们提出框架的有效性。

## Abstract
We present MagicSelector, a joint optimization framework integrating Counterfactual task decomposition, Progressive reranking, and Dynamic Top-K, designed to address the fundamental challenges of tool retrieval in agents. MagicSelector is a specialized framework capable of translating ambiguous user instructions into executable atomic subtasks and guiding high-precision tool retrieval, effectively mitigating redundant noise and severe context distraction in out-of-domain (OOD) scenarios.We empower MagicSelector with these capabilities through three key contributions: (1) a preferenceguided counterfactual task decomposition mechanism that utilizes a counterfactual reward to quantify the marginal causal gain of decomposition on retrieval ranking, effectively imposing fine-grained structural supervision on logical coherence; (2) a progressive tool reranking method driven by self-distillation hard negative mining, which optimizes both point-wise and list-wise relevance to enhance fine-grained discrimination among highly similar tools; and (3) a dual semantic boundary-aware dynamic Top-K strategy that adaptively monitors reranking score cliffs and inter-tool semantic shifts to dynamically truncate the candidate list, maximizing relevant tool recall while filtering long-tail noise. Evaluated on MTDTool, the first task decomposition benchmark we constructed tailored for mobile multi-turn interactions with process-level annotations, MagicSelector yields promising performance. Extensive experiments demonstrate that MagicSelector significantly outperforms state-of-the-art methods in terms of tool retrieval accuracy, OOD generalization capability, and overall token efficiency, thereby demonstrating the effectiveness of our proposed framework.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究动机**：大型语言模型（LLM）驱动的自主智能体（如手机助手）需通过调用外部工具完成复杂任务。然而，将所有工具描述放入有限上下文窗口在计算上不可行，因此工具检索成为关键瓶颈。现有静态检索方法在处理模糊、多轮、多任务用户指令时，存在严重的语义不匹配和检索失败问题。
- **核心挑战**：
  1. **任务分解中的捷径学习**：基于提示或监督微调（SFT）的方法存在累积误差；强化学习（RL）方法缺乏因果归因，容易利用分解结果与检索指标之间的虚假相关，而非进行精确分解，导致域外泛化能力差。
  2. **功能相似工具的区分困难**：用户异质查询与海量工具文档之间存在语义鸿沟，传统重排序缺乏深层token交互，随机负样本提供的学习信号弱。
  3. **动态噪声过滤与上下文效率平衡**：固定Top-K截断要么丢失关键工具，要么引入大量长尾噪声，加剧“lost-in-the-middle”效应。
- **整体含义**：MagicSelector是一个联合优化框架，通过反事实任务分解、渐进重排序和动态Top-K策略，系统性地解决以上三个挑战，实现高精度、高泛化、高效率的工具检索。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
- 将任务分解、工具重排序和上下文截断视为一个可联合优化的管道，而非独立流水线。
- 利用**因果推断**量化分解对检索排序的边际贡献，避免虚假相关。
- 通过**自蒸馏难负例挖掘**和**逐点+列表联合优化**增强模型对相似工具的区分能力。
- 基于**双语义边界感知**的递归制定动态截断点，平衡召回与噪声过滤。

### 2.2 关键技术细节

#### （1）反事实任务分解（Counterfactual Task Decomposition）
- **反事实基线**：对于多轮上下文 `x` 和真实工具集 `G`，先计算不分解时检索结果 `T_raw^K = R_K(x)` 的 NDCG@K 作为基线 `N_raw`。
- **分解策略**：策略模型 `π_θ` 生成候选分解 `y_i`，解析为原子子任务 `A(y_i)`，分别检索后融合得到 `T_atom^K`，计算 `N_atom`。
- **反事实奖励**：
  \[
  R_{cf} = \lambda_{ndcg} \max(0, N_{atom} - N_{raw}) + \lambda_{full} (I[G \subseteq T_{atom}^K] - I[G \subseteq T_{raw}^K])
  \]
  第一项为正向排序增益（仅当分解优于基线时给予奖励），第二项为完整覆盖性奖励（确保所有目标工具被召回）。
- **偏好奖励**：引入过程奖励模型（PRM）评估分解结果在完整性、准确性、共指消解、标准化表达和上下文一致性五个维度的质量，得到 `R_{pref} = σ(s_φ(x,y_i) - s_φ(x,y^⋆))`。
- **联合奖励**：`R = α R_{pref} + β R_{cf}`，在GRPO框架中优化策略模型。

#### （2）渐进工具重排序（Progressive Reranking with Hard Negative Mining）
- **两阶段重排序训练**：
  - **逐点训练**：使用二元交叉熵损失，为每个查询-工具对学习独立的相关性分数。
  - **列表训练**：计算候选工具上的分数分布，最小化与真实标签分布之间的交叉熵（列表损失）。
- **自蒸馏难负例挖掘**：
  - 训练初始模型（基于随机负样本）。
  - 利用当前模型对所有候选工具打分，移除真实工具后，取得分最高的前k个错误工具作为难负例。
  - 使用（查询，正工具，难负例）三元组重新训练模型，迭代多次。
  - 该过程无需额外人工标注，适用于检索器和重排序器。

#### （3）双语义边界感知动态Top-K（Dual Semantic Boundary-Aware Dynamic Top-K）
- **观察**：重排序得分分布呈帕累托分布——仅少数头部工具得分高，其余快速衰减至长尾。
- **候选截断点1（基于得分差）**：`TopK_score = argmax_i (s_i - s_{i+1})`，即相邻工具得分的最大下降点。
- **候选截断点2（基于语义相似度差）**：计算相邻工具描述嵌入的余弦相似度 `sim_i = cos(e_i, e_{i+1})`，`TopK_sim = argmax_i (sim_i - sim_{i+1})`，捕捉工具功能簇的边界。
- **融合策略**：`Final_TopK = max(TopK_score, TopK_sim)`，取两者中较大值以最大化召回（保守策略）。时间复杂度 O(n)。
