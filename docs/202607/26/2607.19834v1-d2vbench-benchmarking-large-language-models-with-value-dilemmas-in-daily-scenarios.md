## 摘要
随着大型语言模型（LLMs）在现实场景中的广泛应用，其输出的价值意涵变得至关重要。然而，现有的评估基准存在不足，包括对涉及多重价值冲突的日常场景中价值困境的覆盖不充分，以及过于简化的评估形式无法有效评估LLMs的价值对齐。为解决这些问题，我们提出了D2VBench，这是一个价值对齐基准，包含通过LLMs与人类多阶段协作构建的10,000个真实日常困境场景实例，并基于158个手动标注的细粒度价值概念。对于基准的评估，我们提出了一种混合评估范式，将多项选择题与开放式问题相结合。我们在八个主流LLMs上进行了全面评估。实验结果表明，D2VBench表现出高可靠性和鲁棒性，有效反映了LLMs在不同价值类别和维度上的对齐程度，为价值对齐研究提供了一个更真实、更细粒度的工具。数据集可在https://github.com/tjunlp-lab/D2VBench获取。

## Abstract
With the wide application of large language models (LLMs) in real-world scenarios, the value implication of their outputs is crucial. However, existing evaluation benchmarks suffer from insufficient coverage of value dilemmas in daily scenarios involving multiple value conflicts and simplistic evaluation formalisms that fail to assess LLMs' value alignment. To address these issues, we propose D2VBench, a value alignment benchmark comprising 10,000 instances of real daily dilemma scenarios constructed through a multi-stage collaboration between LLMs and humans, grounded in 158 manually annotated fine-grained value concepts. For evaluation on the benchmark, we present a hybrid evaluation paradigm that integrates multiple-choice questions with open-ended questions. We conduct comprehensive evaluations on eight mainstream LLMs. Experimental results demonstrate that D2VBench exhibits high reliability and robustness, effectively reflecting the LLMs' alignment across different value categories and dimensions, and providing a more realistic and fine-grained tool for research on value alignment. The dataset is available at https://github.com/tjunlp-lab/D2VBench.

### 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：通过多阶段人机协作，基于**158个人工标注的细粒度价值概念**（形成四层层次结构：类别→核心价值→子价值→规范概念），生成**10,000个包含多重价值冲突的真实日常困境场景**，并采用**混合评估范式**（开放回答+映射到多选选项+多维度可解释评分点覆盖），实现对LLM价值对齐能力的定量、可靠评估。
- **关键技术细节**：
  1. **价值体系构建**：综合马洛斯需求层次、罗克奇终值理论、舍勒价值论和施瓦茨价值理论，设计四层结构，涵盖生存安全、社会秩序、文明进步三大顶级类别。
  2. **数据集构建流程（四阶段）**：
     - **阶段1（基础场景与角色定义）**：LLM基于每个价值概念生成尽可能多的基础场景及主要角色，并通过Sentence-BERT去重。
     - **阶段2（价值困境创建）**：LLM以第一人称视角构建包含明显价值冲突和复杂动机的现实困境，同时反映角色面临的身份冲突、文化惯性、人际压力等多维障碍。人工验证质量，剔除不合格实例。
     - **阶段3（选项生成）**：为每个困境生成四个可能行为选项，覆盖全部可能行动路径，包括消极妥协等非普适价值行为。
     - **阶段4（人工精炼与理由库生成）**：人工审核选项合理性，补充背离普遍价值的合理解释及其严重后果；为每个选项标注**五个维度的可解释评分点**：后果考虑、理性与正当性、风险权衡、责任归属、可行性与执行难度。由专家最终审核。
  3. **评估方法**：
     - 提供开放问题给测试LLM，要求从五个维度详细回答。
     - 选择**GLM-4.6和Qwen3-Max**作为裁判模型，将自由回答映射到**一个或多个**逻辑一致的选项（多标签映射），并计算测试回答对每个选项可解释评分点的覆盖率。
     - 得分公式：`Align-Score = (TNRC / TNFO) × 100`，其中TNRC为回答覆盖的评分点数，TNFO为选项总评分点数。
     - 最终得分：对**与普世价值最一致的选项**赋予1.5倍权重，其他选项权重1.0，加权平均。

### 6. 论文的主要结论与发现

1. **模型排名**：GPT-5.1在所有价值类别中得分最高（平均约65.6），其次是Gemini-3-pro-preview（约63.1），DeepSeek-R1和GLM-4.6居中（约60-61），Doubao-seed-1.6最低（约55.5）。
2. **类别表现差异**：所有模型在**生存安全**类别表现最好，**社会秩序**次之，**文明进步**最差。说明LLM对抽象、长期目标导向的价值困境推理能力较弱。
3. **维度短板**：LLM在**理性与正当性**和**责任归属**维度得分较高，但**可行性与执行难度**维度得分普遍最低（约52-53分），表明LLM擅长价值陈述但缺乏将抽象价值转化为可操作步骤的能力。
4. **多标签映射优于单标签**：单标签映射导致排名不一致且信息损失；多标签映射能更全面捕捉LLM的混合策略推理。
5. **鲁棒性与可靠性**：D2VBench对裁判模型选择、权重调整不敏感，排名稳定。人类一致性高，证明评估有效。

### 7. 优点

- **场景真实性与复杂性**：基于158个细粒度价值概念，通过人机协作构建包含多重价值冲突、现实约束的日常困境，大幅提升了场景的生态效度。
- **评估范式创新**：将开放式回答映射到多个选项，兼取了开放式问题的深度和多选题的量化便捷性；引入五个维度的可解释评分点，使评估具有可解释性。
- **评估方法鲁棒**：使用两个裁判模型取平均、进行权重消融和映射消融，证明排名稳定。人类一致性验证（Pearson r > 0.74）增强了可信度。
- **人工高质量标注**：严格的标注者选拔和训练流程，以及专家审核，保障了数据集和理由库的质量。
- **公开可用**：数据集已在GitHub开源，便于后续研究。

### 8. 不足与局限

- **文化单一性**：数据集完全基于中文语境，价值体系虽然参考了跨文化理论，但实际场景仅反映中国社会文化背景。论文承认无法据此推断模型在不同文化背景下的价值偏差。尽管构建流程可迁移，但当前版本存在文化偏差风险。

- **算力与成本未报告**：未披露构建数据集和评估所需的计算资源，不利于可重复性评估。
- **最优选项标注的主观性**：“与普世价值最一致”的选项由人工标注，可能引入标注者偏见；权重设置（1.5倍）虽经消融验证稳定，但取值仍缺乏理论依据。
