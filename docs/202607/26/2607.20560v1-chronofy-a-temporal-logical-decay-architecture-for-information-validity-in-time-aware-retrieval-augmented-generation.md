## 摘要
检索增强生成（RAG）系统通过检索并整合外部知识来支撑大语言模型（LLM）的输出。然而，当前的RAG架构将所有检索到的事实视为同等有效，而不考虑其时间来源，从而导致了时间幻觉——看似合理但已过时的事实污染了输出。昨日的一份临床实验室报告是有操作价值的；而六个月前的同一报告则只是噪音。我们提出Chronofy，一个三层神经符号框架，实现了时序逻辑衰减架构（TLDA），该架构将时间有效性直接嵌入RAG系统的表示、检索和推理层。第一层在套娃嵌入中保留专用的时间子空间，使得事实的时效性在表示中结构上不可移除。第二层将可学习的指数衰减函数集成到基于图的检索中，其中衰减系数β_j基于贝叶斯决策理论，近似为潜在过程均值回复率的两倍。第三层应用信号时序逻辑（STL）鲁棒函数来评估检索知识的时间有效性，而非LLM输出的置信度，并遵循可能性的最弱链原则，以推理链中衰减最严重的证据来约束输出置信度。我们在时序知识图谱预测基准、TimE时间问答基准以及领域特定敏感性分析上评估了Chronofy，结果表明，显式的时间衰减建模提高了检索精度，减少了时间幻觉，并在时间上下文不足时实现了原则性的数据重新获取触发机制。

## Abstract
Retrieval-Augmented Generation (RAG) systems retrieve and integrate external knowledge to ground large language model (LLM) outputs. However, current RAG architectures treat all retrieved facts as equally valid regardless of temporal provenance, leading to temporal hallucination, where plausible but obsolete facts corrupt the output. A clinical lab reading from yesterday is actionable; the same reading from six months ago is noise. We present Chronofy, a three-layer neuro-symbolic framework implementing the Temporal-Logical Decay Architecture (TLDA) that embeds temporal validity directly into the representation, retrieval, and reasoning layers of RAG systems. Layer 1 reserves a dedicated temporal subspace within Matryoshka embeddings to make fact age structurally irremovable from the representation. Layer 2 integrates learnable exponential decay functions into graph-based retrieval, where the decay coefficient $β_j$ is grounded in Bayesian decision theory as an approximation of twice the latent process mean-reversion rate. Layer 3 applies Signal Temporal Logic (STL) robustness functions to evaluate the temporal validity of retrieved knowledge, not LLM output confidence, and enforces the possibilistic weakest-link principle to bound output confidence by the most decayed evidence in the reasoning chain. We evaluate Chronofy on temporal knowledge graph forecasting benchmarks, the TimE temporal QA benchmark, and a domain-specific sensitivity analysis, demonstrating that explicit temporal decay modeling improves retrieval precision, reduces temporal hallucination, and enables principled data re-acquisition triggers when temporal context is insufficient.

## 2. 方法论：核心思想、关键技术细节、公式与算法流程

### 核心思想
Chronofy采用三层神经符号架构（Temporal-Logical Decay Architecture, TLDA），将时间有效性嵌入系统全流程：

- **Layer 1（表示层）**：在Matryoshka嵌入中保留专用时间子空间，使事实的时效性在表示中不可移除。嵌入向量由时间部分和语义部分拼接而成：e = [e_temp; e_sem]，其中时间投影模块通过LoRA训练，并采用CKA对比损失强制保留时间线索。
- **Layer 2（检索层）**：将可学习的指数衰减函数集成到基于图的检索中。遍历权重公式：w(e_ij) = q_e · c(tr_j) · exp(-β_j · (T_q - T_f))。其中β_j是特定事实类型的可学习衰减系数，通过贝叶斯决策理论（Proposition 1）将其与潜在Ornstein-Uhlenbeck过程的均值回复率κ_j关联：β_j = 2κ_j。检索时通过阈值τ进行认知过滤，排除过时证据。
- **Layer 3（推理层）**：应用信号时序逻辑（STL）鲁棒函数评估检索知识的时间有效性，而非LLM输出置信度。定义有效性信号v(s_i) = min_{e∈facts(s_i)} [q_e · exp(-β_j(e)·(T_q-t_e))]。STL公式φ_valid = G_{[0,n]}(v(s_i) ≥ γ)，鲁棒性得分ρ = min_i (v(s_i)-γ)。若ρ<0，则触发数据重新获取。此外，推导出最弱链原则（Theorem 1）：输出置信度C_out ≤ min_i V(e_i, T_q)，保证推理链的可靠性。

### 关键技术细节
- 时间子空间维度t可调（实验中t=4最优）。
- 指数衰减被证明在理论上有最优性（基于OU过程的信息衰减率）。
- Layer 3的STL验证作为后置质量门，可识别24.6%的“自信但错误”输出。

## 6. 主要结论与发现

1. **显式时间衰减建模始终优于静态检索**：在ICEWS14上MRR提升9.4%，在GDELT上提升48.9%。
2. **单纯使用新鲜度（Recency）反而有害**：在GDELT上MRR下降46.7%，表明原始新鲜度无法替代语义-时间联合权重。
3. **最优β因事实类型而异**：从0（诊断结果，永久稳定）到10.0（政治事件，快速变化），需要域特异性学习。
4. **时间嵌入和衰减重排序具有互补性**：全管线相比仅Layer 2提升4.5% Gold@5（0.567→0.593）。
5. **Layer 3的可选触发机制有效**：在无时间检索时，将精度从0.341提升至0.469（γ=0.9），但检索优化后作用减弱（符合预期）。
6. **Weakest-link原则被验证**：输出置信度确实受最陈旧证据约束。

## 8. 不足与局限

- **指数衰减的单调性限制**：指数函数无法建模非单调生命周期或突然的机制转变（如新法规颁布）。作者承认Weibull在某些指标上略优，但牺牲了理论简洁性。
- **Proposition 1的假设限制**：假设潜在过程为稳态高斯OU过程，对于非平稳或重尾过程仅为近似，实际β通过学习补偿，但缺乏严格保证。
- **实验覆盖的多样性不足**：仅在新闻、政治事件和临床领域评估，尚未在金融、法律、科学文献等其他时效敏感领域验证。
- **解析时间焦点实际覆盖有限**（37.8%），部署中需要专用时间标记器，这成为主要瓶颈。
- **Layer 3在检索优化场景下效果边际**：虽然这是设计预期（保持安静，仅在故障时干预），但可能会让用户低估其实际价值。
- **冷启动问题**：β参数需要领域数据集或专家标注来学习，在新领域无法直接应用。
- **未与现代LLM（如GPT-4o、Claude-3.5）进行对比**，仅使用Gemini 2.5 Flash作为推理模型，可能限制泛化性。
