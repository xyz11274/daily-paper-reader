## 摘要
机器学习工程（MLE）任务需要在迭代式解决方案调试与优化过程中进行长时域决策，同时面对昂贵且反馈驱动的环境交互。为此类任务开发并训练单体智能体从根本上具有挑战性：它必须同时管理极长且含噪的上下文、探索庞大的解决方案空间，并在有限的模型容量和计算预算下保持有效性。为应对这些挑战，我们提出Matryoshka Agent——一个用于复杂长时域任务的统一层级智能体框架。Matryoshka Agent将智能体问题求解分解为决策与执行的协调层级：高层级的Orchestrator维护紧凑的长时域探索状态并发出策略性指令，而低层级Sub-Agents通过标准化的Tool接口与环境直接交互来执行具体解决方案尝试。这种设计将策略探索与代价高昂的执行解耦，大幅减轻了长上下文推理的负担，并实现了高效的迭代优化。我们进一步为Matryoshka Agent开发了一种高效的训练范式。在涵盖多种模型类型与规模的广泛MLE任务上的实验结果表明，Matryoshka Agent是长时域MLE任务及复杂智能体问题求解的一种有效且可扩展的范式。值得注意的是，Matryoshka Agent使得Qwen3-4B-Instruct能够达到与o4-mini相当的Orchestrator性能。将Matryoshka Agent应用于Qwen3-30B-Coder，相对性能提升最高达36.7%。

## Abstract
Machine learning engineering (MLE) tasks require long-horizon decision making over iterative solution debugging and refinement, under expensive and feedback-driven environment interactions. Developing and training a monolithic agent for such tasks is fundamentally challenging, as it must simultaneously manage extremely long and noisy contexts, explore vast solution spaces, and remain effective under limited model capacity and computational budgets. To address these challenges, we propose Matryoshka Agent, a unified hierarchical agent framework for complex long-horizon tasks. Matryoshka Agent decomposes agentic problem solving into a coordinated hierarchy of decision making and execution: a high-level Orchestrator maintains compact, long-horizon exploration states and issues strategic instructions, while lower-level Sub-Agents execute concrete solution attempts through direct environment interaction, mediated by standardized Tool interface. This design decouples strategic exploration from costly execution, substantially reducing the burden of long-context reasoning and enabling efficient iterative refinement. We further develop an efficient training paradigm for Matryoshka Agent. Experimental results on a broad range of MLE tasks with diverse model types and scales demonstrate that Matryoshka Agent is an effective and scalable paradigm for long-horizon MLE tasks and complex agentic problem solving. Notably, Matryoshka Agent enables Qwen3-4B-Instruct to reach Orchestrator performance comparable to o4-mini. Applying Matryoshka Agent to Qwen3-30B-Coder results in at most 36.7% relative performance gain.

## 2. 方法论：核心思想、关键技术细节
### 核心思想：层级解耦（Hierarchical Decomposition）
- 提出 **Matryoshka Agent**，由三层构成：
  - **Orchestrator（高层决策层）**：维护紧凑的跨回合状态（包含先前指令、结果摘要、评分），决定下一步优化方向。
  - **Sub-Agents（低层执行层）**：以全新上下文实例化，负责编写代码、运行、调试、产生具体解决方案。
  - **Tools（中介层）**：格式化Orchestrator指令，注入参考信息，启动Sub-Agent，返回结构化摘要和评分。

### 关键技术细节
- **Orchestrator**：
  - 不直接积累原始代码、执行日志，而是通过工具调用维护评分注释的历史记录。
  - 每次回合控制三方面：选择要优化的先前尝试、编写具体实施指令、标记可参考的先前尝试。
- **Tools**：
  - 输入：父尝试、指令、参考标签。
  - 执行：为Sub-Agent构建干净上下文，管理其生命周期。
  - 输出：简洁的评分和摘要（成功时），或失败状态和诊断摘要（失败时）。
- **Sub-Agents**：
  - 具有独立的、有界的执行-调试循环，最多10次调试迭代。
  - 不继承Orchestrator或其他Sub-Agent的历史。
- **训练范式**：
  - **Solution Refinement Tree（解决方案改进树）**：从根状态开始，Orchestrator在每个非叶节点采样两个替代指令，执行后产生子节点，形成二叉树。
  - **偏好构造**：每个子节点的下游回报定义为子树中的最高分，比较同一父节点下的两个子分支，产生轨迹级偏好信号。
  - **在线对比学习**：使用基于排序的NCE目标优化Orchestrator，能量函数形式为：
    \[
    r_\theta(s_u, \Delta\tau) = \beta \log \frac{\pi_\theta(\Delta\tau|s_u)}{\pi^{(m)}(\Delta\tau|s_u)}
    \]
    损失函数：
    \[
    \mathcal{L}_{\text{orch}} = -\mathbb{E}_u \left[ \beta \log \frac{\pi_\theta(\Delta\tau_u^+|s_u)}{\pi^{(m)}(\Delta\tau_u^+|s_u)} - \log \sum_{\Delta\tau \in C(u)} \left( \frac{\pi_\theta(\Delta\tau|s_u)}{\pi^{(m)}(\Delta\tau|s_u)} \right)^\beta \right]
    \]
  - **Sub-Agent自我强化**：从最高分路径中提取Sub-Agent成功轨迹，进行监督微调（SFT）。

## 7. 优点
- **框架设计简洁解耦**：将战略决策与具体执行分离，大幅降低长上下文推理压力，同时保留关键信息。
- **高效的训练范式**：
  - 基于改进树的采样重用昂贵执行反馈，自动生成轨迹级偏好信号。
  - 在线对比学习结合KL正则化，稳定训练。
  - 联合优化Orchestrator和Sub-Agent（自我强化），实现协同提升。
- **插拔式灵活性**：Orchestrator可在测试时与不同Sub-Agent组合，无需重新训练。
- **跨模型尺度有效性**：小模型（4B）可作为高效决策层，大模型（30B）可同时作为Orchestrator和Sub-Agent，体现了可扩展性。
- **系统实验分析**：包括上下文增长、指令动态、失败案例等，深入揭示了框架工作原理。

## 8. 不足与局限
- **实验局限**：仅在MLE-Dojo一个基准上评估，缺乏对更多长时域任务（如软件工程、科学计算）的验证，泛化性未充分证明。
- **小模型作为Sub-Agent能力不足**：Qwen3-4B作为Sub-Agent时指令跟随能力弱，导致失败（附录E），限制了框架对小模型的全栈应用。
