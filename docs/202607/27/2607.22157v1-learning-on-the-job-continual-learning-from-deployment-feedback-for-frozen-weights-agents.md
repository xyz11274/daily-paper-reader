## 摘要
AI智能体在每次运行中都会遇到学习机会，但几乎全部丢弃：底层模型在部署后被冻结，因此今天解决困难请求的智能体明天再次遇到时需从零开始。然而，常规操作已经以结果判定和事后修正的形式产生反馈。我们证明，当冻结模型与一个将每次运行提炼为可检索的自然语言规则的外部记忆配对时，这种反馈足以用于持续学习。在τ-bench的银行领域，与检索完整策略语料库的静态RAG对照组相比，从单比特结果判定中学习使单次尝试成功率提升至基线的1.6倍，从修正中学习则提升至2.6倍，将基线从未解决过的84个任务中的22个转化为可解。该结果跨越部署范围，在Mistral Large（一种数据主权要求组织可自托管的开放权重模型）上测量，并在前沿模型Claude Sonnet 5上复现。积累的记忆也具有迁移性：每个模型读取由另一个模型构建的存储后，性能都超越自身无记忆基线。我们发布了工具、协议和数据。

## Abstract
AI agents encounter learning opportunities in every episode they run, and discard nearly all of them: the underlying models are frozen at deployment, so an agent that resolves a difficult request today starts from zero when it recurs tomorrow. Yet ordinary operation already produces feedback, in the form of outcome verdicts and after-the-fact corrections. We show that this feedback is a sufficient signal for continual learning when the frozen model is paired with an external memory that distils each episode into retrievable natural-language rules. On the banking domain of $τ$-bench, against a static-RAG control retrieving over the complete policy corpus, learning from the one-bit outcome verdict lifts single-trial success to 1.6$\times$ the baseline, and learning from corrections to 2.6$\times$, converting 22 of the 84 tasks the baseline never solves. The result spans the deployment spectrum, measured on Mistral Large, an open-weights model that organisations with data sovereignty requirements can self-host, and replicated on a frontier model, Claude Sonnet 5. The accumulated memory also transfers: each model, reading the store built by the other, rises above its own no-memory baseline. The harness, protocol, and data are released.

#### 1. 论文的核心问题与整体含义（研究动机和背景）
- **核心问题**：当前部署的 AI 智能体（agent）的模型权重在部署后冻结，无法从运行过程中产生的反馈（如用户是否接受方案、人工是否需要编辑输出等）中持续学习。每次交互都是一次学习机会，但几乎全部被丢弃，导致相同的困难请求再次出现时仍需从零开始。
- **背景与动机**：传统持续学习依赖权重更新，但代价高昂（训练基础设施、灾难性遗忘风险、每次更新需重新评估安全等）。许多组织无法承受。而实际部署中总会存在某种形式的监督信号（结果判定、事后修正）。本文旨在探索一种无需修改权重、仅利用已有反馈信号的持续学习机制。

#### 2. 论文提出的方法论：核心思想、关键技术细节
- **核心思想**：将冻结模型与**外部记忆**（Spark 记忆系统）配对。每个运行情节结束后，将反馈信号提炼为紧凑的自然语言“洞察”（insight），存储于外部记忆中，并在后续相关情节中检索使用。模型权重不变，实现梯度无关的持续学习。
- **关键技术细节**：
  - **Spark 记忆系统**：独立服务器，通过模型上下文协议（MCP）与智能体交互。知识单元为“洞察”，包含标题、内容和检索查询（以未来智能体会问的问题形式）。提供 `search`, `create_memory`, `enrich_memory`, `share_feedback` 四个接口，形成读-贡献-反馈循环。
  - **知识生命周期**：贡献异步通过自动管理管道（安全过滤、质量门控、去重），持续运行修剪、冲突解决、综合等操作。无需人工干预。
  - **两种反馈等级**：
    - **经验（Experience）**：仅接收正确/错误判定（1 bit），智能体自行总结教训（成功时保存成功规则，失败时保存应避免的内容）。
    - **指令（Instruction）**：在失败后额外提供正确的行动序列（任务验证的解决方案），智能体可写出“验证规则”（VERIFIED RULE）。
  - **读写路径**：读取由智能体自主触发（搜索工具），写入仅在情节结束后的反思回合中进行，防止中间自信错误污染记忆。写入时有合同约束（WHEN-THEN 形式、决策关键值必须逐字包含、不得与已验证规则冲突等）。
- **算法流程**（文字说明）：
  1. 智能体与用户或环境交互，使用工具（包括记忆搜索）。
  2. 情节结束后，根据反馈类型（经验/指令）生成反思消息。
  3. 反思回合中，智能体调用记忆创建工具，将提炼的规则存储到外部记忆。
  4. 后续情节中，智能体通过记忆搜索获取相关规则，并应用。
  5. 反馈机制（share_feedback）更新检索排名。

#### 3. 实验设计
- **数据集与场景**：使用 τ-bench 的银行领域（Banking domain），包含 97 个任务。每个任务是多轮对话，智能体需与模拟客户交互，通过工具完成操作，最终数据库状态需匹配预计算的地面真值。评估完全确定性（除一个任务外），无需 LLM 评判。
- **基准（benchmark）**：τ-bench 的“静态 RAG”配置：智能体可检索约 700 份政策文档（BM25 稀疏检索），但无记忆。这是与记忆条件对比的基线。
- **对比方法**：
  - **无记忆基线（No-memory baseline）**：标准 τ-bench 智能体，仅在文档库上检索。
  - **经验（Experience）**：学习来自结果判定（正确/错误）。
  - **指令（Instruction）**：学习来自结果判定 + 事后纠正（验证的动作序列）。
  - **跨模型迁移实验**：将两个模型（Mistral Large 和 Claude Sonnet 5）在指令条件下积累的记忆冻结，让另一模型只读读取，测量迁移效果。
- **协议与指标**：
  - 每个任务运行 4 次试验（trial），记忆条件下存储器持续存在（跨试验学习）。
  - 主要指标：pass^k（任务在 k 次试验中全部通过的比例）、单次试验成功率曲线、保持率（hold rate，任务在 t 试验通过后在 t+1 试验也通过的概率）。
  - 分层分析：将任务按基线是否从未解决（84 个任务称为“floor”），其他为“competent”。
- **复现**：在 Mistral Large 上运行三个条件，在 Claude Sonnet 5 上运行无记忆基线和指令条件，观察复现性。

#### 5. 实验数量与充分性
- **实验数量**：
  - 每个条件运行 97 个任务 × 4 次试验 = 388 次对话。
  - Mistral Large 共 3 个条件（基线、经验、指令）→ 约 1164 次对话。
  - Claude Sonnet 5 共 2 个条件（基线、指令）→ 约 776 次对话。
  - 迁移实验：两个模型各一次（读取对方冻结存储）→ 各 388 次对话。
  - 总实验规模较大，但每个条件仅一次运行（无多次随机种子平均）。
- **充分性与公平性**：
  - 控制变量：无记忆基线已检索完整政策语料库，因此所有提升归因于记忆的额外贡献。
  - 公平对比：记忆条件与基线在同一任务集、相同调度（任务级独立，试验间耦合）下运行。冷启动时无记忆条件与基线性能无差异（空存储器无帮助）。
  - 存在一个基础设施错误（一个任务在一个条件下丢失一次试验），但已声明。
  - 不足：每个条件仅一次运行，无法评估运行间变异；论文使用自助法（cluster bootstrap）估计区间，但仅反映任务采样变异，而非运行随机性。

#### 6. 论文的主要结论与发现
- **部署反馈足够驱动持续学习**：
  - Mistral Large：指令模式单次试验成功率（pass^1）从基线 0.064 提升至 0.170（2.6 倍）；经验模式提升至 0.103（1.6 倍）。
  - Claude Sonnet 5：指令模式从基线 0.248 提升至 0.397（1.6 倍）。
- **学习曲线**：记忆条件成功率随试验次数单调上升，基线平坦。
- **解决之前无法完成的任务**：Mistral Large 指令模式转化了基线从未解决的 84 个任务中的 22 个；Claude Sonnet 5 转化了 57 个中的 28 个。
- **记忆跨模型迁移**：
  - Mistral Large 读取 Sonnet 构建的存储：pass^1 从 0.064 升至 0.289（+0.224）。
  - Claude Sonnet 5 读取 Mistral 构建的存储：pass^1 从 0.248 升至 0.314（+0.066）。
  - 双方在可迁移任务上的转化率约 31%（类似效率）。
- **保持率**：经验模式保持率 0.88，指令模式 0.65（指令模式更积极但可能引入干扰）；但两种模式均显著高于无记忆基线的随机重试概率（0.61-0.70）。

#### 7. 优点：方法或实验设计上的亮点
- **实用性强**：利用部署中自然产生的反馈（1 bit 判定或事后纠正），无需权重更新，成本低、风险低。
- **设计精细**：写入路径有严格合同（WHEN-THEN 形式、决策值逐字、禁止削弱已验证规则等），避免记忆污染；读取路径由智能体自主触发，不干扰原有工作流；支持反馈评分优化检索排序。
- **控制变量严谨**：基线已使用完整 RAG，因此所有提升归因于外部记忆，而非简单知识获取。
- **跨模型迁移实验**：证明记忆不是模型特异性“答案缓存”，而是可泛化的任务知识；且强弱模型之间双向受益。
- **指标全面**：除 pass^k 外，引入保持率、学习曲线、分层转化率，更细致刻画学习效果。
- **可重复性**：公开工具、协议和数据。

#### 8. 不足与局限
- **实验覆盖**：仅一个领域（银行），两个模型（Mistral Large 和 Claude Sonnet 5），未在更多模型（如 GPT-4、更小模型）或多领域（医疗、法律等）验证。
- **运行间变异未估计**：每个条件只有一次运行，无法测量因调度顺序或随机性导致的方差；虽然任务级自助法提供了区间，但跨任务耦合可能被低估。
- **经验模式未在更强模型上运行**：Claude Sonnet 5 仅测试了基线和指令，缺少经验模式对比；作者提到预期更强模型上经验模式收益更大，但未证实。
- **反馈噪声未处理**：实验中反馈信号完全可靠（确定性评估器），但真实部署中反馈可能延迟、缺失或错误；论文明确表示这超出范围。
- **pass^4 无区分力**：由于记忆条件下任务通常在前几轮失败后成功，导致 pass^k（k>=2）衰减快；pass^4 三个 Mistral 条件相同，因为许多任务只有 1-2 次成功。论文建议使用保持率替代。
- **泛化性有限**：当前设计针对重复出现情境（相同任务再次出现），未衡量对新任务类型的泛化。
