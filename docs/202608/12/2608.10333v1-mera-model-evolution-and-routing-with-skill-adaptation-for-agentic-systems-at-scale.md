## 摘要
大语言模型智能体可在单个任务中执行异质序列的模型调用：部分调用需要精细推理，另一部分调用则是格式化或工具参数构建这类结构化步骤。现有路由方法利用了这种不对称性，将简单调用分配给成本更低的小模型，困难调用分配给大模型。这类策略可以降低推理成本，但并未改变小模型本身的能力，因此所能实现的成本节省仍受限于学生（小模型）已有的解决能力。与之不同，MERA以单次模型调用为适配单元，直接改进小模型本身。在每个循环中，MERA重放学生模型失败的调用以获取经执行验证的教师演示，将重复出现的流程蒸馏为迭代更新的技能库SkillBook，并通过监督学习和可选的GRPO对学生LoRA适配器进行微调。路由作为部署阶段的支撑机制：改进后的学生模型部署于经过成本校准的路由器之后，配备基于验证器的回退机制；仅当联合重放能够保持任务质量时，候选技能库、适配器或路由器才会被接纳。实验结果表明，四轮适配将Qwen2.5-Coder-1.5B在留出的HumanEval+MBPP测试集上的通过率从28.7%提升至49.7%。在基于验证器的回退机制下，部署后的策略仅消耗始终使用Luna的60.8%成本，仍保留了88.3%的通过率。在TAU-2基准上，微调后的Qwen3.5-2B性能从14/35提升至18/35，性能与未经过适配的4B模型相当。这些结果表明，基于验证器的多轮适配可以提升小模型的能力，而非仅绕开固定能力的学生模型进行路由选择。

## Abstract
LLM agents execute heterogeneous sequences of model calls within a single task: some invocations require careful reasoning, while others are structured steps such as formatting or tool-argument construction. Prior routing methods exploit this asymmetry by assigning easy invocations to a cheaper small model and difficult ones to a large model. Such policies reduce inference cost, but they leave the small model's capability unchanged, so attainable savings remain bounded by the work the student can already solve. MERA instead improves the small model itself, using a single model invocation as the unit of adaptation. In each cycle, MERA replays failed student invocations to obtain execution-verified teacher demonstrations, distills recurring procedures into an iteratively updated SkillBook, and fine-tunes a student LoRA adapter via supervised learning and optional GRPO. Routing serves as supporting machinery for deployment: the improved student is served behind a cost-calibrated router with verifier-backed fallback, and a candidate SkillBook, adapter, or router is admitted only when joint replay preserves task quality. Empirically, four-cycle adaptation raises Qwen2.5-Coder-1.5B from 28.7% to 49.7% pass on held-out HumanEval+MBPP. Under verifier-backed fallback, the deployed policy retains 88.3% pass at 60.8% of always-Luna cost. On TAU-2, a fine-tuned Qwen3.5-2B improves from 14/35 to 18/35 and matches an unadapted 4B model. These results indicate that verifier-backed multi-cycle adaptation can increase small-model capability, rather than only routing around a fixed student.

# MERA论文详细总结

## 1. 核心问题与研究背景
- 背景：大规模大语言模型智能体处理单个任务时，需要执行异质序列的模型调用：部分调用需要复杂推理，另一部分是格式化、工具参数构建等结构化简单步骤，全调用大模型推理成本过高，粗粒度任务级路由无法适配步骤间的能力异质性。
- 现有方法缺陷：现有细粒度调用级路由仅将简单调用分配给低成本小模型，不改变小模型本身的固有能力，成本压缩空间被小模型的能力上限严格限制；同时，直接利用在线运行日志更新生产部署的模型策略风险高，可能出现小模型静默失败、适配器性能回退、技能泛化性差等问题，缺乏安全可控的迭代进化机制。

## 2. 提出的方法论
### 核心思想
MERA跳出仅围绕固定能力小模型做路由分流的思路，以**单次模型调用**为适配单元，通过多轮离线迭代直接提升小模型本身的能力，技能库、路由仅作为部署支撑机制，最终在保证任务质量的前提下更大幅度降低推理成本。
### 关键流程
MERA分离运行时部署路径和离线迭代更新路径：
- **运行时部署**：
  1. 输入级路由器仅基于当前调用的序列化prompt，选择强模型/低成本小模型/专用学生模型；技能选择器可对重复出现的结构化步骤分发稳定技能模板。
  2. 模型生成输出后，由验证器检查输出合法性、可执行性等，验证失败则触发回退（fallback）到大模型，所有运行事件记录到日志。
- **离线迭代更新（遵循`Skill→LLM→Router`依赖顺序）**：
  1. 将运行日志规范化为步切片，保留prompt、上下文、验证结果、 fallback信息等所有数据。
  2. 更新SkillBook：统计重复prompt特征的成功失败规律，将稳定可重复的执行流程提炼为外部化技能模板（不缓存答案，仅为小模型提供流程提示）。
  3. 更新小模型LoRA适配器：收集小模型调用失败的难例，重放后获取大教师模型生成的、经执行验证的正确演示，对小模型LoRA做微调，支持两种方案：纯监督微调（SFT）、SFT+GRPO强化学习。
  4. 更新路由器：基于当前轮次SkillBook和小模型的实际执行结果生成训练标签（能通过验证则标记为小模型可处理，否则标记为需要大模型），训练路由器。
  5. 联合重放准入验证：仅当更新后的整体策略（Skill+适配器+路由器）在重放中能保持任务质量、降低推理成本时，才会被准入生产部署，否则废弃本次更新。

## 7. 优点
1. 思路创新：跳出了仅做路由分流的传统框架，通过迭代进化直接提升小模型能力，从根源上扩大了成本下降空间。
2. 部署安全：设计了保守的联合重放进城机制，所有更新必须验证端到端质量才能准入生产，避免了静默失败和性能回退，适合大规模生产智能体。
3. 训练设计合理：遵循依赖顺序安排更新调度，避免了 stale 数据带来的训练偏差。
4. 实验设计严谨：明确区分不同模块的贡献，不会混淆小模型本身能力和路由fallback的效果，核心实验做多种子重复保证可靠性。

## 8. 不足与局限
1. 方法依赖验证器质量：如果验证器无法捕捉关键语义错误，会错误放行不安全的降配，带来质量风险。
2. 收益释放较慢：当前设计偏向简单可验证的窄步骤，复杂长范围推理长期留在大模型，成本节省的释放速度较慢。
3. 实验覆盖不足：核心结论仅在代码生成场景得到充分验证，TAU-2工具场景样本量小、统计效力不足，缺乏更多跨领域大样本验证。
4. 重放验证存在偏差：无法完全捕捉更新运行策略后带来的输入分布偏移，重放结果和实际在线运行结果可能存在偏差。
5. 前置路由器精度不足：大部分质量保障依赖后置验证回退，前置路由的精准度较低。
6. 适用场景受限：对于高度非平稳、重复步骤少的任务，技能提炼带来的收益非常有限。
