## 摘要
随着代码智能体越来越多地承担实现任务，核心挑战已从构建单个智能体转向构建能够系统性改进智能体的基础设施。现有方法要么在优化智能体系统时不积累可迁移知识，要么积累知识却不对其开展组合推理，且缺乏让知识依托运行证据实现自进化的机制。MEGA（Meta Evaluation-Grounded Adaptation，基于元评估的适配）作为一种自进化基础设施解决了上述缺口：每个优化周期都会生成持久资产，对这些资产的组合推理可指导后续优化，运行证据会同时精炼已积累的智慧以及支配智慧的推理过程。第一层通过行为模式聚类与经验A/B验证从智能体会话中提炼可复用智慧，将每个处理过程转化为持久资产。第二层将这些资产分解为带类型的智慧图中的原子化PCR（Primary-Context-Resultant，主项-上下文-结果）单元，通过演绎推理、溯因推理和归纳推理扩展隐式关系；随后通过组合检索组装适配特定上下文的执行计划，该检索能够挖掘仅靠嵌入相似度无法获取的桥接知识。第三层针对异构智能体工作流（代码节点、大语言模型调用、工具使用智能体）开展多智能体协同优化，通过消除数据方差的控制评估将性能提升效果归因于具体的策略变更。从第三层反馈的证据推动支配智慧组合的遴选策略以及多轮运行积累的优化轨迹共同实现自进化。最终得到的基础设施中，优化智能体系统与进化指导优化的知识是同一个过程。

## Abstract
As coding agents increasingly handle implementation, the central challenge shifts from building individual agents to building an infrastructure that systematically improves them. Current approaches optimize agent systems without accumulating transferable knowledge, accumulate knowledge without compositional reasoning over it, and lack a mechanism for that knowledge to self-evolve through operational evidence. MEGA (Meta Evaluation-Grounded Adaptation) addresses these gaps as a self-evolving infrastructure: each optimization cycle produces durable assets, compositional reasoning over those assets guides subsequent optimization, and operational evidence refines both the accumulated wisdom and the reasoning that governs it. Layer 1 distills reusable wisdom from agent sessions through behavioral-pattern clustering and empirical A/B validation, transforming each process into a durable asset. Layer 2 decomposes these assets into atomic PCR (Primary-Context-Resultant) units within a typed Wisdom Graph and performs deductive, abductive, and inductive reasoning to expand implicit relations; it then assembles context-specific execution plans through compositional retrieval that surfaces bridging knowledge unreachable by embedding similarity alone. Layer 3 performs multi-agent collaborative optimization over heterogeneous agent workflows (code nodes, LLM calls, and tool-using agents), attributing improvement effects to specific strategy changes through controlled evaluation that eliminates data variance. Evidence fed back from Layer 3 drives the self-evolution of both the curation strategies that govern wisdom composition and the optimization trajectories accumulated across runs. The result is an infrastructure in which optimizing an agent system and evolving the knowledge that guides optimization are one and the same process.

## 2. 提出的方法论
### 核心思想
MEGA（Meta Evaluation-Grounded Adaptation）是一种自进化智能体优化基础设施，通过三层闭环架构实现：优化智能体系统的同时，持续进化指导优化的知识，让优化和知识进化成为同一个过程，跨项目积累的知识可缓解新项目冷启动问题。

### 关键技术细节
#### 核心基础概念
- 四类智慧：一共沉淀四类可复用知识：技能（可复用流程知识）、策略（决策规则）、遴选模式（特定上下文下的有效组合方式）、优化轨迹（成功/失败的优化路径），所有知识统一表示为原子PCR三元组。
- PCR三元组：每个原子单元为`(Primary(核心动作), Context(应用条件), Resultant(预期结果), 实现细节)`，智慧图的边带`充分性/必要性`双评分，节点支持角色流动（同一概念可在不同三元组中担任不同角色）。
- 整体闭环：外层自进化周期满足 $W(t) = L_1(T(t) \cup T_3(t-1)), \Pi(t) = L_2(W(t), E(t-1)), E(t), T_3(t) = L_3(\Pi(t))$，即上一轮优化输出的证据和会话会驱动下一轮的知识更新。

#### 三层架构流程
1. **Layer 1：基于会话的智慧生成**：从原始智能体会话中蒸馏验证可复用智慧
   - 流程：客户端隐私脱敏过滤→两阶段聚类（预聚类划分领域，BIRCH聚类自适应发现行为模式，单趟O(n)处理效率高，无需预设聚类数量）→LLM合成结构化知识→结构过滤（去重、冲突解决）→行为A/B验证（对比加入知识的处理组和无知识的对照组，同时验证性能提升和token效率，仅通过验证的知识进入下层）

2. **Layer 2：智慧推理与遴选**：基于智慧图做组合推理生成上下文专属执行计划，同时驱动知识自进化
   - 知识分解：将输入智慧资产分解为原子PCR单元，构建带类型的智慧图
   - 多模式推理：通过演绎推理（传递因果推理，长程推理自动做得分衰减抑制假阳性）、溯因推理（反向推理发现未显式记录的前置条件）、归纳推理（统计检验发现隐式共现关系），迭代扩展隐式边直到收敛
   - 组合检索：基于奖收集斯坦纳树（PCST）做组合检索，能挖掘到仅靠嵌入相似度无法发现的桥接知识，最终将检索得到的子图转换为分角色的执行计划（不是简单的top-k列表，区分立即执行、前置条件、失败回退等不同角色）
   - 自进化与图维护：基于ROI做智慧评分校准，通过归因反馈从个体、组合、内容三个层面迭代更新知识，定期做图卫生维护（去重、冲突解决、过时内容更新）

3. **Layer 3：评估驱动的多智能体优化**：优化异构智能体工作流，生成可归因的优化证据反馈闭环
   - 优化范围：不局限于prompt优化，支持同时优化异构工作流的所有组件，包括代码节点、LLM调用、工具使用智能体的prompt、工具配置、代码逻辑、编排结构
   - Seed-Epoch归因机制：每个优化epoch固定随机种子采样评估集，同epoch内所有迭代用同一个评估集，消除数据方差，性能变化可准确归因到策略变更；epoch饱和后换种子进入下一阶段，自动验证过拟合
   - 优化流程：资产扫描→适配入口（根据已有资产跳过已完成阶段）→缺评估数据则自动合成匹配的评估集→多智能体分工协作优化（不同代理负责错误诊断、代码验证、架构重构等任务）→优化完成后元学习代理提取优化轨迹和评估证据，反馈给Layer 2更新智慧图，完成闭环
