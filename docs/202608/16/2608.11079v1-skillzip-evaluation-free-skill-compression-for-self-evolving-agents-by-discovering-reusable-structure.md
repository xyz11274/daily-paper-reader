## 摘要
自进化智能体通过追加成功流程与失败修复积累可复用技能。随着时间推移，同一需求常会在多个分支、示例和警告中被重复表述，常见动作序列被复制而非复用，导致最终得到的技能注入成本高且难以维护。通用提示压缩并不适用于该场景，因为技能并非一段无结构文本：技能的名称和描述定义其适用场景，工作流控制执行过程，工具与输出契约约束有效性，即使没有采样任务激活稀有例外，这些例外仍可能必不可少。评估引导压缩可以测试这些行为，但会引入轨迹回滚、额外成本，且依赖压缩阶段的评估集。我们提出SkillZip，这是一种无评估方法，通过寻找技能最短的忠实结构化解释完成压缩。核心思路是一次解释、多次引用：在对应适用范围内将重复规则声明一次，将重复动作序列提取为共享流程，仅将差异保留为显式例外。我们将该思路形式化为定义在技能契约和残差之上的带类型最小描述长度目标，要求满足对每个提取触发项、工作流边、工具需求、约束义务和输出字段的严格覆盖约束。该形式化方法提供了简单的共享阈值，通过构造本身保留了独有的稀有规则，并且支持高效局部更新。SkillZip包含两种模式：仅需一次结构化提取调用和确定性优化的单次模式，以及无需重放任务或重新解析完整历史即可集成每次自进化补丁的持续写入式Zip（Zip-on-Write）模式。通过全面实验评估，我们验证了SkillZip在压缩性能、泛化能力和成本开销方面的有效性与优越性。

## Abstract
Self-evolving agents accumulate reusable skills by appending successful procedures and failure fixes. Over time, the same requirement is often restated in several branches, examples, and warnings, while common action sequences are copied rather than reused. The resulting skill becomes expensive to inject and difficult to maintain. Generic prompt compression is ill-suited to this setting because a skill is not a flat passage: its name and description define when it applies, its workflow controls execution, its tool and output contracts constrain validity, and rare exceptions may remain essential even when no sampled task activates them. Evaluation-guided compression can test these behaviors, but it introduces rollouts, cost, and dependence on the compression-time evaluation set. We present SkillZip, an evaluation-free method that compresses a skill by finding its shortest faithful structural explanation. The intuition is explain once, reference many: state a repeated rule once at the scope where it applies, factor a repeated action sequence into a shared procedure, and keep only the differences as explicit exceptions. We formalize this intuition as a typed minimum description-length objective over a skill contract and a residual, subject to a hard coverage constraint for every extracted trigger, workflow edge, tool requirement, obligation, and output field. The formulation provides simple sharing thresholds, preserves unique rare rules by construction, and supports efficient local updates. SkillZip has a one-shot mode with one structured extraction call and deterministic optimization, and a continual Zip-on-Write mode that integrates each self-evolution patch without replaying tasks or reparsing the full history. Through comprehensive experimental evaluations, we demonstrate the effectiveness and superiority of SkillZip in compression performance, generalizability, and cost overhead.

## 1. 核心问题与研究背景
- 自进化智能体通过追加成功流程、失败修复的方式积累可复用技能，属于增量式追加更新而非全局重构，随着进化轮次增加会产生严重的技能膨胀问题：同一规则、动作序列被多次重复复制，即使真正的新需求已经饱和，技能文本长度仍会持续增长，导致上下文占用成本高、执行效率低、维护难度大。
- 现有方案存在明显缺陷：
  - 通用提示压缩针对token重要性或当前查询设计，不契合技能的结构化特性，容易误删虽然稀有但必不可少的例外规则，无法满足技能对未来未知任务的复用需求；
  - 评估引导式压缩（如SkillReducer）需要依赖压缩阶段的任务回滚、评估集验证，不仅压缩成本高，还容易过拟合到压缩时的评估样本，遗漏未被测试到的需求。

## 2. 提出的方法论
### 核心思想
遵循**一次解释、多次引用**的原则，将技能抽象为结构化契约，在不接触下游任务、评估数据的前提下，寻找技能的最短忠实结构化解释：仅在对应作用域声明一次重复规则，将重复动作序列提取为共享过程，只保留差异作为显式例外，通过硬约束保证所有原有需求不丢失。

### 关键技术细节
1. **结构化契约建模**：将输入技能解析为带类型的结构化契约`C = ⟨I, G, T, C, O, E⟩`，其中：
   - `I`是接口（技能名称、适用场景、触发/排除条件）；`G`是工作流（动作、分支、循环、终止条件）；`T`是工具协议（工具名、参数要求、错误处理）；`C`是带作用域的规则（必须/禁止/推荐行为、生效条件）；`O`是输出契约（输出格式、必填字段、验证规则）；`E`是支撑证据（示例、说明，关联到对应契约单元）；
   - 解析置信度不足的内容会被锁入残差原样保留，强制要求压缩后的表示必须覆盖所有提取出的必需契约单元，从构造上避免内容丢失。
2. **带约束的最小描述长度目标**：优化目标为寻找可复用单元库`K`和残差`R`，最小化`K`和`R`的总token长度，约束条件为所有必需契约单元都被`(K,R)`覆盖；仅当共享后的总长度小于重复存储的原长度时，才会触发共享合并，避免无意义的抽象。
3. **四类结构化复用规则**：
   - 等价需求合并：同义转述合并为单一规则，差异保留为残差；
   - 跨作用域规则提升：被多个子分支重复的规则提升到最近公共父作用域，冲突保留为显式例外；
   - 重复工作流抽取：多次出现的动作序列抽取为共享过程，原位置替换为调用；
   - 变体合并：多个带条件的相似规则合并为通用规则+带条件的差异例外。
4. **两种运行模式**：
   - **One-Shot单次压缩**：流程为扫描原技能文本→提取结构化契约→生成可复用候选→选择最短覆盖方案→渲染输出→结构审计（补全缺失内容），适用于对已进化完成的技能做一次性压缩；
   - **Zip-on-Write持续增量压缩**：适配自进化的增量更新流程，存储当前压缩后的契约元数据，每次新补丁仅在 affected 局部作用域做优化，分为吸收（无新内容）、细化（给现有单元加约束）、扩展（新增需求）、重构（触发新共享）四种操作，累积到阈值后再做全局重打包，无需重放历史任务、重解析全量历史，效率极高。

## 6. 主要结论与发现
1. 自进化确实会产生严重技能膨胀：平均5轮进化后，技能长度达到初始长度的5.2倍，压缩是自进化agent的必要需求；
2. SkillZip压缩效果显著：平均压缩率达到31.2%，远高于SkillReducer的9.2%，同时保留甚至提升了任务性能，平均任务得分0.577，高于未压缩技能的0.570和SkillReducer的0.544；
3. 压缩效率大幅提升：相比SkillReducer平均获得3.5倍端到端速度提升，且不需要任何任务回滚，额外开销极低；
4. 跨模型泛化能力更好：压缩后的技能保留了完整的显式规则和约束，跨模型转移的性能保留率达到0.97，高于SkillReducer的0.91；
5. Zip-on-Write持续压缩效果验证：从进化第一轮就启动持续压缩，可以将技能长度始终控制在初始长度的1.6-1.9倍，相比无压缩降低38%-50%的长度，且不损失任务精度；晚启动压缩只能部分消除已累积的冗余，效果远不如早启动。

## 7. 方法与实验的亮点
1. 无评估设计从根源上避免了对评估集的依赖，既降低了压缩成本，又避免了过拟合风险，通过硬覆盖约束天生保证了稀有规则的保留，不依赖触发频率；
2. 针对自进化技能的冗余特点（知识密度高、冗余为重复结构而非无关内容）做针对性优化，比通用压缩、现有技能压缩更适配该场景；
3. 同时支持一次性压缩和增量持续压缩两种模式，适配不同使用需求，增量模式的局部更新设计效率很高；
4. 输出为普通可读文本技能，可检查、可版本控制，兼容现有agent架构，不依赖特定模型；
5. 实验设计严谨，变量控制严格，结论可靠。

## 8. 不足与局限
1. 压缩保真度依赖初始结构化解析的准确性，解析不确定的内容只能原样保留，可能导致压缩不充分，方法本身不修正原技能的错误，仅整理结构；
2. 保存保证仅针对解析出的契约单元，无法保证压缩后的技能和原技能对任意大模型的行为完全一致，没有解决自然语言本身的歧义问题；
3. 未在百轮以上的超大规模长期自进化场景验证方法的扩展性；
4. 目前仅验证了工具使用、推理、表格处理三类任务，尚未在开放域对话、具身机器人等其他类型技能场景验证通用性。
