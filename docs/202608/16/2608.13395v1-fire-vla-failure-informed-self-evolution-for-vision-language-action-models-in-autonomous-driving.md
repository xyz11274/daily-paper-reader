## 摘要
强化学习通过评估从当前策略采样得到的轨迹优化自动驾驶视觉-语言-动作（VLA）模型。分组相对策略优化（GRPO）从每个轨迹展开组内的奖励差异中学习。当所有采样轨迹性能都较差时，这种相对信号仅能对故障排序，无法识别故障区域外的合理行为。本文提出FIRE-VLA，这是一种故障感知自进化框架，可将这类未解决的故障转化为下一策略的特权监督信号。低奖励、低多样性的展开组会触发从同一模型的冻结轮次初始副本进行自蒸馏。教师模型与学生模型参数规模相同，但仅教师模型可观测隐藏的未来轨迹。监督过程跟随学生生成的前缀，且仅约束答案令牌，同时GRPO对所有组保持激活。更新后的策略作为下一轮的教师模型，使得故障分布的路由可随策略动态变化，无需引入规模更大的外部教师模型。从相同的Qwen2.5-VL-3B SFT checkpoint出发，对比实验匹配了学生轨迹展开与策略更新的次数。在来自150个留存nuScenes场景的6019个样本上，FIRE-VLA保持了相当的单样本规划性能，将G=4的平均L2误差从1.848米降至1.500米，将评估持续故障发生率从13.03%降至11.20%。平均误差的降低主要源于减少了罕见的严重轨迹展开故障，而非普通轨迹上的均匀性能提升。

## Abstract
Reinforcement learning improves autonomous-driving vision-language-action (VLA) models by evaluating trajectories sampled from the current policy. Group relative policy optimization (GRPO) learns from reward differences within each rollout group. When all sampled trajectories are poor, this relative signal can rank failures without identifying behavior outside the failed region. We introduce FIRE-VLA, a failure-informed self-evolution framework that converts such unresolved failures into privileged supervision for the next policy. Low-reward, low-diversity groups trigger self-distillation from a frozen round-start copy of the same model. Teacher and student have the same parameter scale, but only the teacher observes the hidden future trajectory. Supervision follows the student's generated prefix and is restricted to answer tokens, while GRPO remains active for every group. The updated policy supplies the teacher for the next round, allowing the routed failure distribution to change with the policy without requiring a larger external teacher. Starting from the same Qwen2.5-VL-3B SFT checkpoint, the comparison matches student rollout and policy-update counts. On 6,019 examples from 150 held-out nuScenes scenes, FIRE-VLA retains comparable single-sample planning, reduces G=4 mean L2 from 1.848 to 1.500 m, and lowers evaluation-persistent failure prevalence from 13.03% to 11.20%. The reduction in mean error arises mainly from rare severe rollouts rather than uniform improvement across ordinary trajectories.

# 论文详细总结
## 1. 核心问题与研究背景
- 背景：当前自动驾驶领域的视觉-语言-动作（VLA）模型常使用分组相对策略优化（GRPO）做强化学习后训练，GRPO依靠同一rollout组内的轨迹奖励差异生成学习信号。
- 核心问题：当某一组内所有采样轨迹都表现较差时，GRPO仅能对组内失败轨迹排序，无法引导模型找到失败区域外的合理行为；现有解决方案需要引入规模更大的外部教师模型，额外成本较高。

## 2. 提出的方法论
### 核心思想
提出FIRE-VLA故障感知自进化框架，将GRPO无法解决的全失败组故障转化为特权监督信号，通过同规模模型自蒸馏实现自进化，无需引入更大的外部教师，故障监督分布可随策略更新动态调整。
### 关键流程
1. **失败感知路由**：对当前策略生成的每组on-policy rollout，计算三个统计量：组内平均奖励、奖励标准差、有效轨迹占比。若满足「平均奖励低于批量30百分位数 + 奖励标准差低于批量30百分位数 + 有效占比≥0.5」，则判定为**未解决失败组**。普通组仅用GRPO更新，失败组额外增加特权自蒸馏（PSD）损失，GRPO对所有组保持激活。
2. **师生上下文构建**：师生模型初始参数完全相同（同规模），教师模型冻结不更新，仅学生模型可训练；两者共享学生生成的前缀，只有教师能观测到隐藏的真实未来轨迹，学生无法接触特权信息。
3. **on-policy答案令牌蒸馏**：仅对轨迹答案区域的令牌做监督，用JS散度对齐学生和教师的输出分布；为降低计算量，仅保留教师输出的top16令牌加1个残差尾桶做分布计算，且对单个令牌的散度做截断，最终得到平均PSD损失。
4. **策略更新与自进化**：总损失为 `总损失 = GRPO损失 + 0.1 × PSD损失`；更新得到的新策略会作为下一轮的教师模型，下一轮的失败分布也会跟随新策略动态调整，形成自进化循环。

## 6. 主要结论与发现
1. FIRE-VLA的单样本规划性能和标准GRPO相当，差异无统计显著性。
2. 在G=4随机rollout设置下，FIRE-VLA将平均L2误差从1.848m降至1.500m，评估持续失败率从13.03%降至11.20%，误差超过10m的严重错误率从1.35%降至0.83%，提升显著。
3. 平均误差的降低主要来自抑制罕见的严重rollout错误，并非在所有普通轨迹上实现均匀提升，标准GRPO在普通误差区间的表现反而更优。
4. 该方法可随策略更新动态调整需要监督的失败区域，不需要引入额外的大尺寸外部教师模型。

## 7. 方法与实验亮点
1. 精准抓住了GRPO优化中全失败分组的信息缺陷，问题定义清晰。
2. 采用同规模自蒸馏方案，不需要引入更大的外部教师，降低了额外成本。
3. 仅对未解决失败组增加额外监督，保留了GRPO对普通分组的原有学习信号，不干扰正常优化过程。
4. 采用轮次更新机制，让失败监督分布动态匹配当前策略的失败情况，适配性更强。
5. 实验设计控制了核心变量，统计分析采用场景聚类的bootstrap置信区间，结论严谨。

## 8. 不足与局限
1. 仅做了单训练种子的实验，未测量训练种子带来的性能波动，结论的稳健性待验证。
2. FIRE-VLA额外增加了教师前向计算量，和GRPO的对比不是等算力对比，性能提升包含额外算力的贡献。
3. 未开展模块消融实验，无法拆分失败路由、特权自蒸馏、轮次进化三个模块的单独贡献。
4. 仅测试了两轮自进化，无法证明增加更多轮次能否带来持续提升。
5. 实验为开环轨迹预测评估，未测试闭环自动驾驶的安全性、舒适性、合规性等实际应用指标，实际工程价值有待验证。
6. FIRE-VLA两轮训练使用不相交的提示子集，没有纵向追踪同一提示的改进过程。
