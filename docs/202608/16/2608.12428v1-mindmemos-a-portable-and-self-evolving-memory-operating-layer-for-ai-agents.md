## 摘要
记忆是AI智能体的核心组件，能够支撑智能体积累经验、维持个性化，并在长期交互中实现自适应。然而现有记忆系统在开发完成后通常保持固定，限制了其通过持续使用调整自身记忆模型、组织策略与过程性知识的能力。我们提出MindMemOS，这是一个可移植的自进化记忆运行层，采用统一的实体属性时间结构组织开放世界信息。MindMemOS支持场景自适应记忆建模、高阶模式发现、自主记忆优化与持续技能进化。其MindMemEvolve算法采用验证驱动的进化搜索，针对目标场景优化记忆模式，而梦境机制通过合并冗余记录、解决冲突整合已积累的记忆。此外，隐式修正反馈可作为人在回路信号，识别并修正可能不准确或存在对齐偏差的记忆。其MindSkillEvolve算法进一步将智能体执行轨迹转化为可复用、逐步精细化的技能。MindMemOS在LOCOMO上取得94.03%的准确率，在PersonaMem上取得70.63%的准确率。与初始技能基线相比，MindSkillEvolve将SpreadsheetBench的成功率提升了9.2个百分点。

## Abstract
Memory is a core component of AI agents, enabling them to accumulate experience, maintain personalization, and adapt over long-term interactions. However, existing memory systems often remain fixed after development, limiting their ability to adapt their memory models, organization strategies, and procedural knowledge through continued use. We present MindMemOS, a portable and self-evolving memory operating layer that organizes open-world information using a unified entity property timestructure. MindMemOS supports scenario-adaptive memory modeling, higher-order pattern discovery, autonomous memory refinement, and continuous skill evolution. Its MindMemEvolve algorithm employs validation-driven evolutionary search to optimize memory schemas for target scenarios, whiledreaming consolidates accumulated memories by merging redundant records and resolving conflicts. In addition, implicit corrective feedback serves as a human-in-the-loop signal for identifying and revising potentially inaccurate or misaligned memories. Its MindSkillEvolve algorithm further transforms agent execution trajectories into reusable and progressively refined skills. MindMemOS achieves 94.03% accuracy on LOCOMO and 70.63% on PersonaMem. MindSkillEvolve improves SpreadsheetBench success by 9.2 percentage points over the initial-skill baseline.

## 1. 核心问题与研究背景
- 背景：基于大语言模型的AI智能体越来越多地应用于长周期知识密集型任务，需要长期记忆存储用户偏好、已有知识、任务经验，突破上下文窗口限制，支撑个性化与知识复用。
- 现有研究缺陷：参数化记忆依赖特定模型架构，可移植性差；外部记忆系统的结构、提取策略、组织方式在部署后固定不变，带来三大核心问题：
  1. 手动设计的记忆schema适配特定场景，换域改造成本高，无结构化schema的表示又不支持细粒度推理
  2. 持续积累的记忆存在冗余、过时、冲突，缺乏系统性的离线维护机制
  3. 记忆内容和过程技能分离管理，无法将积累的执行经验转化为可复用、持续优化的智能体能力
- 核心问题：解决现有AI智能体记忆系统部署后缺乏自适应性，无法支撑长期交互持续进化的问题。

## 2. 提出的方法论
### 核心思想
提出一个可移植的自进化记忆运行层MindMemOS，采用统一的**实体-属性-时间**三维结构组织开放世界信息，分层架构解耦智能体集成、记忆算法与存储结构，支持从记忆建模、检索、维护到schema优化、技能进化的全生命周期自主进化，可灵活适配不同大模型与智能体框架。

### 关键技术细节
1. **三维统一记忆结构**
   - 实体维度：作为记忆的主体锚点，支持人、组织、事件等各类主体，存储实体间语义关系
   - 属性维度：描述实体的特征，不固定为通用schema，可随目标场景自适应调整，分为一阶显式事实（来自单观测）和高阶模式（来自多观测合成）
   - 时间维度：绑定信息的有效时间，同实体-属性对的记录按时间线排列，保留历史版本不直接覆盖，支持信息更新的可追溯
2. **两种记忆添加策略**
   - MindVanilla：面向无预定义schema的开放域场景，自动处理对话文本，分块提取记忆，去重分类后存储，支持快速记忆录入
   - MindSchema：面向场景化任务，在预定义/自动进化的schema引导下，经过片段分割、记忆生成、实体融合、图合并四步生成结构化记忆图
3. **紧凑型混合双向检索**
   - 结合BM25稀疏词法匹配与嵌入稠密语义匹配，用RRF融合结果
   - 支持正向（先检索实体再匹配对应属性）和反向（先检索属性再关联对应实体）双向遍历，由LLM做迭代检索规划，限制遍历范围仅保留任务相关关联，避免图规模爆炸
4. **全链路自进化机制**
   - **Dreaming（离线梦境整合）**: 离线阶段以最近新增记忆为种子，按实体聚类构建整合范围，检测冗余、冲突、碎片化问题，生成非破坏性的更新方案（合并、归档过时、添加关系），保留操作溯源，在解决冲突的同时压缩活跃记忆规模
   - **反馈驱动记忆修正**: 同时支持显式反馈（用户直接修改记忆）和隐式反馈（从用户对智能体任务输出的修正中提取记忆更新信号），将反馈按持久性分为任务临时、场景特定、长期三类，避免将临时任务修正错误存入长期记忆
   - **MindMemEvolve（记忆schema自进化）**: 以验证集问答准确率为优化目标，采用LLM引导的进化搜索算法优化schema：初始化种群后，每轮评估个体适应度，保留精英个体，通过错误诱导变异（基于错误信号针对性修改schema）、随机探索变异、交叉操作产生后代，多轮迭代后选择最优schema；变异由LLM基于领域知识引导，而非纯随机搜索
   - **MindSkillEvolve（轨迹驱动技能进化）**: 维护云边协同的版本化技能注册表，自动将智能体执行轨迹绑定到对应技能版本，积累足够轨迹后，分析轨迹中的成功策略和重复失败模式，生成技能更新；分为无监督（仅用轨迹信息）和有监督（加入任务得分作为监督信号，强化高成功轨迹的行为）两种变体
