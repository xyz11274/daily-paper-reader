## 摘要
随着编码智能体越来越多地承担实现任务，核心挑战已从构建单个智能体转向构建可系统性改进智能体的基础设施。现有方法要么优化智能体系统时不积累可迁移知识，要么积累知识后不对其开展组合推理，且缺乏让知识通过运行证据实现自进化的机制。MEGA（基于元评估的适配，Meta Evaluation-Grounded Adaptation）作为一种自进化基础设施解决了这些缺口：每个优化周期都会生成持久化资产，对这些资产的组合推理可指导后续优化，而运行证据会同时细化已积累的智慧以及支配该智慧的推理过程。第一层通过行为模式聚类和实证A/B验证从智能体会话中提炼可复用智慧，将每个过程转化为持久化资产。第二层将这些资产分解为带类型智慧图中的原子PCR（原-上下文-果，Primary-Context-Resultant）单元，执行演绎、溯因和归纳推理以扩展隐式关系；随后通过组合检索组装特定上下文的执行计划，该检索可挖掘出仅通过嵌入相似度无法获得的桥接知识。第三层对异构智能体工作流（代码节点、大语言模型调用、工具使用智能体）开展多智能体协同优化，通过消除数据方差的控制评估将改进效果归因于具体的策略变更。从第三层反馈的证据会推动支配智慧组合的管控策略和多轮运行积累的优化轨迹同时实现自进化。最终得到的该基础设施中，优化智能体系统与演化指导优化的知识是同一过程。

## Abstract
As coding agents increasingly handle implementation, the central challenge shifts from building individual agents to building an infrastructure that systematically improves them. Current approaches optimize agent systems without accumulating transferable knowledge, accumulate knowledge without compositional reasoning over it, and lack a mechanism for that knowledge to self-evolve through operational evidence. MEGA (Meta Evaluation-Grounded Adaptation) addresses these gaps as a self-evolving infrastructure: each optimization cycle produces durable assets, compositional reasoning over those assets guides subsequent optimization, and operational evidence refines both the accumulated wisdom and the reasoning that governs it. Layer 1 distills reusable wisdom from agent sessions through behavioral-pattern clustering and empirical A/B validation, transforming each process into a durable asset. Layer 2 decomposes these assets into atomic PCR (Primary-Context-Resultant) units within a typed Wisdom Graph and performs deductive, abductive, and inductive reasoning to expand implicit relations; it then assembles context-specific execution plans through compositional retrieval that surfaces bridging knowledge unreachable by embedding similarity alone. Layer 3 performs multi-agent collaborative optimization over heterogeneous agent workflows (code nodes, LLM calls, and tool-using agents), attributing improvement effects to specific strategy changes through controlled evaluation that eliminates data variance. Evidence fed back from Layer 3 drives the self-evolution of both the curation strategies that govern wisdom composition and the optimization trajectories accumulated across runs. The result is an infrastructure in which optimizing an agent system and evolving the knowledge that guides optimization are one and the same process.

# 提出的方法论
## 核心思想
MEGA（Meta Evaluation-Grounded Adaptation）是一套自进化智能体优化基础设施，通过三层闭环架构统一知识积累、组合推理、证据驱动自进化过程，实现「优化目标智能体」和「进化指导优化的知识」同步完成，让优化能力随使用持续复合提升。

## 关键技术细节
MEGA整体是自强化的三层循环结构，每层核心功能如下：
1. **第一层：基于会话的智慧生成**
   - 输入：原始智能体会话轨迹，输出：经过验证的可复用智慧资产
   - 核心流程：客户端隐私脱敏过滤→两阶段聚类（先预分领域缩小搜索空间，再用BIRCH算法单遍聚类发现行为模式，可自适应生成聚类数，区分同一问题的不同有效解法）→LLM合成结构化智慧+结构过滤（去重、解决冲突）→多阶段质量验证：经过结构过滤、自评估打分、行为A/B验证（处理组注入提炼的知识，对照组不注入，实证测量性能提升和token效率，只有通过验证的智慧才能进入下一层）。
2. **第二层：智慧推理与管控**
   - 核心载体是**类型化智慧图（Wisdom Graph）**：所有智慧资产分为技能、策略、管控模式、优化轨迹四类，都被分解为原子PCR（Primary-Context-Resultant）三元组：Primary代表核心动作，Context代表适用条件，Resultant代表预期结果，附带实现细节；图的边附带充分性、必要性双评分，节点支持角色流动（同一概念可在不同三元组中分别作为动作或条件）。
   - 推理扩展：对PCR图做三类推理扩展隐式关系：演绎（传递因果推理，长距离推理做分数衰减抑制假阳性）、溯因（反向推理发现未被显式记录的前置条件）、归纳（统计检验发现显著共现的隐式关系），迭代推理直到不再产生符合阈值的新边。
   - 组合检索：基于奖收集Steiner树（PCST）做组合检索，以高查询相似度的节点为种子，能自动纳入低相似度但对连接种子必不可少的桥接知识，解决了纯嵌入相似度检索找不到桥接知识的问题；最终将检索子图转换为角色区分的上下文特定执行计划，不同类型的智慧承担不同的执行角色（技能作为执行项、策略作为门控规则等），而非简单返回检索列表。
   - 自进化维护：基于ROI做智慧效用校准，通过证据反馈从个体、组合、内容三个层面更新知识，定期做图卫生维护（去重、冲突解决、过时内容更新），保证智慧图质量随使用提升。
3. **第三层：评估驱动的多智能体优化**
   - 优化范围：支持异构智能体工作流的全栈优化，不止优化prompt，还可优化代码节点、工具配置、编排结构，适配真实复杂智能体系统。
   - 核心机制：
     - 适配流程：自动扫描现有资产，缺少评估数据时自动生成分层的评估数据集，区分数据缺口和工作流问题，只对缺口做针对性数据增强。
     - Seed-Epoch 归因机制：同一epoch内用固定种子的评估集，消除数据方差，可准确将性能变化归因到具体策略变更；迭代饱和后换种子进入新epoch，自动验证泛化性，抑制过拟合。
     - 多智能体分工：不同专用智能体分别负责诊断、修改、审核、元学习，中心优化代理统一决策，保证优化方向清晰。
   - 闭环反馈：优化完成后，将性能证据、优化轨迹结构化反馈回第二层，更新智慧图的知识和评分，为后续项目提供经验。

# 主要结论与发现
1. 在技能编排任务上，MEGA的原子PCR分解+PCST组合检索，比现有整技能编排方法获得更高的任务通过率（46.5% vs SkillNet 41.7%、AgentSkillOS 41.1%），同时token消耗更低、编排延迟更小，单位token效率提升明显。
2. 在端到端优化任务上，MEGA在四个公开基准上全面超过现有SOTA优化方法，总得分达到76.55，比最强基线GEPA高出7.03个百分点，且需要更少的验证数据就能收敛，在需要多跳组合推理的任务（如HoVer）上提升尤为明显（+18%）。
3. 三层闭环设计实现了完整的自进化机制，优化目标智能体和进化指导优化的知识是同一过程，随着跨项目的运行周期积累，新任务的冷启动性能会逐步提升，实现优化能力的复合增长。

# 方法亮点与优点
1. 首次统一解决了现有智能体优化领域的三个核心缺陷，将知识积累、组合推理、证据驱动自进化整合为完整的闭环基础设施。
2. 提出的PCR原子分解、角色流动智慧图、PCST组合检索，有效解决了组合性缺口，能挖掘纯嵌入相似度无法找到的桥接知识，同时减少了上下文冗余，提升了运行效率。
3. 具备元优化特性：优化过程本身产生的经验也会被积累为知识，后续新项目不需要从零开始搜索优化策略，优化能力随使用持续提升。
4. Seed-Epoch归因设计消除了数据方差，多层防过拟合机制保证了优化增益的真实性和泛化性。
5. 支持异构智能体工作流的全栈优化，适配真实世界中混合代码、LLM调用、工具智能体的复杂系统，适用范围更广。

# 不足与局限
