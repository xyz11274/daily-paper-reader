## 摘要
记忆是AI智能体的核心组件，可支撑智能体积累经验、维持个性化，并在长期交互中实现自适应。然而，现有记忆系统在开发完成后通常保持固定，限制了其通过持续使用调整记忆模型、组织策略和过程性知识的能力。本文提出MindMemOS，这是一个可移植的自演进记忆操作层，它采用统一的实体属性时间结构组织开放世界信息。MindMemOS支持场景自适应记忆建模、高阶模式发现、自主记忆精修和技能持续演进。其MindMemEvolve算法采用验证驱动的进化搜索，针对目标场景优化记忆模式，而做梦（dreaming）通过合并冗余记录、解决冲突整合已积累的记忆。此外，隐式校正反馈可作为人在回路信号，用于识别和修正潜在不准确或对齐偏差的记忆。其MindSkillEvolve算法进一步将智能体执行轨迹转换为可复用、逐步精修的技能。MindMemOS在LOCOMO上达到94.03%的准确率，在PersonaMem上达到70.63%。与初始技能基线相比，MindSkillEvolve将SpreadsheetBench的任务成功率提升了9.2个百分点。

## Abstract
Memory is a core component of AI agents, enabling them to accumulate experience, maintain personalization, and adapt over long-term interactions. However, existing memory systems often remain fixed after development, limiting their ability to adapt their memory models, organization strategies, and procedural knowledge through continued use. We present MindMemOS, a portable and self-evolving memory operating layer that organizes open-world information using a unified entity property timestructure. MindMemOS supports scenario-adaptive memory modeling, higher-order pattern discovery, autonomous memory refinement, and continuous skill evolution. Its MindMemEvolve algorithm employs validation-driven evolutionary search to optimize memory schemas for target scenarios, whiledreaming consolidates accumulated memories by merging redundant records and resolving conflicts. In addition, implicit corrective feedback serves as a human-in-the-loop signal for identifying and revising potentially inaccurate or misaligned memories. Its MindSkillEvolve algorithm further transforms agent execution trajectories into reusable and progressively refined skills. MindMemOS achieves 94.03% accuracy on LOCOMO and 70.63% on PersonaMem. MindSkillEvolve improves SpreadsheetBench success by 9.2 percentage points over the initial-skill baseline.

## 1. 核心问题与研究背景
- 背景：基于大语言模型的AI智能体越来越多地应用于长周期知识密集型任务，需要长时记忆存储用户偏好、已有知识、任务经验，弥补上下文窗口容量限制；现有记忆研究分为两类：
  - 参数/隐式记忆：依赖特定模型架构或额外训练，跨模型、跨运行时可移植性差
  - 外部结构化记忆系统：记忆提取规则、结构模式、组织策略在部署后固定，无法自适应调整
- 核心痛点：现有系统存在三个关键缺陷：①手动设计的结构模式更换场景需要大量改造，无结构表示又不支持细粒度推理；②持续累积的记忆存在冗余、过时、冲突，缺乏系统化维护；③记忆内容和过程技能分离管理，无法将执行经验转化为可迭代的可复用技能。
- 研究目标：打造可移植、支持全生命周期自主进化的AI智能体记忆操作层。

## 2. 提出的方法论
### 核心思想
设计分层解耦的可移植记忆操作层，用统一的**实体-属性-时间**三维结构组织信息，支持从记忆建模、检索、维护到技能进化的全流程自主适配，实现AI智能体记忆与能力的持续自演进。

### 关键技术细节
1. **核心三维记忆结构**：沿三个维度组织记忆，支持灵活扩展：
   - 实体维度：作为信息锚点，存储人、组织、事件等主体，记录实体间语义关系
   - 属性维度：描述实体的特定属性，不固定模式，可随场景自适应调整，支持一阶事实和高阶聚合模式两种属性
   - 时间维度：绑定每个记忆的有效时间，同一实体属性对的多条记录按时间组织成时间线，保留历史版本不覆盖
2. **两种记忆添加策略**：
   - `MindVanilla`：针对无预定义模式的开放域场景，自动处理自由文本，做分块、去重、冲突检测，生成扁平记忆记录
   - `MindSchema`：针对场景特定需求，按四步生成结构化记忆：剧集分割→基于当前模式提取实体属性生成记忆子图→实体匹配融合→子图合并入全局记忆图，支持自动合成高阶属性
3. **Compact Search 混合检索**：采用外层LLM检索规划+内层混合检索的分层架构，结合BM25稀疏匹配和嵌入稠密匹配，支持正向（实体→属性）和反向（属性→实体）双向图遍历，限制只遍历任务相关关联，避免全图扩展，兼顾检索覆盖率和效率
4. **四类自进化机制**：
   - `MindMemEvolve`（记忆模式自进化）：以问答任务验证准确率为优化目标，采用LLM引导的进化算法搜索最优场景模式：初始化初始种群→迭代进行适应度评估→保留精英个体，通过误差诱导变异、随机探索变异、交叉产生新种群→最终选择全训练集上准确率最高的模式作为最优结果
   - **Dreaming（离线记忆整合）**：离线处理增量写入产生的冗余冲突，以实体为中心构建处理范围，两步检测问题后生成非破坏性更新方案（合并、归档过时记录、添加关系链接），保留记忆溯源，减少活跃记忆体积
   - **Feedback（人在回路记忆修正）**：支持两种反馈模式，显式反馈接收用户直接对记忆的自然语言修正，隐式反馈从用户对智能体任务输出的校正中提取持久化修正，按持久性分为临时、场景特定、长期三类，避免将临时任务修正错误存入长时记忆
   - `MindSkillEvolve`（技能自进化）：维护版本化技能注册表，收集绑定技能版本的智能体执行轨迹，累积到阈值后批量生成技能改进方案，得到新的技能版本；分为无监督（仅从轨迹提取模式）和有监督（额外加入任务得分做引导）两种变体
