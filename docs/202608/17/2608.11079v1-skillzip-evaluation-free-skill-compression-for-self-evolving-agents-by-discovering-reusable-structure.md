## 摘要
自进化智能体通过追加成功流程与失败修复来积累可复用技能。随着时间推移，同一需求常会在多个分支、示例与警告中被重复描述，公共动作序列被复制而非复用，最终得到的技能不仅注入成本高昂，且难以维护。通用提示压缩并不适配该场景，因为技能并非扁平文本：其名称与描述定义适用场景，工作流控制执行流程，工具与输出契约约束有效性，而罕见异常即使未被任何采样任务激活，仍可能是必不可少的。评估引导式压缩可测试这些行为，但它会引入轨迹回滚、额外成本，且依赖压缩阶段的评估集。我们提出SkillZip，这是一种无评估方法，通过寻找技能最短的可信结构解释实现技能压缩。核心直觉为一次解释、多处引用：在适用作用域内仅声明一次重复规则，将重复动作序列分解为共享流程，仅保留差异作为显式异常。我们将该直觉形式化为作用于技能契约与残差的带类型最小描述长度目标，对每个提取的触发条件、工作流边、工具需求、约束义务与输出字段施加严格覆盖约束。该公式提供简单的共享阈值，通过构造保留唯一的罕见规则，且支持高效局部更新。SkillZip包含单次模式与持续写入时压缩（Zip-on-Write）模式：单次模式仅需一次结构化提取调用与确定性优化，写入时压缩模式可集成每次自进化补丁，无需重放任务或重新解析完整历史。通过全面实验评估，我们验证了SkillZip在压缩性能、泛化性与开销成本方面的有效性与优越性。

## Abstract
Self-evolving agents accumulate reusable skills by appending successful procedures and failure fixes. Over time, the same requirement is often restated in several branches, examples, and warnings, while common action sequences are copied rather than reused. The resulting skill becomes expensive to inject and difficult to maintain. Generic prompt compression is ill-suited to this setting because a skill is not a flat passage: its name and description define when it applies, its workflow controls execution, its tool and output contracts constrain validity, and rare exceptions may remain essential even when no sampled task activates them. Evaluation-guided compression can test these behaviors, but it introduces rollouts, cost, and dependence on the compression-time evaluation set. We present SkillZip, an evaluation-free method that compresses a skill by finding its shortest faithful structural explanation. The intuition is explain once, reference many: state a repeated rule once at the scope where it applies, factor a repeated action sequence into a shared procedure, and keep only the differences as explicit exceptions. We formalize this intuition as a typed minimum description-length objective over a skill contract and a residual, subject to a hard coverage constraint for every extracted trigger, workflow edge, tool requirement, obligation, and output field. The formulation provides simple sharing thresholds, preserves unique rare rules by construction, and supports efficient local updates. SkillZip has a one-shot mode with one structured extraction call and deterministic optimization, and a continual Zip-on-Write mode that integrates each self-evolution patch without replaying tasks or reparsing the full history. Through comprehensive experimental evaluations, we demonstrate the effectiveness and superiority of SkillZip in compression performance, generalizability, and cost overhead.

## 1. 核心问题与研究背景
- 背景：自进化智能体通过追加成功流程、失败修复累积可复用技能，每次更新仅做局部追加，不做全局整理，会导致技能文本持续膨胀：多轮自进化后，技能长度可达初始的5倍以上，新增文本多是重复规则、复制的工作流，而非新增有效知识，会大幅提升每次调用的上下文预填充成本，还会干扰执行逻辑。
- 现有方法缺陷：
  - 通用提示压缩：将技能视为扁平文本，基于查询相关性裁剪token，不匹配技能的结构化特性，且容易误删稀有但关键的异常规则，无法适配面向未来未知任务的可复用技能需求。
  - 评估引导式压缩（如SkillReducer）：依赖压缩阶段的任务回滚、验证，不仅成本高，还依赖压缩时的评估集，容易过拟合，遗漏未被评估集覆盖的关键约束。
- 核心问题：如何在不访问下游任务、执行轨迹、验证器的前提下，对自进化智能体积累的冗余技能做保真压缩，保留所有关键需求同时压缩技能长度。

## 2. 提出的方法论
### 核心思想
核心直觉为**一次解释，多处引用**：将技能建模为带类型的结构化契约，提取重复的共享结构，仅保留差异作为显式异常，在满足所有原需求全覆盖的硬约束下，寻找总长度最短的保真压缩表示。

### 关键技术细节
1. **结构化契约解析**：将原始技能文本解析为结构化契约 `C(S) = ⟨I, G, T, C, O, E⟩`，各部分定义为：
   - `I`（接口）：技能名、用途、触发条件、排除场景
   - `G`（工作流）：动作、顺序、分支、循环、回退、停止条件
   - `T`（工具协议）：工具名、必填参数、前置条件、错误处理
   - `C`（作用域规则）：必须/禁止/建议行为，以及对应作用域、守卫条件
   - `O`（输出契约）：响应类型、必填字段、验证规则
   - `E`（支撑证据）：链接到对应契约元素的示例、说明文本
   解析不确定的文本会被标记为锁定残差，原样保留不修改。
2. **形式化优化目标**：基于最小描述长度（MDL）原则，在「原技能所有提取出的需求单元都被压缩表示覆盖」的硬约束下，最小化共享结构库`K`和残差`R`的总渲染token长度，保证压缩后总长度最短且所有需求都被保留。
3. **四类结构复用规则**（都基于长度成本判断是否执行）：
   - 等价需求合并：相同/近义规则如果共享表示加残差的总长度更短，则合并
   - 跨作用域规则提升：同一规则出现在多个子作用域且所有子作用域都需要时，移到最近公共祖先作用域，仅保留冲突差异为局部异常
   - 重复工作流复用：重复出现的动作序列，只要定义共享流程加多次调用的总长度更短，就提取为共享流程
   - 守卫变体整合：多个带守卫的相似规则，只要「通用核心规则+各守卫异常」的总长度更短，就整合为通用规则加显式异常
4. **两种运行模式**：
   - 单次（One-Shot）压缩：针对已累积完成的膨胀技能，流程为：扫描原文本→提取结构化契约→生成可复用候选→选择满足覆盖约束的最小成本表示→渲染输出→结构审计恢复缺失内容
   - 写入时压缩（Zip-on-Write）：适配自进化的增量更新，新补丁产生后仅在补丁影响的局部作用域做优化，分为吸收（无新需求）、精炼（优化现有规则）、扩展（新增需求）、重构（提取新共享结构）四类操作，满足条件时触发全局重打包，不需要重放历史任务、重新解析全量历史，效率较高。

## 6. 主要结论与发现
- 自进化确实存在技能膨胀问题：多轮进化后技能长度平均达到初始的5.2倍，冗余大量存在，压缩十分必要。
- 压缩性能与保真度更优：SkillZip平均压缩率达到31.2%，远高于SkillReducer的9.2%，同时平均任务得分0.577，高于未压缩技能的0.570和SkillReducer的0.544，压缩后性能没有损失反而略有提升。
- 压缩效率远高于评估引导方法：平均端到端压缩速度是SkillReducer的3.5倍，不需要任何任务回滚，开销更低。
- 跨模型泛化能力更好：压缩后的技能跨不同主干模型迁移时，性能保留率高于SkillReducer，表示更通用。
- 持续压缩可有效控制技能膨胀：从自进化第一轮就激活Zip-on-Write，最终技能长度仅为初始的1.6~1.9倍，远低于无压缩的2.5~3.7倍，且不损失甚至小幅提升最终任务性能，越早激活压缩效果越好。

## 7. 亮点
- 提出无评估压缩框架，完全不依赖压缩阶段的下游任务、验证，避免了评估集过拟合风险，压缩成本更低。
- 硬覆盖约束从构造上保证了稀有规则的保留，不会因为出现频率低被误删，适配可复用技能面向未知任务的需求。
- 同时支持单次压缩已有膨胀技能和增量自进化的持续压缩，适配不同应用场景，增量压缩仅做局部更新，效率高。
- 输出保留了技能的人类可读性，可直接检查、修改、版本管理，适配自进化智能体的迭代需求。
- 实验设计严谨，结论可靠，覆盖了方法的所有核心特性。

## 8. 不足与局限
