## 摘要
基于学习的记忆系统在自进化大语言模型智能体中面临两个紧密耦合的挑战。首先，轨迹索引的效用随交互历史增长，从而将有限的反馈分散到不断扩展的状态空间中。其次，由于轨迹级奖励被共同分配给共同检索的记忆，不相关的经验可能会收到误导性的效用更新，进而陷入记忆-奖励陷阱。为解决这些挑战，我们提出了降阶记忆强化学习（RoMeRL），该方法通过按结果极性和记忆动态分解的固定维度每任务记忆状态来表示不断增长的轨迹索引效用空间。RoMeRL通过一组固定的语义坐标整合新经验，这些坐标的内容随时间更新或替换，从而将反馈集中在有界的效用支持上。理论上，我们证明这种降阶参数化增加了每个效用坐标收到的平均反馈，并在通用坐标转移模型下刻画了错误坐标的稳态占用率。实证上，在ALFWorld和LifelongAgentBench上，RoMeRL提高了任务性能，将Cold-Q比率降低了80.0%，反馈密度提高了约6.0倍，维护的记忆大小减少了84.4%，并将LLM调用减少了21.1%。这些结果表明，降阶效用状态支持高效的自进化智能体记忆，同时限制了持续性的奖励污染。代码可在以下网址获取：https://github.com/YOUNG-fnxm/RoMeRL

## Abstract
Learning-based memory systems for self-evolving LLM agents face two tightly coupled challenges. First, trajectory-indexed utilities grow with the interaction history, thereby dispersing limited feedback over an ever-expanding state space. Second, because trajectory-level rewards are jointly assigned to co-retrieved memories, irrelevant experiences may receive misleading utility updates and consequently enter the memory-reward trap. To address these challenges, we introduce Reduced-Order Memory Reinforcement Learning (RoMeRL), which represents the growing trajectory-indexed utility space using a fixed-dimensional per-task memory state factorized by outcome polarity and memory dynamics. RoMeRL incorporates new experiences through a fixed set of semantic coordinates whose contents are updated or replaced over time, thereby concentrating feedback over a bounded utility support. Theoretically, we show that this reduced-order parameterization increases the average feedback received by each utility coordinate and characterize the steady-state occupancy of erroneous coordinates under a generic coordinate-transition model. Empirically, across ALFWorld and LifelongAgentBench, RoMeRL improves task performance, reduces the Cold-Q ratio by 80.0%, increases feedback density by approximately 6.0 times, reduces the maintained memory size by 84.4%, and cuts LLM calls by 21.1%. These results show that reduced-order utility states support efficient self-evolving agent memory while limiting persistent reward contamination. ## 1. 核心问题与整体含义

- **研究背景**：大语言模型（LLM）智能体本质上是无状态的，难以跨交互积累和复用经验。智能体记忆系统通过存储和检索过往经验来解决这一问题，而近年来的学习型记忆系统进一步将记忆的生成、检索和效用优化纳入端到端学习框架，使记忆系统能随交互经验自我进化，无需更新底层 LLM。
- **核心问题**：现有学习型记忆系统普遍采用**轨迹索引效用**（trajectory-indexed utility）表示方式，即每条存储的轨迹对应一个独立的效用变量。这导致两个紧密耦合的挑战：
  1. **反馈稀释**：随着交互历史增长，效用状态空间不断膨胀，有限的反馈被分散到越来越多的变量上，导致大量记忆缺乏直接更新（冷启动）。
  2. **记忆-奖励陷阱（Memory-Reward Trap, MRT）**：由于轨迹级奖励是共同分配给所有被检索记忆的，弱相关、噪声甚至失败的经验在成功轨迹中出现时，也可能获得正向效用更新，造成奖励错误归因。
- **整体含义**：论文提出通过“降阶”效用状态来解决这一矛盾——在不扩大效用支持空间的前提下提高反馈覆盖密度，从而在保持自进化能力的同时抑制奖励污染。

## 2. 方法论

### 核心思想
- **降阶记忆状态**：将每个任务不断增长的轨迹索引效用空间替换为一个**固定维度（2×2）的每任务状态**，由两个二元因子分解：
  - **结果极性**（Outcome Polarity）：成功（+）与失败（−）；
  - **记忆动态**（Memory Dynamics）：整合型/巩固型（Consolidated, C）与自适应型（Adaptive, A）。
  - 二者笛卡尔积产生四个语义坐标：PCC（Positive Consolidated）、PAC（Positive Adaptive）、NCC（Negative Consolidated）、NAC（Negative Adaptive）。
- **反馈集中**：新经验通过一组固定语义坐标的更新或替换来纳入，坐标内容可变但语义身份固定，从而将有限的反馈集中在有界的效用支持上。

### 关键技术细节
- **四个坐标的定义**：
  - **PCC**：保留全局最有效率的一次成功轨迹（按效率最小化选择），代表稳定可复用的成功模式。
  - **PAC**：保留失败后的首次成功轨迹（按时间顺序选择），代表从失败到成功的恢复模式。
  - **NCC**：保留“高效用失败”经验（效用超过初始阈值的失败中效用最高者），用于保留诊断价值高的失败信息。
  - **NAC**：保留最近一次失败轨迹，用于追踪当前失败状态。
- **检索打分**：结合语义相似度和学习效用：
  \[
  \text{score}(m) = (1-\omega_Q)\cos(e(x_t), e(m)) + \omega_Q Q(m)
  \]
  其中 \(e(\cdot)\) 为嵌入编码器，\(\omega_Q\) 为权重。
- **效用更新**：对检索到的坐标执行标准 Q 更新：
  \[
  Q_{g,t+1} = Q_{g,t} + \alpha \mathbb{1}[m \in S_t](r_t - Q_{g,t})
  \]
  新代表内容继承当前效用作为热启动，后续反馈逐步适应新内容。

### 理论分析（公式与结论）
- **定理1（偏差-方差分解）**：轨迹索引效用估计的均方误差分解为方差项与信用缺口平方项：
  \[
  \mathbb{E}[(\hat{Q}_i - \theta_i)^2] = (v_i^0 + a_i)^2 + \frac{\sigma_i^2}{n_i}
  \]
  表明增加反馈只减小方差，无法消除任务基线 \(v_i^0\) 和观测归因偏差 \(a_i\)。
- **定理2（反馈预算）**：要在维度为 \(N_t\) 的状态上以精度 \(\epsilon\)、置信度 \(1-\delta\) 估计所有原始回报目标，所需反馈和轨迹预算为：
  \[
  F_T = O\left(\frac{N_t}{\epsilon^2}\log\frac{N_t}{\delta}\right), \quad T = O\left(\frac{N_t}{k\epsilon^2}\log\frac{N_t}{\delta}\right)
  \]
  说明全池学习需要随记忆数量增长的反馈。
- **定理3（反馈集中）**：给定交互预算 \(T\)，每个坐标平均收到 \(\bar{n}_d \approx kT/d\) 次更新。固定维度4的状态相比维度 \(N_t\) 的轨迹索引状态，平均反馈增加 \(N_t/4\) 倍，方差从 \(O(\sigma^2 N_t/(kT))\) 降至 \(O(4\sigma^2/(kT))\)。
- **命题1（错误坐标稳态占用）**：在通用“干净–错误”坐标转移模型下，稳态错误比例不超过 \(\gamma/(\gamma+\lambda)\)，期望错误坐标数不超过 \(d\gamma/(\gamma+\lambda)\)。当满足 \(d\gamma/(\gamma+\lambda) < N_t \rho_{\text{full}}\) 时，降阶状态的错误暴露低于全池。

## 6. 主要结论与发现

- **任务性能提升**：RoMeRL 在整体宏观平均成功率上达到 **0.862**，超过最强基线 MemRL 的 0.830，提升 3.2 个百分点。
