## 摘要
大型语言模型可以通过强化学习来改进搜索代理，然而现有的自对弈代理在重复生成任务的同时，会丢弃在成功搜索过程中获得的知识。我们提出了CoEvoKG，一个将知识图谱同时转化为可验证训练任务来源和代理进化的持久证据记忆的框架。CoEvoKG联合训练一个任务生成器和一个搜索代理：生成器从知识图谱中采样的实体链创建多跳问题，而代理则从答案正确性的奖励和实体路径受图证据支持的搜索轨迹中学习。当搜索成功时，CoEvoKG会验证并对检索到的证据进行去重，然后将其写回相应的图节点和边。未来的轮次会重复使用这个丰富的图进行任务生成和奖励计算，从而在模型自我进化与知识积累之间形成闭环。在六个QA基准（NQ、TriviaQA、PopQA、HotpotQA、2WikiMultiHopQA和Bamboogle）上使用三个骨干模型的实验表明，CoEvoKG在Qwen2.5-3B-Instruct、Qwen2.5-7B-Instruct和Llama-3.1-8B-Instruct上的宏平均准确率分别比相应的基础模型提高了+11.2、+10.1和+11.6个百分点。在匹配的训练预算下，CoEvoKG在三个骨干上的宏平均分数进一步比竞争性的自对弈基线和搜索代理的RL基线提高了+2.6至+3.7个百分点。代码可在https://github.com/lazzy1225/CoEvoKG获取。

## Abstract
Large language models can improve with reinforcement learning for search agents, yet existing self play agents repeatedly generate tasks while discarding the knowledge gained during successful searches. We introduce CoEvoKG, a framework that turns a   knowledge graph into both a source of verifiable training tasks and a persistent evidence memory for agent evolution. CoEvoKG jointly trains a task generator and a search agent: the generator creates multihop questions from entity chains sampled   from the knowledge graph, while the agent learns from rewards for answer correctness and search trajectories whose entity paths are supported by graph evidence. When a search succeeds, CoEvoKG verifies and deduplicates the retrieved evidence, then   writes it back to the corresponding graph nodes and edges. Future rounds reuse this enriched graph for task generation and reward computation, closing the loop between model self evolution and knowledge accumulation. Experiments on six QA benchmarks   (NQ, TriviaQA, PopQA, HotpotQA, 2WikiMultiHopQA, and Bamboogle) with three backbone models show that CoEvoKG improves macro average accuracy over the corresponding base models by +11.2, +10.1, and +11.6 points on Qwen2.5-3B-Instruct,   Qwen2.5-7B-Instruct, and Llama-3.1-8B-Instruct, respectively. Under matched training budgets, CoEvoKG further improves over competitive self play baselines and RL baselines for search agents by +2.6 to +3.7 macro average points across the three   backbones. Code is available at https://github.com/lazzy1225/CoEvoKG.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究背景**：可验证奖励的强化学习（RLVR）已成为提升大语言模型推理能力的有效范式，将其扩展到智能体设置（如多轮调用搜索工具获取证据）对知识密集型任务很有前景，但面临两大障碍：
  1. 现有智能体 RL 方法在固定的人类书面 QA 池上训练搜索，奖励验证可行但限制了训练分布，扩展到更难的多跳任务成本高，而无约束的问题生成又会产生模糊、不可回答或琐碎的问题。
  2. 自进化方法让模型生成并解决自己的任务，但循环不稳定：生成任务可能过易、过难或无法验证，存在答案泄漏或证据不足的问题；且求解器获得奖励后，检索到的证据被丢弃，即使成功轨迹中包含支持实体连接和答案的段落。
- **核心问题**：如何让搜索代理在自进化过程中既获得可持续的高质量训练任务，又能积累和复用成功搜索中获取的知识，形成闭环进化。
- **整体含义**：CoEvoKG 将知识图谱（KG）同时用作可验证的多跳任务来源和由求解器验证证据不断丰富的持久外部记忆，使模型自我进化与知识积累形成闭环，在多个 QA 基准上显著提升准确率。

## 2. 提出的方法论

### 2.1 核心思想

- **KG 实体链的双重角色**：知识图谱中的实体链既作为结构化、可验证的多跳任务模板来源，也作为由求解器验证证据不断丰富的外部记忆。
- **联合训练**：任务生成器（proposer）和搜索代理（solver）围绕共享的 KG 链池协同训练，形成"任务生成→求解→验证→证据回写→再生成"的闭环。

### 2.2 关键技术细节

- **任务生成（Task Generation from KG Chains）**：
  - 从基于维基百科的 KILT 知识图谱离线随机游走构建初始链池 G0，每条链为 2–3 跳实体序列，边带类型化自然语言关系标签，节点带文章段落。
  - Proposer 根据链生成问题并选择答案实体（链上任意实体而非仅末端，避免位置泄漏）。
  - 质量门控（Quality Gate）：由 LLM 验证器判断链保真度、多跳需求、单一答案焦点和清晰度，并有硬性"无泄漏"约束（Eq. 6）。
  - 种子回退（Seed Fallback）：无候选通过质量门时用人类书面 QA 种子问题填充，保持批次完整。
- **奖励设计（Rewards for Path Support and Difficulty）**：
  - Solver 奖励（Eq. 7）：Rs = R_ans × (1 + β·S_path)，结合答案正确性和路径支持度，路径支持仅对正确轨迹计入，避免奖励无支持的猜测。
  - 路径支持验证（Eq. 8-9）：从轨迹中提取实体路径 ĉ_τ，与当前证据图进行确定性关系一致性评分（直接得分 M_direct 或一跳桥接 M_bridge），几何平均聚合步骤支持度；任一跳缺乏支持则分数大幅下降，确保每跳可追溯。
  - Proposer 难度奖励（Eq. 10）：基于组内成功率 p_s 计算单峰钟形奖励，目标成功率随训练退火（p⋆(t) 从高到低），鼓励问题落在求解器当前能力边界附近。
- **验证图记忆（Verified Graph Memory）**：
  - 正确且路径受支持的轨迹（R_ans=1 且 S_path ≥ τ_path）在更新后被写回图记忆，按实体序列哈希去重；新序列成为新链，已见序列合并新证据到段落中，推进 G_t → G_{t+1}。
- **优化**：
  - Solver 使用 GRPO（组相对优势，Eq. 11）；Proposer 使用 REINFORCE++（累积折扣回报 + 全局批归一化，Eq. 12）。
  - 两个策略共享相同的 PPO 风格代理目标（带低方差 KL 惩罚），仅优势估计方式不同；另用低概率 token 优势仿射缩放稳定训练。

- **三个骨干模型**：Qwen2.5-3B-Instruct、Qwen2.5-7B-Instruct、Llama-3.1-8B-Instruct。

- CoEvoKG 在宏平均准确率上相对基础模型分别提升 +11.2（30.9→42.1）、+10.1（44.0→54.1）、+11.6（39.8→51.3）点。
- 在匹配训练预算下，CoEvoKG 宏平均优于 Search-R1 和 SSP 基线约 +2.6 至 +3.7 点。
- 多跳和搜索密集型设定上增益尤为显著（如 Bamboogle 提升 +19.2/+11.2/+16.8 点）。
- 训练动态显示 CoEvoKG 初始慢热但持续提升，SSP 中期后退化，Search-R1 早期饱和；链池增长后趋于平台期，种子回退率保持少数，KL 和熵稳定无发散或坍塌。

## 7. 优点

- **任务源与记忆的统一**：将 KG 同时作为验证任务来源和持久证据存储，巧妙解决了可验证任务供给和知识复用的双重难题。
- **质量门控**：硬性"无泄漏"约束 + LLM 验证器，有效抑制了自博弈中常见的答案泄漏和不可回答问题等问题。
- **过程奖励设计**：路径支持评分（几何平均）确保每跳可追溯而非仅端点正确；对正确轨迹才计入过程奖励，避免奖励无依据的合理实体表面匹配。
- **难度退火奖励**：将生成任务约束在求解器当前能力边界，避免过易或过难，且随训练动态调整。
- **证据回写闭环**：验证、去重后回写证据至图记忆，使后续轮次在更丰富的上下文上生成和验证，形成真正的共同进化。
- **实验设计规范**：匹配训练预算的公平对比、构建式消融（而非随机留一）+ 配对显著性检验、外部人工基准评测（而非训练用验证器自评），有效排除了奖励黑客风险。
