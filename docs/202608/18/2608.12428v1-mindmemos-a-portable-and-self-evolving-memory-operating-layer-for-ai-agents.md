## 摘要
记忆是AI智能体的核心组件，能够支持智能体积累经验、维持个性化，并在长期交互中完成自适应。然而现有记忆系统通常在开发完成后保持固定，限制了它们通过持续使用调整自身记忆模型、组织策略和过程性知识的能力。我们提出MindMemOS，这是一个可移植的自进化记忆运行层，它采用统一的实体属性时间结构组织开放世界信息。MindMemOS支持场景自适应记忆建模、高阶模式发现、自主记忆精炼与持续技能进化。其MindMemEvolve算法采用验证驱动的进化搜索为目标场景优化记忆模式，而dreaming通过合并冗余记录、解决冲突来整合已积累的记忆。此外，隐式校正反馈可作为人在回路信号，用于识别和修正潜在不准确或存在对齐偏差的记忆。其MindSkillEvolve算法进一步将智能体执行轨迹转换为可复用、渐进精炼的技能。MindMemOS在LOCOMO上取得94.03%的准确率，在PersonaMem上取得70.63%的准确率。相较于初始技能基线，MindSkillEvolve将SpreadsheetBench的成功率提升了9.2个百分点。

## Abstract
Memory is a core component of AI agents, enabling them to accumulate experience, maintain personalization, and adapt over long-term interactions. However, existing memory systems often remain fixed after development, limiting their ability to adapt their memory models, organization strategies, and procedural knowledge through continued use. We present MindMemOS, a portable and self-evolving memory operating layer that organizes open-world information using a unified entity property timestructure. MindMemOS supports scenario-adaptive memory modeling, higher-order pattern discovery, autonomous memory refinement, and continuous skill evolution. Its MindMemEvolve algorithm employs validation-driven evolutionary search to optimize memory schemas for target scenarios, whiledreaming consolidates accumulated memories by merging redundant records and resolving conflicts. In addition, implicit corrective feedback serves as a human-in-the-loop signal for identifying and revising potentially inaccurate or misaligned memories. Its MindSkillEvolve algorithm further transforms agent execution trajectories into reusable and progressively refined skills. MindMemOS achieves 94.03% accuracy on LOCOMO and 70.63% on PersonaMem. MindSkillEvolve improves SpreadsheetBench success by 9.2 percentage points over the initial-skill baseline.

  - 现有外部记忆系统大多在开发完成后结构、组织策略固定，存在三个核心痛点：

    3. 记忆内容和流程技能分离管理，无法将累积的执行经验转化为可复用、持续进化的技能。
- 核心问题：解决现有AI智能体记忆系统无法在长期使用中自主适配场景、维护记忆质量、进化流程知识的缺陷。

## 2. 提出的方法论
### 核心思想
设计一个可移植的自进化记忆运行层，采用统一的**实体-属性-时间**三维结构组织开放世界信息，支撑记忆从写入、检索、维护到技能进化的全生命周期自主优化，适配不同场景和智能体框架。

### 关键技术细节
1. **核心记忆结构**：三维记忆图结构
   - 实体维度：作为记忆的锚点，对应人、组织、事件等主体，存储实体间语义关系；
   - 属性维度：描述实体的特征，可根据场景自适应调整，分为一阶（单观测的显式事实）和高阶（多观测合成的模式）两类；
   - 时间维度：同一实体-属性对的多条记录按时间形成时间轴，保留历史版本，支持信息演化表示，不直接覆盖旧信息。
2. **两种记忆写入模式**
   - `MindVanilla`：无需预定义schema，直接处理自由文本对话，适合开放域场景，自动做去重、分类存储；
   - `MindSchema`：基于场景适配的schema做结构化提取，自动做对话分段、实体融合、子图合并，支持高阶属性合成。
3. **Compact 检索**：采用LLM代理做检索规划，结合BM25稀疏匹配和嵌入稠密匹配，支持正向（先找实体再找属性）和反向（先找属性再找对应实体）双向图遍历，限制检索范围保证效率，支持细粒度实体匹配增强。
4. **四类自进化机制**
   - `MindMemEvolve`：验证驱动的LLM引导进化搜索算法，以任务问答准确率为优化目标，自动进化适配场景的记忆schema。流程为：初始化初始schema的种群→迭代做单簇适应度评估→保留精英，通过错误诱导变异（基于错误信号针对性修改）、随机探索变异、交叉产生后代→多轮迭代后选出最优schema。
   - **Dreaming离线整合**：针对在线写入产生的冗余、冲突，以实体为中心构建待整合范围，检测冲突、重复等问题，生成非破坏性更新计划，归档过时记忆、合并冗余记录，保留更新溯源，在减少存储的同时解决冲突。
   - **人在回路反馈修正**：分为两类：显式反馈支持用户用自然语言直接修改记忆；隐式反馈从用户对智能体任务的校正中提取信号，自动区分临时任务修正、场景特定修正、长期记忆修正，仅将长期有用的修正存入记忆，避免错误更新。
   - `MindSkillEvolve`轨迹驱动技能进化：支持技能全生命周期版本管理，将智能体执行轨迹绑定到对应技能版本，积累足够轨迹后，分析成功模式和失败规律，生成技能更新，分为无监督（仅用轨迹信息）和有监督（加入任务得分作为监督信号）两种变体。
5. **分层架构设计**：解耦智能体集成、算法、存储三层，可通过API、SDK、插件等方式对接任意第三方智能体框架，保证可移植性。
