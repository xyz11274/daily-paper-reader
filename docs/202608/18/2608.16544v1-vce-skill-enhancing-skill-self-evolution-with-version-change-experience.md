## 摘要
智能体越来越依赖可复用技能来编码任务知识、工具使用流程和验证规则。现有技能自演化方法主要利用从当前任务收集的执行轨迹修订技能，公共技能版本历史中积累的演化知识大多未得到开发利用。我们的初步研究表明，两类知识来源之间存在明确的互补性：公共技能变更提供可复用的演化先验，而轨迹则提供契合当前任务的证据。受此启发，我们提出VCE-Skill，该方法将含噪声、依赖具体实现的公共技能变更提炼为可复用的结构化版本变更经验，并将其与基础演化器输出的轨迹衍生提议自适应融合，从而在利用外部经验的同时保留任务特定证据。大量实验表明，VCE-Skill可提升技能自演化性能，平均得分提升3.20--4.98分；迁移实验进一步证明，所得技能具备更强的跨模型迁移性能。我们的工作指出，公共技能版本变更是一种此前未被充分探索却十分有效的先验知识来源，推进了轨迹驱动的技能自演化研究。

## Abstract
Agents increasingly rely on reusable skills to encode task knowledge, tool-use procedures, and validation rules. Existing skill self-evolution methods primarily revise skills using execution trajectories collected from current tasks, leaving the evolution knowledge accumulated in public skill version histories largely untapped. Our pilot study reveals a clear complementarity between the two sources: public skill changes provide reusable evolution priors, whereas trajectories provide evidence grounded in the current task. Motivated by this, we propose VCE-Skill, which distills noisy and implementation-specific public skill changes into reusable, structured version-change experience and adaptively fuses it with trajectory-derived proposals from the base evolver, thereby exploiting external experience while retaining task-specific evidence. Extensive experiments demonstrate that VCE-Skill improves skill self-evolution, increasing mean scores by 3.20--4.98 points; transfer experiments further show that the resulting skills achieve stronger cross-model transfer performance. Our work highlights public skill version changes as a previously underexplored yet effective source of prior knowledge and advances trajectory-driven skill self-evolution.

## 1. 核心问题与研究背景动机
- 大背景：大语言模型智能体普遍依赖可复用技能包存储任务知识、工具调用流程、验证规则，技能需要持续迭代演化来适配工具更新、任务分布变化。当前主流的技能自演化范式是轨迹驱动，即仅依托当前任务收集的执行轨迹生成技能修订方案。
- 核心问题：轨迹驱动范式受限于当前收集轨迹的质量和覆盖范围，低质量/不完整轨迹会导致演化效果差，还容易过拟合到当前观测，遗漏当前任务未暴露的通用更新知识；而公共技能仓库中积累了大量历史版本变更中隐含的演化知识，该资源此前几乎未被技能自演化研究利用。
- 研究动机：作者初步研究发现，公共版本变更知识和轨迹知识存在明确互补性：公共变更提供可复用的通用演化先验，轨迹提供贴合当前任务的落地证据，因此有必要设计方法整合两类知识提升技能自演化效果。

## 2. 提出的方法论
### 核心思想
将公共技能仓库中嘈杂、和具体实现绑定的版本变更，提炼为结构化可复用的版本变更经验，再和当前轨迹生成的演化提案做自适应融合，同时利用外部通用先验、保留当前任务的特定证据，增强现有轨迹驱动技能自演化的效果。该方法为模块化设计，可适配任意现有轨迹驱动自演化框架。

### 关键技术流程
分为离线经验蒸馏、在线自适应优化两个核心阶段：
1. **离线经验蒸馏阶段**
   - 第一步变更抽象：提取公共技能相邻版本的原始差异，将其拆分转换为结构化更新事件，每个事件包含原始差异片段、影响的技能组件、语义操作、更新意图四个部分。
   - 第二步分层生成经验：将相同属性的更新事件汇总泛化为可复用的更新模式，再将同一技能的所有更新模式合成为技能级演化洞察，最后将同一任务域下多个技能的演化洞察泛化为域级可迁移经验，所有经验结构化存储为经验库，蒸馏过程会移除仓库特定的细节信息，保留通用可迁移的指导。
2. **在线优化带自适应经验注意力阶段**
   - 经验选择：根据当前目标任务、当前待优化技能、上一轮演化的反馈构造查询，从经验库中筛选最多K个最相关的经验，汇总为外部演化指导。
   - 并行生成自提案：基础演化器利用当前技能的执行轨迹，生成基于当前任务证据的自演化提案。
   - 自适应注意力融合：给外部经验指导和自提案分配自适应权重（初始权重均为0.5，权重和为1），融合生成增强演化提案，所有编辑保留来源标签用于后续归因。
   - 应用更新与反馈调整：应用增强提案生成新技能后，根据验证集性能变化和编辑来源归因计算统一反馈：若更新性能提升且更多来自某一来源，则提高该来源的权重，反之降低权重；权重被限制在[0.3, 0.7]区间内，避免完全忽略任意一类知识，进入下一轮迭代。

## 3. 实验设计
- **测试基准/数据集**：共5个覆盖不同任务类型的基准，分别是：SearchQA（开放域检索问答）、OfficeQA（文档/表格数值推理）、ALFWorld（长程具身任务执行）、Spreadsheet（电子表格操作与计算）、BFCL-v4（函数调用与工具选择）。
- **测试模型**：覆盖不同规模和厂商的4个大语言模型：Qwen3.5-27B、GPT-5.2、DeepSeek-v3.2、Claude Sonnet 5。
- **对比基线**：分为五类：
  1. 非演化基线：无技能方案、LLM一次性生成技能方案
  2. 现有自演化基线：EvoSkill、SkillClaw、SkillOpt三种主流方法
  3. 消融实验变体：移除经验蒸馏（直接用原始版本差异做经验）、移除自适应注意力（固定等权重融合）
- **额外实验**：跨模型迁移实验（源模型演化的技能直接迁移到目标模型测试）、超参数敏感性实验、人工审核实验（验证LLM语义决策的可靠性）。

## 6. 主要结论与发现
1. 公共技能版本历史确实包含轨迹驱动自演化未覆盖的有用演化知识，且和轨迹知识存在明确互补性，是有效的未被充分探索的先验知识来源。
2. VCE-Skill可以稳定提升所有测试的现有自演化方法的性能，平均得分提升3.20-4.98分，仅带来约10%的额外token开销，性价比高。
3. 经验蒸馏和自适应注意力两个核心模块都对性能有显著贡献，移除任意模块都会带来明显的性能下降。
4. VCE-Skill演化得到的技能具备更强的跨模型迁移能力，跨模型迁移平均得分提升超过5分，提升幅度高于源模型上的增益。

## 7. 方法与实验的亮点
1. 研究视角创新：首次系统挖掘公共技能版本历史作为技能自演化的先验来源，明确了两类知识的互补性，开辟了技能自演化的新研究方向。
2. 方法设计灵活通用：模块化即插即用设计，不需要修改现有自演化框架的核心逻辑，可适配任意轨迹驱动自演化方法，通用性强。

4. 实用价值突出：不仅提升源模型上的演化效果，还显著提升技能的跨模型迁移能力，更适合多模型部署的实际场景。

## 8. 不足与局限

4. 自适应权重调整采用固定步长的简单更新策略，存在进一步优化的空间。
