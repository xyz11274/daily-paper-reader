## 摘要
随着智能体任务复杂度不断提升，大语言模型（LLM）智能体越来越依赖经验记忆来跨任务复用过程性知识。有效的记忆设计必须共同解决三个核心问题：存储什么内容、记忆如何构建与检索，以及记忆如何进化。现有系统仅部分解决了上述问题：它们将轨迹、洞察或工作流存储为独立条目，丢弃了子任务与可复用技能之间的组合关系；采用忽略关系信号的平面嵌入相似度进行检索；且维护记忆时未利用其关系结构。我们提出HyperSkill，这是一个基于超图的记忆框架，可同时改进上述三个方面。HyperSkill将记忆表示为包含两类节点的超图，即子任务步骤与可复用技能，其中每条超边连接来自单条轨迹的子任务与技能。双路径检索可同时对子任务层级和轨迹层级进行查询，并根据检索到的轨迹中的共现情况对技能排序。周期性的结构感知维护会通过质量加权传播修剪低效用节点并合并冗余技能。在结合GPT-4o与Qwen3-30B-A3B的xBench、GAIA和WebWalkerQA数据集上的实验表明，HyperSkill优于十种记忆基线方法，在GAIA上提升最高达+11.51，在WebWalkerQA上提升最高达+11.18。

## Abstract
As agentic tasks grow in complexity, LLM agents increasingly rely on experiential memory to reuse procedural knowledge across tasks. Effective memory design must jointly address what to store, how memory is structured and retrieved, and how memory evolves. Existing systems tackle each only partially: they store trajectories, insights, or workflows as isolated entries, discarding compositional relationships among subtasks and reusable skills; retrieve by flat embedding similarity that ignores relational signals; and maintain memory without leveraging its relational structure. We propose HyperSkill, a hypergraph-based memory framework that jointly improves all three. HyperSkill represents memory as a hypergraph with two node types, subtask steps and reusable skills, where each hyperedge links the subtasks and skills from a single trajectory. Dual-path retrieval queries both subtask and trajectory levels, ranking skills by co-occurrence across retrieved trajectories. Periodic structure-informed maintenance prunes low-utility nodes and merges redundant skills via quality-weighted propagation. Across xBench, GAIA, and WebWalkerQA with GPT-4o and Qwen3-30B-A3B, HyperSkill outperforms ten memory baselines, yielding gains of up to +11.51 on GAIA and +11.18 on WebWalkerQA.

# 2. 提出的方法论
## 核心思想
利用超图天然支持表示多元关联的特性，将经验记忆组织为包含子任务、技能两类节点的超图，每条超边绑定单条执行轨迹的所有子任务和技能，同时实现结构保留的存储、双路径结构感知检索、结构引导的记忆演化，完整解决记忆设计的三个核心问题。

## 关键技术细节
### 超图记忆结构
- 节点分为两类，所有节点都携带自然语言内容、类型标签和动态效用分数（效用分数结合历史检索的成功率、平均步骤效率动态计算，同时衡量技能/子任务的有效性和效率）：
  - 子任务节点：编码任务分解的单步过程，包含步骤描述和适用前提；
  - 技能节点：从轨迹中提取的可复用执行知识，成功轨迹提取正向执行策略，失败轨迹提取需要避免的错误模式。
- 超边：每条超边对应一条完整执行轨迹，绑定该轨迹用到的所有子任务节点、技能节点，同时包含原任务描述和提炼的可迁移经验教训，超边用「任务描述+经验教训」的拼接文本生成嵌入，用于后续检索。

### 双路径超边检索
针对新任务，从两个互补路径检索相关轨迹，兼顾结构匹配和语义匹配：
- 子任务路径：先将新任务分解为细粒度子任务，匹配存储中最相似的top-k子任务节点，扩展得到所有包含这些子任务的候选超边（轨迹），可以挖掘出任务描述不同但过程结构相似的相关轨迹；
- 轨迹路径：直接用新任务的完整描述匹配超边嵌入，得到top-k语义最相关的候选超边；
- 融合两个路径的候选超边，提取其中的经验教训作为轨迹级上下文提供给智能体。

### 共现排序技能检索
从候选超边的并集得到候选技能集合，不再仅用语义相似度排序，而是统计每个技能在所有候选超边中的共现次数，按共现次数从高到低排序取top-k：共现次数越高说明该技能在多个相关任务中反复使用，可靠性更高，排序相同时用语义相似度打破平局。

### 结构感知的周期性记忆演化
每执行一定数量任务后，对记忆做两轮维护，长期保持记忆的紧凑性和高质量：
- 质量驱动修剪：移除被检索足够多次但效用分数低于阈值的低质量节点，同时从所有关联超边中删除该节点；
- 结构感知技能合并：仅对技能节点做合并，先计算质量加权的共现矩阵（同时考虑两个节点的效用、共现超边的大小，小超边共享的节点相关性更高），再通过质量加权传播得到融合结构信息的技能嵌入，相似度超过阈值的技能对会被LLM合并为一个更高阶的可复用技能，之后重新分配所有超边的所属关系。
