## 摘要
递归自我改进（RSI）要求AI系统能够改进构建AI的过程（即AI4AI）；机器学习工程（MLE）为研究这一能力提供了一个具体且可执行的测试平台。我们推出了OpenMLE，一个用于MLE中RSI研究的开源全栈系统，涵盖带有执行反馈的可验证任务环境（OpenMLE-Gym）、算子学习（OpenMLE-RL）以及长时程搜索（OpenMLE-Evo）。在此栈上，我们将Frontis-MA1（35B）后训练为MLE的元进化智能体，将后训练和推理围绕四个原子程序进化算子（Draft、Improve、Debug、Crossover）对齐：这些算子通过基于执行依据的SFT和RL在针对所有评估基准去重后的数据上进行训练，然后组合成长时程搜索，在单一循环中将学习与进化耦合。在MLE-Bench Lite上，单台RTX 4090（显存上限12 GB）下每个任务12小时的预算内，Frontis-MA1（35B）通过OpenMLE-Evo将奖牌平均值从39.39%提升至60.61%，并通过OpenMLE-Evo-Max（基准无关的经验先验与异步搜索）达到71.21%，超过了GPT-5.5 + Codex，接近GPT-5.6 Sol和2.8T的Kimi K3。在保留的NatureBench Lite上，两个组件均可迁移：当框架固定时，换入训练后的模型将Match-SOTA从50%提升至70%；当模型固定时，换入OpenMLE-Evo将其从20%提升至50%。我们发布模型权重和完整的OpenMLE栈，以支持面向RSI的可执行AI4AI的可复现研究。代码：https://github.com/FrontisAI/OpenRSI

## Abstract
Recursive self-improvement (RSI) requires AI systems that improve the process of building AI (i.e., AI4AI); machine learning engineering (MLE) offers a concrete, executable testbed for studying this capability. We introduce OpenMLE, an open full-stack system for RSI research in MLE, spanning verifiable task environments with execution feedback (OpenMLE-Gym), operator learning (OpenMLE-RL), and long-horizon search (OpenMLE-Evo). On this stack we post-train Frontis-MA1 (35B) as a meta-evolution agent for MLE, aligning post-training and inference around four atomic program-evolution operators (Draft, Improve, Debug, Crossover): the same operators are trained via execution-grounded SFT and RL on data deduplicated against all evaluation benchmarks, then composed into long-horizon search, coupling learning and evolution in a single loop. On MLE-Bench Lite under a 12-hour per-task budget on one RTX 4090 capped at 12 GB VRAM, Frontis-MA1 (35B) improves Medal Average from 39.39% to 60.61% over its base model with OpenMLE-Evo, and reaches 71.21% with OpenMLE-Evo-Max (benchmark-independent experience priors and asynchronous search), exceeding GPT-5.5 + Codex and approaching GPT-5.6 Sol and the 2.8T Kimi K3. On held-out NatureBench Lite, both components transfer: with the framework fixed, swapping in the trained model raises Match-SOTA from 50% to 70%; with the model fixed, swapping in OpenMLE-Evo raises it from 20% to 50%. We release the model weights and the full OpenMLE stack to enable reproducible research on executable AI4AI toward RSI. Code: https://github.com/FrontisAI/OpenRSI

## 1. 核心问题与研究动机

- **宏观背景**：AI能力提升不再仅依赖人类工程师，AI系统正越来越多地参与编写代码、运行实验和构建下一代AI系统，这一方向被称为“AI for AI（AI4AI）”。其终极目标是递归自我改进（Recursive Self-Improvement, RSI），即每个改进后的系统反过来进一步改进产生下一代的流程。
- **核心问题**：实现RSI需要的不只是更强的一次性生成或规划能力，而是能够检查数据、提出算法、执行实验、诊断失败、决定下一步计算投入的智能体。机器学习工程（MLE）是AI4AI的最直接、可量化的载体——智能体需要构建端到端的机器学习方案，并通过执行反馈逐步迭代优化。
- **现有缺口**：虽然已有工作在搜索框架（AIDE、AIRA等）、可执行环境（MLE-Bench、MLGym等）和基于执行反馈的后训练（AceGRPO、MLE-RL等）三条线上推进，但没有任何公开系统**同时**覆盖任务环境构建、执行依据的智能体后训练、长时程进化搜索以及全套可复现组件。论文将此定义为待填补的空白。

## 2. 方法论：OpenMLE 全栈系统

### 2.1 总体框架
- **核心思想**：将训练和推理统一围绕四个原子程序进化算子（**Draft**——生成新代码、**Improve**——改进已有代码、**Debug**——修复故障代码、**Crossover**——融合两个父代码），形成“元进化循环”：同一套算子即用于训练，也用于推理时的搜索组合。
- 三层架构：
  - **OpenMLE-Gym**（环境层）：5,758个质量门控的可执行任务（156个精选锚点 + 3,362个Kaggle数据集任务 + 2,240个Kaggle竞赛任务），提供隔离沙箱执行、六种结构化反馈模式（成功、运行时错误、缺少代码、缺少提交、评分失败、超时）、任务特定评估器。
  - **OpenMLE-RL**（学习层）：执行依据的SFT + RL训练。SFT语料含26,259个示例（并行路径的完整Draft方案17,245个 + 进化路径的轨迹步骤9,014个），采用预算自适应收集（达到示例配额或执行预算即停止）；RL使用自适应奖励边界、熵加权优势（entropic advantage）和异步rollout。
  - **OpenMLE-Evo**（搜索层）：长时程进化搜索，核心创新包括结构化经验卡（每个节点）、任务级经验板、三因子父程序选择（质量+进步+新颖性）以及操作触发式按需记忆合成（滞后生成、有界上下文）。

### 2.2 关键技术细节
- **奖励归一化**：将异质评估指标转为统一方向（越大越好），先使用固定任务边界计算基础奖励，再根据历史对策略分数前沿动态计算自适应边界，避免有意义的分数差异被压缩；公式为 `r_base(s; b_best, b_worst) = clip((s−b_worst)/(b_best−b_worst), 0, 1)^α`。
- **熵加权优势**：通过 leave-one-out softmax 形式 `A_i ≈ exp(βr_i)/((1/(G−1))Σ_{j≠i}exp(βr_j)) − 1`，将更多学习信号集中到每个rollout组的上尾候选，β由固定熵/KL预算二分搜索确定。
- **异步rollout**：生成-执行组独立入队，训练器消费已完成组，消除同步批处理中最慢任务的排队等待（实测平均步时从97.0分钟降至50.8分钟，约1.91×加速）。
- **父程序采样**：训练时结合父奖励、子奖励方差和访问冷却三因子；推理时OpenMLE-Evo用质量/进步/新颖性三因子的 softmax 采样替代纯分数的贪婪选择。
- **记忆机制**：节点经验卡确定性存储 + 经验板聚合 + 仅在算子调用时按需生成LLM总结并缓存；对Improve检索祖辈和同辈信息、对Crossover检索双亲支系、对Debug检索同错误特征历史节点，上下文从平均102.8K字符压缩至35.7K（Improve）且99分位从389K降至54.3K。

### 2.3 数学形式化
- 问题设定：`p_t ~ g_θ(·|τ, a_t, c_t)`，`s_t = R_τ(E(p_t, τ))`，即模型参数θ、任务τ、算子a_t、上下文c_t条件下生成程序，沙箱E执行并由评估器R_τ打分；进化推理目标是 `p* = argmax_t s̃_t`。
- 元进化学习目标：`L_evo(θ) = −E[(w(s_i) log g_θ(p_i|τ_i, a_i, c_i))]`，SFT用高分样本正监督，RL用执行奖励和熵优势加权更新。

## 6. 主要结论与发现

- **训练与搜索增益可叠加**：Frontis-MA1-35B在相同OpenMLE-Evo框架下，奖牌平均从基座39.39%提升至60.61%（+21.22 p.p.），Human Rank从0.5828提升至0.7647；30B复制验证从34.85%提升至53.03%（+18.18 p.p.）。
- **系统级表现**：结合OpenMLE-Evo-Max（跨任务经验先验+异步并行搜索），Frontis-MA1-35B达到71.21%奖牌平均，超过GPT-5.5+Codex（68.18%）且接近GPT-5.6 Sol和Kimi K3（均72.73%）。
- **搜索框架增益独立显著**：固定模型换框架（OpenMLE-Evo vs. Claude Code/Codex）在多个前沿模型上稳定提升（GLM-5.2：59.09%→62.12%；Kimi K2.6：59.09%→66.67%；MiniMax M3：54.55%→59.09%）；相对原始AIRA-Evo提升7.58 p.p.（53.03%→60.61%）。
- **长时程改进机制**：后期Improve和Crossover贡献了总验证增益的85%～91.9%，说明搜索将时间花在积累和重组互补分支上，而非重复修复单一程序；跨模型检索记忆（质量/进步/新颖性三因子选择）能保留分数略低但结构互补的分支。
- **迁移证据**：NatureBench Lite上模型固定换框架使Match-SOTA从20%→50%，框架固定换模型从50%→70%；在蛋白质变体预测任务上达到g=0.1161的聚合改进，超过基座的0.0243。
- **搜索效率**：OpenMLE-Evo相对AIRA-Evo减少41.7%总token和50.3%提示token，但新最佳更新数从229增至246（每百万token新最佳更新数+84.3%），Improve操作的新最佳率从4.73%升至9.36%。

## 7. 优点与亮点

- **全栈开源性**：同时释放任务数据、沙箱基础设施、训练代码、评估框架和模型权重（对照附录Table 11，现有系统极少同时具备所有工件），可复现性极高。
- **共享算子接口的元进化设计**：将训练与推理统一为同一组程序变换算子，使后训练模型成为进化搜索的变异引擎，构成ML工程中首个真正可执行的元进化闭环。
- **数据严谨性**：所有训练数据针对全部评估基准去重；组合溯源严格区分（Kaggle竞赛剔除MLE-Bench重叠项）；质量门控五维语义过滤。
- **受控实验方法论**："模型固定换框架、框架固定换模型"的双向置换分析，能清晰拆解训练增益和搜索增益，是系统级AI研究的优秀范式。
- **训练技术创新**：自适应奖励边界、熵加权上尾信号、异步rollout消除排队延迟、预算自适应SFT在稀疏成功任务中保留验证算力。
- **搜索效率与效果并重**：既有指标提升，也有token消耗/上下文长度/新最佳效率等详细机制分析；案例轨迹直观展示了搜索如何将经验转化为决策。

## 8. 不足与局限

- **RSI能力边界**：论文明确承认未实现完整RSI——进化系统本身固定，不演化自身搜索策略；智能体仅改进外部ML工件，未参与语言模型自身的后训练等更核心的AI开发环节。
- **奖励信号单一**：学习主要依赖最终执行分数，无法捕获研究方向本身是否有前景、可泛化性或值得更多计算等判断性信号。
- **搜索策略的经验利用有限**：父选择仅用质量/进步/新颖性三个因子，经验卡中大量确定性元数据未被利用；权重为固定值而非任务自适应，搜索策略自身不具备学习能力。
- **评估覆盖有限**：主基准仅22个任务（MLE-Bench Lite），迁移基准仅10个任务（NatureBench Lite），小模态组（音频、多模态各2任务）统计推断力不足；训练算力、整体训练成本、模型推理成本等未披露，妨碍成本-效益评估。
- **框架分离的束缚**：外部进化框架与一般编码代理分离，限制了模型自主发起动作交互的范围，也限制了将进化与灵活智能体问题求解统一的可能性。
- **潜在偏差风险**：NatureBench等参考代理结果来自官方报告（非完全同实验条件复测）；部分外部系统结果为单次评估（无±统计）；开放式竞争任务中随机种子、沙箱环境波动等因素虽经三次重复缓解仍非完全消除。

## 9. 总结性评价

本文是AI4AI/RSI方向近期最重要的全栈系统贡献之一。它不仅在MLE-Bench上取得了超越GPT-5.5+Codex的竞争性结果，更重要的是建立了从可验证环境→算子学习→进化搜索→开源发布的完整闭环研究范式。其价值不仅在于Frontis-MA1模型本身，更在于OpenMLE作为可复现、可扩展的测试平台，使后续研究能够在真实的可执行反馈循环中系统推进向递归自我改进的演进。论文在实验严谨性（去重、受控置换、多次重复、机制分析）上堪称标杆，同时诚实标注了capability boundaries与未披露算力信息，为后续工作在更完整RSI目标、更丰富学习信号和更智能搜索策略上留有明确方向。
