## 摘要
自我对弈智能体可以无需目标基准中的问题即可生成训练数据，但其课程缺乏持久状态：失败会影响梯度，却不会明确塑造未来的练习。外部技能记忆保留了程序性经验，但通常是从固定任务分布中学习的。我们提出了\textbf{SESA}（自演化技能增强智能体），它将程序性记忆变为工具增强搜索自我对弈中的演化状态。一个挑战者提出问题，而一个独立参数化的求解器仅检索技能。信息性失败被提炼为可复用技能并写回记忆。更新的记忆改变了求解器的行为与成功率，进而改变挑战者的奖励及未来问题的分布；由此产生的前沿产生了新的失败，继而重写记忆。这种双向循环使任务生成与技能记忆共同演化。由于检索到的技能塑造了在策略训练轨迹，其益处既能进入模型参数，也能保留在外部库中，从而实现免记忆部署和可选的推理时检索。在七个开放域和多跳问答基准上，SESA在多种主干模型上将平均准确率较SSP提升1.2至3.2个百分点，并在统一评估协议下超越技能增强的SkillRL基线0.9个百分点。在Qwen3模型上，SESA-Off相较SSP保持了1.8至2.2个百分点的改进，而最终技能库进一步增加了0.5至1.0个百分点。这些结果表明，演化技能记忆不仅仅是推理时的插件：它改变了策略学习与未来训练分布，同时保留作为可选外部记忆的价值。我们的代码可在https://github.com/Zenghuang-Fu/SESA-Self-Evolving-Search-Agents获取。

## Abstract
Self-play agents can generate training problems without questions from target benchmarks, but their curricula lack persistent state: failures affect gradients yet do not explicitly shape future practice. External skill memories preserve procedural experience but are typically learned from fixed task distributions. We introduce \textbf{SESA} (Self-Evolving Skill-Augmented Agent), which makes procedural memory an evolving state of tool-augmented search self-play. A challenger poses problems, while a separately parameterized solver alone retrieves skills. Informative failures are distilled into reusable skills and written back to memory. The updated memory changes solver behavior and success, which changes the challenger's reward and the distribution of future problems; the resulting frontier produces new failures that rewrite memory. This bidirectional loop makes task generation and skill memory co-evolve. Because retrieved skills shape on-policy training trajectories, their benefits can enter the model parameters as well as remain in the external bank, enabling memory-free deployment and optional inference-time retrieval. Across seven open-domain and multi-hop question-answering benchmarks, SESA improves average accuracy over SSP by 1.2--3.2 points across multiple backbones and surpasses the skill-augmented SkillRL baseline by 0.9 points under a unified evaluation protocol. On Qwen3 models, SESA-Off retains 1.8--2.2 points of improvement over SSP, while the final skill bank adds a further 0.5--1.0 points. These results show that evolving skill memory is not merely an inference-time plug-in: it changes policy learning and the future training distribution while retaining value as optional external memory. Our code is available at https://github.com/Zenghuang-Fu/SESA-Self-Evolving-Search-Agents.

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **现有方法的割裂**：现有的智能体训练路线存在两条互补思路——(a) **零数据自博弈（self-play）**：智能体自行提问并求解（如 SSP），任务生成是内生的，但具备"瞬态经验"缺陷：失败只影响一次策略梯度，却不留下可复用的显式策略痕迹；(b) **技能增强强化学习（skill-augmented RL）**：将经验蒸馏为可检索的策略/技能存入外部记忆（如 SkillRL），但通常从固定数据集或手工课程中学习，任务不是智能体自己选择的。
- **缺口（Mirror-image limitation）**：自博弈会决定"练什么"但会遗忘"学到什么"；技能增强 RL 记住了"怎么做"但任务来源不是自己选的。两者都缺少一个**既能自选练习前沿、又能持久保留自身失败经验**的智能体。
- **核心问题**：如何让程序性记忆成为自博弈中真正的**演化状态**——失败经验显式写回记忆，记忆改变求解行为，进而改变挑战者的奖励与未来问题的分布，形成双向闭环。

## 2. 方法论：SESA 的核心思想与关键技术细节

- **总体框架**：SESA（Self-Evolving Skill-Augmented Agent）由三个角色组成——**挑战者（Proposer/Challenger）** 出题并提供可验证答案；**求解器（Solver）** 借助搜索工具求解并**唯一地检索技能**；**评判器（Judge）** 校验答案。外加一个非参数化**技能库 B**。
- **技能表示**：每条技能存为 `s = (u, c, a, z, m)`，即"描述、触发条件、避错提示、可复用查询模板、检索/有用/有害统计"。
- **四阶段闭环（SESA flywheel）**：
  1. **记忆初始化（Memory Priming）**：B₀ = 15 条手写技能 + 142 条自博弈引导阶段挖掘的技能，共 157 条，提供初始检索基座并锚定之后技能蒸馏的粒度。
  2. **非对称自博弈（Asymmetric Self-Play）**：挑战者与求解器使用**独立参数**；检索到的技能**只暴露给求解器**，防止技能直接泄漏进问题生成，保持博弈的不对称性。
  3. **前沿塑形（Frontier Shaping）**：定义问题 x 的求解器经验成功率 p̂ₛ(x)（G 次 rollout 中成功的比例）。挑战者奖励使用**钟形、端点惩罚**的设计：p̂ₛ ∈ {0,1} 时给 −λ 惩罚，否则 rₚ(x) = 4(ℓ+p̂ₛ)(h−p̂ₛ)。目标是让挑战者持续生成**刚好超出当前求解器能力边界**的问题——过于简单或完全不可解都被惩罚。
  4. **失败蒸馏（Failure Distillation）**：失败的 rollout 进入 300 条容量待处理队列，每 10 步且积累 ≥20 条时合并，优先挑选**重复失败**和**即使有检索技能仍失败**的样本；由 DeepSeek-v4-pro 抽象为触发条件、区分线索、避错提示与查询模板；用 E5-base-v2 的余弦相似度 ≤0.93 作为去重与入库条件；非种子技能在"检索次数≥3 且有用数 − 有害数 < 0"时被淘汰，技能库超过 800 条时移除得分最低的非种子技能。
- **训练目标**：基于 GRPO（Group Relative Policy Optimization），求解器每组生成 G 条 rollout，奖励为稀疏二元判断（归一化精确匹配 + 模型语义匹配）；检索上下文 `R(q; Bt)` 直接进入 on-policy rollout，因此技能的收益能被内化到策略参数中，而非仅是推理时提示。
- **双路径技能复用**：训练后的求解器支持两种部署——**SESA-Off**（禁用技能库，纯参数化推理）与 **SESA-On**（保留技能库，推理时检索增强）。二者的权重完全相同，差值即纯外部记忆增益。

## 3. 实验设计

- **数据集**：7 个 QA 基准共 3,125 条留出问题——开放域事实检索：NQ、TriviaQA、PopQA；多跳组合推理：HotpotQA、2WikiMultiHopQA、MuSiQue；以及挑战性分解集 Bamboogle（125 条）。前六个各取 500 条。
- **训练数据**：完全零数据设定——沿用 SSP 发布的 50,000 个种子目标答案（16,547/16,729/16,724 分别对应 1/2/3 跳需求），挑战者需借助搜索引擎将其转化为唯一可答的问题。
- **对比方法**：(1) **Base**——未经过持续训练的基座；(2) **SSP**——无技能库的搜索自博弈基线；(3) **SkillRL-Search-7B**——技能增强 RL 的发布的 checkpoint；(4) **SESA-Off / SESA-On**——SESA 的两种部署模式。
- **骨干网络**：Qwen3-4B、Qwen3-4B-Instruct、Qwen3-8B、Qwen2.5-7B-Base、Qwen2.5-7B-Instruct、LLaMA-3.1-8B、Search-R1-7B（搜索专用初始化）。
- **组件消融**：leave-one-out 去掉记忆初始化 / 前沿塑形 / 失败蒸馏（在 Qwen3-4B 上）；另有双路径消融、与 SkillRL 的对照实验、训练动态分析。

## 6. 主要结论与发现

- **SESA 在平均准确率上稳定超过 SSP**：Qwen3-4B +2.3、Qwen3-4B-Instruct +2.7、Qwen3-8B +3.2、Qwen2.5-7B-Base +2.1、Qwen2.5-7B-Instruct +1.5、LLaMA-3.1-8B +1.2、Search-R1-7B +1.8 个百分点；相对各自 Base 提升 3.6–28.5 点不等。
- **相对 SkillRL 的优势**：在同一协议下，SESA（51.0）比 SkillRL-Search-7B（50.1）高出 0.9 点，说明"内生任务前沿 + 技能演化"比"固定数据集 + 技能学习"更有价值。
- **技能收益主要驻留在策略参数中**：SESA-Off（禁技能库）相比 SSP 仍高 1.8–2.2 点，说明技能塑造了策略梯度、被内化为参数能力，而非单纯的提示技巧；启用最终技能库额外 +0.5–1.0 点。但该项增益存在数据集层面的正负波动（如 2Wiki/Bamboogle 出现负值），外部记忆是"与任务和模型相关的可选增强"。
- **失败蒸馏是最关键组件**：移除后平均下降 2.7 点；移除前沿塑形下降 2.2 点；移除记忆初始化下降 1.5 点。
- **记忆是自我精炼而非无限增长的**：训练中活跃技能数量先膨胀后收缩，体现了去重与负效用淘汰的持续作用。

## 7. 优点（方法或实验设计的亮点）

- **提出了真正耦合的闭环**：自博弈（内生任务生成）与技能记忆（持久失败经验）不再是两条平行的路线，而是一个互相驱动的反馈系统——这是与仅"自博弈 + 技能库"简单组合的核心区别。
- **严格的信息不对称设计**：技能只对求解器开放、不对挑战者开放，防止解题策略泄漏进生成问题，保证了博弈的正当性。
- **前沿塑形的奖励设计**：不是简单使用"1 − 准确率"，而是钟形 + 端点惩罚，同时抑制"太简单"和"不可解"两个方向，驱动挑战者持续产出恰好超出当前能力的题目。
- **双路径评估设计非常巧妙**：通过 SESA-Off vs SESA-On 共享权重、仅切换技能库启用的对照，清晰分离了"技能内化到参数"与"技能外部调用"两部分的贡献。
- **技能库机制完整**：包含初始化、检索、蒸馏、去重、效用追踪、淘汰与容量管理，形成了一个"活的记忆"；收益由观察到的下游行为（帮助/伤害计数）驱动，而非简单的时间老化。
- **零数据纯自博弈设定**：训练不消费任何测试基准的问题，泛化收益来自自生成搜索经验，结论更具说服力。
- **跨尺度、跨家族、跨专用化的验证**：7 种骨干覆盖 4B–8B 范围、裸基座与指令微调、通用模型与搜索专用模型，增强结论的普适性。

- **应用场景局限**：方法聚焦搜索型问答任务，未验证其在代码生成、工具调用、Agent 长程规划等其他智能体场景中的迁移能力。
