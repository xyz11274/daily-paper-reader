## 摘要
优化现代推荐模型仍然严重依赖工程师手动迭代架构、目标和训练策略的更改。虽然基于LLM的代理可以自动化这一试错过程，但让LLM同时选择修改方向并生成具体假设，往往在有限的实验预算下导致搜索不稳定。受上述挑战启发，我们提出了RecHarness，一种用于自动推荐模型优化的赌博机路由智能代理框架。RecHarness将优化过程分为两步：赌博机路由器根据历史验证反馈选择下一个修改方向，而LLM在选定方向内生成具体的优化假设和可执行代码编辑。为了维持长期探索，RecHarness使用跳跃盆地机制，在局部编辑停滞时激活结构跳跃臂。在多个推荐任务、数据集和模型骨干上，RecHarness相比LLM推理搜索实现了更稳定的性能提升，并更有效地利用有限的试验预算。在一个大规模短视频广告平台进行的为期7天的在线A/B测试中，所选候选方案使ADVV提升2.084%，收入提升0.534%，曝光量提升0.559%。代码可在https://github.com/6lyc/RecHarness获取。

## Abstract
Optimizing modern recommender models still depends heavily on engineers manually iterating over architectural, objective, and training-strategy changes. While LLM-based agents can automate this trial-and-error process, allowing the LLM to both select modification directions and generate concrete hypotheses often leads to unstable search under limited experiment budgets. Inspired by the above challenge, we propose RecHarness, a Bandit-Routed Agentic Harness for automated recommender model optimization. RecHarness separates the optimization process into two steps: a bandit router selects the next modification direction according to historical validation feedback, while the LLM generates a concrete optimization hypothesis and executable code edit within the selected direction. To sustain long-horizon exploration, RecHarness uses a jump-basin mechanism to activate a structural-jump arm when local edits stagnate. Across multiple recommendation tasks, datasets, and model backbones, RecHarness achieves more stable performance improvements and uses limited trial budgets more effectively than LLM-reasoning search. During a 7-day online A/B test on a large-scale short-video advertising platform, the selected candidate improves ADVV by 2.084%, Revenue by 0.534%, and Exposure by 0.559%. Code is available at https://github.com/6lyc/RecHarness.

### 1. 核心问题与整体含义（研究动机与背景）

- **现实痛点**：现代推荐系统模型的优化高度依赖工程师手动迭代架构、训练目标、优化策略等，效率低且成本高。尽管 LLM 智能体可自动化这一试错过程，但与通用 ML 工程任务不同，推荐系统优化是**持续迭代**过程，每次试验耗资巨大，且需要解读训练日志、收敛行为、失败信号等丰富文本反馈。
- **核心挑战**：若让 LLM 同时负责「选择修改方向」和「生成具体假设」，在有限实验预算下会导致搜索不稳定、方向发散、成功率低——现有研究表明，通用 LLM 在上下文探索（in-context exploration）中表现不可靠，但将 LLM 推理与传统 bandit 机制结合可显著改善。
- **研究目标**：构建一个验证驱动的优化框架（harness），能在架构、目标函数、训练策略等广义工程搜索空间中，适应不同推荐场景、模型家族与评估目标，实现**稳定、高效、跨场景**的自动化推荐模型优化。

### 2. 方法论：核心思想、关键技术细节与算法流程

#### 核心思想

RecHarness 将优化过程**解耦为两个层级**：

- **Bandit 路由器**：依据历史验证反馈（标量分数）决定「下一个修改方向」（即哪些编辑臂参与试验），解决有限预算下探索-利用的权衡问题；
- **LLM 推理生成器**：在选定方向内，结合实验技能（Experiment Skill）与文本日志，生成具体的优化假设和可执行代码编辑，解决「怎么改」的问题。

#### 关键技术与机制

1. **候选人状态与二元奖励定义**
   - 以当前最优实现（incumbent）为基线，`Δ_t(a) = M(f_{t,a}) − s_t*` 衡量候选的验证提升；
   - 组内归一化后，成功信号定义为：候选有效、超过同组平均、且不低于历史最优。
2. **Thompson 采样路由**
   - 每个编辑臂 `a` 维护 Beta 后验 `Beta(α_a, β_a)`，每轮采样 `θ̂_a`，选取 Top-G 臂；
   - 用二元成功信号更新 `(α_a, β_a)`，类似多臂赌博机框架，但后验仅作为分配试验的局部证据，不假设固定全局成功概率。
3. **Experiment Skill（实验技能）**
   - 一段压缩文本，记录当前最优、最近成功编辑、被否决方向、失败原因与验证趋势摘要；
   - **仅影响 LLM 的变异生成**，不参与 bandit 后验更新，防止文本摘要静默覆盖标量证据；
   - 每个验证轮后自动更新（成功→提炼经验；失败→写入规避规则）。
4. **Jump-Basin 机制（盆地感知跳跃）**
   - 手臂分本地臂（局部微调）与跳跃臂（结构性大改）；
   - 当 W 轮窗口内改善率低于阈值 τ，激活跳跃臂进入选择集；
   - 跳跃后被接受需经 R 轮本地重调并超过 incumbent 一定边际 δ_jump，而非只看即时验证分数。
5. **三层控制流程**
   - Level 1（人类）：定义优化目标、验证指标、候选编辑臂；
   - Level 2（Bandit）：标量验证反馈驱动试验预算分配；
   - Level 3（LLM + Experiment Skill）：生成假设、代码、验证分数与文本教训；
   - 改进者晋升为下一轮 incumbent，循环迭代直至预算耗尽。

### 6. 主要结论与发现

- **解耦有效**：将「选方向」与「生成修改」分离，能显著提升有限预算下搜索的稳定性与效率。RecHarness 在每次验证检查点都优于所有消融变体（0.5050→0.6125（第 2 轮）→0.6342（第 4 轮））。
- **路由带来准确性与增益提升**：RecHarness 非基线试验中 47.92% 刷新轮起点最优，远超随机路由（22.45%）和 LLM 选臂（21.74%）；最大单次增益（24.00%）远高于无 bandit 的 LLM 自由搜索（10.16%）。
- **跨场景迁移能力强**：Amazon 上 5 个模型平均 HR@10 均超越论文已发表结果，其中弱基线（GRU4Rec）提升 85.85%，强基线（HSTU）仍提升 12.58%；KuaiRec 上弱基线 TPM 的 MAE 双双下降超 26%，强基线 GR 也四项指标一致提升。
- **工业落地价值**：在线 A/B 测试中，RecHarness 发现的结构性改进（对六组实时行为序列应用自注意力后压缩注入排序器）使 ADVV +2.084%、Revenue +0.534%、Exposure +0.559%，离线生产 AUC 提高 0.09%。

### 7. 优点

- **模块化设计清晰**：方向选择（bandit）与假设生成（LLM）解耦，「标量证据」与「文本证据」各司其职，防止文本摘要覆盖标量统计证据，系统边界明确。
- **方法有价值且实用**：将推荐优化形式化为预算约束下的 incumbent 条件 bandit 问题，Thompson 采样天然适配小样本下的探索-利用权衡；Jump-Basin 机制在结构跳跃后设置重调窗口，符合工程实践（大改需局部适应后评估）。
