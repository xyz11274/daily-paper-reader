## 摘要
大型语言模型（LLM）智能体在科学研究中越来越多地被用于组织和调用专门的计算工具。然而，它们对具有静态语义的预定义工具空间的依赖限制了其在开放世界科学工作流中的适用性，在这些工作流中，工具需求、能力和边界会动态演化。为此，我们提出了 SciToolAgent-Evo，一种用于开放世界科学工具获取的 ontology 感知自进化智能体。它由不断演化的技能、经验记忆和本体化的工具图驱动，在累积过程中从对比轨迹中提炼可泛化知识，而在推理过程中则制定主动请求，并利用基于 LinUCB 的赌博机门控来动态平衡探索与利用。一旦获取新工具，其科学本体将在线完成，以无缝集成到已知图中。此外，我们引入了 OpenSciToolBench，这是一个包含四个难度级别、共 900 个现实任务的基准测试。大量评估表明，SciToolAgent-Evo 达到了最先进的性能，验证了其鲁棒性和泛化能力。

## Abstract
Large language model (LLM) agents have been increasingly adopted in scientific research for organizing and invoking specialized computational tools. However, their reliance on predefined tool spaces with static semantics limits their applicability to open-world scientific workflows, where tool requirements, capabilities, and boundaries evolve dynamically. To this end, we propose SciToolAgent-Evo, an ontology-aware self-evolving agent for open-world scientific tool acquisition. Driven by an evolving memory of skills, experiences, and an ontologized tool graph, it distills generalizable knowledge from contrastive trajectories during accumulation, whereas during inference, it formulates active requests and utilizes a LinUCB-based bandit gate to dynamically balance exploration and exploitation. Once a novel tool is acquired, its scientific ontology is completed online for seamless integration into the known graph. Moreover, we introduce OpenSciToolBench, a benchmark containing 900 realistic tasks across four difficulty levels. Extensive evaluations show that SciToolAgent-Evo achieves state-of-the-art performance, validating its robustness and generalization.

## 2. 方法论

### 2.1 总体框架
- 包含两个阶段：
  - **知识累积阶段（Knowledge Accumulation）**：基于训练任务进行对比轨迹生成、轨迹批判、知识蒸馏，形成可进化的记忆。
  - **本体感知推理阶段（Ontology-Aware Inference）**：通过技能/任务路由、主动请求生成、本体引导检索、LinUCB 门控控制、工具链执行和知识更新，完成开放世界工具获取。

### 2.2 核心形式化定义
- **工具空间**：`T = TK ∪ TU`，`TK` 为已知工具图 `GK=(VK, EK)`，`TU` 为未知工具集，初始仅暴露极少基本属性。
- **本体（Ontology）**：`ot=(bt, ht)`，`bt` 为基本属性（功能、输入/输出类型、类别），`ht` 为高级科学属性（适用对象、科学场景）。
- **技能（Skill）**：`ki=(Ni, Zi, Ei)`，任务级工具链指导单元，可复用的流程。
- **经验（Experience）**：`e=(de, se, ae, he)`，非参数化提示，提供细粒度工具选择指导。
- **Bandit Gate**：LinUCB 决策模块，上下文向量 `xj=[fj, mj, sj, pj]ᵀ`，分别表示 top-1 已知工具可行性、top-2 置信边距、本体对齐分数、历史探索成功先验。

### 2.3 关键机制
- **对比轨迹生成与蒸馏**：对每个训练任务，先以 `Tbase=0` 采样确定性轨迹；若失败，则以不同温度 `Texp∈{0.2,0.5,0.8}` 多次探索采样。若探索轨迹成功，构造对比对，识别关键分歧并生成诊断文本，进而蒸馏出**领域特定经验**和**通用经验**，去重后存入经验池。
- **主动工具请求**：不直接基于原始查询匹配工具，而是先生成一组原子化的工具需求描述 `Rq={r1,...,rl}`，再基于需求检索候选工具，降低匹配难度，提升需求-能力的语义对齐。
- **LinUCB 门控平衡探索与利用**：对每个请求 `rj`，门控根据上下文向量决策选择已知工具（利用）或未知工具（探索）。更新公式为：
  - `aj = argmax_a (θ̂_aᵀ xj + α·sqrt(xjᵀ A_a⁻¹ xj))`
  - 执行成功后更新 `Aa ← Aa + xj xjᵀ`，`ba ← ba + r xj`。
- **知识更新**：当未知工具被成功使用后，从其交互历史补全本体，并迁移到已知工具图；同时将成功轨迹抽象为技能存入技能库，形成自进化闭环。
