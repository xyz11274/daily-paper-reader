## 摘要
记忆是AI智能体的核心组件，可支撑智能体积累经验、维持个性化，并在长期交互中实现自适应。然而现有记忆系统通常在开发完成后保持固定，限制了其通过持续使用调整自身记忆模型、组织策略与过程知识的能力。本文提出MindMemOS，这是一个可移植的自演化记忆操作层，它采用统一的实体属性时间结构组织开放世界信息。MindMemOS支持场景自适应记忆建模、高阶模式发现、自主记忆优化与持续技能演化。其MindMemEvolve算法采用验证驱动的演化搜索为目标场景优化记忆模式，而做梦（dreaming）模块通过合并冗余记录、解决冲突整合已积累的记忆。此外，隐式纠正反馈可作为人在回路信号，用于识别和修正可能不准确或存在对齐偏差的记忆。其MindSkillEvolve算法进一步将智能体执行轨迹转化为可复用、渐进优化的技能。MindMemOS在LOCOMO上取得94.03%的准确率，在PersonaMem上取得70.63%的准确率。MindSkillEvolve在SpreadsheetBench上的成功率相较初始技能基线提升了9.2个百分点。

## Abstract
Memory is a core component of AI agents, enabling them to accumulate experience, maintain personalization, and adapt over long-term interactions. However, existing memory systems often remain fixed after development, limiting their ability to adapt their memory models, organization strategies, and procedural knowledge through continued use. We present MindMemOS, a portable and self-evolving memory operating layer that organizes open-world information using a unified entity property timestructure. MindMemOS supports scenario-adaptive memory modeling, higher-order pattern discovery, autonomous memory refinement, and continuous skill evolution. Its MindMemEvolve algorithm employs validation-driven evolutionary search to optimize memory schemas for target scenarios, whiledreaming consolidates accumulated memories by merging redundant records and resolving conflicts. In addition, implicit corrective feedback serves as a human-in-the-loop signal for identifying and revising potentially inaccurate or misaligned memories. Its MindSkillEvolve algorithm further transforms agent execution trajectories into reusable and progressively refined skills. MindMemOS achieves 94.03% accuracy on LOCOMO and 70.63% on PersonaMem. MindSkillEvolve improves SpreadsheetBench success by 9.2 percentage points over the initial-skill baseline.

# 论文详细总结
## 1. 核心问题与研究背景
- 现有大语言模型智能体需要长期记忆支撑经验积累、个性化适配与长周期任务执行，当前主流记忆方案存在明显缺陷：
  1. 参数化记忆方案依赖特定模型架构或额外训练，跨模型、跨框架可移植性差；
  2. 主流外部记忆系统的记忆结构、提取策略、组织模式在部署后固定不变，无法随使用持续优化，带来三大问题：
     - 手动设计的领域schema适配成本高，无结构表示不支持细粒度时序推理；
     - 持续积累的记忆存在冗余、过期、冲突问题，缺乏系统化维护机制；
     - 记忆与技能分离管理，无法将执行经验转化为可复用的渐进优化技能。
- 核心研究目标：打造一个可移植、支持全生命周期自主进化的统一记忆操作层，解决上述问题。

## 2. 提出的方法论
### 核心思想
构建分层解耦的可移植自进化记忆操作层，基于统一的实体-属性-时间三维结构组织记忆，内置多套进化机制，同时实现场景自适应记忆建模、自主记忆维护、记忆schema自动优化与执行技能持续迭代。

### 关键技术细节
1. **核心记忆结构**：统一三维（实体-属性-时间）记忆图
   - 实体维度：作为记忆的主体锚点，支持人、组织、事件、物品等各类主体，保留实体间语义关联；
   - 属性维度：描述实体的特征/模式，不限制固定集合，可随场景自适应调整，支持一阶（单观测事实）和高阶（多观测合成的模式）属性；
   - 时间维度：绑定每个记忆的有效观测时间，同实体同属性的多条记录形成时间线，保留历史版本不覆盖，支持信息演化追溯。
2. **两种记忆写入策略**
   - MindVanilla：面向开放域无预定义schema场景，自动处理自由文本，完成去重、分类、冲突初步检测，无需手动配置；
   - MindSchema：面向特定场景，基于当前schema完成对话分段、实体属性抽取、实体融合、子图合并，自动合成高阶属性。
3. **紧凑混合检索**
   外层由LLM做检索规划，内层结合BM25稀疏匹配+Embedding稠密匹配，支持正向（实体→属性）和反向（属性→实体）双向图遍历，限制遍历范围避免检索爆炸，兼顾检索效率和准确性。
4. **四大自进化机制**
   - **Dreaming（离线记忆整合）**：离线处理增量写入带来的冗余冲突，按实体聚簇记忆，检测冲突、冗余问题，生成非破坏性的更新合并计划，归档过期记忆，保留版本溯源，在减少活跃内存体积的同时解决冲突。
   - **人在回路反馈修正**：同时支持显式反馈（用户直接修正记忆）和隐式反馈（从用户对智能体任务的纠正中提取长期记忆修正，自动区分临时任务修正和长期记忆更新，避免错误更新长期记忆）。
   - **MindMemEvolve（记忆schema自进化）**：以「下游任务回答准确率最高」为优化目标，针对非可微的schema优化问题，采用LLM引导的进化算法求解：初始种群基于初始schema随机变异，每轮评估个体适应度、保留精英，再通过错误诱导变异（针对性修复信息缺口）、随机变异（增减实体属性）、交叉操作生成下一代，多轮迭代后选出最优schema，自动发现场景相关的高阶模式。
   - **MindSkillEvolve（技能持续进化）**：将智能体执行轨迹绑定到对应技能版本，积累足够轨迹后批量分析，提炼成功模式和 recurring 失败模式，生成新版本技能；分为无监督（仅基于轨迹分析）和有监督（结合任务得分强化有效行为、抑制错误行为）两个变体，支持版本管理、跨设备同步与回滚。
