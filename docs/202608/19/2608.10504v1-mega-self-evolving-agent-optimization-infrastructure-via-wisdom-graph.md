## 摘要
随着编码智能体越来越多地承担实现工作，核心挑战已从构建单个智能体转变为构建能够系统性改进智能体的基础设施。现有方法要么在优化智能体系统时不积累可迁移知识，要么积累知识后不对其开展组合推理，且缺乏让知识通过运行证据实现自进化的机制。MEGA（Meta Evaluation-Grounded Adaptation）作为一种自进化基础设施解决了这些缺口：每个优化周期都会生成持久资产，对这些资产的组合推理指导后续优化，运行证据会同时精炼积累的智慧以及管控该智慧的推理过程。第一层通过行为模式聚类和经验A/B验证从智能体会话中提炼可复用智慧，将每个过程转化为持久资产。第二层将这些资产分解为类型化智慧图中的原子化PCR（Primary-Context-Resultant）单元，并执行演绎、溯因和归纳推理以扩展隐式关系；随后通过组合检索组装适配特定上下文的执行计划，该检索能够挖掘出仅通过嵌入相似度无法获得的桥接知识。第三层对异构智能体工作流（代码节点、LLM调用、工具使用智能体）执行多智能体协作优化，通过消除数据方差的控制评估将改进效果归因于具体的策略变更。第三层反馈回的证据推动管控智慧组合的遴选策略以及多轮运行积累的优化轨迹共同实现自进化。最终得到的基础设施中，优化智能体系统与演化指导优化的知识是同一个过程。

## Abstract
As coding agents increasingly handle implementation, the central challenge shifts from building individual agents to building an infrastructure that systematically improves them. Current approaches optimize agent systems without accumulating transferable knowledge, accumulate knowledge without compositional reasoning over it, and lack a mechanism for that knowledge to self-evolve through operational evidence. MEGA (Meta Evaluation-Grounded Adaptation) addresses these gaps as a self-evolving infrastructure: each optimization cycle produces durable assets, compositional reasoning over those assets guides subsequent optimization, and operational evidence refines both the accumulated wisdom and the reasoning that governs it. Layer 1 distills reusable wisdom from agent sessions through behavioral-pattern clustering and empirical A/B validation, transforming each process into a durable asset. Layer 2 decomposes these assets into atomic PCR (Primary-Context-Resultant) units within a typed Wisdom Graph and performs deductive, abductive, and inductive reasoning to expand implicit relations; it then assembles context-specific execution plans through compositional retrieval that surfaces bridging knowledge unreachable by embedding similarity alone. Layer 3 performs multi-agent collaborative optimization over heterogeneous agent workflows (code nodes, LLM calls, and tool-using agents), attributing improvement effects to specific strategy changes through controlled evaluation that eliminates data variance. Evidence fed back from Layer 3 drives the self-evolution of both the curation strategies that govern wisdom composition and the optimization trajectories accumulated across runs. The result is an infrastructure in which optimizing an agent system and evolving the knowledge that guides optimization are one and the same process.

## 1. 核心问题与研究动机/背景
- 行业背景：编码智能体已经逐步承担实际代码实现工作，开发范式发生转变，人类角色转向定义优化目标、设计评估数据，领域核心挑战从构建单个高性能智能体，转变为构建能够系统性、持续迭代改进智能体的基础设施。
- 现有方案的三大核心缺陷：
  1. 优化过程不积累可迁移知识：单次项目优化完成后，策略生效的条件和逻辑不会结构化留存，新项目需要从头开始搜索策略，现有记忆层仅解决存储问题，未支持结构化推理；
  2. 已存储知识不支持深度组合推理：现有技能编排大多在整技能层面操作，无法分解为原子单元做内部依赖推理，也不能自动挖掘隐式关系，无法解决组合性鸿沟问题；
  3. 知识无法基于运行证据自进化：缺乏闭环反馈机制，未验证的错误、过时知识会持续积累，逐步降低检索质量，无法随着运行迭代自动更新知识。
- 核心研究问题：现有工作未将知识积累、组合推理、证据自进化三个核心能力统一到同一基础设施中，无法支撑智能体的系统性持续改进。

## 2. 方法论：核心思想与关键技术
### 核心思想
构建三层闭环的自进化基础设施MEGA（Meta Evaluation-Grounded Adaptation），将优化智能体系统和进化指导优化的知识统一为同一个过程，基于带原子知识单元的类型化智慧图，实现知识积累→推理编排→优化验证→知识自更新的完整闭环。

### 关键技术细节
整体分为三层架构，形成自强化循环：
1. **Layer 1：会话式智慧生成**
   - 核心目标：从原始智能体会话痕迹中蒸馏出经过实证验证的可复用智慧资产
   - 流程：先在客户端完成隐私过滤（脱敏、去敏感信息），随后通过两阶段聚类提取行为模式：第一阶段基于嵌入相似度做领域预聚类缩小搜索空间，第二阶段用BIRCH算法做单遍线性聚类，自适应得到不同的行为模式簇；之后用LLM合成结构化智慧，完成去重、冲突解决等结构过滤；最后通过行为A/B验证：分别在注入智慧的处理组、不注入的对照组运行测试，同时测量性能提升和token效率，只有通过验证的智慧才会进入下一层。

2. **Layer 2：智慧推理与遴选**
   - 核心目标：将智慧分解为原子单元，做推理扩展，组装上下文相关的执行计划，基于运行证据实现自进化
   - 关键技术：
     - PCR原子分解：所有智慧（包括技能、策略、编排模式、优化轨迹四类）都分解为`Primary(核心动作)-Context(应用条件)-Resultant(预期结果)`的原子三元组，节点支持角色流动（同一概念可在不同三元组中担任不同角色），边带充分性、必要性双因果评分（借鉴Pearl因果理论）；
     - 三模态推理：通过演绎（传递因果推理推导隐式关系）、溯因（反向推理挖掘未记录的前置条件）、归纳（统计检验发现显著共现的新关系）三种方式扩展隐式边，直到不再产生符合阈值的新边为止；
     - PCST组合检索：将检索问题建模为奖品收集斯坦纳树问题，把查询相似度高的节点作为种子，自动纳入连接种子必需但相似度低的桥接知识，解决纯嵌入相似度无法检索桥接知识的问题；
     - 自进化与图卫生：基于ROI做智慧效用校准，从个体效用校准、组合模式强化、内容更新三个维度实现自进化；定期自动执行图去重、矛盾解决、过时内容更新，保证知识图质量。

3. **Layer 3：评估驱动的多智能体优化**
   - 核心目标：对异构智能体工作流（代码节点、LLM调用、工具使用智能体）做联合优化，生成可归因的证据反馈给前两层，闭环自进化
   - 关键技术：
     - Adapt流水线：自动扫描现有目标系统资产，缺评估数据时自动生成分层的合成评估数据集，随后进入迭代优化循环，多智能体分工协作完成诊断、假设、验证、重构；优化完成后元学习agent提取结构化的优化轨迹存入智慧图；
     - Seed-Epoch归因机制：同一个优化轮次（Epoch）内所有迭代都使用固定种子采样的验证集，消除数据方差，让性能变化可以准确归因到具体策略变更；轮次饱和后换全新采样的验证集，自动检验过拟合；
     - 多层过拟合防护：禁止过拟合性的启发式代码修改，跟踪训练-验证精度 gap 动态限制优化范围，基于错误可修复性设置合理目标，避免无效搜索。
