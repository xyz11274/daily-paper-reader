## 摘要
可复用技能封装了解解决真实世界专业任务所需的过程性知识，为基于LLM的智能体在专业领域实现自我进化提供了一条路径。现有的自我进化技能方法从模型的参数化知识或轨迹中内部构建技能，因此受限于模型已知的内容。然而，专业技能背后的领域惯例和标准流程往往超出这一边界，难以仅从智能体自身引出。为了解决这个问题，我们提出了一种新框架Search2Skill，它自动识别智能体的能力缺口，搜索外部资源以弥补这些缺口，并将检索到的证据蒸馏为结构化、可复用的技能。具体而言，Search2Skill通过基于规则的强化学习方案进行优化，该方案共同改进何时搜索、如何搜索以及如何生成技能。在来自三个基准测试的八个专家级领域上的实验表明，Search2Skill在流式评估和留出评估协议下均持续优于基于搜索增强和基于轨迹的技能学习基线。进一步的分析表明，性能提升来自技能抽象而非原始检索证据，并且所获得的技能可跨模型规模迁移。

## Abstract
Reusable skills, which encapsulate the procedural knowledge required to solve real-world professional tasks, offer LLM-based agents a path toward self-evolution in expert domains. Existing self-evolving skill methods construct skills internally from the model's parametric knowledge or trajectories, and are therefore bounded by what the model already knows. However, the domain conventions and standard procedures underlying professional skills often lie beyond this boundary and are hard to elicit from the agent alone. To address this issue, we therefore propose a novel framework, Search2Skill, that automatically identifies the agent's capability gaps, searches external sources to address them, and distills the retrieved evidence into structured, reusable skills. Specifically, Search2Skill is optimized by a rubric-based reinforcement learning scheme that jointly improves when to search, how to search, and how to generate skills. Experiments on eight expert-level domains from three benchmarks show that Search2Skill consistently outperforms both search-augmented and trajectory-based skill-learning baselines under both streaming and held-out evaluation protocols. Further analyses show that the gains arise from skill abstraction rather than raw retrieved evidence, and that the acquired skills transfer across model scales.

- **背景**：基于 LLM 的智能体在开放、专业化的环境中部署时，核心挑战是如何持续扩展其能力范围。可复用技能（Reusable Skills）封装了领域工作流、解决策略和工具使用知识，为智能体的自我进化提供了路径。
- **核心问题**：现有自进化技能方法（如 Trace2Skill、ReasoningBank 等）均为**“内视型”（Inward-looking）**方法——仅从模型自身的参数化知识或执行轨迹中归纳技能，因此被模型的**能力边界（Knowledge Boundary）**所限制。而专业领域技能所依赖的领域惯例、标准流程和专家实践经验，恰恰往往位于这一边界之外，无法仅靠模型自身引出。
- **关键洞察（初步研究）**：
  - LLM 在很大程度上能感知自身的能力边界——在最终答错的题目上，探索触发率比答对的题目高出 27~36 个百分点（跨 4 个 Qwen3 模型规模）。
  - 若将外部搜索精准对准这些被自我识别的能力缺口，自进化上限可平均提升 **14.3%**：例如 14B 和 32B 模型可分别达到 81% 和 77% 的准确率，接近甚至超过 235B 模型 79% 的执行准确率。
- **解决思路**：提出 **Search2Skill** 框架，将智能体的自进化从"向内重组已有经验"转向"向外搜索外部证据并蒸馏技能"。

## 2. 方法论：Search2Skill 框架

### 2.1 核心思想

Search2Skill 形成一个闭环：**能力缺口识别 → 外部搜索 → 技能蒸馏 → 技能入库复用**。给定任务 q，智能体先基于参数知识与技能库推理；识别到能力缺口后进入探索状态，生成针对性查询，收集外部证据，将其蒸馏为结构化可复用技能写回技能库，供当前及未来相关任务使用。

### 2.2 任务形式化

- 任务定义为元组 (q, M)，其中 q 为输入问题，M 为持久技能库。
- 交互轨迹：τ = (o₁, r₁, a₁, o₂, r₂, a₂, ..., o_T, r_T, a_T)，其中 o 为环境观测，r 为中间推理，a 为动作。
- 动作空间涵盖三类核心决策：
  1. **搜索动作**（web search / page visit）；
  2. **技能生成动作**（将检索证据蒸馏为结构化技能 s，并更新 M ← M ∪ {s}）；
  3. **最终回答动作**（终止 rollout）。

### 2.3 基于 Rubric 的强化学习奖励设计

针对 GRPO 仅有单一结果奖励导致的三决策信用分配问题，设计了四个奖励项：

| 奖励项 | 作用 | 具体机制 |
|---|---|---|
| **R_base** | 任务正确性与动作格式检查 | 最终答案正确 + 动作格式合规 |
| **R_when（探索必要性）** | 决定"何时搜索" | 组内对比门控（group-contrastive gate）：将 rollout 分为探索组 G_exp 和直接作答组 G_direct，计算准确率差 Δ = ȳ_exp − ȳ_direct，以阈值 τ₀=0.25 判断探索是否值得奖励 |
| **R_search（搜索质量）** | 决定"如何搜索" | LLM-as-a-Judge 评估查询的抽象性（是否面向可复用原则而非实例细节）与证据增益（是否解决关键不确定性），不良查询施加罚项 p_q ∈ [0, 0.3] |
| **R_skill（技能生成质量）** | 决定"如何生成技能" | 两个维度：(1) 复用度 s_reuse——冻结骨干模型在相似问题上使用技能与直接推理的准确率差；(2) 接地性 s_ground——逐声明审计技能是否忠实于检索证据 |

**最终奖励公式**：

```
R(τ) = clip[0,1]( λa·R_base(τ) + λc·sc(τ) )
```

其中 λa=0.7，λc=0.3；统一决策奖励 sc(τ) 为门控结构：

- Δ > τ₀ 且 τ ∈ G_exp：sc = q(τ)（质量奖励）；
- Δ < −τ₀ 且 τ ∈ G_direct：sc = 1；
- 否则：sc = 0。

质量奖励：

```
q(τ) = max(0, ½(s_reuse + s_ground) − p_q(τ))
```

该设计将质量奖励**门控在已证明的能力缺口之后**，既避免无差别探索，又鼓励高质量的技能蒸馏。

### 2.4 训练流程

1. **SFT 冷启动**：用 DeepSeek-V3.2 和 GLM-5 教师在 WebInstruct-verified 语料上执行完整 Search2Skill 循环，经拒绝采样（仅保留最终答对的轨迹）收集约 8K 条高质量轨迹，覆盖探索与直接作答两种行为。
2. **GRPO 强化学习**：在 2K 条过滤后的高质量问题上训练，每个锚点问题配 3 个相似问题用于在线技能复用评估。问题集中在物理、化学、金融、商业、经济学五个领域。
3. **技能检索**：用 text-embedding-v4 嵌入，按描述相似度（γ=0.7）与源问题相似度（1−γ）加权，检索 top-3、阈值 θ=0.50；技能库上限 300 条。

## 3. 实验设计

### 3.1 评估基准

- **SuperGPQA**：Math、Management、Science（过滤为中等与困难难度）；
- **MMLU-Pro**：Law、Philosophy、History；

### 3.2 两种评估协议

1. **流式协议（Streaming）**：问题按序列流处理，前面生成的技能立即写入技能库供后续问题使用，衡量持续积累能力；报告 3 种随机问题顺序的平均准确率。
2. **留出协议（Held-out）**：按 2:1 划分采集集与测试集，在测试集上禁用搜索、仅复用冻结的技能库，衡量技能的内在可复用性。

### 3.3 对比基线

- **搜索增强类**：Direct Inference（直接推理）、Search Agent（带搜索工具不训练）、Search Agent train（GRPO 训练搜索但无技能学习）；

- 所有方法共享相同骨干（Qwen3-4B、Qwen3-8B）、相同搜索环境（Google Search API + 页面压缩工具 + 沙箱 Python）与相同嵌入模型。

## 6. 主要结论与发现

1. **主结果**：流式协议下，Search2Skill train 相对直接推理在 Qwen3-4B 上提升 **+8.3%**、在 Qwen3-8B 上提升 **+9.3%**；留出协议下分别提升 **+5.1%** 和 **+6.6%**，均优于所有搜索增强与技能学习基线。
2. **增益来源是技能抽象而非原始证据**：复用抽象技能比缓存原始检索证据平均高 **+4.5%**（表 3）。
3. **RL 修复了全套流水线失败模式**：五类失败（错过搜索触发、搜索查询差、格式错误、技能覆盖不足、技能幻觉）的失败占比从训练前平均 25.3% 降至训练后 11.9%。
4. **奖励消融**：去掉任一 rubric 奖励都会导致性能下降；r_when 贡献最大（去掉后搜索率飙升至 96.6%，准确率下降 3.8%），说明三个奖励互补。
5. **技能可跨模型规模迁移**：8B 模型挖掘的技能库使 4B 执行器提升 +4.1%、14B 执行器提升 +3.5%，且均优于对应基线；4B + Search2Skill 技能在 Science 上（56.5%）超过无辅助 8B 直接推理（50.0%），技能可作为"外部能力支架"。
6. **样本效率优越**：在 Philosophy 上仅用 168 个问题即从 51.8% 跳升至 57.2%，而内视型基线几乎停滞。

## 7. 方法亮点与优点

- **突破知识边界的全新范式**：将"向内归纳轨迹"转向"向外搜索+蒸馏"，直接回应了专业领域技能难以从模型内部引出的根本问题。
- **联合优化三决策的奖励架构**：采用组对比门控将质量奖励与"已证明的能力缺口"绑定，避免了无差别探索，巧妙解决了探索必要性奖励的信用分配问题；公式简洁（单一门控 + 单一质量标量）。
- **技能质量的双重保障**：执行式复用分数（冻结骨干实测）+ 接地性审计（逐声明溯源），并叠加查询罚项，确保技能既泛化又忠实于证据。
- **实验设计精细**：流式 vs 留出双协议互补，分别衡量持续积累能力与内在复用性；排除"缓存原始证据"这一朴素替代解释；跨模型迁移验证了技能的中立性。
- **工程细节严谨**：原始题目拦截机制（防止直接检索题目答案）、技能分阶段揭示（先描述后展开）、库管理避免后处理干扰归因。

## 8. 不足与局限

- **检索组件未训练**：论文明确承认框架不训练检索部分本身，技能覆盖不足的减少仅来自技能生成的校准（更好的 use_when 描述），检索器的召回瓶颈可能限制上限。
- **评估范围有限**：
  - 行动空间仅限 3 类工具，未覆盖需要沙箱文件系统交互的 EvoAgentBench 其余 3 个 split；
  - 训练数据仅覆盖 5 个领域，与 8 个评估领域存在分布差异，跨领域泛化结论的普适性仍需更多测试。
- **基线覆盖不完整**：论文未与同时代的其他外部搜索技能蒸馏方法（如有）对比；SkillOpt 在留出设置下的批次级优化特性使其无法与流式方法直接比较，对比维度略有割裂。
- **LLM 裁判的主观性风险**：查询质量和接地性均依赖 Qwen3.7-Max 的零样本判断，存在裁判偏好偏差；未报告裁判与人类判断的一致性率。
- **计算成本较高**：每次 RL 训练需在线评估技能复用（3 个相似问题 × 2 次推理），且 4B 与 8B 各约 17~22 小时，大规模扩展（如 32B/235B 骨干）的实际可行性未验证。
