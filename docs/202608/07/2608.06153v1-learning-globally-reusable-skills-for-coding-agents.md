## 摘要
自动技能进化使大型语言模型（LLM）智能体无需昂贵的重新训练即可持续改进。然而，现有方法通常将技能进化视为一系列局部更新，忽略了技能之间的关系，并且常常产生过度拟合的技能更新，无法跨任务泛化。我们提出GSE，一种全局化的技能进化框架，联合优化技能兼容性和技能泛化性。为了保持技能库的一致性，GSE维护一个技能关系图（SRG），显式建模并共同进化技能间的关系。为了提高泛化性，GSE执行基于聚类的技能整合，从局部更新中抽象出可复用能力，并采用回放驱动的验证来防止过度拟合和行为退化。我们在两个代表性的软件工程任务上评估GSE：揭示缺陷的测试生成和误报缺陷报告过滤。在OpenHands和mini-SWE-agent这两个最先进的编码智能体中，GSE始终取得最佳的精确率、召回率和F1分数。与现有进化技术相比，GSE在测试生成中将精确率和召回率提高了6.1%~34.1%和31.8%~180.0%，在误报过滤中提高了15.4%~96.4%和13.1%~19.8%。在内部工业智能体上的部署进一步使F1分数提高了61.4%，证明了GSE在进化有效技能方面的有效性和泛化性。

## Abstract
Automated skill evolution enables Large Language Model (LLM) agents to continuously improve without expensive retraining. However, existing approaches typically treat skill evolution as a sequence of local updates, overlooking relationships among skills and often producing overfitted skill updates that fail to generalize across tasks. We propose GSE, a globalized skill evolution framework that jointly optimizes skill compatibility and skill generalization. To preserve consistency across the skill bank, GSE maintains a Skill Relation Graph (SRG) that explicitly models and co-evolves inter-skill relationships. To improve generalization, GSE performs cluster-based skill consolidation to abstract reusable capabilities from local updates and employs replay-driven verification to prevent overfitting and behavioral regressions. We evaluate GSE on two representative software engineering tasks: bug-revealing test generation and false-positive bug report filtering. Across two state-of-the-art coding agents, OpenHands and mini-SWE-agent, GSE consistently achieves the best precision, recall, and F1-score. Compared with existing evolution techniques, GSE improves precision and recall by 6.1%~34.1% and 31.8%~180.0% for test generation, and by 15.4%~96.4% and 13.1%~19.8% for false-positive filtering. Deployment on an internal industrial agent further yields a 61.4% improvement in F1-score, demonstrating the effectiveness and generalizability of GSE for evolving effective skills.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：大型语言模型（LLM）智能体被广泛应用于软件工程任务（如测试生成、缺陷分析），但其静态设计（固定提示词、工具策略、人工技能库）难以适应多样化的编程语言、项目约定和故障模式。自动技能进化（skill evolution）作为无需重新训练模型的轻量级改进手段，受到越来越多的关注。
- **核心问题**：现有技能进化方法（如 Live-SWE-agent、Trace2Skill）将进化视为一系列独立的局部更新，存在两个关键缺陷：
  - **局部生成不兼容**：仅从单条执行轨迹生成更新，忽略技能间的依赖、互补或冲突关系，可能破坏技能库的整体一致性。
  - **局部成功难泛化**：从单条轨迹得到的更新高度特化，直接合并容易导致技能碎片化、过拟合，无法跨任务复用，甚至引发行为回退。
- **整体含义**：论文主张技能进化应被建模为**全局优化问题**，而非局部更新序列；需要同时保证技能间的兼容性（compatibility）和技能本身的泛化性（generalization），从而实现长期有效的智能体持续学习。

## 2. 论文提出的方法论：核心思想、关键技术细节

提出 **GSE（Globalized Skill Evolution）** 框架，核心思路是将技能库视为相互关联、可复用的系统，并围绕三个环节进行全局优化：

- **① 轨迹收集（Trace Collection）**：
  - 对底层智能体进行插桩，记录其推理步骤、工具调用、命令参数、环境反馈和任务结果。
  - 对原始轨迹进行简化：过滤文件搜索命令的冗长输出、原始文件内容、低价值日志等，保留命令、目标路径、关键错误信息和推理块，以提高后续分析的效率。

- **② 进化提案生成（Evolution Proposal Generation）**：
  - **失败诊断**：分层判断失败源于导航（context exploration）、推理（reasoning）还是执行（execution），并区分两类进化方向：通用能力增强（general capability enhancement）和可复用问题模式（reusable problem pattern）。
  - **技能关系图（Skill Relation Graph, SRG）**：将技能库建模为有向图 G=(V,E)，节点为技能，边表示三种关系：
    - dependency（技能 vj 依赖 vi 的假设或结果）；
    - co-usage（技能互补，联合使用效果更佳）；
    - conflict（技能提供冲突指导，不应同时激活）。
  - **关系感知的传播**：提出技能更新时，通过 SRG 查找受影响技能，若更新改变其假设、中间输出、适用条件或交互模式，则生成辅助进化提案，共同进化技能内容和关系。
  - **DSL 结构化提案**：提案包含操作（Operation）、目标技能（Target Skill）、具体内容（Content）、理由（Rationale）、预期效果（Expected Behavior）和关系更新（Relationship Updates），以降低歧义并便于下游处理。
  - **本地验证**：在临时技能库上应用提案并重放原始失败案例，不能解决的直接丢弃，过滤低效提案。

- **③ 技能泛化（Skill Generalization）**：
  - **基于聚类的技能整合（Cluster-based Skill Consolidation）**：
    - 对修改现有技能的提案，按受影响技能集合聚类（相同技能缺陷往往反映相同能力缺口）。
    - 对于新建技能，按 rationale 和预期效果的语义相似度聚类。
    - 聚类后由 merge agent 提取共同能力模式，去除案例特定细节，形成更高层的通用技能，构建候选技能库。
  - **回放驱动的验证（Replay-Driven Validation）**：
    - 对修改现有技能的候选库，回放受影响技能相关的历史案例；
    - 对新技能，回放生成该聚类的所有案例；
    - 仅当候选技能库维持或提升性能时才被接受，从而防止过拟合和行为回退。

- **整体流程**（算法 1 所示）：收集轨迹 → 生成提案 → 本地验证 → 聚类整合 → 回放验证 → 合并入技能库。

## 6. 论文的主要结论与发现

- **测试生成**：GSE 在 OpenHands 上 F1 达 0.31（最强基线为 0.22，提高 40.9%）；在 mini-SWE-agent 上 F1 达 0.38（最强基线为 0.29，提高 31.0%）。相比现有进化技术，precision 提高 6.1%~34.1%，recall 提高 31.8%~180.0%。
- **误报过滤**：GSE 在 OpenHands 上 F1 达 0.70（基线最高 0.43）；在 mini-SWE-agent 上 F1 达 0.46（基线最高 0.39）。precision 提高 15.4%~96.4%，recall 提高 13.1%~19.8%。
- **人工技能缺陷**：人工技能在 OpenHands 上有一定提升，但在 mini-SWE-agent 上反而略有降低，体现出静态技能的脆弱性。
- **现有进化方法局限**：Live-SWE-agent 和 Trace2Skill 提升有限，主要因为局部更新不能协调技能关系、无法验证泛化。
- **消融结果显示**：去掉 SRG 或去掉技能泛化都会显著降低性能（测试生成 F1 从 0.31 降至 0.27；误报过滤 F1 从 0.70 降至 0.59 或 0.54），说明两个组件缺一不可。
- **工业部署**：在内部智能体上，GSE 将 F1 从 0.43 提升到 0.71（提升 65.1%；相比人工技能提升 61.4%），表明 GSE 对较强工业智能体依然有效。
- **成本效益**：GSE 以适度进化成本（+12.28% token）换取显著性能提升，且任务执行时 token 消耗最低，效率优于人工技能和现有进化方法。
