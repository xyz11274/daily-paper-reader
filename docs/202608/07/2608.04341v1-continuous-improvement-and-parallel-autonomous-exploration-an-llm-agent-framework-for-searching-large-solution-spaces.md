## 摘要
我们提出一个框架，为LLM代理提供两种机制，使其能够自主搜索大型解空间。首先，一个基于留出数据评分的排行榜充当奖励信号，驱动每个代理在重复提交中不断改进其解决方案，这一循环即使只有一个代理也能运行。其次，该框架支持完全自主地并行运行多个代理，无需人类参与：代理各自独立地进行分析、调研方法、实现、自我评估、提交和修订，而一个协调代理仅负责后勤事务。在共享奖励下并行运行代理，能够拓宽所探索的解空间区域，而不是仅仅细化单一初始范式。我们将该框架实例化到商品-目录匹配任务上（一个核心电商检索任务，具有大规模、类别结构的解空间），并将其表述为带有精确率-覆盖率工作点的选择性预测问题。单个代理会在其初始范式中细化，而并行自主代理则会浮现出性质不同的解决方案。在此测试平台上，最佳合格覆盖率（每个类别≥95% P@1）在单个代理时达到47.8%-57.4%，五个代理时达到62.8%-69.4%，而基线为33.3%。我们的贡献在于框架本身：一个持续改进的奖励循环，以及一个完全自主并行探索的基础，并附有案例研究证据。

## Abstract
We present a framework that gives LLM agents two mechanisms for searching large solution spaces autonomously. First, a leaderboard scored on held-out data acts as a reward signal that drives each agent to refine its solutions over repeated submissions, a loop that operates even with a single agent. Second, the framework enables running many agents in parallel, fully autonomously, with no human in the loop: agents independently analyze, survey methods, implement, self-evaluate, submit, and revise, while a moderator agent handles only logistics. Running agents in parallel under the shared reward broadens the explored region of the solution space rather than refining the single seeded paradigm. We instantiate the framework on product-to-catalog matching (a core e-commerce retrieval task with a large, category-structured solution space), posed as selective prediction with a precision-coverage operating point. A single agent refines within its seeded paradigm, whereas parallel autonomous agents surface qualitatively different solutions. On this testbed, best qualified coverage (>=95% P@1 per category) reaches 47.8-57.4% with a single agent and 62.8-69.4% with five, against a 33.3% baseline. Our contribution is the framework itself: a continuous-improvement reward loop and a substrate for fully autonomous parallel exploration, backed by case-study evidence.

- **核心问题**：如何让 LLM 代理在**大解空间**中自主、高效地搜索解决方案。许多实际优化问题（如电商检索）解空间庞大，且需要任务特定的优化策略，传统的单代理、单范式搜索容易陷入局部最优。
- **研究动机**：
  - 现有 LLM 代理多聚焦于**协作式**多代理架构（如 MetaGPT、ChatDev、CAMEL），缺乏对“共享奖励下的并行自主探索”这一机制的研究。
  - 已有迭代优化方法（如 Reflexion、Agent-K）多为**单代理**闭环，缺少多代理并行扩展。
  - 产品-目录匹配（product-to-catalog matching）具有**大规模、类别结构化**的解空间，不同类别适用不同方法，是检验自主探索的理想测试床。
- **整体含义**：论文提出了一个**通用框架**，为 LLM 代理提供两种互补的搜索机制——**持续改进奖励循环**（单代理也可运作）和**完全自主的并行探索**（多代理共享奖励、无人在环），并以案例研究提供证据。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想

> 以**留出测试集上的排行榜分数**作为奖励信号，驱动代理反复提交、观测分数、自我修订；同时支持多个独立代理并行运行，在共享奖励下拓宽解空间的探索范围。

### 2.2 两个核心机制

1. **持续改进奖励循环（Continuous-Improvement Reward Loop）**
   - 代理在**训练集**上自评、实现方法、提交测试集预测；
   - 排行榜 API 基于**留出的测试集标注**计算 P@1 与覆盖率，判断是否合格（每类别 P@1 ≥ 95%），按合格提交的**平均覆盖率**排名；
   - 代理可查看完整排行榜（含分数与方法简述），据此修订并再次提交——该循环**即使只有一个代理也能运作**。

2. **并行自主探索（Parallel Autonomous Exploration）**
   - 多代理（实验中为 5 个）**相互独立**地全流程运作：分析数据 → 调研方法 → 提出假设 → 实现 → 自评 → 提交 → 修订；
   - 代理之间**仅共享排行榜分数和高层方法描述**，不共享代码，结构上防止相互复用；
   - 一个**协调者代理**（moderator）只处理后勤（时间警告、排行榜更新、GPU 队列管理），**不提供技术指导**，保证无人类在环。

### 2.3 关键基础设施与安全措施

| 组件 | 功能 |
|------|------|
| **LeaderboardAPI** | 评估提交、计算指标、检查资格、排名、写入持久化 JSON 账本 |
| **训练/测试分离** | 训练含标注供自评；测试不含标注，必须提交后才能评分；严格的目录权限边界 + 自动化预运行泄漏检查 |
| **代理工作区隔离** | 每个代理独立工作目录，结构上防止读取他人产物 |
| **GPU 资源管理** | 两层级锁，30 分钟 CLAIM/RELEASE 协议 + 系统级看门狗终止未授权 GPU 进程 |
| **持续运行强制** | 心跳机制 + 固定节奏进度汇报 + 协调者定时警告 + 截止时强制终止 |

### 2.4 任务形式化

- 输入：用户 Listing \( q = (t_q, d_q, m_q, c_q) \)（标题、描述、元数据、类别）；
- 输出：正确目录 SKU \( s^* \in \mathcal{S}_{c_q} \)（该类别目录，最多 33K SKU）；
- **选择性预测**设定：低置信度 Listing 可弃权，换取高精确率；
- 指标：**P@1**（覆盖预测中 top-1 正确的比例）、**覆盖率**（做出预测的 Listing 比例）；
- 目标：每个类别独立满足 P@1 ≥ 95%，其中最大化平均覆盖率。

## 6. 主要结论与发现

- **持续改进有效**：排行榜奖励驱动单代理也能大幅超越基线——最佳合格覆盖率从 33.3% 提升至单代理 47.8–57.4%，并行五代理 62.8–69.4%（表 2）。

| 指标 | 基线 | 单代理 | 并行（5） |
|------|------|--------|-----------|
| 最佳平均覆盖率 | 33.3% | 47.8 / 57.4 / 49.9 | 62.8 / 69.4 / 68.2 |
| 最佳平均 P@1 | 97.3% | 96.7 / 96.7 / 95.1 | 95.1 / 95.1 / 95.1 |

- **深度 vs 广度**：单代理在种子范式内深度迭代（反复调 BGE-M3 变体与阈值），从不尝试非嵌入方法；并行代理则拓宽搜索，浮现出 TF-IDF 重排、字符串相似度匹配等**性质不同**的方法。
- **范式逃逸**：所有 3 次单代理运行均未跳出嵌入范式（60～124 次提交内）；所有 3 次 5-代理运行中，均有代理在会话内达到非嵌入方法。收益集中在最难的“智能手机”类别（单代理 0.8–1.9% vs 并行 24.8–41.1% 覆盖率）。

## 7. 优点

- **框架贡献明确**：提出的“排行榜奖励循环 + 并行自主探索”组合是一个**任务无关**的通用基础设施，而非特定任务的技巧堆叠。
- **工程严谨性**：训练/测试分离、自动化泄漏检查、目录权限边界、GPU 锁与看门狗等设计细节，体现了系统级的安全考量；观察到的“尝试复用他人产物”行为被结构性阻止。
- **去中心化的信息共享**：代理共享分数与方法描述但不共享代码，既支持分化又保持独立。
- **诚实的实验报告**：明确区分描述性结果与因果断言，不夸大结论，并主动指出混杂变量和缺失的对照条件。
- **任务选择恰当**：类别结构化解空间 + 精确率-覆盖率工作点，天然适合检验“广搜索”与“深细化”的权衡。

## 8. 不足与局限

- **因果性不足**：单代理 vs 并行的覆盖率差异与代理数量、总计算量、GPU 争用、排行榜可见性混杂，不能作为缩放规律解读。
- **缺乏关键对照**：无“无种子”对照条件，无法区分“种子基线导致窄搜索”与“模型自身先验导致窄搜索”。
- **任务覆盖有限**：仅验证于单一任务（商品-目录匹配），跨任务（如搜索排序、推荐、列表质量检查）的泛化尚未实证。
- **模型单一性**：全部代理使用 Claude Sonnet 3.5，结论可能受模型特定行为影响。
- **安全性未审计**：代理自主编写和提交的代码未经人工安全审查；基础设施边界只能防止跨代理损害，但无法审计代码本身。
- **时间范围有限**：5 小时会话属于有界任务，更长时段、成功标准模糊的开放式场景未验证。
- **单代理 P@1 略高于并行**（95.1–96.7% vs 95.1%）：并行的广度探索以每组代理的精确率为代价（深度与广度的固有取舍，论文已承认）。
