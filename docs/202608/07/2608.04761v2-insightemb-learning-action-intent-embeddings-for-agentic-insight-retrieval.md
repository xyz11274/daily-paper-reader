## 摘要
自我改进的智能体会从先前的轨迹中积累可复用的洞察，使得检索对于将积累的经验转化为可操作指导变得越来越重要。在每个决策步骤，检索到正确的洞察可以帮助智能体朝向目标前进，我们将这一设置称为智能体洞察检索。然而，现有的检索方法主要建模语义相似性，而忽略了所检索到的洞察是否能解决智能体当前的决策瓶颈。我们提出InsightEmb，一种对比嵌入框架，仅使用数学推理数据即可学习可迁移的、以进展为导向的检索几何结构。InsightEmb联合学习将具体情境与抽象启发式规则对齐，并聚类具有相似进展结构的推理轨迹。我们在动态智能体任务和一个静态技能检索基准上评估了InsightEmb。在没有任何环境特定训练的情况下，InsightEmb在所有评估中都取得了改进，超越了现有推理嵌入模型的性能。这些结果表明，状态-洞察匹配的几何结构可以跨域迁移，使得能够从公开可用的推理数据中进行有效训练，而无需昂贵的环境特定监督。

## Abstract
Self-improving agents accumulate reusable insights from prior trajectories, making retrieval increasingly important for turning accumulated experience into actionable guidance. At each decision step, retrieving the right insight can help the agent progress toward its goal, a setting we refer to as agentic insight retrieval. However, existing retrieval methods primarily model semantic similarity, while overlooking whether a retrieved insight resolves the agent's current decision bottleneck. We propose InsightEmb, a contrastive embedding framework that learns transferable progress-oriented retrieval geometry using only mathematical reasoning data. InsightEmb jointly learns to align concrete situations with abstract heuristic rules and to cluster reasoning trajectories with similar progress structures. We evaluate InsightEmb on dynamic agent tasks and a static skill-retrieval benchmark. Without any environment-specific training, InsightEmb improves over all these evaluations, surpassing the performance of existing reasoning embedding models. These results suggest that the geometry of state-insight matching can transfer across domains, enabling effective training from publicly available reasoning data without expensive environment-specific supervision.

## 1. 核心问题与整体研究动机

### 研究背景
- 基于 LLM 的智能体（LLM agent）在交互式环境（如网页导航、具身任务、工具使用）中通常采用 ReAct 等推理-行动交替框架，需要在庞大的动作空间中做出决策。
- 先验研究表明，为智能体提供从过去经验中蒸馏出的**洞察（insight）**——即抽象规则和策略（例如"在随机探索前先检查目标可能所在的位置"）——能有效提升任务表现。
- 这些洞察来自智能体对历史轨迹经验的自我改进，因此**如何动态检索到当前决策步骤最相关的洞察**成为关键问题。

### 核心问题
- 现有检索方法（如标准嵌入模型、RAG 检索器）主要建模**语义相似性（semantic similarity）**，却忽略了核心问题：**检索到的洞察是否真正解决了智能体当前面临的决策瓶颈（decision bottleneck）**，是否能让智能体朝目标取得实质进展。
- 作者将这一任务命名为**智能体洞察检索（agentic insight retrieval）**，并将"相关"定义为**以进展为导向（progress-oriented）**：一个洞察只有在被使用后能缩小与目标之间的差距时才算有用，而非仅仅与当前观察在表述上相似。

### 核心挑战：抽象鸿沟（Abstraction Gap）
- 查询（智能体当前的具体观察 + 动作历史）与目标（抽象的洞察规则）处于**不同抽象层级**，相关性的判定取决于智能体的**下一步意图**，而非主题相似度。
- 举例：在 ALFWorld 的"把热土豆放进冰箱"任务中，标准检索器会检索到"加热规则"，但如果智能体尚未找到土豆，真正该检索的是"搜索优先级"规则——这正是主题相关与程序相关的语义鸿沟。

### 关键洞察（本文的突破口）
- 智能体情境与抽象规则的匹配问题**并非领域特有**：数学推理中的"具体问题 → 抽象解题启发式"与具身任务中的"具体状态 → 执行策略"共享相同的**结构**——检索到的规则应能解决当前瓶颈、促成下一次有效行动。
- 因此，可以利用公开可得的数学推理数据训练一个跨域可迁移的嵌入模型，无需昂贵的环境特定监督。

## 2. 方法论：InsightEmb 两阶段对比训练框架

### 2.1 核心思想
- 设计一个**动作意图嵌入（action-intent embedding）**：对于一个情境 s =（目标 g，动作历史 h，观察 o），其动作意图是该情境中必须被解决的**潜在瓶颈**。嵌入函数 fθ 应将情境排序在与其进展相关（而非主题相关）的洞察附近。
- 核心设计主张：**数学启发式检索与智能体洞察检索是同一类"情境→瓶颈解决规则"匹配问题**——如表 1 所述，数学中的"问题陈述↔解题启发式"、智能体任务中的"任务+观察↔执行策略"构成结构类比。

### 2.2 训练数据构建流程（蒸馏管道）
1. **轨迹收集**：每个训练数学问题运行 5 次 rollout，记录完整交互历史，并标注成功/失败。
2. **洞察蒸馏**：通过 LLM（主实验用 DeepSeek-R1，鲁棒性实验用 GPT-5.2）对轨迹子集进行多子集遗传搜索，生成 BUNDEL 洞察（多规则摘要）和 ATOMIC 洞察（单条规则，去除思维链）。
3. **效用过滤（公式 1）**：每个候选洞察通过"预置到问题前是否提升该问题的解题率"来判定归属——提升则归入 I⁺，否则归入 I⁻。该标签将对比损失与**经验证明的进展**而非作者主观判断绑定。

### 2.3 Stage 1：情境到洞察匹配（Situation-to-Insight Matching）
- **目标**：弥合抽象鸿沟——让模型学习将数学问题与相应启发式规则匹配。
- **查询形式**：三种（i）纯问题陈述；（ii）问题+完整思维链轨迹；（iii）问题+截断部分轨迹。同一问题在三种形式下共享同一组 I⁺/I⁻ 标签，保证跨执行阶段的检索一致性。
- **训练数据规模**：11,950 对对比样本，涵盖计数与概率（4,383）、数论（4,620）、几何（2,947）三个数学域（来自 MATH 数据集）。
- **训练目标（InfoNCE 对比损失，公式 3）**：
  - L₁ = −log [ exp(sim(fθ(q), fθ(I⁺))/τ) / Σ_{I∈{I⁺}∪N} exp(sim(fθ(q), fθ(I))/τ) ]
  - 温度参数 τ = 0.01，训练组大小 11，负样本包括批次内负样本（in-batch negatives）。

### 2.4 Stage 2：情境到经验匹配（Situation-to-Experience Matching）
- **目标**：让模型在相同抽象层级上识别**结构相似**的情境——即两个看似不同的情境是否需要相同的推理策略。这能增强情境表示本身的结构聚类，反过来稳定 Stage 1 学到的抽象匹配。
- **实现**：与 Stage 1 共享相同的对比目标和数学数据，差异仅在于匹配目标由抽象规则替换为**结构相似的已解题**（T⁺ 为结构相似题，T⁻ 为不相似题）。
- **训练数据规模**：2,896 对（计数概率 966、数论 966、几何 964）。

### 2.5 推理：动态洞察检索
- 无需任何环境特定微调。每个决策步骤 t，对当前状态 sₜ 添加一个**任务无关的指令前缀**（如"给定一个 ALFWorld 任务观察，检索能有效帮助智能体解决任务的洞察或策略"），编码后在预编码的洞察语料库中检索 top-k 最相似洞察，预先置入 LLM 的提示。
- 检索准则：I* = arg max sim(fθ(sₜ), fθ(I))（公式 2）。

### 2.6 基座模型与训练配置
- 基于 Qwen3-Embedding-4B 微调，使用 DeepSpeed ZeRO-3、8 张 GPU，学习率 1×10⁻⁵（余弦调度）、批大小 8×2 梯度累积、温度 0.01、最大序列长度 1,536 tokens、训练 6 轮、warmup 0.1。Stage 2 从 Stage 1 的检查点继续训练。

## 7. 局限性与潜在风险

1. **洞察语料质量的依赖**：InsightEmb 的检索质量上界受限于预生成的洞察语料。若语料库本身缺少针对某类瓶颈的洞察，或洞察表述含混/带有幻觉成分，即使检索完全准确也无法提升智能体表现。
2. **数学域与智能体域的结构类比依赖**：训练数据全部来自竞赛数学（MATH 数据集），其与具身/网页/科学环境之间的结构同构性是本文的核心假设。虽然实验验证了正向迁移，但对于动作空间语义更复杂、瓶颈定义更模糊的领域（如开放式对话、多智能体协作规划），该假设的适用性尚未得到验证。
3. **进步判定的二元性**：效用过滤（公式 1）仅区分“提升/不提升解题率”的二元归属，未建模不同洞察间的边际效用差异或组合效应。多个洞察可能协同生效，单一洞察的独立效用可能被低估或高估。
4. **检索的局部贪婪性**：动态检索在每个决策步独立选取 top-1/top-k 洞察，未考虑跨步检索结果的全局一致性。若某一步检索到错误类别的洞察，模型缺少显式的纠错/回退机制来撤消其负面影响。
5. **成本未完全透明**：训练使用 8 张 GPU 但未披露 GPU 型号、训练时长、总 token 消耗；推理阶段为每个决策步编码当前状态（Qwen3-Embedding-4B 规模），在长 horizon 任务中的累计编码开销可能不可忽略。

## 8. 结果可信度评估

### 8.1 指标相关性
- 动态环境统一使用**任务成功率**（ALFWorld/ScienceWorld）或**平均任务分**（WebShop），是与最终应用目标直接对齐的客观指标；SRA-Bench 使用检索召回率/NDCG，标准且可复现。
- 所有基线共享同一动作模型、历史窗口、步数上限与检索协议，控制了混淆变量。

### 8.2 统计可靠性
- ALFWorld 评测 140 局、WebShop 与 ScienceWorld 各 500 局，样本量足以支撑几个百分点的成功率差异判断。
- 论文**未报告多次独立运行的平均与方差/置信区间**，也未说明是否做了显著性检验（如配对 bootstrap 或 t 检验）。考虑到动作模型为贪婪解码（无采样噪声），成功率的差异主要来自检索注入顺序，方差可能相对可控，但这一信息未被量化。

### 8.3 消融充分性
- 覆盖了训练监督来源（数学 vs 域内）、查询形式（有无半轨迹）、洞察生成器、动作模型、检索预算（k）、语料粒度（BUNDLE/ATOMIC）等关键维度，消融体系完整。
- 一个未覆盖的消融是：**只训练 Stage 1（不加 Stage 2）**的单独贡献评估。论文将两阶段作为整体使用，未单独报告 Stage 2 的独立边际增益，这削弱了 Stage 2“情境到经验匹配”设计必要性的直接证据。

### 8.4 泛化边界
- 三个动态环境均为**单智能体、工具受限、目标明确**的封闭式任务。对开放式、多模态、多智能体环境的泛化尚未验证。
- 静态评测 SRA-Bench 主要验证通用检索能力，但其任务族中与“智能体决策瓶颈”最接近的工具使用/代码生成任务并未单独分析排序提升的来源。

## 9. 启发与未来方向

1. **进展驱动的检索范式**：本文提出的“以进展为导向（progress-oriented）”而非“以语义相似为导向”的检索准则，可推广到更广泛的 LLM 应用，如工具选择、示例选择（ICL）、记忆管理、代码修复等任一“当前状态→下一步最优策略”的场景。
2. **跨域监督的可行路径**：利用数学推理数据作为廉价、可扩展的训练信号，为具身智能体的记忆检索提供通用的嵌入先验，避免了对每个新环境重新收集有监督检索数据的成本。
3. **可解释的瓶颈分类**：观察到的六类共享瓶颈（搜索/识别、状态转换、验证、错误恢复、结构/布局、先策略后执行）为未来构建可解释的智能体反思机制提供了分类学基础。
4. **动态语料更新**：当前洞察语料是静态预生成的。未来可将 InsightEmb 与洞察反思/校验闭环结合，在任务执行后按效用过滤动态追加新洞察。
5. **多步全局检索规划**：将单步贪婪检索扩展为考虑跨步一致性（如基于已检索过的洞察集合调整下一步检索目标）的全局规划式检索，是自然的前进方向。

## 10. 总评

InsightEmb 是一篇**问题定义清晰、方法简洁、实验充分**的论文。其核心贡献不在于提出全新的模型架构，而在于**重新定义了智能体洞察检索的“相关性”标准**——从“主题相似”转向“进展相关”，并创造性地用数学推理数据作为跨域训练信号来学习这一标准。该方法具有一定的意外性与启发性：将具体问题与抽象规则的匹配视为跨领域通识结构，使得无需目标环境监督即可习得具有程序感知能力的检索嵌入。虽然论文在统计检验、Stage 2 独立消融等细节上仍有完善空间，但其方法在三个异构环境中的一致增益、优于域内微调的结果以及对“检索伤害”问题的改善，均有力地支撑了核心论点。该工作为智能体长期记忆与经验利用的研究提供了一个坚实的新基准与有价值的研究方向。
