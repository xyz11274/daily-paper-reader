## 摘要
长时程LLM智能体日益依赖外部执行支持来维持状态、跟踪进度、调用工具、验证结果并在交互中复用经验。然而，有效的装备使用带来了两个相互耦合的挑战：从噪声交互轨迹中形成状态，以及对外部状态访问的运行时控制。现有智能体通常通过提示、启发式规则或特定领域约定来处理这两者，使得外部工作空间及其使用策略需要手工设计。为解决这一问题，我们研究了装备策略学习问题，其中智能体离线学习装备策略，并在运行时任务执行过程中在线部署这些策略以构建和更新外部装备状态。我们引入了EvoHarness-RL，它将信念、进度与经验（BPE）暴露为面向策略的装备状态。监督式装备微调教会基础智能体装备动作空间以及如何构建有用的外部状态，而代价感知的GRPO则探索协调策略，以在长时程交互过程中选择性地读取、更新和整合该状态。在ALFWorld上以Qwen3-8B LLM实例化后，EvoHarness-RL达到了96.9%的成功率，并揭示了两个关键动态：装备退火，即训练将反复出现的装备使用模式内化到模型策略中，使智能体从频繁调用装备转向选择性地访问外部状态；以及装备演化，即进度更新和经验整合将装备提炼为紧凑、任务自适应的状态基底。这些结果表明，长时程智能体受益于可训练的策略来构建和协调外部装备工作空间，而不仅仅是添加更强的工具或更大的记忆。

## Abstract
Long-horizon LLM agents increasingly rely on external execution support to maintain state, track progress, invoke tools, verify outcomes, and reuse experience across interactions. However, effective harness use raises two coupled challenges: state formation from noisy interaction traces and runtime control over external-state access. Existing agents usually handle both through prompts, heuristics, or domain-specific conventions, leaving the external workspace and its usage policy manually engineered. To address this, we study the problem of harness policy learning, where agents learn harness policies offline and deploy them to construct and update external harness state online during runtime task execution. We introduce EvoHarness-RL, which exposes Belief, Progress, and Experience (BPE) as policy-facing harness state. Supervised harness fine-tuning teaches the base agent the harness action space and how to construct useful external state, while cost-aware GRPO explores coordination policies to selectively read, update, and consolidate that state during long-horizon interaction. Instantiated on ALFWorld with a Qwen3-8B LLM, EvoHarness-RL reaches 96.9% success and reveals two key dynamics: harness annealing, where training internalizes recurring harness-use patterns into the model policy and shifts the agent from frequent harness calls toward selective external-state access, and harness evolution, where progress updates and experience consolidation refine the harness into a compact, task-adaptive state substrate. These results suggest that long-horizon agents benefit from trainable policies for constructing and coordinating with external harness workspaces, beyond simply adding stronger tools or larger memories.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式与算法流程

### 2.1 核心思想：统一Harness抽象（BPE）

将异构的外部执行支持组件抽象为三种面向策略的功能角色（而非领域特定的内部实现），记为 `H_t = (B_t, P_t, E_t)`：

| 组件 | 英文 | 功能 | 对应问题 |
|------|------|------|----------|
| 信念 | Belief (B_t) | 当前环境状态的外部化估计（对象状态、位置、关系） | 智能体遗失环境当前真实状态 |
| 进度 | Progress (P_t) | 子目标分解与执行状态记录 `(g_i, σ_i)` | 智能体遗忘已完成/待办/阻塞的步骤 |
| 经验 | Experience (E_t) | 跨episode的复用知识（技能、失败模式、搜索先验） | 智能体重复发现相同程序或错误 |

### 2.2 Agent-Harness动作协议

定义紧凑的四个harness元动作：`A_bpe = {track, commit, recall, note}`，覆盖agent与BPE之间的主要信息流：

- **track**：从Belief读取特定对象/全局状态；
- **commit**：向Progress写入子目标或执行更新；
- **recall**：从Experience检索可复用知识；
- **note**：向Experience写入新见解（暂存后整合）。

策略动作空间为 `A = A_env ∪ A_bpe`，两者消耗相同的交互预算，即harness调用具有机会成本。

### 2.3 环境适配器（Environment Adapter）

- BPE是**功能接口**而非固定模式，通过环境适配器将领域特定信号接入通用BPE接口。
- ALFWorld实例化：
  - Belief：基于规则的动作-观测解析器，后台更新世界状态；由 `track [object]` 或 `track [world]` 选择性访问；
  - Progress：有界承诺计划列表（上限8个子目标），由 `commit [subgoal]` 更新；
  - Experience：跨episode技能库（通用技能、任务特定技能、常见错误、搜索先验），由 `recall` 和 `note` 访问；并行rollout期间主技能库固定，epoch边界由整合模型执行add/update/remove/forgetting操作。

### 2.4 两阶段训练管线

**Stage 1：监督式Harness微调（SFT）**
- 使用Claude Opus教师在同一BPE接口下收集成功轨迹（500个ALFWorld训练游戏 → 87条成功轨迹、1153个next-action样本）；

- 教师rollout中积累的经验初始化后续GRPO的技能库。

**Stage 2：成本感知GRPO优化**

奖励函数为五项加权组合：

```
R(τ) = R_succ(τ) + λ_eff·R_eff(τ) + λ_div(u)·R_div(τ) − λ_spam·R_spam(τ) − λ_inv·R_inv(τ)
```

## 6. 论文的主要结论与发现

1. **SOTA性能**：EvoHarness-RL在Qwen3-8B上达到**96.9%平均成功率**（seen）/ **86.6%**（unseen），较ReAct基线提升+49.0个百分点，使8B模型匹配Claude Opus 4.5水平；显著优于SkillOS（80.2%）和SkillRL（89.9%）。
2. **两阶段训练有效性**：推断时harness（56.4%）→ SFT（68.6%）→ GRPO（96.9%），逐级放大收益。
3. **BPE普适帮助**：对强模型也有显著提升（GPT-4.1 +22.1，GPT-5 +25.7，Claude Opus 4.5 → 98.5%）。
4. **关键动态一——Harness退火（Annealing）**：训练将重复的脚手架式harness使用内化为模型策略，从频繁调用转向选择性外部状态访问（每episode约1次）。动作级分解显示：recall最持久、commit/note快速衰减、track居中——不同动作的衰减率不同，证明策略学习的是环境自适应的协调模式而非固定分布。
5. **关键动态二——Harness演化（Evolution）**：经验库经历扩张→整合→致密化，最终形成包含通用技能、任务特定技能、错误修正和搜索先验的紧凑任务自适应状态基底，而非被动追加式存储。
6. **成本感知优化价值**：EvoHarness-RL在训练各阶段奖励均高于标准GRPO，说明显式harness协调比单纯RL更高效。

## 7. 优点：方法与实验设计的亮点

- **统一抽象的简洁性**：将异构harness组件压缩为BPE三个功能角色，既保持足够信息量支持长时程任务，又紧凑到可进行策略学习——是一个优雅的归纳偏置。
- **可训练协调层的首创性**：不同于Harness-1等将harness作为环境侧构造或提示约定，本文首次将harness访问作为一等的、可学习策略决策（harness policy learning）。
- **动作空间设计巧妙**：四个元动作（track/commit/recall/note）在信息流覆盖完整性与可学习性之间取得良好平衡；环境动作与harness动作共享预算的设计自然引入成本意识。
- **奖励塑形有深度**：时间相关的多样性退火权重（cosine annealing）有效防止策略坍塌，同时收获可解释的训练动态（harness annealing）。
- **环境适配器架构**：BPE接口与领域实现解耦，框架具有跨环境迁移潜力。
- **训练动态分析深入**：不仅报最终结果，还细致分析动作级退火差异（recall最持久等），增强了结论的可解释性和说服力。
- **案例研究具象化**：展示"recalled hint错误→agent纠错→写入note"的完整闭环，直观验证harness的"可复用但可修订"定位。

## 8. 不足与局限

- **环境单一性**：仅在ALFWorld（文本家庭任务）验证，未能展示在更复杂环境（软件开发、网页导航、机器人控制）中的有效性；ALFWorld的规则化环境可能低估了真实世界噪声的挑战。
- **任务相对简单**：ALFWorld子目标基本为顺序结构，Progress的有界列表实现（8子目标上限）在更具层次性或图结构依赖的任务中可能不足。
- **教师依赖**：SFT数据依赖Claude Opus教师，教师质量直接影响初始策略和技能库质量；虽然论文指出与SkillOS等使用相同骨干对比，但对专有模型的依赖仍可能影响可复现性。
- **经验库整合的隐性成本**：consolidation由Claude Opus在epoch边界执行，其成本未纳入训练开销报告；大规模部署时的可持续性存疑。
- **算力报告不完整**：未报告总训练时长（GPU-hours），也未对比不同配置下的计算成本，不利于实际部署决策。
- **多样性奖励度量偏粗**：`|{verb(a_t)}|/|τ|` 只统计动作动词类型的数量比例，可能无法完整反映语义多样性。
- **单模型验证**：仅使用Qwen3-8B作为可训练策略模型，不同规模/架构模型的harness学习行为是否一致未被验证。
- **动态的解释性局限**：harness annealing被解释为"策略内化"，但未通过注意力分析或可解释性工具直接验证内化机制。
