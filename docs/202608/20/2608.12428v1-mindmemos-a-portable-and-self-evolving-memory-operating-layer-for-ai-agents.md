## 摘要
记忆是AI智能体的核心组件，使它能够积累经验、维持个性化，并在长期交互中实现持续适应。然而，现有记忆系统在开发完成后通常保持固定，限制了其通过持续使用调整自身记忆模型、组织策略与过程性知识的能力。我们提出MindMemOS，这是一个可移植的自进化记忆运行层，它采用统一的实体属性时间结构组织开放世界信息。MindMemOS支持场景自适应记忆建模、高阶模式发现、自主记忆优化与持续技能进化。其MindMemEvolve算法采用验证驱动的进化搜索为目标场景优化记忆模式，而梦境机制通过合并冗余记录、解决冲突来巩固已积累的记忆。此外，隐式修正反馈可作为人在回路信号，用于识别和修正可能不准确或对齐错误的记忆。其MindSkillEvolve算法进一步将智能体执行轨迹转化为可复用、逐步细化的技能。MindMemOS在LOCOMO上取得94.03%的准确率，在PersonaMem上取得70.63%的准确率。MindSkillEvolve在SpreadsheetBench上的成功率相较于初始技能基线提升了9.2个百分点。

## Abstract
Memory is a core component of AI agents, enabling them to accumulate experience, maintain personalization, and adapt over long-term interactions. However, existing memory systems often remain fixed after development, limiting their ability to adapt their memory models, organization strategies, and procedural knowledge through continued use. We present MindMemOS, a portable and self-evolving memory operating layer that organizes open-world information using a unified entity property timestructure. MindMemOS supports scenario-adaptive memory modeling, higher-order pattern discovery, autonomous memory refinement, and continuous skill evolution. Its MindMemEvolve algorithm employs validation-driven evolutionary search to optimize memory schemas for target scenarios, whiledreaming consolidates accumulated memories by merging redundant records and resolving conflicts. In addition, implicit corrective feedback serves as a human-in-the-loop signal for identifying and revising potentially inaccurate or misaligned memories. Its MindSkillEvolve algorithm further transforms agent execution trajectories into reusable and progressively refined skills. MindMemOS achieves 94.03% accuracy on LOCOMO and 70.63% on PersonaMem. MindSkillEvolve improves SpreadsheetBench success by 9.2 percentage points over the initial-skill baseline.

## 2. 提出的方法论
### 核心思想
提出一个可移植、自进化的AI智能体记忆运行层MindMemOS，采用统一的**实体-属性-时间**三维结构组织开放世界信息，覆盖记忆从生成、检索、维护到进化的全生命周期，支持记忆模式和技能的持续自适应优化，可便捷集成到各类现有智能体框架。

### 关键技术细节
1. **三维记忆核心结构**：沿着实体（记忆的主体，如人、组织、事件）、属性（实体的特定特征，如偏好、关系）、时间（信息的有效时间）三个维度组织为记忆图，支持实体间语义关联、同一实体属性的时间线演进，保留历史信息不覆盖。
2. **两种记忆生成策略**：
   - MindVanilla：不需要预定义模式，处理自由文本对话，自动分块、去重，完成新增/更新/合并/跳过等操作，适配开放域场景；
   - MindSchema：基于动态场景模式，自动分话题、生成记忆子图、融合实体、合并到全局记忆图，支持从多个历史记忆合成高阶模式属性，适配特定场景。
3. **紧凑混合检索**：外层大语言模型做检索规划，内层结合BM25稀疏匹配和嵌入稠密匹配，支持正向（先找实体再找属性）和反向（先找属性再找实体）双向图遍历，通过检索键增强提升细粒度匹配精度，限制遍历范围避免冗余扩展。
4. **离线梦境记忆巩固**：以最近新增的记忆为种子，构建以实体为中心的巩固范围，两阶段检测冲突、冗余、低价值内容，生成非破坏性更新计划（合并冗余、归档过时、解决冲突），保留更新溯源，减少活跃内存容量同时解决冲突。
5. **人在回路反馈修正**：支持两种反馈模式：显式反馈（用户直接用自然语言修正记忆）、隐式反馈（从用户对智能体任务输出的修正中自动提取持久化记忆更新）；会按持久性将修正分为任务临时、场景特定、长期三类，避免将临时任务修正错误存入长期记忆。
6. **MindMemEvolve记忆模式进化算法**：以场景QA对的回答准确率为优化目标，采用大语言模型引导的进化算法搜索最优模式：流程为初始化初始模式种群→分簇做适应度评估→保留精英个体，通过错误诱导变异、随机变异、交叉生成新种群→多轮迭代后选择适应度最高的模式作为最优结果；变异过程结合错误信号做定向修复，用大语言模型的领域知识引导搜索，比纯随机搜索效率更高。
7. **MindSkillEvolve技能进化算法**：云端统一管理技能版本，自动收集智能体执行轨迹并绑定到对应技能版本，攒够批量轨迹后分析成功模式和重复失败，生成技能更新；分为无监督（仅用轨迹信息）和有监督（额外加入任务得分做监督）两种变体。
