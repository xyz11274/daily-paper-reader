## 摘要
在不熟悉的环境中学习行动，要求智能体推断世界如何运作，并随着新证据的出现修正这种理解。然而，有限的观察可能支持多个世界模型，这些模型能解释过去的交互，但在未见状态下会预测出不同结果。我们提出 Memento 3，在 Memento 系列基础上，使冻结的 LLM 智能体能够通过外部记忆持续学习显式世界模型。该智能体维护一个自然语言规则手册作为持久语义记忆，记录关于环境动态的可修正假设，同时将未知方面保持为未指定。它将该规则手册编译为可执行代码，用于预测和规划。通过观察、反思、规则修订、编译和验证的持续循环，智能体利用预测误差来改进规则手册及其代码。只有当 LLM 判断更新后的代码忠实于规则手册，并且逐单元精确回放能够复现观察到的状态转移时，更新后的代码才会被接受。我们将这一过程作为基于模型的递归自我改进（RSI）路径加以研究：智能体自主探索环境，修正其世界模型，并使用经过验证的更新来指导后续交互与学习，而底层 LLM 保持固定。一种群体扩展并行维护多个世界模型，共享交互证据，并利用它们的预测来指导探索。在 ARC-AGI-3 上，单模型智能体通关了全部 25 个公开游戏的所有关卡，平均相对人类动作效率（RHAE）达到 100.0，且仅使用人类动作数量的 44%。在一个 Atari Pong 案例研究中，学习到的反馈控制器在三个不同开局的三次评估回合中均以 21:0 获胜，且无需进一步调用 LLM。

## Abstract
Learning to act in unfamiliar environments requires agents to infer how the world works and revise that understanding as new evidence arrives. Yet limited observations can support multiple world models that explain past interactions but predict different outcomes in unseen states. We introduce Memento 3, building on the Memento series to enable frozen LLM agents to continually learn explicit world models through external memory. The agent maintains a natural-language rulebook as persistent semantic memory, recording revisable hypotheses about environment dynamics while leaving unknown aspects underspecified. It compiles this rulebook into executable code for prediction and planning. Through a continual loop of observation, reflection, rule revision, compilation, and verification, the agent uses prediction errors to refine both the rulebook and its code. Updated code is accepted only when the LLM judges it faithful to the rulebook and cell-exact replay reproduces the observed transitions. We investigate this process as a model-based route to recursive self-improvement (RSI): the agent autonomously explores the environment, revises its world model, and uses verified updates to guide subsequent interaction and learning, while the underlying LLM remains fixed. A population extension maintains multiple world models in parallel, sharing interaction evidence and using their predictions to guide exploration. On ARC-AGI-3, the single-model agent clears every level of all 25 public games, achieves a mean Relative Human Action Efficiency (RHAE) of 100.0, and uses 44% of the human action count. In an Atari Pong case study, a learned feedback controller wins 21:0 in each of three evaluated episodes with different openings, without further LLM calls.

## 1. 核心问题与整体含义

- **研究动机**：智能体进入陌生环境时，不仅要学习"哪些动作有用"，还要学习"动作会带来什么后果"。基于模型的方法通过世界模型预测动作后果，但有限交互历史往往留下一个"版本空间"——多个程序都能复现所有已观测转移，却在未观测状态上给出不同预测。例如"箱子在墙前停下"与"箱子在第7列停下"可能解释同一轨迹，但预测不同。
- **关键矛盾**：回放验证可以拒绝不一致的程序，却无法在多个一致候选中识别正确规则。因此智能体需要持续维护并修正其泛化假设。
- **整体含义**：论文提出 Memento 3，将 Memento 系列从"策略侧"（学习哪些决策/程序该用）扩展到"模型侧"（学习世界如何运作的规则）。核心设计称为 **Code as Model**：用自然语言规则手册作为持久语义记忆，编译为可执行代码用于预测与规划，在冻结 LLM 的前提下实现基于模型的递归自我改进（RSI）。

## 2. 方法论

- **核心思想**：智能体的外部学习状态为 `Zt = (Ht, ψt, θt)`，其中 `Ht` 是交互记录（证据），`ψt` 是自然语言规则手册（语义记忆/假设），`θt` 是可执行世界模型（用于预测、回放验证与规划）。规则手册陈述"相信什么规则"，执行代码固定"规则如何被应用"。
- **问题形式化**：环境建模为确定性、目标导向的 POMDP `M = ⟨S, A, O, T, ρ, G⟩`，目标集 `G` 未知。学习与控制被表述为 Bayes-adaptive POMDP，维护对状态与模型规则的信念 `bt(s, m)`。
- **五阶段持续学习循环**：
  1. **观察（Observation）**：执行动作 `at` 得到 `ot+1`，扩展记录 `Ht+1 = Ht ∥ (at, ot+1)`。
  2. **反思（Reflection）**：冻结 LLM 在三种修订选择中决策——保留、修订规则手册、仅修复代码。
  3. **规则修订（Rule Revision）**：若选择修订，LLM 修订算子 `Δϕ` 生成新规则手册 `ψ̃t+1`。
  4. **编译（Compilation）**：规则手册引导的编译器 `Cϕ` 从旧代码、新规则手册与记录生成可执行 `θ̃t+1`。
  5. **验证（Verification）**：双重条件——(a) LLM 判断代码忠实于规则手册（`θ ∈ [[ψ]]`）；(b) 逐单元精确回放复现所有已记录的下一次观测（`verify(θ; Ht) = 1`）。仅当两者同时满足才接受更新。
- **模型选择**：在多个可接受候选中，用 LLM 近似最小描述长度偏好（`Simplify_LLM`），即 `arg min [L(ψ) + L(θ|ψ)]`，可解释为在规则手册忠实先验下的 MAP 选择。
- **规划与控制**：在确定性点信念近似下，规划退化为在可执行模型 `M̂θ = ⟨Ŝθ, A, fθ, Ĝθ⟩` 中寻找最短目标路径，满足 `Vθ(x) = 0`（若 `x ∈ Ĝθ`），否则 `Vθ(x) = 1 + min_a Vθ(fθ(x,a))`。无可用计划时，LLM 选择中间探索目标。
- **群体扩展**：维护 `N` 个并行的规则手册–可执行对 `Φt = {(ψit, θit)}`，共享同一交互记录。每个规划回合按行为等价类均匀采样一个成员执行计划，所有成员用同一证据检验与修复。`N=1` 退化为单模型设置。该设计用于缓解"自确认"问题——错误模型若其动作从不暴露错误，可能长期不被证伪。
- **Git 记忆**：规则手册与编译模块存于版本控制仓库，每次迭代提交并打标签，使智能体可检视、diff、恢复任意历史版本。
