## 摘要
持续学习要求模型积累过往经验并将其迁移到新任务中。尽管持续学习已有大量研究，但现有工作大多局限于非具身场景，尚未扩展到具身环境。为填补这一空白，我们提出了 EmbodiedCLBench，这是首个用于评估自进化智能体持续学习能力的具身仿真基准。以组合泛化为核心评估原则，我们的基准评估智能体能否先从基础任务中学习，再重组所获技能以解决复杂、未见的高级任务。基于 EmbodiedCLBench，我们在多种智能体框架和学习方法上开展了大量实验，揭示了持续存在的局限性和独特行为。结果表明，虽然高级任务在零样本设定下几乎无法解决，但来自基础任务的经验能够带来持续改进。即使任务复杂度增加，这种经验带来的收益仍保持稳定。然而，这种改进并不随学习样本数量的增加而相应扩展，当前智能体无法从额外经验中提取有意义的信息。总体而言，我们的发现凸显了持续学习作为一种基础但尚未充分探索的能力，而我们的基准为在具身环境中设计有效的自进化智能体提供了宝贵资源。我们的代码和数据集可在 https://pku-value-lab.github.io/EmbodiedCLBench-homepage 获取。

## Abstract
Continual learning requires models to accumulate past experience and transfer it to new tasks. Despite substantial research on continual learning, existing work remains largely confined to non-embodied settings, without extending to embodied environments. To address this gap, we introduce EmbodiedCLBench, the first benchmark in embodied simulation for evaluating the continual learning capability of self-evolving agents. With compositional generalization as the core evaluation principle, our benchmark evaluates whether agents can first learn from basic tasks and then recombine the acquired skills to solve complex, unseen advanced tasks. Based on EmbodiedCLBench, we conduct extensive experiments across multiple agent harnesses and learning methods, revealing consistent limitations and distinctive behaviors. Our results show that while advanced tasks can be hardly solved under zero-shot setting, the experience from basic tasks enables consistent improvement. Such benefit from the experience remains stable even if the task complexity increases. However, this improvement does not scale accordingly with the number of learning samples, and current agents cannot extract meaningful information from additional experience. Collectively, our findings highlight continual learning as a fundamental yet underexplored capability, and our benchmark offers valuable resources for designing effective self-evolving agents in embodied environments. Our code and dataset are available at https://pku-value-lab.github.io/EmbodiedCLBench-homepage.

## 1. 核心问题与整体含义

- **研究动机**：自进化智能体（Self-evolving Agents）需要具备从过往交互中积累经验并迁移到新任务的能力，即持续学习（Continual Learning）。然而，现有持续学习研究大多局限于非具身场景（如知识密集型任务、数字交互环境、长期模拟世界），无法捕捉具身任务中固有的空间复杂性和物理约束。
- **核心空白**：具身智能基准虽然覆盖感知、导航、操作和规划等能力，但均未专门设计用于评估持续学习能力。因此，领域内缺乏一个专门用于评估自进化具身智能体能否积累经验并迁移到新任务的基准。
- **整体含义**：论文提出 EmbodiedCLBench——首个面向具身仿真的持续学习基准，以**组合泛化**（Compositional Generalization）为核心评估原则，衡量智能体能否先从基础任务学习技能，再重组这些技能以解决未见的高级任务。这一工作将持续学习定位为具身智能体的一项基础但尚未充分探索的能力。

## 2. 方法论

### 2.1 核心思想

- 以**组合泛化**作为持续学习能力的可操作化度量：如果智能体从基础任务中学习了技能，就应当能够重组这些技能元素来解决新颖的、更复杂的高级任务，而非从零学习每个新任务。
- 基础任务充当智能体的**测试时学习数据**（test-time learning data）和**记忆**（memory），在尝试高级任务前积累经验。

### 2.2 任务层级设计

- **原子动作（Atomic Actions）**：来自 TongSim 的单一对象交互（如"拿起杯子"），由一系列可执行步骤组成（如走向杯子、看向杯子、拿起杯子）。
- **基础任务（Basic Tasks）**：将少量原子动作组合为实用的家务操作（如"把杯子放在桌上"），涵盖六类能力：物体操作、空间放置、可及性控制、电器操作、活动驱动场景配置、家庭状态恢复。
- **高级任务（Advanced Tasks）**：组合更多原子动作（来自 2–4 个基础任务类别），如"整理房间"需要拿起书、放上书架、关闭柜子、关灯。

### 2.3 图构建与评估协议

- **状态转移图**：由于使用 TongSim 闭源版本无法在线仿真，构建离线可复现的状态转移图。每个图节点代表唯一环境状态（配对第一人称视角图像和动作候选集），每条边对应确定性状态转移。
- **路径构建**：定义初始状态和目标状态后，用广度优先搜索（BFS）找到最短路径；通过从最短路径节点扩展替代可执行动作来构建干扰路径。
- **评估流程**：
  - **学习阶段**：智能体完成基础任务以积累经验。
  - **测试阶段**：智能体尝试未见的高级任务。
  - **交互格式**：多轮交互——智能体接收任务描述和初始状态图像，每步从动作候选中选择一个动作，转移到下一状态并接收新图像，直到到达目标（成功）或耗尽步数预算（失败）。
- **动作候选三类型**：最优动作（沿最短路径）、次优动作（可执行但偏离最短路径）、无效动作（当前状态不可执行）。
- **成功率的计算**：SR = (1/N) Σ ci，其中 ci ∈ {0,1} 表示任务 i 是否完成。

### 2.4 文本生成与验证

- 任务描述和动作选项由 Qwen3.7-Plus 通过三阶段流水线生成（任务描述改写、逐状态选项改写、跨状态选项加固），旨在避免语言线索泄露正确答案。
- 三名标注者独立验证每个生成样本（图像、任务描述、动作选项），全部通过才保留。

## 3. 实验设计

### 3.1 基准与场景

- **仿真平台**：TongSim（闭源版本），提供 6 个场景、2 种相机高度、51 个物体类别、7 种原子动作。
- **任务规模**：共 268 个任务——168 个基础任务（六类各 28 个）+ 100 个高级任务。
- **复杂度**：每个原子动作含 3 步；基础任务最短路径 6 步（2 个原子动作），高级任务 12 步（4 个原子动作）。高级任务的原子动作来自 2–4 个基础任务类别。

### 3.2 评估设置

- **Zero-shot**：无学习阶段，直接执行基础任务和高级任务。
- **In-Context Learning (ICL)**：学习阶段完成 2 个相关基础任务，测试阶段将完整交互轨迹保留在上下文中。
- **Skill Learning**：学习阶段完成相同基础任务后，以 Markdown 格式写出简洁的技能总结；测试阶段仅提供技能总结而非交互轨迹。
- **步数预算**：测试阶段允许最短路径 + 3 步额外步数；学习阶段允许 + 6 步。

### 3.3 对比方法

- **四种智能体框架（Harness）**：OpenClaw、Claude Code、Codex、Hermes。
- **两种骨干模型**：Qwen3.8-Flash 和 GPT5.6-Terra（通过官方 API）。
- **主要指标**：成功率（Success Rate, SR）。

### 3.4 分析实验

- 组合复杂度影响（3–6 个原子动作）。
- 学习样本数量缩放（k=0 到 k=6）。
- 错误分析（最优/次优/无效动作选择率变化）。
- 步数预算敏感性（0–6 额外步数）。

- **主实验**：4 种 Harness × 2 种模型 × 3 种设置（Zero-shot、ICL、Skill Learning），覆盖基础任务和高级任务，共形成 8 组主要对比。

  - **局限**：分析实验主要使用 Hermes + Qwen3.8-Flash 单一组合，泛化性有限；未报告多次运行的方差或统计显著性；未与其他持续学习方法（如微调、记忆增强）进行对比。
  - **公平性**：所有 Harness 和模型在相同任务图和评估协议下测试，ICL 与 Skill Learning 使用相同的基础任务，比较条件基本对等。

## 6. 主要结论与发现

- **发现 1**：高级任务在零样本下几乎无法解决（成功率约 10%），但来自基础任务的经验能带来一致提升（ICL 和 Skill Learning 将成功率提升至 30% 以上），跨所有 Harness 和模型一致。
- **发现 2**：零样本成功率随组合复杂度增加而急剧下降，但持续学习带来的增益（相对于零样本）保持稳定（约 30%），表明持续学习收益对任务难度不敏感。
- **发现 3**：成功率不随学习样本数量相应扩展。单个基础任务即可带来显著提升（从 8%–10% 升至 28%–40%），但额外样本无一致进一步增益，表明当前智能体无法从额外经验中提取有意义信息。
- **发现 4**：持续学习改变了智能体的决策行为——无效动作减少 13%–20%，最优动作显著增加，次优动作略有增加。ICL 和 Skill Learning 方向一致，但 Skill Learning 的变化幅度更小。
- **发现 5**：随额外步数增加，所有设置成功率单调上升，且 ICL 和 Skill Learning 的上升斜率更陡；但即使最宽松预算下，经验智能体与零样本智能体的差距仍然显著，表明额外容忍度无法替代先验经验。

## 7. 优点

- **首创性**：首个面向具身仿真的持续学习基准，填补了持续学习研究与具身智能评估之间的空白。
- **评估原则清晰**：以组合泛化为核心原则，将抽象的持续学习概念操作化为可测量的任务层级（原子动作→基础任务→高级任务）。
- **离线可复现设计**：状态转移图支持并行离线评估，无需运行仿真器，同时支持对任务复杂度的灵活控制和细粒度行为分析。
- **防泄露机制**：三阶段 LLM 生成流水线 + 人工验证，通过改写任务描述和动作选项避免语言线索泄露正确答案，迫使智能体依赖视觉推理。
- **多维度分析**：除主实验外，还系统分析了复杂度影响、样本缩放、决策行为和步数预算，结论丰富且具有实践指导意义。
- **跨框架验证**：在 4 种 Harness 和 2 种骨干模型上验证，结论具有较好的泛化性。
