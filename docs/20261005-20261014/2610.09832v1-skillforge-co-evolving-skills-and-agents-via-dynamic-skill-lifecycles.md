## 摘要
记忆增强的强化学习增强了LLM智能体解决复杂长时程任务的能力。技能是此类记忆的一种形式，将指令与针对任务类型的适用条件配对。然而，随着策略改进，不加区分地保留每一项技能会让过时或有害的条目不断累积，从而误导智能体。我们提出SkillForge，一种智能体强化学习方法，通过由适应度驱动的技能生命周期（试验、活跃、稳定和退役状态）来编译和演化技能库，使技能与模型在整个训练过程中协同演化。强化学习前的评估阶段首先利用基础模型自身的轨迹预退役低适应度技能，得到一个经过滤的技能库，随后以此为基础进行监督微调。强化学习从该检查点接手，在每次迭代中，选择性退役、稳定化和LLM引导的变异在策略优化的同时持续锻造技能库。在多个交互式智能体基准上，SkillForge取得了最高的总体成功率，相较于最强基线实现了最高7.8%的相对提升，同时在整个训练过程中保持技能库紧凑。我们推出SkillFurnace，一个包含5000多条标注记录的数据集，汇集了经退役过滤的SFT轨迹、带有适应度标注的演化技能库，以及带有经人工标注失败类别的退役事件，以支持关于技能质量和生命周期管理的研究。

## Abstract
Memory-augmented reinforcement learning strengthens LLM agents' ability to solve complex long-horizon tasks. Skills are one such form of memory, pairing instructions with an applicability condition over task types. However, retaining every skill indiscriminately as the policy improves lets obsolete or harmful entries accumulate and mislead the agent. We propose SkillForge, an agentic RL method that compiles and evolves the skill library through a fitness-driven skill lifecycle of trial, active, stable, and retired states, so that the skills and the model co-evolve throughout training. A pre-RL evaluation phase first uses the base model's own rollouts to pre-retire low-fitness skills, yielding a filtered library that then seeds supervised fine-tuning. Reinforcement learning takes over from this checkpoint, and at each iteration selective retirement, stabilization, and LLM-guided mutation continue to forge the skill library alongside policy optimization. Across multiple interactive agent benchmarks, SkillForge achieves the highest aggregate success rate, delivering up to 7.8% relative improvement over the strongest baseline while keeping the skill library compact throughout training. We introduce SkillFurnace, a dataset of 5k+ annotated records bundling retirement-filtered SFT trajectories, evolved skill libraries with fitness annotations, and retirement events with human-annotated failure categories to support research on skill quality and lifecycle management.

# SkillForge 论文深度总结

## 1. 核心问题与研究动机

- **背景**：通用智能体（如 Claude Code、OpenClaw）的能力很大程度依赖推理时可调用的模块化抽象。LLM 存在固定知识截止，无法吸收个性化工作流或部署后的工具约定，因此近期研究聚焦于**技能（skill）**——将指令、示例与适用条件打包，按需检索进智能体上下文。
- **问题**：技能库通常以“只增不减”的方式累积。随着策略改进，过时或有害技能会污染上下文、挤占高质量条目，导致检索质量下降。已有实证表明，人工整理的技能库中确实存在损害性能的条目，且库越大收益递减。
- **核心痛点——延迟过时（delayed obsolescence）**：某些技能曾达到稳定状态，但随着策略成熟，其适应度跌破退役阈值，从有用变为误导。现有技能增强 RL 方法均将技能库视为**追加式（append-only）**，无法纠正或淘汰条目。
- **整体含义**：论文主张将技能库管理视为**主动锻造过程**而非被动累积，让技能与模型在在线 RL 中协同演化，从而保持活跃技能集紧凑且与智能体当前能力对齐。

## 2. 方法论

### 2.1 核心思想
- 提出 **SkillForge**：一种适应度驱动的技能生命周期机制，技能在 **trial → active → stable → retired** 四态间迁移，配合 LLM 引导的变异，使技能与策略在训练中共同演化。
- 三阶段流程：
  1. **预退役评估**：用基础模型自身轨迹过滤低适应度种子技能；
  2. **退役感知冷启动**：在存活技能上做监督微调；
  3. **技能-策略协同演化 RL**：每次迭代执行选择性退役、稳定化与变异。

## 3. 实验设计

- **环境 / Benchmark（三个交互式智能体基准）**：
  - **ALFWorld**：具身控制，130 任务未见测试集，分 Pick/Look/Clean/Heat/Cool/Pick2 子任务；
  - **WebShop**：网页导航，500 任务留出测试集，报告 Score 与 Succ.；
  - **Search-Augmented QA**：搜索增强问答，覆盖 NQ、TriviaQA、PopQA、HotpotQA、2WikiMultiHopQA、MuSiQue、Bamboogle 共 51,713 样本。
- **对比方法**：
  - 闭源 LLM：GPT-4o、Gemini-2.5-Pro；
  - 上下文/记忆方法：ReAct、Reflexion、Mem0、ExpeL、MemP、SimpleMem；
  - RL 方法：RLOO、GRPO；
  - 记忆增强 RL（最直接对比）：MemRL、EvolveR、SkillRL、Mem0+GRPO、SimpleMem+GRPO；
  - Search QA 额外对比：Search-o1、R1-Instruct、Search-R1、ZeroSearch、StepSearch。
- **实现**：基于 verl 框架，GRPO 优化器，基础模型 Qwen2.5-7B-Instruct，先经退役感知 SFT 得到环境特定初始化。训练 200 步，学习率 $1\times10^{-6}$，$\epsilon=0.2$，$\beta=0.001$，温度 1.0，组大小 $G=8$。锻造周期每 10 步一次，$K_{mutate}=5$、$K_{retire}=3$，教师模型为 Kimi-K2.5。
- **消融实验**：w/o forging、w/o pre-retirement、w/o retirement、w/o mutation 四组，跨三环境。
- **额外分析**：锻造动态（技能库规模/状态演化）、适应度分布 KDE、阈值敏感性扫描、失败分类学、最深锻造谱系案例。

## 6. 主要结论与发现

- **性能**：SkillForge 在 ALFWorld 达 92.4%、WebShop 达 78.4%、Search QA 达 48.7%，均为最高；相对 SkillRL 在 ALFWorld 提升 2.8%、WebShop 提升 7.8%（相对），Search QA 微平均最高。
- **紧凑性**：训练全程技能库保持紧凑（100/95/85），而无退役变体膨胀至 132/121/111，说明**质量管控而非规模**驱动增益。
- **消融结论**：移除整个生命周期降幅最大（WebShop 达 7.4% 相对）；预退役是单组件影响最大者（1.8%/4.5%/2.5%）；各组件存在次可加交互。
- **锻造动态**：技能库通过退役（削减左尾）与变异（填充中段）两股相反流达到动态平衡，稳定态保留大部分技能，平均适应度约 0.73。
- **延迟过时的实证**：退役事件平均峰值适应度 0.67，退役时下降 0.28，57.2% 曾达稳定态；**过度刚性排序**是主导失败模式（74.5%），说明程序性僵化而非内容缺失是 LLM 蒸馏技能的主要失效方式。
- **变异有效性**：变异子技能存活率 52.7%–64.8%，最终技能中 46.4% 来自变异而非种子。

## 7. 优点

- **问题定位精准**：首次形式化“延迟过时”这一技能增强 RL 的失败模式，并给出可检测的数学定义。
- **方法设计优雅**：四态生命周期 + 迟滞阈值 + 代际保护 + 逆适应度加权变异，机制完整且相互制衡，避免过早退役与瞬时波动误判。
- **协同演化视角**：将技能库视为动态种群而非静态仓库，与在线 RL 的非平稳性对齐。
- **实验扎实**：三环境、多基线、完整消融、统计检验、阈值敏感性、失败分类学与谱系案例，论证链条完整。
- **数据集贡献**：发布 SkillFurnace（5,852 条记录），含退役过滤 SFT 轨迹、带适应度标注的演化库快照、带人工失败分类的退役事件，支持后续技能质量预测研究。
- **工程可复现**：详细列出超参、模板、硬件与训练时长，教师模型可替换，框架无特定供应商依赖。

## 8. 不足与局限

- **信用分配粗糙**：适应度为 episode 级，K 个共检索技能共享单一二值奖励，无法区分个体贡献。虽共检索频率低于 15%，但结构性共检索任务上可能拖慢收敛。
- **模型规模单一**：仅用 7B 基础模型，更大模型下生命周期动态是否一致未知。
- **依赖外部教师**：变异质量取决于教师模型的指令遵循能力，弱教师会产生低质变异，需靠 trial 门控过滤。
- **适应度估计保守**：采用累积平均而非 EMA，对适应度变化响应较慢；论文承认这是有意为之（避免误退），但可能延迟对真实衰退的响应。
- **阈值需调参**：$\delta_{retire}$、$S_{max}$ 等关键阈值虽做了敏感性扫描（±1.4% 波动），但仍需按环境调整。
- **应用限制**：方法面向交互式环境中的技能增强 RL，需环境奖励信号与可检索技能库；对无明确奖励或技能难以结构化的场景适用性有限。
- **偏差风险**：退役事件标注的 Cohen's κ 仅 0.5，人工分类存在一定主观性；部分基线数值引自原论文，评测配置可能不完全一致。
