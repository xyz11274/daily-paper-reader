## 摘要
模仿学习旨在从大量机器人观测和示范中学习技能，因此面临数据稀缺和环境泛化的问题。现有方法主要专注于域内任务的模仿，因此在泛化到未知任务时存在困难。为弥合这一泛化差距，我们提出了动力学感知元模仿（DAMI）框架。通过整合元学习以构建共享技能空间，DAMI使智能体能够快速适应新任务。我们引入了视觉-运动轨迹（VMT）模块来捕获任务潜在空间中的复杂时空动力学。此外，我们提出了非配对统一任务（U2T）模块以融合非结构化的多模态观测。为协调这些表示，我们集成了任务条件特征调制（TCFM）机制，该机制专门用于调制低级3D特征。通过从随机完整参考示范中捕获内在动力学，我们的框架学习底层任务逻辑而非记忆静态线索，从而确保有效泛化。在仿真和真实世界环境中的大量实验表明，我们的方法在直接推理已见任务和通过少样本微调适应未见任务方面均优于最先进的基线方法。

## Abstract
Imitation Learning aims to learn skills from extensive observations and demonstrations for robots, so it suffers from data scarcity and environment generalization. The existing methods predominantly focus on imitation from in-domain tasks and consequently struggle with generalization to unseen tasks. To bridge this generalization gap, we propose the \textbf{D}ynamics-\textbf{A}ware \textbf{M}eta-\textbf{I}mitation (DAMI) framework. By integrating meta-learning to construct a shared skill space, DAMI equips agents for rapid adaptation to novel tasks. We introduce the Visual-Motor Trajectory (VMT) module to capture complex spatio-temporal dynamics within the task latent space. Furthermore, we propose the Unpaired Unified Task (U2T) block to fuse unstructured multimodal observations. To coordinate these representations, we integrate a Task-Conditioned Feature Modulation (TCFM) mechanism customized for modulating low-level 3D features. By capturing intrinsic dynamics from a random complete reference demonstration, our framework learns the underlying task logic rather than memorizing static cues, ensuring effective generalization. Extensive experiments in both simulation and real-world settings demonstrate that our approach outperforms state-of-the-art baselines regarding direct inference on seen tasks and adaptation to unseen tasks via few-shot fine-tuning.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：模仿学习（IL）在机器人操作中有效，但严重依赖大量高质量示范数据。现有方法在域内任务上表现尚可，但对**未见任务**（unseen tasks）泛化能力极差，容易出现过拟合、分布偏移和动作误解释（action misinterpretation）等问题。
- **背景**：多任务模型往往记忆训练模式而非任务逻辑；大型视频训练成本高且存在域偏移；元学习虽有少样本适应潜力，但面临大分布偏移时难以推断动力学；上下文模仿学习（ICIL）依赖视觉相似性而非动作语义。
- **整体含义**：需要一种能从**稀疏示范**中提取**任务内在动态逻辑**、并快速迁移到**新任务**的框架，平衡表达力和数据效率。

## 2. 论文提出的方法论

### 核心思想
- 将**元学习（MAML）** 与**3D扩散策略**结合，学习一个**共享技能初始化**，再通过少量示范快速微调适应新任务。
- 策略条件包括：当前观测（点云+状态）、语言指令、一条**完整参考示范**（200帧），从而推断任务意图而不只是匹配外观。

### 关键技术细节

| 模块 | 功能 |
|------|------|
| **VMT（Visual-Motor Trajectory）** | 联合编码示范中的视觉特征和动作序列，加入位置编码，通过Transformer捕获**时空动力学**，输出令牌序列 H_demo。避免仅依赖静态视觉。 |
| **U2T（Unpaired Unified Task）** | 将VMT输出的示范令牌、CLIP文本特征与观测-时间步条件进行**Transformer融合**。只在U-Net第一个下采样块执行，其他层使用更轻量的观测-时间步条件。 |
| **TCFM（Task-Conditioned Feature Modulation）** | 使用FiLM机制对U-Net各层特征进行**任务条件调制**，将融合后的条件注入低层3D几何特征。 |
| **Meta-Learning（MAML）** | 内循环：在支持集（support batch）上做1步SGD更新得到θ'；外循环：在查询集（query batch）上平均梯度，用AdamW更新初始化θ。保留二阶导数。 |

### 算法流程（文字说明）
1. **元训练**：每个外步枚举当前GPU上的所有任务，每任务采样支持集、查询集和一条完整参考轨迹。VMT编码演示，CLIP编码文本，视觉编码器提取观测特征。U-Net预测动作轨迹，计算扩散损失。内循环更新θ'，外循环累积全MAML梯度后更新θ。维护EMA副本。
2. **新任务适应**：加载EMA策略，用新任务的示范数据通过AdamW进行N步微调（200步仿真/500步真实），同时采样支持集和参考轨迹重建条件。
3. **推理**：基任务直接使用EMA策略；新任务用微调后策略。

### 关键公式
- 扩散损失：\( \mathcal{L}_{diff} = \mathbb{E}_{k,A_0,\epsilon} [\|A_0 - \hat{A}_0\|^2] \)
- 内循环：\( \theta'_i = \theta - \alpha \nabla_\theta \mathcal{L}_{diff}(\theta, B^{sup}_i) \)
- 外循环：\( \bar{g}_t = \frac{1}{|B|}\sum_{T_i}\nabla_\theta \mathcal{L}_{diff}(\theta'_i, B^{qry}_i) \)
