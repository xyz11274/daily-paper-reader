## 摘要
LLM智能体在外部环境中行动，每个动作都会改变后续决策所依赖的状态，并且单个错误步骤可能浪费交互预算或在观察到最终失败之前很久就触发不可逆的副作用。因此，可靠部署需要步骤级置信度估计：在动作执行之前，每个提议动作是有用的校准概率。现有的LLM置信度估计器被设计为对给定提示的响应进行评分，但智能体的置信度还取决于执行后果：类似情况下的类似动作在环境响应后是否真正推进了任务。我们引入了\method (\methodshort)，这是一个自进化的评论者框架，其中LLM评论者从其自身过去的判断及其观察到的后果中积累证据。在每个轨迹之后，一个看到完整执行反馈的后见之明LLM对每个步骤是否有用进行投票。由此产生的伪标签填充到一个记忆库中，每当类似步骤再次出现时，相关的有用和无用经验会被检索到评论者的提示中。\methodshort无需训练，也不使用真实步骤标签。在三个智能体基准和三个评论者骨干网络上，\methodshort在每个数据集-评论者组合中实现了最佳校准（ECE和Brier）和排名（AUC），相对于最强的无训练基线，ECE降低高达54%。

## Abstract
LLM agents act in external environments where each action changes the state that later decisions condition on, and where a single wrong step can waste interaction budget or trigger irreversible side effects long before the final failure is observed. Reliable deployment therefore requires \emph{step-level confidence estimation}: a calibrated probability that each proposed action is productive, available \emph{before} the action is executed. Existing LLM confidence estimators are designed to score a response from the given prompt, but agent confidence also depends on execution consequences: whether similar actions in similar situations actually advanced the task after the environment responded. We introduce the \method (\methodshort), a self-evolving critic framework in which an LLM critic accumulates evidence from its own past judgments and their observed consequences. After each trajectory, a hindsight LLM that sees the full execution feedback votes on whether each step was productive. The resulting pseudo-labels populate a memory bank from which related productive and unproductive experiences are retrieved into the critic's prompt whenever a similar step recurs. \methodshort requires no training and uses no ground truth step labels. Across three agent benchmarks and three critic backbones, \methodshort attains the best calibration (ECE and Brier) and ranking (AUC) in every dataset--critic combination, reducing ECE by up to $54\%$ relative to the strongest training-free baseline.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：LLM 智能体在外部环境（如网页、移动 GUI、Shell）中执行多步任务时，每一步的动作都会改变后续状态，单步错误可能引发不可逆后果（如提交表单、删除文件）或浪费交互预算。因此，在动作**执行前**需要可靠的**步骤级置信度估计**——即对提议动作是否“有生产力”（productive）的校准概率。
- **现有方法不足**：传统 LLM 置信度估计（如 token 逻辑值、一致性、言语化置信度）都是基于给定提示对**响应**评分，而智能体置信度还取决于动作执行后的环境反馈（即执行后果）。现有方法依赖当前上下文，缺乏跨轨迹的持久记忆。训练型过程奖励模型需要标注数据且不适用于固定 API 模型。
- **论文目标**：在无需训练、无真实步骤标签的部署场景下，提供自进化的步骤级置信度估计，通过利用智能体自身历史执行经验来校准评论者（critic）的判断。

## 2. 方法论：Critic Experience Bank (CEB)

### 核心思想
- 搭建一个**评论者经验库**（Experience Bank），从已完成轨迹中利用**后见 LLM** 为每个步骤生成伪标签（productive/unproductive），形成记录存入银行。当新步骤出现时，检索最相关的正例和反例作为对比上下文，辅助冻结的 LLM 评论者做出更精确的置信度估计。
- 评论者本身权重不变，其行为通过检索到的经验动态适应，实现**自进化**。

### 关键技术与细节
1. **Hindsight 投票标签**：
   - 每个轨迹完成后，让后见 LLM \( g_\phi \) 看到完整状态-动作-观测序列，对每一步独立进行 \( V=5 \) 次采样投票（温度 \( \tau=0.7 \)），多数决定伪标签 \( \hat{y}_t \in \{0,1\} \)。
2. **记录格式**：
   - 每条记录包括：任务摘要 \( q' \)、状态摘要 \( s' \)、动作 \( a' \)、观测摘要 \( \tilde{o}' \)、伪标签 \( \hat{y}' \)、在线置信度 \( \hat{z}' \)、以及一致性标志 \( \chi' \)（在线二值判断与伪标签是否一致）。
3. **检索机制**：
   - 查询键 \( \kappa_t = \text{task} \| \text{state} \| \text{action} \)。
   - 库中记录键类似。
   - 使用 TF-IDF 嵌入计算余弦相似度，从正例桶 \( B^+ \) 和反例桶 \( B^- \) 中各取 top-\( k \)（默认 \( k=2 \)），构建对比提示。
   - 额外引入重复标志 \( \rho_t \)，标记当前动作是否与最近几步重复，示警短循环。
4. **批评者推理**：
   - critic 提示包含：任务、当前状态、历史、提议动作、检索到的正反例、重复标志。
   - critic 返回一个 JSON，其中 `"score"` 字段为原始分数 \( r_t \)，最终置信度 \( \hat{z}_t = \text{clip}(r_t, 0, 1) \)。

### 算法流程
- 对于任务流中的每个任务：对于每一步，执行检索、调用 critic 获得置信度、执行动作并得到观测；轨迹完成后，用后见 LLM 生成伪标签并将所有记录加入银行。

## 6. 主要结论与发现

- **CEB 在所有评估中全面超越基线**：在 9 个数据集-骨干组合中，ECE、Brier、AUC 均为最佳；ECE 相对最强无训练基线降低最高 **54%**（InterCode-Bash + GPT-4.1）。

## 8. 不足与局限

1. **模型同质问题**：所有实验统一使用 actor、critic、hindsight labeler 为同一模型，未探究独立 labeler 的效果。这样可能引入**系统性偏差**（如模型对自身行为的评估偏差）。

3. **银行扩容问题**：当前未实现淘汰或压缩机制，随着轨迹增多，检索库无限增长，影响推理速度和存储。论文仅实验了数百条轨迹，真实部署可能面临规模挑战。
4. **计算开销**：后见 LLM 投票需要 V=5 次采样，检索需在线 TF-IDF 嵌入计算；相对于直接言语化置信度，CEB 的额外调用次数更多。
5. **消融覆盖面**：大部分消融仅在 Mind2Web 上执行，在其他数据集上是否表现为同样趋势未验证。
6. **开源与复现**：虽方法无需训练，但依赖 GPT-5.4 等商用模型，完全复现受限；Qwen3-Next 也是假设模型，未提供具体权重。
7. **部署流假设**：方法假设任务流顺序到达且银行不交叉污染，实际多用户并发或银行更新策略未讨论。
8. **风险与伦理**：论文未探讨低置信度动作交给人类或重规划时的交互决策优化，也未分析潜在错误传播风险。
