## 摘要
检索增强生成（RAG）已成为将多模态大语言模型（MLLM）锚定于外部知识的关键范式。最近的GraphRAG方法引入了结构化的实体-关系图以改进检索与推理。然而，这些方法仍受限于将知识图谱视为离线构建且单次查询的静态数据结构。这种静态范式与知识密集型推理的交互式、迭代性本质不相适应，造成了三个瓶颈：（i）以文本为中心的分割，阻碍了跨模态推理；（ii）冻结的结构无法整合新证据或纠正错误；（iii）僵硬的单次检索，缺乏自适应改进。为克服这些局限，我们提出了EvoGraph-R1，一个自演化的GraphRAG框架，将知识图谱重新构想为通过智能体交互塑造的动态环境。我们将检索形式化为一个马尔可夫决策过程（MDP），其中智能体观察图状态并执行动作以查询（GraphRetrieve）、扩展（WebSearch）、精炼（GraphEdit）或终止（Answer）推理。这些动作重塑超图结构并生成反馈信号，指导后续演化。通过这一闭环，超图通过整合新证据、纠正错误和精炼结构而演化，以支持多跳推理。在多模态VQA和文本QA基准上的实验表明，在准确率、覆盖率和可追溯性方面，该方法显著优于现有的RAG基线，确立了自演化知识图谱作为跨模态的基础范式。

## Abstract
Retrieval-augmented generation (RAG) has emerged as a critical paradigm for grounding Multimodal Large Language Models (MLLMs) in external knowledge. Recent GraphRAG methods introduce structured entity-relation graphs to improve retrieval and reasoning. However, they remain limited by treating knowledge graphs as static data structures built offline and queried in a single pass. This static paradigm misaligns with the interactive, iterative nature of knowledge-intensive reasoning, creating three bottlenecks: (i) text-centric fragmentation that impedes cross-modal reasoning, (ii) frozen structures unable to incorporate new evidence or correct errors, and (iii) rigid single-pass retrieval without adaptive refinement. To overcome these limitations, we introduce EvoGraph-R1, a self-evolving GraphRAG framework that reconceptualizes knowledge graphs as dynamic environments shaped through agent interactions. We formulate retrieval as a Markov Decision Process (MDP) where the agent observes the graph state and executes actions to query (GraphRetrieve), expand (WebSearch), refine (GraphEdit), or terminate (Answer) the reasoning. These actions reshape the hypergraph structure and generate feedback signals that guide subsequent evolution. Through this closed loop, the hypergraph evolves by integrating new evidence, correcting errors, and refining structure to support multi-hop reasoning. Experiments on multimodal VQA and text QA benchmarks demonstrate substantial improvements over existing RAG baselines in accuracy, coverage, and traceability, establishing self-evolving knowledge graphs as a fundamental paradigm across modalities.

- **背景**：检索增强生成（RAG）是提升多模态大语言模型（MLLM）事实性的关键范式，但现有 RAG 难以处理复杂组合推理；GraphRAG 通过知识图谱引入结构化信息，但仍存在三大瓶颈：

  3. **刚性检索**：单次检索，无迭代精炼，初始证据不足时无法调整策略。
- **核心问题**：知识图谱应被视为动态推理基板，而非被动数据结构。现有方法将图当作静态结构，与人类迭代推理本质不符。
- **整体含义**：论文提出一种自演化范式，将知识图谱重塑为智能体可交互、可修改的动态环境，使图结构与推理过程协同进化，以解决多模态、多跳知识密集型问答中的检索与推理难题。

## 2. 论文提出的方法论

- **核心思想**：将多模态 GraphRAG 建模为**马尔可夫决策过程（MDP）**，智能体（agent）在动态超图环境中交互，通过强化学习学习最优动作策略，使图不断自演化以支持推理。
- **关键技术细节**：
  - **多模态超图构建**：三阶段
    1. 文本子图提取：用 MLLM 作为提取器，从文本中抽取 n-元超边（含自然语言描述、实体集、关系类型、置信度）。
    2. 视觉子图构建：为每张图像生成场景描述并建立锚节点，确保视觉事实有源可溯。
    3. 跨模态融合：通过实体解析函数 φ 匹配文本和视觉实体，合并为统一超图 \(G_H = (V, E)\)。再用多模态编码器 GME 对所有元素嵌入索引。
  - **智能体图形演化**：
    - **状态** \(s_t = (G_t, H_t, q)\)，其中 \(G_t\) 为当前超图，\(H_t\) 为历史动作序列，\(q\) 为查询。
    - **动作空间** A 包含四种类型：
      - GraphRetrieve：查询图内元素（实体/子图/超边向量检索）。
      - WebSearch：当图内证据不足时，调用外部搜索，返回内容附加到上下文。
      - GraphEdit：包含三个子操作 —— Insert（插入新实体/超边）、Update（修正现有超边）、Delete（降低噪声元素置信度）。**这是实现图演化的核心动作**。
      - Answer：终止推理并基于当前图生成最终回答。
    - **演进策略**：每个动作 a_t 触发状态转移 \(G_{t+1} = \pi_{\text{evolve}}(a_t, G_t)\)，不同动作对图产生不同影响（仅 GraphEdit 修改图结构）。
    - **奖励函数** \(R(\tau)\) 三部分：
      - 结构奖励 \(R_{\text{struct}}\)：鼓励格式正确的推理步骤。
      - 答案奖励 \(R_{\text{ans}}\)：用 F1 式 token 重叠评估预测与真值语义匹配度。
      - 综合奖励 \(R(\tau) = -\lambda\sum c(a_t) + R_{\text{struct}} + \mathbb{I}[R_{\text{struct}}=1.0]\cdot R_{\text{ans}}\)，其中 \(c(a_t)\) 为动作成本，\(\lambda>0\) 效率系数。只有当结构完整时才给予答案奖励。
    - **策略优化**：使用群体相对策略优化（GRPO），对每组轨迹计算优势，实现稳定学习。
- **算法流程文字说明**：初始化最小超图 → 每步观察状态，从策略中采样动作 → 若为 GraphEdit 则修改图结构；若为 WebSearch 则获取外部文本并附加 → 其他动作收集信息不改变图 → 更新历史 → 当选择 Answer 时终止，基于最终超图生成回答 → 完整轨迹获得奖励 → 用 GRPO 优化策略。
