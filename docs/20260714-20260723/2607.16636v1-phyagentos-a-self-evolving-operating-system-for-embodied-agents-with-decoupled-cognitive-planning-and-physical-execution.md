## 摘要
视觉-语言-动作模型、世界模型和智能体规划器各自推动了物理智能的发展，但它们的组合缺乏统一的执行抽象、共享状态、语义验证以及在异构具身体上的持久经验。我们提出PhyAgentOS，一个将调度、验证、内存、基准测试和安全性作为系统级服务提供的运行时基础。其以会话为中心的运行时将会话（而非动作）视为调度、兼容性预检、监督执行、证据收集和接受的最小单元。为了将认知与物理执行解耦，认知-物理边界是一个文件系统：状态即文件协议将跨层状态具体化为带有YAML的Markdown，产生可检查、可版本化的记录，无需代理层和运行时层之间的代码依赖。这些视图形成了一个统一的认知状态空间，对齐了意图、能力、环境、执行和经验。会话验证器通过基于证据的成功、失败或重新规划判定来区分执行终止和语义任务完成。验证结果通过认知记忆整合为可重用知识和纠正经验，关闭了无需重新训练的试错循环。基准测试重用部署会话和验证路径，因此结果可追溯到实际执行。分层安全性约束了策略驱动和智能体驱动的执行：预检、动作桥接、安全守卫、心跳监控和目标局部约束。验证是逐步进行的：游戏测试认知规划，模拟添加动力学和控制，真实机器人添加硬件噪声，同时保持认知层不变。PhyAgentOS在Optimus-67、StarDojo和DST-Dojo上进行了基准测试，在19种以上的仿真和物理具身体上进行了验证，并在LIBERO、Calvin和RoboCasa365上跨多种VLA模型获得了提升。

## Abstract
Vision-language-action models, world models, and agentic planners each advance physical intelligence, yet their composition lacks a common execution abstraction, shared state, semantic verification, and persistent experience across heterogeneous embodiments. We present PhyAgentOS, a runtime foundation delivering scheduling, verification, memory, benchmarking, and safety as system-level services. Its Session-Centered Runtime treats a session, not an action, as the minimum unit of scheduling, compatibility preflight, supervised execution, evidence collection, and acceptance. To decouple cognition from physical execution, the cognition-physics boundary is a file system: the State-as-a-File protocol materializes cross-layer state as Markdown with YAML, yielding inspectable, versionable records without code dependencies between Agent and Runtime layers. These views form a unified cognitive state space aligning intent, capabilities, environment, execution, and experience. The SessionVerifier distinguishes execution termination from semantic task completion via evidence-grounded verdicts of success, failure, or replan. Verified outcomes are consolidated through epistemic memory into reusable knowledge and corrective lessons, closing a trial-and-error loop without retraining. Benchmarking reuses the deployment session and verification path, so results trace to real execution. Layered safety constrains both policy-driven and agent-driven execution: preflight, action bridges, SafetyGuard, heartbeat monitoring, and target-local constraints. Validation is progressive: games test cognitive planning, simulation adds dynamics and control, real robots add hardware noise, with the cognitive layer held constant. PhyAgentOS is benchmarked on Optimus-67, StarDojo, and DST-Dojo, validated on 19+ simulated and physical embodiments, and gains on LIBERO, Calvin, and RoboCasa365 across multiple VLA models.

## 1. 论文的核心问题与整体含义

**研究动机与背景：**  
当前VLA模型、世界模型和智能体规划器各自在感知-动作预测、动力学模拟和高层推理方面取得了进展，但它们组合在一起时存在三个结构性缺陷：
- **缺乏统一抽象**：各层以不同粒度和格式表达状态（像素、潜在表示、符号工具调用），需要临时转换器。
- **缺乏物理验证**：执行终止（action finished）常被混淆为任务完成（task completion），没有组件在语义上验证物理结果是否达成目标。
- **缺乏持久记忆**：跨会话的经验在任务结束后丢弃，无法累积知识。

现有机器人中间件（如ROS）提供通信基础设施，但不提供任务级调度、语义验证、永久内存或分层安全，因此不能视为具身AI的操作系统。

**核心问题：** 如何构建一个系统级运行时，为异构的物理智能体提供调度、验证、记忆、基准测试和安全作为一等服务，从而实现可执行、可验证、可进化的物理交互。

## 2. 论文提出的方法论

**核心思想：** PhyAgentOS将认知-物理边界作为一个文件系统（State-as-a-File协议），将会话（session）而非单个动作为最小调度单元，通过解耦认知规划（Agent层）和物理执行（Runtime层）实现可审计、可恢复、可进化的闭环。

**关键技术细节：**
- **三层架构**：Agent层（目标规划、会话编译、技能和目标选择） → 协议边界（Markdown文件集合） → Runtime层（WatchdogSupervisor、SessionRunner、SkillRuntime、Target）。
- **State-as-a-File协议**：所有跨进程数据（目标、技能、会话、环境、经验、知识）以人类可读的Markdown文件+嵌入式YAML块存储。主要文件包括：
  - `SESSIONS.md`：会话交易中心（唯一ID、目标、状态、结果）
  - `SKILLRUNTIME.md`：可重用执行方法描述
  - `TARGETS.md`：执行目标描述（能力、观察模式、动作语义）
  - `ENVIRONMENT.md`：结构化环境快照
  - `LESSONS.md` / `KNOWLEDGE.md`：经验记录（失败原因、纠正措施）
- **SessionVerifier**：在会话执行完成后，评估证据包（初始/终止观察、环境快照、动作历史）与任务目标是否一致，输出`success`、`failure`或`replan`。
- **认知记忆**：Episodic Memory（保存单个会话）、Semantic Memory（聚合模式）、Procedural Memory（将已验证模式提升为可重用技能），通过`KNOWLEDGE.md`和`LESSONS.md`持久化，无需神经网络重训练。
- **双执行流**：
  - **Policy-driven**：基于VLA策略的连续控制循环（PolicySkillRuntime），运行时管理观察-推理-动作闭环。
  - **Agent-directed**：通过TargetSessionHandle暴露受控工具调用（BuiltinSkillRuntime），适用于离散游戏交互等。
- **分层安全**：兼容性预检（执行前拒绝无效配置）、动作桥（确定性的坐标系转换等）、SafetyGuard（注入位置/速度/力矩校验）、心跳监控（检测进程失效）、目标局部约束（硬件级急停等）。

**公式/算法（文字说明）：**  
Policy-driven形式化为：A_t = Policy(I, O_t, S_t, H_t)  
Agent-directed形式化为：T_t = Agent(I, O_t, S_t, H_t)  
SessionVerifier 实现函数 V(G, S0, ST, τ, H) → {success, failure, replan}

## 6. 论文的主要结论与发现

- PhyAgentOS**无需重训练**即可提升多种VLA模型在多个benchmark上的性能：LIBERO整体+0.4~+1.3百分点，CALVIN完整链成功率+1.4~+6.7百分点，RoboCasa365整体+7.2~+9.2百分点。
- 游戏层验证认知模块独立有效性：Optimus‑67红石任务达30%（超越所有基线）、StarDojo达22.0%（超基线18.0%）、DST‑Dojo生存天数翻倍至2.10天。
- 许多物理失败是**可恢复的执行错误**而非根本性任务误解，通过语义验证+控制恢复可纠正。
- 认知记忆和试错循环能有效累积经验，避免重复错误（如DST‑Dojo死亡原因中黑暗致死率从90%降至80%）。
- 分层安全架构能够有效阻止无效配置和危险动作，安全事件记录清晰可审计。

## 7. 优点

- **操作系统级统一抽象**：通过文件协议解耦认知与物理，使得同一认知层可驱动游戏、仿真和真实机器人。
- **以会话为中心的运行时**：使调度、预检、监控、验证在一固定生命周期内执行，提升可控性。
- **语义验证**：SessionVerifier基于证据判定任务完成情况，克服了二进制完成信号的陷阱。
- **无需重训练的自进化**：通过记忆累加经验（LESSONS.md/KNOWLEDGE.md），形成闭环改进，不依赖模型微调。
- **渐进式验证**：从游戏（纯认知）到仿真（加物理）到真实（加噪声），隔离了物理复杂性，保证结论可追溯。
- **模型无关**：支持多种VLA（OpenVLA, π0, π0.5, X-VLA等）和策略后端，易于替换和比较。
- **跨平台兼容**：零样本跨具身迁移，通过适配器链实现，已在19+硬件上验证。

## 8. 不足与局限

- **轮询协议延迟**：当前基于轮询的协议实现（Watchdog定期扫描SESSIONS.md）会引入延迟，对实时性要求高的场景可能不够。事件驱动模型可以降低延迟但需保证原子写入语义。
- **长期记忆无压缩界限**：LESSONS.md和KNOWLEDGE.md随会话持续增长，上下文选择依赖启发式（任务类型匹配+时间加权），缺乏理论保证。技能提升的回归测试仍依赖人工或基准编排。
- **真实机器人评估覆盖不足**：真实实验主要侧重于安全机制验证（预检、Guard、急停），缺乏大规模任务级别成功率统计。虽然展示了跨多个平台的基础部署，但未能全面展示端到端任务性能的统计证据。
- **目标图与会话编译器未完全实现**：论文架构中提到允许DAG级任务分解和多智能体协调，但完整实现（TASK.md等）标注为“描述但未完全实现”。
