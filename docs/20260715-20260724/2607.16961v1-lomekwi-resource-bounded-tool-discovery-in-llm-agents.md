## 摘要
现有的工具使用基准报告了复杂多步骤任务的单一成功率。受认知科学思想的启发，我们将工具使用与工具发现区分开来，并将后者分解为好奇心（模型发现构建工具所需部件的能力）、识别（模型发现创建工具过程的能力）和效率（模型创建后对工具的使用能力）。我们展示了该框架可应用于现有的发现任务，如Voyager。此外，我们提供了识别能力与模型大小呈逆比例关系的证据，并引入并分析了一类组合游戏来证明这一点。我们还在一个旨在模拟真实任务的独立环境中进一步观察到这种逆比例关系。

## Abstract
Existing tool-use benchmarks report a single success rate for complex, multistep tasks. Inspired by ideas from cognitive science, we distinguish tool use from tool discovery and decompose the latter into curiosity (the model's ability to discover the parts needed to build the tool), recognition (the model's ability to discover the process of creating the tool), and efficiency (the model's use of the tool after creation). We show that this framework can be applied to existing discovery tasks, such as Voyager. In addition, we provide evidence that recognition inversely scales with model size, and we introduce and analyze a class of combinatorial games that demonstrates this. We further observe inverse scaling in a separate environment designed to emulate real-world tasks.

### 论文的主要结论与发现

1.  **识别能力（R）存在逆缩放现象**：在Lomekwi和Recognition MCP两个环境中，论文都发现**识别（R）能力与模型规模呈反比关系**。更大、更强的模型（如Claude Opus, Qwen3.5-27B）反而不如较小模型（如Claude Haiku, Qwen3.5-2B）频繁地选择构建或寻找工具。
2.  **解释**：较大的模型对其“蛮力”解决问题的能力更自信，因此倾向于放弃探索工具，直接尝试手动解决。相反，较小的模型由于自身能力不足，被迫进行工具探索，从而获得了更高的识别率。
3.  **U型缩放**：当在Recognition MCP环境中告知模型“有一个工具能解决问题”（提供先验知识）后，识别能力（R）的逆缩放趋势转变为**U型缩放**。即极小的模型和极大的模型识别率较高，而中间尺寸的模型最低。这符合理论预期：小模型探索是出于“需要”，大模型探索是出于“对冲”，中段模型则因“过度自信”而放弃。
4.  **传统成功率的局限性**：论文强调，如果只报告最终的成功率（S），由于大模型在效率（E）或蛮力（G）上更强，会掩盖其在识别（R）上的显著缺陷。
5.  **成功率的分解**：总体上，好奇心（C）和效率（E）随模型规模正向增长，但识别力（R）的逆增长导致整体构建率（Build Rate）出现非线性甚至下降。
