## 摘要
协作拓扑结构既影响基于大语言模型的多智能体系统的性能，也影响其执行成本。由于任务在复杂度和所需能力上各不相同，近期方法会生成任务特定的协作图，以指定智能体参与方式和信息流。然而，代表性的拓扑生成器在整个组织中要么使用单个智能体，要么使用预定义分组，忽略了不同子任务之间不同的协作需求。我们的关键洞见是，为每个功能角色在局部选择粒度，将细粒度控制与同一组织内可复用的协作模式结合起来。学习这样的组织需要在组合式构建空间中进行探索，而来自最终答案奖励的中间反馈有限。因此，我们提出 MAGIC，一种用于混合粒度图生成的密集奖励强化学习框架。具体而言，MAGIC 通过依次选择一个功能角色，将其实例化为单个智能体或可复用分组，并将其连接到现有单元，从而构建混合粒度智能体图。我们直接使用当前策略下采样轨迹的回报来优化构建策略，并使用基于势能的奖励塑形，从基于探测的效用和结构信号中提供中间反馈，同时保留累积任务奖励。MAGIC 在八个基准上优于最先进的基线，并在我们的效率研究中展现出强大的推理效率。

## Abstract
Collaboration topology shapes both the performance and execution cost of LLM-based multi-agent systems. Because tasks differ in complexity and required capabilities, recent approaches generate task-specific collaboration graphs that specify agent participation and information flow. However, representative topology generators use either individual agents or predefined groups throughout an organization, overlooking differing collaboration needs across subtasks. Our key insight is to select granularity locally for each functional role, combining fine-grained control with reusable collaboration patterns within one organization. Learning such organizations requires exploring a combinatorial construction space with limited intermediate feedback from final-answer rewards. Therefore, we propose MAGIC, a dense-reward reinforcement learning framework for mixed-granularity graph generation. Specifically, MAGIC constructs a mixed-granularity agent graph by sequentially selecting a functional role, instantiating it as a single agent or reusable group, and connecting it to existing units. We directly optimize the construction policy using returns from trajectories sampled under the current policy and use potential-based reward shaping to provide intermediate feedback from probe-based utility and structural signals while preserving the cumulative task reward. MAGIC outperforms state-of-the-art baselines across eight benchmarks and demonstrates strong inference efficiency in our efficiency study.

## 1. 核心问题与整体含义

- **研究背景**：基于大语言模型的多智能体系统（LLM-based MAS）通过结构化交互协调专业化智能体，其性能与执行成本高度依赖**协作拓扑**（决定智能体参与方式与信息流）。
- **核心痛点**：现有拓扑生成器存在**固定粒度失配**问题——
  - **智能体级方法**：全程使用原子智能体，需逐节点组装协作，缺乏可复用分组先验，构建序列长。
  - **分组级方法**：全程使用预定义分组，将分组视为不可分割单元，限制细粒度结构控制，对简单子任务强加不必要的多智能体执行。
- **关键洞见**：同一查询内的不同子任务对协作需求不同（如 API 更新任务中，调查上游变更适合 SearchGroup，测试兼容性适合 TestingGroup，而一两行补丁只需单个 ProgrammerAgent）。因此应**为每个功能角色在局部选择粒度**，将细粒度控制与可复用协作模式统一在一个组织中。
- **学习挑战**：
  - 混合粒度空间组合爆炸（m 个双粒度角色有 2^m 种实现）。
  - 中间构建决策缺乏反馈，仅靠最终答案奖励难以区分同分轨迹。
- **整体含义**：提出 MAGIC 框架，将任务条件化 MAS 拓扑生成建模为**混合粒度组织空间中的增量构建**问题，用密集奖励强化学习直接优化构建策略。

## 2. 方法论

### 2.1 核心思想
- 从空图开始，**顺序地**为每个功能角色选择：角色类型 → 原子/分组实现 → 前驱连接，最终生成可执行的混合粒度智能体图。
- 全原子与全分组组织均为该混合空间的**特例**。

### 2.2 问题形式化
- 给定任务查询 Q 和固定角色库 R，构建组织 G = (U, E)，每个单元 u_i = (i, r_i, z_i)，z_i ∈ {AtomicAgent, Group}。
- 目标：最大化期望任务得分 E[S(Execute(Q, G), y*)]，约束 G ∈ G_legal（合法实现、接口兼容、无环）且 N ≤ N_max。

### 2.3 增量构建策略
- **状态编码**：冻结文本编码器嵌入查询与角色实现；节点特征融合实现语义、粒度、构建位置、度嵌入；Edge-aware GRU 按构建顺序编码单元，结合前驱均值表示与查询嵌入；任务条件注意力池化后投影为决策上下文 c_t。
- **分层动作**：非 STOP 动作 a_t = (r_t, z_t, b_t)，概率分解为角色选择 × 粒度选择 × 各前驱边独立伯努利决策：
  π_θ(a_t|s_t) = π_θ(r_t|s_t) · π_θ(z_t|r_t,s_t) · ∏_j π_θ(b_jt|r_t,z_t,s_t)。
- **合法性掩码**：约束角色库、方向、结构；达到单元上限时仅 STOP 合法。
- **执行语义**：分组展开为固定内部 DAG，与原子单元共享相同输入-输出契约；外层摘要器从所有汇点生成最终答案；空图回退到直接回答。

### 2.4 基于势能的密集奖励优化
- **探测效用**：从其他训练查询中固定选取 4 个探测问题 P，执行部分图获得跨查询参考效用，配对增益 ΔU_t = Σ_p[S(G_{t+1},p) − S(G_t,p)] / (|P|+κ)。
- **结构势能**：复杂度惩罚 C(G) = w_n[N_exp − b_n]⁺ + w_e[E_exp − b_e]⁺；角色重复惩罚 D(G) = Σ_r[m_r − 1]⁺。
- **密集奖励**：d_t = αΔU_t − βΔC_t − γ_RΔD_t，累积势能 Φ_{t+1} = Φ_t + d_t。
- **奖励塑形**：r'_t = r_task_t + ηΦ_{t+1} − Φ_t，初始与终止势能设为 0。
- **策略优化**：每查询采样 K=2 条轨迹，按动作位置对齐归一化计算优势 A_{k,t} = (G_{k,t} − μ_t)/(σ_t + ε)；损失 L = −sg(A)log π_θ + β_KL·D_KL(π_θ‖π_ref) − β_H·H(π_θ)。
- **理论保证（命题 1）**：在相同折扣 η 且 Φ_0 = Φ_T = 0 条件下，塑形回报与任务回报完全相等，即塑形保持期望任务回报与最优策略集不变。

## 6. 主要结论与发现

- **有效性**：MAGIC 在全部 8 个基准上排名第一，MMLU-Pro 从 73.60% 提升至 83.20%，LCB-v6 pass@1 从 26.86% 提升至 36.57%。
- **组件贡献**：混合粒度优于全原子与全分组两个端点；密集反馈相比仅终端奖励在 MMLU-Pro 上提升 7.00 个百分点，同时减少约 15% token。
- **优化路线**：在匹配 API 预算下，Dense-reward RL 在多数预算阶段优于 Search-then-SFT（CNY 10 时 MMLU-Pro 领先 8.00 个百分点）。
- **效率**：MAGIC 在 4 个代表性基准上均位于性能-token Pareto 前沿，在 MMLU-Pro、HumanEval、TabFact 上 token 消耗最低。
- **诊断发现**：
  - D1：粒度偏好任务与角色依赖（MMLU-Pro 偏好 GAA，TAT-QA 偏好 AAG），混合分配比固定端点高 4.5/2.5 个百分点且 token 更少。
  - D2：验证配置覆盖率受执行预算解析上界约束 Coverage(B) ≤ min(1, B/2^m)。
  - D3：密集奖励将中间 ADD 动作的非零优势率从 32.81% 提升至 83.13%（MMLU-Pro），并能区分部分同终端分数轨迹。
