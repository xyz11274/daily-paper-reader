## 摘要
多智能体大语言模型系统将一个拥有广泛上下文的发送者与一个局部视野有限的执行者配对。我们研究短消息何时能改善执行者的下一步决策、何时原始上下文更可取，以及何时更强的发送者会有帮助。我们的框架——\emph{接收者相对有界协调}——将消息效用表示为接收者增益减去协议税。当税收节省超过省略信息与解码器不匹配带来的损失时，压缩优于原始上下文。即使\emph{贝叶斯充分}压缩也可能失败，当有界执行者无法利用其表面形式时。一个三阶段分解将外化、吸收和\emph{动作闭合}分开，解释了在正确内容到达接收者后错误如何仍然存在。在单交叉条件下，发送者升级在接收者负担阈值以上有帮助。在六个基准上，相同的Qwen协议将ContextBench联合准确率从$0.633$提高到$0.775$，但将ToolSandbox从$0.889$降低到$0.653$。固定消息重放揭示了尽管正确工件恢复，仍存在闭合失败。这些结果指导了一个推理时选择器，在评估的通信机制上改善了准确率-成本前沿。

## Abstract
Multi-agent LLM systems pair a sender with broad context and an executor with a limited local view. We study when a short message improves the executor's next decision, when raw context is preferable, and when a stronger sender helps. Our framework, \emph{receiver-relative bounded coordination}, expresses message utility as receiver gain minus protocol tax. Compression beats raw context when tax savings exceed losses from omitted information and decoder mismatch. Even \emph{Bayes-sufficient} compression can fail when a bounded executor cannot use its surface form. A three-stage decomposition separates externalization, absorption, and \emph{action closure}, explaining how errors remain after the correct content reaches the receiver. Under a single-crossing condition, sender upgrades help above a receiver-burden threshold. Across six benchmarks, the same Qwen protocol raises ContextBench joint accuracy from $0.633$ to $0.775$ but lowers ToolSandbox from $0.889$ to $0.653$. Fixed-message replay reveals closure failures despite correct artifact recovery. These results guide an inference-time selector that improves the accuracy-cost frontier on the evaluated communication regimes.

# 论文总结：Bayes-Sufficient Compression Is Not Enough

## 1. 核心问题与整体含义

- **研究动机**：多智能体 LLM 系统通常将任务拆分为“拥有广泛上下文的发送者（sender）”与“局部视野受限的执行者（executor）”。发送者向执行者发送短消息，但短消息何时真正改善执行者的下一步决策、何时原始上下文更优、何时更强的发送者才有帮助，尚缺乏统一的理论解释。
- **核心问题**：论文聚焦于**步骤级（step-level）** 的通信效用问题——一条消息是否改善接收方的下一步决策，而非仅看聚合任务指标。
- **整体含义**：作者提出“**接收者相对有界协调**（receiver-relative bounded coordination）”框架，主张通信的价值应以**接收方增益减去协议税**来衡量。核心论断是：**贝叶斯充分（Bayes-sufficient）压缩并不足够**——即使消息保留了全部目标相关信息，若其表面形式（surface form）无法被有界执行者使用，仍会导致失败。
- **背景意义**：现有多智能体研究多关注智能体数量、拓扑结构或训练方法，而本文强调“**如何协调**”比“多少智能体”更关键，并将通信选择建模为推理时的控制问题。

## 2. 方法论

### 2.1 核心思想

- **接收者相对视角**：通信是否有用，取决于它是否改善**已部署接收方**的下一步决策，而非信息论意义上的充分性。
- **效用分解**：消息效用 = 接收方增益（receiver gain）− 协议税（protocol tax）。
- **三阶段损失分解**：将消息后损失拆分为**外化（externalization）**、**吸收（absorption）**、**动作闭合（action closure）**。

### 2.2 关键技术细节与公式

- **动作充分目标**：定义 $Z^\star_t$ 为动作充分协调目标，满足 $A^{j,\star}_t \perp S^t_i \mid (X^j_t, Z^\star_t)$，即给定局部视野与目标后，发送者状态对最优动作无额外信息。
- **通信-税恒等式（命题1）**：
  $$U_{\rho,\ell}(M_t; Z^\star_t) = R_\rho(0) - R_\rho(1) = A^\star_{C,\ell}(M_t; Z^\star_t) - \tau_{\rho,\ell}(M_t)$$
  即效用 = 类最优风险降低（增益）− 协议税。
- **压缩定理（定理2）**：
  $$\Delta U_{cmp-raw} = \Delta\tau_{raw\to cmp} - I_{omit} - \Lambda_C(M_t \to C_t)$$
  压缩优于原始上下文，当且仅当节省的税超过省略信息与解码器不匹配之和。
- **贝叶斯充分压缩的失效（定理3）**：对任意压缩率 $\alpha \in (0,1)$ 与 $\varepsilon>0$，存在任务与 $\alpha$-proper 贝叶斯充分压缩，使原始上下文零误差，而压缩消息误差至少 $1/2 - \varepsilon$。构造基于“交替标签对阈值分类器”的不可分性。
- **三阶段损失分解（定理4）**：$L_{total} = L_{ext} + L_{abs} + L_{close}$，对应外化、吸收、动作闭合，各分量非负（由数据处理不等式保证）。
- **固定消息重放（命题5）**：固定发送者消息后，发送侧外化项在配对比较中抵消，差异仅来自接收侧吸收与闭合。
- **发送者升级阈值（定理6）**：在单交叉（single-crossing）条件下，更强发送者的净价值 $\Psi_{s,s'}(b) = \Delta A - \Delta\tau$ 在接收者负担 $b$ 上存在唯一阈值 $b^\star$，低于阈值有害、高于阈值有益。
- **残差传播（命题7）**：在共享状态工作流中，若残差持续超过修复量，则残差差距按 $\Delta_{t+h} = \left(\prod_{u=t}^{t+h-1}\lambda_u\right)\Delta_t$ 传播。
- **推理时协议选择器（式5）**：
  $$J_t(\alpha) = A^\star_{\Phi_\alpha,\ell}(M_t(\alpha); Z^\star_t) - \tau_{\rho_\alpha,\ell}(M_t(\alpha)) - \eta_c c(\alpha) - \eta_r r_t(\alpha)$$
  动作集为 {skip, compress(B), raw, escalate(C'), refresh}，通过离线校准 + 在线评分执行。

## 3. 实验设计

### 3.1 数据集 / 场景

- **六个基准家族**：
  - **BFCL**：函数调用（高局部充分性/噪声区）
  - **ToolSandbox**：有状态工具使用（高局部充分性/噪声区）
  - **ContextBench**：代码上下文检索（上下文密集/有益区）
  - **RepoBench**：仓库级代码补全（上下文密集/有益区）
  - **SWE-bench Lite**：软件修复（能力迁移）
  - **τ-bench**：客服工具-用户交互（弱有益/边界区）
  - **LongCLI-Bench**：共享状态压力测试（附录）

### 3.2 对比方法 / 协议

- **三种端点协议**：
  - **RO（Receiver-Only）**：无消息
  - **SF（Sender-Full）**：暴露完整原始上下文
  - **MA（Multi-Agent）**：有界压缩消息（默认预算 B=128 tokens）
- **对比变体**：
  - 匹配发送者（MA_match，9B→9B）vs 更强发送者（MA_main，80B→9B）
  - 固定消息重放（同一发送者消息，不同接收者）
  - 严格重编码探针（direct vs strict recode）
  - 发送者替换消融（7 个候选发送者）
  - OpenAI 模型家族扩展（gpt-4o-mini、gpt-5.4-nano/mini、gpt-5.4、o3、o4-mini）
  - 选择器对比：always-skip、always-send、always-raw、always-rewrite、梯度提升、学习质心、MasRouter

### 3.3 主要指标

- **hit_joint**：联合准确率（工件+动作均匹配）
- **hit_artifact / h_action**：工件准确率 / 条件动作转换率
- **L_content / L_closure**：内容损失 / 闭合损失
- **Δ_comm = Acc(MA_main) − Acc(RO)**，**Δ_cmp = Acc(MA_main) − Acc(SF)**，**Δ_strong = Acc(MA_main) − Acc(MA_match)**

## 6. 主要结论与发现

- **压缩效果符号翻转**：同一 Qwen 协议使 ContextBench 联合准确率从 0.633 升至 0.775，却使 ToolSandbox 从 0.889 降至 0.653。说明通信效果取决于**接收者与协议条件**，而非仅任务本身。
- **贝叶斯充分 ≠ 接收者可用**：严格重编码探针在 τ-bench 降低 13.5 个百分点、ContextBench 降低 6.0、ToolSandbox 降低 3.5，BFCL 不变，验证定理3。
- **闭合主导的接收侧损失**：GLM-5、o3、MiniMax-M2.5 的工件准确率 ≥0.61，但动作转换率仅 0.545、0.195、0.053；错误动作率高达 40.8%–94.0%，且发生在解析有效、工件正确之后。
- **更强发送者的阈值效应**：SWE-Lite +52.1pp、ContextBench +21.0pp、RepoBench +8.8pp，但 ToolSandbox −26.4pp、BFCL −16.0pp、τ-bench −2.8pp。拟合交叉点 RO ≈ 0.629（95% CI [0.552, 0.706]），89.5% 锚点符合单交叉。
- **选择器改善准确率-成本前沿**：ContextBench 上选择器达 0.7367 准确率、1735 tokens/步，比 always-send 省 46.4% tokens；ToolSandbox 在线路径达 1.000 准确率、省 70.2% tokens、降 31.0% 延迟。
- **共享状态残差传播**：LongCLI 与高耦合 ToolSandbox 中扰动产生持续下游赤字，修复仅部分闭合；宽耦合 ToolSandbox 快速重同步。

## 7. 优点

- **理论贡献扎实**：提出接收者相对有界协调框架，给出通信-税恒等式、压缩定理、贝叶斯充分失效定理、三阶段损失分解、发送者阈值定理，均有完整证明（附录 B）。
- **步骤级分析视角**：将分析单元从聚合任务指标下沉到单步决策，能区分“消息无用”“消息有用但接收者不会用”“错误跨步传播”三类失败。
- **识别策略精巧**：固定消息重放隔离接收侧损失；发送者替换隔离发送侧效应；严格重编码探针直接检验表示敏感性。
- **实验覆盖广**：6 个基准 + 7 个发送者 + 多模型家族（Qwen/OpenAI/DeepSeek/Llama/GLM/MiniMax），跨规模与跨家族验证。
- **统计严谨**：配对设计、实例聚类 bootstrap、McNemar 检验、Wilson 区间、多随机种子复现。
- **实用产出**：推理时选择器在准确率-成本前沿上优于固定策略与学习路由器，且校准敏感性低（5%–40% 校准分数下准确率波动仅 0.90pp）。
- **可复现性**：代码与逐步记录开源（MIT 许可），提供切片清单与复现脚本。

## 8. 不足与局限

- **步骤级而非轨迹级**：框架在单步粒度上预测精确，但扩展到端到端任务成功需建模跨步误差相关性；论文承认这一点。
- **理论假设较强**：定理依赖 log-loss、proper 压缩、瓶颈因子化、单交叉、共享 carry 序列等条件；实际部署中这些假设可能被违反。
- **选择器为分析引导**：增益代理 $\hat{A}$ 基于命中率代理分数而非实测对数概率；协议税偏移可能吸收增益效应，实例级排序信号有限。
- **实验覆盖不均**：OpenAI 扩展中 MA 单元步数（60–150）少于 RO/SF（300），部分单元格协议覆盖不等；τ-bench 效果不显著（CI 含零）。
- **共享状态结论有条件**：残差传播结果仅在轨迹耦合非平凡时成立；松散耦合场景下轨迹自行重同步，干预无效。
- **应用限制**：通信机制可能传播错误指令或暴露敏感上下文；降低通信成本也可能降低有害工作流的门槛，需与预期用途一并评估。
- **算力报告有限**：未报告具体推理时长或总 GPU 小时数，仅给出节点型号与 API 成本估算。
