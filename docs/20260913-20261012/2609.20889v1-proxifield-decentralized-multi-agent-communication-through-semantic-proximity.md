## 摘要
随着大语言模型能力的扩展，多智能体通信已成为一个日益活跃的研究领域。主流协议通常采用刚性结构，这会引入协调瓶颈，并且可能随着智能体数量的增加而性能下降。我们提出 Proxifield，一种轮次自适应的多智能体协议，具有去中心化的智能体决策能力，它根据智能体不断演化的语义邻近性构建稀疏通信图。无需模型训练或集中式规划器，Proxifield 使用推理时导出的四种路由信号连接智能体：直接寻址、信息需求、计划对齐和信息互补性。我们在两个领域中将 Proxifield 与两种代表性协调基线进行比较：集中式 Star 协议和去中心化 Shared Context 协议，这两个领域分别是无人机搜索与救援以及集体推理基准 HiddenBench。我们首先消融基础模型能力，发现在两个领域中，Proxifield 的性能都随模型规模提升而提高（35B -> 397B 参数模型），并且在最大规模下 Proxifield 优于所有基线。随着团队规模增加，Proxifield 相对于 Star 的任务奖励优势从 (N=5) 时的 5.4% 扩大到 (N=25) 时的 53.0%，再到 (N=50) 时的 59.5%，而 Shared Context 始终表现不如这两种协议。Proxifield 对永久性智能体故障也显著更具鲁棒性，在最严重条件下保留了其无故障任务奖励的 73.6%，相比之下 Shared Context 为 58.3%，Star 为 38.8%。这些结果表明，去中心化、语义自适应的路由可以提升多智能体系统的可扩展性和容错性。

## Abstract
As LLM capabilities have expanded, multi-agent communication has emerged as an increasingly active area of research. Prevailing protocols often adopt rigid structures that introduce coordination bottlenecks and can degrade as the number of agents increases. We introduce Proxifield, a round-adaptive multi-agent protocol with decentralized agent decision-making that constructs sparse communication graphs from the evolving semantic proximity of agents. Without model training or a centralized planner, Proxifield connects agents using four routing signals derived at inference time: direct address, information needs, plan alignment, and information complementarity. We compare Proxifield with two representative coordination baselines, a centralized Star protocol and a decentralized Shared Context protocol, across two domains: Drone Search and Rescue and the collective-reasoning benchmark HiddenBench. We first ablate base-model capability and find that, in both domains, the performance of Proxifield improves with model size (35B -> 397B parameter model) and Proxifield outperforms all baselines at the largest scale. As team size increases, Proxifield's task-reward advantage over Star widens from 5.4% at (N=5) to 53.0% at (N=25) and 59.5% at (N=50), while Shared Context consistently underperforms both protocols. Proxifield is also substantially more robust to permanent agent failure, retaining 73.6% of its no-failure task reward under the most severe condition, compared with 58.3% for Shared Context and 38.8% for Star. These results demonstrate that decentralized, semantically adaptive routing can improve the scalability and fault tolerance of multi-agent systems.

- **背景**：随着 LLM 能力提升，多智能体系统（MAS）在计算机操作、代码生成、机器人等领域快速扩展，但**协调协议的发展速度落后于系统规模的增长**。

  - 难以适应执行中途出现的依赖变化、故障或负载失衡；
  - 随团队规模增大产生**协调瓶颈**和**错误传播**；
  - 刚性协调脚手架带来的收益随基础模型能力提升而递减。
- **现有动态方法的不足**：已有动态拓扑方法（如 RADAR、G-Designer、MASRouter）虽能自适应生成通信图，但**仍依赖集中式 LLM 规划器或学习式图生成器**，重新引入了协调瓶颈，且往往需要训练轨迹。
- **核心研究问题**：能否在**不依赖集中式规划器、不进行模型训练**的前提下，从智能体自身演化状态中推导出通信连接？
- **整体含义**：论文提出 Proxifield，用"语义邻近性"替代"物理邻近性"（受动物群体去中心化局部交互启发），实现去中心化、轮次自适应的稀疏通信拓扑，旨在同时提升**可扩展性**与**容错性**。

## 2. 方法论

### 2.1 核心思想
- 将通信拓扑视为**推理时的协调决策**而非固定架构；每一轮重建有向交互图 $G^{(t)} = (A^{(t)}, E^{(t)})$，边 $a_i \to a_j$ 表示 $a_j$ 接收 $a_i$ 的提案。
- 无需集中式 LLM 规划器，无需训练轨迹，图构建是**确定性**的（给定提案与嵌入）。

### 2.2 五阶段算法流程（每轮重复）
1. **Propose（提案生成）**：每个智能体基于决策状态 $S_i^{(t)} = \langle \rho_i; o_i^{(t)}; H_i^{(t)} \rangle$（角色、观测、记忆）独立生成五元组 $X_i^{(t)} = \langle m_i^{(t)}, u_i^{(t)}, r_i^{(t)}, Q_i^{(t)}, D_i^{(t)} \rangle$，即消息、临时动作、理由、信息需求集合、显式收件人集合。
2. **Route（类型化语义路由）**：用预训练文本编码器嵌入消息、理由、观测、记忆摘要，计算四种路由信号：
   - **直接寻址** $s_{addr}$：指示函数，判断收件人是否被显式指定（作为优先边，不计入加权分数）；
   - **需求匹配** $s_{ask}$：发送方需求 $Q_i$ 与接收方观测/记忆的最大余弦相似度（每个需求单独嵌入，避免池化混淆）；
   - **计划对齐** $s_{align}$：消息与理由表示的中心化后余弦相似度最大值（≥3 个智能体时中心化）；
   - **信息互补** $s_{comp}$：观测与记忆相似度的补值，鼓励连接持有不同信息的智能体。
   - **稀疏图构建**：复合分数 $w_{i\to j}^{(t)} = \max\{\lambda_{ask}s_{ask}, \lambda_{align}s_{align}, \lambda_{comp}s_{comp}\}$；先处理直接寻址边，再按分数降序处理，受发送预算 $k$ 和接收上限 $c_{in}$ 约束；最后执行**覆盖遍历**，为无入边智能体补充最高分入边。
3. **Reply（提案投递与同伴评估）**：接收方对收件箱中每个提案返回结构化回复 $y_{j\to i}^{(t)} = \langle v_{j\to i}^{(t)}, \tilde{u}_{j\to i}^{(t)}, e_{j\to i}^{(t)} \rangle$，verdict 为 ACCEPT / REJECT / COUNTER 三类。
4. **Commit（动作提交）**：若所有路由接收方均返回 ACCEPT，则直接提交临时动作（**短路机制**，省去一次模型调用）；否则调用 LLM 提交策略 $\pi_{\theta_i}^{commit}$ 综合本地上下文选择最终动作。反提案为建议性而非强制性。
5. **Update（环境更新与记忆）**：同步应用联合动作，每 $\Delta_{mem}$ 轮通过递归摘要将观测与对话折叠进运行摘要。

### 2.3 关键超参数
- 语义通道权重固定为 $(\lambda_{ask}, \lambda_{align}, \lambda_{comp}) = (0.90, 0.85, 0.80)$（基于通道重要性人工设定，非学习所得）；
- 接收上限 $c_{in} = 3$，发送预算 $k \in \{1, 2\}$，记忆窗口 $\Delta_{mem} = 5$；
- 每轮模型调用量介于 $2N$ 到 $3N$ 之间。

## 3. 实验设计

### 3.1 评估场景 / Benchmark
- **Drone Swarm Search Environment (DSSE)**：网格化海上搜救环境，动态幸存者漂移概率分布。作者做了两项改造：
  - 引入**差异化角色**（scout 有半径 6 格的地面真值视野但不能 SEARCH；searcher 只能 SEARCH 但仅见当前格概率）；
  - **系统化扩展方案**：$S$ 个 scout 配 $4S$ 个 searcher、$2S$ 个坠机点、每点 2 名幸存者，网格面积约 $80N$ 格，保持每智能体格数恒定。回合长度 $T=100$。
- **HiddenBench**：分布式信息下的集体决策基准，共享信息偏向错误答案、私有信息共同支持正确答案。使用全部 80 个任务实例（$N=3$ 至 $7$），回合长度 $T=15$，在第 5/10/15 轮计算讨论后投票。

### 3.2 对比方法
- **Independent Agents（无通信）**：各自独立行动；
- **Star（集中式编排）**：固定星形拓扑，额外编排者智能体（始终使用最大模型），每轮 $2N+1$ 次调用；
- **Shared Context（黑板，DeLM 启发）**：去中心化共享上下文，含分层压缩、忠实性验证、原子追加，每轮 $5N$ 次调用；
- **Discussion**：HiddenBench 原始讨论协议（仅作参照）。

### 3.3 三项研究问题（RQ）
- **RQ1 模型能力**：Qwen3.5 三个 MoE 规模（35B-A3B / 122B-A10B / 397B-A17B），DSSE 固定 $N=5$；
- **RQ2 规模扩展**：$N \in \{5, 25, 50\}$，仅 DSSE（HiddenBench 不支持灵活扩展）；
- **RQ3 永久故障鲁棒性**：$N=25$，累积故障概率 $q \in \{0, 0.2, 0.4, 0.6, 0.8\}$，故障率由 $q = 1-(1-p_f)^T$ 反推每轮离线概率，仅 DSSE。

### 3.4 指标
- DSSE：**任务奖励**（合作总和，越早救援奖励越高）、**参与率**（有非零奖励的 searcher 比例）；
- HiddenBench：讨论后准确率 $d_{post}$、讨论前 $d_{pre}$、全信息 $d_{full}$。

## 6. 主要结论与发现

- **RQ1（模型能力）**：Proxifield 性能随模型规模提升而改善，在最大规模（397B）下于两个领域均超越所有基线。DSSE 中 35B 全去中心化团队（奖励 6.97）击败由 397B 编排者监督的 Star（4.74）；HiddenBench 中 35B 时 Shared Context 领先（0.77 vs 0.63），但 397B 时 Proxifield 反超（$k=1$ 时 0.79，$k=2$ 时 0.81 vs 0.78）。增大边预算 $k=2$ 收益甚微，不足以抵消额外成本。
- **RQ2（规模扩展）**：Proxifield 相对 Star 的任务奖励优势从 $N=5$ 时的 5.4% 扩大到 $N=25$ 时的 53.0%、$N=50$ 时的 59.5%。Star 参与率从 $N=5$ 的 75% 骤降至 $N=25$ 的 33%（编排者饱和）；Proxifield 在 $N=50$ 仍保持 >50% 参与率。Shared Context 扩展性甚至差于无通信基线。
- **RQ3（故障鲁棒性）**：$q=0.8$ 时 Proxifield 保留 73.6% 无故障奖励（28.8→21.2），而 Shared Context 保留 58.3%、Star 38.8%、No-Comm 39.8%。$q=0.8$ 时 Proxifield 参与率 39%（其余协议 8–11%），五次运行救援 60/100 名幸存者（其余仅 10–12 名）；搜索成功率 6.07%（其余 0.38–0.48%）；每 100 次 SEARCH 覆盖 52 个不同格子（其余 8–14 个），重复搜索显著更少。
- **总体结论**：去中心化、语义自适应路由能同时改善多智能体系统的可扩展性与容错性。

## 7. 优点

- **方法创新性**：用"语义邻近性"替代物理邻近性，将通信拓扑完全下放为推理时决策，**无需训练、无需集中式规划器、无需共享全局上下文**，规避了集中式瓶颈。
- **确定性路由**：图构建由嵌入与确定性规则完成，不额外消耗生成式模型调用，可复现性强。
- **工程细节扎实**：ACCEPT 全通过时的短路提交机制节省调用；覆盖遍历保证无孤立智能体；类型化需求（state/plan）设计精细；每轮仅 $2N$–$3N$ 次调用，成本可控。
- **实验设计严谨**：种子匹配的故障调度保证跨协议公平；Star 编排者用最大模型构成强基线；跨两个异质领域验证；同时报告任务奖励、参与率、成本多维指标。
- **鲁棒性验证深入**：不仅报告奖励，还给出搜索成功率、去重格子数等细粒度证据，支撑"分布式协调得以保留"的论断。

## 8. 不足与局限

- **环境覆盖有限**：规模扩展与故障鲁棒性**仅在 DSSE 单一环境**验证，作者自认需在更多协作场景中确认泛化性。
- **基线对比不完整**：未与 RADAR、G-Designer、DyTopo、AgentNet 等**同类动态/去中心化拓扑方法**对比，仅对比集中式 Star 与共享上下文。
- **超参数未调优**：语义通道权重 $(\lambda_{ask}, \lambda_{align}, \lambda_{comp})$ 为人工设定，作者承认未来需经验性校准；未提供敏感性分析。
