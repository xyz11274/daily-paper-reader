## 摘要
训练工具使用型智能体从自身经验中改进仍然具有挑战性，因为监督微调依赖于固定的教师蒸馏轨迹，而稀疏奖励强化学习对长程交互的监督较弱。我们提出了DeepSearch-Evolve，一个基于DeepSearch-World构建的网络智能体自蒸馏框架，DeepSearch-World是一个确定且可验证的环境，具有可复现的搜索和页面阅读工具。DeepSearch-World包含42万个由实体级随机游走构建的多跳问答任务，并支持自我进化所需的关键智能体认知行为，包括进度验证、基于事实的反思和故障恢复。DeepSearch-Evolve迭代执行轨迹生成、过滤、数据混合和微调，以训练更强的智能体。在没有更强大模型蒸馏的情况下，DeepSearch-World-9B与开源智能体相比取得了有竞争力的性能，在BrowseComp上达到31.2%，GAIA上61.5%，HotpotQA上93.4%，表明可验证环境能够实现长程网络智能体的可扩展自我进化。我们将发布环境、42万个训练池、验证集、模型和代码，以促进未来对自我改进的深度搜索智能体的研究。

## Abstract
Training tool-use agents to improve from their own experience remains challenging, as supervised fine-tuning relies on fixed teacher-distilled trajectories, while sparse-reward reinforcement learning provides weak supervision for long-horizon interactions. We present DeepSearch-Evolve, a self-distillation framework for web agents built on DeepSearch-World, a deterministic and verifiable environment with reproducible search and page-reading tools. DeepSearch-World contains 420K multi-hop QA tasks constructed from entity-level random walks and supports key agentic cognitive behaviors useful for self-evolving, including progress verification, grounded reflection, and failure recovery. DeepSearch-Evolve iteratively performs trajectory generation, filtering, data mixing, and fine-tuning to train stronger agents. Without distillation from more capable models, DeepSearch-World-9B achieves competitive performance compared with open-source agents, reaching 31.2% on BrowseComp, 61.5% on GAIA, and 93.4% on HotpotQA, showing that verifiable environments enable scalable self-evolution for long-horizon web agents. We will release the environment, 420K training pool, validation set, model, and code to facilitate future research on self-improving deep search agents.

## 1. 论文的核心问题与整体含义（研究动机和背景）
- **核心问题**：如何让具备工具使用能力的智能体（特别是长程网络搜索智能体）从自身交互经验中自主改进，而不依赖更强模型（如GPT-4）蒸馏的固定轨迹或稀疏的最终奖励。
- **研究背景**：现有方法包括监督微调（SFT）在正轨迹上，但性能容易饱和；强化学习（如GRPO）奖励稀疏，对中间步骤缺乏指导；近端策略自蒸馏（OPSD）需要可靠的密集监督，但在工具使用环境中难以获得。
- **整体含义**：论文试图通过构建一个**确定且可验证的离线环境**（DeepSearch-World），并结合**自蒸馏循环**（DeepSearch-Evolve），使搜索智能体能够从自身已验证的轨迹中逐步学习规划、记忆、错误恢复等高级行为，实现无需更强模型的自主进化。

## 2. 论文提出的方法论：核心思想、关键技术细节
- **核心思想**：利用确定性、可验证的离线维基百科环境，构造大规模多跳QA任务，并让智能体在该环境中自我生成轨迹，通过环境提供的实体级进度验证和基于规则的反饋，获得过程级监督；然后通过**脚手架教师智能体**生成高质量轨迹，再将其转换为标准ReAct格式，用于监督微调下一代学生智能体，如此循环迭代。
- **关键技术细节**：
  - **DeepSearch-World环境**：
    - 基于维基百科超链接图，通过实体级随机游走生成42万个多跳QA实例，每个实例有隐式目标实体集。
    - 离线语料库包含约1000万个维基条目，支持两个确定性工具：`web_search_wiki`（BM25检索，返回标题、摘要、URL）和`visit_wiki`（通过SQLite索引返回全文）。
    - 环境存储每个问题的目标实体集，并在每次工具调用后自动进行实体级进度验证：若返回结果匹配未完成实体则标记为成功，否则触发分阶段规则反射（第一次失败给出通用修正信号，多次失败给出更强线索如规范名称或模糊描述）。
  - **脚手架教师智能体**：三种阶段的提示：Plan（初始化进度状态，含已完成列表、待办列表、经验、信息）、Act（多轮工具调用+进度状态更新）、End（基于已验证工作记忆生成紧凑答案）。教师轨迹包含明确的规划、记忆跟踪、错误恢复。
  - **自我演化训练循环**（DeepSearch-Evolve）：
    - 每一轮R：当前模型π_θ_R在环境中生成脚手架轨迹，保留答案正确的轨迹，再用Qwen3.5-9B进行轨迹级质量过滤（去除冗余、弱目标对齐、不一致推理）。
    - **Scaffold-to-ReAct转换**：删除阶段特定提示，将进度状态和反思重写为思考块，保留工具调用和观察，形成标准ReAct格式训练数据。
    - 监督自蒸馏更新：在验证过的ReAct轨迹上进行SFT，相当于硬标签标记级策略蒸馏。采用**时间衰减的重要性采样**（因子γ=0.5）混合不同轮次的轨迹，优先近期数据同时保留早期数据防止遗忘。
- **公式/算法流程**：第3.3节给出损失函数：(1) SFT最小化L_SFT(θ)=E[∑ KL(δ_yt || π_θ)]，(2) OPSD最小化L_OPSD(θ)=E[∑ KL(q_t || π_θ^t)]。论文最终采用前者（演进式SFT）。

## 6. 论文的主要结论与发现
- **主要结论**：确定性、可验证的环境可以替代更强模型的蒸馏，使小型开源智能体（9B）通过自我生成和过滤轨迹实现持续改进，在多个搜索推理基准上达到与依赖更强教师或合成数据的开源智能体相当的性能。
- **具体发现**：
  - DeepSearch-World-9B相比骨干Qwen3.5-9B-Instruct在各基准上大幅提升（如BrowseComp +23.8%，GAIA +37.6%，HotpotQA +48.1%）。
  - 自我演化SFT依赖数据池多样性，更大的池（42万 vs 10万）带来更高、更稳定的性能。
  - 状态内化和反思重写对于从脚手架轨迹提取有效监督至关重要。
  - 拒绝采样（答案正确性验证）是自蒸馏中最重要的筛选步骤。
  - 工具使用行为显著改善：平均交互轮数从4.7增至18.0，搜索调用从3.8增至12.6，页面访问从0.9增至5.4，高级能力得分从19%升至70%。

## 7. 优点
- **方法创新**：提出了一种无需强模型蒸馏的自进化框架，通过确定性环境提供过程级验证信号，并将高级认知行为（规划、记忆、错误恢复）编码到标准ReAct训练数据中。
- **环境设计**：DeepSearch-World是确定性的、可复现的、低成本的离线环境，支持大规模并行轨迹生成和验证，避免了实时网络访问的不确定性和成本。
- **丰富的消融**：系统地拆解了各个组件（数据规模、轨迹过滤、状态内化、反思重写）的贡献，提供了清晰的归因。
- **性能提升显著**：仅从自身生成的已验证轨迹中学习，即能达到甚至超越许多依赖更强教师或复杂合成管线的开源模型。
- **可扩展性**：异步生成-训练设计使得可以在单一集群上高效进行多轮迭代。

## 8. 不足与局限
- **实验覆盖有限**：环境仅基于维基百科，领域和知识覆盖有限，可能无法泛化到更广泛的知识源或现实Web环境。作者也承认需要扩展到更广泛的知识来源。
- **训练范式局限**：当前采用演进式SFT，未探索RL或OPSD更新，后者可能进一步提升泛化性和灵活性。作者指出如何在RL训练中注入高级能力（规划、错误恢复、工具使用策略）仍未探索。
- **偏差风险**：维基百科本身可能存在社会偏见（如性别、地域、文化偏斜），模型训练后可能继承这些偏见。需要更多样化的数据源和安全对齐。
- **应用限制**：工具格式与真实Web工具对齐，但后端数据源仅限于维基，直接替换为线上工具可能面临性能差异（离线环境确定性 vs 线上动态性）。作者通过额外12.0轮GRPO微调（使用真实SerpAPI和Jina）来缓解，但该部分实验细节有限。
- **缺乏统计显著性测试**：消融实验报告了平均值但未提供变异度指标（如标准误差），难以判断差异是否统计显著。
- **对比基线不完全公平**：一些开源基线（如Marco-DR、MiroThinker）使用了更强模型蒸馏或更大模型，论文虽然承认这一点，但对比表直接并列可能误导对“同规模自进化”优势的解读。
