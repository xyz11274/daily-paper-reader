## 摘要
现有面向长时程LLM智能体的记忆系统通常将先前的轨迹作为被动上下文检索，而非将其转化为可执行能力。本文提出MSCE——一种无需训练的“记忆-技能”协同演化框架，该框架将智能体的经验组织为有根基的步骤轨迹、可复用的程序化策略以及声明式环境认知。MSCE将带有正面预估收益的有证据支持的L2策略结晶化为可调用技能，这些技能保留了证据链接、适用边界、决策指导、验证规则以及可靠性估计。它进一步引入了反思加权价值回填，通过密集的局部自我反思传播稀疏的终端反馈，从而产生用于管理记忆和技能演化的证据校准的轨迹值。在EvoAgentBench和LoCoMo上的实验表明，MSCE显著优于最先进的技能增强型和记忆驱动型智能体基线，展现出强大的跨领域迁移能力和终身演化能力。

## Abstract
Existing memory systems for long-horizon LLM agents often retrieve prior traces as passive context rather than converting them into executable capabilities. In this paper, we propose MSCE, a training-free Memory--Skill Co-Evolution framework that organizes agent experience into grounded step traces, reusable procedural policies, and declarative environmental cognition. MSCE crystallizes evidence-backed L2 policies with positive estimated gain into callable skills that retain evidence links, applicability boundaries, decision guidance, verification rules, and reliability estimates. It further introduces reflection-weighted value backfilling, which propagates sparse terminal feedback through dense local self-reflections to produce evidence-calibrated trace values for governing memory and skill evolution. Experiments on EvoAgentBench and LoCoMo demonstrate that MSCE significantly outperforms state-of-the-art skill-augmented and memory-driven agent baselines, exhibiting strong cross-domain transferability and lifelong-evolution capabilities.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：现有LLM智能体的长期记忆系统主要被动存储和检索历史轨迹（如原始交互、压缩上下文或反思），但这些记忆被作为被动上下文复用，并未转化为可执行的操作性知识（技能）。例如，重复的插件安装步骤仍需要智能体每次重新推理；反复探索同一代码仓库仍需重新列出目录。这导致token消耗高、效率低，且无法实现经验的自主演化。
- **背景**：长时程多任务场景（如工具使用、文件编辑、工作流协调）需要智能体具备跨会话记忆和自适应能力。已有工作要么侧重于事实记忆（原始日志），要么侧重于经验记忆（反思、总结），但缺乏从记忆中主动提炼可复用技能并基于证据进行治理的机制。
- **本文贡献**：提出MSCE（Memory-Skill Co-Evolution）框架，通过三层记忆层级（L1轨迹、L2策略、L3环境认知）将经验组织为有根基的证据，再将正增益的L2策略结晶化为可调用技能，并通过反射加权价值回填实现记忆与技能的协同演化。无需训练，即可提升长时程自主任务的性能与效率。

## 2. 方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：将智能体交互经验组织为结构化的三层记忆，并从中提取可复用的技能，通过证据锚定和价值信号控制技能的创建、修订和淘汰，形成记忆与技能的闭环演化。
- **技术细节**：
  - **三层记忆层级**：
    - **L1轨迹记忆**：存储每个步骤的`(状态, 动作, 观察, 自我反思, 轨迹价值)`，是基础证据层。价值初始为空，终端反馈到达后通过反射加权回填填充。
    - **L2策略记忆**：从跨回合的L1轨迹中归纳出可复用的程序化策略，包含触发条件、自然语言过程、验证标准、适用边界、支持证据集。归纳需要至少来自nmin个不同回合的证据。
    - **L3环境认知记忆**：从多个活跃L2策略中抽象出的声明式环境知识，如实体结构、动作-响应规律、约束条件。通过提示`Πenv`生成，避免包含过程性指令。
  - **技能结晶化**：满足以下条件的L2策略可结晶为技能：
    - 保留支持证据且增益$G(f^{(2)}) > \theta_G$（正增益）；
    - 近期证据与当前触发、过程、边界一致（稳定性）。
    - 增益公式：$G(f^{(2)}) = \bar{V}_{with} - \bar{V}_{blend}(S_{without})$，其中$\bar{V}_{with}$为软max加权均值，$\bar{V}_{blend}$为收缩后的无侧均值。
    - 结晶后的技能包含触发器、过程、验证规则、边界、证据锚点、决策指导和可靠性估计$\eta = (n_{pass}+1)/(n_{trial}+2)$。
  - **反射加权价值回填**：
    - 耦合稀疏终端反馈$R_i$与密集步骤级自我反思$\rho_{i,t}$，产生统一轨迹价值：
      $$V(f^{(1)}_{i,t}) = \alpha_{i,t} R_i + (1-\alpha_{i,t})\gamma V(f^{(1)}_{i,t+1})$$
      其中$\alpha_{i,t} \in [0,1]$由提示`Πreflexion_score`根据反思的忠实性、因果洞察性、可迁移性和具体性估计。
  - **在线更新流程**：回合结束后，持久化L1轨迹 → 接收终端反馈 → 回填价值 → 关联或归纳L2策略 → 触发L3抽象 → 评估技能资格 → 结晶验证 → 部署。同时根据失败/纠正生成决策指导。
