## 摘要
自我进化框架通常优化任务解决方案，同时将周围框架视为固定不变。我们提出了感知框架的自我进化（HASE），一种基于智能体强化学习的框架，其中单个模型可以在多轮动作空间中生成任务解决方案或编辑选定的框架组件。HASE使得单个Qwen3-8B模型能够匹配使用Claude Code作为框架提议者的GPT-OSS-120B模型在文本分类上的性能。在alpha因子挖掘中，HASE超越了已报道的GPT-OSS-120B基线。HASE还能修复不完善的评估组件，并在圆填充算法发现中收敛到最先进的性能。这些结果表明，HASE通过统一的智能体过程改进了框架和解决方案。

## Abstract
Self-evolving frameworks usually optimize task solutions while treating the surrounding harness as fixed. We introduce Harness-Aware Self-Evolving (HASE), an agentic reinforcement-learning framework in which a single model can generate task solutions or edit selected harness components in a multi-turn action space. HASE enables a single Qwen3-8B model to match the text-classification performance of a GPT-OSS-120B model that uses Claude Code as the harness proposer. In alpha factor mining, HASE outperforms the reported GPT-OSS-120B baseline. HASE also repairs imperfect evaluation components and converges to state-of-the-art performance in circle-packing algorithm discovery. These results show that HASE improves the harness and the solution through one unified agentic process.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **问题**：当前自演化（Self-Evolving）系统通常将模型周围的「框架」（Harness）视为固定不变，只优化目标解决方案（如代码、算法等）。框架包括提示词（prompts）、记忆（memory）、上下文检索（retrieval）、工具接口、验证器（validator）和评分器（scorer）等组件，这些组件决定了模型观察到的信息、可用的动作以及候选解的评分方式。
- **固定框架假设的局限**：
  - 人类编写的验证器可能不完整或与外部环境不一致，模型可能在评分驱动下利用验证器漏洞而非真正解决问题。
  - 引导框架（如提示词、检索策略）可能提供糟糕的搜索先验，抑制了模型通过改进自身计算环境来提升性能的机会。
- **整体含义**：提出一种统一的、感知框架的自我进化方法，让单一模型在同一智能体动作空间中既能生成任务解决方案，也能编辑选定的框架组件，从而协同进化模型权重、框架和解决方案，提升模型在复杂任务上的表现。

## 2. 论文提出的方法论：核心思想、关键技术细节、算法流程

- **核心思想**：将框架编辑融入多轮强化学习动作空间，使得模型在搜索任务解的同时也能修改自身的引导组件和评估组件。通过阶段级（phase-level）审核和真实世界反馈（oracle）锚定，防止奖励黑客攻击（reward hacking）。
- **两种框架组件类型**：
  - **引导组件**（Guidance）：如提示词、记忆格式化、检索脚本、上下文选择等。这些组件改进搜索过程，但不改变任务正确性。HASE允许自由改进。
  - **评估组件**（Evaluation）：如验证器和评分器，定义解的合法性和任务指标。HASE仅在本地代理评分与外部真实评分出现分歧时才能被编辑，且必须通过阶段级审核。
- **统一动作空间**：模型可以在多回合交互中生成解决方案或使用sandbox工具（如`ls`、`cat`、`replace`、`done`等）检查和修改框架文件。没有硬编码的计划器，模型根据上下文决定行动。
- **算法流程（Algorithm 1）**：
  1. 初始化持久化框架 h₀ 和策略 πθ；
  2. 若任务允许评估框架进化，初始化不匹配集 M = ∅；
  3. 对每个阶段 p = 1..P：
     - 初始化阶段候选池 Cₚ = ∅；
     - 对每个GRPO epoch e = 1..N_epoch：
       - 从 πθ 中 rollout 多回合轨迹（包含解提议和框架编辑动作）；
       - 用本地评估器对提交的解打分 r_task；
       - 为轨迹分配奖励 r(τ)（不直接奖励框架操作，只奖励最终解质量）；
       - 将可解析的、具有正PoC（概念验证）信号的引导编辑加入 Cₚ；
       - 用GRPO更新 πθ；
     - 若任务允许评估进化，查询真实评估器并加入不匹配集 M，审核评估编辑；
     - 审核引导编辑（过滤、排序、验证评分），提交最佳稳定框架 h←h_{p+1}。
- **奖励设计**：框架编辑本身无直接奖励；引导编辑的信用通过PoC信号传递（编辑后同轨迹解获得更好分数）；评估编辑的奖励仅当代理评分与真实评分不一致时按不匹配集一致性的提升比例给予。
- **引导框架进化**：阶段边界对候选池进行过滤、排名和验证，仅提交验证集上改进的补丁。
- **评估框架进化**：每个补丁必须修复更多不匹配集中的案例，同时保留接口和未退化的案例。不需要一次性修复所有错误，随着新反例出现逐步调试。

## 6. 论文的主要结论与发现

1. **HASE使小模型匹敌大模型+外部搜索**：Qwen3-8B在S2D文本分类中达到86.98%准确率，与Meta-Harness（GPT-OSS-120B + Claude Code）的86.8%相当，证明了统一智能体框架的有效性。
2. **在Alpha因子挖掘上超越强基线**：HASE Qwen3-8B在CSI300上取得RankIC 0.0302、AER 14.35%、IR 1.70，优于之前报道的GPT-OSS-120B（RankIC 0.0318、AER 7.89%、IR 0.80）及其他大模型。
3. **评估框架修复能力**：圆填充中，HASE从有缺陷的验证器开始，通过两轮分歧驱动修复，最终达到AlphaEvolve SOTA（2.635983）。Heilbronn三角形中，修复验证器后协同进化解性能（0.036082）远超冻结策略（0.021880）。
4. **统一动作空间无需外部提议者**：HASE不依赖独立的强大编码模型作为框架搜索器，而是同一个8B模型同时承担任务解和框架编辑。

## 7. 优点

- **统一框架**：将过去分离的框架搜索和任务解搜索整合到一个动作空间中，让模型自主决定何时编辑框架、何时提交解，更具灵活性。
- **安全设计**：对评估组件的编辑受真实世界oracle锚定，仅在出现分歧时允许修改，且需阶段审核，防止奖励黑客攻击。引导组件自由编辑但需阶段验证。
- **广泛验证**：在引导和评估两类框架进化上均取得显著成果，覆盖分类、金融、几何优化等领域。
- **多回合自纠错**：在S2D中展示了模型通过编辑检索工具自我纠正错误分类的具体案例。
- **资源效率**：仅用8B模型实现120B+外部搜索系统的性能，表明通过协同进化可以显著提升小模型系统能力。

## 8. 不足与局限

- **非全面规模化研究**：每个领域仍有更困难的设定未测试（如更大数据集、更复杂任务），尚不清楚HASE在极端缩放下的表现。
