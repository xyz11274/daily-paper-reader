## 摘要
基于结果监督的搜索智能体可学习何时及如何检索证据，但终端奖励既无法定位中间错误，也无法在错误累积之前修正当前搜索轨迹。将纠正反馈视为习得的轨迹内干预会耦合两类角色：智能体必须决定何时请求并使用反馈，而评判器必须从结果混淆的轨迹采样（rollout）中推断出有用的修正，这些采样的失败模式会随着智能体的改进而发生变化。我们提出CAFE（耦合智能体-反馈进化，Coupled Agent--Feedback Evolution），该框架采用共享参数模型交替承担搜索智能体与评判器角色。CAFE基于基础智能体自身失败构建的轨迹初始化反馈条件恢复，随后耦合在线优化与离线优化。在线强化学习（RL）过程中，比较性反馈估计利用提示级别的调用-跳过成功差距塑造请求回报，而感知反馈的优势塑形在反馈前后对token优势进行重加权。离线阶段，由轨迹采样得到的偏好优化从匹配的成功与失败轨迹中学习反馈。在七个智能体搜索基准测试中，CAFE的平均性能优于所有被评估的基于RL的搜索智能体，在全部六个域外基准测试中都保留了性能增益，并且减少了答案级幻觉。单侧消融实验表明，仅改进智能体或仅改进评判器最终都会进入性能平台期，而交替更新两类角色能持续提升性能。这些发现表明，自我改进的搜索智能体需要与其引导的策略共同进化的反馈。

## Abstract
Outcome-supervised search agents learn when and how to retrieve evidence, but terminal rewards neither localize intermediate errors nor redirect an ongoing trajectory before those errors compound. Treating corrective feedback as a learned in-trajectory intervention couples the two roles: the agent must decide when to request and use feedback, while the critic must infer useful corrections from outcome-confounded rollouts whose failure patterns shift as the agent improves. We introduce CAFE (Coupled Agent--Feedback Evolution), a framework in which a shared-parameter model alternates between search-agent and critic roles. CAFE initializes feedback-conditioned recovery from trajectories built around the base agent's own failures, then couples online and offline optimization. During online RL, a comparative feedback estimate uses a prompt-level call--skip success gap to shape request returns, while feedback-aware advantage shaping reweights token advantages before and after feedback. Offline, rollout-derived preference optimization learns feedback from matched successful and unsuccessful trajectories. On seven agentic search benchmarks, CAFE outperforms the evaluated RL-based search agents on average, retains its gains across all six out-of-domain benchmarks, and reduces answer-level hallucinations. One-sided ablations show that improving only the agent or only the critic eventually plateaus, whereas alternating the two updates continues to improve performance. These findings suggest that a self-improving search agent needs feedback that co-evolves with the policy it guides.

# 论文核心问题与研究背景
- 现有基于结果监督的搜索智能体仅依赖终端任务奖励，无法定位搜索轨迹中的中间错误，也不能在错误累积前纠正当前搜索方向，早期错误会不断传播最终导致任务失败
- 现有引入反馈的工作大多是prompt驱动的事后修正，而非可学习的轨迹内主动干预，同时存在三个核心挑战：
  1. 智能体需要学习何时请求反馈，但救援成功的轨迹和原生成功的轨迹终端奖励相同，难以正确分配信用
  2. 反馈评判器没有ground truth标注，反馈质量被前置搜索错误和后续智能体动作混淆，难以学习有效反馈
  3. 智能体策略更新后，遇到的失败分布会发生变化，静态反馈评判器会逐渐和策略不对齐，失去指导作用

# 论文提出的方法论
## 核心思想
提出**耦合智能体-反馈进化（CAFE）**框架，让同一个共享参数的大语言模型交替承担搜索智能体和反馈评判器两个角色，通过交替在线优化智能体策略、离线优化反馈生成能力，实现二者的共同进化，保证反馈始终匹配智能体当前的失败分布。

## 关键技术细节
1. **反馈增强初始化**
   - 收集基础智能体自身的失败轨迹，让教师大模型定位第一个错误出现的位置，保留错误前缀，插入反馈请求动作，再由教师生成纠正反馈和后续成功恢复的轨迹，仅保留最终修复成功的轨迹做监督微调（SFT），让模型一开始就学习处理自身真实会遇到的错误
2. **在线智能体强化学习优化**
   - **比较性反馈估计（CFE）**：对同一个输入prompt，采样多组搜索轨迹，分为请求反馈组和不请求反馈组，计算两组的成功率差异，将该差异作为反馈请求的效用奖励，加入原任务奖励，同时惩罚重复多次的反馈请求，让智能体学习何时请求反馈是有用的
   - **感知反馈的优势塑形**：针对原方法会给整个轨迹所有token相同奖励的问题，将轨迹拆分为反馈请求前、请求动作、反馈请求后三段，降低错误前缀的奖励权重，提高正确恢复部分的奖励权重，解决信用分配错误的问题
3. **离线反馈优化与共进化循环**
   - **滚动导出偏好优化（RDPO）**：每一轮在线更新后，从最新生成的搜索轨迹中，挖掘前缀匹配的成功请求反馈轨迹和失败请求轨迹，将成功轨迹对应的反馈作为正偏好，失败轨迹的反馈作为负偏好，用直接偏好优化更新共享模型，保证反馈始终匹配当前智能体的最新失败模式
   - 循环交替执行「在线智能体更新→离线反馈优化」，实现二者的持续共同进化

# 主要结论与发现
1. 性能方面：7B参数规模的CAFE平均性能优于所有被评估的基于RL的搜索智能体，比最强基线高出2.1 EM和1.3 F1；性能增益可以保留到所有六个域外基准，泛化性良好。
2. 幻觉方面：CAFE可以有效降低答案级幻觉，平均幻觉率从纯outcome监督GRPO的17.6%降低到12.6%，在所有基准上都实现了幻觉率下降。
3. 共进化方面：单独只优化智能体、或者单独只优化反馈评判器，性能最终都会进入平台期；只有交替更新二者，性能可以持续提升，验证了共进化的必要性。
4. 反馈演化方面：反馈会随着智能体的进步自动调整关注方向：早期聚焦纠正基础检索、实体对齐错误，中期聚焦证据验证，后期聚焦解决重复搜索、规划错误等高阶问题，匹配智能体不断变化的失败分布。

# 方法优点
1. 核心思路创新：首次明确提出搜索智能体的自改进需要反馈和策略共同进化，解决了静态反馈和 evolving 策略不对齐的长期问题。
2. 模块设计针对性强：CFE和优势塑形解决了反馈引入后的信用分配混淆问题，RDPO利用前缀匹配偏好对解决了反馈无ground truth的问题，设计精巧贴合问题本身。
3. 通用性强：在3B和7B不同规模的模型上都能取得稳定提升，3B CAFE的性能已经可以和部分7B搜索基线可比，实用性强。
4. 实验充分严谨：从主性能、泛化、消融到机制分析，各个维度都做了验证，核心结论得到了充分支持。

# 不足与局限
1. 方法层面：采用共享参数承载两个角色，对模型容量有一定要求，更小参数量模型的双角色承载能力还未经过充分验证。
2. 训练成本：交替迭代的训练流程比单阶段训练更复杂，训练门槛和成本更高。
3. 任务通用性：目前仅在搜索问答任务验证了效果，在其他长周期智能体任务（如任务规划、代码开发）的通用性还需要进一步测试。
4. 初始化依赖：初始反馈数据依赖教师大模型标注，还未实现完全不依赖外部教师的全自举训练。
