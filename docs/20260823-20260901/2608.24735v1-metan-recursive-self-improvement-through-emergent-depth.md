## 摘要
自我改进的大语言模型智能体仅优化答案，而非生成答案的过程。添加元层级的系统会将该层级固定，而进行自我编辑的系统必须保留部分自身编辑机制不变以维持稳定性，因此其可实现的元深度上限约为2。我们提出Meta$^n$，该方法保持元操作固定，转而对其输入进行递归。该操作$Ω$被重复应用于其自身生成的产物，读取下方求解器栈的轨迹以及生成这些轨迹的代码，随后将下一层构建为策略化预处理模块和可调用助手库。由于$Ω$始终不变，它不会造成系统失稳；且由于其输入严格增长，每一层都能从比上一层更高的视角开展推理。深度由收敛性决定而非预先固定，演化存档会对层链进行搜索。在两种骨干模型上，Meta$^n$在全部8个基准族上的表现均优于以往的自我改进智能体。性能提升最显著的是专为抵御技能记忆构建的ARC-AGI-2，在该基准上仅有Meta$^n$取得正得分。消融实验表明，递归带来的大部分收益来自每一层向下一层传递的条件信息，且尽管没有提示规定各层角色，不同层仍会随深度涌现出明确区分的角色。代码可获取于https://github.com/minnesotanlp/meta-n

## Abstract
Self-improving LLM agents refine answers, not the process that produces those answers. Systems that add a meta-level hold that level fixed, and those that edit themselves must leave part of their own editing machinery untouched to stay stable, capping the meta-depth they realize at roughly two. We present Meta$^n$, which keeps the meta-operation fixed and recurses on its input instead. That operation, $Ω$, is applied repeatedly to its own products, reading the traces of the solver stack below together with the code that produced them, then writing the next layer as a strategic pre-process and a library of callable helpers. Because $Ω$ never changes, it cannot destabilize the system, and because its input strictly grows, each layer reasons from a higher vantage than the last. Depth is set by convergence rather than fixed in advance, and an evolutionary archive searches over layer chains. Across two backbones, Meta$^n$ outperforms prior self-improving agents on all eight benchmark families. The sharpest case is ARC-AGI-2, built to resist skill memorization, where it alone scores above zero. Ablations indicate that most of the gain from recursion comes from the conditioning each layer passes to the next, and distinct layer roles emerge with depth although no prompt prescribes them. Code available at https://github.com/minnesotanlp/meta-n

## 1. 核心问题与研究背景

## 2. 提出的方法论
### 核心思想
通过架构设计绕开原有两难：**固定一个通用的元操作Ω不修改，转而对Ω的输入进行递归**，每次Ω读取已有下层栈的运行轨迹和生成代码，输出新的一层，深度增长到无性能提升就自动停止，既保证了系统稳定性（Ω不变），又能突破原有元深度上限。

### 关键技术细节
1. **单层级运行逻辑**：每个新元层分为构建阶段和运行阶段：
   - 构建阶段：固定元操作Ω接收输入：前序深度的所有运行轨迹、前序所有层的代码、全部任务描述、当前深度，输出新层$C_d$，包含两部分：① 预处理函数$f_{pre}^d$：为每个任务生成注入策略上下文；② 可调用助手库$L(d)$：存放可复用的工具函数。
   - 运行阶段：包装器$M_d$将新层套在原有求解器外，流程为：外层预处理先生成上下文，逐层向下传递细化上下文，基求解器接收合并后的上下文生成脚本，合并所有层的助手库（深层重名覆盖浅层），最后沙箱执行得到结果。
2. **层链搜索策略**：支持两种增长模式：
   - 线性递归：贪心逐层增长，直到连续多轮无明显性能提升就停止，深度由收敛自动决定；
   - 演化存档搜索：维护候选层链的存档，采样父代时给高分、少扩展的链加探索奖励，生成子代时控制温度保证多样性；额外支持**整合防护**机制：每个新候选仅优化单个目标任务，继承其他任务的已有最优结果，保证每个任务的性能轨迹单调不退化。

## 6. 主要结论与发现
- Meta n在两种骨干模型的全部8个基准上，性能均优于现有自改进智能体，在专为对抗技能记忆设计的ARC-AGI-2上，是唯一取得正得分的方法；
- 递归带来的性能收益中，约72%来自层间上下文条件传递，15%来自可调用代码库跨任务转移，剩余约13%来自搜索机制本身；
- 不需要prompt预先指定各层角色，不同深度会自然涌现出功能分化的角色：深度2生成通用跨任务原语，深度3生成任务专用化规则和路由，深度4及以上主要承担修正回滚、细化优化的功能；
- Meta n的性能收益和任务的失败模式多样性、基模型的提升空间正相关：失败模式越多样、基模型离性能天花板越远，收益越显著。

## 7. 优点
- 架构创新：从根本上解决了原有自改进方法「元深度提升」和「系统稳定性」的两难问题，首次实现了2层以上的有效元深度，不同深度会产生结构差异化的功能，而非冗余重复；
- 通用性强：一个固定的元操作提示模板可以适配从代码生成、算法发现到文本分类、终端任务等完全不同的场景；
- 自适应深度：深度由收敛自动决定，不需要手动预先指定，可适配不同复杂度的任务；
- 实验设计严谨：控制了变量和计算预算，多骨干多基准验证，结论可靠；
- 揭示了无监督角色涌现的规律，深化了领域对递归元改进的认知。
