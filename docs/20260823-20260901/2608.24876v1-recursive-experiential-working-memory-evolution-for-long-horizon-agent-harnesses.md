## 摘要
递归自改进（RSI）在长视野任务中仍极具挑战性，不断增长的任务历史会模糊任务状态并导致技能调用错位。我们提出Recuris，这是一种面向长视野智能体框架的递归经验-工作记忆架构：在该架构中，工作记忆跟踪任务进度，并从经验记忆中指导技能选择，将技能使用锚定在当前需求而非完整任务历史上。这种耦合还将执行过程转化为结构化证据，可将故障定位到特定记忆组件。在各类任务中，固定元智能体将该证据转化为技能记忆的局域化、经验证门控的更新，重塑执行过程并产生新证据，形成有界的递归记忆演化循环。在四个长视野基准测试和十个模型上的实验表明，Recuris在37组已完成的模型-基准配对中提升了35组的任务成功率，将前沿模型推至SOTA级任务性能：在tau-bench上，它为GPT-5.6 Sol提升17.8个百分点，为Claude Opus 5提升15.6个百分点，使Opus 5达到87.9%的成功率；在SkillFlow上，为Qwen3.6-27B/35B分别提升16.6/13.5个百分点。随着交互视野增长，优势进一步扩大，在最长任务中优势达到+32.2个百分点，常见长视野故障最高减少80%。这些结果表明，递归演化记忆可作为递归自改进（RSI）的可扩展基础，使智能体能够将积累的经验持续转化为越来越有效的长视野行为。代码：https://github.com/Gen-Verse/Recuris

## Abstract
Recursive self-improvement (RSI) remains hard in long-horizon tasks, where growing histories obscure the task state and misalign skill invocation. We introduce Recuris, a recursive Experiential-Working Memory architecture for long-horizon agent harnesses, in which Working Memory tracks task progress and guides skill selection from Experiential Memory, grounding skill use in current needs rather than the full history. This coupling also turns execution into structured evidence that localizes failures to specific memory components. Across tasks, a fixed Meta-Agent turns that evidence into localized, validation-gated updates to Skill Memory that reshape execution and yield new evidence, forming a bounded recursive memory-evolution loop. Across four long-horizon benchmarks and ten models, Recuris improves task success in 35 of the 37 completed model-benchmark pairs, carrying frontier models to SOTA-level task success: on tau-bench it adds +17.8 points to GPT-5.6 Sol and +15.6 to Claude Opus 5, taking Opus 5 to 87.9%, and +16.6/+13.5 points on Qwen3.6-27B/35B on SkillFlow. The advantage widens as the interaction horizon grows, to +32.2 points on the longest tasks, and common long-horizon failures fall by up to 80%. These results position recursively evolving memory as a scalable foundation for RSI, enabling agents to continuously transform accumulated experience into increasingly effective long-horizon behavior. # 论文详细总结
## 1. 核心问题与研究背景
- 大语言模型智能体在长视野（长时序）任务中，递归自改进（RSI）长期存在核心痛点：随着交互历史增长，冗长历史会遮蔽当前任务状态，导致技能调用错位。
- 现有方法检索技能时要么依赖初始指令、要么依赖完整交互历史，历史中混杂过时信息、已完成步骤和执行噪音，缺乏紧凑可靠的当前任务状态来对齐积累经验和当前执行需求，现有记忆机制通常是固定的，无法根据执行结果迭代优化，难以支撑有效的递归自改进。

## 2. 提出的方法论
### 核心思想
提出Recuris架构，通过耦合经验记忆（存储可复用技能）和工作记忆（跟踪验证当前任务状态），生成结构化执行痕迹支撑精准故障定位，由固定元智能体完成局域化、验证门控的记忆更新，形成有界递归记忆进化循环，整个过程不需要修改底层大模型，仅进化外部记忆控制层，实现低成本的递归自改进。

### 关键技术流程
分为两个嵌套循环：
1. **任务内验证式EM-WM耦合执行循环**
   - 结构化工作状态：工作记忆初始化后，每个目标会记录内容、状态（待处理/完成/阻塞）、支撑证据、阻塞点，仅保留紧凑的当前任务进度信息。
   - 状态锚定的技能调用：仅在预定义执行事件（如 draft 工具调用阶段、轮次边界）触发技能检索，仅将匹配当前状态的技能放入上下文，而非全量注入所有技能。
   - 证据锚定的状态更新：状态更新必须经过环境反馈验证，只有实际观测证据支持的状态变化才会提交，不相信模型自行声明的任务完成，保证工作状态始终和实际执行结果一致。
   - 执行过程会生成结构化轨迹，记录每一步的状态、调用技能、动作、观测结果、验证决策，为后续进化提供诊断依据。
2. **跨任务有界技能记忆进化循环**
   - 基于轨迹的故障定位：固定元智能体从结构化轨迹中，将每个失败归因到具体的记忆组件（经验技能错误/状态定义错误/调用策略错误/验证检查错误）。
   - 组件特异性补丁修复：仅对出故障的组件生成修改补丁，未出问题的组件完全保留，避免全量重写记忆带来的不稳定性。
   - 验证门控补丁准入：补丁只有同时满足「修复了原目标故障」+「不会导致开发集已解决的锚定任务性能退化」两个条件，才会被正式并入记忆，否则保留原记忆。
   - 递归循环：更新后的记忆用于后续任务执行，生成新的结构化轨迹，触发下一轮进化，整个过程底层大模型、元智能体流程都保持固定，仅进化外部记忆控制层，属于有界递归，不会出现无限制的自我修改。
3. 额外支持**单任务测试自适应模式**：针对没有共享结构的孤立任务，可在同一个任务的多次尝试内，基于自身失败轨迹进化局部记忆，适配单任务场景。

## 3. 实验设计
### 数据集与基准
共使用4个长视野任务基准：
- τ²-Bench：包含两个工具使用领域，`τ²-Retail`（114个任务）、`τ²-Airline`（50个任务），要求智能体通过合规工具调用满足用户需求，只有环境验证完全完成才算任务成功。

## 7. 方法与实验设计亮点
- 设计思路新颖：将递归自改进限定在外部可进化的记忆控制层，不需要修改底层大模型参数，也不需要改写整个智能体程序，兼容性好、可复用性强，进化一次可多次复用给不同模型，成本低。
