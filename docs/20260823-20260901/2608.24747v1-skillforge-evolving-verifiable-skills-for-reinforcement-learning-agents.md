## 摘要
大语言模型（LLM）智能体通过强化学习（RL）训练以完成复杂决策任务。然而，大多数经RL训练的智能体仍为回合制，无法在不同回合间积累可复用知识。近年基于技能的方法（如SkillRL）试图通过从原始轨迹中提取技能解决该问题，但将技能库视为仅可追加的存储库，未验证已存储技能是否仍保持有效性。本文提出SkillForge，这是一个面向持续技能演化的框架，支持通过环境交互对技能进行验证与精炼。通过在智能体交互过程中显式化技能使用，RL可直接优化环境动作与技能调用决策。SkillForge进一步引入基于证据的技能验证与多路径技能归纳，使技能库能够在持续扩容的同时保持质量。在ALFWorld、WebShop和AppWorld上开展的大量实验表明，SkillForge性能始终优于SkillRL，证明了持续可验证技能在训练更强LLM智能体方面的有效性。

## Abstract
Large language model (LLM) agents are trained with reinforcement learning (RL) for complex decision-making tasks. However, most RL-trained agents remain episodic and cannot accumulate reusable knowledge across episodes. Recent skill-based approaches, such as SkillRL, attempt to address this issue by extracting skills from raw trajectories, but treat the skill bank as an append-only repository without verifying whether stored skills remain effective. In this paper, we propose SkillForge, a framework for continuous skill evolution that enables skills to be verified and refined through environment interaction. By making skill usage explicit during agent interaction, RL can directly optimize both environment actions and skill invocation decisions. SkillForge further introduces evidence-based skill verification and multi-pathway skill induction, allowing the skill bank to continuously grow while maintaining its quality. Extensive experiments on ALFWorld, WebShop, and AppWorld show that SkillForge consistently outperforms SkillRL, demonstrating the effectiveness of continuously verified skills in training stronger LLM agents.

# 论文详细总结
## 1. 核心问题与研究背景
- 背景：当前大语言模型（LLM）智能体普遍采用强化学习（RL）训练解决复杂决策任务，但绝大多数RL训练的智能体仍为回合制，每个任务从头开始推理，无法跨任务回合积累复用有效的知识，导致重复探索、学习效率低下。
- 现有方案缺陷：SkillRL等近年提出的技能-based方法，通过从交互轨迹提取技能实现知识复用，但将技能库设计为仅可追加的存储库，不对已存入技能的有效性进行验证，存在三个核心缺陷：
  1. 技能使用不可观测：技能批量注入prompt，无法确认智能体是否实际使用了某技能
  2. 效果无法归因：没有显式使用信号，无法确认任务成功是否由某技能带来
  3. 技能质量无控制：错误、过时的技能会一直留在库中，逐渐污染知识库
- 核心问题：如何让RL训练的LLM智能体持续积累、迭代高质量可复用技能，保证技能库扩容同时维持技能有效性。

## 2. 提出的方法论
### 核心思想
提出SkillForge持续技能演化框架，通过显式技能调用让技能使用可追踪，基于环境交互得到的证据验证和精炼已有技能，结合多通路新技能归纳，实现技能库持续高质量演化。

### 关键技术细节
1. **技能表示与检索**
   - 每个技能为结构化单元，包含：可调用标题标识、技能意图、核心决策原则、适用条件、分类（通用/任务特定）、状态（激活/审核中）
   - 技能库分为两层：通用技能（跨任务适用的通用策略）+ 任务特定技能（对应某类任务的领域知识）
   - 每轮任务开始，基于语义相似度检索和任务最相关的top技能，仅将技能标题和一句话意图组成紧凑目录注入prompt，完整技能内容仅在显式调用后返回，保持prompt紧凑。

2. **显式技能调用与联合优化**
   - 要求智能体每步输出除环境动作外，可通过`<skill_call>`结构化标签显式调用技能，调用后将完整技能内容拼接到下一步观测中
   - 技能调用成为轨迹中可追踪的离散事件，实现技能使用的可观测和可归因
   - 采用GRPO算法优化策略，同时优化环境动作和技能调用决策，滚动轨迹按任务结果分为成功/失败集合，抽象后存入缓冲区用于技能更新。

3. **持续技能演化机制**
   - **多通路技能归纳**：每固定训练步数，调用教师LLM从轨迹抽象归纳新技能，根据可用轨迹选择三种归纳通路：
     - 提取：仅成功轨迹可用时，从成功轨迹提取通用可复用策略
     - 精炼：仅失败轨迹可用时，从重复失败中总结修正策略
     - 对比分析：同时有成功失败轨迹时，对比两者差异得到关键决策规则
     新技能生成后经过词法+语义去重再加入技能库，避免冗余。
   - **基于证据的技能验证**：对每个技能跟踪指数移动平均（EMA）成功率和总使用次数，计算低表现得分，得分越高说明技能无效的证据越充分，优先交给LLM反思，根据使用记录决定保留或修改技能，及时淘汰/修正失效技能，避免知识退化。

4. **整体训练流程**：交替进行「技能增强的轨迹采样→策略参数更新」，每固定步数执行一次技能库更新（归纳新技能+验证精炼已有技能），更新后的技能库立即用于后续采样，形成闭环演化。
