## 摘要
当我们谈论递归自我改进（RSI）时，我们谈论的是一种现象、一种机制，还是一种前景？在迈向自主且不断演化的智能的过程中，RSI 正在许多尺度上被提出，但尚无单一框架能够形式化地描述这些新兴实例。其在经典领域中的对应物——迭代策略改进——由广义策略迭代（GPI）刻画；这是一个适用性广泛且理论性质已被充分理解的框架，但仅限于更新原则与评估基础都位于智能体之外的情形。在本文中，我们提出广义智能体迭代（GAI），一个将迭代策略改进与 RSI 描述为同一学习范式的两种情形的形式化框架。GAI 将智能体定义为一个系统内可修改组件的配置，并将学习过程建模为智能体评估与智能体改进的循环。两个关键调节维度随后区分这些实例：改进机制是否属于智能体的一部分，以及衡量它所依据的标准是否根植于其外部。前一个调节维度划定了 GPI 与 RSI 之间的边界，后一个则决定系统的极性，即锚定型、目标漂移型或完全自指型。此外，我们使用这些坐标将现有系统置于相同的两个轴上，并使递归自我改进的缺陷能够逐个条件地加以陈述。我们将本文视为迈向探索 RSI 形式化刻画的第一步；该刻画立足于经典解释，使现有系统具有可比性，并为分析和设计新系统提供有原则的基础。

## Abstract
When we speak of recursive self-improvement (RSI), are we speaking of a phenomenon, a mechanism, or a prospect? Towards autonomous and evolving intelligence, RSI is being claimed at many scales, while no single framework that formally describes these emerging instances exists. Its counterpart in the classical realm, iterative policy improvement, is characterized by generalized policy iteration (GPI), a framework of broad applicability with well-understood theoretical properties, but only where the update principle and the evaluation base lie outside the agent. In this paper, we propose Generalized Agent Iteration (GAI), a formal framework that describes iterative policy improvement and RSI as two cases of a single learning paradigm. GAI defines the agent as a configuration of modifiable components within a system and models the learning process as a cycle of agent evaluation and agent improvement. Two pivotal dials then distinguish the instances: whether the improving mechanism is part of the agent and whether the standard it is measured against is grounded outside it. The former dial delineates the boundary between GPI and RSI, and the latter determines a system's polarity as anchored, goal drift, or fully self-referential. Moreover, we use these coordinates to place existing systems on the same two axes and make the defects of recursive self-improvement statable one condition at a time. We see this paper as a first step toward exploring a formal characterization of RSI that rests on the classical account, makes existing systems comparable, and provides a principled basis for analyzing and designing new ones.

## 2. 方法论：核心思想与关键技术细节

### 2.1 核心思想
将 GPI 的"评估—改进"交替循环推广为一个更一般的循环，其中**被改进的对象不再只是策略与价值，而是"智能体"这一可修改组件的配置**；GPI 与 RSI 的差别被归约为两个可调的"旋钮"（dials）设置。

### 2.2 形式化定义
- **世界与目标**：世界为 MDP `W = (S, A, p, r)`，`G` 为外部目标，二者均属环境，不属于系统本身。系统目标是服务 `G`，其最优配置由式 (1) 给出：`χ* ∈ argmax_χ E[Σ γ^t r(S_t, A_t) | χ]`，该目标由世界与目标固定，不由系统自身决定。
- **系统与智能体（定义 1）**：系统是一个五元组配置 `χ = (π, V, m, U, ρ)`：
  - `π : S → Δ(A)`：选择世界动作的策略；
  - `V : S → R`：动作评论家（评价策略）；
  - `m : X → Δ(X_Ag)`：修改器（提出系统应如何改变）；
  - `U : X → R`：修改评论家（评价某项改动是否服务 `G`）；
  - `ρ`：评估基础（评论家据以衡量的标准）。
  - 智能体是系统中**可修改的部分** `Ag ⊆ O`；智能体实例为 `ξ ∈ X_Ag`；`χ[ξ]` 表示用 `ξ` 替换系统的智能体部分。成员可变化，例如 `Ag = {π, V}`（修改器固定）或 `Ag = {π, V, m, U, ρ}`（连修改器与评估标准都可改写）。
- **GAI 循环（定义 2）**：交替执行两个操作——
  - **智能体评估**：评论家依据评估基础 `ρ` 对智能体部分打分（策略层用 `V`，智能体层用 `U`）；
  - **智能体改进**：修改器产生新的智能体实例 `ξ ~ m(· | χ)`，系统采纳之，`χ ← χ[ξ]`。

### 2.3 两个旋钮（Two Dials）
- **旋钮 1：改进机制是否属于智能体（m ∈ Ag？）**
  - `m ∉ Ag`：`m` 内容固定，充当外部改进机制，即 GPI 所迭代的抽象"评估—改进"算子；
  - `m ∈ Ag`：系统可改写自身修改器，递归在 `m` 处闭合，无外部元层。
- **旋钮 2：衡量改进的标准是否保持"锚定"（ρ 是否有外部内容、是否属于智能体）**
  - 决定系统极性（polarity），见表 2。

### 2.4 两个实例的对照
- **GPI 作为锚定实例**：`Ag = {π, V}`，`m ∉ Ag`，其内容固定为评估算子 `E_m` 与改进算子 `I_m`，更新为 `V ← E_m(V, π; ρ_V)`、`π ← I_m(V)`；修改评论家 `U` 存在但不被使用；`ρ_V` 锚定于世界奖励 `r`。当 `E_m` 为策略评估、`I_m` 为贪心时，即策略/价值迭代，在有限 MDP 下收敛到 `π*`。
- **RSI 作为自修改实例**：`m ∈ Ag`（典型 `Ag = {π, V, m, U}`），更新为
  - 策略层：`V ← E_m(V, π; ρ_V)`，`π ← I_m(V)`（下标 `m` 表明这些算子由当前修改器决定，而非外部固定）；
  - 智能体层：`ξ ~ m(· | χ)`，`χ ← χ[ξ]`，`m' ← (ξ)m`，`U' ← (ξ)U`——下一个修改器与评论家由当前修改器产生，递归在 `m` 处闭合。
- **自我改进者的参考理想（式 4）**：若 `m` 确实朝其基础改进，则 `(m, U)` 需满足一对**自洽条件**：
  - 智能体评估：`U(χ) = E_{ξ~m(·|χ)}[ρ_U(χ, ξ) + γ U(χ[ξ])]`；
  - 智能体改进：`supp m(·|χ) ⊆ argmax_ξ [ρ_U(χ, ξ) + γ U(χ[ξ])]`。
  - 关键限定：这是**刻画性条件而非被强制执行的更新**，没有任何外部机制保证其成立；"改进"是 `m` 内容的性质，不是框架的性质。

### 2.5 极性的三种状态（表 2）
| 极性 | ρ 的状态 | 后果 | 代表系统 |
|---|---|---|---|
| **Anchored（锚定）** | 有外部内容且 `ρ ∉ Ag`，智能体不能改写 | 朝固定外部标准改进 | Gödel machine；STOP |
| **Goal Drift（目标漂移）** | 有外部内容但 `ρ ∈ Ag`，可被改写 | 衡量进步的标准本身可被改写，改进可能偏离外部目标 | Red Queen Gödel Machine |
| **Fully Self-Referential（完全自指）** | 无外部内容（空，或 `ρ` 依赖 `U`） | 无外部信号进入循环，评论家方程退化为内部自洽 | Socratic learning（立场论文） |

- **Remark 2（学习到的代理）**：外部评判器或奖励模型无论训练数据如何都算"锚定"——旋钮问的是标准**位于何处**，而非它多忠实于目标；同一个评判器若成为智能体组件，则属 Goal Drift。
- **Remark 1（自设任务）**：智能体自提任务/问题/目标被视为自我改进的一种形式，因为这些自设任务仍从属于不可被智能体编辑的外部客观目标。
- **回归 GPI**：固定修改器为外部过程、移除修改评论家及其基础 `ρ_U`，即恢复策略与价值上的经典循环。

## 6. 主要结论与发现

- **统一性结论**：GPI 与 RSI 是**同一交替循环的两种旋钮设置**；二者差别仅在于（i）改进机制是否位于智能体内，（ii）衡量改进的标准是否保持锚定。
- **极性三分**：`m ∈ Ag` 时，系统极性由 `ρ` 决定——**Anchored / Goal Drift / Fully Self-Referential**；实践中已展示的自改进系统绝大多数落在 Anchored。
- **四个缺陷（表 4）**，每个对应一项被违反的 GPI 条件：
  1. **候选自我的搜索（Search over candidate selves）**：触发于 Dial 1（`m ∈ Ag`），违反"改进廉价且单调"；状态为结构性且已被观测（RSIBench-Data 的非单调结果）。
  2. **自评估（Self-evaluation）**：触发于 Dial 1（`U ∈ Ag`），违反"评估者外在于被评估对象"；结构性。
  3. **未锚定的基础（Ungrounded base）**：触发于 Dial 2（`ρ_U` 未锚定），违反"目标由智能体之外评估"；自洽条件只约束 `(m, U)` 对，不指涉 `G`，既不唯一确定系统、也不提供忠实性保证——与 Ring & Orseau (2011) 的 "delusion box" 形成早期形式对应。
  4. **目标漂移（Goal Drift）**：触发于 Dial 2（`ρ_U ∈ Ag`），`G` 名义不变但度量标准可被改写；结构性且已被观测（Red Queen Gödel Machine）；Everitt et al. (2016) 表明只有当价值函数能预见改写并以当前效用评估未来时才无害，Hibbard (2012) 对基于模型的效用给出保证——**标准的固定性是需要被"争取"的，而非默认**。
- **对"RSI 就是配置空间上的 MDP"这一反驳的回应**：MDP 的转移律与奖励在智能体之外固定，而 GAI 中下一个配置由**智能体内部的修改器**抽取，评估标准也可能在内部，因此不等同。

- **无实证验证**：全文没有实验、没有量化评测、没有可复现的基准；框架的"有效性"仅由概念一致性与文献归类支撑。作者自己承认，缺陷多为"表述的性质"，凡现有系统体现某缺陷者只是引用而非测量。
- **无可达性与复杂度主张**：配置空间是参考性理想化——"写出智能体实例由修改器抽取"说明的是**被选择什么**，而非该选择是否可达、是否可负担。论文没有关于

任何关于**修改器搜索复杂度、样本效率、收敛速率或停止条件**的分析——经典 GPI 在有限 MDP 下的收敛性保证在 GAI 中没有对应物，自洽条件式 (4) 的存在性、唯一性与解集规模也未被讨论。因此框架能说明"配置由谁抽取"，却无法回答"抽取是否可行、代价几何、何时应当停止"。
- **旋钮被二值化，而真实系统是连续的**：`m ∈ Ag?` 与 `ρ` 是否锚定被处理为非此即彼的判定，但实际系统的"可修改程度"往往是一个谱——例如修改器只能在受限参数空间内被微调，与完全自由重写并非同一件事；评估标准可能部分锚定、部分可改写。二值化使分类清晰，却也损失了对"部分锚定""受限自改"这类中间形态的刻画能力。
- **系统边界 O / Ag 的划定依赖研究者判断**：判断某组件是否"属于智能体"需要先界定系统的外延，而"什么是系统、什么是环境"本身是一个建模选择。同一架构在不同建模下可能被归入不同极性，这削弱了分类轴的可复核性——论文虽以表 4 的 structural / observed 标注部分缓解，但未给出判定边界的独立程序。
- **缺陷目录自承不完整**：论文明确说该目录"按设计很短"，只记录经典保证在何处终止。这意味着多智能体交互、外部世界分布变化下的漂移、目标 G 本身不完整或需人类解释的情形，以及"自改带来的安全/对齐风险"等维度，均未纳入体系。
- **对 G 的强假设**：`G` 被假定为固定、外部、可形式化的目标。论文未讨论 G 不可完全形式化、需要在运行中由人类澄清、或 G 之间存在冲突时框架如何运作；而恰恰在这些情形下，"锚定"这一概念本身会变得难以操作。
- **与相邻形式化传统的对话不足**：框架未与开放式演化（open-endedness）、元学习理论、AIXI 谱系或安全可证明的自改（provably safe self-modification）等既有形式化传统做严格对照，因此"GAI 是分析 RSI 的原则性基础"这一主张的边界尚未被外部标准检验。
- **经验支撑不对称**：如第 5 节所述，已展示的自改进系统绝大多数落在 Anchored 行，Goal Drift 与 Fully Self-Referential 两行主要由边界案例与立场论文代表，分类轴在经验上是"头重脚轻"的。

## 9. 开放问题与未来方向

论文将自身定位为"探索 RSI 形式化刻画的第一步"，并明确列出若干从"缺陷目录"走向"定理"的靶点：

- **自洽条件的解集刻画**：式 (4) 只说明一个自我改进者若朝其基础改进需满足什么，但没有刻画满足该条件的 `(m, U)` 对有多少、结构如何、是否唯一。这是把"参考理想"变为"可分析对象"的前提。
- **RSI 到 GPI 的命题化归约**：论文主张 GPI 与 RSI 是同一循环的两种旋钮设置，但这一统一目前是**概念层面**的。能否给出严格的归约命题（在什么条件下 RSI 系统可被表示为某个 GPI 实例，反之亦然），是统一性主张能否成立的关键。
- **系统内部能否判定自身忠实性**：即一个自指系统能否在内部判定自己的修改器是否仍然忠实于外部目标 G。这直接关系到 Goal Drift 是否可被系统自身检测与阻止，也触及 Gödel 式自指限制的边界。
- **可达性与复杂度理论**：为配置空间上的搜索建立可达性、代价与收敛的理论，使 GAI 从参考性理想化走向可分析模型。
- **经验验证与基准**：需要能区分 Anchored / Goal Drift / Fully Self-Referential 三种极性的可复现基准，以补足当前分类依赖文献解读的短板；Meng et al. (2026) 的非单调结果是一个起点，但远非系统性证据。

## 10. 总体评价

- **贡献定位**：这是一篇**概念整合型立场论文**，其价值不在新算法或新实验，而在于提供了一个可操作的判据（两个旋钮）与一张统一坐标系（三种极性 + 四个缺陷），把此前散落于 Gödel machine 谱系、语言智能体自精炼、代码自修改、科研循环与共演化评估器中的现象纳入同一讨论框架。它回应的是"缺少判据"这一真实缺口，而非再添一个案例。
- **最扎实的部分**：形式化定义（定义 1、定义 2）的简洁性、两个旋钮的清晰可核对性，以及把风险组织为"违反了哪条经典 GPI 条件"的做法——后者把笼统的"失控"叙事拆解为可单独陈述、可单独讨论的条件违背，并以 structural / observed 标注保持了克制。
- **最薄弱的部分**：无实证、无可达性与复杂度主张、旋钮二值化、系统边界依赖建模判断，以及与相邻形式化传统对话不足。这些使框架目前更像一个**组织性词汇表 + 待证纲领**，而非一个已闭合的理论。
- **适用建议**：适合作为设计新自改系统时的**检查清单**（先问 m 是否在 Ag 内、ρ 是否锚定、是否触发四类缺陷），以及作为后续形式化工作的**问题清单**（三个开放问题）。但不宜将其极性分类当作可独立复核的客观判据，也不宜将其缺陷目录当作 RSI 风险的完整枚举——论文自己对此有明确保留。
- **一句话概括**：GAI 把"智能体如何改进自己"还原为"评估—改进循环中的两个旋钮"，用三值极性与四条条件违背给出了 RSI 的第一张统一坐标图；它成功地让不同系统变得可比较，但仍需可达性理论、忠实性判定与经验基准来把这张图从"目录"变成"定理"。
