## 摘要
递归自我改进（RSI）需要一种具体机制，使 AI 系统能够观察自身能力，并将这些证据转化为下一轮学习。我们提出 NeoHorse-1，一系列智能体原生模型，旨在通过智能体后训练探索这一路径。我们的系统将异构模型池与智能路由相结合，记录每个用户轮次的预测能力需求、所选服务层级以及后续交互。这些记录被转换为训练样本，保留交错的推理、工具调用和 Harness 上下文，并通过结构验证、六维语义评估和子场景级标注进行筛选。路由信号将有监督微调组织为三阶段课程，并扩展到路由引导的同策略蒸馏，其中教师在同一进度下监督学生生成的响应。能力引导的分配随后将评估反馈转化为下一轮训练混合数据，从而闭合“评估—选择—更新”循环：系统学会做什么，反过来塑造它下一步从什么中学习。在涵盖基于 Harness 的智能体、工具使用、编码和指令遵循的十一个基准上，后训练将 4B 的宏平均从 58.94 提升至 64.87，将 9B 的从 65.60 提升至 69.04，显著缩小了后训练 4B 模型与 9B 基础模型之间的总体差距。NeoHorse-1 为这一反馈驱动过程提供了初步原型，并为通过连续迭代实现 Harness 介导的 RSI 提供了路径。

## Abstract
Recursive self-improvement (RSI) requires a concrete mechanism through which an AI system observes its capabilities and converts that evidence into the next round of learning. We present NeoHorse-1, a family of agent-native models developed to explore this path through agentic post-training. Our system combines a heterogeneous model pool with intelligent routing, recording the predicted capability demand, selected service tier, and subsequent interaction for each user turn. These records are converted into training examples that preserve interleaved reasoning, tool calls, and harness context, and are admitted through structural validation, six-dimensional semantic evaluation, and subscene-level labeling. Routing signals organize supervised fine-tuning into a three-stage curriculum and extend to routing-guided on-policy distillation, where a teacher supervises student-generated responses under the same progression. Capability-guided allocation then converts evaluation feedback into the next training mixture, closing an evaluation-selection-update loop in which what the system learns to do shapes what it learns from next. Across eleven benchmarks covering harness-based agents, tool use, coding, and instruction following, post-training raises the macro-average from 58.94 to 64.87 at 4B and from 65.60 to 69.04 at 9B, substantially narrowing the aggregate gap between the post-trained 4B model and the 9B base model. NeoHorse-1 provides an initial prototype of this feedback-driven process and a path toward harness-mediated RSI across successive iterations.

## 1. 核心问题与研究动机

- **递归自我改进（RSI）的落地缺口**：RSI 的吸引力是结构性的——一旦模型改进本身被部分自动化，每一代都能为下一代做贡献，训练不再受限于人工标注数据。但实现该愿景需要**一个具体机制**，让 AI 系统能观察自身能力，并把这种证据转化为下一轮学习信号。
- **论文的核心主张**：一个**已部署的路由 Harness（routing harness）本身就包含这种机制**。除了任务输出，智能体交互还会留下执行轨迹，以及关于"模型能做什么、还不能做什么"的可观测证据。
- **三个可复用信号**：Harness 除服务用户请求外，还产出
  - 执行轨迹（把训练锚定在真实交互上）；
  - 路由信号（刻画能力需求）；
  - 记录下来的结果（揭示模型仍在何处不足）。
- **现有工作的局限**：轨迹 SFT 主要模仿固定教师策略；智能体 RL 依赖可执行环境奖励；课程学习通常依赖显式难度标签或数据集特定启发式，成本高且不实用。路由系统的请求/上下文条件预测恰好提供了替代性难度信号。
- **整体含义**：NeoHorse-1 是"Harness 介导的 RSI"的**初步原型**，目标是让"系统学会做什么"反过来塑造"它下一步从什么中学习"，形成评估—选择—更新闭环。

## 2. 方法论

### 2.1 核心思想

- 将异构模型池 + 多 Harness（含 OpenSquilla）组成的路由系统作为**数据飞轮**：每轮记录"预测能力需求—实际服务层级—后续交互"，把记录转为训练样本，再把评估反馈转为下一轮数据配比。
- 训练侧三件套：**智能体监督（user-turn SFT）→ 路由引导课程 → 路由引导在线策略蒸馏（OPD）**，外加**能力引导数据分配**闭合循环。

### 2.2 数据侧：三层粒度与质量门控

- **三种粒度**：
  - *Trajectory*：Harness 执行的完整交互（用户请求、模型响应、工具调用、环境观测、恢复尝试、终止结果）。
  - *User turn*：从一次用户请求到下一次用户请求/任务终止，是**基本序列化训练单元**。
  - *Subscene*：共享局部目标的相邻 user turn 组，是**语义刻画单元**。
- **序列化与上下文策略**：采用 Qwen3.5 chat template 与工具调用格式；**保留当前轮推理，省略历史轮推理**；历史可见响应、工具调用、工具结果、系统指令与 Harness 上下文均保留但**不计算预测损失**；因果注意力保证只看更早内容。
- **数据质量三关**：
  1. **去重与去污染**：精确/近重复去重，并用同一匹配设施把训练候选与评测集比对，保证训练—评测不相交。
  2. **结构验证（规则化）**：重建请求/响应/工具调用/观测/终止事件，检查载荷可读性、消息结构、请求响应存在性、因果顺序、工具调用—结果配对闭合性；产出三类结果——*internally complete*（直接进入语义评估）、*partially recoverable*（只贡献因果闭合的子轨迹）、*quarantined*（隔离）。
  3. **六维语义评估**：目标达成、指令遵循、工具使用、证据一致性、错误恢复、终止；每维标注 PASS / WARN / FAIL / NOT_EVALUATED，并单独保存覆盖率；缺失证据或评审中断**绝不转为正面判定**；长轨迹分段评估后按轮聚合。
- **场景刻画（子场景级）**：三轴属性体系
  - *Scene*：任务类型、应用域（软件/金融/工作/学业/个人等）、使用上下文、asking/doing；
  - *Goal*：验收标准（正确性、完整性、格式合规）、跨轮关系（新/延续/修改/恢复/歧义）；
  - *Outcome*：可验证结果（产物产出、状态改变、证据可得、真/假）。
  - 每个属性保留推导方法与置信度，结构事实不可被语义评审覆盖。
- **路由信号（预测—行动—结果分离）**：路由在 user-turn 级估计能力需求，分四个服务层级 **C0（有界低风险）→ C1（通用默认）→ C2（多步推理与执行）→ C3（最大能力/可靠性）**；语料同时保留**原始预测、策略调整后决策、实际服务层级**三者，使预测需求、策略约束与执行动作可独立分析；tier 语义版本化以适应服务栈演进。
- **能力引导数据分配**：在每轮迭代，用与训练去污染的**分层评测集**评估当前 checkpoint，按属性、质量维度、结果状态、路由层级聚合为**模型缺陷画像**，把下一轮训练混合数据向表现不足区域倾斜，同时保留广覆盖；成功轨迹提供正监督，有信息量的失败指出需补强区域。新老数据一起重分配，更新后的 checkpoint 回到 Harness 又暴露下一批能力缺口。

### 2.3 训练侧

- **智能体监督（SFT）**：以 user turn 为样本，监督当前轮保留的助手目标 span（推理、序列化工具调用及参数、可见响应、结束 token），其余 token（系统指令、工具规格、用户消息、工具结果、padding、历史）掩码为 0。损失为掩码 token 级交叉熵，**按批次内受监督 token 数归一化**，而非按总序列长度或轮数：
  - `L_SFT = − Σ_i Σ_t m_{i,t} log p_θ(x_{i,t} | x_{i,<t}) / Σ_i Σ_t m_{i,t}`
- **路由引导课程学习**：不用"实际服务的模型身份"作难度标签（会受用户覆盖、服务可用性、部署策略干扰），而是**从首个受监督助手响应之前可得的请求与交互历史重新估计能力需求**，赋给整个样本作为轮级排序代理。
  - 排序分数：硬排序 `s_i = k_i`（分配层级索引）；软排序 `s_i = Σ_{k=0}^{3} k·π_{i,k}`（层级得分加权均值），软排序可区分同层样本。
  - **三阶段调度**：每阶段约占 1/3 样本，逐步引入高分样本，**保留部分低分样本到后期阶段**，防止训练末段被高需求交互主导；每个样本每 pass 只用一次；全程沿用同一掩码 SFT 目标，**阶段间不重置优化器、不重启学习率调度**。
- **路由引导在线策略蒸馏（R-OPD）**：解决 SFT 学的是"记录下来的助手响应"而部署时学生基于**自己生成的前缀**的条件分布错配问题。
  - 用记录中紧邻助手响应之前的上下文作为生成起点，按同一公式打分，施加同样的三阶段分配 `ρ_j`（j ∈ {1,2,3}）。
  - 阶段 j 中，学生 checkpoint `p_θ̄` 对批次 C 中每个上下文生成一条响应 R（可能含推理、工具调用或可见文本）；固定教师在每个位置给出下一 token 分布；两模型用各自原生模板渲染相同消息与工具，并对齐响应 token ID；**随训练刷新 rollout checkpoint**，使后期上下文接受更新近学生行为的教师监督；收集响应期间 rollout 参数固定。
  - 损失为**响应归一化的反向 KL**：每位置仅保留 rollout 学生的 top-K 候选 token 并把剩余概率聚成一个 bin（共 K+1 个桶），两模型使用相同候选集与全词表概率得到粗化分布 `P̃`、`Q̃`：
    - `L_OPD(θ; R) = (1/Σ_r w_r) Σ_r w_r · (1/L_r) Σ_t D_KL(P̃_{θ,r,t} ‖ Q̃_{r,t})`，默认 `w_r = 1`。
    - 梯度只穿过当前学生在已收集前缀上的概率，生成 token、候选 ID、教师分数保持固定；prompt 与 padding 无损失。
  - 阶段化目标：`L_R-OPD^(j)(θ) = E_{C∼ρ_j, R∼p_θ̄(·|C)} [L_OPD(θ; R)]`。
