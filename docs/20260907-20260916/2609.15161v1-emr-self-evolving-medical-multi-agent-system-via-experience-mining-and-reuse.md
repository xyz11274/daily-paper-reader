## Abstract
Large language model (LLM) driven multi-agent systems have shown promise in complex clinical reasoning, yet existing approaches rely on static strategies and lack persistent clinical memory, preventing self-evolving from prior diagnostic successes and failures. We present EMR, a self-evolving medical multi-agent system via Experience Mining and Reuse. EMR introduces a hierarchical clinical experience library that organizes accumulated knowledge into three levels: clinical principles, diagnostic patterns, and representative cases. During inference, EMR emulates multidisciplinary consultation: a planner agent coordinates domain-specific department agents for specialized reasoning, while a summary agent synthesizes their analyses into a final decision. Critically, EMR automatically extracts correct diagnostic insights and failure-related warnings from multi-agent reasoning trajectories, incrementally updating the experience library to guide future cases. # EMR：基于经验挖掘与复用的自演化医疗多智能体系统 —— 论文总结

## 1. 核心问题与研究背景

- **背景**：LLM 驱动的多智能体系统在复杂临床推理（多症状表现、鉴别诊断、跨科室会诊）中已显示出潜力，代表性工作包括 MedAgents、MDAgents、ReConcile、AI Hospital、ColaCare 等。
- **两大核心缺陷**：
  1. **策略静态**：多数系统依赖固定的推理策略与角色分配，面对复杂或未见过的临床病例时反复出现同类诊断错误。
  2. **任务孤立（无状态）**：每个任务被当作独立实例处理，既不能从既往成功经验中学习，也无法避免已犯过的诊断错误，缺乏持久化的临床记忆。
- **核心主张**：缺失的关键是**显式且持久的经验抽象**。多智能体系统应从自身的推理轨迹中抽取可复用知识，以可迁移、可扩展、与模型无关的形式存储，并且同时涵盖成功策略与系统性失败模式。
- **整体含义**：在不修改模型参数的前提下，通过“经验挖掘—复用”闭环实现医疗多智能体的持续自演化，为可扩展、可解释的临床推理提供路径。

## 2. 方法论

### 2.1 核心思想
模拟多学科会诊流程：规划智能体 → 多科室智能体 → 汇总智能体；同时把整条协作轨迹蒸馏为分层经验，增量更新经验库，并在后续推理中检索复用。

### 2.2 多智能体医疗系统
- **规划智能体（Planner）**：在问题级与选项级两个粒度识别医学专科领域，得到问题级领域集合 \(D_q\) 与选项级领域集合 \(D_o\)；同时参考检索到的历史经验，用于改进领域分配、规避既往错误。形式化：\(D_q=\mathrm{LLM}(q,E_r|r_p,\pi_q)\)，\(D_o=\mathrm{LLM}(q,O,E_r|r_p,\pi_o)\)。
- **科室智能体（Department Agents）**：对每个领域 \(d\in D_q\cup D_o\)，以领域专家角色结合问题、选项与检索经验生成专门分析：\(a_d=\mathrm{LLM}(q,O,d,E_r|r_d,\pi_d)\)，所有分析汇总为 \(A\)。
- **汇总智能体（Summary Agent）**：不仅做简单聚合，而是结合各科室分析与检索经验进行反思式推理，解决观点冲突、纠正局部错误，输出最终答案与综合分析：\(\hat{y},a_{sum}=\mathrm{LLM}(q,O,A,E_r|r_s,\pi_s)\)。

### 2.3 经验挖掘
- **轨迹生成**：为每个样本记录结构化轨迹 \(\tau=(q,O,D_q,D_o,A,a_{sum},\hat{y})\)，并与标准答案 \(y\) 比较，判定成功/失败，作为监督信号。
- **经验收集与分类**（collector 角色 + 挖掘提示）：
  - **Golden Experience**：来自成功轨迹，编码有效推理策略、诊断原则与经验证的决策模式。
  - **Warning Experience**：来自失败轨迹，总结失败原因、误导性线索与反复出现的错误模式。
  - 形式化：\(\epsilon=\mathrm{Collect}(\tau,y|r_c,\pi_c)\)。
- 每类经验按三个抽象层级输出（principle / pattern / case），并有字数约束（原则与模式 30–50 词，案例 40–60 词）。

### 2.4 经验复用
- **分层经验库**：\(L=\{L_{principle},L_{pattern},L_{case}\}\)，分别对应高层诊断规则与临床指南、可复用推理结构与决策模板、具体情境化临床案例，兼顾抽象性与细节。
- **更新机制（三步）**：
  1. 检索潜在相关经验 \(R=\mathrm{Retrieve}(L_t,\epsilon)\)；
  2. 用嵌入向量计算余弦相似度 \(\mathrm{Sim}(\epsilon,R)=\max_{\epsilon_i\in R}\frac{e(\epsilon)\cdot e(\epsilon_i)}{\|e(\epsilon)\|\|e(\epsilon_i)\|}\)；
  3. 按阈值更新：若 \(\mathrm{Sim}(\epsilon,R)<\theta\) 则直接加入新经验；否则交由 LLM 判断合并为更紧凑表示或丢弃（无推理价值的冗余条目）。
- **检索机制**：给定查询上下文 \(c\)，\(E_r=\mathrm{Retrieve}(L,c,k)\)，按“先原则 → 再模式 → 后案例”的层次化顺序检索，并将结果注入规划、科室与汇总三类智能体，**全程不更新模型参数**，使经验库成为模型无关的外部知识源。

## 6. 主要结论与发现

- **性能一致领先**：Qwen3-8B 上平均准确率由 MDAgents 的 77.8 提升至 **81.1**；GPT-4o 上达到 **93.9**（相对 MDAgents 平均 +3.3% / +2.0% / +1.5%，不同设置下）。MedQA 达 96.8（较 EvolveR +4.1），MedMCQA 89.2（+0.6），在 USMLE 风格复杂题上增益更大。
- **经验是最大增益来源**：移除经验模块性能下降 6.7%，退化到静态系统水平；说明仅有协作结构不足，必须配合经验积累。
- **层级贡献不均**：principle 层最关键（去除后下降 4.6%），pattern 层次之（2.5%），case 层最小（1.2%），三层互补。
- **Golden + Warning 互补**：仅用 golden 经验下降 2.6%，说明失败警示起到“护栏”作用。
- **经验可迁移**：强模型（GPT-4o、DeepSeek-V3）挖掘的经验可提升弱模型（Qwen3-8B），且迁移是**双向的**；跨数据集迁移也持续有效，说明经验库捕捉的是通用医学推理知识而非数据集特定启发式。
- **效率与架构无关性**：token 与延迟均低于主流多智能体基线；将经验机制接入 MDAgents / ReConcile 也能带来 2.4–2.7 个点提升。
- **鲁棒性**：即使仅保留 10%–20% 经验库或注入 20%–40% 噪声，仍显著优于无经验系统。
- **可解释性**：挖掘出的经验以自然语言呈现，人类可读，可归纳出四类反复失败模式：过度依赖参数化知识、医学概念混淆、表面因果推理、多智能体集体幻觉。

## 7. 优点

- **问题定位准确**：明确指出医疗多智能体“静态策略 + 无持久记忆”的痛点，并用显式经验抽象给出机制性解法。

## 8. 不足与局限

- **模态与场景受限**：仅针对文本医学选择题，未纳入医学影像、实验室信号、电子病历等多模态信息；全部为离线基准评测，未在真实临床环境中验证，输出不应视为临床建议。
