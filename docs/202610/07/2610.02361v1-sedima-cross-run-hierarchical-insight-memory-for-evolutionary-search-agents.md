## 摘要
由大语言模型（LLM）驱动的进化搜索是一种用于自动程序与算法发现的有力范式，然而现有系统大多没有记忆：每次运行都从头探索，因此智能体会反复重新发现相同的改进，并再次遇到相同的死胡同。我们提出 SEDIMA，一种面向进化搜索智能体的持久分层洞察记忆。SEDIMA 将原始轨迹提炼为自然语言洞察，使用注意力加权质心按语义相似度对其进行聚类，并检索相关指导以调节未来的变异，从而在多次运行和多个问题之间积累可迁移知识，而非局限于单条轨迹内。作为一个即插即用模块，SEDIMA 不修改搜索算子，在评估 100 个候选的固定预算下，将 AlgoTune 上的平均最终性能提升 5.5%，在 ALE-Bench LITE 上提升 6.6%。在 OpenEvolve 下，SEDIMA 在五个被评估的骨干模型上平均需要少 32.3% 的迭代次数即可达到基线最佳性能。

## Abstract
Large language model (LLM)-driven evolutionary search is a powerful paradigm for automated program and algorithm discovery, yet existing systems are largely memoryless: each run explores from scratch, so agents repeatedly rediscover the same improvements and re-encounter the same dead ends. We introduce SEDIMA, a persistent hierarchical insight memory for evolutionary search agents. SEDIMA distills raw traces into natural-language insights, clusters them by semantic similarity using attention-weighted centroids, and retrieves relevant guidance to condition future mutations, accumulating transferable knowledge across runs and problems rather than within a single trajectory. As a drop-in module that leaves the search operators unmodified, SEDIMA improves average final performance by 5.5% on AlgoTune and 6.6% on ALE-Bench LITE under a fixed budget of 100 evaluated candidates. Under OpenEvolve, SEDIMA requires 32.3% fewer iterations on average to reach baseline-best performance across the five evaluated backbones.

## 1. 核心问题与整体含义

- **研究背景**：LLM 驱动的进化搜索已成为自动程序与算法发现的重要范式。系统通过反复选择候选、用 LLM 提出语义化修改、评估结果并保留最优变体来迭代优化（如 AlphaEvolve、OpenEvolve、ShinkaEvolve、LLM4AD 等）。
- **核心问题**：现有系统**基本无记忆（memoryless）**——每次运行都从零开始，运行结束后丢弃产生成功与失败的推理过程。这导致两类浪费：
  - **跨运行浪费**：面对新任务时，智能体重新推导已发现的修改、重新探索已知无效的方向。
  - **运行内不稳定**：单次轨迹中解质量剧烈波动，缺乏持久信号来巩固有效经验。
- **整体含义**：作者提出 SEDIMA，将记忆从"单条轨迹内"扩展到"跨运行、跨问题"，实现可迁移知识的持续积累，且不修改底层搜索算子，作为即插即用模块使用。

## 2. 方法论

### 核心思想
- 通过**两个接口**与进化搜索耦合：评估后**写入（write）**、变异前**读取（read）**，完全不动选择、种群管理、变异算子。
- 构建**持久的三层记忆层级**，将原始经验蒸馏为可复用洞察，并按语义检索注入变异提示。

### 三层记忆结构
- **Level 1 原始轨迹（Raw Traces）**：每次评估后存储步索引、父/子适应度、适应度差、事件来源、原始评估报告。不做解释，作为高层记忆的证据来源。
- **Level 2 蒸馏洞察（Distilled Insights）**：LLM 将轨迹转为紧凑自然语言洞察，并链接回 Level 1 证据。
  - 初始评估生成**问题级洞察**（描述主要算法/架构瓶颈）。
  - 后续父子评估生成**变更级洞察**（描述修改类型及性能影响）。
  - 抽象掉实现细节，保留可复用教训（缓存、剪枝、向量化、数据结构变更、减少冗余计算等）。
- **Level 3 语义聚类（Semantic Clusters）**：按嵌入相似度分组，新洞察若与最近簇的余弦相似度超过阈值则加入，否则新建簇。簇代表用**注意力加权质心**刷新。

### 关键技术细节与公式
- **簇分配**：最近簇 $k^* = \arg\max_k \cos(e_i, c_k)$，当 $\cos(e_i, c_{k^*}) \geq \tau_{cluster}$ 时加入，否则新建簇。
- **语义中心性**：$s_i = \frac{1}{n-1}\sum_{j\neq i}\cos(e_i, e_j)$。
- **非参数注意力权重**：$w_i = \frac{\exp(s_i/\tau)}{\sum_j \exp(s_j/\tau)}$。
- **簇代表**：$c = \sum_i w_i e_i$。$\tau \to \infty$ 时退化为均值池化；$\tau$ 越小越强调原型性洞察。
- **分层检索**：查询嵌入 $e_q$，簇排序 $r^{cluster}_k = \cos(e_q, c_k)$，保留超过 $\tau_{ret}$ 的 top-$K_c$ 簇；簇内按 $r^{insight}_i = \cos(e_q, e_i)$ 选 top-$K_i$ 洞察。簇相似度与洞察相似度**分别保留**，不合并为单一分数。
- **证据与推荐合成**：每条检索洞察可附最多 2 条 Level 1 轨迹，LLM 综合生成 **3 条可执行建议**注入 diff 或全重写提示。
- **预算与回退**：检索受固定簇数、洞察数、提示长度限制，上下文成本不随记忆增长；若无簇过阈值，回退到原始变异提示。

### 超参数
- 簇阈值 $\tau_{cluster}=0.8$，检索阈值 $\tau_{ret}=0.6$，质心温度 $\tau=0.1$，$K_c=3$，$K_i=3$，检索证据上限 2500 tokens，簇摘要最多 10 条成员洞察。

## 3. 实验设计

### 数据集 / Benchmark

### 评估协议

- 每次运行最多 **100 个进化步**，每步生成并评估 1 个子代。

- 记忆用**不相交问题集**构建，确保评估问题不贡献于解决自身的记忆。

## 6. 主要结论与发现

- **性能提升**：固定 100 候选预算下，AlgoTune 平均最终性能提升 **5.5%**，ALE-Bench LITE 提升 **6.6%**；20 组匹配对比全部 favor SEDIMA。
- **弱模型受益更大**：Qwen 3 Coder 在 ALE-Bench 上提升 11.0%（OpenEvolve）/ 9.0%（ShinkaEvolve），说明持久指导对较弱搜索尤其有价值。
- **收敛更快**：OpenEvolve 下平均少 **32.3%** 迭代达到基线最佳性能（如 GPT-5.4 从 78 步降至 55 步，减少 29.5%）。
- **跨问题迁移有效**：同 benchmark 记忆提升 4.8%/6.7%，跨 benchmark 记忆仍提升 1.8%/2.9%，证明语义检索可跨问题族迁移。
- **随机检索几乎无效**：随机检索仅略高于无记忆，说明增益来自**相关经验检索**而非单纯增加提示文本。
- **短格式收益更大**：ALE-Bench 短格式提升 8.1%/6.9%，长格式 6.2%/5.1%，说明重复优化模式更易迁移。

## 7. 优点

- **即插即用设计**：仅两个接口（评估后写、变异前读），不改搜索算子，可无缝集成到多个 harness，工程价值高。
- **分层记忆架构清晰**：原始轨迹→蒸馏洞察→语义聚类三层，兼顾证据可追溯性与抽象可迁移性。
- **注意力加权质心**：非参数机制让原型性、高价值洞察主导检索，优于简单均值池化（消融验证）。
- **语义检索而非谱系检索**：突破单轨迹限制，实现跨问题、跨 benchmark 迁移。
- **上下文成本可控**：固定簇数、洞察数、token 预算，提示长度不随记忆增长。
- **实验设计严谨**：记忆隔离防泄漏、同模型约束、跨 harness 验证、多种消融与嵌入鲁棒性测试。
- **定性案例完整**：清晰展示 write–retrieve–apply 全流程及具体代码修改。

## 8. 不足与局限

- **依赖 LLM 洞察质量**：错误摘要、弱语义匹配或噪声评估报告可能存储并复用误导性指导。
- **超参数固定**：聚类与检索超参数固定，未探索自适应机制。
- **记忆无界增长**：当前存储无合并或遗忘机制，大规模下可能降低效率与相关性。
- **计算成本未匹配**：SEDIMA 增加蒸馏、嵌入、推荐合成调用，迭代减少不等于总计算量减少；未报告 GPU/成本细节。
- **主结果单次运行**：主表每模型–harness 对仅一次运行，方差未知。
- **缺乏直接基线对比**：未与 ReEvo、LoongFlow、DeltaEvolve、CORAL、PRISM 等记忆型系统直接比较，无法断言优越性。
- **伦理风险**：继承底层 LLM 的偏见与幻觉，持久记忆可能**放大**错误洞察到后续变异或运行；额外调用增加计算与环境成本。
