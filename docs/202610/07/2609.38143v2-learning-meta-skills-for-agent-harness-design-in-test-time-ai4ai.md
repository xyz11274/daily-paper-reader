## 摘要
智能体的性能既取决于其推理能力，也取决于其行动所处的环境。我们研究测试时AI-for-AI，探讨在目标模型与构建者模型权重均固定的情况下，构建者如何学习为目标模型构造更优的执行环境。为使构建者的经验可复用，我们引入元技能：规定何时需要支持以及提供何种资源的原则。构建者从目标模型在开发集上的执行反馈中学习这些原则，随后利用冻结的技能库为未见任务构造执行环境。在Harness-Bench和NewtonBench上，完整技能库的元技能相比无技能构造将宏平均性能提升了8.95个百分点，相比将同一技能库直接交付给目标模型提升了12.02个百分点。这些结果凸显了将经验转化为可执行支持的价值。同一模型同时承担两种角色时性能的提升，进一步表明了一条通过学习构建更优环境来实现系统级自我改进的路径。

## Abstract
Agent performance depends on both reasoning ability and the environment in which it acts. We study test-time AI-for-AI, asking how a Builder can learn to construct better execution environments for a Target while both models' weights remain fixed. To make the Builder's experience reusable, we introduce Meta-Skill: principles specifying when support is needed and what resources to provide. The Builder learns these principles from Target's execution feedback on the development set, then uses the frozen skill bank to construct harnesses for unseen tasks. Across Harness-Bench and NewtonBench, full-bank meta-skills improve macro-average performance by 8.95 percentage points over no-skill construction, and 12.02 points over direct delivery of the same bank to the Target. These results highlight the value of translating experience into executable support. Gains when the same model serves both roles further suggest a path to system level self-improvement through learning to build better environments.

## 6. 主要结论与发现

- **元技能在教师能"执行"它们时最有用**：完整技能库交给Builder比直接交给Target在全部6个设置中均更优，平均提升12.02个百分点（最高25.43点）。收益来自将声明性知识操作化为持久状态、可执行工具、验证逻辑或控制决策。
- **经验使Builder超越单纯构造能力**：完整技能库Builder在全部6个设置中优于无技能Builder，平均提升8.95个百分点（宏平均65.31%）。
- **协调是主要瓶颈时经验收益最大**：NewtonBench平均提升10.96点，Harness-Bench为6.95点，说明失败模式跨任务稳定复现时经验最有用。
- **完整技能库通常优于稀疏检索**：6个设置中5个更优，NewtonBench平均增益7.19点。
- **精炼非单调**：NewtonBench上第一遍变化小于1.1点，第二遍增加约13点；Harness-Bench上Gemini持续提升但Qwen从第一遍峰值下降4.06点，说明修订可能过度特化于近期证据。
- **支持设计是自我改进的独立目标**：同模型实验中，元技能相比无技能构造平均提升18.71点，相比直接交付Target提升14.14点。
- **元技能支持跨Builder复用但依赖实现**：接收方自学习银行优于导入银行（Harness-Bench +3.69点，NewtonBench +9.93点）；跨Builder+Target迁移仍获正向点估计（+4.58 / +5.48点）。
- **控制器普遍改善harness表现**：移除controller使三个Target分数下降（Gemini -13.36点，置信区间排除零）。
- **元技能帮助闭合执行缺口**：NewtonBench上无有效提交从394降至254（-35.5%），正确发现从439升至535（+21.9%）。
