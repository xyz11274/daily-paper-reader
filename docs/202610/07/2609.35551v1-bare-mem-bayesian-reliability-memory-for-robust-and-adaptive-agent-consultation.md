## 摘要
在多智能体系统中，可靠的咨询具有挑战性，因为顾问的能力因任务而异，且误导性信息可能使咨询效果不如自主推理。我们提出BaRe-Mem，一种用于多智能体咨询的在线贝叶斯可靠性记忆。它基于中心模型的内部信念表示来估计顾问的可靠性，并根据历史交互更新这些估计。这些估计调节顾问响应的影响，并指导在咨询与自主推理之间的选择。在九个基准和六个中心模型上，BaRe-Mem对误导性顾问信息的鲁棒性优于辩论和多数投票。在更具挑战性的任务上，它在所有测试的误导水平下均保持优于自主推理。此外，我们将BaRe-Mem机制扩展到智能体团队中的工作分配。在MuSiQue基准上，BaRe-Mem相比基于历史成功次数的路由提高了任务完成率，并更早地识别出有能力的工人。

## Abstract
In multi-agent systems, reliable consultation is challenging because advisor capabilities vary across tasks, and misleading information can make consultation worse than autonomous reasoning. We introduce BaRe-Mem, an online Bayesian reliability memory for multi-agent consultation. It estimates advisor reliability based on the central model's internal belief representations and updates these estimates from historical interactions. These estimates modulate the influence of advisor responses and guide the choice between consultation and autonomous reasoning. Across nine benchmarks and six central models, BaRe-Mem is more robust to misleading advisor information than debate and majority voting. On the more challenging tasks, it remains above autonomous reasoning across all tested misleading levels. Moreover, we extend the BaRe-Mem mechanism to worker allocation in agent teams. On the MuSiQue benchmark, BaRe-Mem improves task completion over routing by historical success counts and identifies capable workers earlier.

## 1. 核心问题与整体含义

- **研究动机**：在多智能体系统中，单个 LLM 无法覆盖所有复杂任务所需能力，因此系统趋向于由多个智能体组成网络，通过相互咨询来获取外部能力。然而，顾问的能力因任务而异，且可能提供流畅但错误的信息。
- **核心问题**：误导性咨询可能导致模型放弃原本正确的答案，使咨询效果反而**不如自主推理**。此外，多个顾问的一致同意并不保证正确性（可能共同强化同一个错误）。
- **关键挑战**：
  - 如何将历史交互转化为**上下文相关的可靠性估计**，以调节外部信息对当前决策的影响；
  - 可靠性估计需随任务流扩展、对误导信息鲁棒、并能适应顾问可靠性的变化；
  - 由于协作收益随单智能体能力提升可能递减甚至为负，可靠性不仅应决定"如何信任"，还应决定"**是否咨询**"。
- **整体含义**：论文提出 BaRe-Mem，将可靠性记忆建模为在线贝叶斯回归问题，同时估计顾问可靠性与中心模型自身能力，从而实现"**信任谁**"与"**是否咨询**"的双重自适应决策。

## 2. 方法论

### 2.1 核心思想
- 将每个候选答案（K 个顾问响应 + 中心模型自主答案）表示为基于中心模型内部信念的向量，用**贝叶斯线性回归**建模其被验证的正确性，在线更新可靠性后验。
- 可靠性估计有两个用途：(1) 通过**注意力调制**调节各顾问响应的影响；(2) 通过比较咨询能力与自主能力，决定是否咨询。

### 2.2 关键技术细节

- **信念表示**：对问题 $q_t$ 和候选 $k$，中心模型编码得到隐藏表示 $h_{t,k}$，分解为问题信念 $\psi_q(t)$（跨候选共享）与答案内容信念 $\psi_c(t,k)$（候选特有）。候选表示为 $x_{t,k} = [e_k \otimes \psi_q(t); \psi_c(t,k); 1]$，其中 $e_k$ 为来源 one-hot 标识。
- **可靠性得分**：$w^\top x_{t,k}$ 分解为来源可靠性项、答案内容可靠性项和偏置项。
- **贝叶斯记忆**：令 $s_{t,k} = 2y_{t,k}-1$（$y$ 为正确性标签），建模 $s_{t,k} \sim \mathcal{N}(w^\top x_{t,k}, 1)$，先验 $w \sim \mathcal{N}(0, \lambda^{-1}I)$。后验精度 $\Lambda = \lambda I + \sum xx^\top$，均值 $m = \Lambda^{-1}b$。
- **在线更新**：通过 **Kalman 增益** $g_{t,k}$ 进行秩一更新，无需重算整个后验，且更新顺序无关（附录证明）。
- **可靠性估计**：$p_{t,k} = \Phi(\mu_{t,k} / \sqrt{1+v_{t,k}})$，其中 $\mu = x^\top m$，$v = x^\top \Lambda^{-1} x$。无证据时所有顾问可靠性均为 0.5。
- **可靠性引导注意力**：对每个注意力头，在 softmax 前对顾问 $k$ 的 token 加偏置 $\beta_{t,k} = \gamma \log(p_{t,k} / \max_{k'} p_{t,k'})$，最可靠顾问权重不变，其余按比例下调。**无额外可训练参数**。
- **是否咨询的决策**：
  - 咨询能力建模为 $A(T) = T\rho + (1-T)(\kappa - \delta)$，其中 $T$ 为最高顾问可靠性，$\kappa$ 为自主能力，$\rho$ 为可信证据下的咨询能力，$\delta$ 为不可靠证据导致的退化。
  - $\kappa_t = p_{t,0}$，$T_t = \max_k p_{t,k}$；$\rho, \delta$ 通过另一个在线贝叶斯回归从历史验证结果中学习。
  - **决策规则**：若 $A(T_t) \geq \kappa_t$ 则咨询，否则自主推理。等价于当 $T_t \geq T^*_t = \hat{\delta}/(\hat{\rho}+\hat{\delta}-\kappa_t)$ 时咨询。
  - 阈值随自主能力 $\kappa_t$ 和退化 $\hat{\delta}$ 增大而升高，随 $\hat{\rho}$ 增大而降低——**越强的模型需要越可信的外部证据才值得咨询**。

## 6. 主要结论与发现

- **Obs.1 咨询鲁棒性依赖能力 regime**：在能力支持型任务中，Question + Peers 和 Debate 相对稳定；在能力挑战型任务中，误导比例超过 50% 后两者均跌破自主推理基线。多数投票最脆弱。
- **Obs.2 可靠性咨询有帮助但仍需自主推理**：Advisors + memory 显著优于 Question + Peers，但在能力挑战型任务中误导占主导时仍会跌破自主基线——说明**相对顾问加权只能决定"更信任谁"，无法决定"是否值得咨询"**。
- **Obs.3 BaRe-Mem 自适应决定何时咨询**：能力支持型中咨询比例几乎不变（87%→85%）；能力挑战型中从 90% 降至 21%（Qwen3-14B），从 85% 降至 18%（Phi-4）。
- **校准性**：估计的自主能力 $\kappa$ 与经验准确率单调相关；预测咨询增益 $\hat{\Delta}$ 与真实增益 $\Delta$ 一致，曲线在 $\hat{\Delta}=0$ 附近过零，决策边界与实际边界对齐。
- **稀疏反馈**：<1%（约 170 样本）的验证反馈即可带来明显增益，性能随后快速饱和。
- **智能体团队路由**：BaRe-Mem 在所有 lead 模型和验证设置下任务完成率最高，比历史成功计数路由高 1.8–4.9 个百分点，比随机路由高 9.1–11.4 个百分点；能以更少 worker 调用更早找到有能力的工作者。
- **自适应速度**：初始 worker 准确率在任务流早期快速上升并稳定，明显优于历史成功计数基线。

  - 可靠性同时用于**注意力调制**（如何信任）和**咨询决策**（是否咨询），形成互补的双机制。

## 8. 不足与局限

- **算力信息缺失**：未报告 GPU 型号、数量、推理时长等，难以评估实际部署成本。
- **误导信息构造方式**：人工替换为流畅但错误的响应，可能无法覆盖真实场景中顾问的"自信错误"、"部分正确"或"格式错误"等多样误导模式。

- **决策模型简化**：咨询能力建模为 $T$ 的线性插值，可能无法捕捉复杂的非线性交互；$\rho$ 和 $\delta$ 的估计假设单位高斯噪声，实际中噪声方差可能不同。
