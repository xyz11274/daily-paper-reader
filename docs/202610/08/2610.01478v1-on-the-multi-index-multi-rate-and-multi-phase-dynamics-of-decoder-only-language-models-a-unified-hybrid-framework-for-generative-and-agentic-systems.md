## 摘要
大型语言模型（LLMs）正日益被部署为自主决策与规划回路中的计算引擎，然而其系统与控制论处理仍受限于架构简化、指标混淆以及对工具交互的非形式化描述。本文提出一种将仅解码器语言模型视为多指标、多速率系统的控制论形式化方法，并为治理智能体工具交互多阶段动力学的随机混合系统框架奠定基础。我们在三个层次耦合的演化指标上形式化该架构：（i）跨层深度的超快前馈Transformer块级联，其中层归一化被刻画为球面投影，且键值缓存通过因果前缀不变性被证明为精确的内部状态实现；（ii）在令牌生成步骤上的无控制随机差分递归，其中有限上下文截断诱导出时间齐次马尔可夫链；（iii）一种自主模式切换机制，治理令牌生成与工具执行机制之间的转换，其中工具调用在轨迹到达切换流形时触发，随后由外生状态跳跃映射以外部观测增广上下文串。通过在连续可评估声明上定义提示依赖的评估器，我们获得任务级误差过程，其无故障历史与期望误差增长在条件故障风险与误差漂移假设下具有界。

## Abstract
Large language models (LLMs) are increasingly deployed as computational engines in autonomous decision-making and planning loops, yet their systems and control treatment remains hindered by architectural simplifications, index conflations, and informal descriptions of tool interactions. This paper presents a control-theoretic formulation of decoder-only language models as multi-index, multi-rate systems, and sets the stage for a stochastic hybrid systems framework to govern the multi-phase dynamics of agentic tool interaction. We formalize the architecture across three hierarchically coupled evolution indices: (i) an ultrafast feedforward cascade of transformer blocks across layer depth, where layer normalization is cast as a spherical projection and key--value caching is proven to be an exact internal state realization via causal prefix invariance; (ii) an uncontrolled stochastic difference recursion over token generation steps, where finite context truncation induces a time-homogeneous Markov chain; and (iii) an autonomous mode-switching mechanism governing transitions between token generation and tool execution regimes, where tool invocations are triggered upon trajectory arrival at switching manifolds, followed by exogenous state jump maps that augment the context string with external observations. By defining a prompt-dependent evaluator over successive evaluable claims, we obtain a task-level error process whose fault-free histories and expected error growth admit bounds under conditional fault-hazard and error-drift assumptions.
