## 摘要
在规则未知的不熟悉环境中学习完成任务，仍然是LLM智能体面临的关键挑战。当前的LLM智能体通常以散文形式记录其发现，这可能无法紧凑、明确地说明环境如何运作。受科学家将观察组织为可检验、可预测理论的启发，我们提出了Schema，一种通过交互式程序归纳来组织学习与行动的智能体框架。LLM智能体决定调查什么以及如何行动，将其对环境的不断演进的理解表达为可执行程序。该框架由一个持久程序工作区以及一小组接口组成，这些接口用于根据交互历史检查这些程序、在程序内进行规划，并在逐步验证下执行计划。在相同基础模型下，Schema将ARC-AGI-3 RHAE从58.7%提升至99.2%，解决了100%的公开DiG-bench游戏，并在MazeBench上达到前50名人类玩家的中位表现。大量分析表明Schema在未知机制发现方面的有效性，消融实验证实了每个组件的贡献。

## Abstract
Learning to complete tasks in unfamiliar environments with unknown rules remains a key challenge for LLM agents. Current LLM agents often record their discoveries in prose, which may not provide a compact, explicit account of how the environment works. Inspired by how scientists organize observations into testable, predictive theories, we introduce Schema, an agent harness that organizes learning and action through interactive program induction. The LLM agent decides what to investigate and how to act, expressing its evolving understanding of the environment as executable programs. The harness consists of a persistent program workspace and a small set of interfaces for checking these programs against the interaction history, planning within them, and executing plans under step-by-step verification. Schema raises ARC-AGI-3 RHAE from 58.7% to 99.2% with the same base model, solves 100% of the public DiG-bench games, and reaches the median performance of the top-50 human players on MazeBench. Extensive analysis shows the effectiveness of Schema in unknown mechanism discovery, and ablations confirm the contribution of each component.

- **关键洞察**：人类通过观察、实验与推理发现环境机制，并将其抽象为**显式、可复用、可迁移的理论**（如科学理论）。LLM 智能体缺乏这种持久、可检验的知识表示形式。
- **整体含义**：论文提出 **Schema**，首个在未知环境中实现人类水平机制发现的智能体框架（agent harness），将学习与行动组织为**交互式程序归纳（Interactive Program Induction, IPI）**，用可执行程序表达对环境的理解。

## 2. 方法论

### 核心思想
- 智能体将环境理解表达为**可执行程序 P**，包含两部分：
  - **状态 grounding**：构建观察对象、属性、关系的结构化表示及跨步信息。
  - **转移规则**：编码动作与对象交互对状态的影响。
- 程序通过统一预测接口调用：`(ô_{t+1}, z_{t+1}) = P(z_t, o_t, a_t)`。
- 智能体自主决定调查什么、如何行动，程序在工作区中持久保存并跨上下文压缩存活。

### 四个基本操作（IPI 范式）
1. **Hypothesize（假设）**：用文件工具编写/修订程序 P，编码机制；`read_history` 工具检索历史转移作为证据。
2. **Certify（认证）**：通过 `backtest` 工具在完整交互历史 H_t 上回放程序，检查一致性：
   - 不匹配集 `M(P, H_t) = { i < t : ô^P_{i+1} ≄ o_{i+1} }`
   - 一致性判据 `Cert(P, H_t) ⇔ M(P, H_t) = ∅`
   - 返回反例（预测 vs 观测）供智能体修订。
3. **Plan（规划）**：将 P 作为模拟器，给定目标谓词 g，选择搜索过程 σ 与预算 b：
   - `π ← Search_σ(P, z_t, o_t, g; b)`，π 为动作序列。
   - 支持 BFS、DFS、A*、贪心或自定义搜索，不消耗环境动作。
4. **Act with Verification（验证执行）**：提交动作序列，逐步执行并检查预测；一旦不匹配立即丢弃剩余动作并返回意外转移（受模型预测控制启发）。

### 关键设计
- **持久程序工作区**：存储 P、笔记、辅助脚本、历史 H_t，跨回合、关卡、上下文压缩持久。
- **智能体主导**：LLM 自由组织接口调用，利用广泛先验知识做上下文相关决策，而非固定学习流程。

- **ARC-AGI-3**：Schema 将 RHAE 从 basic harness 的 1.2–20.2% 提升至 86.1–99.2%；Fable 5 下达 99.2%，Sol max 达 96.7%；Fable 5 通关全部 25 游戏，仅用人类 57% 的动作总量。

## 7. 优点

- **范式创新**：提出交互式程序归纳（IPI），将程序归纳与动作选择统一到单一 LLM 智能体中，区别于固定学习流程的 WorldCoder/CWM。
- **知识表示优势**：可执行程序比散文更紧凑、可验证、可复用，跨上下文压缩持久存活。
- **完整闭环**：假设→认证→规划→验证执行四操作形成闭环，反例驱动修订，规划不消耗环境动作。
- **实验扎实**：三个异构 benchmark、多模型、消融、重复运行、长时程行为分析，证据链完整。
- **人类水平表现**：在多个 benchmark 上达到或超越人类基线，且动作效率更高。
- **成本效益**：DiG-bench 每通关关卡成本更低，MazeBench token 成本与 baseline 相当但性能更优。
