# On the Multi-Index, Multi-Rate, and Multi-Phase Dynamics of Decoder-Only Language Models: A Unified Hybrid Framework for Generative and Agentic Systems 

Ali Pakniyat, Member, IEEE 

Abstract — Large language models (LLMs) are increasingly deployed as computational engines in autonomous decision-making and planning loops, yet their systems and control treatment remains hindered by architectural simplifications, index conflations, and informal descriptions of tool interactions. This paper presents a control-theoretic formulation of decoder-only language models as multi-index, multi-rate systems, and sets the stage for a stochastic hybrid systems framework to govern the multi-phase dynamics of agentic tool interaction. We formalize the architecture across three hierarchically coupled evolution indices: (i) an ultrafast feedforward cascade of trans-former blocks across layer depth, where layer normalization is cast as a spherical projection and key–value caching is proven to be an exact internal state realization via causal prefix invariance; (ii) an uncontrolled stochastic difference recursion over token generation steps, where finite context truncation induces a time-homogeneous Markov chain; and (iii) an autonomous mode-switching mechanism governing tran-sitions between token generation and tool execution regimes, where tool invocations are triggered upon trajectory arrival at switching manifolds, followed by exogenous state jump maps that augment the context string with external observations. By defining a prompt-dependent evaluator over successive evaluable claims, we obtain a task-level error process whose fault-free histories and expected error growth admit bounds under conditional fault-hazard and error-drift assumptions. 

I. I NTRODUCTION 

The transformer architecture, introduced originally as an encoder-decoder system for sequence transduction [1], has converged into the ubiquitous “decoder-only” configuration in modern foundation models, including OpenAI’s GPT series [2], Meta’s LLaMA, and Mistral. Unlike encoder-decoder architectures driven by exogenous reference inputs (such as a source text in machine translation), a decoder-only model operates as an unforced, causal sequence generator that evolves purely via recursive token concatenation. Within each token-generation step, the circulating sequence of dis-crete tokens is mapped via fixed embedding operators into an initial continuous tensor state, which propagates through a cascade of spatial- and channel-mixing transformer blocks under a lower-triangular causal attention kernel. In modern autonomous and agentic applications, this sequence generator operates across two primary modalities: generative open-loop rollout, wherein text evolves through unforced recursive token emission, and agentic tool-augmented interaction [3], [4], wherein internal generation halts to coordinate with ex-

Recognizing that generative foundation models are in-creasingly embedded inside critical decision-making loops, the systems and control community has initiated several lines of research to analyze transformers using rigorous dynamical tools. Prompt engineering has been cast as an optimal control problem with an explicit notion of reachability [6], depth layers have been modeled as continuous-time interacting particle systems and consensus dynamics on manifolds [7]– [9], attention routing has been studied through the lens of Markov chains [10], next-token prediction has been inter-preted via nonlinear filtering and stochastic optimal control duality [11]–[13], and robotic deployment safety has been investigated using control barrier functions [14]. Despite this fruitful expansion, existing representations in the literature exhibit notable modeling simplifications and structural ambiguities. In reachability-based prompt formu-lations such as [6], the entire multi-layer transformer network is collapsed into an abstract static operator; this abstraction produces modeling discrepancies where the control input is introduced as a continuation token at one stage, yet treated as an amended initial condition in the state space at another. Conversely, continuous-time depth formulations [7]–[9] pro-vide valuable convergence results by viewing layer depth as ordinary differential equations, yet they deliberately iso-late the self-attention operator under idealized conditions— frequently omitting layer normalizations, projection matrices, and the position-wise Multi-Layer Perceptrons (MLPs) that constitute over two-thirds of the network’s non-embedding parameters. More fundamentally, control expositions rou-tinely conflate the deterministic, finite-horizon feedforward evaluation across layer depth ℓ ∈ { 1, . . . , L } with the uncon-trolled stochastic difference recursion that generates tokens across generation time t ∈ N; these two processes evolve on distinct index sets, inhabit different mathematical spaces, and possess fundamentally different dynamical properties. Finally, in the machine learning literature on agentic tool use [3], [4], tool invocation is treated as an informal software wrapper or string-delimited prompt hook. Rather than rec-ognizing these interactions as formal dynamical phenomena, existing control treatments lack a unified framework to model tool-augmented generation as a hybrid system with discrete modes, state jump maps, and contractive error dynamics. F. Key–Value Caching as an Exact Internal State Realization 

In computational practice, autoregressive token generation across context length n is accelerated via Key–Value (KV) caching to avoid re-evaluating preceding sequence states across the depth cascade. In the machine learning litera-ture, this procedure is routinely treated as an algorithmic runtime optimization or an implementation detail of the attention operator. From a systems theory perspective, however, the KV cache fulfills the classical role of an internal state: a perpetually renewing initial condition that absorbs the entire history of past inputs into a minimal sufficient statistic. Rather than maintaining an expanding memory operator over the full historical sequence, causal prefix invariance ensures that the cached keys and values decouple past trajectory history from future evolution through an exact, instantaneous readout.

The task-level quantities above separate architectural structure from behavioral performance. The Markov kernel specifies the distribution of generated contexts, whereas the evaluator Ψ and the assumptions on α and δdrift specify a task-dependent reliability model. Their identification for particular models, decoders, and task classes is left for future work. V. C ONCLUSION 

This paper establishes a control-theoretic model of decoder-only language models. It separates the deterministic transformer cascade across layer depth from the uncontrolled stochastic recursion across token-generation time, and em-beds both within a hybrid description of agentic execution and context updates. The model makes the associated state spaces, clocks, and transition mechanisms explicit. Within this formulation, familiar system-theoretic questions admit precise statements and direct analysis: Causal prefix invariance makes Key–Value caching an exact internal state realization. Context truncation induces a time-homogeneous finite-state Markov representation, while fixed parameters and deterministic tie-breaking make greedy decoding ultimately periodic. At the task level, a prompt-dependent evaluator induces an error process over successive evaluable claims. Conditional fault-hazard and error-drift assumptions then yield bounds on fault-free claim histories and expected error growth, respectively. The architectural results follow from the stated decoder dynamics. The task-level results instead depend on an evalu-ator and on model-, decoder-, and task-specific assumptions. Their identification, the role of external information in the induced error process, and a detailed stochastic hybrid-systems treatment of agentic language models are left for future work.
