## 摘要
交互式语言模型智能体越来越多地通过长时程、多轮调用的推理来解决复杂任务，其中信念或行动上的错误会在工具交互中不断累积。回溯搜索能够从这类失败中恢复，但容易出现资源错配。延迟的结果会掩盖中间搜索决策的贡献，导致归因复杂性；而不断演化的执行证据则导致适应复杂性，即先前学到的估计会变得过时。为应对这些挑战，我们首先引入搜索价值动态（SVD），刻画回溯搜索的收益与成本之间不断演化的权衡。基于SVD，我们提出ForkPilot，一种自演化的两阶段策略学习框架。在第一阶段，ForkPilot通过自动构建的结果比较，从已完成的轨迹中离线学习搜索价值策略。在第二阶段，它基于当前观测做出搜索决策，并通过将新完成的轨迹纳入后续策略更新来实现自演化。我们在6个多样化基准和7个广泛使用的LLM骨干系列上评估ForkPilot，包括四个开源系列、GPT-5.6 Sol和Opus 4.8，部署于生产级智能体系统中，并与9个竞争性基线进行比较，其中包括一个被数十万付费用户使用的真实世界测试框架部署。ForkPilot在达到可比的最先进性能的同时，将token使用量最多减少59.2%，证明了其有效性。

## Abstract
Interactive language-model agents increasingly solve complex tasks through long-horizon, multi-call reasoning, where errors in beliefs or actions can compound across tool interactions. Retrospective search can recover from such failures but is prone to misallocation. Delayed outcomes obscure the contribution of intermediate search decisions, leading to Attribution Complexity, while evolving execution evidence leads to Adaptation Complexity, where previously learned estimates become stale. To address these challenges, we first introduce Search Value Dynamics (SVD), which characterizes the evolving trade-off between the gain and cost of retrospective search. Building on SVD, we propose ForkPilot, a self-evolving two-stage policy-learning framework. In the first stage, ForkPilot learns a search-value policy offline from completed trajectories through automatically constructed outcome comparisons. In the second stage, it makes search decisions based on current observations and then self-evolves by incorporating newly completed trajectories into subsequent policy updates. We evaluate ForkPilot across 6 diverse benchmarks and 7 widely used LLM backbone families, including four open-source families, GPT-5.6 Sol, and Opus 4.8 in a production agentic system, against 9 competitive baselines, including a real-world harness deployment used by hundreds of thousands of paid users. ForkPilot achieves comparable state-of-the-art performance while reducing token usage by up to 59.2%, demonstrating its efficacy.

## 1. 核心问题与研究动机

- **背景**：交互式语言模型智能体通过长时程、多轮工具调用解决复杂任务，但信念或行动上的错误会在工具交互中不断累积，导致任务失败。
- **回溯搜索的作用**：智能体可以回顾失败或部分成功的轨迹，结合评分器/验证器反馈，从早期可恢复状态分叉（fork）出新的分支，保留有效动作前缀并尝试替代延续。
- **核心难题——资源错配**：回溯搜索虽然能纠错，但何时搜索、搜索哪条轨迹、搜索多少都极难决策，具体表现为两大复杂性：
  - **归因复杂性（Attribution Complexity）**：延迟到达的结果掩盖了中间搜索决策的增量贡献，且奖励与成本变化相互纠缠，难以判断一次分叉是否值得其计算开销。
  - **适应复杂性（Adaptation Complexity）**：新观测与搜索结果的演化、以及环境自身的变化，会使先前学到的搜索价值估计迅速过时。
- **整体含义**：论文将长时程回溯搜索重新定义为一个**动态计算分配问题**，而非单纯的推理或记忆增强问题，并试图回答两个研究问题：
  - Q1：如何在延迟奖励与演化观测下理论化地理解回溯搜索的价值？
  - Q2：模型能否通过积累经验自演化，动态分配推理资源，兼顾效果与效率？

## 2. 方法论

### 2.1 核心思想：搜索价值动态（SVD）

- 定义配对回放（paired replay）Γ：在同一恢复状态下，协调随机性、相同后续执行规则与总预算约束，比较某分配动作 `u` 与不搜索基线 `u0`。
- 关键量：
  - 奖励差 `Yt(u) = R(τ_u) − R(τ_0)`
  - 归一化成本差 `ΔCt(u) = C(τ_u) − C(τ_0)`
  - 净效应 `Gt(u) = EΓ[Yt(u) − λΔCt(u) | zt]`，其中 `λ ≥ 0` 控制奖励-成本权衡，`Gt(u0)=0`。
- **归因复杂性**量化为 `AΓt(u) = VarΓ[Yt(u) | zt]`：固定输入下奖励差仍因采样与环境响应而波动，n 次独立配对回放的样本均值方差为 `AΓt(u)/n`，归因复杂性越大，达到同等精度所需配对越多。
- **适应复杂性**通过源-当前分布偏移刻画：`|EP Yt(u) − EQ Yt(u)| ≤ S_t(u) := 2TV(P,Q) ≤ √(2DKL(P∥Q))`。
- 方差分解进一步表明：控制器表示 `Z=φ(H)` 会引入表示歧义，`Var(W|Z) = E[Var(W|H)|Z] + Var(g(H,u)|Z)`，即采样噪声与表示歧义共同加剧归因困难。

### 2.2 理论结果：源到当前搜索价值界（Theorem 1）

- 对每个可行动作 `u`，在源输入 `zsrc` 上抽取 `nu` 个条件独立配对样本，其均值记为 `W̄src(u)`，源拟合预测器为 `Ĝsrc(u)`，则对任意 `0<δ<1`，以至少 `1−δ` 概率同时对所有 `u` 成立：

  `|Gt(u) − Ĝsrc(u)| ≤ esrc(u) + √(K·VΓsrc(u)/(nu·δ)) + Ωsrc→t(u) + Ssrc(u) + λD·ξsrc,t(u) =: βδsrc,t(u)`

- 各项含义：`esrc` 为源样本拟合偏差；第二项为采样误差（增加配对可降低）；`Ωsrc→t` 为输入变化；`Ssrc` 为源-当前奖励律偏移；`ξsrc,t` 为期望归一化成本变化。
- **决策推论**：定义 `Lδt(u)=Ĝsrc(u)−βδ`、`Uδt(u)=Ĝsrc(u)+βδ`。若最大下界 `Lδt(uL)>0`，则 `Gt(uL)>0`，且相对最优动作的局部净价值遗憾不超过 `2βδsrc,t(u*)`；若所有上界 `≤0`，则跳过（skip）为最优。
- **重要边界说明**：该定理仅诊断固定回放规则下的归因与陈旧估计问题，**不构成对学习到的操作边际或部署控制器的证书**，因为部署时无法获得精确输入配对与偏移项。

### 2.3 ForkPilot：两阶段自演化策略学习框架

- **第一阶段（Stage I）——从已完成经验中归因**：
  - 在可恢复源状态上执行配对回放，得到 `ẽY = R(τ_u)−R(τ_0)` 与 `ẽD = [C(τ_u)−C(τ_0)]/C̄src`。
  - 每个配对仅标注其被选动作，**无需人工分配标签**，也无需在每个部署决策点做配对回放。
  - 编码器 `rt = fψ(zt)` 生成表示；动作条件化的 M 个任务自助（task-bootstrap）集成头分别预测奖励效应与归一化成本效应，取平均得 `Ĝt(u)`。
  - 由于定理中的偏移项在运行时不可得，ForkPilot 用**集成分歧、源表示支持度、留出配对残差**估计经验边际 `β̂t(u)`，并单独校准。`Lt(u)=Ĝt(u)−β̂t(u)`、`Ut(u)=Ĝt(u)+β̂t(u)` 是决策分数，**不是条件覆盖证书**。
- **第二阶段（Stage II）——闭环适应**：
  - 拟合参数 `θn′` 固定，控制器在每个决策点用当前 `zt` 重新评分可行菜单。
  - 设 `Ft = Ut \ {u0}`，`Pt` 为受限于探针上限 `kpr, dpr` 的受限探针动作集。
  - 决策规则（式 4）：
    - 若 `Lmax_t > 0`：选择下界分数最高的动作（commit）；
    - 否则若 `Uprobe_t > 0`：选择预测归一化全执行成本差最低的受限探针（probe）；
    - 否则：跳过本轮回溯（skip，不终止任务）。
- **自演化机制**：跨任务层面，每完成一个任务后将其有效配对记录加入 `Dn`，重新拟合 `θn+1`；任务内层面参数冻结、仅刷新决策。这使策略能适应独立于智能体行动而演化的真实环境。
- **工程细节**：生产系统中通过会话级虚拟化层隔离并行 rollout，写入暂存于会话本地 overlay，仅最终选中轨迹的变更可发布到真实资产；不可逆外部效应须延迟或排除在推测执行之外。

## 6. 主要结论与发现

- **一致的效率优势**：在 6 个基准上，ForkPilot 平均减少原始 token 36.2%、未缓存 token 30.3%，同时任务分数相对完整 RTS 平均略升 +0.23 分；基准级原始 token 节省 31.8%（SWE-bench）至 39.8%（AutomationBench）。
- **跨规模鲁棒**：从 4B 到 9B、27B，原始 token 节省从 28.5% 升至 33.7%、37.0%，122B-A10B 为 35.8%，效率收益在最大规模趋于饱和而非消失；分数变化稳定在 +0.23 至 +0.30 分。
- **前沿黑盒模型有效**：在生产系统中，ForkPilot 仅用 RTS 的 58.8%–77.8% 原始 token 与 40.8%–76.3% 未缓存 token，对应最多 **59.2% 的未缓存 token 节省**，性能与 RTS 相当；相比 RDS 在所有四个设置中分数更高且原始成本低 53.1%–78.9%。
- **样本高效自演化**：仅用 25% 训练划分（13.3% 总数据）即恢复 81%–85% 的完整训练改进，呈现强前载缩放。
- **机制验证**：刷新状态（full）显著优于冻结前缀；操作边际（margin）是主要效率来源；学习停止优于验证选择的手动阈值；新工具事件（尤其是可恢复错误后出现新标识符）会显著改变搜索价值（翻转率 41.7%）。
- **无反馈泄漏**：掩码反馈下分数与原始几乎持平，打乱反馈仅下降 1.4–2.8 分，说明增益不依赖评估器信息泄漏。
- **宿主调度鲁棒**：顺序调度下 ForkPilot 仍保持未缓存 token 节省（36.5%–64.1%），且分数进一步提升。
