## 摘要
在多智能体系统中，可靠的咨询具有挑战性，因为顾问的能力因任务而异，且误导性信息可能使咨询效果不如自主推理。我们提出了BaRe-Mem，一种用于多智能体咨询的在线贝叶斯可靠性记忆。它基于中心模型的内部信念表示来估计顾问的可靠性，并根据历史交互更新这些估计。这些估计调节顾问响应的影响，并指导在咨询与自主推理之间的选择。在九个基准和六个中心模型上，BaRe-Mem对误导性顾问信息比辩论和多数投票更具鲁棒性。在更具挑战性的任务上，它在所有测试的误导水平下均保持优于自主推理。此外，我们将BaRe-Mem机制扩展到智能体团队中的工作者分配。在MuSiQue基准上，BaRe-Mem相比基于历史成功计数的路由提高了任务完成率，并更早地识别出有能力的工作者。

## Abstract
In multi-agent systems, reliable consultation is challenging because advisor capabilities vary across tasks, and misleading information can make consultation worse than autonomous reasoning. We introduce BaRe-Mem, an online Bayesian reliability memory for multi-agent consultation. It estimates advisor reliability based on the central model's internal belief representations and updates these estimates from historical interactions. These estimates modulate the influence of advisor responses and guide the choice between consultation and autonomous reasoning. Across nine benchmarks and six central models, BaRe-Mem is more robust to misleading advisor information than debate and majority voting. On the more challenging tasks, it remains above autonomous reasoning across all tested misleading levels. Moreover, we extend the BaRe-Mem mechanism to worker allocation in agent teams. On the MuSiQue benchmark, BaRe-Mem improves task completion over routing by historical success counts and identifies capable workers earlier.

# BaRe-Mem 论文深度总结

## 1. 核心问题与研究动机

- **背景**：单一 LLM 无法覆盖复杂任务所需的全部能力，因此 AI 系统日益组织为多智能体网络，智能体之间相互咨询（consultation）成为常态。
- **核心矛盾**：顾问（advisor）的能力具有**任务依赖性**——在某领域可靠的模型可能在另一领域失效；同时，误导性咨询信息可能让中心模型放弃原本正确的答案，导致咨询效果**反而不如自主推理**。
- **关键洞察**：仅靠聚合当前响应（如多数投票、辩论）不足以解决问题，因为多个顾问可能共同强化同一个"看似合理但错误"的答案。中心模型需要估计**哪些外部信息对当前问题是可靠的**。
- **现有方法不足**：
  - 文本记忆（轨迹、摘要、技能）受压缩保真度与检索噪声限制；
  - 连续记忆（隐状态、神经记忆）未显式建模"以中心模型内部信念为条件的顾问可靠性"；
  - 已有工作忽略了"是否应该咨询"这一决策本身——当单智能体能力足够强时，协作收益可能递减甚至为负。
- **整体含义**：论文主张构建一种**持久化的可靠性记忆**，既能调节外部信息的影响强度，又能判断是否值得咨询，从而支撑长周期多智能体系统的鲁棒协作。

## 2. 方法论：BaRe-Mem

### 2.1 核心思想
以**在线贝叶斯线性回归**建模顾问（及中心模型自身）在给定问题上的可靠性，用中心模型的内部信念表示作为条件特征，从已验证的正确性反馈中持续更新，并据此完成两件事：**调节注意力**与**决定是否咨询**。

### 2.2 信念表示与可靠性建模
- 对问题 $q_t$，考虑 $K+1$ 个候选：$K$ 个顾问响应 + 中心模型自身的自主答案 $a_{t,0}$。
- 冻结的中心模型编码每个候选，得到隐表示 $h_{t,k}$，并分解为：
  - **问题信念** $\psi_q(t)$（跨候选共享）；
  - **答案内容信念** $\psi_c(t,k)$（候选特有）。
- 候选表示为 $x_{t,k} = [e_k \otimes \psi_q(t);\ \psi_c(t,k);\ 1]$，其中 $e_k$ 是来源的 one-hot 标识。
- 可靠性得分 $w^\top x_{t,k}$ 分解为三项：**来源可靠性**（源 $k$ 在相似问题上的可靠度）+ **答案内容可靠性** + **偏置**。

### 2.3 贝叶斯记忆更新
- 令 $s_{t,k} = 2y_{t,k}-1$（$y$ 为是否正确），建模为 $s_{t,k} \mid x_{t,k}, w \sim \mathcal{N}(w^\top x_{t,k}, 1)$，先验 $w \sim \mathcal{N}(0, \lambda^{-1}I)$。
- 后验精度 $\Lambda = \lambda I + \sum xx^\top$，均值 $m = \Lambda^{-1}b$。
- 新验证结果到来时，通过 **Kalman 增益**做精确的秩一在线更新：
  - $g_{t,k} = \frac{\Lambda^{-1}x_{t,k}}{1 + x_{t,k}^\top \Lambda^{-1} x_{t,k}}$
  - $m \leftarrow m + g_{t,k}(s_{t,k} - x_{t,k}^\top m)$
  - $\Lambda^{-1} \leftarrow \Lambda^{-1} - g_{t,k}(\Lambda^{-1}x_{t,k})^\top$
- 该更新**与观测顺序无关**，且无需重算整个后验。

### 2.4 可靠性估计
- 预测分布 $s \mid x, D \sim \mathcal{N}(\mu, 1+v)$，其中 $\mu = x^\top m$，$v = x^\top \Lambda^{-1} x$。
- 可靠性估计为正确概率：$p_{t,k} = \Phi\!\left(\frac{\mu_{t,k}}{\sqrt{1+v_{t,k}}}\right)$。
- 无证据时所有候选 $p = 1/2$；证据积累后，正确结果提升可靠性，错误结果降低可靠性。

### 2.5 可靠性引导的注意力（Reliability-Guided Attention）
- 在每个注意力头中修改 softmax 前的未归一化权重：
  - $\alpha_{qj} = \text{softmax}_j\left(\frac{\langle Q_q, K_j\rangle}{\sqrt{d}} + \beta_{t,c(j)}\right)$
  - $\beta_{t,k} = \gamma \log \frac{p_{t,k}}{\max_{k'} p_{t,k'}}$
- 效果：最可靠的顾问权重不变，较不可靠的顾问被逐步降权；**无额外可训练参数、无需训练**，仅依赖顾问间的相对可靠性。

### 2.6 是否咨询的决策
- 建模中心模型的咨询能力：$A(T) = T\rho + (1-T)(\kappa - \delta)$
  - $T$：顾问候选中的最高可靠性（对可信证据的置信度）；
  - $\rho$：有可信证据时的咨询成功率；
  - $\kappa$：中心模型自主能力（由自主候选的 $p_{t,0}$ 给出）；
  - $\delta$：不可靠证据导致的相对自主推理的性能退化。
- $\rho, \delta$ 通过另一个二维贝叶斯回归从历史验证结果中在线学习（线性形式 $z_t = u_t^\top \theta + \varepsilon$）。
- **决策规则**：当 $A(T_t) \geq \kappa_t$ 时选择咨询，否则自主推理。
- 咨询优势可写为：$A(T_t) - \kappa_t = \underbrace{T_t(\hat\rho - \kappa_t)}_{\text{可信证据收益}} - \underbrace{(1-T_t)\hat\delta}_{\text{不可靠证据损失}}$。
- 当 $\hat\delta>0, \hat\rho>\kappa_t$ 时，存在**盈亏平衡信任阈值** $T^*_t = \frac{\hat\delta}{\hat\rho+\hat\delta-\kappa_t}$：自主能力越强、退化越大，所需信任阈值越高；利用可信证据能力越强，阈值越低。

## 6. 主要结论与发现

- **鲁棒性**：BaRe-Mem 在两种能力体系、所有误导比例下均优于辩论与多数投票；在能力挑战型任务中，**所有测试误导水平下均保持高于自主推理基线**，而其他咨询方法在误导比例超过 50% 后普遍跌破基线。
- **自适应咨询**：能力支持型中咨询比例基本稳定（约 83–87%）；能力挑战型中随误导增加从约 85–90% 降至 9–21%，说明模型学会了"何时不咨询"。
- **两个机制互补**：可靠性引导注意力改善"如何用顾问"，自主选择机制提供"不用顾问"的退路；仅靠前者在误导主导时仍会跌破基线。
- **校准性**：估计的自主能力 $\kappa$ 与经验准确率单调相关；预测的咨询增益与真实验证后的增益一致，且预测的决策边界与真实边界对齐。
- **稀疏反馈高效**：低于 1%（约 170 样本）的验证反馈即可带来明显增益，性能随后快速饱和。
- **团队路由**：在 MuSiQue 上，BaRe-Mem 的任务完成率高于历史成功计数路由与随机路由，且能用更少的 worker 调用更早找到有能力的工作者；优势在不同验证设置下持续存在。
- **自适应速度**：初始 worker 准确率在子任务流早期快速上升后趋于稳定，符合 Kalman 增益"早期更新幅度大、后期收敛"的特性。

## 7. 优点

- **方法优雅且轻量**：基于贝叶斯线性回归 + Kalman 增益的精确在线更新，无需训练、无额外可训练参数，注意力修改仅依赖相对可靠性。
- **双机制设计**：同时解决"如何加权顾问"与"是否咨询"两个问题，后者是已有工作普遍忽视的关键缺口。
- **理论完备**：附录给出完整的后验推导、Kalman 增益最优性证明、顺序无关性证明、盈亏平衡阈值分析及决策误差界。
- **条件化可靠性**：可靠性以中心模型的内部信念表示为条件，能捕捉任务依赖的顾问能力，而非仅依赖来源身份或全局成功率。
- **实验覆盖广**：9 个基准、6 个中心模型、6 个顾问、多误导水平、稀疏反馈、团队路由，验证维度丰富。
- **可扩展性**：同一机制从"响应级咨询"自然扩展到"团队 worker 路由"，展示了实际部署潜力。
- **诚实的局限性披露**：附录 B.4 明确指出高误导比例下可靠性估计存在校准偏差（约 0.2 的下限），并给出数学解释。

## 8. 不足与局限

- **算力信息缺失**：未报告 GPU 型号、数量、推理时长等，复现成本与效率评估困难。
- **校准偏差**：在 100% 误导下，经验准确率接近 0，但可靠性估计仍约 0.2，源于单位观测噪声导致 $\Phi(-1)\approx 0.159$ 的下限；论文承认这是"示意性极限"而非通用下界。
- **误导构造的生态效度**：误导响应为人工替换的错误答案，可能无法完全代表真实场景中"流畅但错误"的分布（如幻觉、谄媚、过时知识）。

- **同源模型风险**：部分中心模型与顾问来自同一家族（Qwen 系列），可能高估可靠性估计的跨家族泛化能力。
- **决策模型简化**：咨询能力用线性插值 $A(T)=T\rho+(1-T)(\kappa-\delta)$ 建模，假设 $T$ 与 $\rho,\delta$ 的关系线性，可能无法捕捉复杂交互。

- **团队实验依赖数据集子任务**：使用 MuSiQue 提供的子任务分解，隔离了路由效果，但也回避了 lead agent 分解质量对整体性能的影响。
