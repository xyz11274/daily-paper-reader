## 摘要
在规则未知的不熟悉环境中学习完成任务，仍然是LLM智能体面临的关键挑战。当前的LLM智能体通常以散文形式记录其发现，这可能无法提供关于环境如何运作的紧凑、明确的描述。受科学家如何将观察组织为可检验、可预测的理论的启发，我们提出了Schema，一种通过交互式程序归纳来组织学习与行动的智能体框架。LLM智能体决定调查什么以及如何行动，将其对环境不断演变的理解表达为可执行程序。该框架由一个持久程序工作区以及一小组接口组成，这些接口用于根据交互历史检查这些程序、在其中进行规划，并在逐步验证下执行计划。在相同基础模型下，Schema将ARC-AGI-3 RHAE从58.7%提升至99.2%，解决了100%的公开DiG-bench游戏，并在MazeBench上达到前50名人类玩家的中位表现。广泛的分析表明Schema在未知机制发现方面的有效性，消融实验证实了每个组件的贡献。

## Abstract
Learning to complete tasks in unfamiliar environments with unknown rules remains a key challenge for LLM agents. Current LLM agents often record their discoveries in prose, which may not provide a compact, explicit account of how the environment works. Inspired by how scientists organize observations into testable, predictive theories, we introduce Schema, an agent harness that organizes learning and action through interactive program induction. The LLM agent decides what to investigate and how to act, expressing its evolving understanding of the environment as executable programs. The harness consists of a persistent program workspace and a small set of interfaces for checking these programs against the interaction history, planning within them, and executing plans under step-by-step verification. Schema raises ARC-AGI-3 RHAE from 58.7% to 99.2% with the same base model, solves 100% of the public DiG-bench games, and reaches the median performance of the top-50 human players on MazeBench. Extensive analysis shows the effectiveness of Schema in unknown mechanism discovery, and ablations confirm the contribution of each component.

## 2. 方法论

### 核心思想
- 智能体将环境理解表达为**可执行程序 P**，而非散文。程序具有持久性、可执行性、可验证性。
- 受科学发现与程序合成（counterexample-guided inductive synthesis）启发，形成"假设—验证—规划—执行"闭环。

### 任务设定（形式化）
- 智能体在未知环境行动，动作集 A 已知，但转移函数 T 和完成谓词 G 未知。
- 每步接收观测 $o_t$（潜在状态 $s_t$ 的观测），选择动作 $a_t$，环境按 $s_{t+1}=T(s_t,a_t)$ 演化。
- 累积交互历史 $H_t = ((o_i, a_i, o_{i+1}))_{i<t}$，目标是以尽可能少的交互完成任务。

### 四大基本操作

**（1）Hypothesize（假设）— 将机制编码为程序**
- 程序 P 包含两部分：(i) **状态接地（state grounding）**：构建对象、属性、关系的结构化表示；(ii) **转移规则**：编码动作与对象交互的效果。
- 统一预测接口：$(\hat{o}_{t+1}, z_{t+1}) = P(z_t, o_t, a_t)$，其中 $z_t$ 为程序内部状态。
- 智能体用文件管理工具修订状态表示与转移规则，harness 将每次观测转移追加到历史。

**（2）Certify（验证）— 检查与历史的一致性**
- 通过**回放交互历史**检查程序：对每个记录动作，用记录观测与重建内部状态评估预测。
- 失配集与一致性准则：
  - $M(P, H_t) = \{ i < t : \hat{o}^P_{i+1} \not\simeq o_{i+1} \}$
  - $Cert(P, H_t) \iff M(P, H_t) = \emptyset$
- harness 提供 **backtest 工具**，报告失配及预测/观测对比，给出具体反例供修订。每次修订都需重新检查全历史，使发现累积为连贯程序。

**（3）Plan（规划）— 在程序内搜索**
- 同一预测接口使 P 成为**模拟器**：反馈预测观测与内部状态即可 rollout，无需消耗环境动作。
- 智能体指定目标谓词 $g$，选择搜索过程 $\sigma$ 与预算 $b$：
  - $\pi \leftarrow Search_\sigma(P, z_t, o_t, g; b)$，$\pi = (a_t, \ldots, a_{t+k-1})$
- 支持内置 BFS/DFS/A*/贪心搜索，也可自行编写搜索程序；可调整搜索深度、节点限制、运行时间。
- 规划同时服务于**任务推进**与**实验设计**（构造可测试未解机制的情境）。

**（4）Act with Verification（带验证执行）**
- 提交动作序列，harness 在执行每个动作前获取预测，执行后追加转移至历史。
- **预测与观测一致则继续执行，无需额外 LLM 调用**；一旦失配立即丢弃剩余动作，将意外转移返回给智能体（受模型预测控制 MPC 启发）。
- 每个执行动作都扩展归纳证据，智能体据此决定修订程序、调整计划或进一步探索。

### 实现细节
- 持久工作区存储 P、笔记、辅助脚本、$H_t$，跨轮次、关卡、上下文压缩持久存在。
- 工具分组：文件工具、read_history、backtest、model_predict、commit_actions、规划工具。
- 基准适配器提供观测、动作、任务反馈；智能体自主决定调用哪个操作。

## 6. 主要结论与发现

- **ARC-AGI-3**：Schema 将 RHAE 从基础 harness 的 1.2–20.2% 提升至 86.1–99.2%；相对编码 harness 提升 34.4–40.7 个百分点。Fable 5 达 99.2%，Sol max 达 96.7%，Opus 4.8 达 86.1%。Fable 5 与 Sol max 通关全部 25 个游戏。Fable 5 用人类 57% 的动作总量完成全部 183 关。
- **DiG-bench**：Schema 在 medium/high/max 分别通关 19/20/21 个游戏（基础 harness 为 11/16/19）；最难两层（6–7）max 努力下胜率从 66.7% 升至 100%；medium 努力下损失生命从 96 降至 34；每通关一关 token 成本低约 15%。
- **MazeBench**：36 小时收集 33 宝石、访问 139 房间，超过 top-50 人类中位（29.0% 宝石、53.5% 房间）；相同动作数下优于 Codex；动作 10,000 后仍保持更高探索新颖度（54% vs 40%）。
- **消融结论**：移除任一组件（程序表示、认证、规划、验证）RHAE 从 72.9% 降至 52.4–62.3%，验证每个组件的贡献。
- **知识累积**：程序保持紧凑（2,012 行 vs 散文 6,133 行），每行解释的转移数与函数调用点增加，前向预测准确率保持高位；规则可跨上下文压缩复用（如冰面滑动规则在约 25,000 动作后、≥20 次压缩后于新房间复用）。
- **核心洞见**：持久可执行模型让智能体将个体发现转化为可测试、可精炼、可复用、可行动的显式假设。

## 7. 优点

### 方法亮点
- **范式创新**：提出交互式程序归纳（IPI），将程序归纳与动作选择统一，智能体自主控制学习过程（何时修订、验证、探索、规划），而非在预定义学习流程中充当算子。
- **表示优势**：可执行程序相比散文具有紧凑、显式、可验证、可复用、可迁移的特性，能抵抗上下文压缩带来的知识退化。
- **闭环设计**：假设—认证—规划—验证四操作形成完整闭环，认证用全历史回放保证一致性，验证用 MPC 式逐步检查实现快速纠错。
- **通用性**：同一 harness 适配视觉网格、文本、3D 空间三类异构环境，跨多种基础模型有效。

### 实验亮点
- **多基准、多模型、多努力程度**的系统评估，控制变量严谨（同基础模型对比）。
- **人类基线参照**：三个基准均与人类表现对比，结论有说服力。
- **丰富的定性分析**：trace 动态、案例研究（CN04 几何拼接、AR25 认证、LS20 规划与验证、P-3 隐藏字符串规则、冰面规则复用）深入揭示机制。
- **成本分析**：报告 token 成本与每宝石成本，关注实际部署可行性。
- **重复运行与误差报告**：DiG-bench 三次运行报告标准差，增强可信度。

## 8. 不足与局限

### 实验覆盖
- **仅评估公开集**：ARC-AGI-3 的半私有（55）与私有（55）游戏、DiG-bench 的 49 个私有游戏均未评估，泛化性证据有限。
- **消融范围窄**：仅在 10 个游戏、单一模型（Opus 4.8）上做消融，未跨模型验证组件贡献的普适性。
- **MazeBench 单次运行**：未报告重复运行，长时探索的方差未知。

### 偏差风险
- **人类基线异质性**：三个基准的人类数据来源不同（首次玩家、首次人类、top-50 中位），可比性存在潜在偏差。
- **基准时效性**：论文日期为 2026 年，涉及大量未来模型（GPT-6 Astra、Claude Fable 5 等），部分结果难以独立复现。
- **成本与可及性**：依赖前沿闭源模型与大量 API 调用，长时运行（36 小时）成本高，学术可复现性受限。

### 应用限制
- **依赖基础模型能力**：方法本身不训练模型，效果上限受基础模型先验知识约束；在完全超出模型先验的领域可能失效。
- **程序归纳的可扩展性**：复杂环境中程序可能变得庞大，维护与搜索成本上升；论文未深入讨论程序规模上限。
- **状态接地依赖**：需要智能体自行构建状态表示，在观测高维、噪声大的环境中可能困难。
- **未讨论失败模式**：对程序无法收敛、持续失配、规划搜索失败等情形缺乏系统分析。
- **算力信息缺失**：未披露硬件资源，难以评估方法的计算门槛。
