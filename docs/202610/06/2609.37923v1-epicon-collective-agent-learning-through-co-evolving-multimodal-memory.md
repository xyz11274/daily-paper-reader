## 摘要
智能体可以从过去的执行中学习，但使不同智能体能够重用并基于彼此的经验进行构建仍然具有挑战性。我们提出了EpiCon，一种用于智能体集体学习的共享多模态记忆框架，无需更新宿主模型参数。EpiCon通过两个独立训练的2B模型——记忆控制器和树自组织器——将问题级记忆演化与持久经验库相连接。控制器在多次尝试中联合优化文本指导和视觉证据，并有选择地纳入视觉记忆。自组织器分层整合经验教训，并为新问题检索经验和规则。我们在涵盖四个多模态任务领域的十一个基准上评估EpiCon，使用两种测试框架和多种骨干模型。即使仅进行一次求解尝试，冻结的经验库也能改进其他系统。第二个测试框架在十一个基准上将原始系统的宏平均分数提高了2.6分。在四种宿主配置下，EpiCon相比无记忆将宏平均分数提高了1.7至4.9分，并将记忆操作时间相对于骨干规模的记忆模型减少了67%至74%。

## Abstract
Agents can learn from past executions, but enabling different agents to reuse and build on one another's experience remains challenging. We introduce EpiCon, a shared multimodal memory framework for agent collective learning without updating host model parameters. EpiCon links question-level memory evolution to a persistent experience bank through two independently trained 2B models: a memory controller and a tree self-organizer. The controller jointly refines textual guidance and visual evidence across attempts and selectively includes visual memory. The self-organizer consolidates lessons hierarchically and retrieves experience and rules for new problems. We evaluate EpiCon on eleven benchmarks spanning four multimodal task domains, using two harnesses and multiple backbones. A frozen bank improves other systems even with a single solving attempt. A second harness raises the original system's macro-average score by 2.6 points across eleven benchmarks. Across four host configurations, EpiCon improves macro-average scores by 1.7 to 4.9 points over No Memory and reduces memory-operation time by 67\% to 74\% relative to backbone-sized memory models.

# EpiCon 论文深度总结

## 1. 核心问题与研究动机

- **背景**：基于语言模型的多智能体系统（MAS）在推理、工具使用和协作中会产生大量关于解题流程、失败模式和证据的经验。外部记忆使这些经验无需更新宿主模型参数即可影响后续推理。
- **核心痛点**：
  - 不同智能体之间难以**复用和积累**彼此的经验。
  - 现有多数智能体记忆以**文本为主**，忽略了图表区域、文档细节等视觉证据。
  - 经验教训可能依赖图像区域，且指导与证据需在多次尝试中**共同修订**。
  - 积累的经验需要**整合与检索**才能被后续任务复用。
- **研究目标**：构建一个**共享多模态记忆框架**，连接"问题级记忆演化"与"持久经验库"，使不同框架（harness）和骨干模型（backbone）的智能体能够互相复用和贡献经验，且**不更新宿主模型参数**。

## 2. 方法论

### 2.1 核心思想
EpiCon（Episodic Consolidation）由**专用记忆测试框架**与**两个独立训练的 2B 模型**组成：
- **记忆控制器 Cθ**：负责问题级文本与视觉记忆的协同演化。
- **树自组织器 Sϕ**：维护共享经验库，实现跨问题的经验整合与检索。

### 2.2 共享多模态记忆
- 维护独立于 MAS 的持久经验库 **B**，系统可从中检索指导，也可贡献新经验。
- 经验库更新公式：**B(k+1) = Sϕ(B(k), Uk)**，其中 k 为维护步数（非单条经验），Uk 为一批被接受的教训与修订。
- 评估阶段经验库**冻结**，更新仅限当前问题局部。

### 2.3 问题级多模态记忆演化
- 记忆表示为 **Wi,t = (M_text, M_vis)**：文本记录可操作指导、适用条件与警示；视觉记忆指向源图像中的支撑区域。
- 更新公式：**Wi,t = Cθ_update(Wi,t−1, xi, ŷi,t, τi,t)**，即基于上一状态、问题、图像、最新答案与执行轨迹联合提出修订文本、源图像与区域。
- **自适应视觉记忆注入**：通过门控 **gi,t ∈ {0,1}** 决定下次尝试是否纳入视觉记忆；门控不删除已存储的视觉记忆，原始任务图像始终可用。

### 2.4 共享经验整合与复用
- **树结构组织**：叶子存储问题特定教训，内部节点分组并总结相关经验。
- **维护操作**：Place（放置）、Merge（合并）、Split + Lift（拆分提升）、Consolidation（整合）。
- **规则抽象**：由支持度、失败、冲突和证据强度决定抽象层级与规则资格。
- **检索公式**：**Ri = Sϕ_retrieve(xi, Recall(xi, B))**，先用冻结文本编码器召回候选，再由自组织器选择适用规则、具体经验或"无适用项"。

### 2.5 训练细节
- 两个 Qwen3.5-2B 模型独立微调，采用 **LoRA（rank 16，scaling 32）**，冻结视觉编码器与对齐器。
- 训练配置：3 个 epoch，学习率 1e-4，最大序列长度 8192，每设备批大小 2，梯度累积 8 步。
- 检查点按验证损失选择：控制器第 1000 步，树自组织器第 258 步。

## 6. 主要结论与发现

- **性能提升**：骨干规模 EpiCon 在四种宿主配置下均取得最高 11 基准宏平均，超过最强外部记忆基线 1.9–5.9 分；2B 变体相比 No Memory 提升 1.7–4.9 分。
- **效率优势**：2B 模型将记忆操作时间减少 **67%–74%**，总时间减少 25%–35%，性能仅下降 0.9–3.6 分，位于帕累托前沿。
- **跨系统迁移有效**：冻结经验库在仅更换骨干或框架时分别带来 3.2 和 4.2 分的宏平均提升。
- **集体学习成立**：另一框架演化经验库后，原框架宏平均提升 2.1–3.2 分，8–9 个基准改善。
- **多模态协同演化有效**：演化视觉记忆优于冻结视觉记忆；自适应注入优于始终注入，并降低约 17%–25% 的 MAS 执行时间。
- **树结构优于扁平结构**：ParseBench 从 52.2 提升至 67.3，BabyVision 从 13.2 提升至 15.3。
- **强求解器泛化**：GPT-5.6-Luna 上四个基准全部提升，ParseBench 从 63.8 到 66.5。

## 7. 优点

- **方法创新性**：
  - 首次将**问题级文本-视觉记忆协同演化**与**跨系统共享经验库**统一在一个框架中。
  - 自适应视觉记忆注入机制在保留原始图像的同时选择性注入历史视觉证据，兼顾性能与效率。
  - 树结构 + 规则抽象实现了从具体教训到可复用规则的层次化整合。
- **工程效率**：两个 2B 小模型替代骨干规模记忆模型，显著降低记忆操作开销，具备实际部署价值。
- **实验严谨性**：
  - 单次尝试协议设计巧妙，隔离了"历史经验复用"与"多次尝试收益"。
  - 构建/评估集严格分离，ReasonMap 按地图划分防止泄漏。
  - 跨框架、跨骨干、跨求解器的多维度迁移验证了集体学习的通用性。
- **可复用性**：经验库独立于 MAS，冻结后即可被其他系统直接使用，无需重新构建。

## 8. 不足与局限

- **算力信息不透明**：未报告 GPU 数量、训练时长、总计算量，难以评估可复现性与成本。
- **树操作验证不足**：树组织演示仅通过 schema、节点引用、分区、来源等结构检查，**未经过下游 MAS 重放验证**，其实际有效性存疑。
- **性能不一致**：
  - BabyVision 结果波动大（−2.7 到 +4.8），ReasonMap 提升有限（+0.5 到 +1.9）。
  - 跨框架演化中部分基准出现下降（如 Codex 的 ParseBench 从 63.4 降至 58.9，DeepSeek-Harness 的 MATH-Vision 从 56.6 降至 53.4），说明经验迁移存在任务依赖性。
- **训练数据域覆盖有限**：监督数据仅来自视觉数学、文档理解、图表推理三个域，对通用视觉推理的泛化依赖迁移能力，缺乏针对性训练。
- **2B 模型性能差距**：相比骨干规模变体仍低 0.9–3.6 分，在追求极致性能的场景下可能不够。
- **应用限制**：
  - 经验库构建需要额外的构建题与 MAS 执行记录，冷启动成本未充分讨论。
  - 记忆库的长期维护、容量增长与冲突消解机制未深入探讨。
  - 仅评估了有限的开源骨干与两个框架，对闭源商业模型的适用性验证有限（仅 GPT-5.6-Luna 一组）。
