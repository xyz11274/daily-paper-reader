## 摘要
一个智能体今天能解决的任务，明天可能因新事实、新工具或新治理知识而面临相同任务。大多数智能体系统能够检索相关文本或回忆先前对话，但缺乏一种有原则的方式来判断先前的解决方案何时仍然有效、何时必须调整、何时应当丢弃。我们提出 CORTEX（Contextual Orchestration and Reuse of Task EXperience，任务经验的情境化编排与复用），这是一个通用人工智能系统框架，通过一个外部可验证经验层连接专用智能体。每个经验片段记录其任务条件、来源与工具状态、决定性谓词、证明轨迹、验证器和结果。元控制器选择精确重放、经检验的适配、全新综合或升级处理。被接受的经验片段可通过挑战驱动的开发循环成为任务模式和程序化策略。这为系统提供了一个隐式的能力层，无需改变模型权重即可增长。我们形式化了精确重放和源版本分离的系统契约，并推导了复用何时节省计算。一个受控的双领域实现测试了精确重放核心在1000个合成案例上的表现。完整族留出测试在八个临床和政策划分中的1000个新族案例上测试了程序化迁移，具有完整的新鲜证据基础和对于无关字段及插入顺序扰动的完美不变性。迁移轨迹揭示了经验证策略执行所需的工作。这些结果确立了通过可复用程序、类型化经验和发展性迁移走向通用智能的一条初始路径。

## Abstract
An agent can solve a task today and face the same task under new facts, tools, or governing knowledge tomorrow. Most agent systems can retrieve relevant text or recall prior conversations, but they lack a principled way to decide when a previous solution is still valid, when it must be adapted, and when it should be discarded. We introduce CORTEX (Contextual Orchestration and Reuse of Task EXperience), a general AI systems framework that connects specialized agents through an external layer of verified experience. Each episode records its task conditions, source and tool state, decisive predicates, proof trace, verifier, and outcome. A meta-controller chooses exact replay, checked adaptation, fresh synthesis, or escalation. Accepted episodes can become task patterns and procedural strategies through a challenge-driven development loop. This gives the system an implicit competence layer that can grow without changing model weights. We formalize system contracts for exact replay and source-version separation, and derive when reuse saves computation. A controlled two-domain implementation tests the exact-replay core on 1,000 synthetic cases. Complete-family holdouts test procedural transfer on 1,000 new-family cases across eight clinical and policy splits, with complete fresh-evidence grounding and perfect invariance to irrelevant-field and insertion-order perturbations. The transfer trace exposes the work required for verified strategy execution. These results establish an initial path toward general intelligence through reusable procedures, typed experience, and developmental transfer.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：智能体今天能解决的任务，明天可能因新事实、新工具版本或新治理规则而发生变化。现有智能体系统虽然能检索相关文本或回忆先前对话，但**缺乏一种有原则的机制**来判断：先前的解决方案何时仍然有效、何时必须调整、何时应当丢弃。
- **背景痛点**：
  - 单一前提变更、来源修订或权威机构变化，就可能把"有用的先例"变成"自信的错误"。
  - 现有能力（工具推理、角色协同、外部检索、反思纠错、经验/技能保存）通常由**非正式记忆**连接——系统记住了答案或计划，却没有携带使其正确的条件。
  - 检索增强生成（RAG）改善了对当前外部信息的获取，但只解决"当前证据"问题，未解决"过去推理是否仍可复用"的问题。
- **整体含义**：论文提出 CORTEX（Contextual Orchestration and Reuse of Task EXperience），将"通用智能"重新定义为**可靠任务能力的累积**——通过可复用程序、类型化经验和发展性迁移，在不改变模型权重的前提下增长能力。核心论点：系统可以通过把已完成工作转化为**已验证经验**，仅在显式条件下迁移该经验，并主动寻找测试当前任务模型边界的案例，从而获得更广泛的任务能力。

## 2. 方法论

### 2.1 核心思想
- 构建一个**外部、可查询的已验证经验层**（经验图），连接多个专用窄智能体；能力增长来自组件与外部经验的交互，而非新单体模型或未追踪的权重更新。
- 区分三种经验形式：
  - **Episode（经验片段）**：带输入、决策、检查与结果的完整任务。
  - **Pattern（模式）**：剥离偶然细节、保留决定性谓词。
  - **Strategy（策略）**：可跨任务族复用的过程（如"先解析生效日期再评估规则"）。
- 关键区分：模式只有在前提匹配时才能证成重复结论；策略可指导新搜索，但不能单独证成答案。

### 2.2 架构与关键组件
- **窄智能体（带类型化契约）**：source agent（注册不可变工件及范围）、interpreter（提出与精确文本跨度链接的结构化断言）、state agent（规范化事实，含缺失/冲突值）、planner、reasoner、verifier（检查身份、类型、适用性、逻辑、解释保真度）、experience steward（存储通过的轨迹并安排挑战）。
- **来源与环境注册表**：每个治理工件有摘要、声明范围、有效时间区间、获取时间与权威关系；区分"来源何时适用"与"系统何时得知"；检索文档只能提供证据，不能向智能体发出指令（限制提示注入）。
- **经验图**：存储任务族、选定来源与工具版本、决定性谓词签名、类型化输出、证明轨迹、验证器身份、不确定性状态与挑战状态；边连接经验到模式、策略、来源工件、反例与失效修订。
- **元控制器（Meta-control）**：四模式选择——**Replay（精确重放）**、**Adapt（受检适配）**、**Synthesize（全新合成）**、**Escalate（升级）**；按"最便宜的正当推理模式优先"顺序测试。

### 2.3 形式化契约与公式
- **任务实例**：z = (g, x, c, t, q)，成功响应为类型化包 F(z, S_t) = (y, ρ, u, a)，其中 y 为答案/动作，ρ 为带溯源的推导，u 为未解决条件，a 为处置（发布/请求更多信息/升级）。
- **三值逻辑**：原子谓词取值 {Y, N, U}，U 表示缺失、冲突或范围不足；采用强 Kleene 逻辑，缺失事实绝不静默置为假。
- **版本化规则**：r = (f, v, ι, p, o, I, π)，即族、版本、谱系标识、适用性谓词、输出、有效时间区间、溯源。
- **总差异分类器 Δ(B, C)**：在冻结事实快照下比较新旧适用性，输出 add / retire / modify / same / inapp / unk。
- **可采纳精确重放（Definition 1）**：要求经验活跃、来源解析器选出相同治理工件、所有来源/规则摘要与相关工具版本匹配、决策时间在记录治理区间内、验证器仍受信任、任务与输出类型一致、新谓词与输出上下文签名等于存储签名。该关系**严格强于语义相似度**。
- **命题 1（可靠精确重放）**：在局部可靠性假设下，可采纳精确重放产生与在选定确定性编码规则上全新评估相同的类型化逻辑决策，且带有效重放证明；但**不授权重放有副作用的动作**。
- **命题 2（版本分离）**：若每个当前断言必须通过要求活跃规则摘要等于决策时注册表摘要的门控，则仅由已失效旧版本支持的断言不能被发布为当前结论。
- **命题 3（复用何时节省工作）**：E[C_cold − C_warm] = p·E[C_f − C_r | H] − E[C_l]，即命中概率加权节省减去查找成本。
- **发展循环**：Solve → Verify → Abstract → Challenge → Update competence；候选模式由跨已接受经验识别共同决定性谓词归纳，候选策略由跨族仍有用的操作归纳，**频率本身不使其可操作**。
- **研究目标（式 4）**：在无支持发布概率 ≤ ε 约束下，最大化单位成本的能力覆盖增益；这是设计目标而非已观测的优化结果。

## 6. 主要结论与发现

- **精确重放核心有效**：经验核心与完整确定性评估器在 1,000 个合成案例上均与场景 oracle 完全一致，同时额外提供可复用轨迹与可采纳性结构。
- **消融证明必要性**：移除谱系降至 364/500 与 382/500；移除过期强制降至 409/500 与 399/500；混合版本检索降至 279/500 与 259/500。
- **复用节省计算**：热复用命中率临床 93.6%、政策 100%；平均规则节点评估从 33.88→12.688、52.072→15.836；但中位延迟冷热接近（31.93 vs 32.07 ms；7.62 vs 7.76 ms），说明查找与验证有成本，与命题 3 一致。
- **程序化迁移成立**：完整族留出中 100/100 案例完成角色轨迹、通过来源验证、匹配标签；跨域压力测试中 1,000/1,000 案例通过来源验证、完成通用轨迹、匹配标签，且对无关字段与插入顺序扰动**完全不变**。
- **策略条件工作更多**：迁移轨迹因记录经验与验证簿记而使用更多规则节点工作（45.00 vs 56.00；40.50 vs 52.75），中位延迟略高。
- **模型介导可行**：窄智能体试点中三种条件均匹配全部 4 个留出标签；暴露了 1 个畸形检查器响应与 1 个过度泛化记忆草稿，均被协议拒绝并纠正。
- **总体结论**：确立了通过可复用程序、类型化经验与发展性迁移走向通用智能的一条初始工程路径。
