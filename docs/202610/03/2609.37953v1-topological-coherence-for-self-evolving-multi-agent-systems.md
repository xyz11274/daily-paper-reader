## 摘要
复杂任务本质上耦合了工作流结构、智能体职责、协作与记忆访问：任务区域界定了职责与工具范围，跨区域依赖引发交接，而所有权边界则划定了私有与选择性共享的记忆。现有方法能够联合优化智能体与通信结构，但这种优化本身并不要求职责、交接与记忆边界与任务依赖保持一致。我们将这一要求称为拓扑一致性。我们提出 TOCOMAS，一种拓扑一致的多智能体系统。TOCOMAS 将任务图建立在工具接口之上，将兼容的任务节点组织为可复用的职责域，并推导出依赖驱动且受画像条件约束的协作，以及边界调控的记忆可见性。在在线自演化过程中，TOCOMAS 提出对智能体、协作与记忆策略的耦合变更，仅为后续任务保留满足结构约束并提升评估奖励的候选方案。在 BBEH、WorkBench、SWE-Bench-Verified 和 CoMemBench 上，TOCOMAS 在多种骨干模型上均较基线提升了任务成功率。CoMemBench 还显示，在已验证进展、交接与记忆隔离方面，其相较自演化基线有所提升。

## Abstract
Complex tasks inherently couple workflow structure, agent responsibility, collaboration, and memory access: task regions delimit responsibility and tool scope, cross-region dependencies give rise to handoffs, and ownership boundaries delimit private and selectively shared memory. Existing methods can jointly optimize agent and communication structures, yet such optimization does not by itself require responsibility, handoff, and memory boundaries to remain consistent with task dependencies. We term this requirement topological coherence. We introduce TOCOMAS, a Topology-Coherent Multi-Agent System. TOCOMAS grounds a task graph in tool interfaces, organizes compatible task nodes into reusable responsibility domains, and derives dependency-induced and profile-conditioned collaboration together with boundary-regulated memory visibility. During online self-evolution, TOCOMAS proposes coupled changes to agent, collaboration, and memory policies, retaining for subsequent tasks only candidates that satisfy structural constraints and improve evaluated reward. Across BBEH, WorkBench, SWE-Bench-Verified, and CoMemBench, TOCOMAS improves task success over baselines across backbones. CoMemBench also shows gains over the self-evolving baseline in verified progress, handoffs, and memory isolation.

## 1. 核心问题与整体含义

- **研究背景**：基于大语言模型的多智能体系统（MAS）已成为组合专业化推理、工具使用与交互策略的通用框架。CAMEL、AutoGen、MetaGPT、ChatDev 等系统使复杂任务变得可及，但也将"组织设计"推向了核心位置——系统必须决定每个智能体拥有哪些任务区域、可访问哪些工具与信息、何处需要验证、局部输出如何组合为全局可执行流程。
- **现有方法的不足**：近期工作已能自动搜索计算图、智能体程序或工作流，甚至联合演化智能体角色、提示、模型、工具与通信拓扑（如 EvoMAS）。然而，**任务工作流、智能体职责、协作与记忆仍是分别表示的结构**，缺乏显式约束来保证它们在系统变化过程中保持关系兼容。
- **核心问题**：现有联合优化本身并不要求职责、交接与记忆边界与任务依赖保持一致，导致结构错配。
- **核心概念——拓扑一致性（Topological Coherence）**：不是图结构形状的相似性，而是各层从任务拓扑中推导出的关系之间的一致性。具体表现为：职责区域有胜任的所有者、必需的跨区域依赖有兼容的交接、记忆可见性尊重相同的所有权边界。
- **整体含义**：论文提出 TOCOMAS（Topology-Coherent Multi-Agent System），将拓扑一致性作为贯穿组织与自演化的结构约束，为自演化多智能体系统提供了一种新的组织原则。

## 2. 方法论

### 2.1 核心思想
- 智能体组织、协作与记忆**不应作为独立的配置选择来设计**，而应从共同的任务拓扑中推导出来，并在系统演化过程中被联合筛选。
- 任务拓扑本身提供了共同的组织参照：任务区域界定职责与工具范围，跨区域依赖产生交接与可选验证，所有权边界界定私有与选择性共享的记忆。

### 2.2 关键技术细节

- **问题形式化**：MAS 由配置 C = (G, A, Vin, Vout) 指定，其中 G 为智能体间有向通信图，A 为智能体配置集合（含骨干模型、提示、可访问工具集）。给定任务 q 及其任务图 Tq = (Uq, Dq)，工具锚定的可执行拓扑为 Hq = (Uq, Dq, Ψq)。任务条件配置为 Cq = (C, Hq, πq, ϕq, Λq, Mq)。
- **拓扑一致性定义**：当职责区域有胜任的所有者、必需的跨区域依赖有兼容的交接、记忆可见性尊重相同的所有权边界时，称 Cq 是拓扑一致的。

### 2.3 四大模块

- **模块一：拓扑智能体组织**
  - **任务拓扑与职责商**：将任务图 Tq 通过映射 Ψq 锚定到公共工具图 K 上，为每个节点选择最小有效工具包 Γ(u)，受能力覆盖、边语义兼容、副作用约束与提供者连续性约束。通过满射 πq: Uq → Sq 将操作兼容的节点分组为职责区域，收缩区域得到商拓扑 Hq = Hq/πq。区域合并仅当商拓扑保持无环时才可接受。节点对兼容性剖面 aq(u,v) 包含工具重叠、输入输出兼容、依赖邻接与语义相似度四个分量。
  - **能力锚定的所有权**：所有权映射 ϕq: Sq → Vq 要求区域所需能力 Γ(S) 是智能体可用工具 ΓA 的子集。映射不必是单射——一个智能体可拥有多个兼容区域，结构或操作上不同的区域则分配给不同智能体。若无现有智能体覆盖某区域，智能体池提供新的专业化智能体。智能体角色由任务拓扑中的职责域定义，而非预制文本标签。

- **模块二：结构自适应协作编排**
  - 将跨区域任务依赖推过所有权映射，得到任务执行所需的通信边 Ereq_q。
  - 运行时协作拓扑 Gq 结合依赖诱导边与画像条件空间边 Esp_q（由智能体画像相似度、查询相关性、工具输入输出互补性构建，可自适应剪枝）。
  - 局部执行与边界感知交接：zi = Aϕq(Si)(q|Si, Γ(Si), Mvis_q(Si), {hji})，交接 hij = Route_ij(zi; ξij) ∈ {ρij(zi), ∅}，其中 ρij 仅暴露下游区域所需的工件，必要时触发验证器请求。

- **模块三：边界保持的记忆协调**
  - 每条记忆记录关联其产生智能体、任务区域与来源。职责拓扑诱导可见性策略 Λq，决定哪些私有记录与准入边界证据可供区域使用：Mvis_q(Si) = Filter_Λq(Mq; Si)。
  - 过滤器首先执行所有权与边界权限，语义检索随后仅对可准入记录排序。检索先选种子，再通过类型化图扩展重建区域上下文：Rq(Si) = Expand_L(Seed_k(q|Si, Mvis_q(Si)); Mvis_q(Si))。语义相关性可对可准入记忆排序，但不能覆盖其所有权或共享边界。
  - **所有权变更时的记忆迁移**：若区域 S 被重新分配，其私有记忆随区域迁移，保留来源并更新访问权限，防止经验孤立与意外全局共享。

- **模块四：一致性约束的结构演化**
  - 结构投影 Ωq = Struct(Cq) = (πq, ϕq, Gq, Λq)。Λq 是由职责商诱导的记忆准入、可见性、检索与迁移策略；具体记录 Mq 是运行时状态，不是演化配置中的基因。
  - 演化步骤 t：执行反馈 τq(t) 与累积经验 E(t) 引导结构提案 Ω̃q(t+1) = Propose(Ωq(t), τq(t), E(t))。提案可仅改变部分策略；若改变任务区域所有权，编译过程需将必需交接与记忆权限与新边界协调。
  - **单一结构筛查**：检查每个任务节点有唯一胜任所有者、必需跨区域交接与记忆可见性尊重诱导边界。有效候选被执行，仅当奖励超过父代时才被接受：Ωq(t+1) = Ω̃q(t+1)（若有效且被接受），否则保持 Ωq(t)。被接受的组织可供后续任务使用，执行轨迹为后续提案提供信息。

- **消融揭示各机制的独立贡献**：
  - 拓扑智能体组织：替换为规范顺序分组使 VNCR 下降 14.33 点，表明职责放置比工具可用性更重要。
  - 结构自适应协作编排：替换为固定前驱交接使 VHS 下降 40.85 点、SR 降至零，暴露消费者边界断裂的代价。
  - 边界保持记忆协调：使所有已验证记录全局可见使 ICS 下降 19.96 点，表明记录有效性不等于其应属于智能体上下文。
  - 一致性约束结构演化：保持固定结构使 WorkBench SR 下降 6.52 点。
- **参数敏感性**：组织亲和度在 0.60 时 VNCR 与 VHS 达峰（41.6%、51.3%），过高（0.75）或过低（0.30）均下降；记忆检索预算 k=3 时达峰，扩展至 k=8 反而下降。倾向于有界的任务区域与记忆范围，而非最大化分组或检索。
- **成本分析**：WorkBench 上 TOCOMAS 曲线低于 Peer Review 与 SMoA，高于 Direct LLM Call 与 ADAS；CoMemBench 上在多数共享进展水平低于其他多智能体曲线。将兼容任务节点分组使依赖内化于智能体，交接仅在跨区域边出现，投影工件与边界过滤检索限制了下游上下文，从而在不抑制已验证进展的前提下降低协调开销。
