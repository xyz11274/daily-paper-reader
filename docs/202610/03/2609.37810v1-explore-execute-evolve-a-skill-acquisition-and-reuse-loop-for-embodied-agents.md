## 摘要
视觉-语言-动作模型和世界-动作模型在机器人领域已展现出令人印象深刻的能力，但泛化到未见任务仍然具有挑战性。最近，通用多模态智能体在零样本机器人任务求解方面展现出巨大潜力。然而，它们通常通过从零开始推理和探索物理世界而产生高昂的执行成本。为了降低这些成本，我们提出了RoboSkill，一个通过“探索、执行、进化”闭环连接技能获取与复用的框架。在该闭环中，智能体进行探索以收集任务相关信息，在执行任务的同时适应反馈，并基于执行记录进化其技能库。随后，它复用这些技能来指导下一循环中的探索与执行，从而闭合环路。为提高闭环效率，我们以触觉反馈补充视觉，以减少物理交互过程中的不确定性。我们进一步用可复用代码增强文本指导，以减少技能复用期间的推理开销。在LIBERO-10上，RoboSkill在四个智能体上将首回合成功率提高了12.5至25.0个百分点，并将平均运行时间减少了7.6%至72.4%。在真实机器人上，它将成功率提高了8.3个百分点，并将成功试验的平均运行时间至少减少了14.4%。

## Abstract
Vision-language-action and world-action models have demonstrated impressive capabilities in robotics, yet generalization to unseen tasks remains challenging. More recently, general-purpose multimodal agents have shown great potential for zero-shot robotic task solving. However, they often incur high execution costs by reasoning and exploring the physical world from scratch. To reduce these costs, we introduce RoboSkill, a framework that connects skill acquisition and reuse through an Explore, Execute, Evolve loop. Within this loop, the agent explores to gather task-relevant information, executes tasks while adapting to feedback, and evolves its skill library based on execution records. It then reuses these skills to guide exploration and execution in the next cycle, closing the loop. To improve loop efficiency, we complement vision with tactile feedback to reduce uncertainty during physical interaction. We further augment textual guidance with reusable code to reduce reasoning overhead during skill reuse. On LIBERO-10, RoboSkill improves first-episode success rates by 12.5--25.0 percentage points and reduces average runtime by 7.6--72.4% across four agents. On real robots, it improves success rates by 8.3 percentage points and reduces average runtime for successful trials by at least 14.4%.

## 1. 核心问题与研究动机

- **背景**：视觉-语言-动作模型（VLA）与世界-动作模型（WAM）在机器人控制上已具备快速执行能力，但**泛化到未见任务仍然困难**，其能力主要受限于训练数据与任务分布。
- **新趋势**：通用多模态智能体（如基于大语言模型的机器人智能体）展现出零样本任务求解潜力，但代价高昂——每次执行几乎**从零开始**，需要重复感知、物理试错与失败恢复。
- **核心矛盾**：软件环境（Web、GUI、编程）中的智能体可将交互历史蒸馏为可复用技能，但**物理交互具有部分可观测、场景动态变化、具身约束相关、执行结果不确定**等特性，简单回放固定计划无法奏效。
- **研究目标**：构建一个连接**技能获取与技能复用**的闭环框架，让智能体在物理世界中积累经验、复用技能，从而降低执行成本、提升任务成功率与效率。

## 2. 方法论：RoboSkill 框架

### 2.1 核心思想
- 提出 **Explore–Execute–Evolve（探索–执行–进化）闭环**：
  - **探索**：收集任务相关信息（如物体高度、空间关系）。
  - **执行**：在反馈中适应性地完成任务。
  - **进化**：将执行记录固化为技能包，指导下一轮探索与执行。
- 两个关键设计增强闭环效率：
  - **触觉反馈**（压力/力/力矩信号）补充视觉，降低物理交互不确定性。
  - **可复用代码**增强文本指导，减少技能复用时的推理开销。

### 2.2 关键技术细节

- **探索（Exploration）**
  - 将“获取缺失信息”视为探索子任务，围绕与主任务相同的执行-反馈流程组织。
  - 探索本身可嵌套循环（如抓取失败 → 探索桌面高度 → 通过接触验证 ≈0.446 m → 恢复抓取）。
  - 探索发现保留在会话上下文中，或由智能体作为“自我审查者”整合为技能包。

- **闭环执行（Closed-loop Execution）**
  - 上下文包含：任务指令、机器人控制/感知 API 规范、探索知识、选中的技能包。
  - 观测：RGB + 深度 + 触觉反馈，通过 API 调用获取。
  - 提供 **SDK 而非固定工具**，使智能体可组合 SDK 调用与数据处理，构建可复用代码（如 `depth_pointcloud.py`、`verify_table_height.py`）。
  - 记录交互与执行代码，作为进化阶段的输入。

- **进化（Evolution）**
  - 时机：任务结束时统一审查，避免每个子任务后审查带来的开销。
  - **技能包三要素**：
    - **文本指导**：任务策略、适用条件、失败教训。
    - **可复用代码**：层次化组织的可执行程序。
    - **支撑记录**：失败案例、完整执行轨迹、元数据（描述 + 视觉关键帧）。
  - 若已有对应技能则补充更新，否则新建技能包。
  - **技能使用**：智能体根据元数据选择最多 K=3 个相关技能包，放入新任务工作区。

### 2.3 算法流程（文字描述）
1. 接收任务指令、选中技能、SDK 环境访问权限。
2. 若信息不足 → 执行探索子任务，获取任务知识。
3. 结合知识与技能生成并运行代码，调用 SDK 执行动作、获取观测。
4. 根据反馈继续或修正执行。
5. 智能体决定结束时进入进化阶段，审查会话记录与执行代码，构建/更新技能。
6. 技能指导下一轮探索与执行，闭环完成。
