## 摘要
递归自我改进（RSI）让系统能够从自身结果中改进；在基于大语言模型的多智能体系统中，智能体在任务内相互精炼，而结果则改进它们跨任务的协作方式。然而，现有多智能体协作使这一循环保持开放：协作在操作者层面预先定义，仅拓扑学习保留逐字交换从而传播错误，且对系统自身结果的奖励最大化集中于少数团队。为应对这些挑战，我们提出 CollabFlow，一个学习型智能体协作的 RSI 系统：可训练的 Collab-Director 构建由完整智能体组成的团队，冻结的执行器运行它们，每一轮的结果重新训练该 director。在每一轮内，协作图的边承载证据条件通信协议：仅当发送方的证据以一定幅度更强时，接收方才采纳不同的答案，因此 director 学习谁通信以及如何通信。跨轮次，我们进一步提出协作轨迹平衡（CTB），一种基于流的目​​标，在其构建顺序上对每个团队仅计入一次，并以与奖励成比例的团队分布为目标，从而使多个优秀团队保持参与。我们还界定了这一自生成目标在轮次之间的移动幅度，该幅度随记录积累而缩小。在十二个数据集上，CollabFlow 优于所有基线，并在各轮次中持续改进。代码见 https://anonymous.4open.science/r/CollabFlow-631E。

## Abstract
Recursive self-improvement (RSI) lets a system improve from its own outcomes; in LLM-based multi-agent systems, Agents refine one another within a task, and outcomes improve how they collaborate across tasks. However, existing multi-agent collaboration leaves this loop open: collaboration is pre-defined at the operator level, topology-only learning keeps verbatim exchange that propagates errors, and reward maximization on a system's own outcomes concentrates on a few teams. To address these challenges, we propose CollabFlow, an RSI system of Learned Agent Collaboration: a trainable Collab-Director constructs teams of complete Agents, a frozen executor runs them, and each round's outcomes retrain the director. Within each round, the edges of a collaboration graph carry protocols of Evidence-Conditioned Communication: a receiver adopts a differing answer only when the sender's evidence is stronger by a margin, so the director learns who communicates and how. Across rounds, we further propose Collaborative Trajectory Balance (CTB), a flow-based objective that credits each team once across its construction orders and targets a reward-proportional distribution over teams, so several good teams stay in play. We also bound how far this self-generated target moves between rounds, which shrinks as records accumulate. On twelve datasets, CollabFlow outperforms all baselines and keeps improving across rounds. Code is available at https://anonymous.4open.science/r/CollabFlow-631E.

- **递归自我改进（RSI）的系统化问题**：RSI 指系统从自身产出中改进自身，已成为一个具体的系统工程问题。基于 LLM 的多智能体系统是 RSI 的天然场景——智能体在任务内相互精炼答案，每次交互都留下执行结果，理论上可形成"任务内通信改进 + 跨任务协作方式改进"的双层自改进循环。
- **现有协作范式使循环保持开放**，具体存在三个断点：
  - **预定义的操作者级协作**：现有编排方法为单一执行器组合算子，或预先固定角色与消息路由，智能体本身从未成为通信单元。

- **整体含义**：论文提出 CollabFlow，将"智能体协作本身"作为递归自我改进的对象，联合更新团队成员、连接关系与边协议，在显式预算下实现闭环自进化。

## 2. 方法论：核心思想与关键技术细节

### 2.1 总体架构：Director–Executor 范式

- **可训练的 Collab-Director（πθ）**：负责构建团队（选择智能体、边、协议、输出规则），是每轮唯一被更新的对象。
- **冻结的执行器（Kχ）**：运行团队中的智能体，其参数与智能体群体在训练中保持不变。
- **关键解耦（式 6）**：系统输出分布的变化完全来自 director 构建的团队分布 μθ^V，而非执行器或智能体的更新。

### 2.2 团队构建（Collaboration Graph）

- 协作图 G = (V, E, o)：V 为完整智能体（含不可变画像：角色、工具、继承权限），E 为带协议标签的边，o 为输出规则。
- 协议注册表 P = {FINAL ONLY, ONE WAY, INTERACTIVE}；有状态任务中恰好选择一个有写权限的 Executor。
- **合法动作集采样（式 5）**：director 仅在通过构建检查的合法动作集 Uc(vt) 上采样并重归一化，因此不存在被拒绝的提议；动作包括加智能体、加边、绑定技能、设输出、停止，超时或预算耗尽返回显式中止 †。
- **规范化（Canonicalization）**：仅序列化顺序不同的历史被合并到同一吸收节点 gG，使一个团队的所有构建顺序共享同一执行预留与奖励快照。

### 2.3 消息级改进：证据条件通信（Evidence-Conditioned Communication）

- **证据评分**：智能体 v 的得分 ℓv = max{w(e)}，其中 w=2 表示通过可执行检查，w=1 表示检索支持，否则为 0；证据与候选版本绑定，复制不产生新验证事件。
- **证据门控更新（式 7）**：对答案不同的有向更新 i→j，比较证据差 Δ = ℓi − ℓj 与边际 κ：
  - Δ > κ：采纳发送方答案 ai；
  - Δ < −κ：保留接收方答案 aj；
  - |Δ| ≤ κ：执行一次有界、无工具的修订 Revise。
- **κ = 1 的选择**：由于分数取值 {0,1,2}，κ=1 是唯一能在两级差距上采纳、在一级差距上修订的整数边际；自报置信度不进入 Δ。
- **协议决定门控次数**：FINAL ONLY 无门控，ONE WAY 一次门控，INTERACTIVE 交替方向的有上限门控，遇一致或决定性更新即停。
- **可度量的危害（式 9）**：正确接收方被翻转的概率 = 误采纳率 δC + P(J|C)·修订错误率 cJ，为消融实验提供了可分解的量化依据。
- **单写者约束**：有状态任务中仅 Executor 可写，Advisor 通过其下一次决策起作用，内部写操作串行化。

### 2.4 团队级改进：协作轨迹平衡（CTB）

- **基础**：建立在生成流网络（GFlowNet）与轨迹平衡（TB）之上，但**以完整智能体团队为被评分对象**——一个团队的所有构建顺序终结于同一规范化终端，因此团队只被记一次功。
- **路径核**：前向核为式 5 的合法集策略；学习到的后向核 bφ 仅在规范化终端起作用，通过逐步移除组件在一个团队的构建顺序 O(G) 上归一化，决定信用如何在顺序间分配（均匀核 1/|O(G)| 为消融对照）。
- **平衡条件（式 10）**：log Zψ + Σ log pF = β log rG + Σ log bφ，对每条有效完整路径成立。
- **训练损失（式 11）**：长度归一化的残差平方 (ρTB/T)² + KL 近端惩罚（πref 为采集该批次的 director，类比 TRPO/PPO），长度归一化不改变零残差解。
- **奖励比例目标（式 12）**：精确平衡下 μθ^V(G) ∝ rG^β，每个正奖励团队都保留概率（例如奖励 0.6/0.4/0.2 对应概率 1/2、1/3、1/6），而奖励最大化会把全部质量放在第一个；近似平衡下总变差误差 ≤ tanh(η/2)。
- **自生成团队奖励（式 13）**：奖励 = 答案分数 × Jeffreys 平滑后验成功率 × 最小描述长度结构先验，无调参权重；计数器在批次后按唯一结果各加一次，因此每轮生成下一轮的目标。
- **目标漂移界（Corollary B.22）**：相邻轮次目标的总变差移动有界，且随采样团队记录积累而缩小。

1. 冻结资源上下文、批次前计数器与奖励码版本；
2. 对每个采样任务做 N 次 rollout：从合法动作核采样构建团队，记录所有转移、停止与中止的对数概率；

## 6. 主要结论与发现

- **IID 全面领先**：CollabFlow 在每个 IID 数据集与指标上均领先，平均高出最强基线 2.27 EM 与 4.37 准确率点，所有平均增益在 p < 10⁻² 显著；SFT/GRPO 最多给骨干加 5.5 点，而学习到的团队加 33.3 点。
- **OOD 优势扩大**：除 HumanEval 与 AFlow 打平外全部领先，EM 领先 3.51、F1 领先 4.22，而微调对骨干的移动不足 1 个准确率点。
- **跨执行器可迁移**：提升全部 6 个其他冻结执行器的 IID/OOD 平均分，弱执行器增益更大（IID 中 Pearson r = −0.96），将执行器间 IID 差距从 23.3 点缩小到 9.3 点。
- **消融结论**：去通信代价最大；去 director 训练损失 13.7 IID / 19.5 OOD 点，其中递归贡献 7.6 / 13.6 点；逐字交换、强制修订、全 ONE WAY 在 IID 损失 5.5–9.8 点但在 OOD 损失 14.3–15.6 点，说明分布偏移下危害更大。
- **CTB 优于奖励最大化**：在匹配 rollout 与奖励下，CTB 在全部团队级指标上优于 GRPO、PPO 与无 CTB 版本，团队分布移动最小（TV=0.0937 vs 0.15–0.16），找到 26 条不同成功路径（对照最多 15 条），训练准确率 25 步内超过 0.80。
- **递归增益可持续**：在 20 个最大单步增益的演化步中，任务成功率从 34.4% 升至 75.0%，15 步在 5 步后仍保持领先，承载 83.6% 的 55 次技能编辑。
- **成本最低**：每项 token 最少且波动最小。

## 8. 不足与局限

- **算力披露缺失**：未报告 GPU 型号、数量、训练时长与总计算量，影响复现成本评估。
- **有界 RSI 而非开放式**：答案评估器、执行器、智能体群体与更新规则跨轮固定，仅 director（含后向核与归一化器）、技能库与可靠性记录变化；不学习更新规则本身或评估器。
- **表示能力受限**：受固定智能体群体、协议集、输出模式与资源上限约束；构建覆盖性仅相对于该可容许空间，不保证每个任务都存在有能力完成它的智能体。
- **证据规则的脆弱性**：条件更新用固定规则比较工具与检索支持，真实但不完整或误导性的证据仍可能支持错误候选；伪造事件记录被认证契约排除，但接受伪造即构成契约违反。
- **可靠性估计可能失准**：稀疏或非平稳执行下的可靠性估计未必校准；有限训练不保证达到固定条件下证明的精确终端分布。
- **单写者设计的边界**：仅防止内部写者冲突，不保证计划正确、观测新鲜、动作语义安全或与外部参与者一致。
