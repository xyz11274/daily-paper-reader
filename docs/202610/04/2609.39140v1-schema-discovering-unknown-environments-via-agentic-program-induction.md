## 摘要
在规则未知的不熟悉环境中学习完成任务，仍然是LLM智能体面临的关键挑战。当前的LLM智能体通常以散文形式记录其发现，这可能无法对环境的工作原理提供紧凑、明确的描述。受科学家如何将观察组织成可检验、可预测的理论的启发，我们提出了Schema，一种通过交互式程序归纳来组织学习与行动的智能体框架。LLM智能体决定研究什么以及如何行动，将其对环境不断演变的理解表达为可执行程序。该框架由一个持久程序工作区以及一小组接口组成，用于根据交互历史检查这些程序、在其中进行规划，并在逐步验证下执行计划。在相同基础模型下，Schema将ARC-AGI-3 RHAE从58.7%提升至99.2%，解决了100%的公开DiG-bench游戏，并在MazeBench上达到前50名人类玩家的中位表现。广泛的分析表明Schema在未知机制发现方面的有效性，消融实验证实了每个组件的贡献。

## Abstract
Learning to complete tasks in unfamiliar environments with unknown rules remains a key challenge for LLM agents. Current LLM agents often record their discoveries in prose, which may not provide a compact, explicit account of how the environment works. Inspired by how scientists organize observations into testable, predictive theories, we introduce Schema, an agent harness that organizes learning and action through interactive program induction. The LLM agent decides what to investigate and how to act, expressing its evolving understanding of the environment as executable programs. The harness consists of a persistent program workspace and a small set of interfaces for checking these programs against the interaction history, planning within them, and executing plans under step-by-step verification. Schema raises ARC-AGI-3 RHAE from 58.7% to 99.2% with the same base model, solves 100% of the public DiG-bench games, and reaches the median performance of the top-50 human players on MazeBench. Extensive analysis shows the effectiveness of Schema in unknown mechanism discovery, and ablations confirm the contribution of each component.

## 1. 核心问题与整体含义

- **研究动机**：现代 LLM 智能体在规则明确、流程已知的任务（如编程竞赛、SWE-bench、OSWorld）上表现优异，但在**规则未知、目标未定义的不熟悉环境**中仍显著落后于人类。例如 ARC-AGI-3 官方 basic harness 下最强模型 RHAE 仅约 30%，DiG-bench 最强模型整体胜率 71.4%、最难两层仅 40%。
- **核心症结**：现有智能体多以**散文（prose）形式**在上下文窗口或可编辑记忆中记录发现。随着上下文压缩与记忆重写，这些散文会退化，导致智能体在复杂新环境中"迷失方向"，无法形成持久、可复用、可验证的环境模型。
- **核心洞察**：人类通过观察、实验、推理发现机制，并抽象为**显式、可复用、可迁移的理论**（如科学理论）。受此启发，论文主张智能体应以**可执行程序**这一形式化语言来表达对环境的理解。
- **整体含义**：论文提出 **interactive program induction（IPI，交互式程序归纳）** 范式，并构建 **Schema** 框架，首次在未知环境中实现人类水平的机制发现，将"学习—验证—规划—行动"统一到一个持续演化的可执行程序之上。

## 2. 方法论

### 2.1 核心思想
- 将智能体对环境的理解编码为**可执行程序 P**，该程序同时充当环境模型（预测下一观测）与模拟器（用于规划）。
- 程序持久保存于工作区，跨轮次、跨关卡、跨上下文压缩存续。
- LLM 保持冻结，仅通过工具接口决定"研究什么、如何行动"，控制权完全交给智能体。

### 2.2 任务设定与形式化
- 环境有潜在状态 $s_t$，智能体观测 $o_t$，选择动作 $a_t \in \mathcal{A}$，环境按未知转移函数 $s_{t+1}=T(s_t,a_t)$ 演化，并返回 $o_{t+1}$ 与任务反馈。
- 未知的 $T$ 与完成谓词 $G$ 共同定义环境机制；智能体累积交互历史 $H_t=((o_i,a_i,o_{i+1}))_{i<t}$。
- 目标：以尽可能少的交互完成任务（动作既推进任务，也提供机制证据）。

### 2.3 程序归纳背景
- 程序归纳寻找与输入-输出样例集 $D$ 一致的可执行程序 $P$。
- 采用**反例引导的归纳合成**：合成器提出候选，验证器检查并返回反例，反例加入 $D$ 约束下一候选，同时保留已有证据。
- 在环境学习中，动作结果即为样例，动作选择本身成为归纳过程的一部分。

### 2.4 Schema 的四个基本操作（IPI 实例化）

- **Hypothesize（假设）**：将机制编码为程序 $P$，含两部分：
  - *状态接地*：构建对象、属性、关系的结构化表示及跨步信息；
  - *转移规则*：编码动作与对象交互的效果。
  - 统一预测接口：$(\hat{o}_{t+1}, z_{t+1}) = P(z_t, o_t, a_t)$，其中 $z_t$ 为程序内部状态。
  - 工具：文件管理工具（读写、编辑、搜索工作区）、`read_history`（按关卡/索引/范围/事件类型检索历史）。

- **Certify（认证）**：通过重放交互历史检查程序一致性。
  - 失配集：$M(P,H_t)=\{i<t:\hat{o}^P_{i+1}\not\simeq o_{i+1}\}$；
  - 一致性判据：$\mathrm{Cert}(P,H_t)\iff M(P,H_t)=\varnothing$。
  - 工具：`backtest`（重放并报告失配索引、预测值与观测值）、`model_predict`（行动前检查单步预测）。
  - 每次修订都重检全历史，使发现累积为连贯程序。

- **Plan（规划）**：同一预测接口使 $P$ 成为模拟器，可无环境代价地 rollout。
  - 智能体指定目标谓词 $g$（任务完成、中间路点、或可测试未解机制的情境），选择搜索过程 $\sigma$ 与预算 $b$：
    $\pi \leftarrow \mathrm{Search}_\sigma(P, z_t, o_t, g; b)$，$\pi=(a_t,\dots,a_{t+k-1})$。
  - 支持内置 BFS/DFS/A*/贪心，也可自行编写搜索代码；可调深度、节点上限、运行时间。

- **Act with Verification（带验证执行）**：受模型预测控制启发。
  - 提交动作序列，逐步执行；每步先取预测，执行后追加转移至 $H_t$。
  - 预测与观测一致则继续（无需再次调用 LLM）；**首次失配即丢弃剩余动作**，将意外转移返回给智能体。
  - 任务事件（过关/失败）也交还控制权。

### 2.5 算法流程（文字描述）
1. 智能体观察当前状态，调用文件工具编写/修订程序 $P$；
2. 用 `backtest` 对全历史认证，若失配则据反例修订；
3. 认证通过后，指定目标与搜索过程，在 $P$ 内搜索得到计划 $\pi$；
4. 提交计划，逐步执行并验证预测；
5. 若失配，中断执行，返回新证据，回到步骤 1 修订程序；
6. 循环直至任务完成或预算耗尽。

## 3. 实验设计

### 3.1 数据集 / 场景与 Benchmark

- **ARC-AGI-3**：25 个公开游戏、183 个关卡，64×64 彩色网格，最多 7 个动作，机制与目标需交互发现。主指标 **RHAE（相对人类动作效率）**，结合关卡完成度与相对首次人类玩家的动作效率，后期关卡权重更高，超出人类动作数有二次惩罚。
- **DiG-bench**：70 个文本游戏、7 个难度层，观测为字母/数字/符号字符串，动作是单个字符，转移规则与胜利条件均需推断；生命与步数预算有限，部分游戏有 creative mode 供实验。实验覆盖全部 21 个公开游戏。
- **MazeBench**：3D 探索解谜环境，256 个互联房间、100 颗宝石，含升降机、桥、弹簧、地毯、冰面等机制；使用 ASCII track，11 个动作。以收集宝石数与访问房间数衡量，参照官方排行榜前 50 名人类中位数。

### 3.2 对比方法

- **Basic harness**：官方 ARC-AGI-3 基础框架，无辅助工具。
- **Coding harness**：Claude Code（Claude 模型）或 Codex（GPT 模型），允许持久笔记与代码/shell 执行。
- **Schema**：本文方法，使用相同基础模型。
- **消融变体**：prose model（用散文替代可执行程序）、w/o certification、w/o planning、w/o verification。

### 3.3 基础模型配置

- ARC-AGI-3：Claude Opus 4.8、Claude Fable 5、GPT-5.6 Sol（xhigh 与 max 两档推理努力）。
- DiG-bench：GPT-6 Astra（medium/high/max 三档推理努力）。
- MazeBench：GPT-6 Astra，对比 Codex（GPT-6 Astra、GPT-5.6 Sol）与 Claude Code（Opus 5）。

## 6. 主要结论与发现

- **ARC-AGI-3**：Schema 将 RHAE 从 basic harness 的 1.2–20.2% 提升至 86.1–99.2%；相对 coding harness 提升 34.4–40.7 个百分点。Fable 5 下达 99.2%，Sol max 下达 96.7%，Opus 4.8 下达 86.1%。Fable 5 与 Sol max 通关全部 25 个游戏；Fable 5 用人类 57% 的动作数通关全部 183 关。
- **DiG-bench**：Schema 在 medium/high/max 下分别通关 19/20/21 个游戏（basic harness 为 11/16/19）；最难两层（6–7）max 努力下胜率从 66.7% 升至 100%；medium 努力下生命损失从 96 降至 34；每通关关卡成本低约 15%。
- **MazeBench**：36 小时内收集 33 颗宝石、访问 139 个房间，**超过前 50 人类中位数**（29% 宝石、53.5% 房间）；相同动作数下优于 Codex；10,000 动作后仍保持更高棋盘新颖度（54% vs 40%）。
- **消融结论**：移除任一组件（程序表示、认证、规划、验证）RHAE 从 72.9% 降至 52.4–62.3%，四者均有实质贡献。
- **知识累积**：约 20,000 动作时程序 2,012 行非注释代码，远少于散文变体的 6,133 行笔记；每行解释的转移数与函数调用点均上升，前向预测精度保持高位。
- **跨上下文压缩复用**：冰面滑动规则在约 2,600 动作学到，约 25,000 动作后（≥20 次上下文压缩）在新房间 NxE 复用，A* 找到 38 步路线且全部预测匹配。

## 7. 优点

- **范式创新**：将"可执行程序"作为智能体学习的持久中心对象，区别于散文记忆与反思式方法，提供紧凑、可验证、可复用的知识表示。
- **闭环设计完整**：假设—认证—规划—验证四操作形成完整闭环，认证重放全历史确保新修订不破坏旧发现，验证执行避免错误计划浪费动作。
- **智能体自主性**：不同于 WorldCoder/CWM 等预设学习流程的方法，Schema 将模型修订、实验设计、规划的控制权完全交给 LLM，适应状态接地、转移规则、目标均未知的场景。
- **实验扎实**：跨三类异构环境、多种基础模型、含消融与重复运行，且与人类基线直接对比，说服力强。
- **成本意识**：报告 token 成本并显示 Schema 在 DiG-bench 上更经济，兼顾性能与实用性。
- **长时程验证**：MazeBench 36 小时、27,819 动作的长跑证明方法在极端长时程下仍能持续累积知识。

## 8. 不足与局限

- **算力信息缺失**：未报告 GPU 型号、数量或训练时长；虽为冻结模型推理，但缺少推理总算力/总 token 的完整披露，复现成本难以精确估计。
- **MazeBench 单次运行**：仅一条 Schema 轨迹，未报告重复运行的方差，结论稳健性弱于 DiG-bench 的三次重复。
- **模型依赖性强**：结果高度依赖前沿商用模型（Claude Fable 5、GPT-6 Astra 等），开源或较小模型上的表现未验证，泛化性存疑。
- **基准覆盖有限**：ARC-AGI-3 仅用 25 个公开游戏（半私有与私有集未用）；DiG-bench 仅 21/70 公开游戏；MazeBench 为单一环境，外部效度受限。
- **程序正确性依赖 LLM**：认证仅检查与历史一致，无法保证程序在所有未观测状态下的正确性；复杂环境中程序可能过拟合历史。
- **成本与延迟**：长时程运行（36 小时）与频繁 backtest/规划搜索带来显著计算开销，实际部署门槛较高。
- **潜在偏差风险**：部分游戏结果波动大（如 BP35 在 Sol xhigh 下仅 28.8%），提示对模型配置与随机性敏感；人类基线为"首次游玩"或"前 50 中位数"，与智能体的最优配置不完全对等。
- **应用限制**：方法假设环境有可发现的确定性机制且动作空间给定；对随机性环境、连续动作空间、多智能体场景的适用性未探讨。
