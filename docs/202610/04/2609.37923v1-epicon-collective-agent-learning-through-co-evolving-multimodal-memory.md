## 摘要
智能体可以从过去的执行中学习，但使不同智能体能够重用并基于彼此的经验进行构建仍然具有挑战性。我们提出了EpiCon，一个用于智能体集体学习的共享多模态记忆框架，无需更新宿主模型参数。EpiCon通过两个独立训练的2B模型——记忆控制器和树自组织器——将问题级记忆演化与持久经验库相连接。控制器在多次尝试中联合精炼文本指导和视觉证据，并有选择地纳入视觉记忆。自组织器分层整合经验教训，并为新问题检索经验和规则。我们在涵盖四个多模态任务领域的十一个基准上评估EpiCon，使用两种测试框架和多种骨干模型。冻结的经验库即使在单次求解尝试下也能改进其他系统。第二个测试框架在十一个基准上将原始系统的宏平均分数提高了2.6分。在四种宿主配置下，EpiCon相比无记忆将宏平均分数提高了1.7至4.9分，并相对于骨干规模的记忆模型将记忆操作时间减少了67%至74%。

## Abstract
Agents can learn from past executions, but enabling different agents to reuse and build on one another's experience remains challenging. We introduce EpiCon, a shared multimodal memory framework for agent collective learning without updating host model parameters. EpiCon links question-level memory evolution to a persistent experience bank through two independently trained 2B models: a memory controller and a tree self-organizer. The controller jointly refines textual guidance and visual evidence across attempts and selectively includes visual memory. The self-organizer consolidates lessons hierarchically and retrieves experience and rules for new problems. We evaluate EpiCon on eleven benchmarks spanning four multimodal task domains, using two harnesses and multiple backbones. A frozen bank improves other systems even with a single solving attempt. A second harness raises the original system's macro-average score by 2.6 points across eleven benchmarks. Across four host configurations, EpiCon improves macro-average scores by 1.7 to 4.9 points over No Memory and reduces memory-operation time by 67\% to 74\% relative to backbone-sized memory models.

# EpiCon 论文深度总结

## 1. 核心问题与整体含义

- **研究动机**：基于语言模型的多智能体系统（MAS）在执行任务过程中会产生大量关于解题流程、失败模式和相关证据的经验，但如何让**不同智能体之间复用并积累彼此的经验**仍是一个开放难题。
- **背景痛点**：
  - 现有外部记忆系统（如 Mem0、Cognee、A-Mem、Agent-KB）大多以**纯文本**形式存储经验，难以保留图表区域、文档细节等视觉证据。
  - 多数方法依赖**更新宿主模型参数**或使用与骨干同规模的模型进行记忆操作，成本高、通用性差。
  - 经验教训往往需要跨尝试修正，且需要跨问题整合才能被后续任务复用。
- **整体含义**：论文提出 **EpiCon（Episodic Consolidation）**，一个**共享多模态记忆框架**，在不更新宿主模型参数的前提下，实现智能体的"集体学习"——即经验可在不同 harness（测试框架）和 backbone（骨干模型）之间迁移、复用与共同演化。

## 2. 方法论

### 核心思想
- 将**问题级记忆演化**（同一问题内多次尝试的文本+视觉记忆协同修正）与**持久经验库**（跨问题、跨系统的经验积累与检索）相连接。
- 由两个**独立训练的 2B 模型**承担记忆管理，宿主 MAS 保留自身编排与骨干，参数不变。

### 关键技术细节

- **共享多模态记忆库 B**：
  - 独立于使用它的 MAS 存在，系统可从中检索指导，也可贡献自身经验。
  - 维护更新公式：`B(k+1) = Sϕ(B(k), Uk)`，其中 k 为维护步数（非单条经验），Uk 为一批被接受的教训与修订。
  - 评估时经验库**冻结**，更新仅限当前问题局部。

- **问题级多模态记忆演化（Memory Controller Cθ）**：
  - 记忆表示为 `Wi,t = (M_text_i,t, M_vis_i,t)`，文本记录可操作指导、适用条件与警示；视觉记忆指向源图像中的支持区域。
  - 更新公式：`Wi,t = Cupdate_θ(Wi,t−1, xi, ŷi,t, τi,t)`，即基于上一状态、当前问题与图像、最新答案和执行轨迹进行修订。
  - 控制器可**保留、替换或移除**视觉证据，随指导文本共同演化。

- **自适应视觉记忆注入**：
  - 通过门控 `gi,t ∈ {0,1}` 决定下一次输入是否包含视觉记忆。
  - 输入构造：`ci,t = (Ti,t, ∅)` 若 g=0；`ci,t = (Ti,t, Vi,t)` 若 g=1。
  - 门控只选择输入内容，**不删除**已存储的视觉记忆；当前问题的原始图像始终可用。

- **共享经验整合与复用（Tree Self-Organizer Sϕ）**：
  - 经验库以**树结构**组织：叶子存问题级教训，内部节点分组并总结相关经验。
  - 维护操作包括 **Place（放置）、Merge（合并）、Split + Lift（分裂提升）、Consolidation（整合）**。
  - 整合可抽象出**可复用规则**，由 harness 根据支持度、失败、冲突和证据强度决定抽象层级与规则资格。
  - 检索公式：`Ri = Sretrieve_ϕ(xi, Recall(xi, B))`，先用冻结文本编码器召回候选，再由自组织器筛选适用规则、具体经验或"无适用"。

- **训练方式**：两个 Qwen3.5-2B 模型独立微调，采用 LoRA（rank 16，scaling 32），3 个 epoch，学习率 1e-4，最大序列长度 8192，per-device batch size 2，梯度累积 8 步；控制器选 step 1000，树自组织器选 step 258。

## 6. 主要结论与发现

- **冻结经验库即可提升其他系统**：即使单次求解尝试，跨骨干迁移宏平均提升 **3.2 分**，跨 harness 迁移提升 **4.2 分**。
- **集体学习成立**：一个 harness 可受益于另一 harness 构建的经验库，并贡献新经验反过来提升原贡献者——Codex 宏平均从 53.5→55.7，DeepSeek-Harness 从 53.4→56.6（分别 +2.1、+3.2 分）。
- **2B 模型高效可行**：相比骨干规模记忆模型，记忆操作时间减少 **67%–74%**，总时间减少 25%–35%，宏平均仅低 0.9–3.6 分；相比 No Memory 仍提升 **1.7–4.9 分**。
- **多模态协同演化有效**：演化视觉记忆优于冻结视觉记忆（8 项中 7 项提升）；自适应注入优于始终注入（8 项中 7 项提升），并降低约 17%–25% 的 MAS 执行时间。
- **树结构优于扁平结构**：Tree 在所有测试基准上优于 Flat，如 ParseBench 从 52.2→67.3。
- **泛化到更强求解器**：Codex + GPT-5.6-Luna 上四个基准全部提升，ParseBench 从 63.8→66.5。
- **任务依赖性**：跨 harness 演化收益不均匀，某些基准（如 ParseBench 在 Codex 上）可能因贡献方较弱而下降。

## 7. 优点

- **方法创新性**：
  - 首次将**问题级文本-视觉记忆协同演化**与**跨系统持久经验库**连接，实现真正的集体学习。
  - 自适应视觉记忆注入机制兼顾效果与效率，门控不删除存储内容的设计合理。
  - 树结构 + 规则抽象的分层整合，支持从具体教训到可复用规则的渐进抽象。
- **工程效率**：用两个 2B 小模型替代骨干规模模型，显著降低记忆操作开销，具备实际部署价值。
- **实验严谨性**：
  - 构建/评估严格分离，ReasonMap 按地图切分防止泄漏。
  - 统一单次尝试协议，避免"多试几次"带来的不公平优势。
  - 成本报告分离 MAS 与记忆操作，归一化方式清晰。
- **可迁移性验证充分**：跨骨干、跨 harness、跨求解器（GPT-5.6-Luna）多维度验证，结论稳健。
