## 摘要
递归自我改进（RSI）让系统能够从自身结果中改进；在基于大语言模型的多智能体系统中，智能体在任务内相互优化，而结果则改进它们跨任务的协作方式。然而，现有多智能体协作使这一循环保持开放：协作在操作者层面预先定义，仅拓扑学习保留逐字交换从而传播错误，而系统自身结果的奖励最大化集中于少数团队。为应对这些挑战，我们提出 CollabFlow，一个学习型智能体协作的 RSI 系统：可训练的 Collab-Director 构建由完整智能体组成的团队，冻结的执行器运行它们，每一轮的结果重新训练该 director。在每一轮内，协作图的边承载证据条件通信协议：接收方仅在发送方证据以一定幅度更强时才采纳不同答案，因此 director 学习谁通信以及如何通信。跨轮次，我们进一步提出协作轨迹平衡（CTB），一种基于流的目​​标，在其构建顺序上对每个团队仅计入一次，并以与奖励成比例的团队分布为目标，从而使多个优秀团队保持参与。我们还界定了这一自生成目标在轮次间移动的幅度，该幅度随记录积累而缩小。在十二个数据集上，CollabFlow 优于所有基线，并在各轮次中持续改进。代码见 https://anonymous.4open.science/r/CollabFlow-631E。

## Abstract
Recursive self-improvement (RSI) lets a system improve from its own outcomes; in LLM-based multi-agent systems, Agents refine one another within a task, and outcomes improve how they collaborate across tasks. However, existing multi-agent collaboration leaves this loop open: collaboration is pre-defined at the operator level, topology-only learning keeps verbatim exchange that propagates errors, and reward maximization on a system's own outcomes concentrates on a few teams. To address these challenges, we propose CollabFlow, an RSI system of Learned Agent Collaboration: a trainable Collab-Director constructs teams of complete Agents, a frozen executor runs them, and each round's outcomes retrain the director. Within each round, the edges of a collaboration graph carry protocols of Evidence-Conditioned Communication: a receiver adopts a differing answer only when the sender's evidence is stronger by a margin, so the director learns who communicates and how. Across rounds, we further propose Collaborative Trajectory Balance (CTB), a flow-based objective that credits each team once across its construction orders and targets a reward-proportional distribution over teams, so several good teams stay in play. We also bound how far this self-generated target moves between rounds, which shrinks as records accumulate. On twelve datasets, CollabFlow outperforms all baselines and keeps improving across rounds. Code is available at https://anonymous.4open.science/r/CollabFlow-631E.

# CollabFlow 论文深度总结

## 1. 核心问题与整体含义

- **研究背景**：递归自我改进（RSI）正成为具体的系统问题。基于 LLM 的多智能体系统天然适合 RSI——智能体在任务内相互优化答案，每次交互都留下执行结果，理论上可形成"任务内改进 → 跨任务改进协作方式"的双层闭环。
- **核心问题**：现有多智能体协作使这一闭环在三个关键点保持开放：
  - **协作预定义、停留在操作者层面**：现有编排为单一执行器组合操作符，或预先固定角色与消息路由，智能体本身从未成为通信单元。
  - **仅学拓扑、逐字交换**：学到的拓扑只决定"谁与谁交换消息"，但每条消息完整重新进入接收方推理，导致从众效应与错误传播；策略只学会"谁说话"，没学会"消息如何使用"。
  - **奖励最大化导致团队坍缩**：在自身结果上做奖励最大化训练，策略会集中到少数团队，后续轮次可学习的团队变少；同时一个团队的多种构造顺序还会分散其信用。
- **整体含义**：论文提出 CollabFlow，将"团队通信本身"作为递归自我改进的对象——联合选择拓扑与协议，并在自身结果上重训这一选择，使协作在显式预算下递归地自我改进。

## 2. 方法论

### 2.1 核心思想

- 采用 **Director–Executor 范式**：可训练的 **Collab-Director** 设计团队（选哪些智能体、如何连接、边用什么协议），**冻结的执行器**运行团队；每轮只改变"团队如何被设计"，执行器与智能体参数不变。
- 双层改进嵌套：**轮内**由证据条件协议让智能体相互修正答案；**跨轮**由 CTB 在自身记录上重训 Director。

### 2.2 关键技术细节

- **协作图定义**：有向标注图 G=(V,E,o)，V 为完整智能体（不可变画像），E 的每条边标注协议，协议注册表为 {FINAL ONLY, ONE WAY, INTERACTIVE}；有状态任务中恰好一个授权 Executor 持有写权限。
- **团队构造**：Director 从合法动作集 U_c(v_t) 中采样（加智能体、加边、绑定技能、设输出、停止），采样前经合法性检查，因此**没有采样提案会被拒绝**；停止需满足完整有效团队，超时或预算耗尽返回显式中止 †。构造轨迹经规范化（Canonicalization）合并仅序列化顺序不同的历史，使同一团队的所有构造顺序进入同一吸收节点。
- **证据条件通信（轮内改进）**：智能体以候选版本 a_v 与证据记录 E_v 结束本地回合，得分 ℓ_v = max{w(e)}，其中可执行检查通过 w=2、检索支持 w=1。对 i→j 的有向更新比较证据差 Δ=ℓ_i−ℓ_j 与边际 κ：
  - Δ > κ：采纳发送方答案 a_i；
  - Δ < −κ：保留自身 a_j；
  - |Δ| ≤ κ：做一次有界、无工具的 Revise 调用。
  - 由于得分为 {0,1,2}，固定 **κ=1**（唯一能在两级差距上采纳、在一级差距上修订的整数边际）；自报置信度不进入 Δ。
- **协议语义**：FINAL ONLY 不运行门控；ONE WAY 运行一次门控；INTERACTIVE 在交替方向上运行有上限的多次门控，遇一致或决定性更新即停止。固定顺序扫过边（无环用拓扑序，有环重复至固定上限），形成团队消息级算子 a⁺ = C_G(a)。
- **协作轨迹平衡 CTB（跨轮改进）**：
  - 以**完整智能体团队**为计分对象，所有构造顺序在规范化终点合并，团队只获得一次奖励。
  - 平衡条件：log Z_ψ(c) + Σ log p_F = β log r_G + Σ log b_ϕ，其中 b_ϕ 为学习到的反向核，在终点对构造顺序做归一化 softmax（均匀核 1/|O(G)| 作为消融）。
  - 训练损失：长度归一化残差平方 + KL 近端惩罚（π_ref 为收集该批次的 Director），即 L = E[(ρ_TB/T)²] + α_KL·D_KL。
  - **奖励比例目标**：精确平衡下 μ_θ^V(G|c) ∝ r_G^β，每个正奖励团队都保留概率（如 β=1、奖励 0.6/0.4/0.2 时采样概率为 1/2、1/3、1/6），而非奖励最大化把所有质量压到第一名。
  - **自生成团队奖励**：eR_k = ε_min + r_ans · [(s_k+1/2)/(n_k+1)] · exp[−L_rel]，即答案得分乘以 Jeffreys 平滑后验成功率与最小描述长度结构先验，无调参权重；计数在批次后按唯一结果各加一次。
  - **目标漂移界**：连续轮次目标的总变差移动有界，且随采样团队记录积累而缩小。

### 2.3 理论保证（三条命题）

- **命题 1**：在检查保持（C1）下每条被接受的轨迹产生有效规范团队；在组件完备与可行前缀（C2–C3）下每个目标团队在每轮都有合法构造轨迹。
- **命题 2**：在版本绑定证据、有序门控、单写者（S1–S3）下，证据条件通信使每条记录与其检验过的版本绑定，正确接收方仅可能因误采纳或修订错误被翻转，内部写入串行化。
- **命题 3**：精确有效路径平衡下 CTB 按温度化奖励比例采样规范团队；固定答案得分表与结构码时，相邻轮次目标的总变差差有界并随记录积累缩小。

## 6. 主要结论与发现

- **IID 全面领先**：平均超最强基线 2.27 EM、4.37 accuracy 点，所有平均增益在 p<10⁻² 显著；SFT/GRPO 最多给骨干加 5.5 点，而学习型团队加 33.3 点，说明增益来自团队构造与证据交换而非执行器。
- **OOD 同样领先**：除 HumanEval 与 AFlow 打平外全部领先，EM 领先 3.51、F1 领先 4.22，而微调对骨干影响不足 1 点。
- **跨执行器普适**：提升全部 6 个其他冻结执行器，弱执行器增益更大（IID 中 Pearson r=−0.96），把执行器间 IID 差距从 23.3 点缩小到 9.3 点。
- **范式与组件**：所有范式与消融均低于完整模型，且 OOD 损失更大；去掉通信代价最大，去掉 Director 训练损失 13.7 IID / 19.5 OOD 点（其中递归贡献 7.6 / 13.6）。
- **CTB 优于奖励最大化**：在匹配 rollouts 与奖励下，CTB 在团队级各项指标上优于 GRPO、PPO 与 w/o CTB，团队分布移动最小（TV=0.0937），找到 26 条不同成功路径（对比最多 15 条），训练准确率 25 步内超过 0.80。
- **递归自改进有效**：20 个最大单步增益步中，任务成功率从 34.4% 升至 75.0%，15 步在五步后仍保持领先，承载 83.6% 的 55 次技能编辑。
- **成本最低**：每项 token 最少且波动最小。
