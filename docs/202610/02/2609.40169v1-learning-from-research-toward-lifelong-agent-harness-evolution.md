## 摘要
语言智能体被期望解决日益复杂的任务，由此产生了对持续改进的日益增长的需求。一种有前景的方法是演化智能体框架，即管理工具使用、记忆管理和任务执行的软件，同时保持底层语言模型固定不变。近期方法通过使用元编码智能体基于执行反馈修改框架来自动化这一过程。然而，依赖该智能体已有知识和观察到的失败可能限制探索，并使适应变得被动。受人类专家如何从研究文献中学习以寻求新解决方案的启发，我们提出了ScholarEvolve，一个自动利用最先进研究来指导框架演化的框架。ScholarEvolve将框架演化方向组织为功能模块，并使用主题建模为每个模块识别不同的改进策略。它实现这些策略并评估其组合以提升任务性能。此外，该框架被设计为随时间纳入新出版物，使研究进展能够驱动主动的终身演化。实验证明了在AppWorld和Tau2-Bench上的改进。ScholarEvolve将Qwen3.5-27B在AppWorld Challenge上的任务目标完成率从49.6%提升至63.6%，并将GPT-5.4-mini在Tau2-Bench Telecom上的pass@1从72.7%提升至81.9%。

## Abstract
Language agents are expected to solve increasingly complex tasks, creating a growing need for continual improvement. One promising approach is to evolve the agent harness, the software that governs tool use, memory management, and task execution, while keeping the underlying language model fixed. Recent methods automate this process by using a meta coding agent to modify the harness based on execution feedback. However, relying on that agent's existing knowledge and observed failures can restrict exploration and make adaptation reactive. Inspired by how human experts learn from the research literature for new solutions, we introduce ScholarEvolve, a framework that automatically draws on state-of-the-art research to guide harness evolution. ScholarEvolve organizes the harness evolution directions into functional modules and uses topic modeling to identify distinct improvement strategies for each module. It implements these strategies and evaluates their combinations to improve task performance. Moreover, the framework is designed to incorporate new publications over time, allowing research advances to drive proactive lifelong evolution. Experiments demonstrate improvements on AppWorld and Tau2-Bench. ScholarEvolve raises Qwen3.5-27B task goal completion from 49.6% to 63.6% on AppWorld Challenge, and raises GPT-5.4-mini pass@1 from 72.7% to 81.9% on Tau2-Bench Telecom.

## 1. 核心问题与整体含义

- **研究背景**：语言智能体需要处理日益复杂的任务，持续改进能力成为刚需。相比反复训练大模型（计算代价高昂），演化 **agent harness**（即围绕固定模型管理工具使用、上下文、技能、记忆与执行流程的软件层）是一条更实用的路径。
- **现有方法的三大挑战**：
  - **探索受限**：元编码智能体虽可自由改代码，但往往陷入重复的局部编辑（如反复加验证器、多智能体辩论），探索范围狭窄。
  - **设计知识受限**：元智能体提出的机制受限于其骨干模型已有知识与推理能力，失败轨迹能暴露缺失能力，却难以指导如何构建解决方案。
  - **适应滞后**：基于轨迹与反馈的演化依赖已发生的失败，部署中弱点可能先影响用户，才积累足够证据触发更新。
- **核心洞察**：人类专家会查阅研究文献来学习他人如何解决类似问题。论文将这一实践自动化，提出 **ScholarEvolve**，用前沿研究文献指导 harness 演化，并支持随时间纳入新论文，实现**主动的终身演化**。

## 2. 方法论

### 核心思想
- 将 harness 分解为 **5 个功能模块**，沿“模块 × 研究主题”两个轴组织探索：模块决定“改哪里”，主题决定“用什么机制改”。
- 用**主题建模**从文献中提取语义正交的机制族，分配候选预算以覆盖不同机制，再通过**模块交叉（crossover）**组合并评估完整 harness。

### 五个功能模块
- **Tool interface**：工具选择、工具组合、调用验证。
- **Context management**：上下文选择、压缩、排序。
- **Skills**：技能归纳、检索、整理。
- **Memories**：记忆形成、检索、巩固。
- **Agentic workflows**：任务分解、智能体协调、子智能体委派。

### 关键技术流程

2. **主题建模（基于 TopicGPT）**：
   - 分类体系归纳与精炼：`T_j^(b) = T_j^(b-1) ∪ G(B_j,b, T_j^(b-1), d_j)`，再经精炼函数 `F` 合并同义/重叠主题、吸收过细变体。

   - 覆盖分配：按簇大小排序，**轮询（round-robin）**选取论文，预算 K_j 可覆盖 min(K_j, |T_j^+|) 个不同主题。
3. **从研究机制到可执行变异**：研究智能体阅读全文与官方代码，产出 **mutation blueprint**（源机制、假设、目标模块、接口、状态与工件、运行时操作、终止条件），编码智能体据此实现模块变异，并通过**健康探针**（可导入性、接口兼容、工件构建与重载、有效动作生成）检查。
4. **模块交叉与选择**：
   - 单模块变异增益：`g_{j,p}(i) = r̄_i(H_j^(p)) − r̄_i(H^(0))`。

   - 对入围组合实际评估得到 `Δ(c)`，用**配对 bootstrap 增益区间下界**决定是否保留：`H_{g+1} = ẽH_g` 若 `L_α(ẽH_g, H_g) > 0`，否则保留原冠军。
5. **终身演化**：周期性刷新文献，从当前冠军出发开启新一轮搜索循环；骨干模型固定，冠军代码与持久化工件（技能库、记忆）跨循环继承。

## 6. 主要结论与发现

- **一致提升**：ScholarEvolve 在两个 benchmark、两个骨干的所有指标上均有提升。AppWorld Normal 上 Qwen 提升 12.4 TGC / 20.2 SGC 点；Telecom 上 Mini 提升 9.2 pass@1 / 9.1 pass@4 点。
- **泛化到未见应用**：同一 harness 与工件迁移到 Challenge（含未见 Amazon/Gmail），TGC 增益反而更大（Qwen 14.0 vs Normal 12.4；Mini 9.5 vs 5.3），分别超出 Meta Harness 9.0 与 10.0 点。
- **缩小能力差距**：演化后 Qwen 在 AppWorld Normal 达 81.4% TGC，接近 Kimi-K2.6 的 81.3%，将相对 GPT-5.4 的差距从 16.7 缩小到 4.3 点（约弥补 74%）。
- **终身演化有效**：三轮文献更新后 TGC 达 81.5%、SGC 达 66.7%，相对 Meta Harness 领先 11.9 / 15.5 点。
- **消融结论**：主题引导选择、模块化变异、研究引导三者逐级移除均导致性能下降，说明各组件均有贡献。
- **模块交互显著**：组合优于最强单模块（Qwen +3.5 TGC/12.3 SGC；Mini +4.7/7.0），且单模块分数无法预测最佳组合。
- **可靠性提升**：Qwen 在 585 个任务中 221 个提升、57 个回退；三次全成功的任务从 205 增至 333。
- **残余失败**：演化主要改善“答案交付”（无效响应格式从 492 降至 206 episode），但**约束违反**与**不完整检索**改善有限，需求追踪与证据覆盖仍是开放问题。

## 7. 优点

- **新颖视角**：将“阅读研究文献”这一人类专家实践系统化、自动化，为 harness 演化引入外部知识源，突破元智能体自身知识的局限。
- **结构化探索**：模块 × 主题的双轴组织 + 主题建模的正交化 + 轮询预算分配，有效缓解探索狭窄问题。
- **主动终身演化**：新论文可先于部署失败触发更新，具备前瞻性。
- **严谨的实验协议**：Devo/Dval/Dtest 严格分离，测试集不参与任何选择决策；对比方法预算对齐；配对 bootstrap 保留规则。
- **模块化接口设计**：支持变异隔离与交叉组合，且通过完整 harness 评估捕捉模块交互。
- **丰富的分析**：包含失败分类体系、可靠性转移矩阵、API 需求泛化分析、候选池单独增益等，诊断深入。
