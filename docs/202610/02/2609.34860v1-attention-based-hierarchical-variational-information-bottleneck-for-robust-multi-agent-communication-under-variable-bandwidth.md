## 摘要
在有限带宽下，基于学习的多智能体通信不仅需要决定通信内容，还需要组织消息结构，使得部分传输仍然有用。我们研究前缀截断下的这一问题，即每个消息只有前一部分被接收。为了解决该问题，我们提出\textbf{AH-VIB}，一种基于注意力的自回归变分通信模型，它将变分信息瓶颈（VIB）与序列消息生成和分层鲁棒性损失相结合。我们在一个定制的协作目标检查和占用建图任务上评估AH-VIB，其中配备有限视场传感器的智能体在占用栅格世界中协调扫描检查目标，在可变和固定带宽条件下，并将其与MADDPG、CommNet、平坦VIB基线以及自回归MLP消融进行比较。AH-VIB在最具限制的带宽条件下实现了有竞争力的平均回报，同时提高了性能可靠性。这些结果表明，AH-VIB提高了带宽约束下学习通信的可靠性和优雅降级能力。

## Abstract
Learning-based multi-agent communication under limited bandwidth does not only require deciding what to communicate, but also structuring messages so that partial transmissions remain useful. We study this problem under prefix truncation, where only the first part of each message is received. To address it, we propose \textbf{AH-VIB}, an attention-based autoregressive variational communication model that combines a variational information bottleneck (VIB) with sequential message generation and a hierarchical robustness loss. We evaluate AH-VIB on a custom cooperative object-inspection and occupancy-mapping task, where agents equipped with a limited field-of-view sensor coordinate to scan inspection objects in an occupancy-grid world, under variable and fixed bandwidth conditions, and compare it against MADDPG, CommNet, a flat VIB baseline, and an autoregressive MLP ablation. AH-VIB achieves competitive mean return while improving performance reliability under the most constrained bandwidth conditions.   These results indicate that AH-VIB improves the reliability and graceful degradation of learned communication under bandwidth constraints.

## 1. 核心问题与研究动机

- **背景**：多机器人系统（基础设施巡检、环境监测、危险环境作业）日益依赖通信协调，但实际带宽会因距离、干扰、环境遮挡而动态变化。
- **核心问题**：现有学习型多智能体通信方法大多假设消息“全送达或全丢失”，忽略了**渐进式带宽退化**的现实。论文将可变带宽建模为**前缀截断（prefix truncation）**——只有消息向量的前 k 维被接收，其余维度丢失。
- **关键挑战**：前缀截断本质上是一个**排序问题**——智能体应该“先说什么”？消息的早期维度必须承载最关键的任务信息，使得短前缀仍然有用，后续维度提供细化。
- **研究目标**：不仅压缩通信，而是学习**有序的、面向任务的消息表示**，实现“渐进式信息编码”（progressive information encoding），保证在带宽受限时性能优雅降级。

## 2. 方法论：AH-VIB

### 核心思想
AH-VIB（Attention-based Hierarchical Variational Information Bottleneck）融合两个互补组件：
1. **自回归注意力编码器**：按因果顺序逐维生成消息，使截断前缀在结构上自洽。
2. **分层鲁棒性损失**：在训练中惩罚消息截断导致的团队回报估计下降，使前缀对任务真正有用。

### 关键技术细节

- **问题建模**：通信增强的 Dec-POMDP，智能体复合动作 = 物理动作 + 消息。CTDE 范式，集中式 critic 训练、去中心化执行。
- **前缀截断信道模型**：接收消息 $\tilde{m}_{i,d} = m_{i,d}$（当 $d \le k$），否则为 0。带宽比例 $\rho = k/d_m$，每回合从 Beta 分布采样。
- **VIB 基础**：每个消息维度从高斯分布采样 $z_d = \mu_d + \sigma_d \cdot \varepsilon$，用 KL 散度正则化到标准正态先验（$L_{VIB}$）。
- **自回归消息编码**：每个维度条件依赖于之前生成的维度 $q(z_d | z_{<d}, o_i, c_i)$。用多头注意力实现：query 由编码器隐状态 + 位置嵌入构成，key-value 上下文随已采样维度逐步增长。采样后经 tanh 有界，$W_z$ 参数跨步共享。
- **分层鲁棒性损失**：独立采样截断比例，对联合动作向量施加前缀掩码，评估集中式 critic 在截断下的值 $Q_k$，用 hinge 损失惩罚与全带宽值 $Q_{full}$（stop-gradient）的差距：$L_{hier} = \mathbb{E}_k[\max(0, Q_{full} - Q_k)]$。
- **总损失**：$L_{actor} = \mathbb{E}[-Q_{full} + \beta L_{VIB} + \lambda L_{hier}]$，三项分别驱动任务性能、消息压缩、截断鲁棒性。

- **训练稳定性**：AH-VIB、HVIB、VIB、MADDPG 收敛到相近的最终回报，VIB 与分层鲁棒性目标不阻碍训练。
- **带宽约束下的优势**：在最紧带宽（ρ=0.10, 0.25）下，AH-VIB 取得最高平均回报和最低方差；在较大带宽（ρ=0.75, 1.00）下 CommNet 略优。

- **核心结论**：AH-VIB 的优势在于**带宽受限时的可靠性**与**优雅降级能力**，而非全带宽下的绝对性能优势。
