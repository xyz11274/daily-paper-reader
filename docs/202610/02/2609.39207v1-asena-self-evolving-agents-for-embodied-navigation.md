## 摘要
我们提出了ASENA，一个具身智能体系统，将通用编码智能体与机器人感知、计算、监督执行和持久经验相连接。智能体可以编写和执行程序、检查记录的结果、修复故障，并复用笔记和可执行技能，同时保持其模型权重固定。我们进一步引入了ASENA-VLN，一个4B单目导航策略，作为该可编程系统中的可选工具。ASENA-VLN使用共享的视觉-语言解码器预测机体坐标系轨迹，用于扩展路线和短时域行为，该解码器在路线指令、视觉问答以及新整理的几何推导原子导航任务数据集上训练。作为独立策略，ASENA-VLN在R2R上达到68.7%、在RxR上达到70.2%的最先进成功率。当与编码智能体集成时，学习到的导航在两种智能体基准上将ASENA的成功率提高11个百分点，同时减少执行时间。通过持久工作区演化和模拟器反馈，对重复出现的100任务子集进行十次遍历，进一步将R2R上的成功率从72%提高到98%，将RxR上的成功率从65%提高到89%。在具身问答上，ASENA以更少的交互步骤实现了最先进的准确率。最后，在Unitree G1上的真实世界演示结合了搜索、视觉检查、空间推理和合成手势，无需预建地图，展示了在线编程如何将机器人行为扩展到路线跟随和预定义技能之外。

## Abstract
We present ASENA, an embodied agent system that connects general-purpose coding agents to robot sensing, computation, supervised execution, and persistent experience. Agents can write and execute programs, inspect recorded outcomes, repair failures, and reuse notes and executable skills while keeping their model weights fixed. We further introduce ASENA-VLN, a 4B monocular navigation policy that serves as an optional tool within this programmable system. ASENA-VLN predicts body-frame trajectories for both extended routes and short-horizon behaviors using a shared vision-language decoder trained on route instructions, visual question answering, and a newly curated dataset of geometry-derived atomic navigation tasks. As a standalone policy, ASENA-VLN achieves state-of-the-art success rates of 68.7% on R2R and 70.2% on RxR. When integrated with a coding agent, learned navigation improves ASENA's success rate by 11 percentage points on both agentic benchmarks while reducing execution time. Through persistent workspace evolution and simulator feedback, ten passes over recurring 100-task subsets further improve success from 72% to 98% on R2R and from 65% to 89% on RxR. On embodied question answering, ASENA achieves state-of-the-art accuracy with fewer interaction steps. Finally, real-world demonstrations on a Unitree G1 combine search, visual inspection, spatial reasoning, and synthesized gestures without a pre-built map, illustrating how online programming extends robot behavior beyond route following and predefined skills.

- **核心问题**：如何让机器人在**不更新模型权重**的前提下，通过在线编程、执行反馈与持久工作区演化，持续提升导航与交互能力？
- **整体含义**：论文提出 ASENA，将通用编码智能体（如 Codex、Claude Code）接入机器人感知、计算、监督执行与持久经验系统，使机器人能够编写/执行程序、检查记录结果、修复故障并复用技能。同时提出 4B 单目导航策略 ASENA-VLN 作为可选工具，将导航从"路线跟随"扩展到"自适应搜索与用户交互"。
- **背景定位**：工作处于 Code as Policies、Agentic Self-improvement（Voyager、Reflexion、ENPIRE）、Language-guided Navigation（NaVid、NaVILA、StreamVLN）与 Embodied Question Answering（Explore-EQA、3D-Mem）的交叉点，重点研究**固定权重下持久工作区围绕预训练导航策略的演化**。

## 2. 方法论

### 2.1 核心思想
- 将编码智能体与物理机器人通过统一接口连接，形成 **write–run–inspect** 工作流：智能体读取传感器、推导几何、执行代码、检查可视化、请求机器人动作。
- 所有物理动作经过**监督执行接口**，由 SONIC 全身控制器执行，并受多层安全机制约束。
- 持久工作区存储笔记与可执行技能，使系统通过**程序修订**而非权重更新来改进。

### 2.2 关键技术细节

**（1）基于机器人反馈的程序接地**
- G1 机器人暴露 360° 相机、LiDAR、里程计、IMU、关节状态等接口。
- 智能体可估计几何、检查物体、监控执行；当动作偏离意图时，检查记录证据并修订程序。
- 原子技能（接近物体、穿门、说话、手势）可组合为更大可复用技能。

**（2）多层安全保障**
- 合成手势先在 MuJoCo 中在线验证（姿态连续性、关节/运动限制、自碰撞采样）。
- 验证失败时返回违反约束给智能体修复。
- 任何验证通过的运动需**操作员批准**后才由 SONIC 执行。
- 导航使用 LiDAR 占据栅格进行路径规划与障碍间隙检查；独立安全模块在里程计过期或电量低时拒绝命令；心跳触发停止与手动急停。

**（3）执行转化为保留经验**
- 运行以 **MCAP 格式**记录，对齐传感器/机器人状态与动作、操作员反馈、代码、可视化。
- 工作区表示为 \( W_k = (N_k, S_k) \)，其中 \( N_k \) 为笔记，\( S_k \) 为可执行技能。
- 工作区更新公式：\( W_{k+1} = I_\varphi(W_k, \mathcal{T}_k, f_k) \)，其中 \( \mathcal{T}_k \) 为执行轨迹，\( f_k \) 为反馈，\( I_\varphi \) 为固定权重的改进器。
- **模型与控制器权重始终保持固定**；仿真中私有 worker 可在轮次间编辑工作区，冻结评估时禁止写入。

**（4）ASENA-VLN 导航策略**
- 基于 **Qwen3-VL-4B-Instruct** 扩展，增加轨迹与像素目标的专用 token 词表。
- 输入：最多 8 帧前视图 + 结构化 JSON 指令（含目标文本、质量分、可选末端位姿锚点/锚物体/运动约束），采用**近因加权**视觉 token。
- 输出：共享自回归解码器预测最多 8 个累积机体坐标系路点 \((x, y, \theta)\)，通过固定分箱转换为显式运动目标。
- 辅助监督：像素目标 token（鼓励定位意图目的地）+ 视觉问答（保留原文本词表）。
- 论文所有评估使用**轨迹 token 预测**而非像素目标（后者需额外运动规划器）。
- **原子导航数据**：在 MP3D 和 HM3D 中整理 9 类原子任务（指定距离移动、旋转到目标朝向、从指定方向接近物体、对齐、进入房间、穿门、走廊跟随、跨楼层等），用测地距离、可见性、场景几何验证可行性。
- 训练混合：原子任务 + 短时域 ObjectNav + R2R/RxR/ScaleVLN/SRDF 的 VLN 数据，用 GPT-5.5 重述为结构化 JSON 格式；加入多视图 VQA 数据。
- 训练规模：**4.3M 样本**，轨迹预测与空间 VQA 按 **3:1** 混合。

## 6. 主要结论与发现

- **ASENA-VLN 独立性能 SOTA**：R2R SR 68.7%、RxR SR 70.2%，NE 显著更低（3.52 / 3.90），nDTW 更高（73.1）。
- **ObjectNav SOTA**：HM3D-v2 80.8/38.1，HM3D-OVON syn. 65.8/37.9、unseen 64.9/38.4，跨 seen/syn./unseen 类别表现一致。
- **强编码智能体本身即强零样本导航系统**：GPT-6 Astra 仅用几何与程序化工具即超越独立 ASENA-VLN，R2R SR 接近人类 90%。
- **学习导航对弱后端增益明显**：Claude Sonnet 5 加入 VLN 后 R2R/RxR SR 均提升 11 个百分点；GPT-6 Astra 增益较小，RxR 上甚至略降。

## 7. 优点
