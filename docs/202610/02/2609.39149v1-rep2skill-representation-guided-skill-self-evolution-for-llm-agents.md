## 摘要
文本技能使基于大语言模型（LLM）的智能体能够在不更新模型参数的情况下积累可复用的程序性知识。然而，现有的技能演化在很大程度上局限于文本空间：优化器必须仅从冗长的执行轨迹和稀疏的任务结果中诊断成功与失败模式，并据此修订技能。这种纯文本范式将智能体的内部表征——其中包含其不断演化的执行状态的丰富记录——排除在技能优化循环之外。我们提出疑问：智能体能否通过反思自身的内部表征来改进其外部文本技能？我们提出Rep2Skill，一个表征引导的智能体技能自演化框架。具体而言，在收集到的智能体执行轨迹上，Rep2Skill对其内部模型表征轨迹进行建模，以定位偏离成功执行动态的轮次，并进一步将这些信号与执行上下文一起解释为可操作的文本反馈，用于有针对性的技能修订。在两个智能体环境和两个开源LLM上的实验表明，在自演化设置中——同一LLM同时充当执行器和优化器，且没有更强的外部模型——Rep2Skill始终优于纯文本方法。这为智能体自我改进超越纯文本反思确立了一个有前景的方向。

## Abstract
Textual skills enable large language model (LLM) based agents to accumulate reusable procedural knowledge without updating model parameters. Yet existing skill evolution remains largely confined to the text space: an optimizer must diagnose success and failure patterns, and revise skills solely from long execution trajectories and sparse task outcomes. This text-only paradigm leaves the agent's internal representations, which contain rich records of its evolving execution state, outside the skill optimization loop. We ask whether an agent can improve its external textual skills by reflecting on its own internal representations. We introduce Rep2Skill, a representation-guided framework for self-evolution on agent skills. Specifically, upon the collected agent rollouts, Rep2Skill models their internal model representation trajectories to localize turns that deviate from successful execution dynamics, and it further interprets these signals alongside the execution contexts as actionable textual feedback for targeted skill revision. Experiments on two agent environments with two open-source LLMs show that Rep2Skill consistently outperforms text-only approaches in the self-evolution setting, where the same LLM serves as both executor and optimizer without a stronger external model. This establishes a promising direction moving agent self-improvement beyond text-only reflection.

- **背景**：LLM 智能体通过"文本技能"（可复用的程序性指令、规则与策略）在不更新模型参数的前提下积累经验，已在多步长程任务中展现价值。

- **被忽视的信号**：智能体的**内部表征**（hidden states）蕴含其执行状态的丰富记录，能反映工具使用决策、执行失败等信号，甚至可在行为显式暴露前被检测到，但这一信息源长期被排除在技能优化循环之外。
- **核心研究问题**：*智能体能否通过反思自身的内部表征来改进其外部文本技能？*
- **整体含义**：论文主张将表征空间信号引入技能演化循环，为智能体自我改进开辟"超越纯文本反思"的新方向。

## 2. 方法论：Rep2Skill 框架

### 核心思想
将智能体执行过程中的**内部表征轨迹**作为额外证据源，通过"分组采样 → 表征归因 → 表征到文本的言语化 → 文本空间技能修订"的闭环，实现更细粒度的信用分配（credit assignment）与更精准的技能更新。

### 关键技术细节

- **问题设定**：冻结的 LLM 智能体 πθ 在技能 s 下执行任务 x，产生轨迹 τ=(o₁,a₁,…,o_T,a_T)，获得任务级分数 r(τ)。目标是最大化期望性能 J_D(s)。采用**自演化设定**：同一 LLM 同时充当执行器与优化器，无更强外部模型。

- **分组 rollout 采样**：对同一任务实例与同一技能采样 K 个 rollout（实验中 K=4），利用组内行为差异作为结构化诊断证据（借鉴 group-relative 优化思想）。

- **轮次级表征归因**：
  - 从冻结智能体的固定层（第 24 层解码层）提取每轮 hidden state h_t，对所有 token 取平均。
  - 用 PCA 投影至 64 维并做逐维标准化（投影与统计量仅在成功轨迹上拟合）。
  - 采用 **Neural CDE（神经受控微分方程）** 建模潜在轨迹动态，仅用成功轨迹训练；输入不含技能、奖励与失败信息，防止结果泄漏。
  - 归因分数 c_t = ‖h_t − ĥ_t‖²₂（预测误差），误差越大表示越偏离成功执行动态；取 top-K_c（K_c=3）作为"关键轮次"。

- **表征到文本的言语化**：由分析器 M_a（同一冻结 LLM）将关键轮次连同完整轨迹、当前技能、任务描述一起解释为文本反馈 F^(k)。反馈需满足严格约束：引用的技能规则必须是当前技能的精确子串，证据必须引用轨迹中真实存在的步骤文本；诊断类型分为 suspect_rule、rule_conflict、execution_deviation、missing_rule、insufficient_evidence 五类；不合规响应被程序化校验丢弃。

- **文本空间技能修订**：沿用 SkillOpt 的"合并—编辑选择—应用—验证门控"流程。候选技能经小验证集评估，仅当严格优于当前技能时才被接受，否则保留原技能。编辑预算 L=4 作为"文本学习率"。

## 3. 实验设计

- **Benchmark / 场景**：
  - **ALFWorld**：文本化具身家务环境，6 类任务族（pick & place、examine in light、clean、heat、cool、pick two & place），报告 valid_unseen 全部 134 个任务的**成功率**。
  - **WebShop**：模拟电商环境，报告**平均任务分数**与**成功率**。
  - 训练/选择/测试集：ALFWorld 为 39/18/134；WebShop 为 50/20/100，所有划分冻结并跨方法共享。

- **对比方法**：
  - No Skill（基线）
  - Trace2Skill（轨迹局部经验蒸馏为可迁移技能文档）
  - EvoSkill（将失败归因于缺失能力并修订模块化技能）
  - SkillOpt（将技能视为可训练文本状态，有界编辑 + 验证选择）

- **模型**：Qwen3-4B 与 Qwen3.5-9B（覆盖不同规模与架构：全注意力 vs 混合注意力）。

- **实验维度**：
  - 主实验：2 数据集 × 2 模型 × 4 方法（含基线），每设置 3 个随机种子（42/43/44）取均值±标准差。
  - 归因质量分析：轮级非进度轮次预测（AUROC/AUPRC/P@Top-3，以及 Precision@K、Recall@K 曲线）。
  - 消融实验：4 个变体（完整版、去表征言语化、去表征分析器、去分组证据）。
  - 多样性分析：84 组 × 4 rollout（共 336 条轨迹）在文本空间与表征空间的组内差异。
  - 定性案例研究：ALFWorld 一个失败任务的对比分析。

## 6. 主要结论与发现

- **RQ1（性能）**：Rep2Skill 在两个 benchmark、两个模型上均取得最佳表现。ALFWorld 成功率 52.24%（Qwen3-4B）与 69.90%（Qwen3.5-9B），分别超最强文本基线 4.98 与 7.77 个百分点；WebShop 成功率 16.33% 与 23.33%，任务分数 49.79 与 53.56。
- **可靠性**：纯文本方法在自演化下有时**反而低于 No Skill**（如 Qwen3-4B 上 SkillOpt 的 WebShop 分数 39.04 < 41.86；Qwen3.5-9B 上 Trace2Skill/EvoSkill 均低于基线），而 Rep2Skill 始终优于基线，说明表征引导提升了演化稳定性。
- **RQ2（机制）**：轮级非进度轮次检测中，纯轨迹文本 AUROC 仅 0.494，纯表征分数 0.592，而"文本+表征引导"达 **0.838 AUROC / 0.876 AUPRC / 88.22% P@Top-3**，证明表征信号提供互补信息。
- **RQ3（有效条件）**：
  - 组内 rollout 在文本与表征空间均快速发散（第 5 轮 82.7% 动作对不一致，第 10 轮 98.5% 轨迹前缀唯一），支持分组采样与相对比较的必要性。
  - 消融显示三大要素互补：去表征言语化 ↓4.48，去表征分析器 ↓5.22，去分组证据 ↓5.47。
  - 案例研究：表征归因将失败定位到"反复搜索橱柜"的具体轮次，使技能修订从泛泛的"更彻底搜索"变为可操作的"若橱柜未找到，检查台面、抽屉或水槽"，任务从 30 步失败变为 8 步成功。

## 7. 优点

  - 用 Neural CDE 建模成功执行动态，以预测误差作为归因分数，思路清晰且仅需成功轨迹训练。
