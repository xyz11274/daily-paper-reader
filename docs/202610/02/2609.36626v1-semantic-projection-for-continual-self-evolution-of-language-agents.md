## 摘要
语言模型智能体日益依赖持久的自然语言技能，以在其冻结的模型参数之外进行适应。然而，当一个共享技能从非平稳、异构的任务流中被反复修订时，对新任务的改进可能会覆盖早期任务所需的程序。在持续学习中，正交梯度下降（OGD）通过将新任务梯度投影到一个局部保留先前预测的子空间来解决类似的干扰。然而，自然语言技能修订既没有梯度，也没有一个可以进行这种投影的规范向量空间。我们引入\emph{语义范围投影演化}（SSPE），它将梯度投影的功能原理从参数空间迁移到行为空间。SSPE将无约束的技能修订视为一个提议更新，识别其可能干扰的已获得能力，并利用观察到的增益和回退来构建一个兼容的修订，而不仅仅是拒绝该更新。这使得一个共享技能能够在潜在和反复出现的任务情境中演化，而不会将语义领域身份暴露给演化模型。在受控的合成流和异构的真实智能体基准上，SSPE相对于强大的技能演化基线提高了最终跨域能力并减轻了遗忘。演化后的技能在迁移到不同的执行器模型后也保持了最强的平均性能。这些结果确立了语义投影作为语言智能体稳定且自适应自演化的一个有前景的原理。

## Abstract
Language-model agents increasingly rely on persistent natural-language skills to adapt beyond their frozen model parameters. When a shared skill is repeatedly revised from a non-stationary, heterogeneous task stream, however, improvements for new tasks can overwrite procedures needed for earlier ones. In continual learning, Orthogonal Gradient Descent (OGD) addresses analogous interference by projecting a new-task gradient onto a subspace that locally preserves prior predictions. Natural-language skill revisions, however, have neither gradients nor a canonical vector space in which such a projection can be performed. We introduce \emph{Semantic-Scope Projected Evolution} (SSPE), which transfers the functional principle of gradient projection from parameter space to behavior space. SSPE treats an unconstrained skill revision as a proposed update, identifies acquired capabilities with which it may interfere, and uses the observed gains and regressions to construct a compatible revision rather than merely rejecting the update. This enables one shared skill to evolve across latent and recurring task contexts without exposing semantic domain identities to the evolution model. Across controlled synthetic streams and heterogeneous real-agent benchmarks, SSPE improves final cross-domain competence and mitigates forgetting relative to strong skill-evolution baselines. The evolved skill also retains the strongest average performance after transfer to a different executor model. These results establish semantic projection as a promising principle for stable and adaptive self evolution of language agents.

## 1. 核心问题与整体含义

- **研究动机**：语言模型智能体越来越多地依赖持久的自然语言技能（skill）来适应新任务，而无需更新底层模型参数。然而，当同一个共享技能在非平稳、异构的任务流中被反复修订时，针对新任务的改进可能会覆盖、矛盾或降低早期任务所需的过程性知识。
- **核心问题**：作者将这一现象命名为**过程性灾难性遗忘（procedural catastrophic forgetting）**。当前域验证只能拒绝局部较差的编辑，却无法暴露在缺失能力上的回退，也无法解释如何在修复受损行为的同时保留有用的新行为。
- **理论类比**：该问题与持续学习中的干扰问题平行。正交梯度下降（OGD）通过将新任务梯度投影到与历史预测敏感方向正交的子空间来缓解干扰。但自然语言技能修订既没有梯度，也没有规范的向量空间，嵌入空间的正交性并不等价于行为兼容性。
- **整体含义**：论文提出将 OGD 的**功能原理**（而非向量操作）从参数空间迁移到**行为空间**，为语言智能体的稳定且自适应自演化提供新原则。

## 2. 方法论：Semantic-Scope Projected Evolution (SSPE)

### 2.1 核心思想

- 将无约束的技能修订视为一个"提议更新"（proposed update），识别其可能干扰的已获得能力，并通过观察到的增益与回退来**构造兼容修订**，而非仅仅拒绝更新。
- 把验证从"终端接受/拒绝门"转变为**建设性反馈**，用于语义投影修复。

### 2.2 关键技术细节

- **问题形式化**：智能体 πθ 配备持久自然语言技能 St，任务以非平稳流形式到达，按批次 Bt 更新技能。基础模型参数 θ 保持冻结。定义能力上下文 c 上的期望回报 Jc(S)，候选技能 S′ 对能力 c 的影响为 Δc(S′; St) = Jc(S′) − Jc(St)。局部有用的修订可能使早期能力 Δc < 0，即**过程性干扰**。
- **与 OGD 的类比（表 1）**：
  - 当前梯度 gt ↔ 无约束修订 Ŝt
  - 受保护输出敏感度 ↔ 能力胶囊与审计任务
  - 与受保护方向对齐 ↔ 测量的历史回退
  - 正交投影 ↔ 基于观测冲突的修订
  - 零投影步 ↔ 显式不更新
- **三条设计原则**：
  1. 从**可塑提议**开始，历史约束不限制当前证据如何改写技能；
  2. 通过选择性审计将预测范围转化为**测量约束**；
  3. 将失败审计用作**修复反馈**而非仅拒绝信号。

### 2.3 算法流程（Algorithm 1）

1. **执行**：用当前技能 St 在批次 Bt 上执行，得到轨迹 Yt；
2. **诊断**：提取诊断 Dt 和语义动量 μt；
3. **记忆**：记忆算子 Γ 记录不可变微胶囊并关联为能力胶囊，得到 (Mt, Zt)；
4. **提议**：修订算子 P 生成无约束候选 (Ŝt, σ̂t)，σ̂t 预测预期修复、受影响能力、排除范围与不确定性；
5. **风险审查**：风险算子 R 对每个历史胶囊 h 计算干扰风险 ρt(h)；
6. **审计路由**：审计路由器 S 选择最高风险/最不确定能力，以及一个种子随机的预测安全能力（探测假阴性），形成审计库 Vt；
7. **可接受性判定**：候选需在当前库上词典序改进，且在任何选定历史库上无净硬损失：
   - Kt = { S′ | U_Vcur(S′) ≻lex U_Vcur(St), 且 H_Vh(S′) ≥ H_Vh(St) ∀h ∈ At }
8. **迭代投影**：若候选不可接受，收集证据 Ω(k)t = (σ̂t, ρt, {(S(j)t, E(j)t)})，由 LLM 推理算子 Πsem 构造下一候选，最多 Kproj 轮；
9. **更新决策**：接受首个可接受候选；若无，则保留父技能 St+1 = St；
10. **持久化**：封存技能、评估证据与记忆，形成可审计状态。

- **关键点**：Πsem 可自由改写技能任意部分，宿主不施加修复语法，仅负责证据溯源与经验接受测试。整个过程不向演化模型暴露语义领域身份。

## 6. 主要结论与发现

- **受控合成**：SSPE 相对 SkillGrad 将平均遗忘降低 **55.84%**，最终宏能力提升 **+0.3211**，累积前序奖励提升 **+0.09345**，有害更新率降低 **0.3899**；但即时当前能力增益比 SkillGrad 低 **0.02864**，超过预注册容忍损失 0.02，暴露真实的稳定性—可塑性权衡。
- **真实异构流**：SSPE 留下最强的最终冻结技能，平均准确率 **77.50%**（相对无技能执行器 +5.62），在 BFCL 上优势最明显（65.00%，+20.00），在 DocVQA 上匹配最佳（95.00%）。
- **跨模型迁移**：GPT-5.4 演化的 SSPE 技能迁移到 GPT-4.1 后平均准确率 **63.75%**（+3.44），仍为最强，在 BFCL 与 DocVQA 上尤其有效，表明学到的是可移植的过程性指导而非模型特异性行为。
- **消融**：移除历史证据（SSPE-NoHistory）消除了总体优势（平均 73.44% vs 77.50%），说明历史行为证据对跨域兼容性至关重要；增加投影预算（Kproj=2 或 5）不提升最终准确率，默认 Kproj=1 最强，且该结论在 GPT-4.1 上重复。
- **定性案例**：SSPE 在 BFCL 多轮任务中达到 6/6 正确轮次前缀，SkillGrad 为 5/6，SkillOpt 为 1/6，展示 SSPE 能沿错误揭示的前置条件链继续执行并完成待定副作用动作。

## 7. 优点

- **理论迁移清晰**：将 OGD 的功能不变量（保留有用更新、移除改变受保护行为的部分）从参数空间优雅地迁移到行为空间，表 1 的类比明确且具启发性。
- **建设性修复机制**：不同于验证门仅接受/拒绝，SSPE 将观测到的冲突作为修复反馈，让 LLM 构造兼容修订，这是方法的核心创新。
- **无需领域身份**：演化模型不接收语义领域名称、领域数量或标记的分布变化，更贴近实际部署。
- **证据溯源与可审计性**：能力胶囊不可变、审计库固定、封存评估证据，保证过程可追溯。
- **实验设计严谨**：受控模拟器与真实流互补，跨模型迁移验证可移植性，消融清晰分离历史证据与投影深度的贡献。
- **诚实报告权衡**：明确承认即时可塑性损失超过预注册容忍度，并指出受控研究不建立对原生优化器的优越性。

## 8. 不足与局限

- **实验覆盖有限**：
  - 持续流仅含有限领域集合，任务按组到达，实际部署可能涉及开放式领域序列与更不规则的转换；
  - 实验主要在固定任务顺序下进行，未研究替代顺序、循环序列与交错流的鲁棒性。
- **受控模拟器的抽象性**：SkillGrad 与 SkillOpt 是机制级抽象而非真实执行，模拟器不执行任务提示，不重现原生方法的文本行为，因此受控结果只能作为机制证据而非排行榜。
- **非严格算力匹配**：Random replay 审计一个历史能力，SSPE 可审计两个，比较并非算力匹配。
- **预算消融的因果限制**：GPT-5.4 采样不可设种子，不同 Kproj 是独立优化谱系，不能隔离单次额外修复调用的因果效应。
- **可塑性代价**：SSPE 即时当前能力增益低于 SkillGrad，存在真实的稳定性—可塑性权衡。
- **应用限制**：方法依赖 LLM 推理算子 Πsem 与风险审查算子 R 的质量，审计库的构建与选择策略可能影响实际效果；未明确报告算力开销，难以评估大规模部署成本。
- **偏差风险**：定性案例为事后选择，作者明确说明其非因果比较；真实流评估中 SSPE 并非在每个基准上都最优（SpreadsheetBench 上无技能执行器最强，SearchQA 上 SkillOpt 最强）。
