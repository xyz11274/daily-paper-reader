## 摘要
近年来，基于大语言模型的多智能体系统被广泛应用于将工具使用智能体编排为可执行的通信图。然而，现有的自演化编排仍面临关键挑战，包括仅在轨迹结束后才调整团队的事后演化、在混杂基线之下为每个动作赋予相同终端优势的信用扩散，以及未经校准且从不退役的技能准入。为应对这些挑战，我们提出EvoSteer，一种在线自演化图编排的新范式——编排器构建一个运行中的团队，并依据执行特征和学习到的价值估计来修复其看似合理但失败的步骤。为支持这一范式，我们引入锚定轨迹平衡（AnchorTB），一种回归式流匹配损失，通过将子轨迹与冻结参考进行平衡，为每个编排动作分配系数。基于学习到的流，我们进一步提出验证式技能准入，其中候选技能在晋升前先进行试用，仅当配对证据在共享的名义测试预算下通过序贯检验时才被晋升。此外，AnchorTB将测得的任务级参考奖励统计与依赖于前缀的校正相结合。在十二个数据集上的实验结果表明，EvoSteer在问答、数学推理、代码生成和交互式决策方面显著优于基线。我们的代码可在https://github.com/beita6969/evosteer获取。

## Abstract
In recent years, LLM-based multi-agent systems have been widely applied to orchestrate tool-using agents into executable communication graphs. However, existing self-evolving orchestration still faces key challenges, including post-hoc evolution that revises the team only after the trajectory ends, credit diffusion that gives every action the same terminal advantage under confounded baselines, and skill admission that is uncalibrated and never retired. To address these challenges, we propose EvoSteer, a new paradigm of Online Self-Evolving Graph Orchestration -- the orchestrator builds a running team and repairs its plausible but failing steps from execution features and a learned value estimate. To support this paradigm, we introduce Anchored Trajectory Balance (AnchorTB), a regression-style flow-matching loss that assigns each orchestration action a coefficient by balancing subtrajectories against a frozen reference. Built on the learned flow, we further propose Validated Skill Admission, in which a candidate skill is tried before promotion and promoted only if paired evidence passes a sequential test under a shared nominal testing budget. Moreover, AnchorTB combines measured task-level reference reward statistics with prefix-dependent corrections. Experimental results on twelve datasets show that EvoSteer significantly outperforms baselines across question answering, mathematical reasoning, code generation, and interactive decision making. Our code is available at https://github.com/beita6969/evosteer.

# EvoSteer 论文深度总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：基于 LLM 的多智能体系统已从单次模型调用发展为工具使用智能体团队，通过"类型化智能体通信图"（节点=角色+技能，边=通信协议）端到端完成任务。图编排成为从任务目标到可复现执行的关键桥梁。
- **三大核心挑战**：
  - **事后演化（Post-hoc Evolution）**：现有自演化编排仅在轨迹结束后（按轮次或批次）修订团队；执行期间编排器只能不断添加智能体，决定性错误与可恢复步骤在局部难以区分，错误智能体在任务失败前既不会被重跑也不会被移除。
  - **信用扩散（Credit Diffusion）**：在共享终端奖励下，轨迹级方法给每个动作相同的终端优势系数；学习到的状态价值混淆了任务被解决的频率、执行噪声与结构选择，编排器无法判断低分来自"参考很少解决的任务"还是"组织糟糕的团队"；反事实回放虽能定位失败步骤，但不为每个决策提供训练信号。
  - **未校准的技能准入（Uncalibrated Skill Admission）**：技能通过 LLM 判断或成功计数被准入，点估计无法区分"证据不足"与"确认效应"，单条轨迹的偶然策略会被固化，且没有检验追踪已准入技能是否仍有用，导致技能永不退役。
- **整体含义**：论文提出 EvoSteer——在线自演化图编排新范式，将构建、修复与技能成长统一为一组在单一训练目标下的学习决策，实现"边运行边演化"的编排。

## 2. 方法论：核心思想与关键技术细节

### 2.1 在线自演化图编排（Online Self-Evolving Graph Orchestration）

- **核心思想**：编排器 πθ 在结构化环境中组织工具使用智能体（执行器冻结），每个动作一经发出立即执行，取代"先运行后修订"的循环。
- **动作空间**：原子编辑类型包括 `ADD_AGENT, ADD_EDGE, BIND_SKILL, SET_OUTPUT, RERUN_AGENT, DROP_AGENT, STOP`；构建与修复共享同一动作空间与策略，掩码 A(s) 依当前图、角色、技能槽、输出模式与预算动态生成。
- **交错执行**：状态更新为 `s_{t+1} = s_t ⊕ (a_t, o_t^exec, f_{t+1})`，其中 f 为 30 维执行特征向量（图规模、动作类型、修复结果、智能体是否作答与一致、通信修订、环境阶段、预算使用），无需额外模型调用。
- **环内参考价值估计**：轻量头 `v̂_ω(s) = σ(MLP_ω[f(s); onehot(tasktype(q))])`，以平方误差回归估计参考续延奖励；其估计值与一步变化作为反馈展示给编排器，用于判断何时停止等决策。

### 2.2 锚定轨迹平衡（AnchorTB）

- **核心思想**：回归式流匹配损失，通过将子轨迹与冻结参考 ρ 平衡，为每个编排动作分配系数。
- **动作对数比**：`Δℓ_t = ℓ_θ(a_t|s_t) − ℓ_ρ(a_t|s_t)`，在相同上下文、token 与语法掩码下计算；单一合法 token 位置贡献为零。
- **子轨迹残差与损失**：对每个区间 `i:j`，残差 `δ_{i:j} = ũ(s_i) + ΣΔℓ_t − ũ(s_j)`，损失 `L_x = (1/K_T) Σ δ²`，其中 `K_T = T(T+1)/2`；每个动作的系数为其所包含所有跨度残差之和。
- **测得的态流（Measured State Flows）**：`ũ(s) = sg[clip_{[0,β]}(u_{q,x} + c(g(s)))] + b_ψ(h_ρ(s), f(s))`，其中 `u_{q,x}` 为任务级部分留一收缩估计的参考平均奖励变换，`c(g)` 为从落后一批的规范前缀结构桶读取的校正，`b_ψ` 为零初始化 MLP 残差。
- **结构校正**：`c(g) = clip[log(1 + Σy_x/(n_g+n_0))]`，伪计数收缩稀有结构，`c_max` 有界；测得项固定不传梯度，仅更新 πθ 与 b_ψ。

### 2.3 验证式技能准入（Validated Skill Admission）

- **技能提议**：作者模型在作者窗口内从有评分、无副作用的轨迹中蒸馏至多一个候选技能 σ（结构化过程：名称、描述、触发、计划、陷阱、约束），占用候选槽位，在验证前即可被 `ADD_AGENT`/`BIND_SKILL` 选择。
- **配对反事实 rollout**：同一记录、同一强制首角色下启动两条轨迹（绑定 σ 与不绑定），均由参考策略续延；按终端奖励阈值通过率累计胜 W、负 L、平 T₀。
- **序贯验证**：每个候选在验证轮获得双向二项符号检验尾概率 `p+ = P(Bin(D,1/2) ≥ W)`、`p− = P(Bin(D,1/2) ≥ L)`；清除边界则晋升或退役，否则继续累积。
- **预算控制**：`α_{j,ℓ} = α/(j(j+1)ℓ(ℓ+1))`，每方向获一半；仅在出现新证据时消耗预算，总名义水平至多 α，由联合界保证族错误率（FWER）不超过 α（即使检验相关）。

## 6. 主要结论与发现

- **主结果**：EvoSteer 在全部 12 个基准上最优，IID 平均领先最强基线 2.81 EM / 4.01 Acc.，OOD 领先 3.36 / 2.53；AIME 2026 领先最大（8.67），MATH-Hard 最小（0.78，骨干接近上限）。
- **骨干训练 vs 编排**：仅训练骨干（SFT、GRPO†）最多为 IID EM 平均增加 6.09 分，说明增益来自同一冻结执行器上的编排；9B 执行器的 EvoSteer 在所有基准上击败更大的 DeepSeek-V4-Flash。
- **骨干迁移**：训练后的编排器原样迁移到 6 个其他执行器，改善全部 72 个分数；较弱执行器增益更大，IID 跨骨干差距从 17.5 缩至 4.3 分。
- **组件贡献**：交错执行、执行特征 f、可学习修复、参考价值头分别贡献 5.69、4.12、3.57、5.07 IID 分；测得流是 IID 最大单项贡献（自由标量 u_q 损失 6.59 分）；技能演化移除损失 5.27 IID / 3.26 OOD 分。
- **锚的有效性**：锚在 rollout 开始前预测参考结果 AUC 0.812（任务族均值仅 0.506）；学习部分使损失低于仅锚水平。
- **目标对比**：仅更换损失，AnchorTB 比 Tempered TB、TB、PPO、GRPO 高 3.17–8.81 IID 分。
- **技能准入**：接受所有候选平均 +2.76 但伤害 MedQA 与 AIME 2026；验证式准入在全部 6 个 IID 数据集上均有益（+5.95）。
- **环内编辑**：84.2% 提升评分，6.6% 降低；修复类编辑 80.7% 提升；价值引导重规划在两个执行器、所有 IID 数据集上均有益。
- **架构与训练各自贡献**：未训练架构为冻结执行器增加 21.01 IID / 24.04 OOD 分，AnchorTB 训练再增 12.31 / 11.22 分。

## 7. 优点

- **范式创新**：将"运行后修订"转为"运行中编辑"，rerun 与 drop 作为普通动作，使决定性错误可在同一 episode 内被修复，避免错误累积。
- **信用分配精细**：AnchorTB 通过所有子轨迹残差为每个动作分配系数，而非轨迹级单一终端优势；结合任务级参考锚与前缀结构校正，缓解信用扩散与基线混淆。
- **统计严谨的技能管理**：配对反事实 rollout + 序贯符号检验 + α 花费预算，提供名义 FWER 保证；技能可晋升、退役或延迟，解决"从不退役"问题。
- **理论完备**：附录给出完整证明（历史树唯一父节点、理想零残差一致性、动作系数矩阵形式与正定性、序贯检验有效性、FWER 界等）。
- **实验扎实**：12 个数据集、5 次运行、8 个消融、6 个骨干迁移、多种目标对比，覆盖广泛且报告标准差。
- **实用性强**：执行特征无需额外模型调用；价值头 CPU 评估无额外编码器调用；代码与配置公开。
- **案例生动**：MBPP+ 案例展示"表面通过可见测试但隐藏测试失败"的代码被 v̂ 下降（−0.216）触发 rerun 并修正，直观说明机制有效性。
