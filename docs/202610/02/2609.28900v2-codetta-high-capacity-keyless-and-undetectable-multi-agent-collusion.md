## 摘要
基于大语言模型（LLM）的多智能体系统正越来越多地部署在金融、医疗和软件工程等高风险场景中，其中智能体通过自然语言消息进行协调。然而，同样的通道也让串通的智能体能够泄露机密信息或协调未经授权的行为，而隐写术可以将此类通信隐藏在审计人员阅读记录时看起来普通的输出中。现有的可证明不可检测的LLM隐写协议并不适合现实部署。高容量方案假设接收方能够重现发送方的输出分布的对称设置，针对非对称智能体的最先进协议容量非常低，并且大多数方法依赖预共享密钥。我们通过Codetta将不可检测的智能体串通威胁具体化，Codetta是一种用于现实非对称设置中独立部署智能体的高容量隐写协议。Codetta结合了一个估计通信信道的共享公共模型、一种保持发送方输出分布的采样机制以及一种自适应纠错码。它还通过隐写密钥交换消除了预共享密钥，使独立部署的智能体能够建立共享密钥，同时保持记录在计算上与普通模型输出不可区分。在三种智能体工作负载和三种发送方模型上，Codetta达到了最先进非对称协议容量的最高94倍，并且其密钥交换在大约8万个可见token下建立了共享密钥，经验证实的失败概率至多为4.1×10^{-3}。这些结果表明，在独立部署的智能体之间，有效不可检测的串通正变得可行，因此审计必须超越检查通信记录。

## Abstract
Multi-agent systems built on large language models (LLMs) are increasingly deployed in high-stakes settings such as finance, healthcare, and software engineering, where agents coordinate through natural-language messages. The same channels, however, let colluding agents exfiltrate confidential information or coordinate unauthorized actions, and steganography can hide such communication inside outputs that look ordinary to an auditor reading the transcript.   Existing provably undetectable LLM steganography protocols are not suited to realistic deployments. High-capacity schemes assume a symmetric setting where the receiver can reproduce the sender's output distribution, the state-of-the-art protocol for asymmetric agents has very low capacity, and most approaches rely on a pre-shared secret key.   We make the threat of undetectable agent collusion concrete with Codetta, a high-capacity steganographic protocol for independently deployed agents in realistic asymmetric settings. Codetta combines a shared public model that estimates the communication channel, a sampling mechanism that preserves the sender's output distribution, and an adaptive error-correcting code. It further removes the pre-shared key through a steganographic key exchange that lets independently deployed agents establish a shared key while keeping the transcript computationally indistinguishable from ordinary model outputs.   Across three agent workloads and three sender models, Codetta achieves up to $94\times$ the capacity of the state-of-the-art asymmetric protocol, and its key exchange establishes a shared key with about 80k visible tokens at an empirically certified failure probability of at most $4.1\times 10^{-3}$. These results show that effectively undetectable collusion is becoming feasible between independently deployed agents, so auditing must go beyond inspecting communication transcripts.
