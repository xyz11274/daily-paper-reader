## 摘要
迭代式自蒸馏使LLM智能体能够从连续部署中学习，为递归自我改进（RSI）提供了一条路径。然而，我们对现有方法的实验揭示了跨周期部署性能的崩溃，同时使用特权信息（PI）的任务性能也下降。我们通过优先选择信息量大的交互步骤进行蒸馏，并在学生成为下一个教师时保留PI条件下的行为，来解决这种崩溃。我们提出了保留与选择性增强的迭代自蒸馏（ReSAIL），这是一种用于迭代式基于PI的自蒸馏的即插即用增强方法。ReSAIL选择PI最强烈改变教师预测的交互步骤，并平衡跨轨迹产生的蒸馏损失。它还将学生的PI条件输出分布正则化到所选和未选步骤上冻结教师的分布，以保留PI条件行为用于下一周期的监督。在ALFWorld和TextCraft上，ReSAIL在三个周期内跨模型规模持续获得显著增益，当添加到自蒸馏基线时，最终周期成功率的平均绝对增益为22.5%。基于敏感性引导的离线数据选择也提高了AITZ上多模态GUI智能体的动作预测准确性。这些发现首次证明，更稳健的学习机制能够有效缓解迭代式智能体自蒸馏在部署轨迹中的性能崩溃。

## Abstract
Iterative self-distillation enables LLM agents to learn from successive deployments, offering a path toward recursive self-improvement (RSI). Yet our experiments with existing methods reveal a collapse in deployment performance across cycles, while task performance with privileged information (PI) also declines. We address this collapse by prioritizing informative interaction steps for distillation and preserving PI-conditioned behavior as the student becomes the next teacher. We introduce Retentive and Selective Augmentation for Iterative Self-Distillation (ReSAIL), a plug-in augmentation for iterative PI-based self-distillation. ReSAIL selects interaction steps where PI most strongly changes the teacher's predictions and balances the resulting distillation losses across trajectories. It also regularizes the student's PI-conditioned output distributions toward those of the frozen teacher at selected and unselected steps to preserve PI-conditioned behavior for supervision in the next cycle. On ALFWorld and TextCraft, ReSAIL sustains substantial gains across model scales over three cycles, with an average absolute gain of 22.5% in final-cycle success rates when added to self-distillation baselines. Sensitivity-guided selection of offline data also improves action prediction accuracy for multimodal GUI agents on AITZ. These findings provide the first evidence that a more robust learning mechanism can effectively mitigate performance collapse in iterative agent self-distillation over deployment trajectories.

## 1. 核心问题与研究动机

- **背景**：LLM 智能体通过多步环境交互生成轨迹，并从中学习以改进未来决策。将这一反馈闭环迭代化，有望实现递归自我改进（RSI）。
- **现有路径**：基于特权信息（Privileged Information, PI）的自蒸馏将训练时可用、部署时不可用的信息（如参考解、事后反馈、经验总结）蒸馏进模型参数；OEL 进一步将经验收集与离线自蒸馏交替进行，跨多个部署周期迭代。
- **核心问题**：作者实验发现，重复自蒸馏**并不保证持续改进**——SDPO 和 OEL 在连续部署周期中出现**部署性能崩溃**（图 1a），同时**PI 条件下的任务能力也逐周期下降**（图 1b）。
- **两个关键追问**：
  - **Q1**：哪些交互步骤应优先用于蒸馏？作者假设 PI 最强烈改变教师预测的步骤最具信息量，并用 **PI 敏感度**（教师有无 PI 时输出分布的 Jensen–Shannon 散度）量化。
  - **Q2**：学生成为下一周期教师时会发生什么？基础目标仅训练学生无 PI 视图，未显式保留其 PI 条件行为，导致下一周期监督信号退化。

## 2. 方法论：ReSAIL

### 核心思想
ReSAIL 是迭代式 PI 自蒸馏的**即插即用增强**，包含两个互补模块：
- **TBSD（轨迹平衡选择性蒸馏）**：周期内选择性蒸馏。
- **PR（特权保留）**：跨周期保留 PI 条件行为。

### 关键技术细节

**（1）基础设置与基础自蒸馏**
- 周期 r 中，起始策略 πr 与固定轨迹数据集 Dr 配对，训练不再与环境交互。
- 策略有两个共享参数的视图：普通视图 π(·|h) 与特权视图 π(·|h, c)。
- 学生 πS 与冻结教师 πT 均从 πr 初始化；更新后的学生定义 πr+1，部署时无 PI。
- 基础目标为普通视图学生对特权视图教师的 token 平均 KL 散度，在所有步骤 U 上均匀平均（式 1–2）。

**（2）TBSD**
- **SGS（敏感度引导选择）**：用教师 PI 敏感度 s(τ,t) = JSD(普通视图, 特权视图) 对每步打分，按选择比例 ρ 保留全批次最高分步骤（式 3–4）。
- **TLB（轨迹损失平衡）**：先在各轨迹内平均所选损失，再按完整轨迹批次大小归一化，避免步骤多的轨迹获得过大总权重（式 5）。

**（3）PR（特权保留）**
- 将学生的**特权视图**输出分布正则化到冻结教师的特权视图分布（式 6）。
- 覆盖 U 中**所有步骤**（含未被选中的步骤），采用与 TLB 相同的轨迹级归约（式 7）。
- 目的：保留下一周期作为教师时所需的 PI 条件行为。

**（4）联合目标与优化**
- 总损失 L = Lsel + λ·Lret，λ ≥ 0 控制保留强度（式 8）。
- 每次更新重新计算教师敏感度分数与选中集合，反向传播时固定。
- 实现细节：Top-20 加残差尾部近似计算 JSD 与 KL；AdamW，恒定学习率 1e-6，无 warmup。

## 6. 主要结论与发现

- **最终周期性能更高**：SDPO+ReSAIL 与 OEL+ReSAIL 在全部 6 个模型–基准设置上超越所有未增强基线；相对父方法，SDPO 提升 7.0–26.1 个百分点，OEL 提升 20.3–37.0 个百分点。
- **跨周期持续增益**：增强方法在每个周期均优于父方法，且三个周期均值非递减；而 OEL 在全部 6 个设置中最终低于首周期，SDPO 在 5 个设置中如此。
- **组件互补**：SGS 在首周期贡献最大；TLB 改善第三周期；PR 改变跨周期轨迹，使完整方法在 Cycle 2/3 达到最高。
- **选择标准有效**：Top 选择显著优于 Random 与 Bottom，说明收益来自优先 PI 敏感步骤而非任意稀疏化。
- **PR 保留 PI 条件能力**：无保留时 PI 条件成功率从 61.5% 降至 44.8%；有 PR 时从 58.9% 升至 70.3%。
- **超参数**：默认 ρ=0.05、λ=0.5 最优；λ=1 反而下降。
- **泛化性**：SGS 作为离线多模态数据过滤器，在 AITZ 上提升最终动作准确率 1.06 个百分点（65.95% vs 64.89%）。

## 7. 优点

- **问题识别精准**：首次系统揭示迭代自蒸馏的跨周期崩溃现象，并区分部署性能与 PI 条件能力两条退化路径。
- **方法即插即用**：ReSAIL 可叠加在 SDPO、OEL 等不同基线上，无需额外环境交互，适用于部署环境不可重访的受限场景。
- **机制设计有针对性**：SGS 用 JSD 量化 PI 影响、TLB 解决轨迹权重失衡、PR 针对"学生变教师"的角色转换，三者逻辑自洽。
- **实验受控严谨**：固定任务、固定 PI、匹配预算与批次，消融设计能清晰分离各组件贡献。
- **效率分析透明**：给出训练循环成本分解，指出 SGS 反而降低学生优化成本。
- **跨模态验证**：将 SGS 扩展到 GUI 智能体离线数据过滤，增强结论外推性。

## 8. 不足与局限

- **基准覆盖有限**：文本任务仅 ALFWorld 与 TextCraft，AITZ 仅单周期、单一模型，未覆盖更复杂的长程或真实环境。
- **统计强度不足**：仅 3 个解码种子，误差棒为解码变异而非训练变异；PI 敏感度诊断仅 1 个种子、固定探针，非独立留出集。
- **算力开销**：完整 ReSAIL 训练成本约为 OEL 的 1.23 倍，PR 需对所有步骤做特权视图前向/反向，扩展到大模型或长轨迹时成本可能显著。
- **超参数敏感**：ρ 与 λ 需调优，λ=1 时性能下降，跨任务迁移时最优值可能不同（如 TextCraft 用 ρ=0.25、λ=1.0）。
- **PI 依赖**：方法假设存在高质量 PI（经验摘要），PI 生成质量与固定 PI 评估协议未充分探讨其上限影响。
- **理论分析缺失**：未从理论上解释崩溃机制或 PR 为何有效，主要依赖实证。
- **应用限制**：需离线固定数据集，无法在训练中重访环境；对无法获得有意义 PI 的任务不适用。
